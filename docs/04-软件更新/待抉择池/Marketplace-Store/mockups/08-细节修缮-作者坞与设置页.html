1.3 修法（三条，缺一仍可能切）

/* store-dock.css —— ① 列表给内边距：卡的任何描边/阴影不贴裁切边 */
.marketplace-store-dock-list {
  padding: 8px 14px 14px;
}
/* ② 坞内卡不参与「悬停抬升/放大」——坞是窄容器，放大必然被面板 overflow 裁 */
.marketplace-store-dock-list .marketplace-store-author-card:hover,
.marketplace-store-dock-list .marketplace-store-author-card:focus-within {
  transform: none;
}
/* ③ 卡宽改「填满可用宽」而不是 100%!important —— 让 border-box 自己算 */
.marketplace-store-dock-list .marketplace-store-author-card {
  width: 100% !important;
  width: auto !important;
  align-self: stretch;
}

为什么不是把面板 overflow 开成 visible：面板有圆角＋磨砂，hidden 同时负责「列表滚动边界」。开 visible 会让滚动内容从圆角外溢。给列表留 padding 是等价且更稳的做法。

1.4 验收

  • 面板展开 → 指针停在卡上 3 秒：左右边框、外阴影完整，卡宽不跳。
  • 鼠标从卡移到面板边缘（10px 缝）不丢面板（既有行为不回退）。
  • 窄容器（≤760px）降级抽屉下同样不裁。

二、作者页「浏览 / 管理来源」记上次

2.1 行为表（用户口径）

入口打开哪个模式是否写回记忆
作者坞点「作者页」浏览写
作者坞点「管理来源」管理来源写
作者卡 / 作者页里点某个作者进入（直接点作者）上次的模式—
页内切「浏览 ↔ 管理来源」即时切写
首次使用（无记忆）浏览（默认）—
命令面 marketplace.openAuthors / marketplace.openSources分别强制 浏览 / 管理来源写

2.2 存在哪：不会多出「数据位置」行

复用现成的 UI 偏好存储（与「库/作者页的视图方式、排序」同一个抽屉）：

pluginState("marketplace", "ui.prefs")  →  壳的 plugin-states.json
新键：authorMode: "browse" | "manage"（默认 browse，坏值回落）
⛔ 不进 contributes.configuration（那是用户可见的公开设置）
⛔ 不写插件的 dataDir ⇒ 插件详情页右侧不会出现「数据位置」行

你担心的「缓存到插件市场详情页右边出现缓存地址」不会发生：ui.prefs 走壳的统一状态文件，插件自己不落盘。清理方式：清市场缓存 / 重置应用数据（与现有视图偏好同一入口）。

2.3 验收

  • 管理来源 → 关掉软件 → 重开 → 直接点作者：进「管理来源」。
  • 同一会话里从坞点「作者页」：强制浏览并写回；再点作者：浏览。
  • 首次装（无状态文件）：默认浏览。

方案改什么效果发版
A（推荐） marketplace 插件：contributes.configuration 的 order＋title＋description；标题去长句、说明收短 开关上移、文案更短；但「商店行为 / 市场源」两块灰色小节头做不出来（配置 schema 没有分组键） 插件 1.4.1

4.3 方案 B：免费开源照片（真实感，但只能做氛围）

可用的免费来源：Wikimedia Commons（CC0/CC-BY，需在使用处标注来源）、Unsplash / Pexels（免费商用、建议署名）。照片能拍出「码屏 / 电路 / 纸质文档」的质感，但拍的不是这只插件的界面——所以只建议做第 3 帧的氛围图，第 2 帧仍用方案 A。
