## §二 设计前置（design-flow 8 维度）

**① 能力边界**：壳能力——欢迎页与空场背景都是壳兜底。保底设计（W7 拍板后）：**零标签 ⇒ 空场背景**（`MainZone.tsx:146-160` 既有零组空态分支升级为品牌空场；纯静态资产，零插件恒可渲染）；欢迎页改为**纯显式打开**（openWelcome 命令／+菜单／帮助菜单）。边界裁决记档：**壳兜底区块（文件夹/帮助骨架）写死 = 合理；生态联动区块（开始/最近）必须声明式驱动**。

**② API**：无新命名空间。W1 = 推流 payload 扩列（`CreatableViewMeta` 加 `icon`/`iconSource` 可选字段，L9 契约只加不删）。W3 失效校验走既有 `filesystem.exists` IPC（`electron/ipc/handlers/file-handlers.ts:54`）。**回执消息（🔴 2026-10-01 用户指令改判，见文首横幅）**：复用既有 `linkdesk.notifications.show(message, options)`（`electron/preload-pool/namespaces-workspace.ts:36-72`）**零加列**——三条提示走缺省（进铃铛面板、自动弹开、到点自消）；原「加 `toast?: boolean` ＋ 池侧新建轻提示呈现层」已整笔删除。W4 新壳命令 `app.openWelcome`（meta 带 description＋params，硬约束 26；`manual:build` 经 CommandRegistry 自动收录，scripts/build-ai-manual.mjs 仅 vitest 薄壳）。

**③ 通信**：推流（壳 → 池 poolLayout payload）→ 池渲染；点击回 `pool.tabAction`（既有）；持久化 `pluginState("app", ...)`（既有，唯一读写点仍在本组件）；通知走既有 `notifications.show` → preload `IPC.plugins.call('showNotification')` → `IpcBridgeHandler/ui.ts:265` 分发（全链现成，池侧呈现层新增）。铁律合规：池侧零 @src/core import。

**④ 壳侧代码**：改动落点（全部既有文件）——`usePoolSync.ts:324`、`src/core/types/pool/poolLayout.ts:407-411`、`WelcomePoolView.tsx/.css`、`GroupTabBar.tsx:393-443`、`shellMenus.ts:69-111`、`windowLayout.ts:202`、`defaults.ts:90-128`、`useTabManager.ts:249/390/395/400/420`、`windowRelocation.ts`、`App.tsx:120`、`MainZone.tsx:146-160`、`ThemeEngine/seeds.ts:291-299`＋`constants.ts:122-127`、命令注册（shell 命令文件）。**不新增目录**；新增文件仅一个组件级：池侧 `EmptyStage`（空场层，落 `src/pool/shared/`，遵循壳目录规范 feature 分组）。单一权威：creatableViews 唯一来源仍是 viewRegistry，欢迎页与「+」菜单同吃一份数据。

**⑤ 插件侧**：`packages/plugin-sdk/schemas/plugin.schema.json:36-45`——`appearsIn` 是 **manifest 顶层字段**（非 contributes.views），新布尔 `standaloneOpenable` 加在 `appearsIn.properties` 内与 `tabBar` 同级；SDK 门禁/脚手架模板（create-linkdesk-plugin/template/plugin.json:37 同笔加示例或保持缺省）；作者面 `docs/03-插件制造/` 同步（贡献点三件套）；测试 fixture 虚构名（硬约束 21）。loader 消费点无需改（viewRegistry 读 manifest 原样）。⚠️ 缺省 false 是 **breaking**（连带见 00-README §四2）。

**⑥ 显示**：欢迎页 = 主区标签内容（现状）；空场层 = 主区零标签态（`EmptyStage`，GroupPane 零 tabs 与 MainZone 零 groups 两处复用同一组件）；回执消息 = 铃铛面板缺省形态（`notifications.show` 不带呈现选项 ⇒ 进面板、自动弹开、6s 自消）；「⌨」换 lucide `Keyboard`。数据来源逐块：hero（静态）、文件夹（workspace API ＋ pluginState）、开始（creatableViews＋identity art）、最近（pluginState ＋ exists 校验）、帮助（静态命令引用）。

**⑦ 配置**：无新配置项。字体复用既有 `app.fontFamily`（appearance.ts:416-433，uiHint "fontFamily"、`__none__` 哨兵 = constants.ts:172）——新增派生 token `--font-mark`（非配置）：`app.fontFamily` 显式设置 = 其值；未设 = 衬线栈 `'Newsreader','Lyon Text',Georgia,'Songti SC','SimSun',serif`（用户指定，见 §三 W7）。

**⑧ 代码规范＋验收**：颜色全 var(--xxx)；文字全 `t()`；命名 `ldk-welcome-*`／`ldk-empty-stage-*` 命名空间内；验收矩阵见 §五。

**10 条理念对照**：声明式（W2 准入权交 manifest）· 禁硬编码（不写插件名单，identity 走 pickIdentityArt）· AI 友好（openWelcome 命令化＋notifications.show 可编程）· 归一性（图标/文案/入口与市场、关于页、帮助菜单同源）· 插件自由（准入一行声明）。其余条目不受本件影响。
