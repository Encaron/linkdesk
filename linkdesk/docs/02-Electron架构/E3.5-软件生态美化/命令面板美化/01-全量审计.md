## 二、视觉层——逐项差距

### 2.1 快捷键显示 🔴 最大缺失

| | VS Code | LinkDesk |
|------|---------|----------|
| 显示位置 | 每行右侧，始终可见 | **无**（仅 hover 露齿轮 ⚙） |
| 样式 | keycap pill——`Ctrl+K` 小圆角矩形 | — |
| 数据来源 | KeybindingResolver → `resolvedKeybindings` | `KeybindingRegistry` 已完成（E3f #59），**数据现成** |

**影响：** 快捷键是用户学软件的入口。Ctrl+Shift+P 打开命令面板，最常见场景就是"我不知道快捷键是什么，搜一下"。结果搜到了，快捷键仍然看不到——命令面板的核心价值打折。

### 2.2 开合动画 🔴

| | VS Code | LinkDesk |
|------|---------|----------|
| 出现 | scale(0.95→1) + opacity(0→1) ~150ms | 瞬间出现 |
| 消失 | opacity(1→0) ~100ms | 瞬间消失 |
| 遮罩 | 同步 fade | 瞬间 |

**影响：** 命令面板是高频操作，瞬间出现/消失 = "卡了一下"的体感。加 150ms transition 后体验立刻提升。QuickPick 是归一化壳——改一处，主题浏览器、语言选择器一起受益。

### 2.3 空态 🔴

| | VS Code | LinkDesk |
|------|---------|----------|
| 无匹配 | "No matching commands" | **空白列表** |

**代码位置：** `QuickPick.tsx:179`——`filtered.map(...)`，`filtered` 为空时什么都不渲染。用户不知道是卡了还是真的没匹配。

### 2.4 `>` 前缀指示器 🟡

| | VS Code | LinkDesk |
|------|---------|----------|
| 输入前缀 | `>` 字符标明"命令模式" | 仅占位文字"输入命令…" |

VS Code 的 `>` 有双重含义：
1. 视觉上——一眼知道"我在命令面板里"（不是文件搜索 `Ctrl+P`）
2. 功能上——切换前缀字符可以改变模式（`?`=帮助，`>`=命令，无前缀=文件）

LinkDesk 目前只有命令模式（没有文件搜索），`>` 的"模式切换"价值暂无，但**视觉标识**价值存在——用户打开面板时，第一眼看到 `>` 就知道这是命令面板而不是别的浮层。

### 2.5 命令 ID 行 🟡

| | VS Code | LinkDesk |
|------|---------|----------|
| detail 行 | 无（快捷键已够） | 显示 `linkdesk.toggleTheme` 等原始 ID |

**代码位置：** `CommandPalette.tsx:56`——`<span className="palette-item-detail">{cmd.id}</span>`

对开发者有用，对终端用户是噪音。VS Code 不显示 command ID——如果用户需要知道 ID（写快捷键配置），从齿轮进去的快捷键设置页可以看到。

**替代方案：** 
- A) 删掉 ID 行，换成快捷键显示区
- B) ID 保留但改为 tooltip（`title` 属性）
- C) ID 行保留，快捷键另起一行 → 太挤，不推荐

### 2.6 清除按钮 🟢

| | VS Code | LinkDesk |
|------|---------|----------|
| 输入清除 | 无（原生无此需求） | 无 |

VS Code 也没有清除按钮——键盘用户直接 `Escape` 关面板、`Backspace` 删内容。但鼠标用户没有快速清空输入框的入口。成本极低（~3 行 JSX + CSS），可加。

### 2.7 响应式高度 🟢

```css
/* 当前——写死 */
.palette { max-height: 300px; }
.palette-list { max-height: 240px; }
```

VS Code 的 quickInput 高度是**动态**的——根据列表项数量自适应，最小 1 行，最大撑到接近窗口底部。LinkDesk 写死 300px，小屏幕（1366×768 笔记本）没问题，但大屏幕浪费空间。

### 2.8 结果计数 🟢

VS Code 不显示结果计数（也确实不需要——眼睛扫一下就知道有几个）。但 LinkDesk 可以加一个低调的"X 个命令"，增强反馈感。**非必需，可选。**

### 2.9 滚动条样式 🟢

当前无自定义滚动条样式。列表中项目少时滚动条不出现，项目多时走浏览器默认（Windows 下粗滚动条）。加 4 行 `::-webkit-scrollbar` 统一风格。
