# 08-dependsOn + Accent Mode（强调色联动）

> **类型：壳级别** — 设置页声明式依赖机制，改核心设置渲染逻辑，随壳版本发布。
> **状态：🔥 第八优先——小而精，设置页第一个 dependsOn 消费方**
> 让设置页"强调色"行跟着"强调色模式"智能显隐。4 行声明式代码 + 1 个动画。

---

## 基本逻辑

设置页有两行相关配置：
1. **强调色模式**：`跟随主题` / `自定义`
2. **强调色**：颜色值（仅"自定义"时显示）

当用户选择"跟随主题"时，"强调色"行自动隐藏（带平滑折叠动画）。选择"自定义"时滑出。

**核心原则：** 这是 `dependsOn` 机制的第一个消费方——验证声明式依赖的设计是否正确。

---

## 处于软件内位置

```
左下角齿轮 → 设置 → 外观分类
  ├─ 主题：           [暗色默认     ▼]
  ├─ 强调色模式：     [跟随主题     ▼]  ← 选择"自定义"→
  ├─ 强调色：         [████████] #FF6B8A  ← 这行滑出，可点击打开 ColorPicker
  └─ 文件图标主题：   [默认         ▼]
```

**依赖关系声明：**
```json
{
  "accentColor": {
    "dependsOn": {
      "setting": "accentMode",
      "value": "custom"
    }
  }
}
```

## 关键交互

| 交互 | 触发 | 行为 |
|------|------|------|
| **切换模式** | 下拉选择"跟随主题"→"自定义" | "强调色"行 `max-height: 0 → 48px`，200ms 缓动 |
| **切换回跟随** | 下拉选择"自定义"→"跟随主题" | "强调色"行 `max-height: 48px → 0`，200ms 缓动，同时应用主题默认强调色 |
| **选颜色** | 点击强调色色块 | 弹出 ColorPicker（#04），悬浮在色块旁边 |
| **颜色确认** | ColorPicker 中 ✓ | 色块更新颜色，实时应用到全窗口 |
| **动画细节** | 折叠/展开 | `overflow: hidden` + `max-height` 过渡，防止内容在折叠时溢出 |

### 动画规格

```css
.accent-color-row {
  max-height: 0;
  overflow: hidden;
  opacity: 0;
  transition:
    max-height 200ms cubic-bezier(0.4, 0, 0.2, 1),
    opacity 150ms ease;
}

.accent-color-row.visible {
  max-height: 48px;  /* 单行高度 */
  opacity: 1;
}
```
