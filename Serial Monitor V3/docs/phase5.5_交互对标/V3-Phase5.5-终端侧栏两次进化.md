## 二、5.5 进化——控制面板 + 可折叠树 + 改名

### 侧栏布局

```
┌──────────────────────┐
│ 📟 终端 #1  [✎]       │  ← 可编辑的会话名 → 标签页标题联动
│ COM3 ● 已连接  [断开]  │  ← 连接状态 + 操作按钮
├──────────────────────┤
│                      │
│ ▶ 快捷发送        [编辑]│  ← 可折叠区块（默认展开）
│   ┌────┬────┬────┐   │
│   │ AT │+CWLAP│+JAP│  │  ← 快捷发送药丸
│   └────┴────┴────┘   │
│   [+ 添加]            │
│                      │
│ ▶ 发送栏              │  ← 可折叠区块
│   [______________]    │  ← Monaco 单行
│   [发送]              │
│                      │
│ ▶ 收发统计            │  ← 可折叠区块
│   TX: 1,234          │
│   RX: 56,789         │
│                      │
├──────────────────────┤
│                      │
│ ▼ 设置               │  ← 可折叠区块（默认合上）
│   时间戳格式 [HH:mm:ss ▼]│
│   显示行号    [✓]       │
│   显示回显    [✓]       │
│   编码       [UTF-8 ▼]  │
│   ...更多设置...        │
│                      │
└──────────────────────┘
```

### 三个终端的标签栏

### 核心交付：`<SidebarSection>` 通用组件

```typescript
// src/components/shared/SidebarSection.tsx（~60 行）
interface SidebarSectionProps {
  title: string;
  collapsible?: boolean;       // 是否可折叠（默认 true）
  defaultOpen?: boolean;       // 默认展开/合上
  badge?: string | number;     // 右侧标记（如 "(3)"）
  actions?: ReactNode;         // 右侧操作按钮（如 [✎] [编辑]）
  children: ReactNode;
}

// 对标 VS Code 侧栏树形视图的 section header：
//   ▶ 控制面板          ← 合上状态
//   ▼ 控制面板          ← 展开状态，左侧三角箭头旋转
```

**不只是终端用：**

```
文件树侧栏:                  数据库浏览器侧栏:
▶ 工作区文件夹 (2)            ▶ 表 (5)
▶ 大纲                       ▶ 查询历史
▶ 时间线                     ▶ 收藏

Git 侧栏:                   任何插件侧栏:
▶ 更改 (3)                   ▶ [自定义分组]
▶ 暂存的更改 (1)             ▶ [自定义分组]
▼ 未跟踪的文件 (2)           ▼ [自定义分组]
  ├── src/new.c                ├── [内容]
  └── test/new_test.c          └── [内容]
```
