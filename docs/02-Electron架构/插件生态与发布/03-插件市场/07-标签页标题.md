# 标签页标题——市场图标 + 插件名

> 对应任务：E6#30.7。市场第一站设计的标签页维度（原 03-市场交互设计 §七 拆出）。
> 文档归属：市场设计文档族（[03-市场交互设计.md](03-市场交互设计.md) = 总览索引）。

**根因（已实锤）：** `getDefaultLabel`（[tabIdentity.ts:280](../../../../src/core/utils/tabIdentity.ts)）只读 `opts?.detailPluginId`，4 个 list view 全传 `opts.pluginId` → 永远兜底「插件详情」。`findTabByIdentity` / `isSameTabIdentity` 都有 pluginId 兜底（[:187](../../../../src/core/utils/tabIdentity.ts) / [:255](../../../../src/core/utils/tabIdentity.ts)），唯独 getDefaultLabel 漏。

**目标形态：** 标签 = **[🧩 市场图标] + 插件名**
- 修复：`opts?.detailPluginId ?? opts?.pluginId`。
- 图标：市场视图开详情时传自己的图标（`tabs.create` 加 `icon` 参数 → `Tab.icon`，GroupTabBar 已支持渲染 [:305-308](../../../../src/pool/shared/group-tab-bar/GroupTabBar.tsx#L305-L308)）。
- 文本：插件名（manifest.name / marketEntry.name），不带「介绍」后缀。
