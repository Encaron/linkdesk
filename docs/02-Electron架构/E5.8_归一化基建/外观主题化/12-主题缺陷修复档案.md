### #56 玻璃覆盖 neutral 门控语义修复 + radius scale clamp

- **依据：** 审计#2——getAppearanceOverrides（ThemeEngine.ts:954-958）neutral 判定 `blur!==0`/`opacity!==1` 即不覆盖 → 玻璃主题 + custom 拖 glassBlur 到 0 关不掉模糊、glassOpacity 到 1 变不了不透明，config 文案「0 关闭/1 不透明」永不兑现；审计#4——消费路径 applyRadiusScale 无 0.5-2 clamp，程序化写 app.surfaceRadius:5 得 30px 圆角（clamp 只在播种方向 deriveAppearanceSeeds 有）
- **方案：** neutral 判定从「值等于端点」改为 presence 语义（配置被显式写过才覆盖；backgroundImage 空=还原主题基线先例同款）——引擎读「覆盖集合当前含哪些键」，端点值=用户显式意图照常覆盖；applyRadiusScale 消费侧补 clamp(0.5,2)
- **落点：** src/core/services/ui/ThemeEngine.ts（getAppearanceOverrides/applyRadiusScale）+ src/App/startup.ts 配置注册
- **验收：** 玻璃主题 custom 拖 glassBlur 到 0 模糊真关、glassOpacity 到 1 真不透明；滑杆回默认值=还原主题基线；settings.json 直写 surfaceRadius:5 被 clamp 到 2；补单测；npm run check 全绿

### #57 mix 播种 scale 反推修复——二次缩放根治

### #67 插件内容不透明盖玻璃（bug 1）——壳/插件约定设计决策（P1）

- **依据：** 用户实机 bug 1——插件内容不透明、玻璃不可见。已确认壳侧不透明 bg-window 盖 blur（无插件也看不见，见 #66）；「插件自绘不透明再盖一层」为推断**未验证**（实机复现确认）。涉及内容 vs 空间所有权（壳管空间、插件管内容）
- **方案（待拍板）：** ①壳玻璃只在无插件内容的表面/插件区保持不透明（接受主区被插件盖）；②约定玻璃主题下插件容器半透明（插件配合改）；③壳机制级给插件内容留透明通道；先实机复现确认插件层是否真挡，再定方向
- **落点：** 实机复现确认 → 设计决策 → 落点再定
- **验收：** 确认插件内容层对玻璃实际遮挡行为；按拍板方向玻璃可见性达标；npm run check 全绿
- **复现结果（2026-08-24，CDP 实机）：** aurora 应用后对 `.main-zone/.side-panel/.titlebar/.icon-bar/.status-bar` 下**全深度（12 层）扫描**全部元素计算背景——插件内容容器（welcome-page / serial-monitor-view / settings-editor / side-panel-header / group-tab-bar 等）**全走 `var(--bg-window)/var(--bg-card)`，aurora 修复后全为 rgba 半透明**（如 `rgba(22,32,62,0.55)`）；唯一 alpha=1 完全不透明的是**小控件**（send-btn 紫色按钮 rgb(124,58,237) / control-dot 状态点）——按钮/状态点不透明是正确行为，非整面遮挡。**「插件自绘不透明再盖一层」假设未证实**——插件从不自己硬编码整面背景，只是消费 `var(--bg-*)`，而旧 aurora 把 bg-* 给成不透明 hex 才挡住玻璃（与 bug 5 **同根同源**，已随 #66 修复）
- **结论（2026-08-24）：** bug 1 根因 = 壳侧/主题不透明 surface 色（同 #66），#66 落地后插件内容容器随主题 rgba 自动半透明，玻璃可见。原方案 ①（壳只保无插件表面）②（约定插件容器半透明）③（壳机制级透明通道）**均无需落地**——插件层不挡，且 ③ 违反「内容 vs 空间所有权」（壳管空间、插件管内容）。**残余风险**：第三方插件若自行硬编码不透明背景（非 var 消费）仍会盖玻璃——那是插件作者的内容选择，非壳缺陷，不在本次修复范围。若用户要求「任何插件硬编码背景也被玻璃覆盖」，需另立任务（内容所有权边界外推），本任务关闭
- **回勾（2026-08-24，commit 随清单）：** 复现未证实插件层遮挡 + 同根因随 #66 关闭，16✗→15✗
