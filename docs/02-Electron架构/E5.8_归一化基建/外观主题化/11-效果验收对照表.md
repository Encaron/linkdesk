## 五、已知偏差（note，非能力缺口）

**gallery recipe 预览的 `appearance.surface{inset,radius,shadow,border}` vs 引擎契约 `appearance.glass`。**
- gallery 的 `const T` recipe 把浮起形态键（inset/radius/shadow/border）放在 `appearance.surface` 子对象里——这是**渲染器 display 分组**（renderRecipe 硬编码从 `ap.surface` 读这四键）。
- 引擎契约（`src/core/types/theme.ts` ThemeSurface）：浮起形态键在 `appearance.glass`（aurora-glass / paper-zones / image-zones 真实主题均如此）；`appearance.surface` 是**预留 per-surface 精调键映射**（menu-blur 等），引擎 flatten 为 `surface-<key>` 透传、暂无 CSS 消费者。
- 影响：**零**。每壳视觉效果（§二）全部可产出；真实主题写引擎契约即可。不做引擎双写改造（同一 token 两个来源 = 歧义）。

**font.display（展示字）预留子键。**
- gallery ⑦⑬ 的 `font.display` 是 font 域预留子键，schema ThemeFont 现仅 ui/mono 两键——展示字无 CSS 消费者（现状品牌字在插件内容层自理）。不影响主题化验收，属 #50.6 token 表冻结项后续扩展。
