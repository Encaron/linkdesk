# 样式命名空间审计——共享组件 CSS 的全局名纪律

> **一句话**：插件视图的样式表**不是任何一方独占的**——同一个窗口里同时装着宿主 CSS、共享组件 CSS、
> 以及**所有已加载插件的 CSS**，所以**裸类名是全局标识符**：一方定义、他方渲染，两边的样式就落到
> 同一个元素上，**而且不报错**。
>
> **起因**：设置 → 主题里每张卡片右下角是一块纯色，「4 配色」这类文字被自己的背景吞掉（bug 图谱 §C4）。
> 本档 = 那次的**全量审计 + 处置**；门禁 `scripts/check-css-namespace.mjs` 是它的机械化身。
>
> 🔴 **2026-09-16 起，本档是「快照」，不是「进度真相源」**：专项已从「这一条 bug 的处置」扩成
> **跨方样式污染的九件套**（四条标识符轴 ＋ 两层证明），§三 的读数已用**门禁自己的解析口径重算**
> （旧尺子读的 111/8、319/6 **作废**，见 §三 抬头）。**当前进度与「还剩什么」看
> [样式命名空间归一化/交接.md](样式命名空间归一化/交接.md) 顶部的队列表**；
> 本档只负责「这一类问题长什么样、判据是怎么从错尺子纠过来的」。

## 一、先把爆炸半径量出来：文档同表

| 文档 | 装着谁的样式 | 实测读数 |
|:--|:--|:--|
| 壳渲染进程 `index.html` | 壳 `src/**`（含 `index.css` 的全局工具类）+ 共享组件 CSS | — |
| 池文档 `pool.html` | 壳 `src/pool/**` + `index.css`（`src/pool/pool-main.tsx:24` 显式 import）+ 共享组件 CSS + **每只已加载插件一张 `linkdesk://<id>/index.bundle.css`** | **8 张样式表** = 宿主 pool CSS + codicon + 7 只插件 bundle（CDP 实读 `document.styleSheets`） |

三条推论（本档全部判据的立足点）：

1. **裸类名 = 全局标识符**（`.badge` / `.toggle` / `.input` …）；
2. **插件与插件之间也在同一张表里**——甲插件的 `.toolbar` 会命中乙插件的 `.toolbar`；
3. **`@keyframes` 名同样是全局的**（第二条命名空间：先加载者与后定义者互相覆盖）。

## 二、审计方法（可复现）

按「谁占了这个名字 / 谁在用这个元素」把每条规则分三态：

| 态 | 判据 | 例子 |
|:--|:--|:--|
| **裸定义** | 选择器主体就是这个类名本身、且**无祖先** | `.badge { … }`（占名） |
| **scoped 调优** | 有祖先/前缀条件 | `.control-bar .combobox { … }`（消费别人的名，不占名） |
| **渲染面** | 源码里 `className` / `classList` / `querySelector` 出现过的 token | 谁的元素**带着**这个名字 |

**真撞车 = 甲裸定义 `.x` 且乙把自己的元素渲染成 `x`**——此时乙的元素被甲的样式命中，就是 `.badge` 案。

## 四、真案 1 条（已修）

**`.badge`**：共享组件 `ThemePicker` 的卡片徽标写了 `<span class="badge">`，与壳基础件 `Badge` 组件
**已占用的同名类**（实心强调色药丸：`background: var(--badge-background)` + 圆角 + 内边距）相撞
⇒ 底色与文字同为强调色，**文字被自己的背景吞掉**。

- 修法：类名命名空间化 `.badge → .tbadge`（与 `.tname` / `.pv-dot` 同族）。
- **它为什么能潜伏**：壳自己看不见（壳的主题选择器走 QuickPick，不渲染卡片），**只在插件视图炸**；
  而插件视图的样式表在源码外移（L7）之后是「整包吃 `@linkdesk/ui` 的 CSS」——**占名与借名两头
  第一次进同一张表**。这类 bug 没有报错，只有「长得不对」。

## 八、纪律（三条，已写进作者面）

1. **自己的元素用自有前缀**（官方先例：`settings-*` / `file-tree-*`；`ms-*` / `mpd-*` 那类缩写已废弃）；
2. **宿主保留名不要借来给自己的元素用**——要那个样子就**用那个组件**；
3. **状态类一律复合**（`.你的类.active`），不裸写 `.active {}`。

> 宿主侧的另一半纪律（占名的人）：**E6#109l 起是结构性的**——宿主自己定义的类名一律 `ldk-` 开头，
> **不查表、无白名单、无豁免**（`classes.host` 已摘空）；三方名靠「只消费不定义」自动出射程。
> 共享组件侧（判据①）此刻**仍是「新增裸定义要登记」**，它的形态变更归 1.21b。
