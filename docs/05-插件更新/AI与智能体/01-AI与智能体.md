## 两阶段

### Phase 1 —— AI 助手（v2.0）

> 对标 VS Code Copilot Chat。侧栏对话 + 代码补全内联建议。

```
plugins/ai-assistant/
├── plugin.json
├── index.tsx            # 主视图——对话历史 / 上下文面板
├── sidebar.tsx          # 侧栏——对话输入框 + 消息列表 + 代码块渲染
├── ai-service.ts        # AI API 调用封装（OpenAI / Anthropic / DeepSeek）
├── context-provider.ts  # 上下文收集——当前文件 / 打开标签页 / 项目结构
└── inline-suggestion.ts # 编辑器内联建议（Monaco InlineCompletionProvider）
```

### Phase 2 —— 智能体（v2.1+）

> 对标 VS Code Agent Mode。AI 不只是回答问题——自主执行任务。

智能体 = AI 助手 + 工具调用权限：
- `tool: read_file(path)` → `window.linkdesk.filesystem.readTextFile()`
- `tool: write_file(path, content)` → `window.linkdesk.filesystem.writeTextFile()`
- `tool: execute_command(cmd, args)` → `window.linkdesk.exec()`
- `tool: search_code(pattern)` → Grep 工具
- `tool: list_directory(path)` → `window.linkdesk.filesystem.readdir()`
- `tool: get_config(key)` → `window.linkdesk.config.get()`

**关键安全设计：** 智能体的工具调用走用户确认——对标 VS Code 的 "Allow / Deny / Always Allow" 对话框。不是静默执行。

## 为什么是纯插件

| 能力 | 来源 | AI 插件怎么用 |
|------|:--:|------|
| AI API 调用 | Web API | `fetch("https://api.anthropic.com/v1/messages", ...)` 或 `window.linkdesk.exec("node", ["ai-bridge.js"])` |
| 读文件 | E2c FileService | `window.linkdesk.filesystem.readTextFile(path)` |
| 写文件 | E2c FileService | `window.linkdesk.filesystem.writeTextFile(path, content)` |
| 执行命令 | E1 主进程 exec | `window.linkdesk.exec(cmd, args)` |
| 搜索代码 | E2c FileService + grep | 读文件 + 前端正则匹配 |
| Monaco 编辑器 | v1.1 | InlineCompletionProvider / 装饰器 / 幽灵文本 |
| 侧栏 | plugin.json `sidebar` 字段（现有机制） | `"sidebar": "sidebar.tsx"` |
| 底部图标栏 | E2c iconLocation | `"iconLocation": "bottom"` |

**不需要任何新架构。** AI 插件调用的全部 API 都在 E1-E3 中已提供。

---

## 壳看到的是什么

1. 图标栏底部出现 AI 图标（`iconLocation: "bottom"`）
2. 点击 → 侧栏显示对话界面（对标 Copilot Chat 侧栏）
3. Ctrl+L / Ctrl+I → 聚焦 AI 输入框（走 KeybindingRegistry）
4. 编辑器中出现内联建议（Monaco InlineCompletionProvider）

**壳不知道 AI 的存在。** 跟终端、Git、文件树完全一样——壳只知道有个插件。

## 安全边界

| 风险 | 对策 |
|------|------|
| AI 删除文件 | 工具调用走用户确认（Phase 2 #8） |
| API Key 泄露 | 存在 ConfigurationService（`ai.apiKey`），不硬编码，不提交 Git |
| 智能体失控循环 | 最大步数限制（默认 20 步）+ 超时（默认 5 分钟） |
| 敏感文件读取 | 文件访问走 `window.linkdesk.filesystem`——受 preload 权限控制 |
| Prompt 注入 | 用户输入与系统 prompt 分层——系统 prompt 不可被用户消息覆盖 |
