# 01 · 方案与落点契约

> 归属判定先行为主（本案本质上是一次**能力搬家**：从设置仓搬回共享件）。

## 〇、归属判定（为什么这是「住错层」的修正）

按 [设置行案 01 §〇](../设置行-控制只读同行/01-方案与落点契约.md) 的归属三层框架：

- **值标签**（当前值＋单位）与**细调步进**是**控件能力**——归属共享件本体；
- 今天它们住在设置仓（`settings-slider-control` 包裹层 ＋ `sliderValueLabel.ts`）＝「能力住在第一个使用者手里」；
- 病征与你看到的「孤零零滑杆」是同一件事的两面：能力没下沉，第二个使用者出现之日就是复制粘贴之日。
- **修正＝搬家，不是新造**：`formatSliderValue` 的格式化语义（E5.8#77：`×` 倍数 / `px` / 裸数值）随迁进组件，设置仓那份删除。

## 一、API 契约（正表——全部可选，缺省＝现状）

| prop | 类型 | 缺省 | 语义 |
|:--|:--|:--|:--|
| `unit` | `string` | 无 | 单位文案（`px` / `ms` / `FPS` / `×` / `毫米`…由声明者自定）；**无 unit ＝ 无值标签（现状）** |
| `unitPosition` | `"before" \| "after" \| "above" \| "below"` | `"after"` | 值标签位置（你 1.1 的前后左右）；非 `after` 时标签脱离滑杆行内流（above/below 用绝对/网格布局，不挤压轨道） |
| `stepper` | `boolean` | `false` | 轨道两侧渲染 **− / ＋** 按钮；点击按既有 `step` 步进、`min/max` 夹取；`disabled` 联动；`aria-label`＝「减少/增加」＋所在控件标签 |

规则：

1. **基座不动**——仍是原生 `<input type="range">`（键盘方向键/PageUp/Down、原生 `role="slider"` 无障碍全部免费保留）；−/＋ 是**并存**的辅助通道，不接管拖拽。
2. 值标签文案 ＝ `formatSliderValue(value, unit)` 迁入后的统一格式化（继承 E5.8#77 语义：`×` 倍数去尾零、`px` 取整、无 unit 裸值）。
3. −/＋ **单击单发**（长按连发不做——NumberInput 前例，[设置行/数字步进案 04 D-残余](../数字步进件-主题适配/04-任务清单.md)同口径）。
4. `disabled` 时 −/＋ 同步置灰；`stepper` 不声明则一个 DOM 都不多。

## 二、设置仓接线（唯一消费者的迁移）

`renderControl.tsx` 的 `case "slider"`：

- 现状：`<Slider …/>` 外包 `settings-slider-control` ＋ 手拼值标签（`formatSliderValue`）。
- 改后：`<Slider … unit={prop.unit} stepper unitPosition={prop.unitPosition ?? "after"} />`，包裹层值标签与 `sliderValueLabel.ts` **删除**（能力已迁入组件）。
- schema 声明链**零改动**：宿主 schema 的 `unit` 字段（E5.8#77）原样；`unitPosition`/`stepper` 是否进 schema＝**新决策**（见 [04 D3](04-任务清单.md)）——不进则配置页滑杆固定 after＋无细调，插件非配置页场景用 props 全量。

## 三、落点表

| 仓 | 落点 | 动什么 |
|:--|:--|:--|
| 壳 | `src/components/shared/slider/Slider.tsx` ＋ `Slider.css` | 三 props ＋ 值标签渲染 ＋ −/＋ 按钮（`sliderStep.ts` 既有步进推导不动） |
| 壳 | `npm run ui:build` ＋ `@linkdesk/ui` bump | 共享件铁律；**漏 ui:build ＝ dev 里「什么都没变」**（假阴性坑，memory 有案） |
| 设置仓 | `src/views/SettingsView/renderControl.tsx` | slider 分支直传声明 |
| 设置仓 | `settings-slider-control` 样式 ＋ `sliderValueLabel.ts` | 删除（能力已迁） |
| 门禁 | `check-api-surface-additive` | 只增面自动把守；`check-plugin-schema-sync` 若 D3 选「进 schema」则跟跑 |

## 四、验收判据

1. **旧观感零回归**：设置页现有滑杆键（不声明新 props 过渡期）逐键目视＝现状。
2. **新能力四形态**：`after` / `before` / `above` / `below` 各一现场 ＋ `stepper` 现场＋组合现场。
3. **键盘全链**：Tab 到滑杆→方向键→Tab 到 −/＋→Enter，全程无鼠标可用。
4. **脱离设置页**：任一非配置页场景（或临时 demo 页）直接 `<Slider unit="ms" stepper />` 成立——「孤零零」问题的正面验收。
5. `npm run check` 全绿（含 api-surface-additive）＋ token 快照（值标签颜色走 `--text-*`/`--accent`，不引入硬编码）。

## 五、⛔ 不许

- 改既有 props 语义 / 删任何既有导出（只增宣言）；
- 手写 pointer 拖拽状态机（原生 range 基座是组件的头号设计决定）；
- 第二套值格式化器（迁移，不是复制）；
- 设置仓保留双轨（包裹层与组件能力并存两套渲染）。
