## P0-1：开合动画（QuickPick 壳 ~20 行 CSS）

**改 `src/index.css`**——在 `.palette` 和 `.ctx-overlay` 上加 transition。

```css
/* 遮罩 fade */
.ctx-overlay {
  /* ...existing... */
  opacity: 0;
  transition: opacity 150ms ease-out;
}
.ctx-overlay.visible {
  opacity: 1;
}

/* 面板 scale + fade——对标 VS Code quickInput */
.palette {
  /* ...existing... */
  opacity: 0;
  transform: translateX(-50%) scale(0.95);
  transition: opacity 150ms ease-out, transform 150ms ease-out;
}
.palette.visible {
  opacity: 1;
  transform: translateX(-50%) scale(1);
}
```

**改 `QuickPick.tsx`**——在 portal 渲染时，下一帧加 `.visible`（让 CSS transition 生效）：

```tsx
// 打开时延迟一帧加 visible class——否则 transition 不触发
useEffect(() => {
  if (open) {
    const timer = setTimeout(() => {
      // 给 overlay + palette 加 .visible
      document.querySelector('.ctx-overlay')?.classList.add('visible');
      document.querySelector('.palette')?.classList.add('visible');
    }, 10); // 10ms > 浏览器渲染帧
    return () => clearTimeout(timer);
  }
}, [open]);
```

**关闭动画的难点：** 目前 `!open → return null`，portal 直接卸载，动画来不及播放。两个方案：

| 方案 | 做法 | 优劣 |
|------|------|------|
| A) 延迟卸载 | `open` 变 false 时先去 `.visible`，等 150ms 再 `return null` | 简单，但需额外 state |
| B) 始终渲染 | portal 始终 mounted，用 CSS `visibility`/`opacity` 控制 | 无延迟卸载问题 |

**推荐方案 A**——最小改动。加一个 `closing` state + 150ms `setTimeout`。

```tsx
const [closing, setClosing] = useState(false);
// 当 open 由 true→false 时：
useEffect(() => {
  if (!open && !closing) {
    // 去 visible class → CSS 动画播放
    document.querySelector('.palette')?.classList.remove('visible');
    document.querySelector('.ctx-overlay')?.classList.remove('visible');
    setClosing(true);
    setTimeout(() => setClosing(false), 150);
  }
}, [open]);
// 渲染条件：open || closing
if (!open && !closing) return null;
```

> 🔥 **注意：** 此方案用 `document.querySelector` 操控 DOM class，不走 React state，避免触发重渲染打断动画。见硬约束 17（useRef 不得用于渲染输出）。

## P0-2：快捷键显示（CommandPalette ~40 行 TSX+CSS）

**数据来源：** `KeybindingRegistry.getKeybinding(commandId)` 返回 `Keybinding | undefined`。需要先确认这个 API 是否存在。

**假设 API：**
```tsx
// 在 CommandPalette.tsx 中
import { getKeybindingForCommand } from "../../core/KeybindingRegistry";
```

**渲染改动——`renderItem`：**

> 🔥 **对标 VS Code 布局**——两行结构：
> - 第1行: `title` (左) + `category` (右)
> - 第2行: `command ID` (左, 弱化) + `keybinding pill` (右, 齿轮旁)
> 
> ID 保留不删——VS Code 也保留。快捷键在第二行右侧，不是替换 ID。

```tsx
renderItem={(cmd, _isSelected) => {
  const kb = getKeybindingForCommand?.(cmd.id);
  return (
    <div className="palette-item-content">
      <div className="palette-item-row">
        <span className="palette-item-label">{cmd.title}</span>
        {cmd.category && (
          <span className="palette-item-category">{cmd.category}</span>
        )}
      </div>
      {/* 第二行: ID(左) + 快捷键pill(右) —— 对标 VS Code */}
      <span className="palette-item-detail">
        <span className="palette-item-detail-id">{cmd.id}</span>
        {kb && (
          <span className="palette-item-detail-right">
            <KeybindingLabel binding={kb} />
          </span>
        )}
      </span>
    </div>
  );
}}
```

**Keycap pill 组件：**

```tsx
function KeybindingLabel({ binding }: { binding: Keybinding }) {
  return (
    <span className="keybinding-pill">
      {binding.keys.map((key, i) => (
        <span key={i}>
          {i > 0 && <span className="keybinding-sep">+</span>}
          <kbd>{key}</kbd>
        </span>
      ))}
    </span>
  );
}
```

**CSS 改动——`.palette-item-detail` 改为 flex 行：**

```css
/* detail 行: ID(左 flex) + 快捷键pill(右 shrink) */
.palette-item-detail {
  display: flex;
  align-items: center;
  justify-content: space-between;
  font-size: 10px;
  opacity: 0.55;
  margin-top: 1px;
}
.palette-item-detail-id {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
  flex: 1;
  min-width: 0;
}
.palette-item-detail-right {
  display: flex;
  align-items: center;
  gap: 6px;
  flex-shrink: 0;
  margin-left: 8px;
}
```

**`<kbd>` 样式——对标 VS Code keycap：**

```css
.keybinding-pill kbd {
  display: inline-block;
  padding: 1px 5px;
  font-size: 10px;
  font-family: var(--font-mono);
  background: rgba(128,128,128,0.1);
  border: 1px solid rgba(128,128,128,0.12);
  border-radius: 3px;
  line-height: 1.5;
}
/* hover/select 时变亮 */
.palette-item:hover .keybinding-pill kbd,
.palette-item.selected .keybinding-pill kbd {
  background: rgba(255,255,255,0.2);
  border-color: rgba(255,255,255,0.35);
}
```

**齿轮依然保留**（`renderItemActions`）——快捷键显示和齿轮不冲突：
- 齿轮在行末最右侧 → 没快捷键时给用户入口配置
- keycap pill 在 detail 行右侧齿轮旁 → 有快捷键时显示，教用户

> 🔥 **注意：** 如果 `getKeybindingForCommand` API 不存在，P0-2 可降级为：先去 KeybindingRegistry 查当前实现，如果只是缺查询 API（数据已注册好），加一个查询函数 ~10 行即可。

## P2-1：`>` 前缀指示器（QuickPick ~15 行 TSX+CSS）

两个方案：

| 方案 | 做法 | 优劣 |
|------|------|------|
| A) prop 控制 | `QuickPick` 加 `prefix?: string` prop | 通用——主题浏览器/语言选择器不需要 > |
| B) CSS `::before` | `.palette-input::before { content: ">"; }` | 简单，但耦合 CSS |

**推荐方案 A**——prop 控制，QuickPick 不改行为逻辑，只加视觉元素：

```tsx
// QuickPickProps 新增
prefix?: string;

// JSX——在 input 前面
<div className="palette-input-wrapper">
  {prefix && <span className="palette-input-prefix">{prefix}</span>}
  <input ... />
</div>
```

```css
.palette-input-wrapper {
  display: flex;
  align-items: center;
  border-bottom: 1px solid var(--separator);
}
.palette-input-prefix {
  padding-left: 14px;
  font-size: 13px;
  color: var(--text-muted, #888);
  user-select: none;
}
.palette-input-wrapper .palette-input {
  border-bottom: none; /* wrapper 已画线 */
  flex: 1;
}
```

**CommandPalette 传 prop：** `<QuickPick prefix=">" ... />`

## P2-2：命令 ID 行处理（CommandPalette ~10 行）

在 P0-2 快捷键显示的基础上：

- **有快捷键的命令 →** 显示 keycap pill，不显示 ID
- **无快捷键的命令 →** ID 作为 tooltip，行不显示（或弱化为灰色小字）
- **保持 `cmd.title` 的 `title` 属性**——用户 hover 看全称

```tsx
<span className="palette-item-detail">
  {kb ? (
    <KeybindingLabel binding={kb} />
  ) : (
    <span title={cmd.id} style={{ opacity: 0.4, fontSize: 10 }}>
      {cmd.id}
    </span>
  )}
</span>
```

## 不改的

| 项目 | 理由 |
|------|------|
| 快捷键显示在齿轮位（而非右侧） | 齿轮对标 VS Code per-command gear——保留 |
| 分组/分类标题 | 需要 CommandRegistry 支持 `category` 分组，数据层改动大，E3.5 不碰 |
| 模式切换（`?` `>` 文件搜索） | 文件搜索是 E4 功能，届时再加 |
| QuickPick 改为自定义滚动容器 | `overflow-y: auto` 足够，不需要手动管理 virtual list |
| TypeScript 严格类型 | 改的都是渲染层 + CSS，不引入新类型 |
