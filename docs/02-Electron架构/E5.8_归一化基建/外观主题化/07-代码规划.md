#### Slider（#50.9）——通用滑杆控件

- **建法**（怎么建）：`Slider.tsx` props = `{ value, min, max, step?, onChange, ariaLabel? }`；pointer events 拖拽 + 键盘可达（←→ 步进）+ `prefers-reduced-motion` 降级；样式走 CSS 变量；配单测。**外观设置第一个消费者，插件以后也要用。**
- **用法**（建好怎用）：settings 插件 `renderControl.tsx` uiHint switch（L27-62）加 `"slider"` 分支 → 渲染 Slider（value=val, min=prop.minimum, max=prop.maximum）。
- **插件作者 API**（怎么调）：plugin.json 配置项声明即可（E5.7#66 已开放 string enum，plugin.schema.json 无需改）：
  ```jsonc
  { "key": "app.glassBlur", "type": "number", "minimum": 0, "maximum": 32, "uiHint": "slider" }
  ```

#### ThemePicker 卡片（#50.22）——卡片切换主题

- **建法**：`ThemePicker.tsx` = 配方卡片列表（名称 + type 徽标 dark/light + colorways 配色徽标圆点 + 选中态边框）+ 键盘可达；**数据源 = `window.linkdesk.theme.listRecipes()`**（06 §2，含配色/预览色）。
- **用法**：renderControl 加 `"themePicker"` 分支 → 渲染 ThemePicker（value=app.theme, onChange=setRecipe）。
- **插件作者 API**：配置项 `"uiHint": "themePicker"`；点击写 `app.theme`（配方 id）。第三方 UI 也可直接调 `theme.listRecipes()`/`theme.setRecipe()`。

#### 动态 SelectBox（#50.23）——静态 enum 撑不起的动态列表

- **建法**：renderControl 加 `"select"` 分支 + `optionsFrom` 解析——渲染时调 `theme.listRecipes()` 动态取（`"theme.colorways"` = 活动配方配色 / `"theme.sources"` = 混搭来源 06 §2）；预览色块沿用。
- **用法**：配置项声明 `"uiHint": "select"` + 自定义 `optionsFrom` 字段（壳侧读取；**不改主进程配置注册表结构**）。
- **插件作者 API**：`theme.listRecipes()` 返回 `RecipeMeta{ id, name, type, colorways[], domains }`——`domains` 即混搭来源过滤依据（10 §2）。

#### FontFamilySelect 通用化（#50.20）——从只支持等宽到全字族

- **建法**：现状 mono-only（isMonospace Canvas 过滤 + FALLBACK_MONO_FONTS，L42-98——宋体/黑体/Times 选不了）→ 加 `monoOnly?: boolean`（**默认 true 兼容等宽场景**；false = queryLocalFonts 不过等宽过滤）。
- **用法**：`"fontFamily"` 分支已接（renderControl L55-56）——app.fontFamily 配置复用同控件；用户级覆盖写 `--font-ui`（onApply 走 ThemeEngine 覆盖面单一写入点，对标 accentColor）。
- **插件作者 API**：配置项 `"uiHint": "fontFamily"`；资产字体走主题层（05 §2 `font.ui` 资产路径→@font-face→族名，#50.17），用户层只选**系统族名**。

#### 选图「选择图片…」（#50.11）——本地选图 + 拷贝入库

- **建法**：设置背景行改「选择图片…」按钮 → `window.linkdesk.dialog.open({ filters: [{ name:'图片', extensions:['png','jpg','jpeg','webp'] }] })`（**dialog.open 已支持 filters**，dialog-handlers.ts 零改动）→ `window.linkdesk.appearance.importImage(srcPath)`（主进程拷贝进 userData `appearance/` → 返回受控路径）→ 存 app.backgroundImage；配「清除图片」还原。
- **用法**：app.backgroundImage 行（FilePathInput `"file"` 分支扩展或专用按钮）。
- **插件作者 API**：`window.linkdesk.appearance.importImage(srcPath): Promise<string>`（受控路径；禁止插件直接手写 `file://` 绝对路径读——Electron 安全模型，硬约束 12 精神）。

## 1.5 工程目录总览（Phase 10 落地后——对照壳目录规范）

> **一句话：** 六层各归其位——数据层（registry/appearance）→ 应用层（services/ui）→ 契约层（api/types）→ 控件层（components/shared）→ 渲染层（pool/zones）→ 主进程（electron/ipc/handlers）。每文件有明确归属，找不到归属 = 落点错了。

```
src/core/registry/appearance/              ← 数据层：ThemeRegistry（登记/查询配方——多提供方=多个主题插件）✅已存在
src/core/services/ui/                      ← 应用层：ThemeEngine（合并算法/写 :root/广播 theme:changed）✅已存在
src/core/api/linkdesk-api/                 ← 契约层：Appearance 域接口（theme.* API）
src/core/types/                            ← 类型层：RecipeMeta/ColorwayMeta
src/components/shared/slider/              ← 新控件 #50.9（夹内 tsx+css+test）
src/components/shared/theme-picker/        ← 新控件 #50.22
src/components/shared/select-box/          ← 动态化扩展 #50.23（optionsFrom）
src/components/shared/font-family-select/  ← 通用化扩展 #50.20（monoOnly?）
src/pool/zones/background-layer/           ← 新 zone #50.8（全窗固定层）
src/pool/zones/floating-layer/             ← 并列先例（同性质）
electron/ipc/handlers/theme-handlers.ts    ← #50.18 主题 IPC
electron/ipc/handlers/appearance-handlers.ts ← #50.11 选图入库 IPC
electron/ipc/channels.ts                   ← IPC.appearance.importImage 等通道注册
```

**background 归属判据：** `src/pool/zones/background-layer/`——与 `floating-layer/` 并列（全窗固定层先例，壳目录规范 §2），**不建顶层独立夹**（它是渲染层消费者，不是独立子系统）。夹内 BackgroundLayer.tsx（读 `--bg-image`/`--bg-opacity`/`--bg-mask` 渲染全窗背景）+ BackgroundLayer.css（全走 var() 零硬编码）。

**高内聚低耦合：** 数据层不碰 CSS 副作用；应用层经 token + `theme:changed` 广播（池不知来源）；渲染层只消费 var()；控件经 uiHint 声明（renderControl 零 `@src/core`）；主题插件走 `window.linkdesk.theme.*` 零壳 import（[11 §4](../../../03-插件制造/11-主题制作.md)）。
