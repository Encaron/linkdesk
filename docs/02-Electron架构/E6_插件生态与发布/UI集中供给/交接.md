## ✅ E6#127a（2026-09-19 · 会话 C）——#127 实机验收暴露的 dev 轨道补正（未入原编排）

### ⑴ 给下一个 AI 的话

- 🔴 **根因不是 L9 设计，是 E6#7 起埋在 Windows 上的一颗雷**：`vite.config.ts` 的 `userPluginsHome` 走 `path.join` ⇒ 反斜杠（`C:\...\linkdesk\plugins`），而 Vite 传给插件的 importer id **一律正斜杠** ⇒ 解析钩子的守卫 `importer.includes(userPluginsHome)` **恒假**，该钩子在 Windows 上**从未生效**。react 系一直没露馅是因为它们在壳自身 import 图里、有 Vite 优化器兜底（实测重写为共享的 `/node_modules/.vite/deps/*`）；`@linkdesk/ui` 壳自己不 import（grep 只命中注释）⇒ **无兜底** ⇒ 硬失败。⇒ **#123 给该 Map 加 ui 那一笔在 Windows 上是死代码**，其「curl 实测」只验了 CSS 注入、**插件 bundle 的真实解析从未跑过**——这是本批验收的唯一漏网，也是「实机闸门必须用户本人做」的又一例证。
