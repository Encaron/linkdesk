## 一、为什么 `.input` 必须单独裁决（机制与共享组件**不同**）

| | 共享组件类名（件 1） | **宿主 `.input`** |
|:--|:--|:--|
| 定义在哪 | 组件自己的 CSS，**打进插件 bundle** | 宿主 `src/index.css`，与插件视图**同表、运行时共享** |
| 改名何时破坏 | 插件**升级 ui 时**（自带旧 CSS 自洽，有零破坏窗口） | **即时**——插件渲染 `className="input"` 借的就是运行时这一份 |
| 因此 | 壳可先发 | **改它必须与插件重发同批** |

### 实测读数（2026-09-15）

- **定义 5 处**：`src/index.css:245,255,273`（三条规则）+ `src/components/shared/form-row/FormRow.css:23`（`.form-row > .input` 组合契约）+ `src/components/shared/string-list-editor/StringListEditor.css:3`（引用）。
- **壳渲染 2 处**：`src/components/shared/file-path-input/FilePathInput.tsx:44`、`src/components/shared/number-input/NumberInput.tsx:51`。
- 🔴 **插件渲染 10 处**：`settings` 8 处（`ObjectEditor.tsx` 3 · `renderControl.tsx` 1 · 其余 4）+ `serial-monitor` 2 处（`QuickSendBar.tsx` 2 · `Toolbar.tsx` 1 · `SendBehaviorGroup.tsx` 1 —— 执行时以现仓重扫为准）。
- **官方插件 CSS 对 `.input` 的调优**：`FormRow.css` 那条已在壳内；插件侧是否另有 ⇒ **执行时重扫**（`grep -rnE "\.input([^a-zA-Z0-9_-]|$)" E:\linkdesk-plugins --include=*.css`）。

> 判据一句话：`.input` 是**今天唯一还在被插件消费的宿主保留名**——它决定了「一条规则」要不要留例外。

## 二、两条路线（**必须请用户拍板**，写成一句话能作答的选项）

- 代价：**今天零改动**；规则留一条**明写的例外**（不是暗的）。
- 风险：低（不改运行时同表的东西）。

### (b) 前缀化 `.ldk-input`
- 壳改定义 + 壳 2 处渲染 + `.form-row > .ldk-input`；

- 代价：壳 + 2 仓 bump/ver​​ify/重打包/发布/目录收录（照 [07 §三](07-任务-三只插件仓适配重发.md) 的流程）。
