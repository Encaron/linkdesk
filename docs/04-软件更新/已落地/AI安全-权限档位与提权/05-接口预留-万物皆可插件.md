# 05 · 接口预留（对齐「万物皆可插件 · 表现层可替换化」）

> 上游：[万物皆可插件提案 §3.0/§3.2/§3.3/§十](../../待抉择池/万物皆可插件-表现层可替换化/00-提案.md)
> 目的：本档先做，但**把口子留好**——那个任务落地时，确认框/设置页/状态栏/回执可以直接换皮，⛔ 不用返工。

---

## 一、槽位映射（哪张脸可换）

| 本档的呈现面 | 万物任务的槽位 | 替换后必须仍然成立 |
|:--|:--|:--|
| 确认框外壳 | `contributes.renderers.dialogChrome`（M2） | 按钮语义（拒绝/允许一次）、Esc/Enter、超时、fail-closed |
| 提权框外壳 | 同 `dialogChrome`（富内容槽） | 批准只能由用户点；批准写档位不经命令面 |
| 设置页「AI 接入」整套 | `factoryRole:"settings"`（已存在） | 四档读写、风险摘要、`userOnly` 拒调 |
| 状态栏 AI 徽标 | `contributes.statusBar` ／未来 `renderers` | 档位实时、点击直达设置、`aria-live` |
| 回执（拒绝/降权/已执行） | 通知面板（`notificationPanel` 槽，M2） | 不新建第二通知面；文案来自 `receipt()` |

## 二、渲染契约（替换体只准看见这些）

```ts
// 只读
aiPolicy.getState(): {
  mode: "read" | "ask" | "auto" | "full";
  options: Array<{ value: Mode; label: string; summary: string }>;
  riskTable: Array<{ id: string; kind: "op" | "command"; risk: Risk }>;
  protectedCommands: string[];       // userOnly
  effectiveAt: number;
}
// 事件
onDidChangePolicy(listener): Disposable;
// 文案
aiPolicy.receipt(kind, payload): { title: string; message: string; actions?: ... };
```

- 渲染体 **⛔ 不许**：读 `settings.json`、自己判风险、自己写档位、自己维护第二份档位状态。
- 渲染体 **✅ 可以**：换布局、换视觉、换图标；按钮回调仍是 `setMode`（`userOnly`）。

---

## 三、不可替换的深层（明确写死）

| 深层 | 为什么不可换 |
|:--|:--|
| `policy/decide.ts` | 安全判定不能由第三方替换 |
| `policy/risk.ts` | 风险登记是安全边界 |
| `policy/protected.ts`（`userOnly`） | 自提权防线 |
| `runShellCommand` 执行闸 | 唯一出口；替换体够不着 |
| 批准写点（dialog handler settle） | 批准权属于用户，不属于任何渲染体 |
| `ai.*` 配置拒写 | 已有第二道锁，不许任何 UI 绕过 |

> 这与万物提案的铁律一致：**数据照旧同源、命令照旧执行，插件只接管「画」**。

---

## 四、那个任务落地时的接入步骤（预演）

1. `dialogChrome` 槽位上线 ⇒ 本档确认框/提权框自动成为候选；壳内置外壳降为默认。
2. `contributes.renderers` 注册表上线 ⇒ `AiPolicyBadge` 与设置分节注册为可替换渲染体。
3. 数据命令不变（`aiPolicy.getState` / `onDidChangePolicy`）——**零迁移**。
4. 新增门禁：替换渲染体 import `policy/*` 或含 `ai.policy.` 字面量 ⇒ 红（P6/P8 同源）。
5. 逃生舱：`app.resetRendererSlot("dialogChrome")`（万物任务统一命令）＋ `aiPolicy.resetToDefault`（`userOnly`）。

---

## 五、验收判据（跨任务）

- 换上一只「第三方设置 UI / 第三方确认框外壳」后：S1–S9 全过，且 **S6（AI 不能自提权）仍全拒**。
- 卸载替换件 ⇒ 自动回壳内置，档位不丢。
- 替换件崩溃 ⇒ 回退内置＋一条回执（万物提案 §四-7 回退链）。

---

## 六、给「万物皆可插件」实施 AI 的三句话

1. 本档的 `AiPolicyBadge` / 确认框内容 **按槽位渲染体形状**写（只吃 DTO，不吃 core）。
2. 槽位注册时把「AI 权限」当作**首批验证样本**——它同时覆盖 dialogChrome + settings + statusBar + notificationPanel 四个面。
3. 任何「为了换皮而复制判定逻辑」的方案 ⇒ 直接否（违反铁律 A/B）。
