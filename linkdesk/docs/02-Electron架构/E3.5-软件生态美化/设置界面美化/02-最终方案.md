## 核心改动：`title` 字段

这是设置页面最大的 UX 问题——用户看到的是技术键名而非人类可读名称。

### 三步改法

**Step 1 — 类型定义**：[ConfigurationRegistry.ts:14-32](../../../src/core/ConfigurationRegistry.ts#L14-L32)

```typescript
export interface ConfigurationProperty {
  type: ConfigurationType;
  /** 人类可读名称——Settings Editor 渲染为标签。未提供时 fallback 到 configKey */
  title?: string;
  default: unknown;
  // ... 其余不变
}
```

**Step 2 — 渲染 fallback**：[SettingsView.tsx:346](../../../src/components/views/SettingsView.tsx#L346)

```tsx
// 旧
<label className="settings-row-label">{configKey}</label>
// 新
<label className="settings-row-label" htmlFor={`setting-ctrl-${configKey}`}>
  {prop?.title ?? configKey}
</label>
```

**Step 3 — 插件作者补 title**：各 `plugin.json` 的 `contributes.configuration.properties` 加 `"title"` 字段。不补也没事——fallback 到 key 保持当前行为。
