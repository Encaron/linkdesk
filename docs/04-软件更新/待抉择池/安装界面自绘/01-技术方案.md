## 一、8 维度设计前置

```
① 能力边界：壳能力（分发/安装面），非插件能力（核心准入三条件不适用——安装器与插件生态无关）。
   保底设计：不写自绘 = 现状 NSIS 向导照旧，零回归风险（保底天然成立）。
② API：无新 window.linkdesk.* 方法——安装期壳进程未运行，安装器在壳外；契约零改动。
③ 通信：无 IPC。安装器与壳的唯一交联 = 安装选项落注册表（HKCU），壳首启可读（可选，非必需）。
④ 壳侧代码：不在 src/（src = React 渲染层，进 asar，安装器不在其中）。落点 build/installer/（新夹）：
   - build/installer/installer.nsi（T3 自定义 NSIS 脚本 / 引导器工程）
   - build/installer/assets/（品牌位图、动效资源、字体）
   - 现有 build/installer.nsh（PATH 垫片入口）保留或并入上夹，同笔定夺
   - electron-builder.yml nsis 段 = 打包声明唯一真相源（script: / installerHeader 等字段在此声明）
   - 门禁扩展：assert-installer-name.mjs（防文件名漂移，已有）＋ check-packaging-files.mjs 判 build/installer/ 资源齐套
⑤ 插件侧：无（零贡献点、零 SDK 面）。
⑥ 显示：NSIS / 引导器自绘窗口（壳外独立顶层窗口）。位置 = 桌面居中；尺寸 ~760×520（见 mockup）。
⑦ 配置：安装选项**不进** app.* 设置页（安装期一次性决策，非运行期配置）；右键菜单写
   HKCU\Software\Classes\*\shell\LinkDesk（文件）＋ HKCU\Software\Classes\Directory\shell\LinkDesk（文件夹）；
   PATH 写 HKCU\Environment（延续 installer.nsh 现状）。设置页要不要补「右键菜单」开关 ⇒ 后续另议，本件不做。
⑧ 验收：npm run electron:build 出包 → 双击实机全流程（02 §二九幕）→ 覆盖安装 → 卸载干净；
   check 全绿（含门禁扩展）；用户视觉验收 = 打包态（攒批补测口径，04 README §一）。
```

**10 条理念对照**：6 无硬编码（品牌色进 assets 配色表，不散落 nsi）· 8 归一性（安装选项一处声明：nsi 写入与 mockup 流程文档同源）· 10 生存力（保底路线 T1 恒可用）。其余不涉及。

## 二、三档技术路线

| 档 | 做法 | 自由度 | 体量 | 风险 |
|:--|:--|:--|:--|:--|
| T1 现状 | `oneClick:false` NSIS 默认向导 | — | — | — |
| T2 半定制 | electron-builder 内建位图位：`installerHeader`（向导顶条位图）＋ `installerSidebar`（左侧 164×314 位图）＋ MUI2 文案 | 只能换图与文案，骨架仍是向导 | 小（半天级） | 几乎无 |
| T3-b **Bootstrapper 全自绘（推荐）** | 自写小体积**引导器 EXE** 画全部 UI（欢迎/路径/选项/进度动画），后台干安装活；NSIS 退居静默解包器（`/S`）或引导器直接解 `app-<ver>.7z`（electron-builder 可出 7z target）复制落位 ＋ 写快捷方式/注册表 | **UI 完全自由**——mockup 的 HTML 设计语言可直通 | 中大 | 引导器是原生新工程，需要选型（见下） |

**T3-b 引导器技术选型**（实现期定，此处立约束）：

- ⛔ **Electron 不可用作引导器**（50MB+ 运行时，违背「安装包先小后大」）。
- 候选：**WebView2 壳**（C++/C# 小壳 + HTML/CSS 画 UI——mockup 可近乎复用；Win10+ 系统自带 WebView2 运行时）· WPF/WinForms（纯原生）· Qt。**倾向 WebView2**：竞标定稿的 HTML/CSS 动效直接搬，双端设计语言零翻译。
- 安装活的两条子路线：① NSIS `/S` 静默（保留 electron-builder 出包链，引导器只当 UI 皮——进度要靠引导器侧文件复制自算）；② 引导器自解 7z（electron-builder target: 7z 出 `app-<ver>.7z`，引导器调 7.dll/7z 解到目标目录，进度 = 解压回调，真实）。**✅ 定案 ②（2026-10-01 拍板 T3-b 时一并定）**：进度真实、链条更短；**NSIS 全退场**——卸载器 = 引导器的卸载模式（[mockups/E-卸载屏.html](mockups/E-卸载屏.html)），ARP 注册（DisplayName / DisplayVersion / UninstallString / DisplayIcon / NoModify / NoRepair）由引导器首装时写入。
- 大文件校验：解压后对 `resources/` 关键文件做大小/哈希抽查（沿用更新器既有校验思路）。

## 三、文件位置定论（回答「还在 src 吗」）

**不在 src/。** 目录铁律：`src/` = 壳渲染层（进 asar、随包走）；安装器是**壳外二进制**，与打包资源同域。落点：

```
build/
├── icon.ico / icon.svg          # 现有品牌资产
├── installer.nsh                # 现有 NSIS 定制入口（PATH 垫片）→ T3 时并入 installer/ 或保留，实现期同笔定夺
└── installer/                   # 🆕 本件新夹（T3-b 时）
    ├── bootstrapper/            # 引导器工程（WebView2 壳源码，独立构建，产物 ~2MB）
    ├── assets/                  # 品牌位图 / 动效资源 / 配色表（无硬编码：色值集中此处）
    └── installer.nsi            # （🔴 已退役 2026-10-01：NSIS 全退场后无需此文件——卸载器 = 引导器卸载模式，见 §二）
```

打包链改动：`electron:build` 加引导器构建步（`npm run build` 前/后插）；`check-packaging-files.mjs` 加「installer/ 资源齐套」判腿。**mockup（docs/ 下的竞标 HTML）不进包**，与安装器资源是两回事。

> 🔴 **件 3b 订正（2026-10-02，已落地）**：本条原写「electron-builder.yml `nsis` 段声明自定义 script」——**`nsis` 段已整段删除**（target 改 `7z`）。
> 现链条：`electron-builder` 只出**载荷** `linkdesk-setup-<ver>.7z`（`artifactName` 命名它）＋ `win-unpacked/`，
> 对用户的 `linkdesk-setup-<ver>.exe` 由 `scripts/build-installer.mjs` 拼（**自绘壳 ＋ 64 字节 marker ＋ 载荷 ＝ 单文件**），
> `latest.yml` 也改由它写（NSIS 退役后 electron-builder 不再产），`*.blockmap` 随之退场。安装包**名字与契约不变**（`assert-installer-name` 四判据照旧全绿）。

## 五、安装器 i18n（语言选择——2026-10-01 用户拍板要做）

**结论先行**：语言清单目录化 = **无硬编码（声明式）**；安装器的词只归安装器 = **高内聚**——直觉全对，机制如下。

**翻译放哪（定论）**：**不进翻译插件，落 `build/installer/i18n/`**（`zh-CN.json` 默认 ＋ `en.json` 随首版）。三条理由：

1. 安装期壳与插件体系**尚未运行**——插件由壳装载、跑在 userData，安装器在壳之前，翻译插件根本没机会被加载；
2. 翻译插件服务的是**运行期内容面**，生命周期与安装器不同步——安装器 i18n 必须跟安装器同版本走（同笔发版）；
3. 单一真相源：安装器的词全仓只有这一处，谁改翻译都改这份，不与壳词条漂移。

**机制（key 驱动，声明式）**：

- 引导器启动时**扫描 `i18n/` 目录**得出语言清单——下拉项 = 目录枚举，不是写死的数组 ⇒ 未来加语言（日/韩/…）= **加一个 json 文件，零代码改动**；
- 界面文案全部走 key（`installer.welcome.title` 型）查表渲染；缺 key 回落 `zh-CN`，再缺回落 key 名（开发期漏翻立刻可见）；
- 语言选择持久化 `HKCU\Software\LinkDesk\Installer → Language`，升级安装带出上次选择（[02-流程设计.md](02-流程设计.md) §四）。⚠️ 2026-10-02 勘误：原文写作 `HKCU\Software\LinkDesk Installer`（空格），与实现（`syswrite.cpp` 的 `WriteInstallerLanguage`、`tools/i18n-test.ps1`）及 §四对账表口径不一致，**以本行反斜杠版为准**。

**与壳 i18n（lang-defaults）的关系**：两套并行、互不依赖、词条**不共享**（语境与生命周期都不同）；只对齐**术语表**（同一个词人读起来一致：插件 plugin、主题 theme…），靠人工复查对齐，不做机械联动。

## 六、界面技术定论：HTML/CSS（WebView2）＋ 安装器本地明暗主题

- **确认**：UI = **HTML/CSS/JS，WebView2 渲染**（T3-b 的核心收益）——竞标定稿 mockup 的 HTML/CSS/动效可近乎直通移植。
- **不能复用壳主题（定论）**：ThemeEngine 是**壳运行期**机制（CSS var 体系 ＋ 插件主题配方，壳启动后才存在）；安装期壳未运行 ⇒ 安装器**不接主题插件、不吃壳 token**。html-blueprint 的 `var(--xxx)` 规矩约束的是壳面 mockup；安装器是独立面，本档 mockup 用本地 token（各文件头已注明「mockup 仅示意」）。
- **安装器本地轻主题（成立，成本极低）**：明 / 暗两套 CSS `:root` token（黑白灰 ＋ 品牌色一档）。**2026-10-01 用户拍板**：安装器**默认亮色**（偏亮的一套），且**不做主题切换 UI**（保持「一步安装」的克制）；暗色 token 留作后续可选，不随首版承诺。token 参照：**亮 = A 编辑部极简的暖纸白**（E 混合案已试融），暗 = B 深空玻璃。
