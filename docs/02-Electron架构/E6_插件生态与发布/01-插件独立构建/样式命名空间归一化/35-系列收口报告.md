## 六、探针覆盖不到什么（**照 22 号档 §八 的硬要求：1.20 报告必须照抄这一段**）

1. **插件 CSS 只在视图挂载时注入** ⇒ **没有活视图 = 采不到该插件的样式**（本格的方名册 = 4 只插件，与本系列历轮的基线一致）；
2. **只覆盖样式四轴**（类名 / 关键帧 / token / 选择器形态）——**本格件 10 普查出的 6 条 🔴 一条都看不见**（那些是命令 id、设置键、contextKey…）⇒ **非样式轴今天没有任何运行时量尺**；
3. **按文档算碰撞**——池文档与渲染进程文档各有自己的 CSSOM，跨文档同名**不是**碰撞（同一份 `src/index.css` 在两个文档各注入一次，跨文档求和会得 2 倍，那是**重复计数不是差异**）；
4. **看不见运行时动态拼出的名字**（`theme-${variant}`）；
5. **`vendored-shared-css` 只列名不判红**（`@linkdesk/ui` 不是 external ⇒ 每只插件 bundle 内联一份 UI 库 CSS 的**已知结构性事实**）——插件**源码**里的 `ldk-` 借用由 SDK 静态腿判红，**两把尺子合起来才无死角**；
6. **采集层不进 `npm run check`**（check 必须能在没有软件实例的机器上跑）⇒ 探针结论靠**人工/轮次纪律**触达；
7. **域外文件不采**（探针只认仓内 host / shared 两个域）；
8. **浅层形态判定**（轴 ④ 判「形态」不判「意图」）。

## 八、给用户的大白话（**查出什么 / 哪些真危险 / 怎么治 / 还剩什么不治**）

**这一整套在治什么。** 一句话：**「不是问题在长大，是尺子一直在漏。」** 插件的样式和宿主的样式住在**同一个文档、同一张扁平名字表**里，谁都能往里写，撞了不报错——**只是长得不对**（`.badge` 案：徽标文字被自己的背景吞掉，看着是一块纯色）。而**受害方永远收不到通知**：你在自己机器上没装对方插件，一切正常。

**治的结果。** 四条轴（类名 / 关键帧 / 自定义属性 / 选择器形态）**全部结构性收口**：宿主与共享组件**自己定义的类名 100% 是 `ldk-`**（258 ＋ 89 个独立定义零例外），插件必须带**自己的 id 前缀**（18 仓实测零违规）。**「登记表」这个逃生口已经拆掉——只有改名一条路。**

**凭什么信它。** 三层：**约定**（作者面 §12 写死规则）＋ **静态门禁**（35 道，其中 34 道带自测且**逐道真跑**）＋ **运行时探针**（实机 dump 全部样式表，机械断言零跨方碰撞——本轮真跑：**零 red**）。**「门禁绿了」这句话现在是有分量的**：件 8 之后，绿必须是**证明过的绿**（每条判据都得真红过一次才算数）。

**还剩下什么没治（如实说）。**
1. **机制层没隔离**——靠的是「约定 ＋ 门禁 ＋ 探针」，**不是构造上不可能**。所以措辞是「**事实上不会发生**」，不是「不可能发生」。要不要上真隔离**想过并否决了**，决策和** 5 条触发条件**（什么情况下回头重估）都写进了 `docs/decisions/`。
2. **宿主那 17 处基线选择器是「有意的跨方命中」**（`*` reset、滚动条、`select` 这些），**插件依赖它们** ⇒ 登记成例外，不是违规，也**不许删**。
3. **门禁是静态的** ⇒ 运行时动态拼出来的名字理论上能绕过（本系列选择不加运行时拦截）。
4. **三方的 `codicon` 图标字体（651 个类名）不归我们管**，那是外部契约，动了全软件图标变方块。
5. **插件「有意覆盖共享组件外观」是合法特性**，门禁只约束**形态**、不管你**意图**。
6. 🔴 **最大的一条：样式之外的同类问题，这一轮只「查清」了，还没「治」。** 普查发现**同一个形状在这个软件里还有 6 处**：命令 id、设置键、主题/图标/语言 id、**上下文键**、`pluginState`、快捷键。其中两条**比样式的任何一条都危险**，因为它们改的是**行为/权限**而不是外观——**插件一条 `contextKey.set` 能静默改宿主菜单和快捷键的可用性（连一行警告都没有），`pluginState` 的接口还能让一个插件读写另一个插件、甚至宿主自己的数据**。这两条**与样式无关**。🔴 **后续已经立项**：**E6#111「非样式命名空间归一化」专项**（[00-整理档案](../非样式命名空间归一化/00-整理档案.md)），**第 0 格（审查＋派工）已完成**，把普查结论变成了 **20 轮**的排期（1.31–1.50，含迁移基建与 7 个官方仓清账轮），**下一棒 = 1.31**。

**一句话结论**：**样式这一类，收口了**（四条轴结构性覆盖 ＋ 三层证明 ＋ 零 red 实测）；**样式之外，查清了、排好队了、还没治**——那是下一个系列的事。
