- 该单元是 hook ⇒ 需 `@testing-library/react`，而 settings **现在没有**这个 devDep（file-tree / editor 也没有，只有 serial-monitor / marketplace 有）。两条路：

2. **settings 若走 (a)**：`package.json` 的 devDeps 变更要**单独说明**在交接段（谁加的、为什么、版本从哪抄的），lock 同笔。
