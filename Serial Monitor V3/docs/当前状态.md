## 一、项目概况

V3 是 V2 的重架构——保持 V2 全部功能，底盘从 WPF .NET 8 换成 Tauri + React。

| | V2 | V3 |
|------|------|------|
| 框架 | WPF .NET 8 | Tauri v2 + React 18 + TypeScript |
| 接收区 | AvalonEdit | CodeMirror 6 |
| 发送栏 | 多行 TextBox | Monaco Editor 单行 |
| 主题 | DynamicResource | CSS 变量 21 色 |
| 双语 | 自研 T() 函数 | react-i18next `t()` |
| 串口 | C# SerialPort | Rust serialport + tokio |
| 协议 | `[type, subType, ...]` | `[卡片ID, 字段...]` |

## 二、已完成功能

### 终端视图

- CM6 只读接收区，等宽字体，行号显示
- 三色行：接收白色 / 发送蓝色 / 系统消息灰色
- Monaco 单行发送栏，`>` 命令前缀，Enter 发送
- 快捷发送药丸按钮（AT / AT+CWLAP / AT+CWJAP）
- 侧栏设置：时间戳格式 / 消息回显 / 行号 / 系统消息独立显示 / 换行符 / 定时发送 / 发送后清空 / 编码
- 所有设置**真实生效**（走 React Context 共享状态）
- 搜索（CM6 原生面板，按钮 toggle + 蓝色高亮同步）
- 暂停（实时计数，缓冲 2000 条上限，恢复回放）
- 导出日志（`showSaveFilePicker` API）
- 行数上限裁剪（2000 行 → 砍 500）
- "↓ 回到底部"浮动按钮

### 布局

- 3 行 × 3 列骨架（和 V2 一致）
- 顶栏：串口选择 / 波特率 / 打开按钮（绿点）+ 中/EN / ☀ / ?
- 图标栏：📟 终端 / 📊 工作台 / ⚙ 设置，选中蓝条 + 光晕
- 侧栏：220px 默认，160-520px 可拖拽，28px 折叠
- 状态栏：连接绿点 + TX/RX 计数
- 点 ⚙ 设置不改变上一次内容视图（和 V2 `_previousContentTab` 同逻辑）

### 基础设施（V2.6 教训）

- **CSS 变量 21 色**：所有颜色走 `var(--xxx)`，禁止硬编码 hex
- **react-i18next `t()`**：全部 UI 文字走翻译函数，`en.json` 已就绪（45 条映射）
- **归一化 `.form-row`**：标签+控件行强制对齐，`space-between` 错位从根源消灭
- **组件不从 JS 设颜色**：切主题 = 改 `data-theme` 一个属性

### 核心服务（14/14 单测通过）

| 模块 | 功能 |
|------|------|
| DataConverter | Bytes↔Hex↔Text，V2 算法照搬 |
| ProtocolParser | 方括号协议解析，V2 算法照搬，V3 协议适配 |
| RingBuffer | 512 容量，单生产者单消费者 |
| PreferenceService | 唯一配置入口，Phase 1 用 localStorage，Phase 2 切文件 |

### Rust 串口层

| 命令 | 功能 |
|------|------|
| `list_ports` | 枚举 COM 口 |
| `open_port` | 打开 + 启动 tokio 读线程 |
| `close_port` | 关闭 + 冲刷残留 |
| `send_data` | 发送字节 |
| `set_dtr` / `set_rts` | 硬件流控 |
| 读线程 | 100ms 超时 → `\n` 拆行 → emit `serial-data` |

### 数据管道

```
STM32 → Rust serialport 读线程 → emit("serial-data")
→ React listen → RingBuffer.write() → rAF drainAll()
→ CM6 appendLine(三色) → 暂停/搜索/导出/裁剪
```

## 四、技术债务

1. **CM6 搜索面板**：使用 CM6 原生面板，英文标签，UI 不能自定义。Phase 2 可考虑替换接收区为虚拟列表
2. **PreferenceService**：Phase 1 用 localStorage，Phase 2 需切到 Tauri 文件系统 API
3. **CM6 行号动态开关**：lineNumbers 插件初始化后不能动态关，需 CM6 reconfigure
4. **Monaco 打包体积**：~150KB gzipped，如果只做单行输入可考虑换 textarea
