## 变更流程（🔴 纪律，每次批注都走这条链）

1. 用户对 HTML 提修改 → **先改 HTML**（效果图真源）。
2. 同笔在 §二对照表登记（改了哪个锚点、对应哪条拍板）。
3. 若改动**推翻拍板** → 回改对应拍板档（03/04/05/06），拍板档与 HTML 永远同值。
4. R4 实机实现：实现 AI 必读 HTML 全文 ＋ 本档，逐 `data-spec` 锚点对账；**HTML 有的必须做，HTML 没有的不得私自加**。

## §一 蓝图覆盖范围（v1，2026-11-19）

- **只做深色一主题**（官方主题「深色」配方实值 token 化进 CSS；用户拍板不做多主题）。
- **设置页不动**（B 开关将来 = 设置页一行配置项，03 §一·3）。
- 侧栏、主区商店、跨标签详情、hover 悬浮展开（**v2 起实现**，05 §二拍板变更）、状态机、响应式全部入图。
- **v2 变更**（2026-11-19 批注驱动）：图标全量重绘＝Lucide 真实路径统一 stroke；卡片扩为五原型（small/grid/mega/duo/rank）对标 MS Store 实测比例；英雄横幅转真轮播；详情页三页签真实切换；数据丰富度翻倍（真实目录 16 条）。
