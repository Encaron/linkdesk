## 逐格详案

### R4-1.1 ⬜ 图标键
**做什么**：`icon:selected` 处理器扩一分支——非 tabOnly 插件且 `getConfigurationValue(pluginId+".openTabOnIcon")===true` ⇒ 也 `createTab(pluginId)`；默认关零行为差异。
**现状实测**：`tabActions.ts:44-58` 只判 `appearsIn.tabBar && !sidePanel`；配置读取用 `src/core/services/configuration/ConfigurationService.ts` 的 `getConfigurationValue`（grep）。
**判据**：开关关＝现状逐像素不变；开＝侧栏＋商店标签同起。
**验收**：useTabManager.test 补两例；真机手动开关闭各点一次图标。

### R4-1.2 ⬜ installFromDirectory
**做什么**：按 09 §三·补2 表——校验（plugin.json 合法/pluginId 安全字符 `SAFE_PLUGIN_ID`/**拒 core:true**/同 id 已装返回 `reason:"exists"`）→ 复制进 `{userData}/plugins/<id>`（复用既有解压/落盘服务，grep `unzip`/`installPlugin` 流水线）→ 注册 → 发 lifecycle 事件（与网络安装同一路，⛔ 旁路）。
**判据**：五类回执 `{ok:true,pluginId}` / `bad-manifest|unsafe-id|core-forbidden|exists|io` 各有用例；装完插件出现在已装列表且可卸载。
**验收**：单测五例＋真机选文件夹装一个演示插件。
**边界**：只收单插件文件夹或 .linkdesk-plugin 包；⛔ 多插件目录（v2 再议）。

### R4-1.3 ⬜ licenses API
**做什么**：① `licenses.verify(key)`：Ed25519（node:crypto `verify`）——公钥来自目录条目作者块 `publicKey`；载荷 `{pluginId,machine?,exp?}`；`machine` 有值时比对 `env.get()` 新增的 `machineFingerprint`（主进程硬件稳定 hash——主板+机器ID 的 sha256 前 16 位，写入 `electron/services/env-service.ts`）；结果写壳侧权益存储（`plugin-states.json` 域外新文件或同 StorageService 新键 `licenses`）；② `licenses.list()` / `licenses.remove(pluginId)`；③ 安装门：流水线对 `pricing.model` 存在的条目查权益，无 → 拦（回执 `reason:"license-required"`），与 `minAppVersionGate` 同位模式。
**判据**：验签离线可用（断网测）；无效签名拒；`exp` 过期拒；机器不符拒；权益被市场插件替换后**门仍生效**（05 §三·4 判别测试题）。
**验收**：单测（生成测试密钥对）＋真机：装一个测试付费插件走通/走断各一遍。
**⛔**：市场插件内写任何「判付费」逻辑＝违规（05 §三·4）。
