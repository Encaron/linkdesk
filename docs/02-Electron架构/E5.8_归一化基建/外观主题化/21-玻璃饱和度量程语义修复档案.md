## 一、背景与用户实机证据

用户拉 `app.glassSaturate` 滑杆到 0，三主题效果差异巨大：

| 主题 | glass 配置 | saturate=0 实测 |
|---|---|---|
| 整窗主视觉（panorama） | `glass:{}` 空 + 无 tint + opacity 默认 | 全屏灰色 ✅ |
| 全胶囊 | 带色 tint | 带着颜色的灰（半灰） |
| 极光玻璃（aurora） | `blur:24, saturate:1.25, tint:rgba(59,77,148,0.35), opacity:0.275` | **几乎无变化 ✗** |

用户补充决定性观察（2026-08-27）：**只要 app.glassTint≠空，拉动 app.glassSaturate 就无效**；tint 为空时右键菜单（float 层）正常变灰。三主题谱系 = 渐变 tint+opacity 的梯度泄漏，与「主题特殊」无关。

## 二、根因（两条放大链，同源 #117 新缝）

**#117 把 saturate 从 ::after 镜像 filter 移进 ::before backdrop-filter 后，端点从未跨主题复验**——tint 盖片 + opacity 稀释两层夹击：

1. **tint 盖片 = 画在 ::before 自身背景上的平色**（index.css:551 `background: var(--glass-tint, transparent)`）。backdrop-filter: saturate() 只作用于**背后采样图**，从不作用于自身背景 → tint alpha 1 = 完全盖死 backdrop-filter 结果（blur+saturate 双死）；tint 半透明 = 残留彩色罩。
2. **--glass-opacity 稀释整层**（index.css:552，aurora 0.275）→ 整层（含 backdrop-filter 结果）被稀释到 27.5%，剩余 72.5% 露出**未模糊未去饱和的原始背景**。

全胶囊「带色灰」= 半透明 tint 罩在已灰背景上；aurora「几乎不变」= tint 残留彩色 + 27.5% opacity 双层泄漏。float 层（右键菜单，index.css:509-513）无 tint、opacity 1 → 永远正确灰，**反证 saturate 写入 :root 正常**（seeds.ts:233-236 presence 门控）。

**判定**：非回归 commit——#126-#127 只动 zone-measurement token（surface-zones.ts/events.ts，diff 已排除），零玻璃代码。**新缝，起源 #117 删镜像后 saturate 端点未跨主题复验。** glassBlur 同类（同层/同稀释）但 blur=0 端点跨主题一致 + 主题缩放 blur 是含蓄玻璃意图 → 不修，保持现状。

## 三、修复设计（#150 核心 + #151 B，用户拍板 b）

### #150 端点语义核心（CSS index.css:550-552）

目标：**saturate=0 → 任何主题全灰无歧义**；**saturate≥1 → 主题默认零变化**。

| 行 | 现状 | 改后 |
|---|---|---|
| :550 backdrop-filter | `blur(…) saturate(var(--glass-saturate,1))` | **不动**（保住 >1 主题增强：aurora 1.25） |
| :551 background | `var(--glass-tint, transparent)` | **不动** |
| :552 opacity | `var(--glass-opacity,1)` | `max(var(--glass-opacity,1), calc(1 - var(--glass-saturate,1)))`——s=0 强制 opacity≥1 不稀释；s≥1 恒等 |
| 新增 filter | — | `filter: saturate(min(var(--glass-saturate,1),1))`——去饱和 tint 本身；s≥1 恒等 |

**变体裁决**：选 **min-clamp**（filter 只去饱和 <1 段）非 full-range（`filter: saturate(s)` 单一应用）。原因：full-range 会改变 aurora 默认 tint（其 saturate=1.25 会把 tint 放大 1.25× 更艳）——用户明确**主题默认必须零变化**（「点击跟随主题回到主题本身对比度」）。代价 = s<1 时 backdrop 双重应用（s²）轻微非线性，但单调、端点正确、视觉无害，可接受。

端点推演验证：

- **s=0**：opacity→1（不稀释）+ tint 全去饱和 + backdrop 去饱和 → 三主题全灰 ✅
- **s=1**：min-clamp filter saturate(1) 恒等 + opacity max(opacity,0)=opacity + backdrop saturate(1) 恒等 → **零变化** ✅
- **s=1.25**（aurora 默认）：filter saturate(1) 恒等（tint 不动）+ backdrop saturate(1.25) 同现状 → **零变化** ✅
- **panorama**（glass:{} 无 tint opacity 1）：max(1,1)=1 + 透明背景 → **零变化** ✅
- **float 层**（无 tint，opacity 1）：零触碰，已正确 ✅

### #151 tint 强制半透明（选项 B，JS 侧生产者，另立案）

目标：**彩色玻璃永远可见 blur/saturate**（tint 永不当不透明死盖片）。

- CSS `color-mix` 无法自适应封顶（朝透明混合会乘自身 alpha）→ 必须在**生产者**封 alpha ≤0.5：
  - `seeds.ts` 用户 glassTint 路径
  - `tokens.ts` 配方 tint 路径
- 保留 tint 色相，强制 ≥50% 透 → backdrop-filter 结果永远透出，blur/saturate 永远有响应。
- aurora 默认 tint alpha 0.35 **已 <0.5 → 零触碰**；只影响用户/配方的 solid tint。
