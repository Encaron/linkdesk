# 插件橱窗（Plugin Showcase）——Marketplace-Store 的一个组件

> 2026-09-13 重组：原「04-出厂制造/06-Plugin-Showcase-插件橱窗」并入 Marketplace-Store 档案作一章——它是商店顶部的「编辑推荐」横幅，随 Marketplace 插件一起分发，不是独立插件。
> Marketplace 的门面担当。3 张精选插件大卡片，视觉层次感强。

---

## 基本逻辑

Marketplace 商店顶部的一个横幅区域——3 张"编辑推荐"的精选插件大卡片横排。中间那张略大（`scale(1.05)`），两边对称。这是 Marketplace 的"第一屏"——用户打开商店首先看到的。

**核心原则：** 不是广告位——是**策展位**。编辑人工挑选 3 个最能展示 LinkDesk 能力的插件放在这里。

---

## 处于软件内位置

```
Marketplace 商店视图（#05）
  └─ 编辑推荐 Banner（本组件）
       ├─ 卡片 1（左）
       ├─ 卡片 2（中，略大）
       └─ 卡片 3（右）
  └─ 分类标签栏
  └─ 插件卡片网格
```

**嵌入关系：** 被 #05 Marketplace Store 直接嵌入。也可以独立使用（比如启动页的推荐区）。

---

## 生态地位

| 维度 | 说明 |
|------|------|
| **策展** | 编辑推荐 = 平台官方背书。告诉用户"这些是我们最引以为傲的插件" |
| **导航** | 新用户不知道装什么 → 看推荐 → 点一个 → 了解 → 安装 |
| **周期更新** | 可以按周/月更换推荐插件（比如"本周精选"） |
| **依赖链** | 被 #05 Marketplace 消费 |

## 关键交互

| 交互 | 触发 | 行为 |
|------|------|------|
| **hover 卡片** | 鼠标进入 | 上浮 4px，阴影加深，描述从 2 行展开到 4 行（max-height 过渡） |
| **中间卡片放大** | 静态 | 中间卡片 scale(1.05)，视觉重心在中央 |
| **查看详情** | 点击按钮 | 跳转到插件详情页（或展开内联详情） |
| **切换推荐** | 如果有管理后台 | 编辑可以更换推荐的 3 个插件 |

### 推荐插件选择标准

| 标准 | 说明 |
|------|------|
| **展示平台能力** | 推荐能代表 LinkDesk 核心价值的插件 |
| **成熟度** | 功能完整、UI 精美、无已知 bug |
| **多样性** | 3 个覆盖不同领域（如开发工具 + 可视化 + 创意） |
| **新鲜度** | 定期轮换，保持"编辑推荐"的新鲜感 |
