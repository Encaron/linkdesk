## 1. 形态全景——每种窗口能干什么（2026-08-17 文档实查）

| 形态 | 定位 | 状态 | 能干什么 | 不能干什么 |
|:--|:--|:--|:--|:--|
| **PanelZone 底部停靠区** | 常驻工具区（对标 VS Code 底部面板） | ✅ E5.7 #21/#63.7/#88 已落地 | 插件声明 `location:"panel"` 贡献视图（零壳改动实证）；标签切换 + keep-alive；顶部 4px 拖高（120-600 钳制）+ 高度持久化 | 无 Ctrl+J 显隐命令；[+] 按钮 no-op；无容器切换器（多插件混签一条标签栏）；无 panel.reveal |
| **池侧浮层三件套**（Dialog/QuickPick/Toast） | 瞬时交互——模态 | ✅ E5.7 Phase 4 归池已落地 | 居中模态框 / 命令面板 / 全局通知；跨 Pool 边界；壳内渲染不建 OS 窗口 | 不能拖拽、不能 resize、非模态 |
| **壳内悬浮面板（类型 B FloatingPanel）** | 大面板临时工作区（对标 VS Code 设置面板） | 📋 仅 E3 时代设计稿（[04-出厂制造 03](../../04-出厂制造/03-FloatingPanel-通用悬浮面板/README.md)），组件从未落地 | 大 overlay 覆盖主区卡在壳内；可拖（顶部 6px 手柄）+ 可 resize（底部 8px，最小 300px）；actions 区："在主窗口中打开"**面板↔标签页双向互转** / 最大化 / 关闭 | 不创建 OS 窗口；不开新标签页（除非点"在主窗口中打开"） |
| **可拖出面板（类型 A 脱出窗口）** | 真 OS 多窗口——第二块屏 | 📋 设计稿就绪（[脱出窗口设计.md](../E5.7_极简Pool/脱出窗口/脱出窗口设计.md)），推迟 v1.3 | 拖标签页出主窗口 → 独立 BrowserWindow 只渲染那 1 个 tab；拖回并回 / 关窗 tab 回归；`window.open(layout)` 新窗口新 tab；**漂移面板**（PanelZone ⤢ → 面板独立窗口化） | 状态迁移空白：拖出 = unmount+remount，插件 renderer 状态全丢（审计发现 1） |
| ~~OverlayWindow~~ | 外部系统窗口 | ⚰️ E5.7 Phase 4 整删 | —— | 墓碑，勿再提 |

**四层各司其职、互不替代：** 停靠 = 常驻；modal = 瞬时；类型 B = 壳内大面板；类型 A = 壳外多窗口。

### 3.1 #31 Ctrl+J 显隐命令

- **注册命令** `workbench.action.togglePanel`——新建 `src/core/commands/panelCommands.ts`（settingsCommands 同款模式，语义域 = 面板命令；Phase 2 可逆注册已就位，registerShellLocalCommand 走新注册面）
- **键位**：`src/core/commands/shellKeybindings.ts` 加一行 `{ command: "workbench.action.togglePanel", key: "ctrl+j" }`（现网已无 ctrl+j——#88 实查）
- **状态与持久化**：`App.tsx` 加 `panelVisible` state；LayoutService panel 段加 `visible` 字段（与 height/activeViewId 同段持久化，layout.json）
- **显隐语义（零契约改动方案）**：panelVisible=false → usePoolSync 不推 panel 字段 → 池条件渲染永假（现网"无贡献即不推"语义直接复用）——**不改 PoolLayout 契约**；有 panel 贡献时 Ctrl+J 折叠/展开；无贡献时命令 no-op（无面板可开，不加 toast 噪音）
- **验收**：Ctrl+J 关→开面板；重启恢复显隐态；卸载全部 panel 贡献插件后 Ctrl+J 不崩

### 3.2 #32 [+] 新建 = QuickPick 视图选择器

- **行为定义**：[+] 现网语义 = "新建面板视图"（tooltip 壳推 panel.createTooltip）；本项定案 = **QuickPick 视图选择器**（对标 VS Code 面板视图菜单）——列出全部 panel 贡献视图，已激活项带勾选标记，选中 → setPanelActiveViewId + 推 panel
- **实现**：`App.tsx` 桥接 panel:createView 事件（现网 emit 零监听者 no-op——#88 ③）→ QuickPickService 推 DTO（E5.7 #15 桥现成）；数据源 = `ViewContainerService.getViewContainers("panel")` + `getActiveViews`（#63.7 同源，两级展平）
- **验收**：点击 [+] → QuickPick 弹出全视图列表 → 选中 → 面板切到该视图；仅 1 个贡献视图时列表长度 1 正常

### 3.3 #33 菜单栏「面板」菜单（定案设计执行化）

- **定案（memory 面板定案，用户拍板）**：壳声明招牌 + 打开/折叠条目；插件声明子菜单内容（`group:"panel"` 自动归并）；MenuRenderer 渲染全套现成

- **验收**：菜单栏「面板」出现 → 打开/折叠可点；声明 group:"panel" 的第三方插件子菜单自动出现（零壳改动）

### 3.4 #34 容器切换器（⚠️ 执行前用户拍板）
