# 日本語テスト

一只日语的**测试语言包**——用来验证「语言也是一种插件」。

## 这是什么

一只**纯数据插件**：没有一行界面代码，只贡献一份 `ja.json` 词典。装上之后，LinkDesk 的语言列表里就多一个「日本語」。

- 插件 ID：`lang-test-ja`
- 语言：`ja`（日本語）
- 覆盖范围：只翻了少量条目——**它是验证载体，不是完整译文**
- 怎么切：设置 → 语言

> 它存在的意义：证明界面文字和主题一样是**可贡献的数据**——多加一种语言 ＝ 多装一只插件，核心一个字都不用改。

## 结构

```
plugin.json       声明（contributes.languages）
ja.json           词典
```
