## 一、无论哪一格都适用的硬要求（**纪律，不是建议**）

1. **单一真相源不许变成两份**：规则若需要清单/前缀表，必须**长在 SDK 包里、随包下发**（照 `reserved-class-names.json` 的先例）。✅ 本次拍板后**不需要任何清单**（前缀来源 = `pluginId`），这条自动满足——**不要顺手引入基线/白名单文件**。
2. **判据必须能从机器事实推出**：「裸定义类名/关键帧名的首段 === `pluginId`」。靠人看的写进作者面文档。
3. **负控要真跑红**（照 `#109e` 的做法）：往一只真插件仓塞一条违规 ⇒ 该仓 `npm run verify` **当场红**，报点含**文件 ＋ 行 ＋ 名字**；还原即绿（记 sha256 → 改 → 跑 → 还原 → 复核字节相同）。**自测通过不算判据。**
4. **fail-closed，且已实测确认**：插件仓 `scripts/ci-verify.mjs` 的 ① 段 = 「**除报表档外的全部腿**」判红（`ADVISORY_LEGS` 只豁免 `check-font-scale` / `check-spacing-grid`）⇒ 新判据**自动进严格档**。落地时**实测确认**它在 `strictLegs` 里（打印腿名对一眼），**别只读代码**。
5. 🔴 **`plugin.json` 是 JSONC**（可注释、可尾逗号）：读 manifest 的新代码**必须用 JSONC 解析器**（SDK 已依赖 `jsonc-parser`；`validate.ts:172` 是现成先例）。**另**：schema 顶层 `additionalProperties: true` ⇒ **别指望 ajv 替你拦字段**。
6. 🔴 **18 只插件仓的 SDK 依赖全是 `^0.1.19`**（caret 上界 `<0.2.0`）⇒ **新 PATCH 会被自动吃到**，而严格腿是 fail-closed ⇒ **SDK 一发布，任何未改名的仓 CI 当场红**。⇒ **顺序纪律：所有插件仓改名必须先于 SDK 发布**（见 §四 的 ⑧）。
7. 🔴 **改名的正确性判据是机械证明，不是「我看着对」**：见 §五 最后一条 ＋ §六 NC9。

## 二、规则与命名形状

**规则（落地后作者面写这一句）**：
> **插件 CSS 里给自有元素起的类名、以及自己的 `@keyframes` 名，必须以你的 `pluginId` 加一个连字符开头**（例如 `settings-*`、`editor-*`）。

**🔴 一个执行前必须定死的细节：旧前缀怎么处理（`ms-` / `mpd-` / `demo-` / `session-` 这些）**

| 形状 | 做法 | 例（marketplace） | 利 | 弊 |
|:--|:--|:--|:--|:--|
| **(ii) 叠加（推荐）** | 在原名前**插入** `<pluginId>-` | `ms-item-name` → **`marketplace-ms-item-name`** | 🔴 **可机械证明**：「新文件 = 旧文件 + 逐行只插入前缀」逐字节可验（1.16 同一手法）⇒ **静默失样式风险降到零**；且符合本系列 §六.2「**不改词干**」 | 名字长一点（`serial-monitor-qs-input`） |
| (i) 替换 | 用 `<pluginId>-` **替换**旧前缀段 | `ms-item-name` → **`marketplace-item-name`** | 名字干净、一眼归属 | 改的是**词干**⇒ 无法用「只插入」证明，478 处的每一处都要靠 token 判据兜；与 §六.2 的既有纪律冲突 |
| (iii) 缩写保留为二级前缀 | —— | —— | —— | **同 (i) 的弊，且没换来干净** ⇒ 不考虑 |

⇒ **默认走 (ii) 叠加**。理由只有一条但足够：**(B) 路线把「静默失样式」放到了关键路径上，而 (ii) 是唯一能用「逐字节只插入前缀」把这条风险机械消掉的形状**。若某一格执行者认为某仓有更好的理由走 (i)，**必须在交接段写明理由并接受「只能靠 token 判据兜」**——不许悄悄改形状。

**关键帧**（Q3=(A)）：`serial-monitor` 的 `fadeIn` → `serial-monitor-fadeIn`、`slideDown` → `serial-monitor-slideDown`；`marketplace` 的 `ms-icon-spin` → `marketplace-ms-icon-spin`。**同时改 `animation:` 引用处**（关键帧改名漏了引用 = 动画静默消失，同形风险）。
