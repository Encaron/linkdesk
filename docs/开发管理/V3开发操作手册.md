# V3 开发操作手册

> 日常开发怎么跑起来、怎么切换模式、怎么停。看了就会。

---

## 环境准备好（仅此一次）

打开 Git Bash 终端，配 cargo 路径：

```bash
echo 'export PATH="$HOME/.cargo/bin:$PATH"' >> ~/.bashrc
```

关掉终端重开一次，以后永久生效。

---

## 两种打开方式

### 方式 1：浏览器（调 UI 最快）

改代码 → 保存 → 浏览器瞬间刷新，不用编译。

```bash
cd "linkdesk"
npx vite
```

看到 `➜ Local: http://localhost:1420/` → 浏览器打开 `http://localhost:1420`

**优点：** F12 DevTools 调样式、看 console、断点  
**怎么停：** 终端按 `Ctrl+C`

---

### 方式 2：原生 Windows 窗口（最终验证）

弹出真正的桌面窗口，测串口功能用。

```bash
cd "linkdesk"
npx tauri dev
```

**优点：** 和发布后的 exe 一模一样  
**怎么停：** 关掉窗口 或 终端按 `Ctrl+C`

---

## 怎么切换

```
Ctrl+C 停掉当前 → 敲新命令
```

两个不能同时跑——都占 :1420 端口。

---

## 日常套路

```
开发 UI    → npx vite + 浏览器   （秒级反馈）
最终验证   → npx tauri dev       （完整效果）
打包分发   → npx tauri build     （生成 exe/msi）
```

---

## 热更新规则

| 改了哪 | Vite（浏览器） | Tauri dev（窗口） |
|--------|:--:|:--:|
| React / CSS / TS | 瞬间刷新 | 瞬间刷新 |
| Rust（src-tauri/） | N/A | 重编译 0.x~几秒 |

窗口弹出来了就别关，后台挂着改前端代码统统秒更。

---

## 目录结构（防迷路）

```
e:\linkdesk\                   ← git 仓库根目录
└── linkdesk\                  ← 工程目录（npm/cargo 都在这）
    ├── src/                   ← React 前端
    ├── src-tauri/             ← Rust 后端
    ├── package.json
    ├── vite.config.ts
    └── docs/                  ← 文档
```

所有命令都在 `linkdesk/` 目录下执行。
