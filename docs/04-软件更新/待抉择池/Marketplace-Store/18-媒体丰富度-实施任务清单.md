## 一、目标远景（一句话）

**让作者只改 `marketplace.json`（图/视频/价格）和目录的 `collections[]`（谁上哪个槽），就能让首屏、主题页、大卡、小卡长出丰富媒体——不发版、不拖拽、不改代码。**

## 三、从修 bug 的 AI 那里学到的归一化红线（直接套用）

> 近期已修过的光晕、磨砂、下拉菜单，都是「同一个东西写了两套」。本轮在动工前先堵死：

| 东西 | 唯一出处 | ⛔ 禁止 |
|---|---|---|
| hover 光晕 | `--surface-glow` / `--glow`（既有） | 新 `box-shadow` 字面量、逐卡定制辉光 |

| 卡片面 | 既有 `.marketplace-store-card` 面 | 逐卡背景/边框/圆角 |

## 五·补 逻辑设计与回归防线（自审新增）

### 1. 状态 × 媒体矩阵（媒体不参与状态判定）

| 插件状态 | 媒体 | hover 主按钮 | 角标 |
|---|---|---|---|
| 未装 · 免费 | 图 / 视频 | 安装 | 免费 |
| 已装 · 最新 | 图 / 视频 | 已安装（禁用） | 已安装 |
| 已装 · 有更新 | 图 / 视频 | 更新 | 有更新 |
| 已停用 | 图 / 视频 | 启用 | 已停用 |
| 安装中 | 图 / 视频 | 进度（禁用） | 安装中 |
| 安装失败 | 图 / 视频 | 重试 | 安装失败 |
| 离线 | 图 / 视频 | 安装（禁用） | 离线/缓存 |
| 付费 · 未购 | 图 / 视频 | 获取许可 ＋ 我有密钥 | 买断/订阅 |
| 付费 · 临期/过期 | 图 / 视频 | 续费 / 输入新密钥 | 剩 N 天 / 许可过期 |

> 规则：**媒体只决定「画什么」，状态只决定「按钮/角标是什么」**。两者在卡上并列，互不推导；⛔ 用状态去换图、⛔ 用图去猜状态。

### 2. 新卡制造清单（split / wall 都按这个来）

- **必须复用**：`Art`（唯一媒体）、`actionOfCard` / `ActionButton`、`statusOfCard` / `CornerTag`、`menuOfCard` / `MoreMenu`、`cardKeyDown`、`cardPropsEqual`、`entryHue`、`tCategory`、`--surface-*` 面。
- **只允许新写**：版式结构、布局 CSS、变体类名（`is-split` / `is-wall`）、注册点（`CategoryView` / `OrderedCards` / `CollectionSection` / `AuthorStoreView`）。
- **⛔ 禁止**：自己读 `screenshots`/`cover`、自己拼购买/安装按钮、自己定义角标颜色、自己写轮播、自己造 blur/glow。
- **注册点必须齐**：分类页、搜索页、首页合集、作者店、详情跳转——同一个新卡在五处可用，⛔ 只在一处能看。

### 3. 历史 bug → 本次防线

| 历史 bug 类 | 最容易复发的路径 | 本次防线 |
|---|---|---|
| 辉光两套 | 新卡/新 hover 层自写 `box-shadow` | 只允许 `--surface-glow` / `--glow`；G2 |
| 磨砂/模糊两套 | mega hover 条新写 `backdrop-filter` | 只允许 `--surface-blur`；G2 |
| 下拉/筛选两套 | 为媒体另造下拉 | 复用既有 Select / Menu；G1 |
| hover 改几何 | 轮播/快捷层用 `height/margin/display` | 只许 `transform/opacity/遮罩`；F5/F8 |
| 300px「一字一行」 | 新卡在窄容器不降档 | `@container` 降档 + `clamp`；A7/F5 |
| 状态位不一致 | 新卡自算价格/已装 | `statusOfCard` 单一来源；G9 |
| 动作点击冒泡 | 点安装却跳详情 | 事件阻断测试；A8/F8 |
| 滚动位丢失 | hover 触发整页重渲染 | hover 不 setState；F8 |
| 菜单层级事故 | 新 hover 层压过 modal/menu | 复用 z-index/portal；A8 |
| 卡片面不一致 | 新卡自定背景/圆角/边框 | 复用 `.marketplace-store-card` 面；G2 |
| 图片白块/布局跳 | 图 404、加载中 | 生成式兜底 + 骨架；B1/B2/F8 |
| 视频自动播/抢焦点 | 卡内出现 `<video>` | 仅 hero/详情、controls、⛔ autoplay；B3/A8 |
| 旧目录崩溃 | 缺字段/坏视频 | 解析容错 + fixtures；A6 |
| 外链被 CSP 拦 | 图片/mp4 加载失败 | A4 前置审计 |

### 4. 残余风险（必须承认）

- **壳 CSP** 若拦 `media-src`，需一处最小壳改动（A4），这是唯一预定的壳侧改动。
- **真实数据差异**：作者图比例/长标题/无图，会让画面与稿不同（见 17 §十二）。
- **第三方源不补图**：靠生成式封面兜底，不阻断。
- **发布顺序**：插件代码改动需版本号/CHANGELOG；纯目录内容改动不发版（F9）。


- **不跨批次抢跑**：A 没绿不动 B；B 没绿不动 C。
