**②** [`useMemoryMonitor.ts:48`](../../../src/hooks/useMemoryMonitor.ts)：`` message: `内存使用率偏高（${usedMB}MB / ${limitMB}MB），建议关闭不活跃的插件` ``——**裸模板字符串，未经 t()**；对照 [`bridges.ts:240`](../../../src/App/bridges.ts)：`i18n.t("内存压力：界面进程内存占用过高（{{mb}} MB）", { mb })` 同类告警已走翻译链。⚠️ 两处 MB 换算输入单位不同（bridges 的 `totalRSS` 来自主进程 KB 口径采样 `/1024`；useMemoryMonitor 是 bytes `/1024/1024`）⇒ 共享口只收「**取整成形**」（统一 `Math.round`），换算除数各自保留——⛔ 别把单位换算硬并成一份。
