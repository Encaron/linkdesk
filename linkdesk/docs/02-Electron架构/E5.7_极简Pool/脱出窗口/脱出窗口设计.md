# 脱出窗口设计

> 用户拖标签页脱离主窗口 → 独立 BrowserWindow + 同一个 pool.html + pushLayout = 仅渲染脱出的 tab。
> 极简Pool 下脱出窗口 = 1 个新 BrowserWindow + 1 个 WCV——比 E5.6 更简单。

---

## 1. 脱出窗口的定义

| 特性 | 说明 |
|:--|:--|
| 触发 | 用户拖拽标签页超出主窗口边界 |
| 窗口 | 独立 BrowserWindow（无边框，跟随鼠标） |
| 内容 | 同一个 pool.html，pushLayout 只包含脱出的 tab |
| 生命周期 | 临时——关闭 = 销毁 BrowserWindow + WCV，tab 回归主窗口 |
| 代码 | 同一个 PoolZoneShell + MainRenderer——同代码、不同 layout |

---

## 2. 架构

```
主窗口                             脱出窗口
┌──────────────────┐             ┌──────────────────┐
│ BrowserWindow    │             │ BrowserWindow    │
│ ┌──────────────┐ │             │ ┌──────────────┐ │
│ │ WCV 100%     │ │             │ │ WCV 100%     │ │
│ │              │ │             │ │              │ │
│ │ PoolZoneShell│ │             │ │ PoolZoneShell│ │
│ │  所有 Zone   │ │             │ │ 只渲染:      │ │
│ │  含剩余 tabs │ │             │ │  - EditorZone│ │
│ │              │ │             │ │  (含 TabBar) │ │
│ └──────────────┘ │             │ │  (1 个 tab)  │ │
└──────────────────┘             │ └──────────────┘ │
                                 └──────────────────┘

同一个文件:
  pool.html → pool-main.tsx → PoolZoneShell
  preload-pool.ts（同一个——window.linkdesk.* 一致）

区别:
  pushLayout 的内容不同
  主窗口 layout: 所有 groups
  脱出窗口 layout: 只有 { groups: [detachedGroup] }
```

## 3. 主进程 API

### 3.1 创建脱出窗口

```typescript
// electron/detached-window.ts

interface DetachedWindow {
  browserWindow: BrowserWindow;
  wcv: WebContentsView;
  tabId: string;
}

function createDetachedWindow(tab: PoolTab, position: { x: number; y: number }): DetachedWindow {
  // 1. 创建 BrowserWindow（无边框，跟随鼠标位置）
  const win = new BrowserWindow({
    x: position.x - 50,  // 居中于鼠标
    y: position.y - 15,
    width: 800,
    height: 600,
    frame: true,
    title: tab.title,
    show: false,           // 等 ready 后显示
    webPreferences: {
      preload: path.join(__dirname, 'preload-pool.js'),  // ← 同一个 preload
      nodeIntegration: false,
      contextIsolation: true,
      sandbox: true,
    },
  });

  // 2. 创建 WCV（100%×100%）
  const wcv = new WebContentsView({
    webPreferences: {
      preload: path.join(__dirname, 'preload-pool.js'),
      nodeIntegration: false,
      contextIsolation: true,
      sandbox: true,
    },
  });
  win.contentView.addChildView(wcv);
  wcv.setBounds({ x: 0, y: 0, width: 800, height: 600 });

  // 3. 加载同一个 pool.html
  wcv.webContents.loadURL(
    process.env.NODE_ENV === 'development'
      ? 'http://localhost:1420/pool.html'
      : `file://${path.join(__dirname, '../renderer/pool.html')}`
  );

  // 4. 等待 pool:ready → pushLayout（只包含脱出的 tab）
  ipcMain.once('pool:ready', (event) => {
    if (event.sender === wcv.webContents) {
      const layout: PoolLayout = {
        version: 2,
        titleBar: { title: tab.title, menuBarVisible: false },
        iconBar: { icons: [] },           // 无图标栏
        sidebar: { visible: false, width: 0, viewId: null },
        tabBar: {
          groups: [{
            groupId: 'detached-1',
            tabs: [tab],
            activeTabId: tab.id,
          }],
        },
        groups: [{
          id: 'detached-1',
          flex: 1,
          activeTabId: tab.id,
          tabs: [tab],
        }],
        statusBar: { items: [] },         // 无状态栏（可选——简化版）
      };

      wcv.webContents.send('pool:layout', layout);
      win.show();
    }
  });

  // 5. 窗口大小变化 → WCV setBounds
  win.on('resize', () => {
    const [w, h] = win.getContentSize();
    wcv.setBounds({ x: 0, y: 0, width: w, height: h });
  });

  return { browserWindow: win, wcv, tabId: tab.id };
}
```

### 3.2 关闭脱出窗口 → tab 回归

```typescript
function closeDetachedWindow(detached: DetachedWindow): void {
  const { tabId, browserWindow, wcv } = detached;

  // 1. 从主窗口 tabState 中找回 tab
  const tab = findTabById(tabId);
  if (!tab) {
    browserWindow.close();
    return;
  }

  // 2. 从脱出窗口移回主窗口——tabState 操作
  tabState.detachFromWindow(tabId);       // 从脱出窗口的数据中移除
  tabState.addTabToMainWindow(tab);       // 加回主窗口

  // 3. 主窗口 pushLayout（包含回归的 tab）
  const mainWcv = windowManager.getMainPoolView();
  mainWcv.webContents.send('pool:layout', buildLayout(tabState));

  // 4. 销毁脱出窗口
  browserWindow.removeChildView(wcv);
  wcv.webContents.close();
  browserWindow.close();
}

// 监听脱出窗口关闭事件
detached.browserWindow.on('closed', () => {
  closeDetachedWindow(detached);
});
```

## 4. 拖拽检测——useDragDetach

```typescript
// src/pool/hooks/useDragDetach.ts

function useDragDetach(
  tabId: string,
  dragRef: RefObject<HTMLDivElement>
) {
  const onMouseMove = useCallback((e: MouseEvent) => {
    const w = window.innerWidth;
    const h = window.innerHeight;

    // 检测鼠标是否超出窗口边界
    const threshold = 30;  // px
    const outOfBounds =
      e.clientX < -threshold ||
      e.clientX > w + threshold ||
      e.clientY < -threshold ||
      e.clientY > h + threshold;

    if (outOfBounds) {
      // 触发脱出
      window.linkdesk.window.detachTab(tabId, {
        x: e.screenX,
        y: e.screenY,
      });
      cleanup();
    }
  }, [tabId]);

  // mousedown → 开始监听 → mouseup → 停止
  // ...
}
```

## 5. 脱出窗口 vs 新窗口

| 场景 | 触发 | 实现 |
|:--|:--|:--|
| 脱出窗口 | 拖标签页出主窗口 | `detachTab()` — 同一 tab 移动 |
| 新窗口 | 插件调用 API / 命令 | `window.linkdesk.window.open(layout)` — 创建新 tab |

**两种场景共享同一个 `createDetachedWindow` 逻辑。** 区别是 pushLayout 的内容——脱出的是现有 tab，新窗口是新 tab。

---

## 6. 极简 vs E5.6 的脱出窗口

| 维度 | E5.6 | E5.7 |
|:--|:--|:--|
| BrowserWindow | 1 | 1 |
| WCV 数 | 2 (SidebarPool + MainPool) | 1 (MainPool only) |
| pool.html | `?zone=sidebar` + `?zone=main` | 无 zone 参数 |
| SidebarPool 内容 | 侧栏（对脱出窗口无意义） | 不存在 |
| pushLayout | sidebar + groups（分开） | 完整 layout（全字段） |
| 关闭 | 销毁 2 个 WCV + BrowserWindow | 销毁 1 个 WCV + BrowserWindow |

## 7. 漂移面板

底部面板独立窗口化——和脱出窗口同机制：

```
PanelZone 的 "⤢" 按钮
  → window.linkdesk.window.detachPanel()
    → createDetachedWindow({ panel: panelLayout })
      → PoolZoneShell 收到 layout: { panel: {...}, groups: [], ... }
        → PoolZoneShell 只渲染 PanelZone（主区为空占位）
```

关闭漂移窗口 → panel 数据回归主窗口 layout → pushLayout。
