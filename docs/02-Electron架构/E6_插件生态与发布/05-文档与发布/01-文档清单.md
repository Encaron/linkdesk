## 一、插件开发指南

文件：`docs/03-插件制造/11-插件开发指南.md`

### 1.1 大纲

```
# LinkDesk 插件开发指南

一、快速开始（10 分钟上手）
  - npm create linkdesk-plugin my-plugin
  - cd my-plugin && npm install && npm run dev
  - 浏览器看到你的插件

二、项目结构
  - plugin.json      ← 插件身份证
  - src/index.tsx    ← 入口组件
  - i18n/en.json     ← 翻译文件

三、plugin.json 字段详解
  3.1 基本信息：name / version / entry
  3.2 图标：iconSource / icon
  3.3 出现位置：appearsIn
  3.4 贡献点：contributes.viewsContainers / views / commands / menus / keybindings / configuration / i18n

四、视图插件
  - isActive 约定
  - 侧栏 vs 标签页

五、命令系统
  - contributes.commands 声明
  - window.linkdesk.commands.executeCommand

六、菜单
  - contributes.menus 声明
  - window.linkdesk.menu.registerItems
  - 可用的菜单 ID：EditorContext / FileTreeContext / ...

七、快捷键
  - contributes.keybindings 声明
  - when 条件

八、配置
  - contributes.configuration 声明
  - window.linkdesk.configuration.get/set/onChange

九、标签页
  - window.linkdesk.tabs.create/openOrFocus/close

十、i18n
  - contributes.i18n 声明
  - i18n/en.json 格式
  - 渲染时自动 t()

十一、发布
  - npm run build → .linkdesk-plugin
  - 上传到 LinkDesk 插件市场
```

### 1.2 风格

- 每个章节有可运行的代码示例
- 所有示例基于 hello-world 插件
- 新 AI / 新开发者 30 分钟能做出第一个插件

## 二、API 参考

文件：`@linkdesk/plugin-sdk` README

### 2.1 格式

每个命名空间一张表：

```
### linkdesk.tabs

| 方法 | 参数 | 返回值 | 说明 |
|:--|:--|:--|:--|
| create | { pluginId, label?, ... } | Promise<void> | 新建标签页 |
| openOrFocus | { pluginId } | Promise<void> | 打开或聚焦已有 |
| focus | tabId | Promise<void> | 聚焦指定标签 |
| close | tabId | Promise<void> | 关闭指定标签 |
```

覆盖所有公开命名空间。

### 2.2 自动生成

理想情况：从 `packages/plugin-sdk/src/types.ts` 的 JSDoc 自动生成。手动维护也行——API surface 不大（~15 命名空间，~50 方法）。
