## 命名规范（归一化落点）

| 对象 | 规则 | 例 |
|:--|:--|:--|
| CSS 类名 | 全部 `pdf-` 前缀；状态类复合（`.pdf-toolbar.active`）；**禁无锚选择器**；禁借 `ldk-*`；自定义属性挂自有命名空间类下定义 | `.pdf-page-canvas` |
| 命令 id | `pdfReader.` 前缀 | `pdfReader.pageNext` |
| 页码 | 全仓 1-based，只在边界处换算 | — |
| 缩放 | 一律倍率数字（1.0 = 100%），适宽/适页是模式不是特殊倍率 | — |
| 文件拆法 | feature-folder（聚合器＋子模块），禁平铺大卸八块 | `services/pdfDoc/` |
| 同概念同名 | `filePath` 进出一致；引擎封装对视图只暴露一个聚合器 | — |

## 底色不跟主题（用户拍板的落法）

- 阅读区配色族（纸白/暖黄/夜间——档位 T3 拍板）定义为 `pdf-reader` 根类下的自有自定义属性组（如 `--pdf-bg-page`），值是插件自有固定色——**不消费任何壳主题 token**。
- 验收句：切壳主题（含玻璃系）→ 阅读区像素级不动；周边工具栏若用共享件则随主题（允许）。
- ⚠️ 这是有意例外不是漏洞：色值只许出现在这一处定义，其余全引用变量（无硬编码判据的口径）。

## 仓内门禁（每棒必跑，一样不能少）

| 门 | 命令 | 判什么 |
|:--|:--|:--|
| test | `npm run test` | vitest 全绿（单测＋组件测试） |
| verify | `npm run verify` | ci-verify 九段（schema/声明自洽/i18n 字典覆盖/命名空间/…） |
| build | `npm run build` | 出 `pdf-reader.linkdesk-plugin`，包体读数记录 |

提交纪律照壳仓同款收窄版：一棒一 commit、类别前缀、版本号与 CHANGELOG 同笔；`git add` 只加本任务文件（ai-workflow-canon §11）。

## AI 友好化自查（T4/T7 用）

- 每个用户动作有非鼠标路径（命令面板可跑全部功能）；
- 命令 meta 带 `description`＋`params`（AI 读得到就不用猜参数）；
- 结构化读数可查（当前页/总页/缩放/侧栏态）；
- 自查壳侧 `npm run audit:plugin-commands`（只报不拦）对本仓零红灯。
