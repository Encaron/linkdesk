# 宋体印刷体

全界面宋体的纸白墨黑主题——**极限壳主题**，压的是 `font` 域。

## 这是什么

一只**纯数据插件**，演示的是主题系统的**字体轴**：整个界面的字族换成宋体（SimSun），配上纸白底与墨黑字，读起来像一份印出来的文稿而不是一块屏幕。

- 插件 ID：`theme-songti`
- 系统类型：亮色（light）
- 色板：纸白墨黑
- 压的是：`font` 域（字族轴——全 UI 宋体）

> 它存在的意义：**证明主题能改字体，不只是颜色和形状。**

## 结构

```
plugin.json                       声明（contributes.themes）
themes/songti-print.json          色板（含字族设定）
```
