## 二、build 命令

### 2.1 实现

```bash
linkdesk-plugin-sdk build
```

实际步骤：

```
1. validatePluginJson("./plugin.json")
   → 失败 → 打印错误，停止

2. defineLinkdeskPluginConfig() → Vite build
   → 产出 dist/<pluginId>.linkdesk-plugin/
     ├── plugin.json
     ├── icon.svg (如果有)
     ├── i18n/*.json (如果有)
     └── index.bundle.js

3. zip dist/<pluginId>.linkdesk-plugin/ → ./<pluginId>.linkdesk-plugin

4. 输出：
   ✔ Build complete!
     File: ./my-cool-plugin.linkdesk-plugin
     Size: 245 KB
     Ready to publish!
```

### 2.2 Vite 配置要点

```typescript
// vite-config.ts 中
{
  build: {
    lib: {
      entry: pluginEntry,
      formats: ["es"],
      fileName: "index.bundle",
    },
    rollupOptions: {
      external: ["react", "react-dom", "react-i18next", "i18next"],
      output: {
        // 确保 CSS 也打进 bundle（如果有）
      },
    },
  },
}
```

## 三、发布入口——CLI 主路 + 市场 UI 备路（2026-08-30 定案）

> **2026-08-30 拍板：主路 = 命令行 `npm run publish`**（作者终端一键发布，不打开 LinkDesk）；市场 UI「发布插件」按钮 = 可选备路。两条入口走**同一套**自动发布链路（§3.2 + E6#26b/#26c）。总览 → [00-第三方作者旅程.md](../05-文档与发布/00-第三方作者旅程.md) §五。

### 3.1 入口形态

- **主路（命令行）**：`npm run publish`（= `linkdesk-plugin-sdk publish`）——创建 Release + 上传 asset + 更新自己仓库 marketplace.json，全在 git bash 完成。
- **备路（图形，软件内）**：marketplace 插件 UI：
  - 顶部工具栏 "发布插件" 按钮（仅在开发模式或登录后可见）
  - 或者：设置页面 → "发布新插件"

### 3.2 流程

```
1. 作者点击"发布插件"
2. 文件选择对话框（Electron dialog.open）
   → 选 .linkdesk-plugin 文件
3. 壳读文件：
   - 解压临时目录 → 读 plugin.json → 显示预览
   - "确认发布 my-plugin v1.0.0？"
4. 确认 → 上传到 GitHub Releases：
   POST https://api.github.com/repos/{owner}/{repo}/releases
   或 → GitHub REST API 创建 Release + 上传 asset
5. 更新 marketplace.json：
   - clone/拉取仓库 → 加条目 → commit → push
   或 → GitHub API 直接更新文件
6. 返回结果："发布成功！几分钟后可在市场中看到。"
```

### 3.3 ~~简化方案（v1.0）~~ → 已删（2026-08-30 第 2.2 轮审视）

> 🔴 **2026-08-30 第 2.2 轮审视拍板：手动网页上传方案是"当前够用、未来再自动化"的 deferral 话术——否决。** 发布 = GitHub REST API 自动链路**当下做全**：作者在市场 UI 填 GitHub PAT（存配置，`app.*` 配置项，走 audit-config-baseline 保底）→ 点"发布" → 创建 Release + 上传 asset + 更新自己仓库的 marketplace.json，全自动。

```
1. npm run build → 产出 .linkdesk-plugin
2. 打开 LinkDesk → 插件市场 → "发布插件" → 选 .linkdesk-plugin
3. 预览确认（作者/版本/图标）→ 填 GitHub PAT（存配置）
4. 确认发布 → GitHub REST API：
   POST repos/{owner}/{repo}/releases 创建 Release
   POST 上传 asset（.linkdesk-plugin）
   更新根目录 marketplace.json（加条目，commit）
5. "发布成功！几分钟后可在市场中看到。"
```

## 四、审视实锤（2026-08-30 第 2.2 轮——#26 自动发布拍板依据）

> 2026-08-30 第 2.2 轮整轮审视落笔。清单只留修正结论 + 本锚点。

### 4.1 手动网页上传方案删除（deferral 话术）

原 §3.3「不用 GitHub API——网页手动上传 + 手改 marketplace.json，v1.0 接受手动，后续迭代再自动化」——**「当前功能够了，等未来再加」话术，第 2.2 轮拍板否决（用户 2026-08-30 纠正）**。已删，改自动链路全自动。

### 4.2 自动发布链路（#26b/#26c 定型）

```
作者市场 UI 填 GitHub PAT → 存 app.* 配置（audit-config-baseline 保底）
→ 点「发布插件」→ 选 .linkdesk-plugin
→ 预览确认（解压读 plugin.json → 作者/版本/图标）
→ GitHub REST API：
   POST repos/{owner}/{repo}/releases 创建 Release
   POST 上传 asset（.linkdesk-plugin）
   更新根目录 marketplace.json（加条目）
→ "发布成功！几分钟后可在市场中看到。"
```

**依赖：** 发布到作者自己的仓库（多市场源 §六，2026-08-17 用户拍板）——marketplace.json 在作者仓库根目录，别人添加该仓库为市场源即可发现。
