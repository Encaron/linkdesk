## 八、跨线交付：设置插件补丁（线 2 落地用）

文件：`E:/linkdesk-plugins/official/settings/src/views/SettingsView/renderControl.tsx`

```tsx
// 顶部 import（共享件来自 @linkdesk/ui）
import { AiPolicyPicker } from "@linkdesk/ui";

// switch (prop.uiHint) 内，与 "segmented" 同层：
case "aiPolicy": {
  // 数据来自壳命令 aiPolicy.getState（只读）；⛔ 插件不判风险、不写档位字面量
  const state = await executeCommand("aiPolicy.getState") as AiPolicyViewState | null;
  if (!state) return <ReadonlyControl prop={prop} value={value} />; // 老壳/读不到 ⇒ 只读降级
  return (
    <AiPolicyPicker
      value={state.mode}
      options={state.options}            // [{ value, label, summary }] 全部已 t()
      description={state.options.find(o => o.value === state.mode)?.description}
      note={state.mode === "full" ? t("AI 现在可以执行所有操作，不会再询问。这个设置会一直有效，直到你在这里改回来。每一步都有记录，随时可以查看。") : undefined}
      onReset={() => executeCommand("aiPolicy.setMode", undefined, "auto")}
      resetLabel={t("改成自主")}
      ariaLabel={t("AI 权限档位")}
      onChange={(mode) => executeCommand("aiPolicy.setMode", undefined, mode)}
    />
  );
}
```

要点：
1. `aiPolicy.setMode` 是 **userOnly** 命令——插件界面调它属于「用户点击」，允许；AI 经 `exec` 调会拿 `EPROTECTED`。
2. 设置插件**不渲染整张卡片**（矩阵/风险表入口仍是既有 readonly/action 行，声明已在壳侧）：⛔ 不要 `if (mode === "auto")`。
3. `ai.policy.mode` 的值由命令写；`onChange` 只上报 → 命令 → 壳侧 `setConfigurationValue`（单一写点）。
4. 老壳无 `uiHint:"aiPolicy"` 支持 ⇒ 未知 hint 只读降级（既有契约），不崩。

## 十三、逻辑说明（状态机 / 策略 / 边界）

- **判定**：`decide(mode, risk)` 纯函数；`read` 只放 R0；`ask` 全问；`auto` 仅 R3 问；`full` 全放。非法档位按 `ask`（fail-closed）。
- **执行闸顺序**（⛔ 顺序是判据）：`userOnly → EPROTECTED` → `decide` → `deny` 抛 `EPOLICYDENIED` / `ask` 弹唯一确认框 / `allow` 直通 → 执行。
- **档位读数**：每次现读 `userData/settings.json`；键缺失 = `auto`；文件缺失 = `auto`；损坏/非法值 = `ask` + `degraded:true`。
- **提权**：`requestElevation` → 用户允许（full 需两次确认）→ 壳命令 `aiPolicy.setMode` 写配置 → 广播 → 徽标/设置刷新；拒绝 = `{granted:false}`；超时 = `ESHELLTIMEOUT`（未发生）。
- **不变式**：没点头 = 不做；AI 无「批准」通道；`ai.*` 配置对 AI 写仍拒（L1，既有）。
