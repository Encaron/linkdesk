## 五、给 T2 的环境坑

1. **npmmirror 滞后**：本机默认源是 `registry.npmmirror.com`，当天新发的包（如 ui 0.2.56）`npm install` 报 notarget；解法 `npm install <pkg>@<ver> --registry=https://registry.npmjs.org`。且**安装中途失败会把 lockfile 写坏**（空 version 条目 ⇒ arborist `Invalid Version:` 崩）——`rm -rf node_modules package-lock.json` 重装
2. **沙箱/宿主坑**：ZCode 宿主 shell 起安装版要 `env -u ELECTRON_RUN_AS_NODE` ＋ 非沙箱；`--user-data-dir=<路径>` 必须等号形；用户实例占默认 profile 单实例锁，隔离验证用独立 userData
3. **driver 只认 dev 轨道**（按 URL 末段 `pool.html` 挑 target）；对安装版用一次性 CDP eval（Node 24 自带 WebSocket）或 linkdeskctl
