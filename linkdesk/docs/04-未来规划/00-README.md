# 04 — 未来规划

> 2026-07-24。**E1→E2→E3 架构完工后，LinkDesk 的未来。** 分两路。

---

## 两路

| 路 | 目录 | 发布方式 | 判断标准 |
|:--:|------|------|------|
| **壳版本** | [`壳版本/`](壳版本/00-README.md) | 软件更新——所有人自动获得 | 打开 LinkDesk 的人是不是大概率需要？ |
| **官方插件** | [`官方插件/`](官方插件/00-README.md) | Marketplace 可选安装——用户按需 | 特定人群用的 → 不占版本号 |

---
