## 1. 协议概览

PoolLayout 是壳→池的**单向 JSON 快照**。壳不调用池的 React 方法——壳推 layout，池被动渲染。

```
壳 (Shell WebView)
  │
  │  tab/split/sidebar 状态变化
  │
  ├→ syncLayoutToPools()
  │     │
  │     ├→ pushLayout('sidebar', { sidebar: {...} })  ──→ SidebarPool
  │     └→ pushLayout('main',    { groups: [...] })    ──→ MainPool
  │
  │  ～～ IPC 通道 ～～
  │
  ├→ SidebarPool → onLayout → setLayout → SidebarRenderer 重渲染
  └→ MainPool    → onLayout → setLayout → MainRenderer 重渲染
```

## 2. 类型定义

```typescript
// src/core/types/poolLayout.ts

/** 侧栏布局——仅 SidebarPool 接收 */
export interface SidebarLayout {
  visible: boolean;
  width: number;
  viewId: string | null;  // 当前打开的侧栏视图 pluginId
}

/** PoolLayout——壳推给池的完整布局快照 */
export interface PoolLayout {
  sidebar?: SidebarLayout;
  groups: PoolGroup[];
}

export interface PoolGroup {
  id: string;             // 分屏组 ID（对应壳 tabState.groups[].id）
  flex: number;           // 分屏比例（1 = 等分，2 = 两倍宽度）
  activeTabId: string;
  tabs: PoolTab[];
}

export interface PoolTab {
  id: string;             // tabId——全局唯一
  pluginId: string;       // 插件标识
  title: string;          // 标签页标题
  sourceId?: string;      // 载荷——文件路径 / 端口名 / …
  dirty?: boolean;        // 未保存标记
}
```

## 3. IPC 通道

| 方向 | 通道 | 负载 | 说明 |
|:--|:--|:--|:--|
| 壳→主进程→池 | `pool:layout` | `{ sidebar?, groups }` | 壳 pushLayout |
| 池→主进程→壳 | `pool:ready` | `{ zone }` | 池就绪信号 |
| 壳→主进程→池 | `pool:ping` | `{ zone }` | 心跳 ping |
| 池→主进程→壳 | `pool:pong` | `{ zone }` | 心跳 pong |
| 壳→主进程→池 | `pool:push-layout` | `{ zone, layout }` | 壳侧 IPC 中转 |

## 4. 缓冲回放时序

```
t0: Pool WebContentsView 创建
t1: pool.html 加载, preload-plugin.js 执行
    └→ ipcRenderer.on('pool:layout', handler) 注册（模块顶层）  ← 就位
t2: pool-main.tsx React mount
t3: useEffect → window.linkdesk.pool.onLayout(cb)  ← 回调注册
    └→ _onLayoutActive = true
    └→ 回放 _layoutBuffer → cb(layout1), cb(layout2), ...
t4: 壳收到 pool:ready → pushLayout → 池 onLayout 实时接收

竞态窗口: t1-t3（preload就位 ～ React mount）
  防御: _layoutBuffer 缓冲 t1-t3 之间到达的 layout
```

## 5. 未来扩展字段

```typescript
// E6+ 可能的扩展
export interface PoolLayout {
  sidebar?: SidebarLayout;
  rightSidebar?: SidebarLayout;     // 右侧栏

  groups: PoolGroup[];
```

**协议向前兼容：** 池忽略不认识的字段。壳加新字段不破坏旧池。
