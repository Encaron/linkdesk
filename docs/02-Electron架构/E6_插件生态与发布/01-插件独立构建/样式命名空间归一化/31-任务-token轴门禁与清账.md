## 一、🔴 定案：自定义属性定义的作用域规则（**本轮要落地的规则原文**）

> **一句话**：**作用域才是命名空间**。自定义属性名不需要前缀 —— 它**住在哪棵子树里**才是它属于谁。

**(a) 文档级**（`:root` / `html` / `body` / `[data-theme=…]` / 通配 `*`）：
　**只有宿主契约块**可以写 —— **契约块 = 文件级登记**，今天 = `src/index.css` 的 `:root` 与 `[data-theme="light"]` 两块。
　🔴 契约块里放什么名字**不设名单**（引擎写配方键、主题作者加新键都合法 —— [29 号档](29-主题系统保护条款.md) §四.1）。

**(b) 其它一切定义**必须挂在**自有命名空间的子树**之下：
　宿主 = `.ldk-*`（含伪元素限定，如实测的 `.ldk-titlebar::before, …`）· 插件 = `<pluginId>-*` · 共享组件 = `ldk-*`（与宿主**共用宿主命名空间** —— 判据⑥ 已把这两域合成同一个 `ldk-` 空间）。
　⇒ 判定式只看一件事：**这条规则的任一 compound 里有没有出现自有命名空间的类**（宿主/共享：`.ldk-*`；插件：`.<pluginId>-*`）。

**(c) portal 面例外**（[29 号档](29-主题系统保护条款.md) §四.1 ③ 硬要求，为「以后各类下拉/弹层」留的口子）：
　作用域主体可以是**宿主浮层宿主根元素** —— 结构性、宿主所有、由源码唯一确定：`src/pool/zones/floating-layer/FloatingLayerHost.tsx` 渲染的 `#ld-float-layer` ＋ 其下 `#context-menu-root` / `#quick-pick-root` / `#dialog-root` / `#floating-panel-root`。
　⚠️ 这一条**放宽的是「元素归谁」，不放宽「名字归谁」**：宿主照样用 `ldk-*`／契约名，插件照样不得定义 `ldk-*`。

**⇒ 名字层只有一句话**：**不得定义 `ldk-` 开头的自定义属性**（`ldk-` 整个命名空间属宿主 —— 与类名／关键帧**同一句**，CLAUDE.md 硬约束 23 ②）。

**🔴 零名单 · 零白名单 · 零基线表声明**：上面每一条都只依赖 **① 选择器的作用域形态 ② 定义方自己的标识**（宿主／共享／插件，以及插件的 `pluginId`）。**不需要宿主契约名单，也不需要任何名字级清单** —— 唯一「登记」是**文件级**的（哪两个块是契约块）。⇒ 满足 [22 号档 §七](22-收口总方案-跨方样式污染九件套.md) 的系列禁区。

**🔴 两条防误伤（照 [29 号档 §二/§四.1](29-主题系统保护条款.md) 原文，缺一条就会冻死主题系统）**：

1. **JS 侧写入不在本判据管辖内**：`ThemeEngine` 的 `documentElement.style.setProperty`（`ThemeEngine/tokens.ts:142` · `accent.ts:28` · `electron/preload-pool/events.ts:136,167` · `surface-zones.ts:114,120`）**永远合法**；本判据**只管 CSS 源码里的定义**。**任何轮次不许把这条写入链「作用域化」**（那是 P1 禁区）。
2. **`[data-theme="light"]` 不是污染** —— 它是亮色契约块，**不许改成类限定**；`#ld-float-layer` 的 token 定义**不许搬走**（P2 的浮层唯一权威与磨砂地板）。

### 2.3 🔴 本格最值钱的一条：**引擎并没「屏蔽」宿主契约 —— 94 个名字里 79 个是「只有样式表提供」的**

[25 号档 §1.1](25-任务-token轴实测与定案.md) 的隐含假设是「引擎把契约值 inline 写在 `documentElement` 上 ⇒ 插件的文档级定义无效」。**实测把它推翻了一半**：

| 读数 | 值 | 出处 |
|:--|:--:|:--|
| `documentElement.style` 上的 inline token（**引擎真实写入集**） | **15** | 实机直读（池 ＋ 壳两文档一致）：`--accent` `--accent-hover` `--accent-light` · `--font-size-*` ×9 · `--ui-scale` · `--glass-surface-alpha` · `--surface-inset` |
| 其中落在宿主 `:root` 契约里的 | **11** | 其余 4 个（`glass-surface-alpha` / `surface-inset` / `ui-scale` / `accent-light`）是派生键 |
| ⇒ **契约里「引擎不写、只有样式表 `:root` 提供」的名字** | **83** | 94 − 11 |
| 为什么这么少 | **默认主题是 `dark-fallback`（`app.themeColor = "dark-fallback"`）—— 壳的「空兜底配方」（`colors: {}`）⇒ `commitTokens({})` 的**差集清理**把上次写过的主题键全 `removeProperty` 掉 ⇒ 值回落 `index.css` 的 `:root` 硬兜底**（这行为**写在 `src/index.css:2-4` 的注释里，是设计**） |

**🔬 决定性实验（在真跑的池文档里注入一条临时 `:root` 规则，读前后 computed 值，随即移除）**：

| 名字 | 引擎 inline？ | 注入 `:root{--x:rgb(1,2,3)}` 后 | 谁赢 |
|:--|:--:|:--|:--|
| `--accent` / `--surface-inset` | ✅ | **不变**（`#0078d4` / `0px`） | 引擎 inline 赢 ⇒ 文档级定义是**死代码** |
| `--success` · `--error` · `--z-dropdown` · `--badge-text` · `--text-on-accent` · `--radius-md` · `--bg-window` | ❌ | **全变 `rgb(1,2,3)`** | 🔴 **文档级定义赢 ⇒ 真害成立** |

⇒ **结论**：**「插件在 `:root` 写一个宿主契约名」今天真的能全局改写宿主**（`--success` 是被改过的那个语义色的近亲；`--z-*` 被改＝整壳层叠乱、`--badge-text` 被改＝`.badge` 案原形重现）。
　**而且这个屏蔽是「不稳定」的**：inline 集**随主题变化**（差集清理 ＋ 空兜底配方）⇒ 同一只插件在 `dark-fallback` 下污染、切到真主题后**又静默不污染** —— 最坏的一类 bug（**看着时好时坏**）。
　⇒ 这正是 **V1 判红「有真害」**的硬依据，也是 [25 号档 §1.3](25-任务-token轴实测与定案.md) 那两行「抓不抓得住真案」在**机制层**的坐实。

## 三、判据（判定式 ＋ 分级 ＋ 负控）——**本轮要落地的三条判据**

> **口径与 [24 号档](24-任务-运行时全表断言探针.md) 的件 5 探针同源**（**同一条纪律**）：定义点、作用域形态、多选择器规则的切分，**必须调 `scripts/lib/css-selectors.mjs` 的同一份实现**（本轮为它补 token 助手，见 §四.1），**不许各写一份近似版**。

### 3.1 定义点口径

- **定义点** = CSS 源码（**剥注释**）里，每条规则的**规则体**中匹配 `(^|[;{\s])--([\w-]+)\s*:` 的名字。
- **作用域形态** 按逗号切开选择器（`splitSelector`），**每个 compound 各判一次**（`.a, .b { --x: 1 }` 算两个定义点 —— 与类名轴同款）：

| 形态 | 判定 |
|:--|:--|
| **文档级** | 剥伪类/伪元素后，整串以 `:root` / `html` / `body` / `[data-theme…]` / `*` 开头（含 `*::before` 这类**无主体**形态） |
| **类限定** | 主体 compound 含**类选择器**（`.ldk-x` / `.plugin-x` / `.ldk-a .plugin-b` …） |
| **id 限定** | 主体是 `#id` |
| 元素/通配/属性 | 其余（**归件 7 的选择器形态轴**，本轴只判前两类 ＋ 对 id 按 (c) 放行） |

### 3.2 分级表（**判红逐条论证「① 本仓可答 ② 有真害」——[22 号档 §10.3](22-收口总方案-跨方样式污染九件套.md) 硬要求**）

| 判据 | 域 | 判定式 | 级别 | ① / ② |
|:--|:--|:--|:--:|:--|

| **V2 定义 `ldk-*` 自定义属性** | 插件 ＋ 共享组件（任何作用域） | `name startsWith "ldk-"` | 🔴 **红** | ① 本仓可答 ② 占宿主命名空间（与类名/关键帧同句，硬约束 23 ②） |

| **V5 插件的类限定定义不含自有类** | 插件 | `形态 == 类限定` ∧ **该 compound 里没有任何 `.<pluginId>-*` 类** | 🔴 **红** | ① 本仓可答 ② 定义落到宿主／他方元素上（与件 7 的 R3「跨方命中必须有自有根类作祖先」同形） |
| **V6 插件把「有主」名字写在文档级** | 插件 | `形态 == 文档级` ∧ `name startsWith`<pluginId>-`` | 🟡 **黄**（只报不拦） | 名字自带命名空间 ⇒ 无人同吃，**近乎无害**；建议挂自有根类 |

**✅ 明确允许（防误伤清单——判据必须**不**报这些）**：

### 4.1 壳仓：`scripts/check-css-namespace.mjs` 新增 **判据⑨（token 作用域）**

> ⚠️ **编号说明**：**判据⑦（族段规则）与判据⑧（关键帧引用不悬空）已预留给 1.26**（[22 号档 §3.6](22-收口总方案-跨方样式污染九件套.md)）⇒ 本轴取 **⑨**，不去动已写进其它档的⑦⑧ 号。

  - `hasOwnClass(compound, prefix)` → 该 compound 里有没有 `${prefix}` 开头的类（V4/V5 的判定体）

### 7.3 本轴新增的诚实边界（写进交接，1.20 报告要用）

1. **「无主名字」的判定用的是 `<pluginId>-` 前缀** ⇒ `pluginId` 唯一性失效时（硬约束 11 被破）V6 的「近乎无害」不再成立 —— 与系列边界第 5 条同源。
2. **`(c) portal 面**按**浮层宿主根**放行 ⇒ 两个插件若都往 `#ld-float-layer` 下写**同名** token，**本轴判不出**（该面是共用元素）⇒ 归「跨仓才能答 ⇒ 黄」一类，探针的跨方碰撞报出。
3. **JS 侧写入不在管辖内**（§一 防误伤 1）⇒ 插件用 inline style 在**自己的元素**上写 `--x` 仍然合法（`serial-monitor/SessionListItem.tsx:74` 的 `--session-color` 就是这形态）——**这是有意的口子**，不是漏网。
4. **样式表 `!important` 不在判据里**：本轴判「定义在哪」，不判权重战（[24 号档](24-任务-运行时全表断言探针.md) 覆盖边界第 6 条）。

## 八、禁区（沿用系列 ＋ 本轴新增）

**沿用**：⛔ 不引白名单/基线表 · ⛔ 不做渲染隔离（件 9 决）· ⛔ 不改视觉语义 · ⛔ 不以「门禁绿了」当「问题没了」· ⛔ 不压平残余边界。

**本轴新增**：

- 🔴 **不许把 JS 侧写入链「作用域化」**（P1 禁区，[29 号档 §二](29-主题系统保护条款.md)）——`setProperty` 到 `documentElement` 永远是设计。
- 🔴 **不许动主题配方 / `theme.schema.json` / 引擎写入格式**（丙 的全部价值就是不动它们）。
- 🔴 **不许把 `[data-theme="light"]` 改成类限定**、**不许搬走 `#ld-float-layer` 的 token**。
- 🔴 **不许要求插件必须消费 `var(--*)` 或必须用官方组件**（[22 号档 §10.3](22-收口总方案-跨方样式污染九件套.md)）——本轴只约束**定义**的作用域。
- 🔴 **不许顺手做件 7（`src/**` 顶层非类名选择器）** —— 归 1.25/1.26；本轮只在**判据⑨ 的宿主域**上与它相邻（域宽了，但判的是 token 不是选择器形态）。
- ⚠️ **不许顺手把 `serial-monitor` 的字面量色收敛到壳语义色**（§5.3：会改色）。
- ⚠️ 照旧：不跳 `npm run check` · 推前现测代理 · 推完 `ls-remote` 对 SHA · 按路径 `git add`（壳仓有并发写手）。
