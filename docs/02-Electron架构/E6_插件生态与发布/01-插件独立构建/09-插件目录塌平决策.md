## 一、拍板

**2026-09-05 用户：** 内置插件并不是特殊插件，仅仅是声明了 `core:true` 的插件，任何插件都可以声明 core:true。当初分 plugin/builtin 与 plugin/user 只是怕用户把 settings/插件市场等从文件夹直接删掉，仅此而已。除此以外内置与市场插件零区别，**不要给相关插件搞特殊**。

**塌平范围（用户选「全面塌平」）：** repo `plugins/` + userData `{userData}/plugins/` + 发货夹 `bundled-plugins/` 三层全平铺 `plugins/<id>` / `<id>.linkdesk-plugin`，删 builtin/user 双目录。

**为什么（AI 推荐获拍板）：**
- 记忆早已是此立场——[[factory-vs-marketplace-plugins]] :15「core:true 唯一语义=跟着发行版打包不可卸载，不是种族隔离」；CLAUDE.md 硬约束 11「插件身份唯一来源=plugin.json 声明字段，禁按文件位置/目录名推断」。
- 实证：plugins/builtin 4/4 全 core:true、plugins/user 0/16 core:true —— 文件夹是 core:true 的**纯冗余副本**（第二份真相源），一旦位置与声明脱钩即误导。
- 文件夹从未真正挡住删除（高手删 builtin/ 与 user/ 一样易）；真保护 = core:true（隐藏卸载按钮）+ 自动恢复账本（删文件夹→从发货夹恢复，除非 installed-plugins.json removed 标记）——均与文件夹无关。
- ⚠️ **2026-09-07 #18 重塑（上条「自动恢复账本」半句退役）**：自动装回腿改种子一次化（boot 只在「无账本记录 + 目录缺」时铺一次），手删文件夹不再从发货夹自动恢复，而是 respect → 对账置 removed 墓碑永不复活（[E6#18d](../E6-执行清单.md)）；真恢复通道 = 市场重下 / 手装随车 zip 销章。core:true 藏钮半句仍立。
