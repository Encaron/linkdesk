  1. 同一时刻只许存在一张提示条：上一个锚移开立即收，新的才出。⛔ 不许排队、不许堆叠、不许"扫过去弹出三张"。

  3. 本帧也是 placement 翻面的实例：窗口按钮贴着窗口顶边 ⇒ 首选 top（贴锚上方）贴不下 ⇒ 自动翻到 bottom（条落在锚下方）。⛔ 本件是纯框、不带小箭头（2026-09-27 用户拍板）——归属感靠「贴紧锚」（间距固定 GAP_PX = 6），所以翻面只解决「装不下」，不承担「指向」。
  4. 🔴 这一排还有一层风险：改结构可能撞 -webkit-app-region: drag（硬约束 18，窗口顶部 30px 是 OS 级拖拽区）——所以本件坚持属性式、不包元素。

一句话：本件是「把不属于我们的控件（Chromium 原生 tooltip）换成走我们 token 的轻提示条」， 并让它在与右键菜单同源的数据上自动带出快捷键。43 处壳侧 ＋ 4 只官方插件仓是收编面， 三条门禁腿负责不让原生小方框长回来。 详案与 7 条待拍板见 01-设计.md。
