### #56 玻璃覆盖 neutral 门控语义修复 + radius scale clamp

- **依据：** 审计#2——getAppearanceOverrides（ThemeEngine.ts:954-958）neutral 判定 `blur!==0`/`opacity!==1` 即不覆盖 → 玻璃主题 + custom 拖 glassBlur 到 0 关不掉模糊、glassOpacity 到 1 变不了不透明，config 文案「0 关闭/1 不透明」永不兑现；审计#4——消费路径 applyRadiusScale 无 0.5-2 clamp，程序化写 app.surfaceRadius:5 得 30px 圆角（clamp 只在播种方向 deriveAppearanceSeeds 有）
- **方案：** neutral 判定从「值等于端点」改为 presence 语义（配置被显式写过才覆盖；backgroundImage 空=还原主题基线先例同款）——引擎读「覆盖集合当前含哪些键」，端点值=用户显式意图照常覆盖；applyRadiusScale 消费侧补 clamp(0.5,2)
- **落点：** src/core/services/ui/ThemeEngine.ts（getAppearanceOverrides/applyRadiusScale）+ src/App/startup.ts 配置注册
- **验收：** 玻璃主题 custom 拖 glassBlur 到 0 模糊真关、glassOpacity 到 1 真不透明；滑杆回默认值=还原主题基线；settings.json 直写 surfaceRadius:5 被 clamp 到 2；补单测；npm run check 全绿
- **实现（2026-08-25，commit `c15d963f`）：** ① getAppearanceOverrides neutral 门控改 **presence 语义**——新增 `ConfigurationService.hasConfigurationValue`（配置被显式写过即视为覆盖意图），glassBlur=0（关闭）/glassOpacity=1（不透明）端点值=用户显式意图照常覆盖（原「值偏离端点」判定把端点误判为 neutral 默认 → 模糊关不掉/变不了不透明）；reset 摘除 key → 回主题基线
  - ② applyRadiusScale 消费侧补 `clamp(0,2)`（#68 已把 min 0.5→0，档案旧方案写 0.5 下限**不得回写**）——settings.json/程序化直写 app.surfaceRadius:5 不再 5× 圆角（原无 clamp 直接 30px）
- **验收（实测）：** +6 单测（blur 0 端点覆盖 / opacity 1 端点覆盖 / hasConfigurationValue presence / scale 5→2× / -1→0× / 1.5 不变），1077 全绿
- **回勾（2026-08-25）：** 12✗→11✗

### #57 mix 播种 scale 反推修复——二次缩放根治
