# 外观主题化（Theme = 完整外观配方 + 域贡献者）

> **状态：** 设计专题（2026-08-23 建）——骨架已拍板，落地待 #50.6-#50.12
> **一句话：** 主题从「换颜色」升级为「换整套外观配方」——颜色、字体、圆角、玻璃、极简、背景图全由主题决定；主题文件是「域贡献者」，缺的域继承全局默认；设置层可全局粗调（scale）。

## 已拍板快照（11 条）

1. 字体：壳零内置，系统栈兜底 + 主题插件自带字体（getAssetPath）
2. 图标主题先不做，单独立案
3. 摸底先行（02 文档即产物）
4. 主题 = 外观 token 覆盖层，边界 schema 锁死（01 §3）
5. 覆盖粒度 = 全局 scale 系数（04 §6.4）
6. 圆角 = 语义八档 + 偏门值归并（02 §5.2）
7. 字体纯主题层，不进设置层
8. 外观全局共享 + 按窗继承
9. 主题 = 域贡献者，缺的域继承默认（03）
10. 风格 vs 配色分离（03 §4.4）
11. 玻璃连续 scale 不是二元开关（04 §6.2）
