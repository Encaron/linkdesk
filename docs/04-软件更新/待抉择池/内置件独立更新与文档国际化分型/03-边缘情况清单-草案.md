## 一、更新管道

| # | 现象 | 预期 | 判据 |
|:--:|---|---|---|
| X1 | 更新中断网 | 失败回滚、版本不变、一条通知（唯一面） | 机械＋人工 |
| X2 | sha256 不匹配 | 拒装、回基线读序、通知——**安全优先** | 机械 |
| X3 | 下载中断 / 磁盘满 | 临时目录丢弃，下次重试；⛔ 不留半份 | 机械（临时物命名＋rename 原子性用例） |
| X4 | 覆盖层被手删/损坏 | 读序自愈回基线（校验不过视同无覆盖层）；LPM 显示基线版 | 机械 |
| X5 | appliesTo 不满足（新手册＋旧壳 / 旧手册＋新壳） | LPM 标注适用版本；**是否允许强制更新 → 决策点**（⭐建议：标黄＋允许，manifest 可加 `requiresShell:true` 收紧） | 机械＋人工 |
| X6 | 更新中正开着手册页 | 读序原子（rename）→ 看到完整旧版或完整新版，⛔ 不见半份 | 机械 |
| X8 | 更新中退出软件 | 临时物丢弃，下次 checkUpdates 重试 | 人工 |
| X9 | 批量更新部分失败 | 逐项独立成败，互不回滚 | 机械 |
| X12 | 永久离线环境 | 基线永可用；LPM 诚实显示「无法检查更新」，⛔ 不空白、不假绿 | 人工 |
