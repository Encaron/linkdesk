### 3. 落定案（**推荐形态：丙 的「两侧统一作用域规则」**）

若维持丙，规则建议表述为（**本格可改措辞，但三条不许退化**）：

> **自定义属性定义的作用域规则（宿主与插件双侧统一）**
> **(a) 文档级**（`:root` / `html` / `body` / `[data-theme=…]` / 通配）：**只有宿主契约块**可以写，且**只能写契约名单里的名字**（名单**由脚本从契约块导出**，不手抄）；
> **(b) 类限定**（复合选择器，主体带类或有祖先）：**任何一方都可以写**，但**必须挂在自有命名空间的类之下**（宿主 `.ldk-*` · 插件 `<pluginId>-*`）；
> **(c) 🔴 portal 面（2026-09-16 新增，为「以后做各类下拉菜单」预留）**：被 **portal 到浮层宿主**的组件，其局部 token 可挂在**浮层宿主**之下 —— ⚠️ **宿主自己就这么干**（实测 `#ld-float-layer { --float-blur-floor }`；浮层宿主链见 `src/pool/floating/**` ＋ 共享组件 `overlay-portal`）。**没有这一条，将来任何 portal 出去的下拉/弹层都没法带自己的局部 token**（挂组件根类下会因脱离子树而失效）。
> **⇒ 禁止**：① 插件**占用宿主命名空间**（定义 `ldk-*` —— 🔴 **红灯**，这是真害：覆写宿主契约）；② 宿主在文档级定义**契约名单之外**的名字（🔴 红灯，防「影子契约」）；③ 任何一方在**非自有命名空间**的类之下定义（**除 (c) 的浮层宿主**）。
> 🟡 **不是禁止、只给黄灯**：插件把**自有** token（`<pluginId>-*`）定义在文档级 —— 名字自带命名空间、无人同吃，**近乎无害**，只建议挂自有根类（**不拦**）。
> 🔴 **两条防误伤声明（[29 号档](29-主题系统保护条款.md) §二/§四.1，缺了就会冻死主题系统）**：
> 1. **JS 侧写入不在本判据管辖内**——`ThemeEngine` 的 `documentElement.style.setProperty` 与 `preload-pool` 写池侧 `:root` **永远合法**；本判据**只管 CSS 源码里的定义**。**任何轮次不许把这条写入链「作用域化」**。
> 2. **「契约名单」的定义 = `index.css` 契约块 ∪ 主题配方键**（两者都是数据源）⇒ **配方键超出 `index.css` 是合法的**（引擎写入的就是它），**别把它当「影子契约」报红**。
> 🔑 **若定案选「甲」（宿主 token 改名 `--ldk-*`），红灯自动变成纯结构性**：**「插件定义任何 `ldk-*` 名字（类名 · 关键帧 · 自定义属性同一句）」** —— **零清单、零下发数据**，与类名那条规则完全同句；而丙-only 要在作者侧抓住 `marketplace` 那类覆写，**必须给作者下发一份宿主契约名单**（又是一份会腐烂的数据）。**这是甲的第二个结构性好处，本格必须在定案时把它算进代价-收益。**

- **零名单依赖**：名单只用于 (a) 的宿主自查，且**生成式**（脚本从契约块扫出，进 `check` 链做新鲜度校验）。
- **契约块 = 文件级登记**（今天 = `src/index.css` 的 `:root` ＋ `[data-theme="light"]` 两块）；**不是**按名字登记 ⇒ 不违背系列禁区（⛔ 白名单/基线表）。
