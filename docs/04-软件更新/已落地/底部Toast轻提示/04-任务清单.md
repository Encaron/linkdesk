## 〇、落点判定（先回答"住哪"）

| 问题 | 结论 |
|---|---|
| 放 `@linkdesk/ui` 吗？ | **不放**。插件**无权渲染壳覆盖层**；`@linkdesk/ui` 是插件侧组件库，看不见壳的 `position:fixed` 层。插件只通过 `toasts` API 使用。 |
| 放池侧吗？ | **不放**。池是哑渲染器；通知面归壳（与铃铛面板同源）。 |
| 新建 store 吗？ | **不建**。复用 `src/core/services/ui/toast.ts`，加 `presentation` 字段。 |
| 要动设置页吗？ | **v1 不加开关**（避免多一个配置面）；若将来要"关闭轻提示"，走通知设置统一开关（另立件）。 |
