## 二、待建——关键命令

### `revealInExplorer`——#29 🔥 公共 API

**调用方：** 设置（"在文件树中显示 settings.json"）、Git（文件跳转）、AI/智能体（定位文件）。

**规格：**
```
executeCommand("revealInExplorer", { filePath, focus?, select? })
→ RevealResult { success, uri?, error? }

流程：
1. normalizePath(args.filePath)  ← 外部调用方可能传 \
2. 确保文件树侧栏可见（workbench.view.explorer）
3. 逐层展开目录链——绕过 FileExcludeFilter（对标 VS Code）
   使用 findAndExpandToBypassExclude（#29b，当前只有 TODO）
4. 选中 + 高亮（2s 动画） + 滚动到可见
5. 路径不存在 → { success: false, error: "not_found" }
```

**🛡️ #29a:** 入口 `normalizePath(args.filePath)`  
**🛡️ #29b:** 实现 `findAndExpandToBypassExclude`（#6 的 TODO）  
**🛡️ #29c:** `RevealInExplorerArgs` 类型放 `commands.ts`——不建 `src/core/types.ts`

### `explorer.openFocused`——#21 已注册，Enter 快捷键已就绪

**当前行为：** `useFileTreeKeyboard` 的 Enter 处理在 React 层直接打开（不走 `executeCommand`）。全局 KeybindingRegistry 也注册了 Enter → `explorer.openFocused`（占位 handler）。**两套处理不冲突**——React 层做实事，全局 handler 是占位。

**未来方向：** React 层 Enter 改为调 `executeCommand("explorer.openFocused")`——命令系统统一入口。

### `explorer.revealInOS`——#40

跨平台：Windows `shell.showItemInFolder` / macOS `shell.showItemInFolder` / Linux `shell.openPath`。
🛡️ 安全：只接受工作区内的路径（`findClosestRoot` 检查）。
