## 二、禁区

- 🔴 **不许把 i18n 键判红**（**这是本件的存在意义之一**——把"不可判"如实写成黄灯，而不是假装能判）。
- 🔴 **不许引「泛词清单 / 常用键清单」这类手抄表**。
- 🔴 **不许动翻译能力**：`src/i18n/index.ts` 的注册链 · `contributes.i18n` 语义 · 中英切换 · **`i18nResources.ts` 的整份重建语义**（`:41-58` 的注释解释了「逐键 removeResource 不可行」——**那段设计逐字保留**）。
- 🔴 **不许动语言包 id**（归外观族件）。
- 🔴 **不许引白名单 / 基线 / 棘轮**。
- ⚠️ **上位约束**：**零 UI 变化**（除版本号；**翻译是三条横切之一** ⇒ 它的零回归是本格的硬判据）· 只做加法且名字一次定对 · [29 号档](../样式命名空间归一化/29-主题系统保护条款.md) 优先 · 对外宽容。
- ⚠️ 照旧：不跳 `npm run check` · 推前现测代理 · 推完 `ls-remote` 对 SHA · **提交只按路径 `git add <本格文件>`**。
