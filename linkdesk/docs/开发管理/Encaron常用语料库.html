🛡️ 硬约束速查（15 条）

绝对不能违反。AI 进场必读。

15 条硬约束 · 精简版规则必读
1. 所有颜色走 CSS 变量 var(--xxx)，禁止硬编码 hex 2. 所有 UI 文字走 t()，禁止硬编码中文 3. 标签页系统不 import CardRegistry 4. workspace.json 禁止嵌套，必须一层平铺数组 5. IPC 事件订阅必须用 generation counter 模式 6. setState 函数式更新器内部不写副作用 7. 组件只实现 OnData(fields) + OnSend 8. ProtocolParser 独立可替换，RingBuffer { cardId, value } 硬边界 9. 核心无知原则：核心不知道软件是干什么的 10. 禁止 core/ 或 pluginLoader/ 中写死插件 ID 11. 插件身份唯一来源是 plugin.json 声明字段 12. 禁止硬编码路径——所有资产路径走 getAssetPath() 13. async 初始化函数必须防 StrictMode 双重 effect 竞态 14. useEffect 有回调 prop 做非 DOM 副作用时加活跃守卫 15. 出了隐形 bug 不要猜——git checkout 逐 commit 二分定位
