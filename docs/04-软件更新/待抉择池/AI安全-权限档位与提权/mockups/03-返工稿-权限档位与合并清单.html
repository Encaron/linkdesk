#问题处理
1切英文后档位仍中文，点一下才变不再缓存已翻译字符串；共享件按 i18n key 渲染，语言变化即重绘；徽标同。
2「当前权限一览」多余删除；档位块下方保留一条能力摘要。
3打勾符号是 emoji改文字「允许 / 询问 / 不允许」；UI 文案禁 emoji，并加机械检查。
4完全访问通知不消失、重复堆积同一事件一条、8 秒自动收起；重复切换只更新那一条。
5完全访问时档位块五行太高压到三行：四段控件 / 一行说明或告警 / 一行能力摘要。
6按钮是壳还是插件画的选择器是共享件；行与按钮是设置插件的通用行。换设置插件仍可用同一选择器。
7风险表贴边、透明小按钮24px 内边距；主按钮改标准实心按钮。
8操作清单全是内部编号说明列改为用户语言；内部编号只留在 AI 手册。
9设置「逐次确认」但徽标「AI 只读」徽标直接消费变更事件的新值，不再回读文件；与设置页同源。
10文档里红色禁止符号易误解全面去 emoji，改文字标签「禁止 / 注意 / 允许」；加机械检查。
11设置 ID 会不会让 AI 自己升档配置键不是命令；AI 写 ai.* 被拒；切档命令仅限用户；无批准入口。
12接入凭据是什么AI 客户端连接凭据（原有能力）；说明与按钮文案改写。

14文案太口语全部改书面语，删掉实现细节。
