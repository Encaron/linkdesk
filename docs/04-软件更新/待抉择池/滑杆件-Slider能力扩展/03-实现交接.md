## 三、偏差与改判（照 [00 §四](00-README.md) 的口径记账）

1. **设计图里的自定义属性名改了**（唯一一处对 05 设计图的偏离）：设计图用 `--ldk-slider-gap` / `--ldk-slider-btn`，被硬约束 23 的 css-namespace 门禁判红（**`ldk-` 前缀专属宿主，自定义属性不得占用**）⇒ 改名 `--slider-gap` / `--slider-btn`。**类名与形状一字未动**，观感零差异；纸面设计图保留原名。
2. **`unitPosition` 在作者 schema 里是开放字符串**，不是枚举：实测传 `"left"` 不被拒。这是**有意的**——与 `uiHint`/`renderHint` 同口径（未知值优雅回退到缺省 `after`，不 throw）；单测里以「第四条」明确记下。要收紧成枚举得先定「回退还是报错」的语义，不在本件范围。
3. **设置页撑满是 CSS 接手，不是新增 `data-fill` 属性**：包裹层删除后，行宽靠 `.settings-row-control .ldk-slider-root{width:100%}` ＋ 内层 input `min-width:0` 撑开。理由：设置仓是**消费方**，不为它给共享件再开一个只有它用的属性口。
4. **`05-设计图-Slider.html` 未重画**（用户明令设计图已过 skill 门）；偏差 1 的改名只落在代码里，设计图按原样留档。

## 四、实机验收（dev 版 · 2026-10-03）

- **环境**：隔离 dev 实例（自起 vite 于 1420 ＋ `electron . --remote-debugging-port=9455 --user-data-dir=<临时 profile>`；插件主目录＝该 profile 的 `plugins/`，其中 `settings`＝**已发布的 1.0.27**、`@linkdesk/ui` 由 dev 壳的 `ui:build` 产物供给）。
  - ⚠️ 踩坑留痕：vite 的 `fs.allow` 只放行「仓库根 ＋ 默认插件主目录 ＋ `LINKDESK_USER_PLUGINS_HOME`」——**起隔离实例时必须把该变量喂给 vite**，否则插件的 `/@fs` 请求 403、设置视图直接崩。
  - ⚠️ 另一坑：**主进程会把 `ai.debug.remoteDebugging=true` 补成 `--remote-debugging-port=9333`**（该键住 profile 的 `settings.json`）。9333 已被安装版占住 ⇒ 隔离实例的 CDP 整个起不来；隔离 profile 里把该键置 false、只用命令行端口即可。
- **开设置页**：`core.openSettings` 在池文档里会静默 return（factory 槽路由，RELOAD 后不重建）⇒ 本件用真实用户路径：标签栏 `+` → **设置**。
- **主题页（`app.appearanceMode = 自定义`）实测读数**：
  - `.ldk-slider-root` = **7**（正是声明 `stepper: true` 的 7 键），`.ldk-slider-step` = **14**（每根 2 枚）；
  - 每根 `data-pos="after"`、`data-stepper="true"`，按钮 `aria-label`＝「减少」「增加」；
  - 值标签实测：`6px` / `0px` / `0px` / `0.5` / `1` / `1` / `0`（有单位出单位，无单位出裸值）；
  - 越界置灰实测：`0px` 行的「减少」`disabled`、`1` 行的「增加」`disabled`；
  - **点一次 ＋：`6px → 7px`（input 值同步 7）；点一次 −：回到 `6px`**——单击单发、夹取与回写都对。
  - 排布与设计图 `[data-pos="after"]` 的四列（− ｜ 轨道 ｜ ＋ ｜ 值）逐格一致。
