## 二、修复方案

### 2.1 E5#36——硬编码中文 → t()

**规则：** UI 文本 `"中文"` → `t("中文")`。i18n 系统使用 `parseMissingKeyHandler: (key) => key`——即使 en.json 缺翻译，中文用户看到的是 key 原文（就是中文），不会炸。

**app.tsx（12 处）——最严重：**

```typescript
// 改前
description: "配色主题",
category: "开发人员",
setLastError(`串口操作失败：${e?.message || e}`);

// 改后
description: t("配色主题"),
category: t("开发人员"),
setLastError(t("串口操作失败") + `：${e?.message || e}`);
```

**plugin-shell-main.tsx（5 处）——用户可见错误：**

```typescript
// 改前
root.textContent = "缺少参数: ?plugin-view=<插件ID>";

// 改后
// ⚠️ 这个文件在独立 plugin WebView 中运行——i18n 由 preload 注入
import { t } from "@/i18n";  // 或从 window.linkdesk.language 获取
root.textContent = t("缺少参数: ?plugin-view=<插件ID>");
```

**WindowControls.tsx（3 处）——tooltip：**

```typescript
// 改前
title="最小化"  →  title={t("最小化")}
title="关闭"    →  title={t("关闭")}
title={maximized ? "还原" : "最大化"}  →  title={maximized ? t("还原") : t("最大化")}
```

**NotificationCenter.tsx（7 处）——时间标签：**

```typescript
// 改前
return "刚刚";
return `${min} 分钟前`;

// 改后
if (diff < 60) return t("刚刚");
return t("{{min}} 分钟前", { min });
```
