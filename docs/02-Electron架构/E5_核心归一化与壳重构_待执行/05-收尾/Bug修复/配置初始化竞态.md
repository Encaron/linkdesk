# 配置初始化竞态——启动时配置不生效

> 2026-08-06。Filed by Encaron——实测发现。多个配置项启动后需手动切换一次才生效。
> 位于 E5 收尾 → `05-收尾/Bug修复/`

---

## 一、问题

### 症状

| 设置项 | 磁盘值 | 启动后实际行为 |
|:--|:--|:--|
| `menuStyle` (汉堡+标题栏 "两者都开") | 两者都开 | 只显示标题栏菜单 |
| `editor.ctrlScroll` (Ctrl+滚轮放大) | 开 | Ctrl+滚轮无效 |

**切一下设置（开关→重新选）→ 立即生效。** 重启后又失效。

### 根因

App.tsx init 链（L130-L135）：

```typescript
await Promise.all([
  initConfigurationService(),  // ← 异步——读磁盘、解析 JSON、初始化 store
  ...
]);
```

React mount 不等 `useEffect` 中的 async。组件渲染时：

```
1. React mount → 所有组件 render
2. getConfigurationValue("menuStyle") → undefined（store 还是空的）
3. 组件走代码默认值
4. ... 异步等待 ...
5. initConfigurationService() 完成 → store 就绪
6. 但组件已渲染——不再自动重读
```

### 受影响的模式

任何在 mount 时读配置、之后不再自动重读的组件：

```
grep -rn "getConfigurationValue\|useConfigurationValue" src/ components/
→ 可能 ~15-20 处，需逐一审计
```

---

## 二、方案

### 方案 A（对标 VS Code）——配置在 mount 前就绪

```typescript
// 主入口（index.tsx 或 main.tsx）
// 在 ReactDOM.createRoot 之前先加载配置
await initConfigurationService();
// 然后才 mount
ReactDOM.createRoot(...).render(<App />);
```

优点：根本解决——所有组件 mount 时配置已就绪。一行 `await`。
缺点：启动时间增加 ~50ms（读磁盘+解析 JSON），可忽略。
改动：提取 init 链中的配置部分到 entry point。

### 方案 B——配置服务加 ready() 守卫

```typescript
// ConfigurationService.ts
let _ready = false;
export function ready(): Promise<void> { ... }
export function getConfigurationValue(key) {
  if (!_ready) console.warn("[Config] 在 ready 前读取:", key);
  ...
}
```

组件侧：
```typescript
const [ready, setReady] = useState(false);
useEffect(() => { configReady().then(() => setReady(true)); }, []);
if (!ready) return null; // 或 skeleton
```

缺点：每个组件都要加守卫，治标不治本。容易漏。

### 推荐：方案 A

对标 VS Code——`IWorkspaceConfigurationService` 在窗口创建之前已完成初始化。LinkDesk 的 Electron 入口 `index.tsx` 已经是一个 async 上下文，加一行 `await` 即可。

## 三、执行清单

#### E5#115a 审计受影响范围

```bash
grep -rn "getConfigurationValue\|useConfigurationValue" src/ plugins/ --include="*.ts" --include="*.tsx"
```

列出所有调用点，标记哪些在 mount 时读取（易受竞态影响）。

#### E5#115b 提取配置初始化到入口

1. 从 App.tsx `useEffect` init 链中移除 `initConfigurationService()`
2. 在 `src/main.tsx`（或入口文件）`ReactDOM.createRoot` 之前 `await initConfigurationService()`
3. `initStorageService()` 同理（配置依赖存储）

改动量：~5-10 行。

#### E5#115c 验证

- 设置 hamburger+标题栏"两者都开" → 重启 → 两者都显示
- 设置 Ctrl+滚轮"开" → 重启 → Ctrl+滚轮直接可用
- 全量回归：`npm run check` 零新增

---

## 四、涉及文件

| 文件 | 改动 |
|:--|:--|
| `src/App.tsx` | 从 init 链中移除 `initConfigurationService()` + `initStorageService()` |
| `src/main.tsx` | `ReactDOM.createRoot` 之前 `await initConfigurationService()` |
| 受影响的组件 | 无需改动——配置已在 mount 前就绪 |

改动量：~10 行。
