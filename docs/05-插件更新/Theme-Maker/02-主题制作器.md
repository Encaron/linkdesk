# 04 — 主题制作器

> **类型：市场插件** | **05-出厂制造 #07** | 2026-07-27。**纯视图插件——可视化调色 + AI 辅助 + 一键导出。** 不改壳一行代码。

---

## 定位

| | |
|---|---|
| 类型 | **纯视图插件**——`plugin.json` + React 组件 + ColorPicker |
| 前提 | E3f ColorPicker 归一化组件（#59e）+ `dependsOn` 基础设施（#59d0）|

## 三块能力

### 1. 可视化调色

```
┌─ 调色面板 ──────────────────────────────────┐
│                                               │
│  bg-window    [#2B2A24]  ●  → ColorPicker    │
│  bg-card      [#1E1E1E]  ●                  │
│  text-primary [#CCCCCC]  ●                  │
│  text-secondary [#888888] ●                  │
│  border       [#333333]  ●                  │
│  accent       [#AA972A]  ●                  │
│  ...                                         │
│                                               │
│  [即时预览] ── applyTheme() 全界面即时变色      │
└───────────────────────────────────────────────┘
```

每个颜色位右侧的色块点击 → 弹出归一化 `ColorPicker` → 拖拽/输入取色 → `applyAccentColor()` 即时预览全界面。

### 2. AI 辅助

```
┌─ AI 面板 ────────────────────────────────────┐
│                                               │
│  > 给我一个暖色暗系主题，强调琥珀色              │
│  ────────────────────────────────────         │
│  AI → 生成完整主题 JSON：                      │
│  {                                            │
│    "bg-window": "#2B2A24",                   │
│    "bg-card": "#1E1E1C",                     │
│    "text-primary": "#E8E4D8",                │
│    "accent": "#C8A42A",                      │
│    ...                                        │
│  }                                            │
│  [预览] [微调] [保存]                           │
│                                               │
└───────────────────────────────────────────────┘
```

四种 AI 操作：

| 操作 | 用户输入 | AI 输出 |
|------|------|------|
| **生成** | "暖色暗系主题，琥珀强调" | 完整主题 JSON |
| **微调** | "把背景调暖一点" | 相关色值偏移 |
| **变体** | "生成这个主题的 light 版本" | dark→light 色值映射 |
| **批量** | "用这组色相生成 5 个风格变体" | 5 份不同饱和度/亮度的 JSON |

AI 不知道 LinkDesk 架构、不知道其他插件、不知道核心 API。只知道 `{ colorKey: hex }` 这个 JSON schema。合"桌子不知道内容"原则。

### 3. 导出

```
┌─ 导出面板 ────────────────────────────────────┐
│                                               │
│  ☑ 暮光 Sunset      (dark)  ────────────    │
│  ☐ 晨曦 Dawn         (light) ────────────    │
│  ☑ 琥珀 Amber        (dark)  ────────────    │
│                                               │
│  [导出选中 (2)]  [一键导出全部 (3)]             │
│                                               │
└───────────────────────────────────────────────┘
```

导出一个或多个主题为标准插件目录结构：

```
暮光 Sunset/
├── plugin.json        ← 自动生成 contributes.themes
└── sunset.json        ← 主题颜色 JSON
```

可在 marketplace 分发、可分享给其他用户、可直接拖入 LinkDesk 安装。

## 用的核心桌子

| 桌子 | 用途 |
|------|------|
| `ColorPicker` | 归一化调色 UI（`src/components/shared/ColorPicker.tsx`，#59e）|
| `ThemeEngine.applyTheme()` | 即时预览整份主题 JSON |
| `ThemeEngine.applyAccentColor()` | 即时预览单个色值 |
| `ConfigurationService` | 临时读写（预览不落盘） |
| IPC `writeFile` | 导出主题包到磁盘 |

**核心不知道"主题制作"这件事。** 它只知道有张桌子叫 ThemeEngine、有个归一化组件叫 ColorPicker。主题制作器是普通插件，`import` 这些桌子做自己的产品。
