## 五、`AI#47` · 验收面自检（与物理指针无关）

**结论：本轮全部验收读数零坐标输入。** 用到的驱动面（全部与指针无关）：

| 面 | 手段 | 为什么不算坐标输入 |
|:--|:--|:--|
| CLI / MCP 通道 | `linkdeskctl.mjs` / MCP stdio（`exec` / `open-tab` / `install` …） | 纯文本协议，进程间 |
| 池内动作 | `window.linkdesk.pool.tabAction` / `pool.getLayout` / `events.emit("icon:selected")` | 结构化 API 调用 |
| 命令面 | `window.linkdesk.commands.executeCommand`（`tabs.create` / `view.*` …） | 同左 |
| 壳侧对话框（敏感门） | CDP `el.click()`（**DOM 合成点击**，⛔ 不派发鼠标事件） | 按元素解析定位，不推算坐标、不依赖窗口位置 |
| 键盘腿（Esc/Enter） | CDP **真按键**（窗未聚焦时降级 DOM 合成并如实标 `dom`） | 键事件无位置语义 |

**口径订正一条（本轮实测逼出来的，已同笔改进 [01-设计.md §三 验收面第 1 条](01-设计.md) 与 §七 第 7 条）**：原文写「hover-only 面用 CDP `CSS.forcePseudoState` 强制伪状态，而不是移动指针」——`D0#3` 实测（2026-09-28）：`forcePseudoState` 在**深层既有节点**上只改 `matches()`、**不改计算值**（样式若非直接由该伪类派生）⇒ 会**静默假绿**。订正后口径：① 首选 `forcePseudoState`（真·无指针，浅层/直连样式有效）；② 深层节点改用 `driver.mjs --mode mouse`（**元素锚定**：先解析目标元素再把指针送到它中心，不推算坐标、不看窗口位置），并在读数里**如实标注该面用了指针**；③ `--mode force` 保留但打降级警告。⛔ 不变的两条：不推算坐标、不截图猜点。
