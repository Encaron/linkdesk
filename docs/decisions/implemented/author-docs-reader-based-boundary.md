# 作者面文档——边界按读者，不按目录

- **日期**：2026-09-14
- **状态**：implemented
- **背景**：用户要「把所有插件源码移出软件」，并要在第七层「把插件制造这一方面说详细搞详细」。审计发现一个结构性事实：**给插件作者看的文档散在至少五处**——`docs/03-插件制造/`（15 篇，唯一"专门为作者造"的目录）、`docs/02-Electron架构/E5.8_归一化基建/外观主题化/`（22 篇，**写主题插件的作者必读**）、`docs/02-Electron架构/E6_插件生态与发布/{01-插件独立构建,02-插件开发工具链,05-文档与发布/00-第三方作者旅程}`、`packages/plugin-sdk/README.md` 速查表、`contracts/linkdesk.d.ts` + 命名空间矩阵。同时实测出四项代价数据：**48 条出界链接**（`03-插件制造` 指向目录外，其中 39 条去 `02-Electron架构`）、**130 处内部任务号**（`E6#xx`，14 篇，作者/AI 无法解析）、**搬动 15 篇正文要重算 ~90 个外部文件的引用**（含 6 个门禁脚本、**16 个不进 git 无门禁兜底的 memory 文件**、**9 个按规矩不该改的已封存期档案 ⇒ 必然断链**、1 处源码注释）。
- **决策**：
  0. 🔴 **宗旨（2026-09-14 用户亲口定，一切判据从这里出发）**：**`03-插件制造` 的目的是"让插件作者从零开始快速学习如何制作一个插件"** ⇒ **形态是「教学动线」，不是「文档集合」**；判据不是"收齐多少篇"，而是**口号三档能否计时达标**：**AI 10 分钟做出最小插件 / 30 分钟做出视图插件 / 1 天做出高难度插件**（既有 memory `e6-10min-first-plugin` 只立了"10 分钟"一档，本决策扩成三档并把时间变成判据）。**作者必须学会的六项**（区域地图 / 共享 UI 速查 / 区域间互动 / 插件间互动 / 配置项 / 主题）逐项要有落点。**🔴 不是全量搬进来** —— 老 15 篇原地不动，散在别处的设计文档只提炼不搬。
  1. **边界按读者判定，按目录落地**——「这篇给陌生作者读有用吗？」判为作者面的收进 `03-插件制造/`（目录成为作者面的物理全集），判为内部（壳目录规范 / 各层档案 / 执行清单 / 任务档案）的留在原处。
  2. **老 15 篇正文不搬**，归纳靠 `00-README.md` **真索引**（按「我要做什么」分流）实现——用户真正要的"可发现性"靠索引零成本可得；"顺序感"不值 ~90 处引用重算加 9 处必然断链的价。子文件夹只装**新增/重写**的作者面文档。
  3. **主题作者手册从设计文档提炼新写**（读 `外观主题化` 22 篇 → 在 `03-插件制造/主题/` 新写 2 篇），**不搬运**：那 22 篇含代码规划与多份修复档案 = 过程记录，设计文档（为什么）与作者手册（怎么做）是不同读者、不同问题。**字段级契约只留一个真源（`theme.schema.json`），手册只引不抄。**
  4. **内部任务号剥离**：`03-插件制造/**` 不得出现裸 `E6#`/`E5.8#`/`E5#`/`E4V#`（配门禁）。理由 = AI 友好：告诉 AI 别犯错（声明"可忽略"）不如不给它犯错的机会。
  5. **文档单独发一个 npm 包**（而不是塞进 `@linkdesk/plugin-sdk` 的 files）——版本轴独立（文档改一句 ≠ SDK 变了，避免把刚拆焊的轴又焊回去）+ 作者按需安装。**形态复用 `@linkdesk/contracts` 的"真源 + 生成物 + `--check` 字节比对"模式**，杜绝手工双维护。前置硬依赖 = 任务号剥离 + 作者面清单（否则包内全是断链与无法解析的坐标）。
  6. **在线锚 = GitHub 的 `03-插件制造/`**（用户选 (a)）指向**作者面入口**而非单篇——因为出界链接在 GitHub 上全部有效（发 npm 包只装本目录则 48 条全悬空）。
  7. **脚手架新增 `AGENTS.md`**（模板 → 每个新插件天生带）回答四件事：这是什么 / 铁律内联 / 规则去哪找（在线 URL + 离线 npm 包）/ **下一步动线**（用脚手架自己的 script 名）。不加 15 篇文档：**过期副本比没有副本更危险**（本仓 `00-AI执行守则-必读.md` 的"编号已全部作废…照它找必错，且是静默错"横幅就是该故障模式的活标本），且散在 N 个仓里的副本腐烂**没有任何门禁看得见**。
- **影响**：作者面文档成为**对外发布物** ⇒ 两条新门禁（无内部符号 / 出界链接白名单化）；`create-linkdesk-plugin` 与文档包各自 bump（第五根作者轴，进 `npm-release-state.json` + `version-bump` skill 多轴表）；执行载体 = E6 第 7.8 轮（`E6#105a-h`），档案 `docs/02-Electron架构/E6_插件生态与发布/插件源码外移层/11-作者面文档收口.md`。
