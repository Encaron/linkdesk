# Serial Simulator（串口数据模拟器）

> **普通插件**——独立版本、按需安装。接在串口数据管道上，为卡片工作台提供模拟数据。旧「市场插件 / 出厂制造排序 9/11」标记作废（2026-09-13 重组）。
> 接在串口数据管道上，没硬件时假装自己是硬件。终端命令驱动。

---

## 基本逻辑

一个市场插件——注册到串口数据管道（`serial-monitor.data` table）。当没有真实硬件连接时，它可以用命令生成模拟数据流：
- `sim sine temp 0 100 0.5` → 生成正弦波，cardId=temp, 范围 0-100, 频率 0.5Hz
- `sim random humid 30 80` → 生成随机值，cardId=humid, 30-80 范围
- `sim toggle led 2` → 每 2 秒切换 on/off, cardId=led

数据直接写入大厅的串口数据桌子——卡片工作台收到就像真的有 MCU 在发一样。

**核心原则：** 开发卡片工作台不需要硬件。演示 LinkDesk 不需要硬件。用户决定"要不要用"——也不需要硬件。

## 处于软件内位置

```
Marketplace → 安装"串口数据模拟器" → 插件启动
  └─ 注册到 serial-monitor.data table
  └─ 在串口监视器终端注册 `sim` 命令
       └─ 用户输入 sim <subcommand> → 数据流向卡片工作台
```

**数据流：**
```
Serial Simulator 插件
  └─ sim sine temp 0 100 0.5
       └─ 每 2 秒（1/0.5Hz）计算正弦值
            └─ 写入 serial-monitor.data table
                 └─ 卡片工作台订阅 → 卡片更新
```

## 生态地位

| 维度 | 说明 |
|------|------|
| **开发工具** | 开发卡片工作台时不需要硬件——模拟器提供各种数据模式 |
| **演示工具** | 给任何人演示 LinkDesk 时——不需要带 MCU 和传感器 |
| **测试工具** | 卡片工作台的自动化测试——模拟器提供可预测的输入 |
| **市场示范** | 展示"插件可以往大厅桌子写数据"——这是插件间通信的示范 |
| **依赖链** | 依赖卡片工作台（E4 后）的 serial-monitor.data table 存在 |

### 命令自动补全

```
$ sim <TAB>
  sine     — 正弦波
  random   — 随机值
  toggle   — 开关切换
  constant — 常量
  ramp     — 线性斜坡
  list     — 列出所有模拟器
  stop     — 停止指定模拟器
  stop-all — 停止全部
```

## 关键交互

| 交互 | 触发 | 行为 |
|------|------|------|
| **输入命令** | 终端输入 `sim <subcommand>` | 启动模拟数据流，打印确认信息 |
| **自动补全** | 输入 `sim ` 后按 Tab | 列出所有子命令 + 参数提示 |
| **列出活跃模拟器** | `sim list` | 表格显示所有运行中的模拟器 |
| **停止** | `sim stop <cardId>` | 停止该数据流，终端确认 |
| **数据流向卡片** | 每个周期 | 计算新值 → 写入大厅桌子 → 卡片实时更新 |
| **Tab 补全 cardId** | `sim stop <TAB>` | 列出当前活跃的 cardId |

### 支持的模拟模式

| 模式 | 命令 | 参数 | 示例 |
|------|------|------|------|
| 正弦波 | `sine` | cardId, min, max, freqHz | `sim sine temp 0 100 0.5` |
| 随机值 | `random` | cardId, min, max | `sim random humid 30 80` |
| 开关切换 | `toggle` | cardId, intervalSec | `sim toggle led 2` |
| 常量 | `constant` | cardId, value | `sim constant ref 3.3` |
| 线性斜坡 | `ramp` | cardId, min, max, step, intervalMs | `sim ramp volt 0 5 0.1 200` |
