# 媒体策展 · AI 操作手册（JSON-only）

> 适用：`marketplace.json`（目录）与 `collections[]`（槽位）；目标是**不靠鼠标、不靠拖拽**完成换槽位 / 换图 / 换价。
> 唯一入口 = **改 JSON → 刷新目录**。⛔ 拖拽画布 / 可视化编辑器不是入口（本产品没有，也不做）。
> 校验 = `@linkdesk/marketplace-kit`；商店刷新命令 = `marketplace.refreshCatalog`。

---

## 〇、三条铁律

1. **一个事实一个字段**：谁上大屏/横排 = `collections[].items`；某插件长什么样 = 该条目的 `screenshots` / `cover`；价格 = `pricing`。⛔ 在别处再写一份。
2. **换这些都不发版**：目录元数据由商店刷新即生效；只有「图打进插件包（相对路径）」才必须 bump + 重发。
3. **每次改完必须自检**（两条命令，见 §四）；坏输入**非零退出**，不许「看着像好了」。

---

## 一、三步换槽位（hero / mega / 小卡 / duo / split / wall）

**改哪里**：目录根 `marketplace.json` 的 `collections[]`（或 `collections/<id>.json`）。

1. 找合集：`collections[]` 里按下表选 `id` / `layout`。
2. 改 `items`：按显示顺序写插件 `id`（不存在的 id 会静默跳过；顺序就是屏上顺序）。
3. 自检 + 刷新：
   ```bash
   npx marketplace-kit validate ./marketplace.json
   # 商店内：执行命令 marketplace.refreshCatalog（或点「刷新内容」）
   ```

| 想换的位置 | `layout` | 看哪一行 |
|---|---|---|
| 首屏大屏轮播 | `banner` | `collections[?].items`（前 5 个 id） |
| 主题专区横排 | `mega` | `collections[?].items` |
| 装机必备小卡 | `strip` | `collections[?].items` |
| 编辑精选整行分栏 | `split` | `collections[?].items` |
| 两枚一排 | `duo` | `collections[?].items`（前 2 个） |
| 封面图墙 | `wall` | `collections[?].items` |

示例（只改 `items`，别抄整段）：

```json
{ "id": "official-hero", "title": "官方精选", "layout": "banner",
  "items": ["editor", "theme-panorama", "serial-monitor"], "order": 1 }
```

## 二、三步换图（截图 / 封面 / 视频）

**改哪里**：该插件**自己的** `marketplace.json` 条目（官方件在官方目录条目上同笔同步）。

1. 把图/视频放到**稳定 URL**：作者仓稳定分支（`…/HEAD/media/shot-1.png`）或 CDN/COS 固定 key。⛔ 版本 tag（换图=发版）、⛔ 包内相对路径（未装 404）。
2. 改条目字段：
   ```json
   "cover": "https://raw.githubusercontent.com/<owner>/<repo>/HEAD/media/cover.png",
   "screenshots": [
     { "type": "video", "url": "https://…/demo.mp4", "poster": "https://…/poster.jpg" },
     "https://raw.githubusercontent.com/<owner>/<repo>/HEAD/media/shot-1.png",
     "https://raw.githubusercontent.com/<owner>/<repo>/HEAD/media/shot-2.png"
   ]
   ```
   - 视频**至多 1 段且必须排第一**；`poster` 建议给；
   - 选帧：海报 → `cover` → 静帧；去重后**最多 3 帧**；
   - 改图后 URL 加 `?v=20261122` 绕过缓存。
3. 自检 + 刷新：
   ```bash
   npx marketplace-kit validate ./marketplace.json
   npx marketplace-kit media:resolve ./marketplace.json <插件id> --json
   # 商店内：marketplace.refreshCatalog
   ```

> `media:resolve` 打印的就是真机会用的 `kind`（video/image/generated）/ `frames` / `video`；`generated` = 走生成式封面（不是错误，但作者应知道）。

## 三、三步换价

**改哪里**：条目 `pricing`（只展示不裁决；购买走作者销售页、壳离线验签）。

1. 改 `pricing`：
   ```json
   "pricing": { "model": "paid", "price": 9.9, "currency": "CNY",
                "licenseUrl": "https://…/buy", "refundUrl": "https://…/refund", "trialDays": 14 }
   ```
2. 自检：`npx marketplace-kit validate ./marketplace.json`。
3. 刷新：`marketplace.refreshCatalog`。

> `publish` 不会抹掉作者手改的 `screenshots` / `cover` / `pricing` / `license` / `repository` / `authorId`（A2 已修并在 SDK 单测钉住）——但**每次仍要跑 validate**。

## 四、错误模板（与校验器同一套）

所有媒体错误都是同一句式：

```
文件 marketplace.json：plugins[<id>].screenshots[0] → 期望：以 https:// 开头的绝对 URL（相对路径在未装用户的机器上必 404） → 示例：https://raw.githubusercontent.com/<owner>/<repo>/HEAD/media/shot-1.png
```

| 坏输入 | 码 | 判据 |
|---|---|---|
| 相对 URL / 非 https | `screenshot-url-invalid` | error（退出码 1） |
| `http:` 明文 | `screenshot-url-invalid` | error |
| 视频不在首位 | `screenshot-video-restricted` | error |
| 多段视频 | `screenshot-video-restricted` | error |
| 缺海报 | `screenshot-poster-missing` | warning（不拦） |

## 五、AI 可读面（读状态 → 改 JSON → 刷新 → 再读）

| 动作 | 入口 |
|---|---|
| 读市场状态 | 命令 `marketplace.getState` |
| 打开某分类 | 命令 `marketplace.openCategory { category: "themes" }` |
| 打开某插件详情 | 命令 `marketplace.openPlugin { pluginId }` |
| 刷新目录 | 命令 `marketplace.refreshCatalog` |
| 媒体 dry-run | CLI `npx marketplace-kit media:resolve ./marketplace.json [id] --json` |
| 目录校验 | CLI `npx marketplace-kit validate ./` |

**验收口径**：不看源码、不拖拽、只用命令与 JSON，就能换槽位/换图/换价并在刷新后看到结果。
