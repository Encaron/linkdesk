# 01 — 全量 UI/UX 审计

> 审的范围：3 个 UI 表面 · 6 个文件 · ~2,022 行代码
> 审的维度：布局 · 配色 · 图标 · 动效 · 间距 · 字体 · 无障碍 · 响应式

---

## 严重度定义

| 标记 | 含义 | 标准 |
|------|------|------|
| 🔴 | 破坏性 | 用户困惑、无法完成任务、违反硬约束 |
| 🟡 | 一致性 | 风格断裂、与系统其他 UI 不一致 |
| 🟢 | 打磨 | 不完美但功能正常、细微改进 |

## 一、MarketplaceView（主区引导页）

**文件**：[index.tsx](../../../plugins/marketplace/src/index.tsx) (35 行) + [MarketplaceView.css](../../../plugins/marketplace/src/MarketplaceView.css) (276 行)

### 🔴 MV-1 — Emoji 🧩 作为 Hero 图标

**位置**：[index.tsx:21](../../../plugins/marketplace/src/index.tsx#L21)
**当前**：`<span className="marketplace-hero-icon">🧩</span>`
**问题**：违反 UI/UX Pro Max 硬规则——"No emojis as icons"。Emoji 在不同 OS 渲染不同（Windows 彩色、macOS 扁平、Linux 缺失）。LinkDesk 已有 codicon 字体系统。
**修复**：`<span className="codicon codicon-extensions marketplace-hero-icon" />`

### 🔴 MV-2 — 死 CSS——~150 行未使用的样式

**位置**：[MarketplaceView.css:51-276](../../../plugins/marketplace/src/MarketplaceView.css)
**当前**：文件中包含 `.marketplace-search-bar`、`.marketplace-list`、`.marketplace-row`、`.marketplace-btn`、`.marketplace-badge-core` 等大量样式，但当前 `index.tsx` 仅有 Hero 布局，完全不使用这些类。
**问题**：
1. `.marketplace-badge-core` 硬编码 `color: #fff`（违反硬约束 #1）
2. 死代码增加维护负担——改 CSS 变量时误以为已覆盖，实际这些选择器永远不会匹配
3. 与 `MarketplaceSidebar.css` 功能重叠（搜索栏、列表行），可能造成困惑
**修复**：
- 删除所有未使用样式（`.marketplace-search-bar` 到文件末尾）
- 保留 Hero 区域样式（`.marketplace-view` / `.marketplace-hero` / `.marketplace-hero-*`）
- 修复 `.marketplace-badge-core { color: #fff }` → `color: var(--badge-text, #fff)`（如果保留）

### 🟢 MV-3 — Hero 描述未利用空间

**位置**：[index.tsx:22-29](../../../plugins/marketplace/src/index.tsx#L22-L29)
**当前**：仅显示计数 + "在左侧侧栏中浏览..." 提示。
**问题**：引导页可以更有帮助——显示最近使用的插件、快捷入口等。对标 VS Code 的 Getting Started 页。
**修复**：保持现状，E3.5 仅修问题不增功能。

## 二、MarketplaceSidebar（侧栏列表）

**文件**：[sidebar.tsx](../../../plugins/marketplace/src/sidebar.tsx) (552 行) + [MarketplaceSidebar.css](../../../plugins/marketplace/src/MarketplaceSidebar.css) (360 行)

### 🔴 MS-1 — 文本字符 ✕ 作为清除按钮

**位置**：[sidebar.tsx:228](../../../plugins/marketplace/src/sidebar.tsx#L228)
**当前**：`<button className="ms-search-clear" onClick={...}>✕</button>`
**问题**：Emoji/文本图标规则——✕ 在不同字体下渲染大小不一。
**修复**：`<span className="codicon codicon-close" />`

### 🔴 MS-2 — 硬编码绿色 `#4caf50`

**位置**：[MarketplaceSidebar.css:284](../../../plugins/marketplace/src/MarketplaceSidebar.css#L284)
**当前**：`.ms-item-enable-btn { color: #4caf50; }`
**问题**：违反硬约束 #1——所有颜色走 CSS 变量。`#4caf50` 在浅色主题下可能对比度不足。
**修复**：`color: var(--accent-green, #4caf50)` 或 `var(--success, #4CAF50)`

### 🔴 MS-3 — 硬编码 rgba 绿色

**位置**：[MarketplaceSidebar.css:292-293](../../../plugins/marketplace/src/MarketplaceSidebar.css#L292-L293)
**当前**：
```css
.ms-item-enable-btn:hover {
  background: rgba(76, 175, 80, 0.1);
  border-color: rgba(76, 175, 80, 0.4);
}
```
**问题**：硬编码 `rgba(76, 175, 80, ...)`，切主题时不跟随。
**修复**：改为 CSS 变量 `var(--success-bg, rgba(76, 175, 80, 0.1))` / `var(--success-border, rgba(76, 175, 80, 0.4))`

### 🟡 MS-4 — 齿轮按钮仅 hover 显示，键盘不可达

**位置**：[MarketplaceSidebar.css:340-354](../../../plugins/marketplace/src/MarketplaceSidebar.css#L340-L354)
**当前**：
```css
.ms-item-gear-btn { opacity: 0; }
.ms-extension-item:hover .ms-item-gear-btn { opacity: 1; }
```
**问题**：键盘 Tab 导航到插件项时，齿轮按钮仍然 `opacity: 0`，用户看不到操作入口。对标 VS Code——也需要 hover 才显示，但 VS Code 有右键菜单做 fallback。LinkDesk 已有齿轮 ContextMenu，键盘用户可通过 Tab 到齿轮按钮后按 Enter 触发（按钮仍在 DOM 中只是不可见）。
**修复**：加 `:focus-visible` 和 `:focus-within` 规则：
```css
.ms-extension-item:focus-within .ms-item-gear-btn,
.ms-item-gear-btn:focus-visible { opacity: 1; }
```

### 🟡 MS-5 — 搜索框 `outline: none` 焦点指示不够明显

**位置**：[MarketplaceSidebar.css:68-73](../../../plugins/marketplace/src/MarketplaceSidebar.css#L68-L73)
**当前**：`.ms-search-box { outline: none; }` + `.ms-search-box:focus { border-color: var(--accent); }`
**问题**：仅 `border-color` 变化——深色背景下 `1px` 边框色变几乎不可察觉。键盘用户 Tab 到搜索框时无足够视觉反馈。
**修复**：加 `box-shadow: 0 0 0 1px var(--accent)` 光晕，或 `outline: 2px solid var(--accent); outline-offset: -1px;`

### 🟡 MS-6 — 多处 `:focus-visible` 缺失

**位置**：多个交互元素
**受影响的元素**：
- `.ms-install-btn` — 无 focus 样式
- `.ms-section-header` — 无 focus 样式
- `.ms-extension-item` — 无 focus 样式（`div` 角色但 `onClick`）
- `.ms-item-enable-btn` — 无 focus 样式
- `.ms-item-install-btn` — 无 focus 样式
- `.ms-search-clear` — 无 focus 样式

**修复**：全局加 `&:focus-visible { outline: 2px solid var(--accent); outline-offset: -1px; }`

### 🟡 MS-7 — 内联 `style` 硬编码值

**位置**：
- [sidebar.tsx:331](../../../plugins/marketplace/src/sidebar.tsx#L331)：`style={{ cursor: "pointer" }}`
- [sidebar.tsx:337](../../../plugins/marketplace/src/sidebar.tsx#L337)：`style={{ opacity: 0.5 }}`
- [sidebar.tsx:331](../../../plugins/marketplace/src/sidebar.tsx#L331)：`style={{ opacity: 0.6 }}`

**问题**：`opacity: 0.5` / `opacity: 0.6` 散落在 JSX 中，不可维护。`cursor: pointer` 应在 CSS 中统一设置。
**修复**：提取到 CSS 类——`.ms-item-disabled-desc`、`.ms-item-disabled-name`。

### 🟡 MS-8 — 部分区间距不一致

**位置**：[MarketplaceSidebar.css:11-16](../../../plugins/marketplace/src/MarketplaceSidebar.css#L11-L16)
**当前**：`.ms-header { padding: 5px 12px 8px 12px; }`
**问题**：上下 padding 不对称（5px top / 8px bottom），视觉上搜索框不居中。对标 VS Code Extensions header 高度 41px 有精确计算。
**修复**：改为 `padding: 8px 12px` 对称，或精确计算使 header 高度 = 41px。

### 🟢 MS-9 — 搜索框无清除按钮的过渡动画

**位置**：[MarketplaceSidebar.css:79-94](../../../plugins/marketplace/src/MarketplaceSidebar.css#L79-L94)
**当前**：清除按钮通过条件渲染 `{search && <button>}` 出现/消失，无动画。
**问题**：突然出现/消失略显生硬。
**修复**：条件渲染保留（简单可靠），不加动画（无功能影响）。

### 🟢 MS-10 — 空状态 `ms-empty` 无图标

**位置**：[MarketplaceSidebar.css:104-109](../../../plugins/marketplace/src/MarketplaceSidebar.css#L104-L109)
**当前**：`.ms-empty { text-align: center; color: var(--text-muted); }` 仅文字。
**问题**：空状态（"暂无插件"/"未找到匹配的插件"）可以加一个图标提升视觉质量。
**修复**：加 codicon 图标——`codicon-package` 表示无插件，`codicon-search` 表示无结果。

### 🟡 GL-6 — `:!important` 防御性使用

**位置**：[PluginDetailView.css:43](../../../src/components/views/PluginDetailView.css#L43)
**当前**：`.pd-icon-codicon { font-size: 96px !important; }`
**问题**：`!important` 通常意味着选择器优先级问题。`.pd-icon-codicon` 是单类选择器，如果被覆盖说明其他样式特异度更高。
**修复**：审计是否有其他样式覆盖了 `font-size`。如果没有 → 去掉 `!important`。如果有 → 提高选择器特异度（如 `.pd-header .pd-icon-codicon`）。

### 🟡 GL-7 — 插件列表项 `div` 做可点击元素无 ARIA

**位置**：[sidebar.tsx:507](../../../plugins/marketplace/src/sidebar.tsx#L507)
**当前**：`<div className="ms-extension-item" onClick={handleClick}>` —— 用 `<div>` 做点击，无 `role`/`tabindex`/`aria-label`。
**问题**：屏幕阅读器将此元素视为普通 div，不朗读为可交互控件。键盘 Tab 跳过此元素（div 默认无 tabindex）。
**修复**：加 `role="button"` + `tabIndex={0}` + `aria-label={m.name}` + `onKeyDown`（Enter 触发 onClick）。

### 🟢 GL-8 — `useMemo` 随 `lifecycleVersion` 变化但可能过时

**位置**：[PluginDetailView.tsx:52-55](../../../src/components/views/PluginDetailView.tsx#L52-L55)
**当前**：`const installedIds = useMemo(() => new Set(getLoadedPluginManifests().map(...)), [lifecycleVersion]);`
**问题**：`lifecycleVersion` 通过 `onPluginLifecycleChange.event` 更新，但 `useCallback` 依赖数组中有 `[lifecycleVersion]`——effect 的 cleanup 可能注册了新的 listener 而旧的未清理。实际上代码用了 `onPluginLifecycleChange.event()` 返回 unsubscribe，在 cleanup 中调用——没问题。这个 useMemo 依赖正确。
**结论**：逻辑正确，不改。
