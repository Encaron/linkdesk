1. **插件轴**：市场插件 `plugin.json` PATCH → build → publish → **官方目录收录** → `sync:bundled`。
2. **npm 轴**：SDK/kit/contracts 的**累积待发面一次发**（含 toasts 契约）＋ **ui 黄灯灭**（判据⑤：`packages/linkdesk-ui` bump → `npm install` 同步 lock → publish → `release:mark`——Button.css 注释漂移在账）。
3. **软件本体随批发版（发版定义 = CLAUDE.md 硬约束 24——⛔ 不是造出 Release 就算完）**：
   - 攒批版本以当时 `package.json` 为准（0.2.55 起）→ CHANGELOG 段核对（**累计摘要**：上一发布版到本版之间跳过的每段首行并入——发布清单 §一）；
   - tag `v{version}`（推带代理 127.0.0.1:7890）→ CI 出安装包 → **Release 资产齐**；
   - 🔴 **决定性验收**：在你自己电脑的**旧版软件**里点「检查更新」→ 真下载 → 真装上 → 版本号到新——没走到这一步不算发版；
   - 发布判据①③⑤与发行说明对账照 [发布清单 §一](../../../../06-发布管理/发布清单.md)；预演钩子（pre-push-release-rehearsal）必须 `use_stdin: true`。
