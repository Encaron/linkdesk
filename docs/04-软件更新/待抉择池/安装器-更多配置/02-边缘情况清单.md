# 02 · 边缘情况清单（安装器容器）

> 逐条给「**期望 / 现况 / 谁保证**」。**实现时每满足一条，回 [04-任务清单.md](04-任务清单.md) 打勾。**
> E1–E8、E39 是**从旧档搬来的**（它们当初就已经落对过，值得原样保留）；E40 起是**本轮新增**。

---

## 一、紧凑态 ↔ 容器态 的来回（用户点名的老问题，一字不改地留着）

**E1 · 欢迎屏勾了四项 → 进容器**
- 期望：四项**带过去，就是勾上的**（用户旧原话：「我在前一个页面把四个都勾了，那么跳转到更多配置页面，那四个应该是勾上的」）
- 现况：✅ 旧实现已落对（紧凑态与容器态**读同一份**勾选对象）
- 谁保证：单源——改哪边都写回它；两边进入时都重画。**⛔ 重做时不许退回"两处各记"。**

**E2 · 在容器里改了勾选 → 返回紧凑态**
- 期望：反向也同步（紧凑态那四项跟着变），不是只想一个方向
- 现况：✅ 同上（单源，双向自动一致）
- 谁保证：同上

**E3 · 容器态要有返回**
- 期望：**必须有**，且退回**欢迎屏的紧凑态**（不是退到别的屏）；勾选与已填路径都不能丢
- 现况：⏳ 本轮做
- 谁保证：容器底部的「返回」= 与「自定义安装」的收起**同一个出口**（⛔ 不写两条逻辑）

**E4 · 容器态按 Esc**
- 期望：**退一层 = 回紧凑态**（不是关掉安装程序）
- 现况：⏳ 本轮做（旧实现落对过，照抄）
- 谁保证：键盘处理里对容器态单独分支

**E5 · 右上角 ✕ ／ Alt+F4**
- 期望：**仍然关窗口**（这是"退出安装"的意思，跟 Esc 不同）
- 现况：✅ 窗口级处理**不动**；只有 Esc 被细分
- 谁保证：别去碰窗口级逻辑

**E6 · 返回后输入框里的路径还在吗**
- 期望：在（不能白填）
- 现况：⏳ 本轮做（旧实现落对过：路径存 `uiPath`/`uiCache`，控件受控回填，**不靠 DOM 自己记**）
- 谁保证：§五 单源规则的落点

**E7 · 在容器里直接点「继续安装」**
- 期望：跟欢迎屏点「立即安装」**一样**（用同一份勾选 ＋ 同一份路径），不是两条路
- 现况：⏳ 本轮做
- 谁保证：两处**同一个 `beginInstall()`**，`data-primary` 同一个出口

**E8 · 未勾 PATH 的话，装完要不要提示"重启终端"**
- 期望：勾了才提；没勾不提
- 现况：🔵 待拍板（文案归属）
- 谁保证：—

**E39 · 容器里的「继续安装」缺「继续即同意许可协议」告知**
- 期望：容器里也有「继续安装」，**和欢迎屏一样要有那行法律告知**（否则从容器直接装下去的用户**没被告知过**）；或者明确决定"告知留在欢迎屏、子态不重复"
- 现况：⚠️ 该行 `.foot` 住在欢迎屏动作行里（`margin-left:auto` 贴右）；**要不要在容器态再露一次**＝ [04-任务清单.md](04-任务清单.md) 决策点
- 谁保证：⛔ 待用户定（旧档 D6）

## 二、本轮新增（容器特有的）

**E40 · 「随包安装的插件」组**（今天没有数据源）
- 期望：组**先立着**（用户要求提前规划分组），但**不许**空着一个秃标题让人困惑
- 现况：⏳ **待用户定**：① 空时**整组隐藏**；② 空时显示标题 ＋ 一行「（本次安装包未随带可选插件）」；③ 组先不出现、等有数据再说（**与用户"提前规划"的意图抵触，不推荐**）
- 谁保证：—

**E41 · 容器要能滚，且滚动条不挡内容**
- 期望：项多了往下排、能滚；**最后一行的"继续安装"永远够得着**（动作行**不进滚动区**，常驻底部）
- 现况：⏳ 本轮做（产品源**今天没有滚动容器**——这是第一处，得新造）
- 谁保证：动作行在滚动层**之外**；滚动层 `min-height:0`（否则 flex 子项不肯收缩、滚不起来）

**E42 · 权限项被关掉之后**
- 期望：关掉就得**如实说少了什么**（例：不勾 PATH ⇒ 终端里打不开 `linkdesk`），⛔ **不许**在别的屏又偷偷加回去
- 现况：⚠️ 今天只在欢迎屏有一句「重启终端后生效」；**关掉后的后果说明不完整**
- 谁保证：文案归 [04-任务清单.md](04-任务清单.md) 决策点（**不阻塞出图**）

**E43 · 切语言时容器里已填的值**
- 期望：文案全变，**输入框里已填的路径一个字不变**、勾选态不变
- 现况：⏳ 本轮做（旧实现落对过：**文案与值分离**）
- 谁保证：单源 ＋ i18n 只管文案

**E44 · 滚到一半切走再回来**
- 期望：**要么记住位置、要么回到顶部——但必须固定一种**（不许"这次记、下次不记"）
- 现况：🔵 **本夹定：每次进容器都回顶部**（`scrollTop = 0`）——清单不长（三组十来项），记住"上次滚到一半"反而让人以为上面还藏着内容
- 谁保证：进容器时显式置零；⛔ 别改成"记住位置"又不写在实现注释里（见 [04-任务清单.md](04-任务清单.md) C6）

**E45 · 快速连点「更多配置」／「自定义安装」**
- 期望：**不闪、不叠、不出现半展开的中间态**；动画在跑时不响应第二次（或在跑完就近收敛）
- 现况：⏳ 本轮做
- 谁保证：动画期间加锁（照壳内既有做法）

**E46 · 屏幕小 / 高 DPI 缩放后容器不够高**
- 期望：动作行仍可见（它常驻底部），清单可滚 ⇒ **任何高度下"继续安装"都能点**
- 现况：⏳ 本轮做
- 谁保证：同上（滚动层 ＋ 常驻动作行）

**E47 · 容器态按 Enter**
- 期望：Enter = **看得见的**那颗主按钮（＝「继续安装」），不是已经被盖住的「立即安装」
- 现况：⏳ 本轮做（现实现查的是 `$('.scr.on [data-primary]')`，这条查询**不看可见性**）
- 谁保证：进容器时把 `data-primary` 从「立即安装」搬到「继续安装」，退出时搬回——**只切这一处**，⛔ 不改键盘那条共用逻辑

**E48 · 进了容器，用户怎么知道"我在哪"**
- 期望：品牌行与英雄区被面板盖住之后，**页内得有一句自己的标题**（「更多配置」），否则像误闯进来
- 现况：⏳ 本轮做（设计图 [05-设计图-更多配置容器.html](05-设计图-更多配置容器.html) 顶部那句就是它）
- 谁保证：容器标题 ＋ 三组二级标题（[01-容器规格.md](01-容器规格.md) §二）

**E49 · 容器是"整页变"，✕ 与语言药丸还在吗**
- 期望：**在**。容器不是关不掉的模式——✕ 照旧关窗、语言照旧能切，且切语言时已填路径与勾选态一字不变（与 E43 一条心）
- 现况：⏳ 本轮做（两者挂在 `.win` **之外**的 `.frame` 上 ⇒ 面板天然盖不到）
- 谁保证：别把面板的 `inset` 扩到 `.frame`
