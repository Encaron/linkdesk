# 02 — 设计方向

> 2026-07-29。基于全量审计 + UI/UX Pro Max 设计系统。

## 设计原则（UI/UX Pro Max 输出）

| 原则 | 来源 | 如何应用 |
|------|------|---------|
| **No emojis as icons** | Style §4, Pre-Delivery Checklist | 全部 emoji → codicon 字体图标 |
| **Hover states 150-300ms** | Pre-Delivery Checklist | 所有交互过渡统一 `transition: 120-200ms` |
| **Focus states visible** | Accessibility §1, Checklist | 全局 `:focus-visible { outline: 2px solid var(--accent) }` |
| **Don't rely only on hover** | UX §Animation: Hover vs Tap | 齿轮 `:focus-within` 补键盘可达 |
| **cursor-pointer on clickable** | Pre-Delivery Checklist | 所有可点击元素补 `cursor: pointer` |
| **prefers-reduced-motion** | Pre-Delivery Checklist | 动画包在 `@media (prefers-reduced-motion: no-preference)` |
| **Density: 8 (Dense/Dashboard)** | Design Dial | 保持当前紧凑间距，不刻意增加空白 |
| **Motion: 2 (Subtle)** | Design Dial | 仅微交互——fade/color 过渡，不 scale/translate |

## 新增 CSS 变量

LinkDesk 已有 `--error` / `--warning`，缺 `--success` 系列。在 `src/index.css` 的 `:root` 和 `[data-theme="light"]` 中新增：

### 暗色主题

```css
/* E3.5 插件市场美化 —— 状态色补全 */
--success: #4CAF50;
--success-bg: rgba(76, 175, 80, 0.1);
--success-border: rgba(76, 175, 80, 0.4);
--error-border: rgba(224, 108, 117, 0.5);
--warning-border: rgba(204, 167, 0, 0.5);
```

### 浅色主题

```css
/* E3.5 插件市场美化 —— 状态色补全 */
--success: #388A34;
--success-bg: rgba(56, 138, 52, 0.08);
--success-border: rgba(56, 138, 52, 0.35);
--error-border: rgba(224, 108, 117, 0.5);
--warning-border: rgba(212, 160, 23, 0.5);
```

> 浅色主题下 `--success` 用 `#388A34` 对比度 4.7:1（白底），满足 WCAG AA。

## 不变项

不在 E3.5 范围内：
- ❌ 不改 MarketplaceView 死代码（不可达）
- ❌ 不改操作逻辑（单击/双击计时器、启用/禁用/卸载流程、齿轮菜单注册）
- ❌ 不改 i18n key（仅修改 JSX 结构——加 `<span>` 元素）
- ❌ 不拆分 CSS 文件（E3.5 范围外——延后到所有 UI 改动完成）
