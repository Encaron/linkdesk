# 08-持久化与配置（workspace.json 全表 + 迁移）

> **状态：** 提案（2026-08-23 起草）——app.* key 是设置层落地，随 05 schema 拍板。

> **dependsOn 机制复用**（[04 §3](04-两层调节与设置页.md)）：SettingRow 已支持 `if (prop.dependsOn && depValue !== prop.dependsOn.value) return null`——`appearanceMode=custom` 时 6 行覆盖出现，`followTheme` 消失。混搭同理。
> **onApply 接线**：每 key 在 startup.ts `registerConfiguration` 绑定 apply → 主进程 ThemeEngine 重新合并 → 广播 `theme:changed`（#50.10 已有雏形，本表补全）。

## 2. 播种先例（appearanceMode → custom）

对标现有 accentMode→custom 的真实代码（startup.ts L101-105：读当前 DOM `--accent` 播种 `app.accentColor`）：

> 用户切 `appearanceMode: custom` 的瞬间，把**当前生效值**（来自配方）播种进 6 个覆盖 key——不是从 0/默认值开始。否则一开覆盖，玻璃归零、圆角回 1×，配方被「重置」。

```
appearanceMode: followTheme → custom
  → 读 ThemeEngine.getEffectiveTokens()（[06](06-主题API契约.md)）
  → app.surfaceRadius = 当前 --radius-md / 配方半径 …（反向除 scale）
  → app.glassBlur = 当前 --glass-blur（配方值）
  → …6 项全播种
```

用户动 slider = 覆盖配方值（绝对）；切回 followTheme = 覆盖丢弃回配方。**设置层永远只存用户偏离量**，配方是默认。

## 3. scale vs 绝对——粒度决策（拍板 2026-08-23 提案）

| 项 | 粒度 | 理由 |
|:--|:--|:--|
| 圆角 | **scale 系数**（×0.5–2） | 八档有**层级差异**（xs→2xl），乘算保留相对差异，一个 slider 整体缩放（[04 §4](04-两层调节与设置页.md)） |
| 玻璃 | **绝对覆盖**（blur px / opacity / tint） | `--glass-*` 是连续单值，无 per-surface 档位可缩放；用户心智 =「拉模糊到 18」 |

> 修订说明：04 §4 拍板时玻璃也是 scale；本文档精化为「玻璃走绝对」——玻璃没有八档语义，scale 无意义，绝对覆盖更直观。#50.10 的 `app.glassBlur` 键名本就是 px 语义，与本文一致。

## 4. 迁移表

| 现状 | 迁移后 | 处理 |
|:--|:--|:--|
| `app.theme: "Dark"` / `"Light"` | `"dark"` / `"light"`（壳内置配方 id） | 启动时旧值归一化（映射表），不弹窗不重置 |
| `app.theme: "mint-soda"` 等主题 json 名 | 配方 id（json 文件加 `id` 字段） | 读时归一化（[05 §5](05-主题数据模型.md)），id 缺省 = 文件名 |
| 主题插件 4 json → 1 配方 | 迁移合并（决策 F） | 引擎**只读 `colorways[]`**（无旧格式兼容）；现有插件数据改造（[05 §5](05-主题数据模型.md)） |
| 无 `app.accentColor` 影响 | 不动 | 强调色机制与主题 token 共存（[04 §6](04-两层调节与设置页.md)） |

## 5. 设置页组归属（拍板 2026-08-23 决策 D）

- **拍板：** 壳注册**第二个配置贡献**（独立 pluginId `"appearance"`，标题「主题」），主题组 key 全挂它——设置页左侧导航天然多一组（ConfigurationRegistry 派生，一 pluginId = 一组，[04 §5](04-两层调节与设置页.md)）。
- 代价：`app.theme` 从「通用」组迁到「主题」组 = 配置归属变更（值不变，仅分组）。
- 备选（弃）：并入「通用」组（少一组，但主题区 17 key 挤在通用区尾部，违背 [04 §5](04-两层调节与设置页.md) 独立建区拍板）。
