# Data Playground（数据演示器）

> **出厂演示资源**——预置 demo workspace JSON，随软件分发；不是独立插件，归入插件更新目录是因为它消费卡片工作台插件的能力。旧「出厂资源 / 排序 0/11」标记作废（2026-09-13 重组）。
> **状态：⏸️ 推迟到快发布时做**
> 原因：依赖卡片工作台（E4 后）。但它是"开幕雷击"——用户第一次打开就看到完整能力。

---

## 基本逻辑

一个预置的 demo workspace JSON 文件。用户第一次打开 LinkDesk 时，画布上已经摆好 6 张卡片——温度计在跳、波形在跑、指示灯在闪。全是模拟数据，不需要任何硬件。

右下角半透明提示条："📡 模拟数据 · 连接设备后自动切换"。

**核心原则：** 不是"有个 demo"——是**第一次打开就是 demo**。空壳打开 = 用户走了。

---

## 处于软件内位置

```
LinkDesk 启动
  └─ 检查是否有 workspace 文件
       ├─ 无 → 加载 Data Playground（预置 demo workspace JSON）
       └─ 有 → 加载用户上次的 workspace
```

- **文件位置：** `resources/demo-workspace.json`（打包时内置）
- **加载时机：** 首次启动 / workspace 为空时
- **切换机制：** 连接真实设备后自动替换数据源

## 关键交互

| 交互 | 描述 |
|------|------|
| **首次启动** | 自动加载 demo workspace，6 张卡片带模拟数据动画 |
| **数据动画** | 温度数字跳动、波形流淌、指示灯闪烁——不是静态摆放 |
| **提示条** | 右下角半透明浮层，3 秒后自动淡出到 30% 透明度 |
| **连接设备** | 检测到真实串口数据 → 提示条变为"已切换到真实数据" → 卡片数据源切换 |
| **用户操作** | 用户可以拖拽卡片、删除卡片、添加新卡片——demo 不锁定画布 |
| **主题跟随** | 画布上所有卡片跟随当前主题配色 |
