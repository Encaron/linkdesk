## 二、判据最终措辞（🔴 **照抄，不许改口气**）

### 2.1 账的新形状（账的家族裁决结果）

```jsonc
// scripts/host-reserved.json（SDK 副本 / 运行时副本 同源产出）
"appearanceRecipeIds":    ["dark", "light"],                    // 宿主兜底配方 id
"appearanceColorwayIds":  ["dark-fallback", "light"],           // 宿主兜底配色 id
"appearanceIconThemeIds": ["default"],                          // 图标主题保底哨兵
"appearanceSentinels":    ["followTheme"],                      // 混搭来源哨兵（app.themeColor / app.mix*）
"appearanceIdGrants":     { "light": ["theme-defaults"] }       // id → 宿主之外的**正当持有者**
```

- 🔴 **旧栏 `appearanceIds` 拆掉、不留**：它今天**无任何消费方**（`command-ownership.ts:56-63` 明写「不读也不删」）⇒ **现在拆零代价**；一旦 1.37/1.38 按错口径消费了它，拆就要动消费方（[1.35 §15.1](05-任务-外观族id归属评估.md)）。
- 🔴 **`appearanceIdGrants` 不是白名单**（禁区）：它**按 id 记证照**，不记「哪些仓被宽恕」⇒ **新插件永远不在表里，永远判红**。这是 1.34「归属从身份来」的同构。
- 🔴 **为什么必须拆 ＋ 必须记持有者**：不拆 ⇒ `theme-defaults` 的**配色 id `dark`** 撞进配方栏 ⇒ **官方仓当场假红**；不记持有者 ⇒ `theme-defaults` 声明 `light`（它是宿主兜底的**官方实现者**）也判红 ⇒ **两条假红**（宽容度模型：**假红会让真红失效**）。

## 四、禁区

- 🔴 🔴 **不许碰主题机制**：`commitTokens` · `theme:changed` 广播链 · `preload-pool` 写池 `:root` · `#ld-float-layer` · `[data-theme="light"]` · 域表 / 混搭 / 配方键 —— [29 号档](../样式命名空间归一化/29-主题系统保护条款.md) §一 P1–P7 ＋ §二「**唯一的真危险**」逐行适用。**发现自己那条规则会冻死主题系统 ⇒ 当场改规则，不许照做。**
- 🔴 **不许给 `check-theme-audit` / `check-theme-schema` / `check-font-scale-audit` 顺手收紧**（[29 号档](../样式命名空间归一化/29-主题系统保护条款.md) §六）。⚠️ **例外**：§2.6 的**口径 bug 修正**是修错不是收紧，**必须做**。
- 🔴 **不许合并主题两本账**（[1.35 §11.1](05-任务-外观族id归属评估.md) 已裁决）。**但必须登记「两本账的键不是同一个字段」**（一本 = `id`，一本 = 显示名 `label`）＋ 两侧**共用同一归属判据**。
- 🔴 **不许抛错**（[00 §2.7](00-整理档案.md)）。
- 🔴 **必须改名存量 25 条 ＋ 同笔写五键迁移**；🔴 **只改名字不写迁移 = 半成品**。
- 🔴 **不许改图标主题 id**（§2.5 —— 可见文字变化）；🔴 **不许改语言包 id / `langDefs[].id`**；🔴 **不许改 `label`/`name`/文件名**。
- 🔴 **不许把 token（`--*`）拉进来**（CSS 系列件 6 的射程——重复开工 = 两个会话撞车）。
- 🔴 **不许引白名单 / 基线 / 棘轮**（`appearanceIdGrants` 是按 id 的**证照**，不是「被宽恕的仓名单」）。
- 🔴 **不许把「黄灯」写成「红」**（判据 ④ 存量反例就是证据；假红会让真红失效）。
- ⚠️ **上位约束**：**操作体验零变化**（§〇c：名字可变，取值与功能不许变；**主题 / 字体 / 翻译三条横切零回归**是硬判据）· 只做加法且名字一次定对 · [29 号档](../样式命名空间归一化/29-主题系统保护条款.md) 优先 · 对外宽容。
- ⚠️ 照旧：不跳 `npm run check` · 推前现测代理 · 推完 `ls-remote` 对 SHA · **提交只按路径 `git add <本格文件>`**（⛔ 禁 `git add -A` / `git add .`）。
