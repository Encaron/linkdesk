# UI 合规——间距 4px 节奏 + 动画 ≤300ms

> 2026-08-06。E5 收尾 UI/UX 审计。
> 位于 E5 收尾 → `05-收尾/UI合规/`

---

## 一、问题

部分间距不在 4px 节奏刻度上，个别动画超过 300ms 上限。

**UI/UX Pro Max 规则：**
- 间距走 4px 节奏：4 / 8 / 12 / 16 / 20 / 24 / 28 / 32
- 动画走 150-300ms，不超 300ms

---

## 二、审计

### 间距违规

需要全量扫描 `src/**/*.css`：

```bash
grep -rE '\b(10|14|18|22|26|30)px\b' src/**/*.css
```

**常见问题：**
- `10px` → 不在刻度上 → 应为 `8px` 或 `12px`
- `14px` → 不在刻度上 → 应为 `12px` 或 `16px`
- `gap: 10px` / `padding: 14px` 等

**注意：** 字体大小（`font-size`）不在此列——字体走自己的视觉比例。`border-radius` 也不在 4px 节奏约束中。

### 动画违规

```bash
grep -rE '\b[3-9][0-9]{2}ms\b' src/**/*.css
```

**已知违规：**
- `tab-drop-pulse` 动画 `600ms` — 超过 300ms 上限

---

## 三、修复方案

### 间距

```
10px → 8px 或 12px（上下文决定——内间距偏紧用 8，外间距偏松用 12）
14px → 12px 或 16px
18px → 16px 或 20px
```

逐个文件手动改——不可批量替换。同文件中 `10px` 可能一个是 padding 一个是 font-size，只改结构间距。

### 动画

```css
/* tab-drop-pulse 改前 */
animation: tab-drop-pulse 600ms ease-in-out;

/* 改后 */
animation: tab-drop-pulse 250ms ease-in-out;
```

---

## 四、可能遇到的问题

### 1. 间距改后视觉偏移

**风险：** 改 `10px → 8px` 可能让元素显得太紧，`14px → 16px` 太松。

**缓解：** 优先偏向"紧"的方向——间距宁可稍紧不可太松。回顾时用 `git diff` 逐文件确认。

### 2. 动画缩短后感觉太急

**风险：** `600ms → 250ms` 脉冲动画可能失去"呼吸感"。

**缓解：** 250ms 是 UI/UX Pro Max 推荐上限——对标 Material Design 的 `standard-decelerate`。如果确实需要更长，用 300ms（上限）。

### 3. 搜索遗漏

**风险：** grep 可能漏掉 inline style 或 JS 中的动画。

**缓解：**
```bash
# 额外扫描 inline style
grep -rE 'transition|animation' src/**/*.tsx | grep -E '[3-9][0-9]{2}ms'
```
