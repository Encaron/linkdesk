# 同一版本连跑两遍（差异只在**窗口有没有被 OS 聚焦**，见下面的机制说明）；两遍都 24/24。
# 机制（实测，写下来免得下一棒当回归）:
#   · Enter 的监听在**面板**上、Escape 的监听在 window 上 ⇒ 键事件打给谁，取决于页面聚焦态：
#     docFocus=true 时 CDP 真按键的 target = 聚焦元素（面板）⇒ Enter 生效；docFocus=false 时 target = BODY
#     ⇒ Enter 打不到（Escape 照样生效）。⇒ 真用户按 Enter 天然是聚焦窗，不受影响；
#     验收器在窗未聚焦时降级 DOM 合成 KeyboardEvent（仍不碰鼠标），读数如实标 dom。
#   · 门就绪 ≠ 门出现：DialogHost 收到 show 后 50ms 才 focus 面板 ⇒ 验收器等到焦点落上面板再打字。
#   · 面板消失晚 1–2 帧 ⇒ 「门已收」是轮询读数（≤2.5s），⛔ 不是 0ms 快照。
