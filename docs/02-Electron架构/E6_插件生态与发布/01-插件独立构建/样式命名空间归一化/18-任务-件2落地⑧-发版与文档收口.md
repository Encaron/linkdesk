1. **bump** `packages/plugin-sdk/package.json`（PATCH：判据逻辑新增 ⇒ 不是数据变，语义上是 `feat`+PATCH，按 package 惯例走 PATCH）＋ `CHANGELOG` 同笔。

5. 等货架复制（**约 3 分钟，且各包不同时到**）⇒ `npm view @linkdesk/plugin-sdk version` 拿到新号 ⇒ `npm run release:mark`（记基线，**黄灯必须灭**）。

7. **插件仓跟进**：18 仓各 `npm install` 拉新 SDK（lock 更新）→ **逐仓 `npm run verify` 必须绿**（这是「SDK 发布没有把谁打红」的实证）。⚠️ 只写本地容器；推送已授权但**按仓一笔一提交**。
   - 🔴 **本条命令已于 2026-09-16 实测定正（⑧ 现场）**：**`npm install` 拉不动**——旧 `package-lock.json` 钉的 `0.1.21` **仍然满足** `^0.1.19`，npm 于是把它**原样保留**（file-tree 实测：`npm install` 跑完 lock 零改动、`node_modules` 仍是 `0.1.21`、`git status` 干净）。**正确命令 = `npm update @linkdesk/plugin-sdk --registry=https://registry.npmjs.org`**（18 仓 `0.1.21 → 0.1.23`，逐仓**只** `package-lock.json` 变）。⚠️ 这与 §〇 记的「CI 跑 `npm ci`、lock 不刷就吃不到新腿」是**两个不同的假绿来源**：一个说「不发就被吃到」，一个说「发了也不一定被吃到」——**都必须现场证明**（见下条）。
