## 三、每一行的格式（两段式）

```markdown
- [短标题](文件名.md) — 一句话钩子（≤ 40 字，只说"什么时候该点开它"）
```

**规则：**
1. **一行一个文件**；**次级条目**（非 🔥 级、但值得留在入口的）**允许两文件合一行**（批次 7 松绑，上限 2 个链接）。
2. 钩子写**触发条件**，不写内容摘要——例：「**加文件前必读**」优于「壳目录规范说明」。
3. 工程文档（`../docs/...`）**最多保留 3 条**（进度真相源 / E6 清单 / version-bump skill），其余删掉——记忆库引用工程文档会随工程移动而腐烂。
4. 同族文件合并后**只出现合并文件**，原文件名不得再出现。
5. 🔥 标记只保留三级以内（`🔥🔥🔥` 封顶），禁止 `🔥🔥🔥🔥🔥🔥`。

## 四、重写后的自检（机械可验）

## 五、记忆文件自身的书写规范（重写索引时一并统一）

- frontmatter 保留 `name` / `description` / `type`；`originSessionId` 可留可删（无检索价值）。
- `description` 必须写**触发条件**而非内容摘要——它是未来 AI 决定"要不要读"的唯一依据。
- 文件顶部若来自合并，加一行：`> 本文件合并自：a.md / b.md / c.md`
- 禁止在记忆文件里复制工程文档全文——**只留结论 + 指针**。这条是本批整理最重要的长期收益。
