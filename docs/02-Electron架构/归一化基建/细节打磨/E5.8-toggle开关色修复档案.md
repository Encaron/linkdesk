# E5.8 toggle 开关 ON 态糊色修复档案（#144）

> 2026-08-27 用户实机报 + 立案。对应清单任务：E5.8#144（Phase 11.22 一般 bug）。本文档 = 根因侦察 + 修复方案真相源。

---

## 一句话

**toggle 开关 ON 态「轨道 = 旋钮」同色，开关打开后整个糊成一团看不到圆点。** 4 个新主题（终端机/宋体/胶囊/全景）全中；薄荷苏打/暮色森林当初好是碰巧可读非机制保证。根因两层：主题数据 `toggle-knob-on` 设成与 `accent` 同值 + 机制 fallback 语义错误缺契约。

---

## 症状

- **OFF 态永远正常**：轨道 `var(--border)`（深色）+ 旋钮 `var(--toggle-knob)`（浅色）→ 天然有区分度
- **ON 态糊**：轨道 `var(--accent)` + 旋钮 `var(--toggle-knob-on)` → 4 主题把两者设成同色 → 整团淹掉
- 用户记忆：早前对「薄荷苏打」「暮色森林」做过颜色重设设好了，但如今验证主题系统的新主题全糊 → 怀疑机制问题

---

## 根因（file:line 实锤）

### 机制层（index.css:203-217）

```css
.toggle.on { background: var(--accent); }
.toggle.on::after {
  background: var(--toggle-knob-on, var(--toggle-knob));  /* ← index.css:216 */
}
```

- ON 态轨道 = `var(--accent)`
- ON 态旋钮 = `var(--toggle-knob-on, var(--toggle-knob))`
- **缺省 fallback 到 OFF 态旋钮色 `--toggle-knob`**——语义错误：`--toggle-knob` 是为「在 border 色轨道上可见」设计的，ON 轨道是 accent，两者可能同系
- **没有任何机制保证「ON 旋钮与 accent 可区分」**——这就是「一劳永逸」该补的洞

### 数据层（4 主题全中：toggle-knob-on = accent 同值）

| 主题 | 文件 | accent | toggle-knob-on | ON 态结果 |
|:--|:--|:--|:--|:--|
| 终端机 | theme-terminal/themes/terminal-monofont.json:23,30 | `#00E676` | `#00E676` | ❌ 同色糊 |
| 宋体 | theme-songti/themes/songti-print.json | `#4A463E` | `#4A463E` | ❌ 同色糊 |
| 胶囊 | theme-pill/themes/pill-bubble.json | `#D6336C` | `#D6336C` | ❌ 同色糊 |
| 全景 | theme-panorama/themes/panorama.json | `#FFB85C` | `#FFB85C` | ❌ 同色糊 |

### 为什么薄荷苏打/暮色森林当初「设好了」

| 主题 | toggle-knob | toggle-knob-on | 为什么可读 |
|:--|:--|:--|:--|
| 薄荷苏打 mint-soda.json:26-27 | `#6B4AE0` | `#FFFFFF`（显式设白） | 显式设了可读色 |
| 暮色森林 twilight-forest.json:38 | `#FFFFFF` | （**未设**） | 缺省 fallback 到白旋钮，碰巧与 accent 有对比 |

两例都是**碰巧可读**，不是机制保证。

## 修复方案

### ① 机制层（根治——以后忘设也不糊）

`index.css:216` fallback 从「OFF 旋钮色」改为「accent 上可读文字色」：

```css
.toggle.on::after {
  background: var(--toggle-knob-on, var(--text-on-accent, #FFFFFF));
}
```

`--text-on-accent` 语义 = 「accent 上的可读色」（薄荷苏打 `#FFFFFF`、终端机 `#0C0C0C`）。用它做旋钮：accent 深→亮旋钮、accent 亮→暗旋钮，**永远可区分**。

### ② 数据层（修现有错值）

4 主题 `toggle-knob-on` 从 `=accent` 改为 `=text-on-accent` 值（或删键走 ① fallback）。

### ③ 缺键补全

`defaults.json`（亮/暗保底）缺 `text-on-accent`（现缺失）——补上（亮 `#FFFFFF` / 暗 `#FFFFFF`）。

> **暗色修正（2026-08-27 用户拍板）：** 原拟暗 `#0C0C0C`，但 dark accent `#0E639C`（深蓝）上近黑旋钮对比度 ~2.1:1 几乎不可见、恰重现糊色；`#FFFFFF` 对比度 ~5.2:1 清晰可读。用户实机确认后拍板保持 `#FFFFFF`，档案同步。

### ④ 机械审查（2026-08-27 用户拍板：加）

audit 脚本加一条「`toggle-knob-on` 不得与 `accent` 同色」校验 → 未来主题作者写错被 `npm run check` 拦下。与 #130（CSS 消费面审计门禁）同族——**主题数据层防回潮**：机制 fallback 兜底「当前」，④ 兜底「未来」，否则新主题再写同值 = 复发用户实机才发现。
