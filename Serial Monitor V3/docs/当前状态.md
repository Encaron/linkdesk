## 一、项目概况

V3 是 V2 的重架构——保持 V2 全部功能，底盘从 WPF .NET 8 换成 Tauri + React。

| | V2 | V3 |
|------|------|------|
| 框架 | WPF .NET 8 | Tauri v2 + React 18 + TypeScript |
| 接收区 | AvalonEdit | CodeMirror 6 |
| 发送栏 | 多行 TextBox | Monaco Editor 单行 |
| 主题 | DynamicResource | CSS 变量 21 色 |
| 双语 | 自研 T() 函数 | react-i18next `t()` |
| 串口 | C# SerialPort | Rust serialport + tokio |
| 协议 | `[type, subType, ...]` | `[卡片ID, 字段...]` |

## 二、已完成功能

### 终端视图

- CM6 只读接收区，等宽字体，行号显示
- 三色行：接收白色 / 发送蓝色 / 系统消息灰色
- Monaco 单行发送栏，`>` 命令前缀，Enter 发送
- 快捷发送药丸按钮（AT / AT+CWLAP / AT+CWJAP）
- 侧栏设置：时间戳格式 / 消息回显 / 行号 / 系统消息独立显示 / 换行符 / 定时发送 / 发送后清空 / 编码
- 所有设置**真实生效**（走 React Context 共享状态）
- 搜索（CM6 原生面板，按钮 toggle + 蓝色高亮同步）
- 暂停（实时计数，缓冲 2000 条上限，恢复回放）
- 导出日志（`showSaveFilePicker` API）
- 行数上限裁剪（2000 行 → 砍 500）
- "↓ 回到底部"浮动按钮

### 布局

- 3 行 × 3 列骨架（和 V2 一致）
- 顶栏：串口选择 / 波特率 / 打开按钮（绿点）+ 中/EN / ☀ / ?
- 图标栏：📟 终端 / 📊 工作台 / ⚙ 设置，选中蓝条 + 光晕
- 侧栏：220px 默认，160-520px 可拖拽，28px 折叠
- 状态栏：连接绿点 + TX/RX 计数
- 点 ⚙ 设置不改变上一次内容视图（和 V2 `_previousContentTab` 同逻辑）

### 基础设施（V2.6 教训）

- **CSS 变量 21 色**：所有颜色走 `var(--xxx)`，禁止硬编码 hex
- **react-i18next `t()`**：全部 UI 文字走翻译函数，`en.json` 已就绪（45 条映射）
- **归一化 `.form-row`**：标签+控件行强制对齐，`space-between` 错位从根源消灭
- **组件不从 JS 设颜色**：切主题 = 改 `data-theme` 一个属性

### 核心服务（14/14 单测通过）

| 模块 | 功能 |
|------|------|
| DataConverter | Bytes↔Hex↔Text，V2 算法照搬 |
| ProtocolParser | 方括号协议解析，V2 算法照搬，V3 协议适配 |
| RingBuffer | 512 容量，单生产者单消费者 |
| PreferenceService | 唯一配置入口，Phase 1 用 localStorage，Phase 2 切文件 |

### Rust 串口层

| 命令 | 功能 |
|------|------|
| `list_ports` | 枚举 COM 口 |
| `open_port` | 打开 + 启动 tokio 读线程 |
| `close_port` | 关闭 + 冲刷残留 |
| `send_data` | 发送字节 |
| `set_dtr` / `set_rts` | 硬件流控 |
| 读线程 | 100ms 超时 → `\n` 拆行 → emit `serial-data` |

### 数据管道

```
STM32 → Rust serialport 读线程 → emit("serial-data")
→ React listen → RingBuffer.write() → rAF drainAll()
→ CM6 appendLine(三色) → 暂停/搜索/导出/裁剪
```

## 三、待完成

### Phase 2 — 终端完善（Phase 1 后续，达到日常可用）

**目标：** 用 V3 替代 V2 做日常串口调试——收发、搜索、HEX、历史、编码全通。

#### P0 — 真正影响使用

- [ ] **发送历史**：最近 20 条，下拉回填，上下键浏览（V2 `RecordSendHistory`）
- [ ] **COM 口枚举 + 热插拔**：调 Rust `list_ports` 填充 TopBar 下拉框，定时刷新
- [ ] **HEX 模式真的工作**：
  - 发送侧：HEX 输入自动格式化（大写+每两字插空格），非法字符警告，编码选择框禁用
  - 接收侧：HEX 模式显示 hex dump
- [ ] **定时发送真的工作**：setInterval 按间隔调 send，toggle 控制启停
- [ ] **波特率/端口运行时切换**：改波特率 → 关闭→重新打开，不丢连接状态

#### P1 — 体验缺陷

- [ ] **CM6 行号 toggle 生效**：lineNumbers 动态开关（需 CM6 reconfigure）
- [ ] **编码切换真的工作**：GBK/UTF-8/ASCII/Latin-1 收发编码实际生效（GBK 需 encoding-rs 或 TextDecoder 降级）
- [ ] **系统消息 emit**：串口打开/关闭/错误时 emit 系统消息到 CM6 + 系统日志区
- [ ] **TX/RX 真实计数**：从 Rust emit 字节统计，前端实时更新状态栏
- [ ] **接收区右键菜单**：复制/全选/清空/暂停（CM6 已有复制/全选，补充清空/暂停）
- [ ] **快捷发送管理**：[+] 添加/右键编辑/右键删除，持久化到 prefs.json（V2 QuickSend.cs 参照）
- [ ] **CM6 搜索面板替换**：自建 React 搜索条——中文标签、暗色主题、SearchCursor 匹配、装饰系统高亮、Ctrl+F 打开/Esc 关闭

#### P2 — 细节打磨

- [ ] **新数据闪烁**：50ms 半透明蓝底→消失（视觉标准 §微交互）
- [ ] **连接状态过渡**：状态圆点灰→绿 300ms 色相渐变（CSS `transition: background-color`）
- [ ] **DTR/RTS 硬件流控 UI**：TopBar 或侧栏加两个 toggle（Rust 命令已就绪）
- [ ] **数据位/停止位/校验**：串口打开时作为可选参数（V2 有这功能）
- [ ] **发送栏 Shift+Enter 换行**：Monaco 单行模式不支持，考虑切 textarea 或允许 Monaco 扩展到多行
- [ ] **📡 协议筛选器**：按协议类型过滤接收区显示（V2 已有，V3 设计稿里有）

#### 🌟 新架构红利（Phase 2 后期，P0+P1 完成后再做）

V2 受限于 WPF，这些功能做不起或做不了。V3 的 Web 技术栈让它们变成低成本。

- [ ] **实时过滤**：输入关键字 → 接收区只显示匹配行，其余折叠（CM6 decorations 控制行显隐，~50 行）
- [ ] **多视图 tab**：同一份 RingBuffer 数据 → [原始文本] [HEX] [过滤] 三个 tab，切 tab 不丢数据（Pub/Sub 分发，~60 行）
- [ ] **Command Palette**：Ctrl+Shift+P → 模糊搜索所有命令（清空/导出/暂停/HEX 切换…），不用鼠标（~100 行 React）
- [ ] **发送区语法高亮**：Monaco 注册 V3 协议 tokenizer → 卡片 ID 蓝色、数值绿色、! 定义粉色（~20 行规则）

3. **CM6 行号动态开关**：lineNumbers 插件初始化后不能动态关，需 CM6 reconfigure
4. **Monaco 打包体积**：~150KB gzipped，如果只做单行输入可考虑换 textarea
