## 二、每个命令的完整规格（对标 VS Code）

### `explorer.rename`
- F2 或右键菜单触发
- 输入框替换文件名（inline，非弹窗）——`FileTreeNode` 需支持行内编辑模式
- Enter 确认 → `FileService.writeFile` + `FileService.deleteEntry`（rename = move within same directory）
- Esc 取消
- 文件名冲突→提示"已存在同名文件，是否替换？"
- 🛡️ 扩展名用 `extension` from pathUtils，新路径用 `joinPath(dirname, newName)`

### `explorer.delete`
- Delete 键或右键菜单触发
- 支持批量删除（多选）
- 有 `explorer.confirmDelete` 配置项控制的确认对话框
- 删除到回收站（`explorerResourceMoveableToTrash`）vs 永久删除
- 🛡️ 只读文件→禁止删除（`explorerResourceReadonly` when 条件）

### `explorer.newFile` / `explorer.newFolder`
- Ctrl+N / Ctrl+Shift+N 或右键菜单触发
- 在选中的目录下创建，无选中时在根目录
- 创建后自动进入行内重命名模式
- 🛡️ 路径拼接用 `joinPath(dir, name)`，`dir` 可能是 `\`→`normalizePath`

### `explorer.cut` / `explorer.copy` / `explorer.paste`
- 参见 #26 剪贴板服务。粘贴的 when 条件依赖 `explorerResourceCut` context key
- 粘贴重名→"Copy" 后缀递增：`file.txt` → `file - Copy.txt` → `file - Copy 2.txt`
- Ctrl+X 剪切一次性——粘贴后源文件消失，再粘贴无效
