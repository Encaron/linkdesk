## 二、缓存目录那个输入框（值的合法性）

**E9 · 留空**
- 期望：**合法**，含义 = "用默认位置"（默认仍是 `%APPDATA%\linkdesk`）。⛔ 不能因为空就当错误
- 现况：✅ 已落。判词里空值**不算语法错**
- 谁保证：`cacheSyntaxError()` 对空值放行

**E10 · 填了个不存在的盘（如 `Z:\x`）**
- 期望：**不拦**（装的时候那个盘可能还没挂／是移动盘），但也**不能**当成默认位置静默吞掉
- 现况：✅ 已落（判词只查语法，不查存在性）
- 谁保证：语法与存在性**分开**判；存在性由「浏览…」对话框（`FOS_PATHMUSTEXIST`）保证

**E11 · 填了相对路径（如 `cache`）**
- 期望：提示不合规（必须是完整绝对路径），**不开始安装**
- 现况：✅ 已落。`beginInstall()` 先过 `cacheSyntaxError()`，不过就停在原屏
- 谁保证：`beginInstall()` 前置校验

**E12 · 路径里有非法字符 / 未闭合引号**
- 期望：同 E11，红字提示 + 不前进
- 现况：✅ 已落
- 谁保证：同上

**E13 · 路径超长 / 含中文、空格**
- 期望：中文、空格**必须支持**（`C:\我 的缓存` 合法）；超长按 Windows 上限处理
- 现况：✅ 已落（不额外限制，交给文件系统）
- 谁保证：不做多余校验——**少拦截 = 少误伤**

**E14 · 填了「和安装目录同一个地方」**
- 期望：允许（不是错，只是不太整洁）
- 现况：✅ 允许
- 谁保证：—

**E15 · 填了「用户数据目录自己」（`%APPDATA%\linkdesk`）**
- 期望：**允许但提示**（等于没改；缓存会挨着配置放）。⚠️ 绝不能造成"缓存目录 = 配置目录"导致清缓存时误删配置
- 现况：🔵 待拍板要不要加这行提示（**默认不加**，因为清除逻辑本身已按白名单走，见 §七）
- 谁保证：§七 的白名单

**E16 · 用「浏览…」选目录**
- 期望：选完**回填进输入框**，并能看见；取消选择**什么都不变**
- 现况：⚑ **半接**。页面已能接收回填消息（`cache-dir-done` → `setCacheDir`）；**宿主侧还没受理 `browse-cachedir`** ⇒ **现在点这颗按钮没有反应**
- 谁保证：件 2e（见 [03-实现交接.md](03-实现交接.md) §五）——**发版前必须接上，否则就是第二个"许可协议死按钮"**

**E17 · 同一台机器装第二次**
- 期望：**不要**把上次的缓存目录再播一次种（用户可能已经在软件里改过了）
- 现况：🔵 待拍板（决策点 **D2** 推荐"播种制"：只在软件内没有值时采用）
- 谁保证：落点契约（[01-方案与落点契约.md](01-方案与落点契约.md) §三）

## 四、装 / 重装 / 卸载的生命周期

**E22 · 卸载程序的「最后一幕」是不是硬编码**（★ 用户点名）
- 期望：卸载界面里出现的任何路径／文案，都**从当时的真实安装状态来**，不是写死在代码里的字符串
- 现况：🔵 **本件要专门核一遍**。⚠️ 核的对象是**卸载程序的最后一幕**（属于另一件「用户机落点」总账的活），本件不擅改，但**验收时必须一起走**

**E23 · 装完的完成屏要不要显示缓存目录**
- 期望：**不显示**（一显示就多出第二份地址，迟早不一致）
- 现况：✅ 不显示
- 谁保证：落点契约 §三 铁律 3

**E24 · 卸载时缓存目录里的东西删不删**

## 七、清除缓存的边界（把"不许碰"写死）

| 类别 | 目录 | 清除时 |
|:--|:--|:--|
| 可再生缓存 | `Cache` · `GPUCache` · `DawnGraphiteCache` · `DawnWebGPUCache` · `Code Cache` · `Local Storage` · `Network` · `Session Storage` · `Shared Dictionary` | ✅ **清**（≈14.6 MB） |
| 数据 | **`plugins`** | ❌ **绝不动**（55.5 MB，用户装的东西） |
| 配置 | `appearance` · `update` · 各类 json | ❌ **绝不动** |
| 白名单之外 | 任何其它目录 | ❌ **绝不动**（**白名单制**，不是黑名单制——漏列 = 不删，安全侧） |

> 🔴 **判据**：清除逻辑写成**"只删我名单上这几个"**，而不是"删掉除了某某之外的所有"。前者漏了顶多没清干净，后者漏了就是删用户数据。
