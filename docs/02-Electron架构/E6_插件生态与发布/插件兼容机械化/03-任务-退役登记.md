## 〇、本格要回答的三个问题（**照这三条写，一条不许省**）

| # | 问题 | 本格的答案（定案） |
|:--:|:--|:--|
| ① | **删除 / 改名怎么写账？** | 账加 `retired[]`，每条 = `{ name, kind, since, why, replacedBy, approvedBy }`。**退役 ≠ 删除**：退役项**不腾位**（老 `settings.json` 可能还有值；插件此刻占它 = 顶掉宿主的历史数据），老值**仍被读、仍被清扫** |
| ② | **什么算「改语义」？** | **三条判据任一命中 = 退役级动作**（要登记）：**名字变了** / **含义变了** / **取值域变了**。理由：同名但含义变了，拿到旧值的插件行为会变 ⇒ 与「拿走」等价 |
| ③ | **谁批？** | **用户本人点头**（`approvedBy: "用户 · YYYY-MM-DD"`）；⛔ 不许维护者 AI 自己签，⛔ 不许写「团队」这种无主体的话 |

### 第一步：账扩一栏 `retired[]`（`scripts/host-reserved.json`）

```jsonc
"retired": [
  {
    "name": "app.themeColorMode",      // 原名字（改名的写旧名）
    "kind": "configKey",               // 与既有家族同名：commandPrefix|configKey|contextKey|appearanceId|class|keyframe|protocol

    "replacedBy": "app.theme",         // 无替身写 null
```
