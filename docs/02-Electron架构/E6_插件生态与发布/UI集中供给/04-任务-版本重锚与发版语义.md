## 一、改动点

1. **重锚点定案（写进本档 + 总纲 §三回填）**：翻通道发版日的壳新版本号 X（照 version-bump skill 判类别——本批是作者面新能力，倾向 MINOR；0.x 特例以 skill 判定为准）→ `@linkdesk/ui` 发 X。**撞号核对（机械）**：`npm view @linkdesk/ui versions`——若 X 已在历史版本列（0.3.0 高概率被占用），壳 bump 到下一未占用号（X+0.0.1），本档记档原因。
2. **`packages/linkdesk-ui/package.json`**：`version` → 重锚号；`description` 改写新语义（「运行时由壳池统一供给；本包 = 类型契约 + dev 解析体」）；README 同笔。
3. **锁步断言（机械件）**：`scripts/check-npm-release.mjs`（或其断言清单）加一条——**壳发版时 `packages/linkdesk-ui/package.json` 的 version 必须等于壳新版本号**，不等判红。version-bump 档案/流程文档同笔加行（四包之外 ui 包的特殊性：跟壳同号，不跟作者轴小步）。
4. **`peerDependencies` 不动**（react 系照旧）；`dependencies` 里 `@linkdesk/contracts` 照旧——本格不动依赖图。
