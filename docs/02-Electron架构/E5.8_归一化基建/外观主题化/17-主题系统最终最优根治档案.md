## 二、Phase 1 圆角参考系唯一权威（#118）

**方案**：滑杆 = 系统标尺上「标准圆角」一个值。六档（xs..2xl）+ pill 全部平铺 = 滑杆值，clamp 进 [0,32]。删 ratio 概念（`值 ÷ 主题值` × `值 × 主题值` 全灭）。

选此方案的判据：禁止硬编码（零新增常量 vs B 的硬编码阶梯表）· AI 友好 layer 3（「滑杆 16 → 全 16」单心智模型）· 归一化（一条规则）· 语义（滑杆=用户全局覆盖一个值；六档阶梯=主题作者表达，followTheme 不动）。

**改动**：
- `tokens.ts:251-264` `applyRadiusAbsolute`：删 `md` 读取与 `ratio` 计算；六档全写 `clampRadiusPx(absPx)`px。注释改写（删「保主题层级性格」矛盾注释，改标尺语义）。
- `tokens.ts:296-301` ①c pill 直写已绝对，不动。
- 测试更新（断言非 md 档比例结果的 2 处）：
  - `recipe.test.ts:110-116`：`applyRadiusAbsolute(8, {md:"6px"})` → sm 从 `"0px"` 改 `"8px"`（全档=滑杆）。
  - `seeds.test.ts:307-311`：`applyRadiusAbsolute(12, {md:"8px",sm:"4px",lg:"12px"})` → sm `"6px"`→`"12px"`、lg `"18px"`→`"12px"`。
- 其余路径零触碰：followTheme 主题不动；`app.surfaceRadius` 存在性门控语义实现时核对。

**验证**：`npm run check` 全绿；单测断言覆盖「六档+pill 全 = 滑杆值」「0 → 全 0 直角」「32 → 全 32」；CDP 三主题（普通/直角/全胶囊）滑杆 0/16/32 六档+pill 全一致；followTheme 主题零变化。

## 三、Phase 2 浮层权威归位（#119-#121）

**架构**：FloatingLayerHost 从「半权威」升为**浮层唯一权威**——双平面 + 单一门 + 结构隔离地板。DOM 拓扑：

```
#ld-float-layer（fixed inset:0 z 2000 pointer-events:none，唯一权威）
├── #ld-scrim-plane（pointer-events:auto）  ← 全部遮罩归位，无磨砂
├── #context-menu-root / #quick-pick-root / #dialog-root / #floating-panel-root（auto）
├── #toast-root（auto，toast 从「直挂容器」改根级）
└── #overlay-root（auto，新增通用 surface 根；OverlayPortal 默认目标）
```

**隔离地板（ONE 条结构规则，零表面名）**：
```css
#ld-float-layer > *:not(#ld-scrim-plane) > *,   /* 深度2 */
#ld-float-layer > *:not(#ld-scrim-plane) > * > *  /* 深度3 */
{ backdrop-filter: blur(max(var(--glass-blur,0px), var(--float-blur-floor))) saturate(var(--glass-saturate,1)); }
```
深度是结构事实不是表面名——新浮层（含第三方）进层即隔离，零类名知识、零枚举、零壳改动。

**#119 层权威 + 单一门**：
- FloatingLayerHost.tsx 容器加 `id="ld-float-layer"`；新增 `#ld-scrim-plane` + `#overlay-root`；toast 改根级 `#toast-root`。
- OverlayPortal.tsx 默认 rootId → `#overlay-root`（保留 :103 `?? document.body` 兜底——壳侧消费者 SettingsView 等自动回退 body 不崩；池内才进层）。ContextMenu 显式 rootId 不受影响。
- index.css:511-521 浮层枚举 10 选择器全删，替换为结构规则。`--float-blur-floor`（index.css:522）保留为层地板常量。
- 拖拽幽灵排除裁决：icon-drag-preview + MainZone 拖拽预览**不进层**（瞬态 mimetic 副本非文字表面，逐帧 backdrop-filter 纯开销；pointer-events:none 与层穿透一致）。层头注释写「排除是裁决非漏项」。

**#120 全部浮层归位 + 遮罩归 scrim**：
- 4 处遮罩（quick-pick-backdrop / dialog-host-backdrop / floating-panel-backdrop / colorpicker-overlay）+ ContextMenu 透明 backdrop 改归 `#ld-scrim-plane`（遮罩=满屏无磨砂，与 surface 平面分离后结构规则天然不碰它）。
- ColorPicker.tsx:236、SelectBoxDropdown.tsx:82 OverlayPortal 进 overlay-root。
- status-bar-notif-panel（StatusBarZone.tsx:131）改 OverlayPortal → overlay-root（视口右下角定位，无需锚点传递）。
- dropdown-card vta-dropdown（ViewTitleActions.tsx:93）+ **panel-switcher-dropdown（PanelZone.tsx:217）**：换 OverlayPortal 进 overlay-root，锚点坐标原样传入；**panel-switcher 顺带修复定位 bug**（补 `.dropdown-card` 基础类或进 portal 后 fixed 生效）。
- `.group-tab-plus-menu`（GroupTabBar.tsx:388-395）：进 overlay-root + **裸 1001 改走 Z_INDEX 常量**。

**#121 死代码清理**：
- 删 `.group-tab-drag-preview`（GroupTabBar.css:216-227 零 tsx 引用）+ `.colorpicker-command-root` 双 body 壳（ColorPicker.tsx:336-337，内层已进层后冗余）。

**验证**：CDP 逐层验 8+ 种浮层磨砂隔离（含新归位的 status-bar-notif / dropdown-card / group-tab-plus-menu / panel-switcher）；玻璃关零变化；scrim 无磨砂；拖拽幽灵无磨砂（裁决）；四类交互（点击关闭/Escape/焦点陷阱/锚定位置）零回归。实机用户视觉验收后回勾。
