## 第 1.19 轮 · `#109k-b`：作者面 §11 / §11.5 的裸坐标清理

1. 两处改成**自解释的表述**（把「54b 那条」写成「当你想 X 时，做 Y」这类可执行的话），**中英两棵树同笔**（`check-author-docs-bilingual` 只管篇目 ⇒ 内容等价靠人）。

3. 顺手 grep 一遍**全作者面**还有没有同类裸坐标（`\b\d+[a-z]\b` 形态），一次清干净。
4. 🔴 **本格同时认领 1.15 留下的一笔账：宿主关键帧表扩到作者面 ＋ 让门禁也守它。**
   - **事实**：`reserved-class-names.json` 里躺着 **8 个宿主关键帧**（`selectbox-in` / `drop-zone-in` / `dropdown-card-in` / `floating-panel-in` / `group-tab-enter` / `group-tab-exit` / `notif-icon-spin` / `notif-progress-scan`），而作者面 §12 **一个字都没提**；1.15 的对账门禁（`check-reserved-names-doc-sync`）**只守「保留名」那一列（类名）**，不守关键帧。
