## 一、这是什么 / 不是什么

- **是**：① 壳内**设置 → 通用** 新增一个 **存储** 二级分节（缓存位置 / 已用空间 / 清除缓存）；② 自绘**安装器**欢迎屏新增 **更多配置** 子页，把装前可选项集中成一页，并在其中加一行**选择缓存目录**。
- **不是**：不是给缓存「搬家」或改默认落点——默认仍是 `%APPDATA%\linkdesk`，这一件只是**把位置露出来 ＋ 把选择权交给用户**。
- **不是**：⛔ **不是「清缓存 = 恢复出厂」**。缓存 ≠ 数据（见 01 §一），清除只动**可再生**那一小部分。

## 四、三个坑（先记死，别等实现时踩）

1. **运行中的 Chromium 占着缓存文件** ⇒ 当场删不掉，只能"重启后彻底清空"（**与安装器临时目录清不干净是同一成因**：文件被自己占着）。⛔ 界面不许谎报"已清空"。
2. **渲染层 `readonly` 与 `action` 互斥**（`settings` 插件 `renderControl.tsx:48` 与 `:187` 是两条互斥分支）⇒「只读值 + 按钮」**挤不进同一行**。这正是把"打开"动作放进**齿轮**的结构性理由。
3. **缓存 ≠ 数据**（真机实测 2026-10-02）：`%APPDATA%\linkdesk` 共 **70.6 MB**，其中**只有 ≈14.6 MB 可再生**；**`plugins` 的 55.5 MB 是数据**。混为一谈 = 「一键把你装的插件全删了」。
