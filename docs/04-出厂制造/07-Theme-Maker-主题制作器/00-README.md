> **功能概念见：** [02-主题制作器.md](02-主题制作器.md)
> **UI 布局规格：** [01-UI布局规格.md](01-UI布局规格.md)
> 🎨 **交互预览：** [theme-maker-preview.html](theme-maker-preview.html)

## 生态地位

| 维度 | 说明 |
|------|------|
| **插件系统示范** | 第二个市场插件——证明"插件可以创造插件"（一个市场插件，产出另一个市场插件） |
| **创作者工具** | 从"消费主题"到"创造主题"的桥梁——降低主题制作门槛 |
| **市场供给** | 更多人造主题 → 更多市场内容 → 更多用户 → 飞轮效应 |
| **依赖链** | 依赖 FloatingPanel（#03 壳级组件）、ColorPicker（#04 壳级组件） |
| **对标** | VS Code 没有——VS Code 主题编辑器是内置的。LinkDesk 更进一步：主题编辑器也是插件 |

## 排序理由

放在 Marketplace Store（#05）之后因为：先让用户看到商店里有主题可以买 → 再让他们自己做主题卖。
