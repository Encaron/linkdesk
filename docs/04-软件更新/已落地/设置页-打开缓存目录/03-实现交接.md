## 七、风险（★ 先看这三条）

1. **渲染层 `readonly` 与 `action` 互斥** —— 设置插件的 `renderControl.tsx` 里 `renderHint:"readonly"` 走**提前 return** 的分支，`renderHint:"action"` 在 `case "string"` **里面**，两条**不可能同时命中**。
   ⇒ 本轮才落成**两个键、两行**（⛔ 别想"一个键里既显示值又出按钮"）。⚠️ 这是**声明层**的互斥——**控件层**可以两样同排（将来真要做，得先做成 `src/components/shared/` 的共享控件 ＋ 设置插件加一行 `case`）。
2. **动作行的按钮文字 ＝ 该行的 `description`**，而 `description` **同时**是副标题 ⇒ **同一句话会出现两遍**。⇒ `description` 就写**短句「打开缓存目录」**（重复两遍不刺眼）；长解释若要有，放分节的 `groupDescriptions`。
3. **`uiHint` 写错的降级是静默的** —— 未知 `uiHint` 会退化成 `<span>{String(val)}</span>`（不报错、不红屏）。⇒ 落代码后**必须真机看一眼**那一行长什么样，别只看 `npm run check` 绿。
   📌 安装器侧那三个风险（`gen-review.mjs` 的 `must()` 全替换陷阱 / 生成物不许叠定版页 / `main.cpp` 本机编不了）→ 🔀 [../安装器-更多配置/03-实现交接.md](../../待抉择池/安装器-更多配置/03-实现交接.md) §七。
