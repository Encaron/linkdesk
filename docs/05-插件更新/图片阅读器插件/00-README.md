# 05-插件更新 · 图片阅读器插件（蓝图）

> 状态：📋 **蓝图起头**（2026-10-04 用户点名，未立项未拍板）。源码仓尚未建（立项时起 `E:\linkdesk-plugins\official\image-viewer`）。🧭 **开单时机（2026-10-05 归口）**：本插件**零壳依赖**（四只里体量最小），任何时刻可立项；与 04 案六波的先后见 [04 案 07 §五 依赖阶梯](../../04-软件更新/已落地/文件打开方式与贡献点/07-插件侧适配-文件树与编辑器.md)。
> 一句话：单击 jpg/png/gif/webp 开出**看图器**（适窗/缩放/旋转），而不是编辑器里的乱码——四只阅读器插件里**体量最小**的一只，也是「声明即接管」机制最好的试金石。

## 一、定位

用户问题 1.1 的直接解药：「jpg、npg（png）、svg 等等都通过编辑器插件打开，不管能不能用」。本插件接管**位图类**；svg 双身份（文本兼图像）按壳案 [D8 拍板](../../04-软件更新/已落地/文件打开方式与贡献点/00-README.md)默认**不声明**——svg 单击仍进编辑器当文本改，想要看图的人在「打开方式」里选。

## 二、贡献什么

| 声明 | 作用 |
|:--|:--|
| `contributes.fileAssociations: [{ "extension": "jpg" }, …]` | 接管 `jpg / jpeg / png / gif / webp / bmp / ico`（清单立项时定稿；**不含 svg**） |
| 无命令、无菜单贡献 | v1 纯看图；「打开方式」交给壳侧通用选择器 |

## 三、打开逻辑

同 [PDF 阅读器](https://github.com/Encaron/linkdesk-plugin-pdf-reader/tree/main/docs/01-PDF阅读器插件/00-README.md) §三：解析 → tab（sourceId=filePath）→ `readBinaryFile` → `Blob` → `URL.createObjectURL` → `<img>`。**零宿主新能力**。

## 四、功能分期

| 期 | 内容 |
|:--:|:--|
| M1 | 渲染＋适窗居中＋黑底（看图惯例）——**1–2 天可用** |
| M2 | 滚轮缩放（光标为锚）＋拖拽平移＋旋转＋「适窗/1:1」切换 |
| M3 | 多帧 gif 播放控制；EXIF 方向自动摆正；icos 多尺寸取最优帧 |
| M4（远期） | 同目录幻灯片（←/→ 切换）——需要列目录的 fs 面，立项时对现 API |

## 五、任务布置（立项时展开）

1. 本夹展开 → 拍板扩展名清单与 M1 范围。
2. 起仓 → plugin.json 声明 → M1 → 三门 → publish → 官方目录收录（不进种子）。
3. 验收：装后单击 png 开看图器；卸载单击退回（壳 T1 已落则见兜底页）；大图（>20MP）不卡 UI 线程（canvas 降采样读数）。

## 六、依赖与边界

- **依赖：无**（连壳案 T1/T7 都不阻塞 MVP——它们只影响「没装本插件时」的体验）。
- 不做图片编辑（裁剪/涂鸦）；不做相册库管理；不做 svg 渲染（D8 归编辑器）。
