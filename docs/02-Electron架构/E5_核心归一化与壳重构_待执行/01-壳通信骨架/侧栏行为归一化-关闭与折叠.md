## E5#48 🔧 串口未开时关闭标签页——不弹确认

### 现状

关闭串口监视器标签页 → 弹出"关闭会话「COM3」？"确认框。无论端口是否打开。

### 根因

`tabBehavior.invokeBeforeClose` 告诉壳"关闭标签页前问我一下"——但没有区分"端口开着"和"端口没开"。串口没开时关闭不需要确认——没有数据在传输。

### 修复

```typescript
// serial-monitor/src/index.tsx 或 SerialContext
// invokeBeforeClose 回调中检查 isOpen 状态

// 当前
invokeBeforeClose: () => showConfirm({ title: t("关闭会话「{{name}}」？", { name }) })

// 改后
invokeBeforeClose: () => {
  if (!isOpen) return true;  // 端口没开——直接允许关闭
  return showConfirm({ title: t("关闭会话「{{name}}」？", { name }) });
}
```

**不改壳——只改插件逻辑。** invokeBeforeClose 的返回值约定已支持（返回 true = 允许关闭）。

## E5#49 🔧 图标点击 toggle 侧栏折叠

### 现状（2026-08-04 实现前）

```
点 📁 → 侧栏展开（280px）→ 图标高亮
再点 📁 → 图标取消高亮，但侧栏不动（lastSidebar 兜底）
```

**`lastSidebar` 机制（L87）让同图标第二次点击无效——** `containerId` 变 null 后 `effectiveContainerId` 回退到 `lastSidebar`，侧栏纹丝不动。这是 E5#4 为"切换标签页不关侧栏"加的——副作用是图标 toggle 也被挡了。

### 实现（2026-08-04）

不改 ZoneConfig，不改 collapsedWidth（保持 28px）。只让图标点击能触发折叠/展开——和 ◀/▶ 按钮行为完全一致。

```typescript
// SidePanel.tsx —— 图标点击逻辑改造
// 1. ref 桥接——effect 有 [] 依赖，避免闭包过期
const collapsedRef = useRef(collapsed);
collapsedRef.current = collapsed;
const containerIdRef = useRef(containerId);
containerIdRef.current = containerId;

// 2. toggleCollapse 重命名 doCollapse——图标点击 + ◀/▶ 共用
const doCollapse = useCallback((collapse: boolean) => { ... }, []);

// 3. icon:selected handler
if (currentCid === cid) {
  // 同图标 → toggle 折叠/展开
  const shouldCollapse = !collapsedRef.current;
  doCollapse(shouldCollapse);
  shellEvents.emit("sidebar:containerChanged", shouldCollapse ? null : cid);
  shellEvents.emit("sidebar:toggled", !shouldCollapse);
  return;
}
// 不同图标：切换容器，折叠态则展开
if (collapsedRef.current) doCollapse(false);
```

### 行为

```
点 📁 → 侧栏展开 → 再点 📁 → 折叠到 28px → 再点 📁 → 展开
折叠态点 🪢 → 自动展开并切换到串口
◀/▶ 按钮行为不变
```

### v1.6 扩展方向（到时候再做）

- `ZoneConfig.dock.collapsedWidth`——不同 zone 折叠成不同宽度
- `ZoneConfig.dock.showCollapsedHandle`——是否显示拖拽手柄
- E5 不动 ZoneConfig，折叠宽度保持硬编码 28px
