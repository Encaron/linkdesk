## 一、SDK 发版（本格的主事件）

1. **bump** `packages/plugin-sdk/package.json`（PATCH：判据逻辑新增 ⇒ 不是数据变，语义上是 `feat`+PATCH，按 package 惯例走 PATCH）＋ `CHANGELOG` 同笔。
2. **刷 lock**：`npm install --package-lock-only`（根 lock ＋ `packages/plugin-sdk/package-lock.json` 都可能漂 ⇒ `check:lockfile-sync` 必须绿）。
3. `git add` 后、`npm publish` **前**真跑 `npx lefthook run pre-commit`（runbook 坑④）。
4. `cd packages/plugin-sdk && npm publish --registry=https://registry.npmjs.org`（**不要** `npm publish <folder>`，坑②）。
5. 等货架复制（**约 3 分钟，且各包不同时到**）⇒ `npm view @linkdesk/plugin-sdk version` 拿到新号 ⇒ `npm run release:mark`（记基线，**黄灯必须灭**）。
6. **货架保真**：从 registry 下载真 tarball，**解包核新判据在里面**（`dist/eslint/checks/*` 有前缀判据实现）；再**真装一次**（`npm i @linkdesk/plugin-sdk@latest` 到临时工程）跑一次 lint ⇒ 判据真的会红（塞一条违规看它红）。🔴 用户授权里那句「**该手动安装新版就安装新版**」在这里落地：**允许真装、真跑**，不许停在「tarball 里 grep 到文件名」。
7. **插件仓跟进**：18 仓各 `npm install` 拉新 SDK（lock 更新）→ **逐仓 `npm run verify` 必须绿**（这是「SDK 发布没有把谁打红」的实证）。⚠️ 只写本地容器；推送已授权但**按仓一笔一提交**。

## 二、作者面两棵树 §12 改规则

**改什么**（现状见 [05-插件UI写法规约.md §12](../../../../03-插件制造/05-插件UI写法规约.md)）：

| 现状 | 改成 |
|:--|:--|
| 纪律 1：「给自己的元素起**带前缀**的类名——前缀用**你自己的插件名或简写**」 | 「给自己的元素起的类名，**必须以 `pluginId` 加连字符开头**（`settings-*`、`editor-*`）；**不许用缩写**（`ms-` / `mpd-` 那种写法已废弃）」 |

| §12 保留名表（1.15 的对账门禁在守） | **不动**（它的语义没变；⚠️ 改它要同笔改三处——见 1.15） |
