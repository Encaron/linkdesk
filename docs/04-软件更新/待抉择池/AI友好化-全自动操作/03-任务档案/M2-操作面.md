## AI#20 ✅ 浮动面板：补非鼠标路径（**A 类里唯一「够不着且无替代」的自家功能**）——**2026-09-28 会话 10 验毕**

**做什么**：给浮动面板补 API/命令（`panel.setFloatingBounds` 型，或 `revealFloating` 带坐标形参）。

**现状（实测）**：`src/pool/floating/floating-panel/FloatingPanelHost.tsx:155-198`——**顶部 6px 手柄拖拽**（I8-5）＋ **底部 8px 手柄调高**（I8-7），两者**共用** `startGesture`；`onPointerDown` 在 **:266 / :311**；常量 `MIN_HEIGHT = 300`（:52）、`RESIZE_MAX_OFFSET = 80`（:53）。**拖后几何转成显式 px 而零 API 可设** ⇒ 一旦位置只能靠拖，AI 就**永远够不着**。

  - **不是唯一鼠标路径的证法（真机）**：`scripts/dev/m4-fullchain/gate-accept.mjs` **24/24**，**连跑两遍**都全绿（第二遍是 CDP 真按键落在 BODY、降级 DOM 合成 `KeyboardEvent` 的跑法）——门出现 → **Esc ⇒ `EUSERDENIED` ＋ 提示**（AI 侧读到**被拒**）／ **Enter ⇒ 落地 `ok=true`**；**名单外的命令（`view.zoomReset`）与不存在的命令一律不问**；被拒那次**盘上账本（`ai-bridge-log.jsonl`）如实记 `ok=false code=EUSERDENIED arg=update.openUpdateFlow`**（拒绝真没落地）。**回归**：`accept.mjs --channel cli` **39 / 39**（含「装插件门」新文案 ＋ 通知按钮门）。单测 **19 条**（含「**被拒 ⇒ `commands.execute` 从未被调**」）。名单**现只两条**（`install` ＋ `update.openUpdateFlow`）；⚠️ `uninstall` 与串口发数**仍不在通道上**（挂给后续格）。
