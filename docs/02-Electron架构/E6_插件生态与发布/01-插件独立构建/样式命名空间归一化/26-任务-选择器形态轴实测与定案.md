# 第 1.25 轮 · `#109o`：**选择器形态轴实测与定案**（件 7·评估——顶层非类名选择器 ＋ 跨方命中形态）

> **一句话**：类名、关键帧、token 之外还有**第四条通道**——**选择器本身**。一条 `* { margin: 0 }`、`input[type="number"] { … }`、`select { … }` 或 `button { border: none }` **根本不经过任何类名**，却会命中**别人的元素**。宿主侧实测 **16 处**顶层非类名选择器，其中 `*` reset 与 `input[type="number"]` / `select` **正在给插件元素上样式**（`src/pool/pool-main.tsx:24` 显式 import 了 `index.css`）——**今天这是有意的共享基线，但它同时是这一类问题的完整入口**。而两侧门禁的解析器**只认类名**（`SOLE_CLASS`），这类选择器**在门禁里根本不存在**。
> **本格产出 = 逐条裁决 ＋ 三条规则定稿 ＋ 判据草案 ＋ 1.26 的完整任务书**（评估轮，**本格不改产品代码**）。
> **编号**：`#109o`；轮次号 1.25 **不等于执行序**（但本轮恰好同序）
> **🔴 执行序：= [22 号档](22-收口总方案-跨方样式污染九件套.md) §四 轮次表第 6 序**（… 1.24 → **本格** → 1.26 → …）；**1.20 恒为最后**。
> **本档怎么用**：§一 是先验读数（**不是输入，是对账基准**）；**进场先跑 §七**。
>
> **非新能力声明（`check-design-flow` §8.4 ③）**：本格是**存量选择器形态的实测与定案 ＋ 既有门禁的判据设计**，不新增用户能力、不改视觉语义（落地轮同样只做「基线登记 ＋ 门禁 ＋ 极少量形态归位」）。⇒ **无需新能力设计前置**。

### 2. 定三条规则（**本档建议形态，可改措辞，不许退化**）

> 🔴 **前提（[29 号档](29-主题系统保护条款.md) §四.2）**：宿主基线清单**必须收全主题机制用到的** —— `[data-theme="light"]`（亮色契约块）· `*:focus-visible` · `html`/`body`/`#root`/`#pool-root` · `*` 三条 reset。**不许把 `[data-theme=…]` 当「文档级污染」要求改成类限定**（那会让亮色契约块失效）。

> **R1 · 宿主基线块（文件级登记，零名字白名单）**
> 顶层非类名选择器**只允许出现在宿主的一处指定区块**（今天 = `src/index.css` 的文档级区块）；**基线条目文件级登记**（「哪几个文件、哪几条」），**每条一句理由 ＋ 一句「谁依赖它」**；该区块**外**出现顶层非类名选择器 ⇒ **红**。
> ⇒ **刻意不做「按名字白名单」**（系列禁区）：登记的是**区块**，不是名字。

> **R2 · 插件禁止顶层非类名选择器**
> 插件 CSS 里**任何顶层（无祖先）的元素/通配/属性/id 选择器 ⇒ 红**；要写元素样式**必须挂在自己的根类之下**（`.serial-monitor-root input { … }`）。
> ⇒ 今天实测 **0 处** ⇒ **纯预防性，零存量**。

> **R3 · 跨方命中必须有自有命名空间作祖先**
> 选择器主体是**宿主/共享组件名（`ldk-*`）**时，**选择器里必须至少含一个插件自有前缀类（`<pluginId>-*`）**；否则 ⇒ **红**。
> ⇒ 今天那 7 处**全部满足** ⇒ **纯预防性，零存量**；它把「scoped 调优合法」这条既有特性**变成有形态的契约**（**管形态、不管意图**——见 §四 禁区）。
