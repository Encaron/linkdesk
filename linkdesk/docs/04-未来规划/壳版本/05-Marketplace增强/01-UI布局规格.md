## 二、设计 Token

### 2.1 卡片 Token——对标 App Store 卡片风格

| Token | 值 | 用途 |
|------|------|------|
| `--store-card-width` | 180px | 卡片宽度 |
| `--store-card-padding` | 12px | 卡片内 padding |
| `--store-card-border-radius` | 10px | 卡片圆角（比通用小卡片稍大——商店感） |
| `--store-card-icon-size` | 48px | 插件图标尺寸 |
| `--store-card-icon-radius` | 10px | 图标圆角 |
| `--store-card-gap` | 12px | 卡片之间间距 |
| `--store-card-hover-lift` | -4px | hover 上浮量 |
| `--store-card-hover-shadow` | `0 12px 24px rgba(0,0,0,0.15)` | hover 阴影 |
| `--store-card-bg` | `var(--bg-card)` | 卡片背景 |
| `--store-card-border` | `var(--border)` | 卡片边框 (hover 时变为 accent) |

### 2.2 卡片内部排版

```
┌─────────────────────┐
│                     │  ← padding: 12px
│  ┌───────────────┐  │
│  │               │  │  ← 插件图标 48×48, border-radius 10px
│  │   插件图标     │  │
│  │               │  │
│  └───────────────┘  │
│                     │  ← gap: 8px
│  插件名称           │  ← font: 13px Inter 600, --text-primary
│  v1.0.0 · ★4.5 2k  │  ← font: 11px, --text-secondary
│                     │  ← gap: 6px
│  一句话描述信息，    │  ← font: 11px, --text-secondary, 2 行截断
│  超出省略...        │      line-height: 1.4, max-height: ~31px
│                     │  ← gap: 8px
│  [ 安装 ▼ ]         │  ← 安装按钮, 高 26px, accent 绿(未安装) / 灰(已安装)
│                     │
└─────────────────────┘
```

| 元素 | 规格 |
|------|------|
| 图标 | 48×48px, 圆角 10px, 居中 |
| 名称 | 13px 600, 单行截断 `text-overflow: ellipsis` |
| 版本+评分+下载 | 11px 400, `--text-secondary`, 行高 16px |
| 评分金色 | `★` = `#EAB308` (amber), `☆` = `--text-muted` |
| 描述 | 11px 400, 2 行 `-webkit-line-clamp: 2`, 颜色 `--text-secondary` |
| 安装按钮 | 26px 高, 全宽, `--accent` 背景(未安装) / `--text-muted` 边框(已安装) |
| 卡片悬停 | y-4px + 阴影 + 边框 accent 色, 200ms ease-out |
| 有更新角标 | 图标右上角 `●` 6px 圆点, `--accent` 色 |

## 三、卡片网格布局——CSS Grid

```css
.store-card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, 180px);
  gap: 12px;
  justify-content: center;
  padding: 16px;
}
```

**自适应：** 容器宽度变化 → 自动增减列数。3 列（660px+）、4 列（844px+）。

**进入动画（GSAP stagger）：**
```js
// 切换分类/搜索 → 卡片重新渲染 → 入场动画
gsap.from('.store-card', {
  opacity: 0, scale: 0.92, y: 16,
  duration: 0.4, stagger: { each: 0.04, from: 'start' },
  ease: 'power1.out'
});
```

**hover 微交互（GSAP quickTo）：**
```js
gsap.to(card, { y: -4, scale: 1.02, boxShadow: '0 12px 24px rgba(0,0,0,0.15)', duration: 0.25, ease: 'power2.out' });
// mouseleave: reverse
```

## 四、状态矩阵

| 状态 | 触发条件 | 视觉表现 |
|------|------|------|
| **正常——有插件** | 已安装插件 > 0 | 卡片网格正常渲染 |
| **空——无插件** | 过滤后 0 结果 | 居中 "没有找到插件。" + "尝试其他关键词或清除筛选"（`--text-secondary`） |
| **加载中** | 扫描插件中 | 卡片区域 spinner + "正在加载插件列表…" |
| **搜索中** | 输入搜索关键词 | 网格过滤 + 分类栏数量动态更新 |
| **搜索无结果** | 关键词无匹配 | 空状态——同"无插件" |
| **分类选中** | 点分类项 | 选中态背景 + 网格过滤 |
| **安装中** | 点[安装]按钮 | 按钮变 spinner + "安装中…"（`--accent`） |
| **安装完成** | 安装成功 | 按钮变 [已安装]（灰色边框）+ 短暂 toast |
| **安装失败** | 安装失败 | toast 错误信息 + 按钮恢复 [安装] |
| **有更新** | 插件有新版本 | 图标右上角绿色圆点 + 按钮变 [更新]（accent 边框） |

## 五、FloatingPanel 底部按钮行为

| 按钮 | 行为 |
|------|------|
| **在主窗口中打开** | `createTab("marketplace", { mode: "store" })` → 标签页内全屏 → 关闭 FloatingPanel |
| **最大化** | `panel.style.width = '100vw'; panel.style.maxWidth = '100vw'` → 再次点击恢复 |
| **关闭** | `onClose()` → FloatingPanel 消失 → 回到侧边栏模式 |

```css
:root {
  /* === 卡片 === */

  --store-card-icon-size: 48px;
  --store-card-icon-radius: 10px;
  --store-card-gap: 12px;
  --store-card-hover-lift: -4px;
  --store-card-hover-shadow: 0 12px 24px rgba(0, 0, 0, 0.15);

  /* === 分类栏 === */
  --store-sidebar-width: 160px;
  --store-category-item-height: 30px;
  --store-category-icon-size: 16px;

  /* === 搜索 === */
  --store-search-height: 44px;
  --store-search-input-height: 32px;
  --store-search-border-radius: 16px;

  /* === 评分 === */
  --store-star-color: #EAB308;
}

/* === 动画 === */
@media (prefers-reduced-motion: no-preference) {
  .store-card {
    transition: transform 250ms power2.out, box-shadow 250ms power2.out, border-color 250ms ease-out;
  }
  .store-card:hover {
    transform: translateY(var(--store-card-hover-lift)) scale(1.02);
    box-shadow: var(--store-card-hover-shadow);
    border-color: var(--accent);
  }
  .store-card-enter {
    animation: cardEnter 400ms power1.out both;
  }
  @keyframes cardEnter {
    from { opacity: 0; transform: scale(0.92) translateY(16px); }
    to   { opacity: 1; transform: scale(1) translateY(0); }
  }
}
@media (prefers-reduced-motion: reduce) {
  .store-card, .store-card:hover { transition: none; transform: none; }
}
```
