## 2. 变量契约全表

### 2.1 字体族

| 变量 | 默认值（= 现状） | 用途 |
|:--|:--|:--|
| `--font-ui` | `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif` | 根 UI 字体（替换 index.css:148） |

### 2.2 圆角分档（拍板：语义档位 + 偏门值归并）

> **语义档位是给主题作者的「语言」**（像 `--space-md` 一样），偏门值（3/7/9/10/14px）归并到就近档，每处 ±1-2px 视觉差——可接受，活着比精确更重要（拍板）。

| 变量 | 默认值 | 语义（用途） | 归并来源 |
|:--|:--|:--|:--|
| `--radius-xs` | 2px | scrollbar/toggle/拖拽指示 | 1/2px |
| `--radius-sm` | 4px | 输入框/按钮/小 tab（**现状最大宗**） | 3/4px |
| `--radius-md` | 6px | setting-group/卡片 | 6/7px |
| `--radius-lg` | 8px | 对话框/悬浮面板/菜单 | 8/9px |
| `--radius-xl` | 12px | 玻璃态大面板 | 10/12px |
| `--radius-2xl` | 16px | 最大面板/背景容器 | 14px |
| `--radius-pill` | 999px | 胶囊（toggle 归此） | — |
| `--radius-full` | 50% | 圆形控件 | — |

### 2.3 玻璃

| 变量 | 默认值 | 用途 |
|:--|:--|:--|
| `--glass-blur` | 0px（**默认关**） | 表面 backdrop-filter blur（透射量） |
| `--glass-saturate` | 1 | 饱和度（透射色彩增强） |
| `--glass-tint` | transparent | 玻璃面叠加色 |
| `--glass-opacity` | 1 | 玻璃面不透明度 |
| `--glass-specular` | 0 | **液态玻璃顶部高光强度**（Apple Liquid Glass specular——0=关，非零=表面顶部渐变受光带） |
| `--glass-morph` | 0ms | **液态玻璃形变过渡时长**（交互/面板浮起/圆角变化时平滑 morph——0=关，建议 400ms） |

> ⚠️ 玻璃 blur 给上限（性能预警）：大面积 backdrop-filter 是 GPU 负担，契约给 blur 上限（待拍板数值）。
> 🔥 **材质定位（2026-08-23 用户澄清）**：`--glass-*` 这套键实现的是 **Apple Liquid Glass 材质近似**（iOS 26「会透光、会反光、会响应」的玻璃）——blur/saturate 管透射，specular 管反光，morph 管响应。**不是**静态磨砂 Glassmorphism（= 现状只有 blur），**不是** ui-ux-pro-max 的虹彩色差那条路（creative 平台向，非苹果向）。完整材质规范见 [壳半业务外推/02-外观玻璃态设计.md](../壳半业务外推/02-外观玻璃态设计.md)「液态玻璃材质」节。

### 2.4 背景

| 变量 | 默认值 | 用途 |
|:--|:--|:--|
| `--bg-image` | none | 全局背景图（BackgroundLayer 消费） |
| `--bg-opacity` | 1 | 背景图透明度 |
| `--bg-mask` | none | 背景遮罩（压暗保证前景可读） |

### 2.4.1 per-surface 背景（E5.8#50.28-30 增量冻结：⑬ 纸纹/⑭ 影像分区共用）

| 变量 | 默认值 | 用途 |
|:--|:--|:--|
| `--surface-bg-image` | none | per-surface 背景图（纹理 repeat 平铺 / 影像 zones 切片 no-repeat）——5 zone 表面 ::after 消费 |
| `--surface-bg-repeat` | no-repeat | 纹理 = repeat（平铺）；zones 切片 = no-repeat |
| `--surface-bg-opacity` | 1 | per-surface 背景图不透明度 |
| `--surface-bg-size` | auto | zones 切片 = 窗口尺寸（池侧 preload 量测注入） |
| `--surface-bg-zones` | 0 | zones 模式标记（1 = 影像分区，池侧 preload 按此门控量测） |
| `--surface-{titlebar\|icon-bar\|side-panel\|main-zone\|status-bar}-bg-position` | 0 0 | 每 zone 独立负偏移（切片拉回正确区域；池侧量测 getBoundingClientRect 注入） |

> 5 个消费 zone = `.titlebar/.icon-bar/.side-panel/.main-zone/.status-bar`（#50.7 表面选择器同集）。引擎只写共享图/repeat/zones 标记（纯函数）；每窗尺寸 + 每 zone 偏移由 `electron/preload-pool/surface-zones.ts` 量测注入（多窗各自尺寸，壳 ThemeEngine 单实例广播无法知像素）。

### 2.5 阴影收编

散落硬编码的 rgba 阴影收进 token：`--shadow-pop`（下拉/浮层）、`--shadow-dialog`（对话框）、`--shadow-tooltip`（提示）等，默认值 = 现状 rgba 值。
