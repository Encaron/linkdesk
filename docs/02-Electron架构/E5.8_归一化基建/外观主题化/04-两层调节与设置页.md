# 04-两层调节与设置页（主题配方 vs 软件设置）

> **状态：** 拍板（2026-08-23）——玻璃连续 scale、全局 scale 系数、设置页主题区
> **图纸：** 设置页主题区交互见 [mockups/01-设置页-主题区-mockup.html](mockups/01-设置页-主题区-mockup.html)（head 注释双向指针 ←→ 本文 + [05](05-主题数据模型.md) + [08](08-持久化与配置.md) + [10](10-混搭设计.md)）

## 1. 两个来源

| 层 | 来源 | 作用 | 持久化 |
|:--|:--|:--|:--|
| **主题层** | theme.json `appearance` 段 | 整套外观配方（字体/圆角/玻璃/背景图），缺的域继承默认 | 主题文件内，换主题即换配方 |
| **设置层** | 设置面板 slider/加减 | 用户对个别外观项的**覆盖**（圆角、玻璃透明度/模糊、字体…） | workspace.json 配置 |

## 2. 玻璃是连续 scale，不是二元开关

> 用户问：「玻璃是开关形式还是主题形式？」——两者不矛盾。

- **主题层**：主题自带玻璃效果（`--glass-blur: 20px` 等，配方一部分）
- **设置层**：全局拉强度，**拉到 0 = 关**
- 一个滑杆到底就是开关，不用额外二元开关

## 3. 优先级——对标 accentMode 先例

复用已有 `app.accentMode: "followTheme" | "custom"` 模式：

- **followTheme（默认）**：用主题值
- **custom**：用户设置值覆盖主题值

对应外观配置（#50.10）：`app.appearanceMode` 一词 + 具体项（`app.surfaceRadius` / `app.glassOpacity` / `app.glassBlur` / `app.fontFamily`）在 custom 时覆盖对应 token。

## 4. 覆盖粒度（拍板：圆角 scale 系数 / 玻璃绝对覆盖）

**主题作者管精致（per-surface 精调），普通用户管粗调（一个全局滑杆）。**

- **主题层** = per-surface 绝对值（每表面单独定义 6/8/12px）
- **设置层**：
  - **圆角** = 全局**缩放系数** `app.surfaceRadius`（默认 1.0），不是绝对值——×1.5 → 6/8/12px 变 9/12/18px，**相对差异保留**，一个 slider 整体缩放；对标系统缩放 / 浏览器 zoom
  - **玻璃** = **绝对覆盖**（`app.glassBlur` px / `app.glassOpacity` / `app.glassTint`）——`--glass-*` 是连续单值，无八档可缩放，绝对覆盖更直观（粒度精化说明见 [08 §3](08-持久化与配置.md)）
  - CSS 不能 `var * var` → ThemeEngine 在 applyTheme 时用 JS 把每个 radius token 乘 scale 再写入。slider 一动 → 重写全部 radius 变量
- 用户心智 = 「让界面更圆润一点」，不是「把对话框圆角改成 14px」

## 5. 设置页主题独立建区（正式规格）

设置页加「主题」区，与通用区并列。纯 UI 层，不依赖 #48 factoryRole 拍板。建议立案为 #50.10 的一部分或独立小任务。**交互设计已定稿 = [mockups/01-设置页-主题区-mockup.html](mockups/01-设置页-主题区-mockup.html)**，结构与真实 SettingsView 类名一一对应。主题区从上到下：

1. **主题配方**（`app.theme`）——ThemePicker 卡片：多配色配方显示配色徽标，点卡片 = 选配方（配色回跟随）
2. **配色**（`app.themeColorMode` SelectBox：跟随主题配色/自定义配色）→ dependsOn 自定义 → `app.themeColor` 动态 SelectBox（活动配方 colorways）
3. **外观覆盖**（`app.appearanceMode` SelectBox：自定义/跟随主题）→ dependsOn 自定义 → 6 行：`app.surfaceRadius`（Slider ×）、`app.glassBlur`（Slider px，0=关）、`app.glassOpacity`（Slider）、`app.glassTint`（色块+input）、`app.backgroundImage`（FilePathInput + …）、`app.fontFamily`（FontFamilySelect）
4. **混搭区**（`app.mixMode` SelectBox：整体配方/混搭，默认整体配方）→ dependsOn 混搭 → 6 行域来源动态 SelectBox + 一键复位按钮——设计定稿见 [10](10-混搭设计.md)，**执行排期靠后**

> 组归属：主题区 = 壳第二个配置贡献（pluginId `appearance`），见 [08 §5](08-持久化与配置.md)。
> 全部 key 类型/默认/dependsOn 见 [08 §1](08-持久化与配置.md) 全表。

## 6. 强调色与主题 token——主题可用自有 token 摆脱强调色

> 用户点：「有的主题比较特殊，胶囊开关是彩色形式，理论上不受强调色限制。」

- 强调色机制（accentMode）只覆盖 `--accent`/`--accent-hover`/`--accent-light` 三个变量
- **主题只要不消费 `--accent`、用自己定义的彩色 token（如胶囊开关的 `--toggle-on-bg: 彩虹色`），强调色就管不到它**——token 自由定义的自然结果，非新能力
- 文档写明约定：**主题作者想摆脱强调色 = 用自己的 token，不读 `--accent`**
