## 一、布局分区（标签页内全自绘）

```
┌──────────────────────────────────────────────────┐
│ 工具栏 40px（跟随壳主题，可用 @linkdesk/ui 共享件） │
├─────────┬────────────────────────────────────────┤
│ 缩略图   │  阅读区（固定底色，不跟主题）             │
│ 侧栏    │  连续滚动 · 虚拟化只渲染可视页            │
│ 180px   │  页面卡片居中 · 页间距 16px              │
│（默认收起）│                                        │
├─────────┴────────────────────────────────────────┤
│ 状态条 24px（页码 / 缩放读数 · AI 可读的结构化读数） │
└──────────────────────────────────────────────────┘
```

- **工具栏**（高 40px，内容 8px 节奏）：侧栏开关 ‹ 上一页 · 页码框「7 / 132」 · 下一页 › ｜ 缩小 · 百分比 · 放大 · 适宽 · 适页 ｜ 搜索 ｜ 底色切换。图标钮 28×28、间距 4px、悬停 150ms 过渡＋焦点环（键盘可达）。
- **缩略图侧栏**（宽 180px，默认收起——AI 拍板：首屏给阅读让路，开合走命令 `pdf-reader.toggleSidebar`）：懒渲染，仅可视条目出图。
- **阅读区**：页面卡片（白纸面＋1px 边＋柔和投影），纸底色由底色档决定；**切壳主题此区纹丝不动**（验收句）。
- **状态条**（高 24px）：`第 7 页 / 共 132 页 · 125% · 适宽`——同一份数据即命令返回的结构化读数（AI 友好化）。

## 三、交互细则

- **翻页**：方向键 PgUp/PgDn（命令路径）；滚轮直滚；`Ctrl+滚轮` 缩放（同壳编辑器手感）。
- **缩放档**：0.25–4.0 连续，百分比钮点击回 100%；适宽/适页是模式（窗口 resize 跟随），非特殊倍率。
- **搜索条**（T5）：工具栏下方浮条，Enter 下一处 / Shift+Enter 上一处，命中数 `3/17` 直读。
- **错误态两式**（T3，🆕 2026-10-07 拍板：**照 editor 插件 BinaryNotice 同款骨架**，范本 = editor 仓 `src/components/BinaryNotice.tsx`）：区中央图标＋标题＋描述＋**两颗探测接线钮**（共享 `Button`，动作面不在就隐藏、不留死钮）——①「打开方式…」走 SDK 子路径 `@linkdesk/plugin-sdk/shell-commands` 的 `openWith({ uri, name, ext })`，先探 `commands.getCommands()` 含 `SHELL_COMMANDS.openWith`；②「在市场搜索阅读器」先探 `pluginManager.list()` 有 marketplace 插件，动作 = `events.emit("icon:selected", "marketplace")` 揭示其侧栏。损坏态文案「此 PDF 无法打开／文件损坏或不是有效的 PDF 格式」；加密态文案「此 PDF 已加密／暂不支持打开受密码保护的文件」，两态同骨架。⛔ **无「仍旧以本插件强开」钮**（editor 的 forceOpenAsText 是文本兜底角色自有动作；pdf 打不开就是打不开，强开无意义——用户拍板），⇒ 也不立对应命令（无死代码）。
- **加载态**（T3，🆕 2026-10-07 施工修订：**只留不确定式滑动条**）：首屏骨架（灰页面卡＋滑动条），大文件不白屏。⚠️ 原稿写「pdf.js `onProgress` 驱动」——**实测不成立**：pdf.js 在「整段字节交给它」的形态下**一次 onProgress 都不发**（2026-10-07 实测：95MB 文件事件数 = 0），壳 `readBinaryFile` 又只是一次性 IPC（无分块、无 total）⇒ 本项目**拿不到任何真进度**。⛔ 既不画一条假的百分比（骗人），也不留「永远不亮」的确定式分支（死代码）⇒ 滑动条只有不确定式一种；读数出处 = [施工档案/T3-M1阅读器主体.md](施工档案/T3-M1阅读器主体.md) §三。
- **AI 友好化**：全部工具栏动作同挂 `pdf-reader.*` 命令（description＋params 齐全）；状态条读数 = `pdf-reader.getStatus` 返回值。
