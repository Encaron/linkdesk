内置配置组图标 · 设计稿

设置页左侧导航「本体组」四枚图标（通用 / 主题 / AI 接入 / 默认打开方式）。 判据：与插件组彩色 marketIcon 形成「本体 / 插件」天然区分。区分轴取 插件＝有块·彩色·不随主题；本体＝无块·墨线·随主题： 插件图标是货架上的商品（48×48 渐变块），本体图标是软件自身的骨架（16×16，走 --icon-ink 墨色阶梯，亮暗主题自动翻转）。

真源钉桩（拟真度门）：导航窗内所有度量照产品源复刻（settings 仓基线 a489870 · a489870 · nav 200px / 行 padding 6px 20px / 字号 md 14 / 图标位 16×16 圆角 var(--radius-sm)=4px / active 左 2px accent 条 / count 徽标 xs 12px（settings/src/views/SettingsView.css:92-158）· 调色板照 theme-defaults/themes/defaults.json（暗 accent #0E639C / 亮 #0078D4）· 墨色阶梯 --icon-ink = text-primary 78%（src/index.css:28））。 计数徽标数字为示意。本体组四行均落在「本体」列，插件组三行（编辑器 / 文件树 / 串口监视器）用真件内嵌对照。
你的选择：三方案同屏（暗 / 亮双主题）＋放大检视（128px 带 16px 栅格）。 方案 D 专款：强调色元素随主题 accent 翻转，生产消费＝双层（墨层 mask＋accent 层 mask，两层都吃主题 token）；若选 D，IconRegistry 默认项与 PluginIcon 按名解析按双层渲染落码。
选定方案后，四枚 SVG 即按现几何落为 IconRegistry 默认项资产（盘上 SVG），值形态与节奏按 2026-11-18 拍板执行。
