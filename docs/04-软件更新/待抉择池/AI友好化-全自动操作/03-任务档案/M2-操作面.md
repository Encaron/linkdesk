## AI#20 ⬜ 浮动面板：补非鼠标路径（**A 类里唯一「够不着且无替代」的自家功能**）

**做什么**：给浮动面板补 API/命令（`panel.setFloatingBounds` 型，或 `revealFloating` 带坐标形参）。

**现状（实测）**：`src/pool/floating/floating-panel/FloatingPanelHost.tsx:155-198`——**顶部 6px 手柄拖拽**（I8-5）＋ **底部 8px 手柄调高**（I8-7），两者**共用** `startGesture`；`onPointerDown` 在 **:266 / :311**；常量 `MIN_HEIGHT = 300`（:52）、`RESIZE_MAX_OFFSET = 80`（:53）。**拖后几何转成显式 px 而零 API 可设** ⇒ 一旦位置只能靠拖，AI 就**永远够不着**。

**为什么这是本轮第一格**：[§2.3](../01-设计.md) 的 A 类里，**这是唯一「够不着且无替代」的自家功能**——其余 A 类是 OS 层（真够不着，如实列册即可，见 `AI#13`）。

**判据**：浮动面板的**位置/高度可被 API 精确设定**（AI 不需要拖）。

**验收方式**：经契约设一次位置/高度 → **读数与落点一致**（不靠目视）；⚠️ 顺带断言 `MIN_HEIGHT` / `RESIZE_MAX_OFFSET` 这两个**隐藏边界**在 API 路径上**同样生效**（否则 API 会绕过限位，把面板设成一个拖不出来的状态——**那是新的不一致**）。

**风险**：⚠️ 这是**新能力面**（契约加方法）⇒ 走 `design-flow` 8 维清单；且**几何真相源要先确认**（`AI#4` 的布局读取面能不能读到面板几何——读不到就要同笔补，否则「设了但读不出」）。

## AI#29 ⬜ 敏感动作确认面（与既有「装 = 问一声」对齐）

**做什么**：把「**AI 能发起、但敏感动作要用户点头**」落成**一致机制**——**「装/卸插件 = 问一声」为既有先例**。

**依据** = [§八 追问场景②](../01-设计.md)：「🔴 **安全确认：保留『装 = 问一声』**」＋「**AI 友好 ≠ AI 无限制**——白名单 ＋ 授权确认是它的组成部分」。

**判据**：敏感动作有**统一确认回路**，且该回路**不是唯一鼠标路径**（⇒ 确认本身也要能被 AI 读到、被非鼠标路径应答——这就与 `AI#5`（对话框进行中状态可读）**接上了**）。

**验收方式**：AI 发起一次装插件 → **确认弹出** → AI 能**读到**它在等什么（`AI#5`）→ 用户点头 → 落地（记忆《安装确认每次都要问》：**含官方目录**，每次都要问，⛔ 不缓存授权）。

**边界**：⚠️ 确认面**归用户**——⛔ 别为了「全自动」把确认做成可被 AI 自动应答的（那是**把安全网拆了**）。本格要的是**确认回路可被发现、可被非鼠标应答**，**不是**可被 AI 代答。

## AI#30 ⬜ 「唯一鼠标路径清零」总验收

**做什么**：全软件扫描 ＋ 手册登记收口——**B 类 6 条 ＋ C 类 5 条 ＋ A 类（够不着者如实列册）逐条对账**。

**判据** = [§七 第 5 条](../01-设计.md)：「拖动/右键/双击等手势**全部仍在**（给人用的手感一个不少），只是**每一条都另有非鼠标路径**」。

**产出** = **清零表**进本档 ＋ 手册（`AI#11`）同步。

**验收方式**：⚠️ **两手都要**——① **机械面**：`AI#28` 的尺子跑一遍（静态信号）② **语义面**：「每一条都另有非鼠标路径」这句**机器判不了**（[§八 末](../01-设计.md)：「难机械查的 = 语义级」）⇒ **必须留一次人工逐条对账**在案。⛔ 别用 `AI#28` 的绿冒充本格的绿（**静态绿 ≠ 语义清**——同《空转判据 ≠ 零存量》）。

**残留的处理**：审计尾巴上个别未扫到的「仅鼠标」路径 = **发现一条补一格**（`AI#50` 起续号）——[§八 末](../01-设计.md) 已定性：**量级是「加一条命令」，不是「推翻架构」**（⇒ 残留**不阻断**本轮收口，但**必须登记**）。
