> 2026-07-28 定案。5 项决策全部确认，进入执行。

## 已确认决策

### A. Emoji → Codicon ✅

15+ 处 Emoji/文本字符图标 → `codicon` 字体图标。LinkDesk 已全局加载 `@vscode/codicons`。

### B. 移除命令面板按钮 ✅

工具栏 `▸ 命令面板` 按钮删除。入口已有 `Ctrl+Shift+P` + 标题栏 ☰，工具栏按钮是串口监视器 V3 时代历史遗留。

### C. 去除 `transform: scale()` ✅

7 处 hover/active `scale()` → `background` + `color` + `box-shadow`。消除 flex 容器内布局抖动，无 `prefers-reduced-motion` 问题。

### D. `>` → `→` ✅

Monaco 发送区前缀从终端提示符 `>` 改为方向箭头 `→`，语义更准确。

### E. 侧栏设置组分区标题 ✅

12 个设置项分 3 组，每组加 `<div class="setting-section-label">` 小标题：`显示`、`发送行为`、`编码`。

## 不做的事

- ❌ CSS 文件拆分（GL-6）— 属结构性重构，E3.5 定位是 UI 打磨，不做文件重组
- ❌ Monaco 高度 `clamp()`（SA-4）— 逻辑等价，不改
- ❌ 快捷发送表单绝对定位（QS-3）— 涉及 JSX 结构调整，风险收益比不划算
- ❌ 搜索加正则/全词匹配（SB-5）— 功能增强，非 UI 打磨
- ❌ CM6 空状态占位文字（CM-4）— 功能增强，非 UI 打磨
- ⏸️ CM6 `darkTheme` rgba 硬编码（GL-9）— `EditorView.theme` JS 对象中的 `rgba()` 是半透明叠加，浅色背景下仍可见，风险低。切主题动态跟随需要 CM6 compartment reconfigure 机制配合，属功能增强，标记 Phase 2

## 对标 VS Code

| 维度 | VS Code 做法 | LinkDesk 现状 | E3.5 后 |
|------|-------------|--------------|---------|
| 图标系统 | codicon 字体 | Emoji + 文本混用 | codicon 统一 |
| hover 反馈 | background 变化 | scale() 放大缩小 | background + box-shadow |
| 焦点可见 | `:focus-visible` outline | 多处缺失 | 全部补全 |
| 颜色管理 | CSS 变量 + theme JSON | CSS 变量为主，少量硬编码 | 零硬编码 |
| 设置分区 | 设置编辑器有 sections | 侧栏设置无标题 | 3 组标题 |
| 暗/浅双主题 | `body.vs` / `body.vs-dark` | `data-theme` 属性切换 | 保持不变，新变量双主题定义 |
