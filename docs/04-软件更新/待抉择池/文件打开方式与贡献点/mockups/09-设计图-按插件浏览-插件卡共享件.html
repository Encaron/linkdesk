#缺口本件补法

② 组件正表 props 契约——共享件零中文，文案一律调用方 t() 供给

prop型必选裁决
pluginIdstring必身份＋副文本第二行（显示名可改，id 是唯一稳定识别物）
manifestManifestIconShape可选透传 PluginIcon——图标唯一裁决源；缺省走其兜底链
titlestring必显示名（超长省略＋title 全文）
versionstring可选副文本「id · v1.2.0」
summaryReactNode可选常驻摘要（折叠/展开都在），如「声明 45 类 · 竞争 3 类」——管理器组装
expandedboolean必受控——开合策略归管理器（搜索联动、默认全收都是管理器的事）
onToggle(next)=>void必与 expanded 成对
gearItemsMenuItem[]可选卡头齿轮菜单；缺省 = 不渲染齿轮
disabledboolean可选插件停用：卡体降透明＋全惰性（E5：禁用=不参选解析）
childrenReactNode可选展开体——行清单管理器自组，不进共享包（03 §1）

③ 卡头解剖 冻结标注——尺寸是规格不是建议

🔴 嵌套按钮禁令：头里有「整头可点」和「齿轮」两个热区——button 套 button 是非法 HTML。规格：head 是 div，内含①铺满的真 <button> toggle（aria-expanded＋aria-controls）②兄弟节点齿轮绝对定位叠其上（点击天然不冒泡到 toggle）。

④ 全状态现场 真的能点——展开／齿轮／行动作全是活的

行状态全家桶：默认（自动） 当前默认（你设的）→ 恢复自动 候选 · 默认是 X → 设为默认 唯一处理者 + 停用惰性（E5）。 动作写的是 host 面 fileAssociation.setDefault——与文件树右键同一真源（E31 双向同步）。试：展开「编辑器（官方）」看 45 类限高滚动（280px）；hover 任意卡头出齿轮；hover 行出行尾动作。

⑤ 图标全链现场 来源四源枚举 × 白名单兜底——点按钮换着看

来源唯一真相源 = plugin.json 顶层 icon ＋ iconSource: codicon | svg | url | lucide（schema:63-70）； 渲染唯一组件 = 共享 PluginIcon（E6#54b 纯 props——谁有 manifest 谁传，无 registry 特权查询）； 彩色身份回退链 = marketIcon ?? icon ?? DEFAULT_PLUGIN_IDENTITY_URI（默认彩色块）。 lucide 名必须在白名单（LUCIDE_MAP）内，白名单外静默兜底；要保渲染的作者用 codicon 或 url。
📌 点开后的显示：卡内图标展开不放大（身份图全卡只出现一次——防第二真相源）；点图标 = 点头 = 展开（同一热区）。「打开插件详情」不在本件——壳现无承载命令（已查空），v1 齿轮菜单不含此项（03 §3 挂账）；卡头常驻摘要已给「声明/竞争/默认」计数。

⑥ 键盘与可及 本页就是真组件，现在就能试

Tab 站位（每卡三站）：Tab → 整头 toggle（Enter/Space 开合）→ 齿轮（焦点到达即恒显，不靠 hover）→ 展开体行动作钮。菜单内 Esc 关闭；Esc 不用于收卡（Esc 是菜单的）。焦点环 2px accent 全站可见；prefers-reduced-motion 下折角零过渡。

⑧ 生命周期 装卸／停用——卡是活物，跟插件状态走

安装第二只 PDF 阅读器 → 卡片列表即时多一张卡、.pdf 变竞争但默认不漂移（E1，激活序在前者仍持默认）＋提示链（01 §T2 第 5 条）。卸载被覆盖表指向的插件 → 覆盖键惰性失效回声明序，重装即复活（E6——键不清盘）。停用 → 卡降透明、行惰性、解析不参选（E5）。
