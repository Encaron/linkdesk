## 一、VS Code 对标

```typescript
// VS Code: explorerViewer.ts
class ExplorerCompressionDelegate implements ITreeCompressionDelegate<ExplorerItem> {
    isIncompressible(stat: ExplorerItem): boolean {
        return stat.isRoot                  // 根不可压缩
            || !stat.isDirectory            // 🔥 文件不可压缩
            || stat instanceof NewExplorerItem
            || (!stat.parent || stat.parent.isRoot); // 根直子不可压缩
    }
}

// 压缩导航控制器——管理压缩态/展开态切换
class CompressedNavigationController implements ICompressedNavigationController {
    // 段间导航（← → 在压缩段间移动）
    previous(): void;
    next(): void;
    first(): void;
    last(): void;
}
```

**关键差异：** VS Code 的压缩在树模型层（`CompressedObjectTreeModel`）——不是应用层。压缩节点自动处理展开/折叠切换。我们不依赖平台——需要自己实现等效逻辑。

## 三、三个 Bug——详解

### Bug A：同名目录压缩——点两下才展开

**场景：** `工具软件/`（根） → `工具软件/`（子目录） → ...  
**现象：** 压缩为 `工具软件 / 工具软件`，点 twistie 展开 leaf → `shouldUnfold` 可能仍为 false → 要点第二次。
**根因：** `leaf` 引用可能指向旧对象。

### Bug B：压缩链末端文件——twistie 消失

**场景：** `Unity/` → `V4.6.0/` → `standalone.exe`  
**现象：** 压缩显示 `Unity / V4.6.0`，但 `findLeaf` 返回 `standalone.exe`（文件无 twistie）→ twistie 消失→无法折叠回去。
**根因：** `findLeaf` 返回文件，`item` = 文件→无 twistie。
**对标：** VS Code `isIncompressible`——文件不可压缩。链到文件时，用文件的父目录做 twistie 控制器。

### Bug C：叶子展开后子节点不可见

**场景：** `src/` → `components/`（展开后 children 已加载）  
**现象：** twistie↓ 但下面空白。
**根因：** `flattenTree` 压缩分支 `return` 跳过子节点——即使 leaf 已展开且 children 已加载。
**已部分修复：** `18c7287` 加了 `shouldUnfold` 检查。但 #B 未修。

## 四、修复方案

**三合一——`flattenTree` 压缩分支重写：**

```
if (getCompactedPath(item)) {
    leaf = findLeaf(item)
    twistieItem = (!leaf.isDirectory && leaf.parent) ? leaf.parent : leaf
                            // ↑ Bug B 修复：文件→用父目录做 twistie 控制器
    shouldUnfold = twistieItem.isDirectory
                && model.isExpanded(twistieItem.uri)
                && twistieItem.children !== null
                            // ↑ Bug C 修复：展开后解压缩
    if (!shouldUnfold) {
        push({ item: twistieItem, compactedSegments })
        return
    }
    // fall through → 正常渲染
}
```

**改动量：** `FileTree.tsx` ~10 行。

## 五、长期方向
