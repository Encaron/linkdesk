## §1 四形态 + 转移全矩阵

**形态**：T = 标签页（主窗口 group 内）/ P = 底部面板视图（PanelZone）/ B = 壳内悬浮面板（类型 B）/ D = 独立窗口内标签页（类型 A）。（modal = OverlayWindow 已随 E5.7 整删——E5.6 七条转换路径中 (2)(3)(4) 三条 modal 边**废弃**，不复活。）

**转移矩阵（全部有向边——已定 / 废弃）：**

| 边 | 触发 | 机制 | 状态 |
|:--|:--|:--|:--|
| B → T | 面板内「在主窗口中打开」 | openTab + close（#38） | ✅ 已定 |
| T → D | 拖出主窗口边界（释放时判断）/ 右键「在新窗口中打开」 | detachTab → 新窗口 pushLayout | ✅ 已定（#44） |
| D → T 逐个拖回 | 从 D 窗口拖 tab 回主窗口释放 | 只移被拖的那一个 tab（I9-8） | ✅ 本轮定 |
| D → T 关窗并回 | D 窗口 × | mergeAllTabs 全部回归（I9-10） | ✅ 已定（E5.6 (6) + 脱出窗口设计 §3.2） |
| D → D 并窗吸附 | 拖 tab 靠近另一 D 窗口标签栏 → 吸附提示 → 放手 | 移入目标窗口（I9-4/I9-5） | ✅ 本轮定 |
| D 空窗自灭 | 最后一个 tab 移出/关闭 | 窗口销毁（I9-9） | ✅ 本轮定 |
| P → D | PanelZone ⤢ | detachPanel（#45） | ✅ 已定 |
| D(panel) → P | 漂移窗口关闭 | panel 数据回归主窗口 layout | ✅ 已定（脱出窗口设计 §7） |
| T → B | 标签页右键「在悬浮面板中打开」（仅声明 floatingPanel 视图的插件出现该条目） | 转换 = pushPanel 接管 + close tab（#38） | ✅ 已拍板（I8-3） |
| P → T | 「Move to Editor Area」升级（E5.6 (7) 曾有） | moveToEditor 通用 API（#35.5） | ✅ 已拍板建设（新铁律推翻"不做"） |
| B → D / D → B | —— | 无直达——必须中转 T（用户场景 1 已验证唯一路径） | ✅ 已定（中转） |
| T → modal / modal → T / modal → D | —— | OverlayWindow 已死 | ⚰️ 废弃 |

### 场景 1：设置链——悬浮面板 → 标签页 → 拖出窗口（唯一路径）
