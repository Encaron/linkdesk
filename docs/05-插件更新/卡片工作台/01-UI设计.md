## 二、颜色系统

> 来源：`ui-ux-pro-max` → Dark Mode (OLED) palette

### 画布级

| Token | 值 | 用途 |
|------|------|------|
| `--color-background` | `#0F172A` | 画布底色（深空蓝黑） |
| `--color-foreground` | `#F8FAFC` | 文字主色 |
| `--color-muted` | `#272F42` | 卡片背景 |
| `--color-border` | `#475569` | 卡片边框 |
| `--color-accent` | `#22C55E` | 强调色（数据绿） |
| `--color-destructive` | `#EF4444` | 危险操作（删除） |

### 卡片级（走 LinkDesk CSS 变量——跟随当前主题）

| Token | 用途 |
|------|------|
| `var(--bg-card)` | 卡片背景 |
| `var(--text-primary)` | 卡片标题 + 数值 |
| `var(--text-secondary)` | 单位 / 副文字 |
| `var(--accent)` | 滑块轨道 / 开关 ON / 进度条填充 |
| `var(--border)` | 卡片边框 |
| `var(--separator)` | 子项之间分隔线 |

**画布底色独立于主题——** `#0F172A` 是画布专用色，不随主题变。这样主题切换时，工作台卡片颜色跟着走，但画布永远是深色（对标 Figma 暗色画布）。

### 卡片类型色（可选——弹窗中可覆盖）

| 卡片类型 | 默认强调色 | 语义 |
|------|------|------|
| 数值卡片 | `var(--accent)` | 跟随主题 |
| 仪表盘 | `var(--accent)` | 跟随主题 |
| 折线图 | `var(--accent)` | 跟随主题 |
| 进度条 | `var(--accent)` | 跟随主题 |
| 指示灯 | 绿 `#22C55E` / 红 `#EF4444` / 灰 `#64748B` | 状态语义 |
| 滑块 | `var(--accent)` | 跟随主题 |
| 按钮 | `var(--accent)` | 跟随主题 |
| 开关 | `var(--accent)` | 跟随主题 |

**遵循 `dependsOn` 模式：** 弹窗中"颜色"下拉 = "跟随类型"时自定义色块消失，"自定义"时出现。

## 三、字体

| 层级 | 字体 | 大小 | 用途 |
|------|------|------|------|
| 卡片标题 | Fira Sans 600 | 13px | 卡片顶部标题 |
| 数值大字 | Fira Code 700 | 28px | 数值卡片主数字 |
| 单位 | Fira Sans 400 | 12px | 数值旁边 °C / bps |
| 副文字 | Fira Sans 400 | 11px | 子项标签 |
| 弹窗标题 | Fira Sans 600 | 14px | 弹窗标题栏 |
| 弹窗正文 | Fira Sans 400 | 13px | 弹窗内字段 |

**等宽数值：** Fira Code 的 `tnum` 特性（表格数字）——数值跳动时宽度不变，不会左右抖动。

## 四、间距系统

> `--density 8` → 密集仪表盘间距

| Token | 值 | 用途 |
|------|------|------|
| `--space-xs` | 4px | 子项内紧凑间距 |
| `--space-sm` | 8px | 子项之间间距 |
| `--space-md` | 12px | 卡片内 padding |
| `--space-lg` | 16px | 卡片之间最小间距（网格单元 = 80px 时 1 格 = 80px） |
| `--space-xl` | 24px | 弹窗内分组间距 |

**网格单元默认 80px。** 卡片之间最小间距 = 1 个网格单元。这是"高密度仪表盘"的基准——16px 间距对触摸太密，80px 刚好。

## 五、动画

> `--motion 3` → 微交互

| 动画 | 时长 | 缓动 | 用途 |
|------|------|------|------|
| 卡片 hover 图标出现 | 150ms | `ease-out` | ✕ / ≡ 淡入 |
| 弹窗打开 | 200ms | `ease-out` | 缩放 + 淡入 |
| 弹窗关闭 | 150ms | `ease-in` | 缩放 + 淡出 |
| 拖拽吸附 | 200ms | `power1.out` | 松手后卡片滑入最近网格 |
| 数值变化 | 300ms | `ease-out` | 数值大字的数字过渡 |
| 进度条变化 | 300ms | `ease-out` | 填充宽度过渡 |
| 开关拨动 | 150ms | `ease-in-out` | 拨动杆滑动 |

**遵循 `prefers-reduced-motion`：** 所有动画在系统设置"减少动效"时跳过。

| 竖条 | 1×2 | 80×160 | 竖直仪表盘 |

| 全幅 | 4×4 | 320×320 | 大波形图、全屏仪表盘 |


| 元素 | 默认 | hover |
|------|------|------|
| 标题栏 | 标题文字 | ✕ + ≡ 图标淡入 |

| 阴影 | 无 | `box-shadow: 0 2px 8px rgba(0,0,0,0.2)` |

- 所有下拉框走 `<SelectBox>`（#59c）
- 颜色选择器走 `<ColorPicker>`（#59e）
- 子项开关用 `<input type="checkbox">` + 样式覆盖

## 八、侧栏结构——卡片集 + 协议激活

```
侧栏
│
├── 卡片集 ───────────────
│   ├ 环境监测
│   ├ 电机控制
│   └ 调试
│   [+ 新建卡片集]
│
├── 协议激活 ─────────────
│   ☑ 方括号 (bracket)      所有协议平等——勾了就激活
│   ☐ SBQ                   未勾选 → 下拉框不出现、解析器不跑
│   ☐ JSON 行               全不勾 → 下拉显示"无协议"
│                           未安装的协议不出现在列表
│
└── 操作
    [导入] [导出]
```

### 协议勾选联动规则

| 操作 | 行为 |
|------|------|
| ☑ 勾选协议 | 解析器开始跑 → 标签页下拉 + 卡片弹窗下拉出现该协议 |
| ☐ 取消勾选 | 解析器停跑 → 下拉框消失 |
| 标签页当前选中协议 | 自动勾选——不能一边用一边隐藏 |
| 卡片绑定了某协议 | 该协议自动勾选——不能绑了协议但不激活 |
| 全不勾 | 下拉显示"无协议"→ 解析器不跑 → 卡片存在但不收数据 |
| 协议插件被卸载 | 从列表消失 → 自动取消勾选 → 标签页/卡片若在用它 → toast 提示 |
| 用户取消勾选但标签页在用 | toast "SBQ 正在使用" → 保持勾选 |
| 用户取消勾选但卡片在绑 | toast "ADC 卡片绑定了 SBQ" → 保持勾选或强制解绑卡片 |
| 方括号协议 | 和所有协议平等——只是一个插件，不特殊 |

**可取消的时机：** 协议没有被标签页选中、且没有任何卡片显式绑定到此协议。

## 九、响应式

工作台在桌面端使用——不设计移动布局。但需处理：

| 场景 | 行为 |
|------|------|
| 窗口缩放 | 画布不变——网格单元大小不变。用户需手动 Ctrl+滚轮缩放 |
| 标签页窄于 600px | 侧栏自动折叠为图标模式 |
| 画布超大 | 缩放控件 + 鸟瞰图（缩到 10% 看全局） |
