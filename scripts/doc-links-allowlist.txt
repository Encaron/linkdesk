# 格式：<缺失目标>	<哪条任务会建它>        （分隔符 = 制表符；理由必填，无理由 = 配置错误）
# 行首 `#` = 注释。
#
# 🔴 这份名单是给「**计划新建、但还没建**」的文档用的。
#    没有它，门禁会在「先写好引用、再补文档」的正常工作流上**假阳性** —— 闸 1 过不了。
#    ⇒ 每条必须写清**哪条任务会建它**，让「豁免」可被追账、可被回收。
#
# 🔴 与 doc-links-exclude.txt 的分工（别混）：
#    exclude.txt  = 「**这棵树下辈子也不修了**」（永久冻结的历史记录）
#    allowlist    = 「**这份文档会建，只是还没建**」（有主的欠账，建完就该删掉这一行）
#    前者是**永久**舍弃，后者是**临时**挂账 —— 挂在这里的每一条都欠一个 commit 来销账。
#
# 🔴 什么时候该往这里加：
#    只有「某条任务已经立了案、明确了要产出这个文件路径、而且已经有别的文档先引用了它」才加。
#    「我打算以后写点什么」不配进这里 —— 那是空头支票，会让门禁对一段无人负责的路径失明。
