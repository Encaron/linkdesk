# i18n 第二轮——每插件自带翻译（渲染时 t()）

> 2026-08-07 重构。原方案对标 VS Code `%key%` 包语法 → **改为方案 B：渲染时 `t()`，每插件 `i18n/` 目录。**
> 原因为 LinkDesk 单 WebView 架构不需要 `%key%` 的加载时替换——切语言即时生效，无需重载。

---

## 一、前因 + 为什么不用 `%key%`

E5#36 完成了壳源码层 `src/` 所有硬编码中文 → `t()`。插件层和主题 JSON 因量太大延后。

**原方案（对标 VS Code `package.nls.json`）：** `%key%` 占位符 → loader 加载时替换 → 存进 Registry。切语言 → Registry 里已是死字符串 → 要么重启要么重建 Registry。

**VS Code 用 `%key%` 不是设计选择，是多进程的代价：** Main Process 扫描扩展 + 替换 → IPC 传死数据给 Renderer。Renderer 改不了 Main Process 的注册表。

**LinkDesk 没这个束缚——单 WebView，i18next + React 在同一堆。** `t()` 改返回值 → React 重渲染 → 即时生效。`parseMissingKeyHandler: (key) => key` 保证没翻译时 fallback 中文原文。

**结论：不需要 `%key%` 管道。plugin.json 保留中文原文不变。** 翻译文件由每个插件自己提供。

---

## 二、整体模型

```
file-tree/
├── plugin.json            ← 中文原文不动（"title": "在文件树中显示"）
├── i18n/                  ← 新增——译文目录
│   └── en.json            ← { "在文件树中显示": "Reveal in File Tree" }
└── src/...
```

```
三层 fallback：
  t("在文件树中显示")
    → 第 1 层：查 i18next 翻译表（来自各插件 i18n/*.json + lang-defaults）
    → 第 2 层：parseMissingKeyHandler → 返回中文原文
    → 永远不出空白
```

**不需要新 API。** 壳单向读插件文件——和加载 `contributes.languages` 同一个管道。

## 四、消费端审计——哪些 UI 组件渲染 Registry 元数据

翻译注册到 i18next 后，这些消费点必须调 `t()` 才能生效：

| 消费点 | 渲染内容 | 当前是否走 t() | 修复 |
|:--|:--|:--|:--|
| CommandPalette | command.title | ❌ 直接展示原文 | 109i 覆盖 |
| FileTreeContextMenu | command.title | ❌ 直接展示原文 | 109i 覆盖 |
| SettingsView | config.properties.description + config.title | ❓ 需确认 | 审计 |
| SidePanel | viewsContainer.title | ❓ 需确认 | 审计 |
| TabBar | view.title | ❓ 需确认 | 审计 |
| StatusBar | chord 提示 | ❌ 硬编码中文 | 109k 覆盖 |
| EditorTab | "加载中…" 等 | ❌ 硬编码中文 | 109h 覆盖 |
| ThemeBrowser / LanguagePicker | theme.label | ❓ 需确认 | 109j 覆盖 |

**原则：** 所有展示给用户的 Registry 元数据字符串，渲染时包 `t()`。i18next 自带 fallback——找不到翻译就显示中文原文，零风险。

## 五、切语言流程

```
用户点击地球图标 → 切换到 "en"
  → lang-defaults: lang:changed IPC 广播
  → i18n.changeLanguage("en")
  → 所有已注册的翻译（壳 + 各插件 i18n）即时切换
  → React 重渲染——命令面板/右键菜单/设置/标签栏全部更新
  → 不需要重载，不需要重建 Registry
```

## 七、与 `contributes.languages` 的关系

两者不冲突，是两层不同的东西：

| | `contributes.languages` | `contributes.i18n` |
|:--|:--|:--|
| 谁声明 | 语言插件（lang-defaults） | **所有插件** |
| 含义 | "我是一种可用语言" | "我有自己的翻译文件" |
| 内容 | 壳级通用文字翻译 | 本插件的命令/描述/UI 字符串翻译 |
| 注册到 | i18next `"translation"` ns | i18next `"translation"` + `pluginId` ns |
| fallback | 第 2 层（全局兜底） | 和 lang-defaults 同一层（平级 merge） |
