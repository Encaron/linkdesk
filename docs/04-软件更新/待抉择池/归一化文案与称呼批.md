#### 🔴 修订（2026-10-06 实施日）：`打开键盘快捷方式` **不改名**

原「术语双词 ×2」的第二条（`键盘快捷方式` → `快捷键`）**撤销**。用户原话：

> 「那就按打开键盘快捷方式，因为那个从 ui 上看就是打开设置页面的快捷键配置界面。」

**理由**：这条命令的动作面是**打开设置页里那个快捷键配置界面**，不是「快捷键」这个词本身——`打开键盘快捷方式`（动作名）与设置页 tab 名「快捷键」（分区名）**不构成同义竞争**，是我把两个格子的词误并列了。故：

- [`settingsCommands.ts:359/361`](../../../src/core/commands/shell/settingsCommands.ts) 的 title／description **保持原样**；
- 命令面板 tooltip「配置快捷键」与菜单 label「快捷键列表」也是**换视角**的正用（同 ⑧ 判据），不动；
- 外仓**不删** `打开键盘快捷方式`、**不新增** `打开快捷键设置`（原计划的 ＋/− 一并撤销）。
- 🔴 **落锁教训**（已体现进 L2/L3）：术语锁只锁**同一格里的同义竞争**（分类词 `开发者`→`开发人员`、`偏好设置`→`首选项`）；**不同格的近似词**（动作名 vs 分区名）⛔ 不锁——锁错了会把正典的词判红，比不锁更坏。

### N4 机械锁（拍板＝补）

1. **分类前缀**：**会渲染的**命令 `title` 不得含**中文**「`分类：`」前缀（分类只走 `category` 字段）。⚠️ 边界两条（实施期实测钉死）：英文 `About: Copy` 等「Category: Action」形是 VS Code palette 惯例 ⇒ **放行**；`when: "false"` 的命令任何界面都不渲染（title 是调试标签）⇒ **不入锁**。
2. **分类词表**：`category` 取值须住正典词表（首选项/视图/标签页/帮助/文件/编辑器/开发人员），且不得是旧词（`开发者`／`偏好设置`）。⚠️ 只锁**分类格**——`打开键盘快捷方式` 经实施日改判是正典（见上节修订），⛔ 不进黑名单。
3. **字段挪用**：QuickPick 生产者 `serialize` 里 `category` 的取值不得命中状态词表（`当前`／`已隐藏`／`已激活`）。
4. **菜单覆写**：菜单项带 `command` 时，`label` 与命令 `title` **逐字相同**判红（冗余覆写）；不同则须**术语同词**（措辞可随菜单视角变，同 `移动到右侧` vs `切换侧栏位置` 的既有惯例 [`shellMenus.ts:85-87`](../../../src/core/commands/input-bindings/shellMenus.ts)）。

**实现**：[`src/core/commands/commandMetadataHygiene.test.ts`](../../../src/core/commands/commandMetadataHygiene.test.ts)（L1–L5，**每条锁配负控**——不会红的锁等于没锁；L1 的豁免边界与 L2 词表来源都写在文件头）。
