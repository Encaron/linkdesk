## 一、MarketplaceSidebar（侧栏列表——始终可见）

**文件**：[sidebar.tsx](../../../plugins/marketplace/src/sidebar.tsx) (552 行) + [MarketplaceSidebar.css](../../../plugins/marketplace/src/MarketplaceSidebar.css) (360 行)

> 这是用户与插件市场的主要交互界面。`viewRole: sidebarPrimary`，始终渲染在侧栏区域。
> 布局：安装按钮 → 搜索框 → 四分区（已安装/内置/已禁用/待安装），每个插件项有图标+名称+版本+齿轮。

### 🔴 MS-1 — 文本字符 ✕ 作为清除按钮

**位置**：[sidebar.tsx:228](../../../plugins/marketplace/src/sidebar.tsx#L228)
**当前**：`<button className="ms-search-clear" onClick={...}>✕</button>`
**问题**：✕ 是文本字符不是图标，不同字体下渲染大小不一。
**修复**：`<span className="codicon codicon-close" />`

### 🔴 MS-2 — 硬编码绿色 `#4caf50`

**位置**：[MarketplaceSidebar.css:284](../../../plugins/marketplace/src/MarketplaceSidebar.css#L284)
**当前**：`.ms-item-enable-btn { color: #4caf50; }`
**问题**：违反硬约束 #1——所有颜色走 CSS 变量。`#4caf50` 在浅色主题下可能对比度不足。
**修复**：`color: var(--success, #4CAF50)`

### 🔴 MS-3 — 硬编码 rgba 绿色

**位置**：[MarketplaceSidebar.css:292-293](../../../plugins/marketplace/src/MarketplaceSidebar.css#L292-L293)
**当前**：
```css
.ms-item-enable-btn:hover {
  background: rgba(76, 175, 80, 0.1);
  border-color: rgba(76, 175, 80, 0.4);
}
```
**问题**：硬编码 `rgba(76, 175, 80, ...)`，切主题时不跟随。
**修复**：改为 CSS 变量 `var(--success-bg, rgba(76, 175, 80, 0.1))` / `var(--success-border, rgba(76, 175, 80, 0.4))`

### 🟡 MS-4 — 齿轮按钮仅 hover 显示，键盘不可达

**位置**：[MarketplaceSidebar.css:340-354](../../../plugins/marketplace/src/MarketplaceSidebar.css#L340-L354)
**当前**：
```css
.ms-item-gear-btn { opacity: 0; }
.ms-extension-item:hover .ms-item-gear-btn { opacity: 1; }
```
**问题**：键盘 Tab 到插件项时，齿轮按钮仍在 DOM 中（`opacity: 0`），但用户看不到它，不知道那里有操作入口。
**修复**：加 `:focus-within` / `:focus-visible` 规则：
```css
.ms-extension-item:focus-within .ms-item-gear-btn,
.ms-item-gear-btn:focus-visible { opacity: 1; }
```

### 🟡 MS-5 — 搜索框 `outline: none` 焦点指示不够明显

**位置**：[MarketplaceSidebar.css:68-73](../../../plugins/marketplace/src/MarketplaceSidebar.css#L68-L73)
**当前**：`.ms-search-box { outline: none; }` + `.ms-search-box:focus { border-color: var(--accent); }`
**问题**：仅 `border-color` 变化——深色背景下 `1px` 边框色变几乎不可察觉。
**修复**：加 `box-shadow: 0 0 0 1px var(--accent)` 光晕。

### 🟡 MS-6 — 多处 `:focus-visible` 缺失

**受影响的元素**：
- `.ms-install-btn` — 无 focus 样式
- `.ms-section-header` — 无 focus 样式
- `.ms-extension-item` — 无 focus 样式（`div` 角色但 `onClick`）
- `.ms-item-enable-btn` — 无 focus 样式
- `.ms-item-install-btn` — 无 focus 样式
- `.ms-search-clear` — 无 focus 样式

**修复**：交互元素统一加 `&:focus-visible { outline: 2px solid var(--accent); outline-offset: -1px; }`

### 🟡 MS-7 — 内联 `style` 硬编码值

**位置**：
- [sidebar.tsx:331](../../../plugins/marketplace/src/sidebar.tsx#L331)：`style={{ cursor: "pointer" }}`
- [sidebar.tsx:331](../../../plugins/marketplace/src/sidebar.tsx#L331)：`style={{ opacity: 0.6 }}`
- [sidebar.tsx:337](../../../plugins/marketplace/src/sidebar.tsx#L337)：`style={{ opacity: 0.5 }}`

**问题**：`opacity: 0.5` / `opacity: 0.6` 散落在 JSX 中。`cursor: pointer` 应在 CSS 中统一设置。
**修复**：提取到 CSS 类——`.ms-item-disabled-name`、`.ms-item-disabled-desc`。

### 🟡 MS-8 — header 间距不对称

**位置**：[MarketplaceSidebar.css:11-16](../../../plugins/marketplace/src/MarketplaceSidebar.css#L11-L16)
**当前**：`.ms-header { padding: 5px 12px 8px 12px; }`
**问题**：上下 padding 不对称（5px top / 8px bottom），视觉上搜索框不居中。
**修复**：改为 `padding: 8px 12px` 对称。

### 🟡 MS-9 — 插件列表项 `div` 做可点击元素无 ARIA

**位置**：[sidebar.tsx:507](../../../plugins/marketplace/src/sidebar.tsx#L507)
**当前**：`<div className="ms-extension-item" onClick={handleClick}>` —— 用 `<div>` 做点击，无 `role`/`tabindex`/`aria-label`。
**问题**：屏幕阅读器不朗读为可交互控件，键盘 Tab 跳过此元素。
**修复**：加 `role="button"` + `tabIndex={0}` + `aria-label={m.name}` + `onKeyDown`（Enter 触发）。

### 🟢 MS-10 — 空状态无图标

**位置**：[MarketplaceSidebar.css:104-109](../../../plugins/marketplace/src/MarketplaceSidebar.css#L104-L109)
**当前**：`.ms-empty { text-align: center; }` 仅文字，无图标。
**修复**：加 codicon——`codicon-package`（无插件）/ `codicon-search`（无搜索结果）。
