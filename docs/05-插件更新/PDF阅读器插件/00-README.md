# 05-插件更新 · PDF 阅读器插件（蓝图）

> 状态：📋 **蓝图起头**（2026-10-04 用户点名，未立项未拍板）——先把「贡献什么、怎么打开、用什么引擎、分几期」铺好，未来点单即开工。源码仓尚未建（立项时按「一插件一仓」起 `E:\linkdesk-plugins\official\pdf-reader`）。
> 一句话：单击 pdf 直接开出**真正的阅读器**（渲染/翻页/缩放/搜索），不再是编辑器里的乱码；卸载即退回——这一切**只靠一行声明**，壳零改动。

## 一、定位与用户故事

用户原话：「如果我们制作了 pdf 阅读器插件，那么以后文件树的 pdf 文件被单击时打开方式就是 pdf 阅读器插件；退回路径则是卸载或没装时继续默认以编辑器打开——类似 VS Code，它甚至会在 toast 提示我应该装一个 vscode-pdf 插件。」

## 二、贡献什么（声明面，全部现成机制）

| 声明 | 作用 |
|:--|:--|
| `contributes.fileAssociations: [{ "ext": "pdf" }]` | **接管单击与 OS 打开方式**：文件树单击、Windows「打开方式→LinkDesk」都经 `FileAssociationService` 解析到本插件（机制与退回路径见壳案 [文件打开方式与贡献点 T7/T1](../../04-软件更新/待抉择池/文件打开方式与贡献点/00-README.md)） |
| `contributes.commands`（可选） | `pdfReader.pageNext/zoomIn…` 进命令面板；v1 可不做 |
| 无菜单贡献 | v1 不往文件树右键加项（「打开方式」选择器是壳侧通用能力，不需要每家自己写） |

## 三、打开逻辑（链路）

单击／OS argv → 壳解析（`fileAssociation.getPluginFor("pdf")`）→ `tabs.create("pdf-reader", { sourceId: filePath })` → 插件 entry 收 `filePath`（同 editor 的 sourceId 单通道，E5.7#98 口径）→ `lk.filesystem.readBinaryFile` 拿字节 → 引擎渲染。**全程不碰壳、不碰文件树、不碰编辑器。**

## 四、引擎选型

| 方案 | 结论 |
|:--|:--|
| **pdf.js（推荐）** | 文本层可划选复制、页内搜索、缩略图/目录全自绘；不赌池沙箱 CSP 对 `file://` iframe 的口径；Mozilla 维护、生态熟。体积 ~1–2 MB——**Monaco 先例在**（editor 连它都打包），bundle 体积不是门槛。⚠️ worker 文件要随包走通 vite 打包 |
| Chromium 内置 PDF | **否**：池渲染进程沙箱/CSP 下 iframe 指向 `file://` 的行为未验证；UI 不可定制；文本层不可控；等于把产品押在一个赌不上桌的机制上 |

| 期 | 内容 | 备注 |

## 六、任务布置（立项时照此展开）

1. 立案：本夹展开 00/01/04（照 05 惯例）→ 拍板引擎与 M1 范围。
2. 起仓：`npm run create` 脚手架 → plugin.json（fileAssociations 声明）→ `minAppVersion` 按现装壳定（**0.2.32 起步即可**，本插件零新宿主能力依赖）。
3. M1 实现＋仓内三门（test/verify/build）→ `npm run publish` → 官方目录收录 → 种子**不进**（非随包基础件，走市场安装即可验证「装了才接管」）。
4. 验收：单击 pdf／卸载退回（此时壳若已落 T1 兜底页则是干净提示，未落则还是 editor 乱码——如实记）。

## 七、依赖

- **硬依赖：无**——MVP 零壳改动（fileAssociations 机制已在跑）。
- 体验增强依赖壳案 T1（二进制守卫兜底页，管「没装本插件时 editor 里看到的什么」）与 T7（角色声明，管「editor 卸载后谁兜底」）；T2 选择器让用户可在多只 pdf 阅读器间换默认。
- **多只 pdf 阅读器共存（微软/Adobe/第三方都会来）**：默认裁决全部在壳（覆盖表＋选择器＋第二只装上不静默漂移，见壳案 D7）——本插件**零「争默认」逻辑**，装上即候选、卸载即退出，声明之外无任何动作。

## 八、边界（不做）

- 不做编辑/另存 pdf；批注笔记是 M4 远期且非本蓝图承诺。
- 不做「pdf 转文本」之类内容提取面。
- 不向壳申请任何新通道——readBinaryFile 现成。
