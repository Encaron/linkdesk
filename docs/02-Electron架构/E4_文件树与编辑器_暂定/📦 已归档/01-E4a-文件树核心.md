> 2026-07-25。**8 任务，~460 行。** 对标 VS Code Explorer 核心——数据模型 + 虚拟树 + 侧栏注册 + 欢迎视图 + 紧凑文件夹 + 排除模式。

## 一、定位

做完 E4a 后，用户点 📁 图标 → 侧栏出现文件树 → 展开目录 → 看到文件 → 图标正确 → 已排除的文件不显示 → 空工作区显示"打开文件夹"欢迎视图。

```
数据流：
  FileService.listDir(root) → FileTreeModel → ExplorerItem[] 树
    → React 虚拟列表渲染
      → 用户展开/折叠 → FileTreeModel 懒加载子节点
```

## 四、核心设计

### #88 FileTreeModel（~90 行）——对标 VS Code ExplorerModel

```typescript
// FileTreeModel.ts
interface ExplorerItem {
  uri: string;                       // 完整路径（对标 VS Code resource: URI）
  name: string;                      // 显示名称
  isDirectory: boolean;
  isSymlink: boolean;                // 🔥 符号链接标记——不能跟随删除
  children: ExplorerItem[] | null;   // null = 未加载，[] = 空目录
  parent: ExplorerItem | null;
  size?: number;
  modifiedAt?: number;
  // 装饰器（E3f #59b 注册中心 + E4c #106 消费）
  decoration?: FileDecoration;
}

class FileTreeModel {
  private _roots: ExplorerItem[] = [];
  private _expanded = new Set<string>();        // 展开的目录 URI
  private _excludeFilter: FileExcludeFilter;
  private _decorationRegistry: FileDecorationRegistry; // E3f #59b 注入
  private _sortOrder: SortOrder = 'foldersFirst'; // 可配置

  /** 获取根列表 */
  get roots(): ExplorerItem[] { return this._roots; }

  /** 🔥 懒加载——对标 VS Code ExplorerModel.getChildren() */
  async getChildren(parent: ExplorerItem): Promise<ExplorerItem[]> {
    if (parent.children !== null) return parent.children; // 已加载→直接返回缓存
    const entries = await FileService.listDir(parent.uri);
    parent.children = entries
      .filter(e => !this._excludeFilter.matches(e.name, e.isDirectory))
      .map(e => this._toExplorerItem(e, parent));
    this._sort(parent.children);
    this._applyDecorations(parent.children);
    return parent.children;
  }

  /** 🔥 按路径查找——对标 VS Code findClosest() */
  findClosest(uri: string): ExplorerItem | null;

  /** 🔥 查找所在根——对标 VS Code findClosestRoot() */
  findClosestRoot(uri: string): ExplorerItem | null;

  /** 刷新——watchFile 回调触发 */
  async refresh(path?: string): Promise<void>;

  /** 设置工作区根 */
  async setRoots(rootPaths: string[]): Promise<void>;

  /** 排序——文件夹优先 + 按名 + 按修改时间 */
  private _sort(items: ExplorerItem[]): void;

  /** 应用装饰器 */
  private _applyDecorations(items: ExplorerItem[]): void;
}
```

**关键设计决策（对标 VS Code）：**

1. **`children: null` 表示"未加载"**——对标 VS Code ExplorerItem。null ≠ []。空目录 = []，未展开 = null。这个区分对异步树至关重要：null 触发懒加载，[] 不触发。

2. **`findClosest()` 在 `revealInExplorer` 中消费**——给定 `settings.json` 的完整路径，沿着根向下查找最近的 ExplorerItem。VS Code 的同名方法处理了"路径未展开→先逐步展开再查找"的逻辑。

3. **符号链接不跟随删除**——`isSymlink` 标记。删除符号链接 = 只删链接不删目标。这是 VS Code 的行为，也是用户期望的行为。

```typescript
// FileIconResolver.ts + icon-mappings.ts
// 按扩展名/文件名解析图标——对标 VS Code seti/vscode-icons
// 🔥 图标映射与解析逻辑分离——映射存在独立文件中，数据驱动。

// icon-mappings.ts（~30 行）
// 🔥 声明式映射表——加新图标只改数据不改逻辑
const FILE_ICON_MAP: Record<string, string> = {
  // 文件名精确匹配（优先级最高）
  'package.json': 'codicon-package',
  'tsconfig.json': 'codicon-settings-gear',
  '.gitignore': 'codicon-git-ignore',
  'README.md': 'codicon-book',
  // 扩展名匹配
  '.tsx': 'codicon-react',
  '.ts': 'codicon-type-hierarchy',
  '.json': 'codicon-json',
  '.md': 'codicon-markdown',
  '.css': 'codicon-symbol-color',
  '.html': 'codicon-code',
  '.js': 'codicon-symbol-file',
  '.svg': 'codicon-symbol-snippet',
};

const FOLDER_ICON_MAP: Record<string, string> = {
  '.git': 'codicon-git-branch',
  'node_modules': 'codicon-archive',
  'src': 'codicon-folder-src',
  'components': 'codicon-folder-library',
};

// FileIconResolver.ts（~20 行）
class FileIconResolver {
  private _fileMap: Record<string, string>;
  private _folderMap: Record<string, string>;

  constructor(customMappings?: { files?: Record<string, string>; folders?: Record<string, string> }) {
    // 🔥 合并默认映射 + 自定义映射（自定义覆盖默认）
    this._fileMap = { ...FILE_ICON_MAP, ...customMappings?.files };
    this._folderMap = { ...FOLDER_ICON_MAP, ...customMappings?.folders };
  }

  getIcon(item: ExplorerItem): string {
    if (item.isDirectory) return this.getFolderIcon(item);
    const icon = this._fileMap[item.name] ?? this._fileMap[getExtension(item.name)] ?? 'codicon-file';
    return icon;
  }
  getFolderIcon(item: ExplorerItem): string {
    if (item.parent === null) return 'codicon-root-folder'; // 工装区根
    return this._folderMap[item.name] ?? (item.children !== null ? 'codicon-folder-opened' : 'codicon-folder');
  }
}
```

**🔥 v2 扩展点：** `customMappings` 注入。未来图标主题插件通过这个入口提供完整映射——替换 `FILE_ICON_MAP` 和 `FOLDER_ICON_MAP` 全部内容。映射表当前 ~30 项，v2 扩展至 ~500 项。**映射与逻辑分离确保扩展 = 换数据不换代码。**
