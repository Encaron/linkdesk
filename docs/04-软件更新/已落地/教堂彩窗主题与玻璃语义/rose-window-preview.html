玫瑰窗ROSE WINDOW · 亮色玻璃 · 三组彩窗配色

午后圣光 青金石 晚祷紫

午后的光从玫瑰窗灌注进来，落在亮色磨砂玻璃上。每一块面板都浮在深色石廊与宝石彩窗之上——玻璃把彩窗揉成温柔的光斑，金色受光边沿着面板顶部走一道。

文字是暖调深墨，不是纯黑：像旧手抄本的墨与羊皮纸。强调色取自金箔，只在真正需要亮起来的地方出现。

玻璃材质 · 三档

环境玻璃 → --glass-tint / --glass-opacity / --glass-specular　·　内容面 → --surface-reading　·　浮层 → --float-blur-floor 16px
环境玻璃表面 46% + 暖白 tint + 金色受光边标题栏 / 侧栏 / 图标栏 / 状态栏
内容面94% 暖白，承载正文卡片 / 文档 / 浮层面板
浮层磨砂玻璃面 + 保底 16px 背模糊右键菜单 / 下拉 / 提示

环境玻璃让彩窗透上来；文字面单独加厚，正文不跟背景打架。右键菜单这类浮层永远是「比主屏更重一层磨砂」——即使把玻璃不透明度拉到 0，也保底 16px 模糊，字不叠背景。

机制真相：主题的 font 域只有 ui / mono 两个键，没有「标题字体」「正文字体」这种分区——所以「部分字体改成贵重字体」在现行机制里 = 把 ui 整体换成衬线栈（Latin Constantia / Palatino + 中文 思源宋体 / Noto Serif SC），mono 仍然留给代码（Cascadia / Consolas）。壳不做逐组件字体覆盖；预览里的对照就是最终差别。
