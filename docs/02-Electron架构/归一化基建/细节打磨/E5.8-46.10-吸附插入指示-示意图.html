E5.8 #46.10 · 跨窗吸附插入指示设计示意图 · 讨论用

现象二（2026-08-22 已定位）：叠放的脱出窗标签栏被整条高亮——脱出窗 (1217,0) 时其标签栏屏幕 y∈[36,72]， 叠在主窗菜单栏 y∈[66,114] 上方。横条按目标窗渲染，叠窗时用户误认归属主窗菜单栏。 方案：对标 VS Code，两 tab 之间出细竖线插入指示（≈36px 高）替代整条高亮，归属随竖线落在哪个标签栏自然清晰。

三个设计要点

  1. 一个算法，不复制逻辑。竖线缝隙 = 池本地拖拽同一套 computeInsertIndex（提成共享 util）。 壳把光标换算成目标窗 viewport 坐标（screenX − bounds.x）随提示下发，池用自己的 tab 几何算缝。
  2. 松手落位 = 竖线缝隙，提示不撒谎。现状并窗是组尾追加（reduceInsertTab 恒 [...tabs, tab]）； 需加可选 index 参数 splice(index, 0, tab)，释放时插到竖线指的那根缝。
  3. 残留遮挡风险（诚实说明）。源窗压住目标标签栏时竖线可能被遮——现状横条同样被遮，本次不做屏幕锚点浮层， 实机验证后若体验不佳再考虑。
验收：拖 tab 靠近目标窗标签栏 → 光标所在缝隙出竖线（tab 间 / 末尾游走）→ 松手落到那根缝 → 叠窗归属清晰；拖回 / Esc / 释放 → 竖线消失。
