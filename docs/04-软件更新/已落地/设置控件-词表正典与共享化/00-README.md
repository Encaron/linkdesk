## 二、裁定规则（从设置行案 06 §四移植，本案一切取舍用它过）

- **判据 A · 声明对等律**：消费宿主声明（`uiHint`/`statusCommand`/`unit`/`effectiveToken`…）的控件，必须住在任何声明者与渲染者都取得到的层（`@linkdesk/ui`）。
- **判据 B · 词表正典律**：`uiHint` 是宿主与渲染层之间的词表，必须有唯一真相源与**可见**的降级后果。
- **判据 C · 语义不住插件律**：由宿主数据推导的读数语义（来源/生效值）随数据一起提供，⛔ 各家插件自算。
- **搬移口径**：**搬「实现成本」，留「绑定胶水」**——完整控件（背景图选择）整件搬；薄绑定（tone 两件，底座已是共享 `SegmentedRadio`）只搬**预览原子**；纯函数（徽标三件套）进共享层；`ReadOnlyStatus` 整件退场由升级后的 `ReadOnlyText` 承接。
