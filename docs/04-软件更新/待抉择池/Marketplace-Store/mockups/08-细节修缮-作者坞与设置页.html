3.3 落地声明（marketplace 的 plugin.json）

{
  "title": "插件市场",
  "subtitle": "商店的取源与点击行为——官方目录已内置，一般不用改。",
  "groupDescriptions": {
    "商店行为": "点图标与来源页的默认表现；改完即时生效。",
    "市场源": "商店从哪些目录拉插件。官方目录内置且不可删；作者仓库根目录需有 marketplace.json。"
  },
  "properties": {
    "marketplace.openTabOnIcon": { ..., "group": "商店行为" },
    "marketplace.sourcesDefaultCollapsed": { ..., "group": "商店行为" },
    "marketplace.marketplaceSources": { ..., "group": "市场源" }
  }
}

属性顺序 = 渲染顺序：两个开关在前、源列表在后。⛔ 设置插件与 @linkdesk/ui 都不动，⛔ 不发壳。
