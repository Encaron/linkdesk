## 五、实机取证口径（可复跑）

- 手法：最小 Electron 页复刻真实结构（面板 div ＋ 不透明 35px 标签栏 ＋ `top:35px` 内容层）→ `capturePage().toBitmap()` 逐像素采样。
- 读数：默认 **dark / light** 两个内置主题下 **accent 像素 = 0**（整圈被盖死）；`--bg-card` / `--bg-window` 取 `rgba()` 的玻璃主题（`theme-aurora-glass` / `theme-panorama` / `theme-zones`）才透出环。
- 🧠 推论（与你的原话③一致）：**你今天能看见环，是因为你当前主题的内容半透明**；`--surface-radius > 0` 时还会看到「圆角环横切方角」的斜角（原话④末句）。
