### ⑴ **本轴是干什么的**

E6 第 1 层（插件独立构建）的**第二个专项**，紧接 [样式命名空间归一化](../样式命名空间归一化/00-整理档案.md)（CSS 系列，已收官）。

**真问题一句话**：**软件里有一批「公共花名册」——谁都能往上写一个名字，写的时候不核对归属，撞了只小声嘟囔（或连嘟囔都没有）。**

**同形判据（四条全中才算）**：名字空间**扁平** ＋ **多方都能写** ＋ **写时无归属校验** ＋ **冲突静默**（最多 `console.warn`）。🔴 **第四条是关键**：`console.warn` **对用户不可见，对「被覆盖的那一方作者」也不可见**——因为他在自己机器上没装对方插件，一切正常。**「被覆盖」这件事，受害方永远收不到通知。**

**真根因（每一棒收尾都要能复述这句）**：

> **不是名字起坏了，是「谁的名字」被寄托在「取名自觉」上——账本要么没有，要么只用来打印一行字，而宿主自己的名字和第三方名字长着同一张脸。**

**🔄 收口口径（§〇c 修订后，此后一切以此为准）**：**根治 = 规则零例外**（**官方仓全部改名**，**机械定义 = `npm run audit:plugin-scope` 全 0**）＋ **运行时归属仲裁**兜住静态判不了的那类 ＋ 🔴 **每一处改名都同笔带迁移 ＋ 逐项操作实测**。**上位约束 = 操作体验零变化**（**名字可变，取值与功能不许变**）。**唯一保留的黄灯** = i18n 字典键；**三类「全局概念名」永久豁免**（文件关联扩展名 / 语言定义扩展名 / 语言包语言码）。

### ⑴ **本轴是干什么的**

E6 第 1 层（插件独立构建）的**第二个专项**，紧接 [样式命名空间归一化](../样式命名空间归一化/00-整理档案.md)（CSS 系列，已收官）。

**真问题一句话**：**软件里有一批「公共花名册」——谁都能往上写一个名字，写的时候不核对归属，撞了只小声嘟囔（或连嘟囔都没有）。**

**同形判据（四条全中才算）**：名字空间**扁平** ＋ **多方都能写** ＋ **写时无归属校验** ＋ **冲突静默**（最多 `console.warn`）。🔴 **第四条是关键**：`console.warn` **对用户不可见，对「被覆盖的那一方作者」也不可见**——因为他在自己机器上没装对方插件，一切正常。**「被覆盖」这件事，受害方永远收不到通知。**

**真根因（每一棒收尾都要能复述这句）**：

> **不是名字起坏了，是「谁的名字」被寄托在「取名自觉」上——账本要么没有，要么只用来打印一行字，而宿主自己的名字和第三方名字长着同一张脸。**

**🔄 收口口径（§〇c 修订后，此后一切以此为准）**：**根治 = 规则零例外**（**官方仓全部改名**，**机械定义 = `npm run audit:plugin-scope` 全 0**）＋ **运行时归属仲裁**兜住静态判不了的那类 ＋ 🔴 **每一处改名都同笔带迁移 ＋ 逐项操作实测**。**上位约束 = 操作体验零变化**（**名字可变，取值与功能不许变**）。**唯一保留的黄灯** = i18n 字典键；**三类「全局概念名」永久豁免**（文件关联扩展名 / 语言定义扩展名 / 语言包语言码）。

### ⑴ **本轴是干什么的**

E6 第 1 层（插件独立构建）的**第二个专项**，紧接 [样式命名空间归一化](../样式命名空间归一化/00-整理档案.md)（CSS 系列）。

**同形判据（四条全中才算）**：名字空间**扁平** ＋ **多方都能写** ＋ **写时无归属校验** ＋ **冲突静默**（最多 `console.warn`）。
🔴 **第四条是关键**：`console.warn` **对用户不可见，对「被覆盖的那一方作者」也不可见**——因为他**在自己机器上没装对方插件**，一切正常。**「被覆盖」这件事，受害方永远收不到通知。**

**真根因（每一棒收尾都要能复述这句）**：

> **不是名字起坏了，是「谁的名字」被寄托在「取名自觉」上——账本要么没有，要么只用来打印一行字，而宿主自己的名字和第三方名字长着同一张脸。**

**🔄 §〇c 修订后的收口口径（**此后一切以此为准**）**：

### 🔴 两条通用红线（每一棒都适用）

- **提交只按路径 `git add <本格文件>`，⛔ 禁 `git add -A` / `git add .`** —— 壳仓随时有别的会话在途（**第 0 格开工时实测工作区躺着 CSS 系列的 30+ 个改动**；且**索引是共享的**——第 0 格实测暂存区里躺着别的会话的 38 个文件 ⇒ **提交用 `GIT_INDEX_FILE` 建一个临时索引**，别把别人没做完的东西一起提上去）。
