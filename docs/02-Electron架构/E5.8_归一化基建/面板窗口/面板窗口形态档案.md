### 3.1 #31 Ctrl+J 显隐命令

- **注册命令** `workbench.action.togglePanel`——新建 `src/core/commands/panelCommands.ts`（settingsCommands 同款模式，语义域 = 面板命令；Phase 2 可逆注册已就位，registerShellLocalCommand 走新注册面）
- **键位**：`src/core/commands/shellKeybindings.ts` 加一行 `{ command: "workbench.action.togglePanel", key: "ctrl+j" }`（现网已无 ctrl+j——#88 实查）
- **状态与持久化**：`App.tsx` 加 `panelVisible` state；LayoutService panel 段加 `visible` 字段（与 height/activeViewId 同段持久化，layout.json）
- **显隐语义（零契约改动方案）**：panelVisible=false → usePoolSync 不推 panel 字段 → 池条件渲染永假（现网"无贡献即不推"语义直接复用）——**不改 PoolLayout 契约**；有 panel 贡献时 Ctrl+J 折叠/展开；无贡献时命令 no-op（无面板可开，不加 toast 噪音）
- **验收**：Ctrl+J 关→开面板；重启恢复显隐态；卸载全部 panel 贡献插件后 Ctrl+J 不崩

### 3.2 #32 [+] 新建 = QuickPick 视图选择器

### 3.8 视图动作区 + 分栏面板（2026-08-17 拍板——愿景 2 打底 #36.5/#36.6，愿景 3 展望）

- 壳统一渲染器：PanelZone 标签栏右侧动作区（按活动视图声明渲染）——widget 全壳提供（视觉一致 + 插件独立铁律：第三方声明即用零壳改动）

- 铁律对齐：widget 是**通用件**不是给终端造的——谁声明谁用（通用 API 壳先行建设不等消费方）；终端只是第一个潜在消费者

**已拍板 #36.6 侧栏动作区（一处声明两处消费）：**

### 4.1 落位定案（目标树一致性）

| 文件 | 位置 | 理由 |
|:--|:--|:--|
| `FloatingPanelHost.tsx` + `FloatingPanel.css` + `FloatingPanel.test.tsx` | **新建 `src/pool/floating-panel/`** | 「UI 功能域 = 文件夹」判据——floating/ = 模态瞬时浮层域（3 host 平铺例外），floating-panel = 非模态可拖面板域，性质不同分两域；测试同夹（判据 5） |

| DTO 类型 | `src/core/types/poolFloatingPanel.ts` | poolDialog/poolQuickPick/poolToast 同款（#0d.7 步 6 规范 types 列名同步补） |

### 4.2 桥模式（DialogService 同款——归一化）

壳 FloatingPanelService：`pushPanel({ viewId, title, actions })` 序列化 DTO 推池 → 池 FloatingPanelHost 按 **viewId 寻址视图注册表**渲染（内容 = 插件视图——settings/marketplace/未来主题制作器同一条路，壳不持有渲染器）→ 动作回传（"在主窗口中打开"/"最大化"/"关闭"）settle 回壳。**插件 API 面 = 声明制 + 通用 API（#39.5，2026-08-17 新铁律拍板建设）**：contributes.floatingPanel 声明 + linkdesk.panel.revealFloating（身份开关键语义）——原"插件 API 面零新增"被新铁律推翻。
