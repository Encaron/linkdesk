# E3b — 主题引擎跨进程

> 2026-07-24。从旧 P7c 主题部分迁移，适配 Electron。
> **性质：** 让主题成为一等公民插件类型 + 跨 WebView CSS 变量广播。

---

## 一、主题三层退路（照抄 VS Code）

| 层 | VS Code | LinkDesk |
|------|------|------|
| 第 1 层 | `settings.json` → `workbench.colorTheme` | `settings.json` → `app.theme` |
| 第 2 层 | `theme-defaults` 扩展（10 个内置主题，可卸载） | `plugins/theme-dark/` + `plugins/theme-light/`（出厂预装，可卸载） |
| 第 3 层 | `defaultThemeColors` 硬编码对象 | `index.css` `:root` 的 CSS 变量值 |

```
#2 出厂主题：
  plugins/theme-dark/plugin.json → {"contributes":{"themes":[{"id":"dark","uiTheme":"dark","path":"dark.json"}]}}
  卸载后回退到第 3 层。

#3 硬兜底：
  index.css :root { --bg: #1e1e1e; --fg: #cccccc; ... }
  永远存在。不依赖任何插件或 JSON 文件。
```

## 二、主题贡献格式（对标 VS Code `themeExtensionPoints.ts`）

```json
{
  "name": "Dracula",
  "contributes": {
    "themes": [
      {
        "id": "dracula",
        "label": "Dracula",
        "uiTheme": "dark",
        "path": "dracula.json"
      }
    ]
  }
}
```

**和 VS Code 的差异：**
- `uiTheme` 值：`dark` / `light` / `highContrast`（简化——我们没有 textmate token 渲染）
- `path` 指向 CSS 变量 JSON（VS Code 指向 .tmTheme）
- `id` 用于 `settings.json` 的 `app.theme`

**兼容逻辑：**
```
loader 检测主题：
  有 contributes.themes → 新格式注册
  有旧 file 字段 → 升级为 contributes.themes 等价注册
      （id = pluginId, uiTheme = 从 JSON 推断, path = file）
  都没有 → 不注册
```

## 三、CSS 变量跨进程广播

多 WebView 后，主题切换的核心问题：

```
切到 Dracula：
  1. 壳读 dracula.json → 得到 CSS 变量键值对
  2. 壳写入自己的 :root（壳 WebView 生效）
  3. 壳通过 IPC 广播给所有插件 WebView
     → { channel: "theme:changed", payload: { themeId, variables: {"--bg":"#282a36",...} } }
  4. 插件 WebView 收到 → 动态注入 <style> 覆盖 :root
```

```typescript
// 壳侧 ThemeEngine
class ThemeEngine {
  async switchTheme(themeId: string): Promise<void> {
    const theme = ThemeRegistry.get(themeId);
    const variables = await FileService.readFile(theme.path);
    // 壳自己应用
    applyVariables(variables);
    // 广播给所有插件 WebView
    ipc.broadcast("theme:changed", { themeId, variables });
  }
}

// 插件侧（每个 WebView 独立处理）
ipc.onEvent("theme:changed", ({ themeId, variables }) => {
  document.documentElement.setAttribute("data-theme", themeId);
  let style = document.getElementById("linkdesk-theme");
  if (!style) { style = document.createElement("style"); style.id = "linkdesk-theme"; document.head.appendChild(style); }
  style.textContent = `:root { ${Object.entries(variables).map(([k,v]) => `${k}:${v};`).join('')} }`;
});
```

## 四、主题浏览器 UI

对标 VS Code `Preferences: Color Theme`：

```
Ctrl+K Ctrl+T → 主题选择器弹出
  ├── 搜索框（模糊搜索所有已安装主题）
  ├── 主题列表（名称 + 色板预览色块）
```

## 五、产品图标主题（Product Icon Theme）

消费 ThemeRegistry，插件可贡献图标集：

```json
{
  "contributes": {
    "productIconThemes": [
      { "id": "codicon", "label": "Codicon", "path": "codicon.json" }
    ]
  }
}
```

图标引用：`{ "icon": "folder", "iconSource": "codicon" }`。未指定 iconSource → 默认图标集。
