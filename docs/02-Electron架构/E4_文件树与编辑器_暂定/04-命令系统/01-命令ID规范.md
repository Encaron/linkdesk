## 五、AI 进场须知 🛡️

- **所有 handler 是占位**——修 #27 时才替换。不要惊讶 `console.warn`
- **新增命令 → 登记到本文件**——避免 ID 冲突
- **`explorer.*` 命名空间**——非文件树自己的操作不用这个前缀
- **命令注册在 `FileTreeContextMenu.tsx` 模块级 `activateFileTreeContextMenu()`**——幂等（`_registered` guard）
