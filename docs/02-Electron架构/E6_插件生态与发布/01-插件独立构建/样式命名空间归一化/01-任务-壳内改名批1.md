## 二、步骤

1. 按 §1.1 / §1.2 逐条改（建议逐文件改 + 每改一个跑一次 `npx vitest run <该组件的 test 路径>`）。

   - `check-css-namespace` 判据⑤「登记 ↔ 实况反向核对」→ 说明 JSON 没摘干净（或摘多了）；

- TSX：**只改类名位置**。本批的类名位置全部落在 `className=` 及其拼接数组/模板串里（§1.1 已逐条列出）。
