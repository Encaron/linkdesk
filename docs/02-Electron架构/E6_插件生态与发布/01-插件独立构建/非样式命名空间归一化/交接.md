### ⑴ **本轴是干什么的**

E6 第 1 层（插件独立构建）的**第二个专项**，紧接 [样式命名空间归一化](../样式命名空间归一化/00-整理档案.md)（CSS 系列）。

起因：用户 2026-09-16 问「**除了 UI 这部分外，其余部分有没有类似的问题？如数据通信部分？……又或者声明的东西，又或者命令类。**」＋「**不仅仅是我提到的，你还可以自己再找一找。**」；**第二次拍板**（同日晚些）：「**我需要一个极其完善的，根治的方案，所以我问你是否是根治方案。**」＋「**要新增官方仓的插件整理工作对吧，工作量是不是会大一点？如果是的话，建议加任务**」＋「**那十几个主题插件、普通测试插件、语言翻译插件等可以一到两个 AI 做了**」。

**真问题一句话**：**软件里有一批「公共花名册」——谁都能往上写一个名字，写的时候不核对归属，撞了只小声嘟囔（或连嘟囔都没有）。**

**同形判据（四条全中才算）**：名字空间**扁平** ＋ **多方都能写** ＋ **写时无归属校验** ＋ **冲突静默**（最多 `console.warn`）。
🔴 **第四条是关键**：`console.warn` **对用户不可见，对「被覆盖的那一方作者」也不可见**——因为他**在自己机器上没装对方插件**，一切正常。**「被覆盖」这件事，受害方永远收不到通知。**

**真根因（每一棒收尾都要能复述这句）**：

> **不是名字起坏了，是「谁的名字」被寄托在「取名自觉」上——账本要么没有，要么只用来打印一行字，而宿主自己的名字和第三方名字长着同一张脸。**

**🔄 §〇c 修订后的收口口径（**此后一切以此为准**）**：
- **根治 = 规则零例外**（**官方仓全部改名**，不是"登记例外"；**机械定义 = `node scripts/audit-plugin-scope.mjs` 全 0**）
  ＋ **运行时归属仲裁**兜住静态判不了的那类（两个不同第三方 / 动态拼名）
  ＋ 🔴 **每一处改名都同笔带迁移 ＋ 逐项操作实测**（改名的设置项仍能切换/值沿用 · 改 id 的快捷键仍触发 · 改 id 的主题仍跟随）。
- **上位约束**：**操作体验零变化**（**名字可变，取值与功能不许变**）—— 旧说法「除版本号外不要有任何 UI 变化」**已被用户本人修订**。
- **唯一保留的黄灯**：**i18n 字典键**（跨仓不可判）；**三类「全局概念名」永久豁免**：文件关联扩展名 / 语言定义扩展名 / 语言包语言码。
- **两条统一机制（都在仓里有现成先例，不必发明）**：**A 宿主保留名账进 SDK**（照 `packages/plugin-sdk/schemas/reserved-class-names.json`）· **B 运行时首撞者保留 ＋ 后来者降级不覆盖 ＋ `console.error`**（🔴 **不许抛错**——`parseContributions` 无 try/catch ⇒ 抛错 = **整只插件装不上，比现在更坏**）。

**第 0 格已交付**：① [00 总方案](00-整理档案.md)（含 **§〇c 口径修订令** ＋ 全量普查表 ＋ 收口定义 ＋ 残余边界十一条 ＋ 原则对照 ＋ **20 轮总表**）；② **20 份任务书**（[01](01-任务-命令id归属评估.md)–[20](20-任务-本轴收口复核.md)，含**迁移基建**与**官方仓清账 7 格**）；③ E6 清单任务格；④ 本交接文件。

**第 0 格的实测发现（后面每一棒都要用到）**：
- 🔴 **三条活体（今天正在发生的跨方冲突）**：① 官方 `file-tree` **注册了两个 `editor.*` 命令**（`src/components/FileTreeContextMenu/commands/compare.ts:15,19`）⇒ 卸载它永不清理、卸载 `editor` 反而会删掉它们；② `file-tree` **在设共享组件的旗子 `inputFocus`**（`useTreeRename.ts:35,41`）⇒ 两方同屏互相踩；③ `theme-defaults` 声明的主题 id **就是宿主兜底 id `light`**（**有意交接**，但顺带证明兜底 id 是**无主空位**）。
- 🔴 **归属「从名字推」**：命令 id 的运行时路径用 `commandId.split(".")[0]` 当身份（`src/core/registry/commands/CommandRegistry.ts:150,186`）⇒ **同名前缀时覆盖告警被整段吞掉**。
- 🔴 **宿主伪 pluginId `app` / `appearance` / `update` 一个都没设防** ⇒ 第三方可合法同名，**连 warn 都不响**。
- **逐插件清账面**：`file-tree` **75** · `marketplace` **6** · `settings` **4** · `serial-monitor` **2** · `editor` **1** · 主题族 **1–6 各** · 其余 **0**（≈ **123 处**）。

### 🔴 两条通用红线（每一棒都适用）

- **提交只按路径 `git add <本格文件>`，⛔ 禁 `git add -A` / `git add .`** —— 壳仓随时有别的会话在途（**第 0 格开工时实测工作区躺着 CSS 系列的 30+ 个改动**；且**索引是共享的**——第 0 格实测暂存区里躺着别的会话的 38 个文件 ⇒ **提交用 `GIT_INDEX_FILE` 建一个临时索引**，别把别人没做完的东西一起提上去）。
