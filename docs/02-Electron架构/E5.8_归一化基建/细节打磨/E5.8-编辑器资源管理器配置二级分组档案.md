E5.8#78 把二级标题做成通用能力时，壳/设置插件不区分「主题键还是插件键」：

| 链路 | 位置 | 结论 |
|---|---|---|
| 契约类型 | `contracts/linkdesk.d.ts:62` `group?: string` | ✅ 注释明确「第三方键声明即得同能力（零壳改动）」 |
| 加载器透传 | `src/pluginLoader/contributions.ts:55` properties 直 cast 进注册表 | ✅ 无字段过滤，plugin.json 的 `group` 原样流入 |
| IPC 边界 | `src/core/services/plugins/IpcBridgeHandler/configuration.ts:52` | ✅ getSchema 只剥 `onApply`（结构化克隆拒绝），group 完整透传 |

**结论：插件侧纯声明，全程不动设置插件任何代码、不动壳运行时代码。**

## 四、i18n 碰撞分析与处置（关键决策）

设置插件渲染 `t(bucket.group)`。group 值 = plugin.json 里的中文节名。池 i18n 字典（lang-defaults）已含部分高频词，且插件 i18n 用 `addResourceBundle(overwrite=true)` 合并（`src/pluginLoader/i18nResources.ts:27`）——**若插件 en.json 声明同名键会覆盖全局字典**：

| 节名 | lang-defaults/en.json 现值 | 处置 |
|---|---|---|
| 文件 | `File`（文件菜单用词） | **不加**——lang-defaults 已解析为 File，避免覆盖菜单翻译 |
| 显示 | `Display`（值恰好一致） | **不加**——同值无冲突 |
| 编辑 | `Edit`（编辑菜单动词） | **不加**——避免覆盖菜单翻译 |
| 字体/缩进/光标与滚动/智能提示 | 无 | 加进 editor/en.json（Fonts/Indentation/Cursor & Scrolling/Suggestions） |
| 行为/删除与确认/排除与嵌套/外部终端 | 无 | 加进 file-tree/en.json（Behavior/Delete & Confirm/Exclude & Nesting/External Terminal） |

**audit-i18n 门禁不受影响**：它只扫源码 `t("字面量")` 报缺翻译，不扫 plugin.json 动态 group 值；en.json 多余键不报。
