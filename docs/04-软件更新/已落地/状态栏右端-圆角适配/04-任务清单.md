## 五、边界（本轮明确不做 · 见 [00 §六](00-README.md)）

- ⛔ **不动状态栏高度**（`22px × --ui-scale` 是与 VS Code 对齐的既定契约）。
- ⛔ **不动壳固定项的命令接线**（`workbench.action.selectLanguage` / `theme.pick`）与通知中心逻辑。
- ⛔ **不碰插件贡献项的渲染契约**：`PoolStatusBarItem` 三形态（component / button / span）零变化——**不加形态、不改 DOM**。⚠️ 但要如实记一条：`.ldk-status-bar-btn` 是**共享类**，插件贡献的**可点击**状态栏项（[StatusBarZone.tsx:201](../../../../src/pool/zones/status-bar/StatusBarZone.tsx) `item.onClick` 分支）走同一类，故形状语言（18px／药片／让位）对它们一并生效——**这正是 00 §六「本件只治 `.ldk-status-bar-btn` 的形状语言」的口径**，同类同形是期望结果，非外溢事故。
- 玻璃态（`--bg-window` 半透明）下的 hover 底色对比度**实机核一次**（阶段 2.5）。
