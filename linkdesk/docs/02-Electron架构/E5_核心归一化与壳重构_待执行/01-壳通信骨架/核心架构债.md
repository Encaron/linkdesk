## P3 🟡 IpcBridgeHandler 接口反转

### 现状

```typescript
// src/core/IpcBridgeHandler.ts L19-29
import {
  installPlugin, uninstallPlugin, reinstallPlugin,
  loadPlugin, loadPluginRuntime, activatePlugin,
  disablePlugin, enablePlugin, resetPluginCounter,
  getLoadedPluginManifests,
} from "../pluginLoader/loader";
```

**Core 直接 import pluginLoader 的 10 个具体函数。** loader 改函数签名 → bridge 炸。

### 修复——Core 定义接口，loader 实现

```typescript
// src/core/IpcBridgeHandler.ts（改后）
export interface PluginManagementAPI {
  installPlugin(src: string): Promise<string>;
  uninstallPlugin(id: string): Promise<void>;
  reinstallPlugin(id: string): Promise<void>;
  loadPlugin(id: string): Promise<void>;
  loadPluginRuntime(id: string): Promise<void>;
  activatePlugin(id: string): Promise<boolean>;
  disablePlugin(id: string): Promise<void>;
  enablePlugin(id: string): Promise<void>;
  resetPluginCounter(id: string): void;
  getLoadedPluginManifests(): Array<{ id: string; manifest: Record<string,unknown> }>;
}

let _pluginAPI: PluginManagementAPI | null = null;

export function setPluginAPI(api: PluginManagementAPI): void {
  _pluginAPI = api;
}

// handler 中改为调 _pluginAPI.installPlugin(src)
// 不再直接 import loader.ts 的函数
```

```typescript
// pluginLoader/loader.ts（改后——注册自己）
import { setPluginAPI } from "@src/core/IpcBridgeHandler";
setPluginAPI({
  installPlugin, uninstallPlugin, reinstallPlugin,
  loadPlugin, loadPluginRuntime, activatePlugin,
  disablePlugin, enablePlugin, resetPluginCounter,
  getLoadedPluginManifests,
});
```

**依赖反向。** 以前 core → pluginLoader。现在 pluginLoader → core（实现 core 定义的接口）。
