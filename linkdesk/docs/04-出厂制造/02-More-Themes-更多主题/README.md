# 02-More Themes ×3（更多主题）

> **类型：工厂插件** — 预装在 `resources/themes/`，出厂自带但本质是插件（JSON 文件），用户可删。
> **状态：🔥 第二优先——跟着轮播一起做**
> 轮播里只有 4 张卡片太寒酸。7 张才像画廊。

---

## 基本逻辑

在现有 4 个主题（3 暗色 + 1 亮色）基础上，新增 3 个主题：
- **棉花糖 Marshmallow**（亮色·可爱风·粉+奶白）
- **抹茶拿铁 Matcha Latte**（亮色·清新·抹茶绿+米色）
- **琥珀高对比度 Amber HC**（暗色·高对比度·琥珀+深黑）

每个主题 = 33 色键的 JSON 文件。放到 `resources/themes/` 目录，自动被 ThemeBrowser 发现。

resources/themes/

## 生态地位

| 维度 | 说明 |
|------|------|
| **用户获取** | 主题数量 = 软件"成熟度"信号。4 个 = "刚做"，7 个 = "认真做了" |
| **差异化** | 亮色可爱风——VS Code 没有可爱的亮色主题。这是 LinkDesk 的人格 |
| **可访问性** | 高对比度主题——为视障用户准备的入口。有它 = 有 accessibility 意识 |
| **市场示范** | 这 7 个是"出厂主题"。它们是主题制作器的参考模板——用户打开 Maker 看到的就是这些 |

## 三个新主题详细规格

### 🌸 棉花糖 (Marshmallow) — 亮色·可爱

```
主色调:  粉 #FFB5C2 + 奶白 #FFF5E4
风格:    软、暖、圆角加重
目标:    女性用户、儿童、想放松的时候
特点:
  - 背景不是纯白，是奶油色 #FFF5E4（纯白刺眼）
  - 侧栏底色略深一号 #FFE8D6
  - 强调色是柔粉而非亮蓝
  - 按钮圆角加大（8px → 12px）
  - 选中态用柔和的粉色高亮
  - 代码区底色保持浅灰（不能粉色代码背景——太晃眼）
```

### 🍵 抹茶拿铁 (Matcha Latte) — 亮色·清新

```
主色调:  抹茶绿 #7ECB76 + 米色 #F5F0E8
风格:    干净、护眼、日系
目标:    长时间使用、眼睛疲劳少
特点:
  - 背景是温暖米色，不是冷白
  - 侧栏底色略深 #EBE5DB
  - 强调色是抹茶绿 #7ECB76
  - 代码区保持浅灰底
  - 整体对比度偏低——护眼向
  - 选中态用淡绿色高亮
```

### 🔶 琥珀高对比度 (Amber HC) — 暗色·高对比

```
主色调:  琥珀 #FFB000 + 深黑 #0D0D0D
风格:    边框清晰、色差大、可访问性
目标:    视障用户、户外强光下使用
特点:
  - 背景 #0D0D0D（比暗色默认更深）
  - 文字 #FFFFFF（纯白，不用灰）
  - 边框 #FFB000（琥珀色边框清晰可见）
  - 所有 UI 元素都有可见边框（不只是颜色区分）
  - 选中态用琥珀色边框 + 背景微亮
  - 代码区语法高亮色差 ≥ 7:1（WCAG AAA）
  - 按钮有明确边框，不只靠颜色区分
```
