## 3. 双Pool 死代码（E5.6 时代）

| 文件 | 删的内容 |
|:--|:--|
| `electron/overlay-window.ts` | 整文件删除——OverlayWindow 类 ~400 行 |
| `electron/window-manager.ts` | `sidebarPoolView` / `mainPoolView` 双 WCV 管理 + `createPool()` / `destroyPool()` / `rebuildPool()` / `updatePoolBounds()` → 简化为单 WCV `mainPoolView`；`toggleDevTools()` 去 zone 参数 |
| `src/overlay/` | 🔴 整目录删除——OverlayWindow 侧渲染器（MenuRenderer/QuickPickRenderer/ToastRenderer/overlay-main.tsx）迁入 FloatingLayerHost |
| `src/pool/pool-main.tsx` | `RENDERERS` 注册表 + `?zone=` 路由 → 单入口 PoolZoneShell |
| `src/pool/sidebar/` | 整目录删除——SidebarRenderer 迁入 zones/SidebarZone.tsx |
| `src/pool/main/` | 整目录删除——MainRenderer 分解入 zones/EditorZone.tsx |
| `src/components/MainContent.tsx` | 🔴 壳侧标签页渲染逻辑——分解入 TabBarZone + EditorZone（壳渲染进程保留 tabState 等状态逻辑，见执行清单 E5.7#9） |
| `src/App.tsx` | TitleBar / IconBar / TabBar / StatusBar 渲染代码——迁入 zones/ |
| `src/components/` | 壳 UI 组件（TitleBar/TabBar/StatusBar/IconBar 等）——如已被 zones 替代则删除 |
| `electron/keyboard-router.ts` | `getAllInstanceIds()` 遍历 → **单 Pool**（不是"两个 Pool"） |

> 🔴 **壳渲染进程不删。** 壳保留状态逻辑（tabState/syncLayout/pushLayout/Registry/命令执行）——只删 UI DOM。壳 = 纯状态持有者，池 = 纯渲染。
