## 设计 DNA（现有）

- **配色**：Dark Mode (OLED)，CSS 变量全覆盖（`var(--bg-card)` / `var(--accent)` 等）
- **字体**：Sarasa Mono SC（更纱黑体）用于等宽内容，Inter 用于 UI
- **连接状态点**：8px 绿点 + `box-shadow` 脉冲动画
- **Session 色条**：6 色循环分配（绿蓝琥珀紫青粉），`border-left` 标识
- **Hover 操作**：`opacity: 0 → 1` 渐变揭示（齿轮、改名/删除按钮）
