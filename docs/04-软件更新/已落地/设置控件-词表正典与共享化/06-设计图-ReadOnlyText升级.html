帧 3 · EffectiveBadge——是什么、显示什么、摆在哪设置行尾＝已定稿位②③④＝通用性候选（拟定值）

它是什么：共享层的新呈现件，props { label?, value, color? }——「生效：」前缀＋生效值（＋可选色块）。值从哪来：宿主把 effectiveToken 解成 { source, effective?: { value } } 随配置读面一起给，共享 formatEffectiveValue 负责把字体栈截首族／色值配色块——任何调用方拿到的是同一个答案。通用性＝键声明 effectiveToken 即得（含第三方键）＋呈现件任何面板可摆（下面②③④）；它不进驻状态栏（噪音）。
