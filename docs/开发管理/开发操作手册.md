## 环境准备（仅此一次）

### 系统依赖

| 需要 | 安装方式 |
|---|---|
| **Node.js ≥20**（LTS） | [nodejs.org](https://nodejs.org)——装完 `node -v` 确认 ≥20 |
| **Git** | Visual Studio Code 自带（Git Bash） |

**不需要：** Rust / Cargo / Visual Studio Build Tools / WebView2 / Python / Tauri CLI。

### 首次拉工程

```bash
git clone <仓库地址> E:\linkdesk
cd E:\linkdesk\linkdesk
npm install
```

`npm install` 会装 `electron`（~180MB，含 Chromium）+ `electron-builder` + `serialport`。只此一次。

## 三种运行方式

### 方式 1：纯前端热更新（调 UI 最快）

改 React 组件 → 保存 → 浏览器瞬间刷新。

```bash
cd E:\linkdesk\linkdesk
npm run dev
```

浏览器打开 `http://localhost:1420`

**优点：** F12 DevTools、断点、React Profiler  
**缺点：** 没有 Electron 主进程功能（串口、文件系统、对话框不可用）  
**怎么停：** `Ctrl+C`

### 方式 2：Electron 桌面窗口（主力开发）

弹出真正的桌面窗口，完整功能。

```bash
cd E:\linkdesk\linkdesk
npm run electron:dev
```

**优点：** 串口收发、文件系统、对话框全部可用，前端热更新同时生效  
**缺点：** 每次启动比 Vite 慢 ~3 秒（等 Electron 启动 Chromium）  
**怎么停：** 关掉窗口 或 `Ctrl+C`

### 方式 3：打包安装（最终验证）

```bash
npm run electron:build
```

生成 `dist/LinkDesk Setup x.x.x.exe`。装完跟用户看到的一模一样。

> 🔴 **打包版验证纪律（2026-09-11 用户拍板）——验新构建必须用「干净配置」**
>
> **症状：** 重新打包后打开安装版，界面还是老样子，看起来像「新代码没生效」。
> **真因：** 随包插件在**首次启动时解压一次就定住了**——之后启动**不论版本是否变化都不覆盖**（E6#15n/#15o 的设计：软件是软件、插件是插件，插件走市场更新，壳升版不带插件升）。你机器上那个配置里的插件，是你第一次开安装版时的老版本。
> **正解（二选一）：**
> - **一次性空白配置**（验证首选，最干净）：`LinkDesk.exe --user-data-dir=<scratch 下的空目录>` → 从随包 zip 全新建档 18 个插件。
> - **强制重新解压**（在现有配置上验）：`LinkDesk.exe --force-rematerialize-bundled`（或环境变量 `LINKDESK_FORCE_REMATERIALIZE=1`）。
>
> **别直接开安装版就下结论**——那验的是旧代码，会得出假结论（我 2026-09-11 就踩过：看到 1.0.17 老界面，误以为拆分没生效）。
> 验完即关即删配置目录，不留垃圾（「一跑一清」）。

## 日常套路

```
开发 UI    → npm run dev + 浏览器    （秒级反馈，F12 调试）
日常主力   → npm run electron:dev    （完整桌面窗口，前端热更新）
最终验收   → npx electron .          （干净启动，不跑 Vite HMR）
打包分发   → npm run electron:build  （生成 Setup.exe）
```

---

## 热更新规则

| 改了哪 | Vite（浏览器） | Electron dev（窗口） |
|---|---|---|
| React / CSS / TS（`src/`） | 瞬间刷新 | 瞬间刷新（Vite HMR） |
| Electron 主进程（`electron/`） | N/A | **需手动重启**（`Ctrl+C` → 重跑 `electron:dev`） |
| preload 脚本（`electron/preload-*.ts`） | N/A | **需手动重启** |
| 插件代码（`plugins/`） | 瞬间刷新 | 瞬间刷新 |

**前端热更新不关窗口。** 改了 `electron/` 或 preload 才需要重启。

## DevTools 技巧

### Electron 窗口里粘贴代码到 Console

Electron 的 DevTools Console 默认禁止粘贴（安全警告）：

```
Warning: Don't paste code into the DevTools Console that you don't understand...
```

**解法：** 在 Console 输入框里打 `allow pasting`，回车。之后就能正常粘贴了。每次都需重新输——窗口重启后重置。

---

## 注意事项

- Vite 和 Electron 不能同时跑——都占 `:1420` 端口。先 `Ctrl+C` 再换。
- `npx electron .` 是干净启动（不走 Vite），用来验"用户拿到的 exe 长什么样"。
- 改了 `package.json` 的 electron 版本 → 跑 `npm install` 重新下载对应版本的 Chromium 二进制。
