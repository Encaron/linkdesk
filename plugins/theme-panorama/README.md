# 整窗主视觉

把整扇窗当成一张画——**极限壳主题**，压的是 `background` 域。

## 这是什么

一只**纯数据插件**，但它演示的是主题系统里最深的一档：普通主题只换颜色，这一套换的是**整窗的背景层**——一张全窗底图铺满，窗口的各个面（图标栏 / 侧栏 / 标题栏…）改成半透明让位，于是底图从所有缝隙里透出来。

- 插件 ID：`theme-panorama`
- 系统类型：暗色（dark）
- 色板：月夜主视觉
- 压的是：`background` 域（全窗底图 + 半透明 chrome）

> 它存在的意义：**证明主题能改到「整个窗口长什么样」这一层**，而不只是「按钮是什么颜色」。

## 结构

```
plugin.json                  声明（contributes.themes）
themes/panorama.json         色板（含全窗底图与各面的半透明设定）
```
