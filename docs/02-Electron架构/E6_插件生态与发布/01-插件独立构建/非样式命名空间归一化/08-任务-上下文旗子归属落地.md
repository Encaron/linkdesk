### 2.2 生成器（**含本格必修的头号缺陷**）

- 🔴 **修截断**：`:214` 的正则 `[^"'`]+` 把 `'` 当终止符 ⇒ `when: "settingKey == 'x' && myFlag"` 只抓到 `settingKey == `，**`myFlag` 静默不进账**（**假绿**）。改法：**取完整表达式**（引号配对）＋ token 切分 ＋ **比较值过滤显式化**（今天靠"正则出错"侥幸过滤掉 `left`/`right`/`backgroundImage`——**账对，理由错**）。
- **约定面自动派生**：`ctxPublic = ctxRead − ctxWrite − {initCoreKeys 三键} − {UPDATE_*_KEY 两键}` ⇒ 今天自动得到 `settings*` 4 项。
- **两段都进 `renderRuntimeModule()`**（运行时副本）。
- 🔴 **负控 ⑥/⑥′ 必须真跑**（[1.37 §十六](07-任务-上下文旗子归属评估.md)）：⑥ `== 'left'` ⇒ `left` **不进账**；⑥′ `== 'x' && myFlag` ⇒ `myFlag` **必须进账**。

### 2.4 运行时仲裁（**🔴 本格最易写错的一条**）

> 🔴 **旗子是「状态写」不是「注册」⇒ 不许照搬 1.36 的「先者保留」。仲裁 = `console.error` 点名 ＋ 放行。**

**三个「不许」：**
- ⛔ **不许「先者保留」**——`:204-208` 过桥时**身份已丢**（`commands:register` 追加 `windowId`，`contextKey:set` **不追加**）⇒ 运行时**拿不到「谁是先者」**；且语义也错：同一个 `settingKey` 从 A 行移到 B 行**正是靠覆盖实现**。
- ⛔ **不许拒绝**——`gearMenu.ts` 的 `handleGearClose`（`:36-43`）**主动写回** 4 个旗子；拒绝会打断正常关闭流程。且**静默拒绝更隐蔽**（调用方 `await` 成功）。
- ⛔ **不许抛错**（[00 §2.7](00-整理档案.md)）。

**如实登记**：运行时**只能对「宿主专用」出声**，且**身份不全**（§1.4）。⇒ 🔴 **保护主力在静态腿，运行时是第二道网**——**这句必须写进本格的收官报告**，否则会误以为运行时能兜住一切。

### 2.5 活体样本 `settings` —— 走「登记为宿主公开约定面」

**为什么不是改名**（[1.37 §13.2/§13.5](07-任务-上下文旗子归属评估.md)）：改名要**动 2 仓 15 处**（`gearMenu.ts` 8 写 ＋ `coreCommands.ts` 3 读 ＋ `SettingRow.tsx:118` 1 overrides ＋ 命令处理器 3）＋ **`settings` 发版 ＋ 目录回填 ＋ 出厂种子**，且**打破第三方兼容**；而收益（统一前缀）**不足以抵**。**"没有账"才是病根，进了账 ＋ 有机器读 ＋ 冲突出声即达成判据目标。**

**三件加固（缺一即只是"漏网"）：**
1. **账单独成段** `contextKeysPublic`（红/黄可区分）；
2. **双向对账照旧覆盖**（多一个少一个都红）；
3. **运行时出声 ＋ 作者面明写**（两棵树「宿主约定面」表：**可以设，但只有 `settingItemGear` 齿轮菜单该设**）。

⚠️ **`MenuId` 是开放字符串**（`public/schemas/plugin.schema.json`）⇒ **第三方可加入 `settingItemGear` 槽并读这 4 个名字** ⇒ 这 4 个**事实上已是公开约定面** ⇒ 「只授权 `settings`」**机制上无法实现**（要加 `setsContextKeys` 声明 = **新能力，越界，本轴不做**，[1.37 §13.4](07-任务-上下文旗子归属评估.md)）。

## 四、禁区

- 🔴 **不许动 `when` 解析器与 `matches()` 的求值语义**（`ContextKeyService.ts:363-373`「解析失败 ⇒ false，安全起见不显示」是**既有安全设计**，逐字保留）。
- 🔴 **不许动多窗广播**（`electron/ipc/ipc-bridge.ts:205-207`）。
- 🔴 **不许给 `contextKey:set` 的 IPC 通道加身份**（改公共 API 契约 ⇒ 超射程；本格出声**按"经 IPC 写入宿主专用名"触发**）。
- 🔴 **不许动 `overrides` 路径**（`SettingRow.tsx:118` 的 `context={{settingKey}}` 是**合法用法**，`ContextMenu.tsx:132` 消费）——**一行不许动**。
- 🔴 **不许引 `setsContextKeys` 声明**（**新能力，越界**，[1.37 §13.4](07-任务-上下文旗子归属评估.md)）。
- 🔴 **不许「先者保留」/ 拒绝 / 抛错**（§2.4）。
- 🔴 **不许把「快捷键 chord 缺陷」拉进来**（**已立案、不属本轴**）。
- 🔴 **不许引白名单 / 基线 / 棘轮**；账**必须生成式 ＋ 双向对账 ＋ 分两段**。
- 🔴 **不许把「黄灯」写成「红」**（存量 `explorer*` 9 个是反例；**1.49 才收紧**）。
- 🔴 **不许抢跑改插件仓**（逐仓改名归 **1.42–1.46**，§1.5）。
- 🔴 **新增运行时报点文案必须落在 `console.*` 调用之内**（**坑 4**），⛔ **不许动 `EXCLUDE_FILES` / `EXCLUDE_RANGES`**。
- ⚠️ **上位约束**：**操作体验零变化**（名字可变，取值与功能不许变；含主题/字体/翻译三条横切零回归）· 只做加法且名字一次定对 · [29 号档](../样式命名空间归一化/29-主题系统保护条款.md) 优先 · 对外宽容。
- ⚠️ 照旧：不跳 `npm run check` · **提交只按路径 `git add <本格文件>`**（⛔ 禁 `git add -A` / `git add .`）· **不推**（`git push` 必须等用户本人当次点头）。
