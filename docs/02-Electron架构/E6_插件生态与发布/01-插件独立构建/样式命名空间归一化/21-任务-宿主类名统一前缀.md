## 二、要做

### 1. 命名规则（机械、保留可读性）

**规则 = 原样加 `ldk-` 前缀，区域段保留**（不做二次语义化、不做删减）：

| 现在 | 改后 |
|:--|:--|
| `.welcome-hero` | `.ldk-welcome-hero` |
| `.quick-pick-item-label` | `.ldk-quick-pick-item-label` |
| `.wc-btn` | `.ldk-wc-btn` |
| `.pool-grid-cell` | `.ldk-pool-grid-cell` |
| `.zone-resize-handle` | `.ldk-zone-resize-handle` |
| 已带 `ldk-` 的 5 个 | **一字不动** |

- ⚠️ **加前缀后不得与既有名字撞车**：改完跑一遍「改前集合 × 改后集合」求交，**交集必须为空**（例如 `.about-name` → `.ldk-about-name` 若与某处既有名撞车 ⇒ 当场裁决怎么起名，别静默覆盖）。
- ⚠️ **同类问题在关键帧上也在**：宿主那 8 个关键帧（`selectbox-in` / `drop-zone-in` / `dropdown-card-in` / `floating-panel-in` / `group-tab-enter` / `group-tab-exit` / `notif-icon-spin` / `notif-progress-scan`）同样不带前缀、靠 [1.15](11-任务-保留名清单单一真相源.md) 的登记表守。**本格落地时一并判**：要不要同批加 `ldk-`（判完把结论写进交接段；不加也要写明理由）。

### 2. 三件「同笔面」（缺一件就是半成品）

1. **壳源码**：18 个 CSS 文件的定义点 ＋ 33 个 TS(TSX) 文件的渲染点（`className="..."` / 模板串 / 选择器常量表——⚠️ 别忘了运行时选择器那类非 JSX 消费点，件 4 上半 1.16 就在 `electron/preload-pool/surface-zones.ts` 撞到过一个）。
2. **门禁改形态**：`scripts/check-css-namespace.mjs` 判据③ 从「逐个登记」改成**结构性判定**（宿主 CSS 里的顶层类定义必须 `ldk-` 开头）；`--self-test` 的**正控/负控同笔更新**（正控 = 合规名该绿；负控 = 塞一个裸名该红）。🔴 **自测必须接线**（`npm run check` 里那一步）——否则自测自己就是假门禁。
3. **登记表与作者面**：`packages/plugin-sdk/schemas/reserved-class-names.json` 的 `classes.host` 在该格落地后**应为空**（1.17 已把最后一条 `.input` 带走）⇒ 判「删字段 / 留空数组」并同笔改：**作者面两棵树 §12**（中英同笔）· `scripts/check-reserved-names-doc-sync.mjs`（它对账登记表 ↔ 两棵树 §12 表）· SDK 的 schema 四份字节相等纪律（⑧ 记的 md5 `abc468ab77e6`）· `docs/02-Electron架构/E6_插件生态与发布/01-插件独立构建/11-样式命名空间审计.md` 快照。
