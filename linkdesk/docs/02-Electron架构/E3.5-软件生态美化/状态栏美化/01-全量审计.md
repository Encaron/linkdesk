## 二、视觉层——逐项差距

### 2.1 分割符：死 CSS + 文本 hack 🔴

当前代码：
```tsx
<span className="status-divider">│</span>
```
```css
.status-divider {
  display: inline-block;
  width: 1px;      /* ← 被文本内容 "│" 撑破，无效 */
  height: 12px;    /* ← 同上 */
  margin: 0 6px;
  background: var(--separator);  /* ← 被文本覆盖，看不见 */
}
```

**问题：** CSS 画了一条 1px×12px 的竖线，但 span 里有文本 `│` 把它撑破了。实际显示的是文本字符 `│`，不是 CSS 背景。宽度/高度/背景三个属性都是死代码。

**VS Code 做法：** 项目之间用间距分隔，不用竖线。需要分隔时用 CSS 画的细线（空 span + CSS）。

### 2.2 文字对比度 🔴

```css
.status-bar { color: var(--text-muted); }   /* #777——太暗 */
.status-text { color: var(--text-secondary); }  /* #999——尚可 */
```

- `#777` 在 `#1E1E1E` 背景上的对比度 ≈ 4.4:1——WCAG AA 的下限（4.5:1 才及格）
- `12px` 字号下这个对比度更吃力——状态栏始终在屏幕上，用户被"暗字"持续消耗注意力
- VS Code 状态栏用更亮的颜色（约 `#CCCCCC`），对比度 ≈ 10:1

### 2.3 Theme/Language 按钮 🟡

```tsx
{lang === "zh" ? "中" : "EN"}     // 纯文本，无图标
{theme === "Dark" ? "☀" : "☾"}    // Unicode 字符，跨平台渲染不一
```

- `☀`/`☾` 在 Windows 某些字体下显示为方框或不同风格
- 改 codicon 更可靠：`codicon-symbol-color`（主题）、语言可用文字或 globe icon
- 与 VS Code 对标：VS Code 状态栏点击语言模式会弹出语言选择器——LinkDesk 已有 LanguagePicker

### 2.4 项目间距不统一 🟡

```css
.status-bar-left  { gap: 6px; }
.status-bar-right { gap: 2px; }  /* ← 为什么左右不同？ */
```

右区间距 2px 太挤——铃铛、语言、主题三个按钮几乎连在一起。VS Code 右侧项目间有 ~6px 间距。

### 2.5 按钮 hover 区太小 🟢

```css
.status-bar-btn {
  padding: 0 6px;
  height: 22px;
}
```

6px 水平 padding 在 22px 高度上偏紧——鼠标在状态栏上找按钮时很容易错过。VS Code 的按钮 padding 更大（~8-10px）。

### 2.6 错误信息无动画 🟢

`error` 出现/消失瞬间切换——用户可能注意不到错误来了又走了。加一个简短的 fade 过渡。

### 2.7 bar 背景色 🟢

```css
.status-bar { background: var(--bg-window); }
```

和编辑器区同色——VS Code 状态栏背景色略深于编辑区（`#007ACC` 蓝色或 `#68217A` 紫色，取决于主题）。LinkDesk 走主题变量——但如果主题没专门设状态栏色，就和编辑区糊在一起。
