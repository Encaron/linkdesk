> 消灭壳级硬编码 pluginId / MenuId enum / schema enum——插件独立铁律的执行。与 Pool 模型无关，E5.6 未完成部分原样搬入 E5.7。
> 🔴 2026-08-13 审计补记：IPC 通道名是另一类硬编码——`filesystem:readTextFile` 等 50+ 通道名在 main（`ipcMain.handle`）与 preload（`ipcRenderer.invoke`）各写一遍裸字符串。由 Phase 12 **E5.7#63.6** 集中化覆盖，不属本 Phase。

## 1. MenuId enum → string

**文件：** `src/core/registry/MenuRegistry.ts:17`（2026-08-13 审计修正路径——registry/ 不是 services/）

```typescript
// 改前
export enum MenuId {
  TitleBar = "titlebar",
  TabBar = "tabbar",
  // ... 12 个值关死
}

// 改后
export type MenuId = string;

// 壳内部常量（可选——方便壳代码引用）
export const MENU_SLOTS = {
  TitleBar: "titlebar",
  TabBar: "tabbar",
  // ...
} as const;
```

**影响面：** `Map<MenuId, ...>` → `Map<string, ...>`（自动适配）。壳组件约 25 处引用。

## 2. factoryRole 类型

`plugin.schema.json` 中 `factoryRole` 闭合 union → `type: string`——第三方角色名不受限。

## 3. plugin.schema.json 枚举审计

15 处 `enum`，分三类：

| 类别 | 处理 | 数量 |
|:--|:--|:--|
| 阻塞第三方（permissions/uiHint/pluginRole/type） | `enum` → `type: string` | 4 处 |
| 壳行为定义（edge/order/viewRole等） | 保留 | 9 处 |
| 半开半闭（iconSource） | 加值 `"lucide"` | 1 处 |

## 4. plugin-file-service.ts 开放化

**文件：** `electron/plugin-file-service.ts`

```typescript
// 改前——白名单
['builtin', 'user'].forEach(subdir => { ... })

// 改后——扫描所有子目录
const subdirs = await fs.readdir(pluginsRoot);
for (const subdir of subdirs) {
  const pluginDir = path.join(pluginsRoot, subdir);
  if ((await fs.stat(pluginDir)).isDirectory()) {
    // 发现任意子目录下的 plugin.json
  }
}
```

🔴 2026-08-13 审计连带（E5.7#69 认领）：
- `electron/protocol.ts:69-71`——plugin:// 协议解析同样写死 `'builtin'`/`'user'` 两分支。**不同步开放 = 新子目录插件装上后加载不了**——开一扇关一扇白干。
- `src/core/pluginPaths.ts`——`PLUGIN_SUBDIRS = ["builtin", "user"]`（dev 模式 Vite glob）两端同步。
- 安装目标 `'user'`（plugin-file-service.ts:118/182）——语义是政策（安装总去 user），收敛为命名常量。

## 5. additionalProperties: false → true

**文件：** `plugin.schema.json` 根级


第三方可在 `plugin.json` 中加自定义字段——schema 不拒。
