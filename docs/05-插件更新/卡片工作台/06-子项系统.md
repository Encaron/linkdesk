# 06 — 子项系统

> 一个卡片 = 标题 + N 个纵向堆叠的子项。共享同一个 cardId 的数据。

---

## 一、概念

```
卡片 = 容器（标题栏 + 边框 + 背景）
  │
  ├── 子项 1: 进度条（填充条 + 百分比）
  ├── 子项 2: 波形图（小型面积图，最近 60s）
  └── 子项 3: 数值大字（大号数字 + 单位）

所有子项共享同一个 cardId 的数据流。
MCU 发 [humid, 58] → 三个子项同时收到 value=58。
```

**什么时候用子项 vs 独立卡片：**

| 判断 | 子项 | 独立卡片 |
|------|:--:|:--:|
| 共享 cardId？ | ✅ 同一个数据源 | ❌ 不同的数据源 |
| 逻辑上属于"同一个东西"？ | ✅ "湿度的不同显示方式" | ❌ "温度和湿度是两个东西" |
| 用户想一起移动？ | ✅ 拖一张卡片全带走 | ❌ 各自独立拖拽 |

## 二、内置子项类型

### 1. 进度条（progress）

```
████████░░ 58%
```

| 属性 | 说明 |
|------|------|
| 数据 | `value / max * 100` |
| 样式 | `fill` 连续填充 / `segments` 分段（如 10 段，每段 10%） |
| 填充色 | `var(--accent)` |
| 动画 | 宽度 300ms `ease-out` |

**适用卡片类型：** 数值卡片、仪表盘、进度条卡片（自身）

---

### 2. 波形图（wave）

```
╱╲   ╱╲       ← 小型面积图
╱  ╲_╱  ╲___
```

| 属性 | 说明 |
|------|------|
| 数据 | 最近 N 秒的 value 历史 |
| 窗口 | 默认 60s，弹窗可调 |
| 样式 | `area` 面积 / `line` 折线 |
| 颜色 | 填充 `var(--accent)` 10% 透明度，线条 `var(--accent)` |

**渲染：** `<canvas>` 逐帧重绘。数据点存储在卡片实例的内存环形缓冲区——不跨卡片共享。

**适用卡片类型：** 数值卡片、仪表盘

---

### 3. 数值大字（value）

```
37.2 °C
```

| 属性 | 说明 |
|------|------|
| 数据 | `value` + 单位 |
| 字体 | Fira Code 28px bold `tnum` |
| 小数位 | 弹窗中设置 |
| 动画 | 数字过渡 300ms `ease-out` |

**适用卡片类型：** 数值卡片（自身）、仪表盘

---

### 4. 仪表盘（gauge）

```
  ╱╲
 ╱  ╲        ← SVG 弧形
▕  ●
 ╲  ╱
  ╲╱
 37.2°C
```

| 属性 | 说明 |
|------|------|
| 数据 | `value` 在 `[min, max]` 范围中的位置 |
| 尺寸 | 缩小的 SVG——子项版 ~60px 高，独立卡片版 ~120px 高 |

**适用卡片类型：** 仪表盘自身、数值卡片

---

### 5. 指示灯（indicator）

```
● ON
```

| 属性 | 说明 |
|------|------|
| 数据 | `value` 映射到颜色 |
| 颜色映射 | `{ on: green, off: gray, error: red }` |

**适用卡片类型：** 指示灯自身、开关卡片

---

## 三、子项组合规则

### 每个卡片类型默认启用的子项

| 卡片类型 | 默认子项 | 可选子项 |
|------|------|------|
| 数值卡片 | 无 | progress / wave / value / gauge / indicator |
| 仪表盘 | gauge | progress / wave / value |
| 折线图 | wave | value |
| 进度条 | progress | value |
| 指示灯 | indicator | 无 |
| 滑块 | value | progress |
| 按钮 | indicator（状态回显） | 无 |
| 开关 | indicator（状态回显） | 无 |

### 子项纵向排列规则

```
┌──────────┐
│ ≡ 标题 ✕ │  ← 标题栏固定高度 28px
├──────────┤
│ 子项 1   │  ← 每个子项高度由类型决定
├ ─ ─ ─ ─ ┤  ← 分隔线 1px var(--separator)
│ 子项 2   │
├ ─ ─ ─ ─ ┤
│ 子项 3   │
└──────────┘
```

| 规则 | 值 |
|------|------|
| 子项之间间距 | 8px (`--space-sm`) |
| 子项之间分隔线 | `1px solid var(--separator)` |
| 卡片最小高度 | 标题栏 + 至少一个子项能显示 |
| 溢出处理 | 卡片高度不够 → 最下面的子项被裁剪，hover 时显示滚动提示 |
| 子项排序 | 弹窗中上下箭头拖动排序 |

---

## 四、子项与卡片尺寸的关系

```
1×1（80×80）：   最多 1 个子项（如指示灯）
2×1（160×80）：  最多 1 个子项（如进度条）
2×2（160×160）： 最多 3 个子项（标题 + 数值 + 进度条 + 波形图）
4×2（320×160）： 最多 5 个子项
4×4（320×320）： 全部子项

用户开启了超过卡片能显示的子项 → 超出部分裁剪 + hover 提示"展开以查看更多"
```

**resize 联动：** 当用户在弹窗中勾选了超出当前尺寸能显示的子项数量 → 自动将卡片尺寸调整到能容纳的最小尺寸。

## 五、子项配置在 JSON 中的存储

```json
{
  "id": "uuid-01",
  "type": "value",
  "settings": {
    "subItems": [
      { "type": "value",    "order": 0 },
      { "type": "progress", "order": 1, "style": "fill" },
      { "type": "wave",     "order": 2, "window": 60, "style": "area" }
    ]
  }
}
```

**每个子项独立配置：** 同一个 progress 子项，卡片 A 用 `fill` 样式，卡片 B 用 `segments` 样式——各自独立，互不干扰。
