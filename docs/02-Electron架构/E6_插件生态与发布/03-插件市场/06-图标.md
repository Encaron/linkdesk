# 图标——作者自制 · 全态 · 即时 · 双图标

> 对应任务：E6#30e + E6#29c + E6#65/#66/#67（14 市场图标系统档案批次一/二/二·五）。
> 文档归属：市场设计文档族（[03-市场交互设计.md](03-市场交互设计.md) = 总览索引）。

## 双图标模型（E6#67 定案 1-6）

| 字段 | 语义 | 谁读 |
|:--|:--|:--|
| `icon` | **界面小图标**——图标栏/标签栏/行内小位。单色、可 lucide/codicon | 壳界面 + 市场行内小位 |
| `marketIcon` | **市场展示图（cover art）**——详情展示位大框（及将来商店大屏）。可画得讲究复杂（640×640 svg 资产路径） | 只市场消费 |

- **壳零改动**：壳图标栏/标签栏仍只读 `icon`（E6#65a 通道）；市场层读 `marketIcon ?? icon`。
- **一律 SVG**（定案 5）：新配图资产全走 svg；lucide/codicon 仅作小图标，不当展示图。
- **字段形状照 `icon`**：`marketIcon` + `marketIconSource`（plugin.json 顶层可选；与 icon 同枚举）。
- **惯例**：`marketIcon` 值 = 包内资源相对路径（如 `resources/cover.svg`），`marketIconSource` **省略** →
  `linkdesk://` 路径推断（同 serial/aurora 正路——显式 `iconSource:"svg"` 会把路径当裸 URL，已装插件会裂）。

## 展示图裁决（市场层唯一裁决点 display.ts）

- **展示位**（详情头 96px 框 / 商店大屏）：`marketIcon ?? icon ?? 默认封面`。
- **行内位**（列表行 36px）：`icon ?? marketIcon ?? 默认封面`——小图标优先（28px 不硬压 640 封面）；
  无 icon 有封面才用封面兜底。
- 恒返有效 descriptor → 消费方零分支（默认封面替换历史 📄 / codicon-symbol-misc 兜底）。

## 默认展示图（E6#66）

- 市场内任何配图缺位（未装无目录 icon / 已装无 icon+marketIcon）→ **同一画风的默认封面**
  （data-URI 内置于市场插件——640×640 A 家族暗色工程台面 + 通用「dock 装入」意象，零构建耦合，
  不点任何具体插件功能，服务所有无配图第三方）。
- 市场外（壳图标栏/标签栏）空态仍是壳自己的 📄 兜底——默认封面归市场域（#68 再议壳侧改造）。

| 场景 | 图标源 |
|:--|:--|
| 壳图标栏 / 标签栏 | 已装 manifest `icon`（界面小图标，壳只读这个） |
| 已安装列表（行） | `icon ?? marketIcon ?? 默认封面` |
| 详情页（展示位 96px） | `marketIcon ?? icon ?? 默认封面` |
| 探索插件 · 未装（行） | 目录条目 `icon` → 无则默认封面 |
| 已装插件作者换图 | 随版本更新获得（已装不读远程目录图标） |

- **未装插件图标 = 作者提供什么显示什么**——PluginIcon 支持显式 icon descriptor 入参（不走 viewRegistry——未装插件无 registry 条目）。
- **「即时改」** = 重新 fetch catalog（5min 缓存）→ 列表/详情刷新即新图标；已装插件随版本更新（诚实边界——已装不读远程目录图标，marketIcon 同此边界）。
- **「随包」**：已装插件 marketIcon 资产由 SDK packager 随 `.linkdesk-plugin` zip（同 icon 待遇——声明路径拷进包，安装后市场从包内读展示图）。
