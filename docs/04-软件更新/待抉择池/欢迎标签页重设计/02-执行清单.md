## 发版口径

- **壳侧**（T1–T8/T11–T13）：攒批，不逐件定号；用户 dev 点头后统一定号落 CHANGELOG。
- **作者轴**（T9）：plugin-sdk/plugin-docs 各一发，走 `check:npm-release`。
- **官方各仓**（T10）：每仓一发＋官方目录收录＋种子追新——🔴 发版纪律：用户在软件里点得到才算发完。
- **验收方式**：纯壳侧改动 dev 实机即可；无打包态专属件。
