## 二、提案两条主线

### 2.1 主线一：文档分型与翻译机械化

1. **分型**（用户第 11/12 点）：文档分两类——**任务档**（AI 作业/归档/过程记录，中文可、不施翻译锁）与**面人档**（用户/第三方作者/外部 AI 读的：作者面两树、AI 手册、未来的用户操作手册，必须双语＋施锁）。分型本身机械化：无分型标记 ⇒ 门禁红。分型载体待选型（§六-3）。
2. **内容级锁**：DSH 式 pair-hash（`E:\deepseek-harness\docs\*.i18n.yaml` 样本，git blob 哈希配对记录）——补上「一篇之内单边改正文」这个现有门禁的盲区。形态＝现有六腿之外加一条锁腿，带 `--self-test`。
3. **术语级锁**（AI 补充，让「翻译非常标准」可机械的部分）：建术语总表（glossary，中英一对一），门禁逐术语全文对账——出现未收录术语或对错位即红。术语表可先从机械准入/槽位/factoryRole 这批核心词起步。
4. **诚实边界**：语义级「译得对」机器守不了，仍归人/AI 译后审——如实列册，别让门禁假装能读中文。

→ 本主线机械形态细化（出口总账/内容级锁/术语级锁/增量轨）= [01 §九](01-方案与落点契约-草案.md)（2026-11-05 自审补强）。

### 2.2 主线二：官方内容物独立更新轴（LPM）

1. **更新轴三分**：软件轴（慢，20 分钟）· 市场轴（插件，含官方插件）· **新增内容物轴**——官方自产、非插件形态的内容物（AI 手册、用户操作手册、内置文档、未来资源包）。
2. **归一形态（用户倾向）**：Linkdesk Package Manager——一台**角色呈现型插件**（factoryRole，照设置页先例），主视图列内容物清单＋各自版本＋更新按钮；命令化同笔（`lpm.*`，硬约束 26）。简单形态（AI 手册页内单按钮）可作 LPM 里该条目的快捷入口，**不另立第二更新面**。
3. **更新管道复用**：内容物版本化放官方目录（复用收录/鉴权/分发链），标记 channel 区别于市场商品；下载后落盘覆盖 `resources/` 旁的用户层副本——**落点先登记（硬约束 27）**。
4. **离线基线模型**：随包版本＝保底（离线永远可用），LPM 更新＝覆盖层，更新失败/校验失败自动回退随包版——手册永不白屏。

## 三、与姊妹档（万物皆可插件）的矛盾辨析

用户第 7 点已自己想通主干，AI 补三条边界：

1. **画法 vs 内容正交**：表现层提案管「谁画」（欢迎页/右键菜单的渲染体），本档管「内容怎么新」（文档/手册数据）。第三方替换了 AI 手册页的 UI，内容仍调官方内容物 API——两边握手点＝数据命令（姊妹档铁律 A）。
2. **内容物的定义收窄**：LPM 只收**官方自产非插件内容物**（用户原话「凡不涉及第三方插件」）；第三方插件永远走市场两步收录，官方插件也已在目录里——LPM 不做第二市场、不给任何人绕过收录的口子。
3. **「核心感」保护**：AI 手册是壳级纪律的载体（AI#16），给它整套插件化会把它拉进「可替换/可卸载」的语义场——这与它「软件说明书」的宪法地位冲突。**载体不插件化、更新管道插件化**（§六-1 展开讨论）。

## 四、AI 补充发散点

1. **手册条目带「适用版本」标注**——内容轴与软件轴解耦后必有错配窗口（新软件＋旧手册），条目级版本标注＋LPM 列表提示，比强制同步诚实。
2. **原子更新＋回滚**——下载校验通过才落盘、失败保留旧版（回退链纪律在内容轴的同构复用）。
3. **用户操作手册尚未诞生**——它是全新文档类型，诞生时即按分型制度立档（双语＋面人型＋锁），不欠技术债。
4. **内容物总账**——哪些东西算官方内容物、住哪、谁更新，建议一份登记表（对齐用户机落点规范的立法风格），防「乱放」复发。
5. **AI 手册英文化的排期现实**——现手册量大，一次翻完不现实；可按 00-README/01-路径总览 先行、逐章追翻，门禁按「已翻章节」增量亮灯。
6. **LPM 本身可被替换吗**——它若走 factoryRole 就天然可被第三方整套替换（姊妹档 §3.3 机制），替换后官方内容物 API 仍在——正交性的又一个证明点。

## 五、风险与边界

- **写盘落点未登记 = 门禁红**（硬约束 27）：内容物落盘位置是本档第一个要过的关。
- **安全**：内容物更新源必须鉴权（复用官方目录 token 链），防下载劫持；校验失败回随包版。
- **版本错配**：见 §四-1，不做强制同步，做诚实标注。
- **别造第二更新面**：AI 友好化「通知面唯一」的同款纪律——更新入口归一 LPM，页面按钮只是深链。
- **别把任务档管死**：分型门禁只对面人档施翻译锁，任务档照旧中文直行——别让门禁把 AI 作业流程拖慢。
