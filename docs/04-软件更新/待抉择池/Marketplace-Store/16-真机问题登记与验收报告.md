**① 单层呈现的实现（F14 配方组成部分）**
- 选项 A：本体退场——hover 时被盖住的重复本体 `visibility:hidden`
- 选项 B：展开层完全不透明盖死
- **推荐：双保险都上（A＋B）**。理由：玻璃主题下 B 单独用需要把不透明度调很重（破坏玻璃质感）；A 单独用在展开层几何小于本体时会露边；两者都是 CSS 级成本，叠加后任何主题都稳。
