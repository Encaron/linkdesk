  - 🔴 诚实留档三条（档案 §四）：**一次「canvas 不跟随换档、文本层与页卡却跟随」的观察未复现**——池页硬 reload 后连续 15+ 次换档 canvas 全部逐档对齐，且按原序操作复刻不出；判断**不是本格回归**（canvas 渲染链是 T3 的路径，本格一行没改），怀疑点是 T3 单条 drain 循环在某次 `renderPage()` 的 await 永不 settle 时会吞掉后续全部渲染请求（pdf.js 分帧渲染依赖 rAF），建议后续格加看门狗——⛔ 本格不动 T3 渲染路径；**`preview.pdf` 部分字形复制为乱码** = 该文档 CJK 子集字体无 `ToUnicode` 表（同文档有 `ToUnicode` 的串逐字正确）；**搜索浮条底色偏淡** = 本机主题把 `--bg-card` 覆写成 15% 洗色，壳自家浮动面（`DialogHost.css:27`/`QuickPickHost.css:41`）用的是同一个 token ⇒ ⛔ 插件不改（只消费 00.5 §二 表既有 token，归主题侧）。
  - 方案：pdf.js `getTextContent` 文本层叠加（划选复制）；页内/全文档搜索（pdf.js findController 原语 vs 自绘——**T5 当场评估并把结论写进本条✅行**）；搜索高亮样式走插件命名空间。
  - 落点：`src/services/textLayer/`（文本层渲染＋命中定位纯函数）＋ `src/components/SearchBar.tsx`（浮条，Enter/Shift+Enter 导航）；命中色复用 `--pdf-hit` token，不新增色值。
  - 判据：实机——划选复制出文字；搜索命中高亮、上下导航；文本层不干扰缩放/虚拟化两件既有功能（回归）。
