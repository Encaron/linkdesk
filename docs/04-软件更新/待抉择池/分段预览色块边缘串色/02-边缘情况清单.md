# 02 · 边缘情况清单

> 每条写「**什么情形** → **会怎样** → **本件怎么算**」。已经实测的标 🔬，据码/据 CSS 推出的标 🧠。

| # | 情形 | 会怎样 | 本件怎么算 |
|:--:|:--|:--|:--|
| **E1** | `theme-panorama.moonlight`（`separator: rgba(255,255,255,0.12)`） | 🔬 同病、且比极光玻璃**更明显**（alpha 更高＝环绕列透得更实） | 在修法覆盖内（同一条规则） |
| **E2** | `theme-pill.bubble`（`separator: rgba(214,51,108,0.10)`） | 🔬 同病：左缘＝10% 粉叠在**浅色**上（偏白粉），而那里本该是 10% 粉叠在**深色**上 | 在修法覆盖内 |
| **E3** | **第三方主题**写半透明 `separator` | 🧠 同病——本件与主题是谁的无关，只与 alpha 有关 | 在修法覆盖内；⛔ 不要求第三方改主题 |
| **E4** | 显示缩放 125% / 150% / 200%（DPR>1） | 🔬 125% 复测：左缘仍 `#e2e3e4`，与 `#525252` 之间是抗锯齿过渡 | **只柔化、不消除** ⇒ 必须修；⛔ 不能判为「亚像素错觉」 |
| **E5** | `app.accentSource` = `自定义`（`--accent` **纯色**块） | 🧠 纯色无「首/末列」之别 ⇒ 环绕列与本色相同 ⇒ **永远正常** | 不涉及；修法 A 对它**零影响**（同一基类，纯色加 `origin` 无副作用） |
| **E6** | `app.fontTone` 的 `Aa` 分半预览 | 🧠 它是两个子 `<span>` **各涂纯色**，不走背景铺贴、也不依赖边框 | **不受影响**（这正是「只有第一个按钮」的原因） |
| **E7** | 将来有人把同款样式用在**没有边框**的元素上 | 🧠 无边框时 `padding-box` ≡ `border-box` ⇒ 铺贴区不变 | 修法 A **零行为变化**（安全） |
| **E8** | 圆角档（`--radius-sm` ／ `app.surfaceRadius`） | 🧠 环绕列在**边界列**、裁剪来自 `overflow:hidden` 的圆角，两者位置不冲突 ⇒ 圆角大小不影响本病 | 不涉及；⛔ 不动圆角 |
| **E9** | `app.uiFontScale` / `window.zoomLevel`（`--ui-scale`） | 🧠 `52×30` 与 `1px` 若随 scale 变，则环绕列**按比例仍在边界** ⇒ 同一现象（宽窄变，性质不变） | 不涉及；⛔ 不动几何 |
| **E10** | **壳那份拷贝**（`SegmentPreview.css`）今天有产品消费方吗？ | ✅ 已改定（2026-10-06）：**有**——归一化后它就是**唯一**一份，`app.accentSource` 的分半色块与 `app.fontTone` 的 `Aa` 半都吃它 | 本案修的正是它（真修＝基类 `border-box` ＋ 变体长手） |
| **E11** | 你实际看到的是哪一份？ | ✅ 已改定：**共享件那一份**（插件私有 `.settings-segmented-swatch` 已随 1.0.40 整删） | 这是「修共享件 ⇒ 必须发插件新版」的原因（见 [03](03-实现交接.md) §二） |
| **E12** | 只加 `background-repeat: no-repeat` 呢？ | 🔬 边框那 1px 露底（`#1e252d`，面板色透出）——浅底上更明显 | 已列 B 案并**否决**（01 §六） |
| **E13** | Windows **高对比 / 强制色彩模式** | 🧠 该模式下系统会**覆盖**作者色（边框色被系统接管）⇒ 本病**自动隐身** | 不涉及；⛔ 不为此做特殊分支 |
| **E14** | 第三方插件照抄了这段 CSS（自我复制的「另一个拷贝」） | 🧠 修共享件**不会**自动修好别人仓里的拷贝 | ⛔ 本件不代改第三方；✅ 记为**作者面笔记**候选（共享件修正后，正典/作者文档里值得留一句「渐变块若自带边框，请 `background-origin: border-box`，且变体⛔ 别用 `background` 简写」）——是否落笔由 D2 之后定 |
| **E15** | 🔴 只加 `background-origin: border-box` **而不动变体的简写** | 🔬 **等于没修**：`background` 简写会把 `background-origin` 一并重置回 `padding-box` ⇒ 逐像素与修前相同（左 `#F2F2F2` / 右 `#272727`） | ✅ **已钉**（01 §五之二）——这是 `@linkdesk/ui` **0.2.49 的真实形态**：该版 CHANGELOG 已改写成「未生效」，真修复由 **0.2.50** 承接（变体改长手） |
| **E16** | 插件私有那份拷贝（`.settings-segmented-swatch` / `.settings-font-tone-half`） | ✅ 已整删（1.0.40）：两个 tone 控件改吃共享 `SegmentPreviewSwatch` / `SegmentPreviewText`；`sharedUi.ts` 的 `pick()` 双轨同笔整层删除 | ⛔ **别再按名字去找第二份源文件**——今天只有共享件一处；`packages/linkdesk-ui/dist/index.css` 是编译产物（`ui:build` 自动重生），不是源 |
