## 二、要做

### 1. 分两层落地（**这是本格的关键设计，别混成一层**）

| 层 | 文件 | 能不能自测 | 进不进 `npm run check` |
|:--|:--|:--|:--|
| **① 纯分析层** | `scripts/runtime-style-audit.mjs` 的**导出函数**（吃「dump JSON」→ 出「跨方碰撞报告」） | ✅ **能**（喂固定 JSON 夹具，正控绿/负控红） | ✅ **进**（`--self-test` ＋ 常规跑夹具，**不需要活软件**） |
| **② 采集层** | 同文件的 CLI 部分（连 CDP → dump → 调 ① → 打印/落 JSON） | ❌ 需要活软件（**不作为 check 链的硬门槛**） | ⛔ 不进（另挂一个 npm script，见下） |

> 🔴 **为什么必须拆两层**：只有一个「连上才跑」的脚本，等于**又一次把「判据活着」寄托在人工**——夹具测不到的判据会腐烂（记忆 `gate-selftest-must-be-wired`）。纯函数层**必须在 `npm run check` 里被自测**。

### 2. 采集层要 dump 什么（**归属 fail-loud**）

对**池文档**与**渲染进程文档**各 dump 一次：

- `document.styleSheets` 每张表的**归属线索**：`href`（`linkdesk://<id>/…` ⇒ 该插件）· ownerNode 上的 `data-vite-dev-id`（开发态）· 无 href 且无 dev-id ⇒ **标「未归属」**；
- 每张表里：**规则选择器文本 ＋ 规则体里定义的自定义属性名** ＋ `@keyframes` 名；
- 引擎落点：`getComputedStyle(document.documentElement)` 或 `documentElement.style` 上**被 inline 写入**的 token 名单（**宿主契约，单列**）。

🔴 **fail-loud 纪律**：**归属不了的样式表一律报「未归属」并让它结论不成立**——**不许静默当成宿主**（静默兜底 = 又一个「错的启发式」，正是本系列的病根）。

### 3. 输出与用法

- 机器可读：`--json` 落一份 `scratch/runtime-style-audit.json`（含每方的名字集合 ＋ 碰撞清单 ＋ 未归属清单）；
- 人读：摘要（每方名字数 / 碰撞数 / 未归属数 / 探针覆盖不到清单）；
- **用法文档写进脚本头部**（含**怎么带 CDP 启动**：隔离 profile ＋ `--remote-debugging-port=9222`；⚠️ 具体启动配方**照本仓当时的实机惯例**，别抄本文的示意）；
- 另挂一个 npm script（如 `audit:runtime-style`），**不塞进 `npm run check`**（check 必须能离线跑）。

### 5. 明写「探针覆盖不到什么」（不许省）

至少列出（并随实测补充）：

## 三、口径纪律（**和静态门禁必须同口径，否则两把尺子又对不上**）

🔴 **本系列的病根就是「两把尺子」**（§一 层 3：`includes("-")` 那把错尺子 ＋ 审计档同款错尺子互相印证）。⇒ 探针的「独立定义」口径**必须与 `check-css-namespace.mjs` / SDK 的 `css-selectors.ts` 完全一致**：

- **独立定义** = 逗号切开后的某个 compound、**无祖先**（无空格/`>`/`+`/`~`）、**主体恰好是一个类名**；
- `.control-bar .ldk-combobox { }` 这类**有祖先的 scoped 调优 = 合法消费，不算定义**；
- 复合（`.x.on`）、纯元素、纯属性选择器 **一律不算「类名定义」**（它们归**第 4 条轴**单列）。

⚠️ 实现时**优先复用/对齐** `packages/plugin-sdk/src/eslint/checks/css-selectors.ts` 的 `bareClassDefinitions` / `keyframeDefinitions` 口径（在 DOM 里跑等价逻辑），**别另写一套近似版**（详案 [15](15-任务-件2落地①-SDK判据腿.md) §一 的纪律：口径漂移由构造不可能发生）。
