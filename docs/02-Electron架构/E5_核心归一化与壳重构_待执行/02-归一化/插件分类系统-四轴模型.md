## 一、四轴模型

对标 VS Code `package.json`：不判断插件类型，只检查插件声明了什么能力。

| 轴 | VS Code 对标 | 管什么 | 从哪读 |
|:--|:--|:--|:--|
| `pluginRole` | `activationEvents` + `main`/`browser` | 加载策略——要不要 import JS | `loadPluginLifecycle` 局部变量推导 |
| `appearsIn` | `viewsContainers` + `views` 组合推导 | UI 出现位置——图标栏/侧栏/标签页/状态栏 | 消费侧直接读 manifest |
| `factoryRole` | 约定（settings 是特殊贡献点） | 系统角色——设置/市场 | `FactorySlots` |
| `contributes` | `contributes` | 能力声明——主题/语言/命令/菜单/文件关联 | `parseContributions` |

**四轴正交——不互相推导。** 一个插件可以同时有 `factoryRole: "settings"` 和 `appearsIn: { iconBar: "bottom", tabBar: true }`。

## 二、旧方案的问题

E4 时代三个字段来自三个不同时期：

| 字段 | 作用 | 问题 |
|:--|:--|:--|
| `iconLocation` | 图标栏位置 `"top"/"bottom"` | 默认 `"top"`，不声明也显示 → 编辑器意外出现在图标栏 |
| `viewRole` | 交互模式 `"sidebarPrimary"/"tabOnly"` | 名字看不懂，和 `iconLocation` 组合爆炸 |
| `keepSidebarOnFocus` | 侧栏切换时保留 | 独立布尔值，和前两个组合 2³=8 种可能 |

**新方案一个字段**：`appearsIn: { iconBar, sidePanel, tabBar, statusBar }`。四个布尔/枚举值，填了的就有，没填的没有。一眼看懂。

## 三、pluginRole——加载策略

只管**要不要 import JS 组件**，不管 UI 位置。

| 值 | 含义 | 壳行为 |
|:--|:--|:--|
| `"view"` | 有 React 组件 | 调用 `loadPluginComponent` |
| `"data"` | 纯数据（主题/语言/协议） | 跳过 JS 加载 |
| 不声明 | 自动推导 | 有 entry → view，无 entry + 有 contributes → data |

**推导仅一处**（`loadPluginLifecycle`，局部变量）：
```typescript
const role = manifest.pluginRole
  ?? (!manifest.entry && contributes ? "data" : undefined);
```

## 四、appearsIn——声明式 UI 位置

```typescript
// types.ts
appearsIn?: {
  iconBar?: "top" | "bottom";  // 不填 = 不显示图标
  sidePanel?: boolean;         // 不填 = false
  tabBar?: boolean;            // 不填 = false
  statusBar?: boolean;         // 不填 = false
};
```

### 消费侧（每处直接从 manifest 读，不推导不缓存）

| 消费方 | 读什么 | fallback |
|:--|:--|:--|
| `viewRegistry.getIconLocation()` | `appearsIn.iconBar` | `iconLocation`（旧字段兜底，仅此处） |
| `viewRegistry.getTabCreatableViews()` | `appearsIn.tabBar === true` | 无 |
| `IconBar.tsx` 过滤 | `getIconLocation() === "top"/"bottom"` | — |

### 向后兼容

旧字段 `iconLocation`/`viewRole` 保留在 `PluginManifest` 类型中标记 `@deprecated`。`getIconLocation()` 做一层 `??` fallback。后续版本删除。

## 六、完整插件形式——全部声明式，不改壳代码

| 插件形式 | 声明方式 | 壳行为 |
|:--|:--|:--|
| 纯标签页（编辑器） | `appearsIn: {tabBar: true}` | 标签页渲染 |
| 图标+侧栏（文件树） | `appearsIn: {iconBar:"top", sidePanel: true}` | 图标+侧栏 |
| 全区域（串口监视器） | `appearsIn: {iconBar:"top", sidePanel: true, tabBar: true}` | 全区域 |
| 底部齿轮+标签页（设置） | `appearsIn: {iconBar:"bottom", tabBar: true}` | 齿轮+标签页 |
| 纯数据（语言/主题） | `pluginRole: "data"` | 零 UI，只注册 contribute |
| Git 集成（未来） | `appearsIn` 全字段 + `contributes.menus` | 全区域+右键菜单 |
| Markdown 预览（未来） | `appearsIn: {tabBar: true}` + `contributes.fileAssociations` | 右键+标签页 |
| 零 UI 工具（未来） | `pluginRole: "data"` + `contributes.commands` | 只注册命令 |
