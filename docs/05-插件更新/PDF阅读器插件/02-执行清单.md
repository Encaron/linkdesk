## 施工棒次（T1–T8）

- [ ] **T1 起仓与声明面**——脚手架＋插件身份＋图标＋市场 debut。
  - 方案：`npx create-linkdesk-plugin@latest`（0.1.25）在 `E:\linkdesk-plugins\official\` 起仓 `pdf-reader`（脚手架自建 git 仓；容器本身绝不 `git init`——`E:\linkdesk-plugins\README.md` 铁律一）；`pluginId = "pdf-reader"`、`minAppVersion` 按现装壳定（0.2.32 起步）；声明面照 [01-任务书 §四⑤](01-任务书.md)（fileAssociations pdf ＋ appearsIn 仅 tabBar ＋ identityField=filePath ＋ i18n 声明＋icon）；`resources/icon.svg` 商城展示图标（**三处用途：标签栏/市场列表/打开方式选择器；无图标栏图标**）——SVG 自己画，设计感对标官方各仓图标（先 ls 官方仓 resources 对齐风格）；i18n 声明串过自有字典。
  - 判据：`npm run build` 出 `pdf-reader.linkdesk-plugin`；dev 壳手动装包（拖进市场/开发者安装）后标签页骨架出现、图标上标签栏；官方各仓审计脚本认得这仓（目录下有 plugin.json）。
  - 禁区：不填 `distribution`（废弃字段）；不立任何占位命令/组件（无死代码从第一棒守起）。

- [ ] **T2 引擎引入**——pdf.js 跑通渲染管线。
  - 方案：`pdfjs-dist` 钉版本进 lockfile（登记表 [01-任务书 §五B](01-任务书.md)）；worker 随 vite 打包走通（T2 专项判据）；cmaps/标准字体产物随包；`readBinaryFile` 拿字节 → `getDocument` → 单页 canvas 渲染样例 pdf。
  - 判据：dev 壳实机——样例 pdf 打开渲染出第一页（哪怕 UI 还很糙）；池沙箱 CSP 下 worker 正常起（实机验，不是 dev server 验）；包体读数记录在案。
  - 禁区：worker 打不通**不许**塞主线程凑合——上报，用户拍板。

- [ ] **T3 M1 阅读器主体＋固定底色**——界面设计落地。
  - 方案：工具栏（翻页/页码/缩放/适宽/适页）＋连续滚动＋**虚拟化只渲染可视页**（大文件不死——首屏只渲染可视 ±2 页）；错误态两式（损坏文件/加密文件）；**阅读底色固定不跟主题**——纸感底色族走 `pdf-` 命名空间自有自定义属性，不消费壳主题 token；周边工具栏可用 `@linkdesk/ui`。设计图（UI 布局规格 html）先出、请用户过目再写码（设计批准 ≠ 实现授权）。
  - 判据：实机——单击 pdf 全链（渲染/翻页/缩放/适宽）；**切壳主题阅读区纹丝不动**；100MB 级 pdf 滚动不卡、内存不涨穿（页面对象 `destroy()` 纪律）；卸载退回。
  - 禁区：夜间档给不给 = 设计时请用户拍板，不擅自定。

- [ ] **T4 命令化＋i18n（AI 友好化收口）**。
  - 方案：`pdfReader.*` 命令族（pageNext / pagePrev / zoomIn / zoomOut / fitWidth / fitPage / gotoPage 等随 M1 已有功能立——**没有的功能不立命令**）全带 `description`＋`params`（照 [21-插件命令化规范](../../03-插件制造/21-插件命令化规范.md)）；结构化读数命令（当前页/总页/缩放）供 AI 操作；i18n 自有字典补全（en 全覆盖）；配置项（若 §四⑦ 拍板给了）声明＋字典同笔。
  - 判据：命令面板可跑全部命令；`ci-verify` ⑧段（own-dict-coverage）绿；`npm run manual:build` 壳侧手册若收录本插件命令则零手工（声明驱动天然收录）。
  - 禁区：description 是声明数据不是 UI 文字（硬约束 2 例外口径）；title/group 必须 i18n。

- [ ] **T5 M2 文本层**——划选复制＋页内搜索。
  - 方案：pdf.js `getTextContent` 文本层叠加（划选复制）；页内/全文档搜索（pdf.js findController 原语 vs 自绘——**T5 当场评估并把结论写进本条✅行**）；搜索高亮样式走插件命名空间。
  - 判据：实机——划选复制出文字；搜索命中高亮、上下导航；文本层不干扰缩放/虚拟化两件既有功能（回归）。

- [ ] **T6 M3 缩略图＋目录**。
  - 方案：左缘缩略图侧栏（可视页懒渲染）＋目录/书签树跳转（pdf.js outline）；侧栏开合走命令（AI 可操作）。
  - 判据：实机——缩略图点击跳页、目录跳转、懒渲染不整本铺开；命令面板有侧栏开关。

- [ ] **T7 测试/门禁/机械检查收口**（用户 2026-10-07 点名：一样不能少）。
  - 方案：纯逻辑单测补齐（页码计算/缩放档位/虚拟化窗口/搜索高亮定位——SDK `vitest-setup` 基建；替身照契约非实现）；组件测试照 [docs/03-插件制造/](../../03-插件制造/) 覆盖层口径；无死代码自查（未引用导出 grep＋audit 工具若有）；CSS 命名空间自查（`pdf-` 前缀、无锚选择器零、状态类复合）；硬编码自查（hex 只许出现在自有底色族定义处）。
  - 判据：三门 `test` / `verify` / `build` 全绿；覆盖读数记录在案；自查四项各出一行读数。
  - 禁区：不放宽判据凑绿；测试 fixture 禁真实文案（虚构值）。

- [ ] **T8 README＋发布＋官方目录收录**。
  - 方案：README 照 [12-README说明区媒体契约](../../03-插件制造/12-README说明区媒体契约.md)（**展示图标上说明区**；src 照源规则）；CHANGELOG 起账；`npm run publish`（发版五步照 [docs/06-发布管理/作者轴npm发版.md](../../06-发布管理/作者轴npm发版.md)——插件轴🟢已授权发就走到端，推必带代理 127.0.0.1:7890）；**官方目录收录**（`E:\linkdesk-plugins\linkdesk-marketplace` 提交收录条目——插件仓根那份 marketplace.json 只是自己的源，**不收录用户永远点不到**，硬约束 24）；出厂种子**不进**。
  - 判据（§三 全套）：壳仓零 diff；市场实机搜到/装上/可更新；卸载退回如实记录；Windows「打开方式」候选出现。
  - 禁区：收录条目 icon/readmeUrl/downloadUrl 逐字段照 editor 先例核对；发完不验「用户点得到更新」不算发完。
