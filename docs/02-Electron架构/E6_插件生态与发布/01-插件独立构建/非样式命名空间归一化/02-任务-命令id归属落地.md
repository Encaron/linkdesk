## 一、判据表（**含必须真跑过的负控**）

| 判据 | 要求 | 负控（**必须真能红**，且覆盖它想抓的那一类形态） |
|:--|:--|:--|
| **① 插件命令 id 带归属** | `contributes.commands[].id` 的**第一段 == `pluginId`**（结构判定，**不查表**） | 把某仓一条 id 的前缀**删掉**（如 `file-tree.x` → `x`）⇒ 当场红、报点带 `file:line` ＋ 「应以 `file-tree.` 开头」；**还原后 sha256 逐字节相同**。⚠️ **负控不许用「瞎编一个名字」**——那测不出射程 |
| **② 宿主保留前缀** | 插件命令 id **不得**落在账内（`workbench.` / `update.` / `view.` / `theme.` / `core.` / `app.`） | 在插件仓临时塞一条 `workbench.action.showCommands` ⇒ 红（**且与宿主那一条重名**，正好是"顶替宿主命令"的真形态） |
| **③ 归属来源修正（H1）** | 两个**运行时**注册同 id、不同真身份 ⇒ **必须出声 ＋ 不覆盖** | 单测：两个不同 pluginId 注册同一 id ⇒ 断言「先者的 handler 仍在」＋「日志点名双方」。**反向负控**：**同一** pluginId 重注册 ⇒ **不许出声、必须生效**（这条是防"改坏合法语义"，见 §二 禁区） |
| **④ 归属来源修正（H2）** | `unregisterCommands(pluginId)` **只删自己的** | 单测：`beta` 注册 `acme.foo` ⇒ 卸载 `alpha` 后 `acme.foo` **仍在** |
| **⑤ 归属来源修正（H3）** | `on-command` 激活**用真身份**，不用名字第一段 | 单测：属主推导不再来自 `commandId.split(".")[0]` |
| **⑥ 协议 id 同族** | 与 ①② 同账同腿 | 同 ② 的形态（塞一条撞宿主内置协议 id ⇒ 红） |
| **⑦ 账 ↔ 实况双向对账** | 账里多一条 / 实况多一条 ⇒ **两侧都红** | ① 只改账（加一个假前缀）⇒ 红；② 只改实况（在 `src/core/commands/` 加一条 `zzz.` 命令）⇒ **红**（**这一条最关键**——它是"宿主新增名字忘重跑生成器"的机器兜底） |
| **⑧ 旧门禁未空转** | 盘一遍：本格新增的腿是否让某条旧 check **输入清零后继续跑绿** | 照 CSS 系列件 8 的做法**实测**（不是看代码猜） |

**每条 `--self-test` 的要求**：**正控 ＋ 负控都要有**，且**负控要自证真的变异了**（记忆 `css-rename-round-toolkit` ⑥：否则假绿）。

## 二、禁区

- 🔴 **不许抛错**：`contributions.ts` 的命令注册调用点在 `parseContributions` 内 ⇒ 抛错 = **整只插件装不上**（[00 档 §2.7](00-整理档案.md)）。修法只能是 **不覆盖 ＋ `console.error`**。
- 🔴 **不许改坏「同插件重注册」的合法语义**：`loader 先注册元数据 → 组件 mount 重注册 handler（只更新 handler/title，不动元数据）`（`src/core/registry/commands/CommandRegistry.ts:59-61`）——**这是既有设计，逐字保留**。
- 🔴 **不许动多窗归属表**（`_poolCommandWindows` / `_poolPending`）。
- 🔴 **不许引白名单 / 基线 / 棘轮**；保留名账**必须生成式 ＋ 双向对账**。
- 🔴 **不许重构注册表 / 换数据结构**（「复合键」路线若 1.31 未选中，本格**不许自己发明**）。
- 🔴 **不许改命令 id 的「公共 API」语义**：命令 id 是跨插件调用面（`executeCommand`）＋ `menus[].command` / `keybindings[].command` 的引用目标 ⇒ **改一个 id 要同笔改全部引用点**（1.31 的存量裁决里要给出引用点清单）。
- ⚠️ **上位约束**：**零 UI 变化**（除版本号；含主题/字体/翻译三条横切零回归）· **只做加法且名字一次定对** · [29 号档](../样式命名空间归一化/29-主题系统保护条款.md) 冲突时以它为准 · **对外宽容**（第三方侧新判据默认黄灯；判红必须论证「本仓可答 ＋ 有真害」）。
- ⚠️ 照旧：不跳 `npm run check` · 推前现测代理 · 推完 `ls-remote` 对 SHA · **提交只按路径 `git add <本格文件>`**（**禁 `git add -A`**）。
