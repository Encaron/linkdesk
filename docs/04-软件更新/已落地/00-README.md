## 归档规矩（git 历史要对得上）

1. **移动只走 `git mv`**——rename 历史全保，`git log --follow <已落地的文件>` 可追全沿革。
2. **归档笔的提交信息带锚点**：任务名 + 所随发版号（例：`docs:04「设置页通用归类」销账归档——随壳 vX.Y.Z 发版`），做到 **CHANGELOG 版本段 ↔ 归档 commit ↔ 目录收录 commit** 三方可互查。
3. **子夹成套的整夹移入**（设计文档 + mockups 一起走），目录结构不变。
4. 每次归档在下表记一行。
5. **未发版也能提前归档**（用户实机验收通过即可，不必等发版）——但台账「所随发版」栏必须标 **⏳ 未发版** ＋ 去向（先例：启动过场与加载态 ⇒ 后随 v0.2.19 出货、HintTip 落点与尺寸返工 ⇒ 后随 v0.2.21 出货），避免「归档了但没人知道它还没出货」。
6. 🔴 **搬家半径怎么算（2026-09-29 会话 22 实证——⛔ 别凭感觉估）**——判据**不是**「链接里有没有 `../`」，是**「链接解析后落不落进 `待抉择池/`」**：`待抉择池/` 与 `已落地/` **同深**，所以夹内一切 `../../` 及以上的相对链接**原样成立**（不会漂），只有指向**池内兄弟件**的（`../dev验收前置.md` 型）才断 ⇒ 改指 `../../待抉择池/…`。
   · **夹外入链要同时扫三种写法**，只扫一种必漏：① **repo 根相对**（`docs/04-软件更新/待抉择池/X`——含 `CLAUDE.md` 与 `electron/`/`src/`/`scripts/` 注释里的指针）② **从夹外往回写的相对串**（`../../待抉择池/X`）③ **池内平写**（`待抉择池/X`，池内各 README 的表里就是这种）。
   · **验收判据** = `node scripts/check-doc-links.mjs` 绿；⚠️ 它**只扫 `docs/**/*.md`**——`electron/`/`src/`/`scripts/` 里的注释指针它不管，得自己扫（本次扫法 = 遍历 `git ls-files` 全文匹配旧路径串）。
   · 🔴 **历史叙述点不许改**（改了＝篡改当时）：档案里「这件事当时发生在池里」的记述、设计期的池目录树快照一律留原样，并在本台账该行**记明「有意保留 N 处」**（先例：AI友好化系列留 4 处）。
   · **分摊读数（供下次估工）**：AI友好化系列整套子夹 = 夹内 22 条断链 ＋ 夹外 33 处路径串 ＋ 8 处夹外相对链接 ＋ 3 份权威文档改写 ＋ 本台账 1 行。
   · ⚠️ **源码注释指针会撞 commit-msg 闸**：`src/`/`electron/` 里改注释路径属「软件侧文件 staged」⇒ 旧版闸要首行 `feat:`/`fix:`/`breaking:`（挂 `fix:` 是撒谎、`--no-verify` 是绕过全部钩子）。**2026-09-29 会话 22 已给闸加「注释-only 豁免」**（`scripts/check-version-bump.mjs` 头注 ④，自测 34 例）⇒ 这类搬笔照写 `docs:` 即可，闸会放行并点名。
7. 🔧 **机械件（2026-10-06 建）：`node scripts/archive-case.mjs <案名>`**——把上面 1–6 的机械活一次做完（**干跑**＝只读出计划与读数；`--apply` ＝ `git mv` ＋夹内外双解析回填＋清空目录＋跑 `check-doc-links`·`check-empty-dirs` 复验，末尾打印**台账行草稿**与**本波提交路径清单**）。它就是规矩 6 的机械化：判据同一把尺子（import 门禁的 `linkTargetsInLine`，⛔ 不另写正则）；⛔ **只 add 本波文件**由它给清单；index 已脏则 `--apply` **拒跑**（防与并行案的 staged 改动同笔混装）；`--keep <rel>:<line>` 标「有意保留」；夹内**真死链只报不改**（修不修由人判——它分不清抬头叙述与真指针）；单文件案与整夹案都吃。⚠️ 自测 15 例（含一条钉住 2026-10-06 那次「只测前缀 ⇒ 假 0」的**反例**）**在写盘前自跑**，判据坏了直接拒跑（比挂 check 链更靠前：门禁是进 CI 才拦，这是动手前拦）。
