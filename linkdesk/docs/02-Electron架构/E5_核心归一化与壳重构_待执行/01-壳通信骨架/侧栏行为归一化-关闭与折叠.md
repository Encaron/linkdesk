# 侧栏行为归一化——关闭弹窗 + 折叠/展开

> 2026-08-02。**E5 新增任务。** 两个独立的问题，共享同一个架构——ZoneConfig 驱动行为。
> 执行清单任务：E5#48（串口未开不弹确认）、E5#49（侧栏折叠留口子）

---

## E5#48 🔧 串口未开时关闭标签页——不弹确认

### 现状

关闭串口监视器标签页 → 弹出"关闭会话「COM3」？"确认框。无论端口是否打开。

### 根因

`tabBehavior.invokeBeforeClose` 告诉壳"关闭标签页前问我一下"——但没有区分"端口开着"和"端口没开"。串口没开时关闭不需要确认——没有数据在传输。

### 修复

```typescript
// serial-monitor/src/index.tsx 或 SerialContext
// invokeBeforeClose 回调中检查 isOpen 状态

// 当前
invokeBeforeClose: () => showConfirm({ title: t("关闭会话「{{name}}」？", { name }) })

// 改后
invokeBeforeClose: () => {
  if (!isOpen) return true;  // 端口没开——直接允许关闭
  return showConfirm({ title: t("关闭会话「{{name}}」？", { name }) });
}
```

**不改壳——只改插件逻辑。** invokeBeforeClose 的返回值约定已支持（返回 true = 允许关闭）。

## E5#49 🔧 侧栏折叠行为——口子开在 ZoneConfig 里

### 现状

```
点 📁 → 侧栏展开（280px）
再点 📁 → 侧栏关闭（0px，完全消失）
再点 📁 → 侧栏展开（280px）
```

**和 VS Code 不同——VS Code 点一下图标是 toggle，侧栏关闭但不丢失上下文。** LinkDesk 当前的 lastSidebar 逻辑（SidePanel.tsx L55-60）已经保留上下文——切标签页时侧栏不关。但**再点同一个图标的行为**是"开→关→开"，中间"关"时侧栏完全消失。

### 目标——对标 VS Code，但留口子给未来布局

```
E5 当前：
  点 📁 → 展开（280px）→ 点 📁 → 折叠（4px 竖条，只留拖拽手柄）→ 点 📁 → 展开
  
v1.4 侧栏在右：
  点 📁 → 展开（280px，右边）→ 点 📁 → 折叠（4px 竖条，右边）
  
v1.6 侧栏 floating：
  点 📁 → 展开（浮窗）→ 点 📁 → 折叠（缩成小图标，贴窗口边缘）
```

**折叠行为取决于侧栏的 `dock.edge`：**
- `edge: "left"` → 折叠到左边缘，4px 宽竖条
- `edge: "right"` → 折叠到右边缘，4px 宽竖条
- `edge: "bottom"` → 折叠到底边缘，4px 高横条
- `mode: "floating"` → 折叠成小图标，吸附到最近边缘

### ZoneConfig 改动

```typescript
// src/core/LayoutEngine.ts——ZoneConfig 加折叠字段
interface ZoneConfig {
  // ... 现有字段 ...

  dock?: {
    // ... 现有字段 ...

    /** 折叠后的宽度。E5 默认 4px——VS Code 风格竖条。0 = 完全消失 */
    collapsedWidth?: number;

    /** 折叠后是否显示拖拽手柄——用户可以从折叠态拖出来 */
    showCollapsedHandle?: boolean;
  };
}
```

**E5 不改 SidePanel 的折叠动画——只给 ZoneConfig 加字段。** SidePanel 的 toggle 行为在 E5#4（SidePanel 改造）中已经包含——从 `shellEvents.on("icon:selected")` 触发。折叠宽度从 `layoutEngine.getZone("sidebar").dock.collapsedWidth ?? 4` 读取。

### v1.4/v1.6 时怎么扩展

```
E5:         collapsedWidth: 4 → 4px 竖条
v1.4:       collapsedWidth: 0 → VS Code 风格——完全消失（侧栏不占空间）
v1.6 float: 折叠 → FloatingManager 接管 → 32px 小图标贴在窗口边缘
```

**Zone 组件不感知。** SidePanel 还是接收 bounds——4px 宽和 280px 宽对组件来说只是 `style.width` 不同。
