# 注册点矩阵——Phase 2 执行地图

> E5.8#7（2026-08-19）。全仓注册点清单——grep 实证 + 逐项标注现有 dispose 覆盖度。
> 用途：Phase 2（#8 设计 → #9 RegistryBase v2 → #10 13 Registry 返 disposer → #12 卸载链路）的执行地图。
> 判据总纲：**一切注册返回 disposer，卸载逆序回滚**——插件重装契约（"可卸载 ⇒ 可重装"）的机械保障。

## 基线核对记录（清单 2026-08-17 口径 → 现状）

清单 #7/#10 写 "core/registry/ 14 文件（13 Registry + RegistryBase）" 系 **2026-08-17 结构**。E5.8 #0d.7-14 已把 registry 细分为 `commands/ appearance/ languages/` 子夹 + KeybindingRegistry 拆 `KeybindingRegistry/` feature-folder——文件组织已变，**注册面口径不变**：13 注册表 = 11 核心 registry 模块 + StatusBarService + QuickPickService（services/ui 按注册表消费）。

**RegistryBase 采用现状（关键发现）**：11 核心模块仅 **4 个**采用 RegistryBase（markPlugin 自动对称清理）——其余 7 个靠 lifecycle.ts 手动列举 unregister* 清理。
