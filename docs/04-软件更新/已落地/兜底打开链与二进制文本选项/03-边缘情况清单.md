## 一、前半（兜底打开链）

| # | 现象 | 预期 | 判据 |
|:--:|---|---|---|
| E1 | **点开头文件**（`.gitignore` / `.env` / `.editorconfig`）：`extension()` 判 `idx > 0` ⇒ 与无后缀同为 `""` | 同修：四路入口任一路打开都可编辑 | 人工（四路逐条）；机械：T4 入口对 `""` 也调宿主面 |
| E2 | **空文件（0 字节）** | `isBinary(new Uint8Array(0)) === false`（既有负控已钉）⇒ 正常可编辑，⛔ 不进提示页 | 机械（`EncodingService.test.ts` 既有） |
| E3 | **GBK 中文正文（无 NUL）** | 既被判「非二进制」（既有负控已钉）⇒ 走正常编码检测，⛔ 不许因本件被误送进强制文本态 | 机械（既有） ＋ 人工 |
| E4 | **覆盖表里指向已卸载插件** | `resolveOpenTarget` 视同未覆盖 ⇒ 落挂牌者（既有语义）✓ | 机械（既有用例） |
| E5 | **无后缀文件的覆盖表键** | `normalizeAssociationOverrideKey("")` ⇒ `""` ⇒ 空键不写（⛔ 别在覆盖表里造空键行） | 机械 |
| E6 | **无后缀文件的标签身份** | `sourceId = filePath` ⇒ 身份去重照常（同文件聚焦、异文件新建）；`label` ＝ 文件名本身（无后缀）✓ 不需要「未命名」特判 | 人工 |
| E7 | **语言映射** | 无后缀 / 未扩展名 → `plaintext`（`language-map` 既有回落）⇒ 无高亮但可编辑 | 人工 |
| E8 | **旧壳 + 新插件** | `getPluginFor("")` 在旧壳回 `undefined` ⇒ 插件侧 `pluginId \|\| ""` ⇒ 空 type ⇒ 旧壳渲染进程兜底 ⇒ **仍是欢迎页**（⛔ 无回归，但也无修复）⇒ **发版次序要求壳先行/同批** | 人工（可见） |
| E9 | **新壳 + 旧插件** | 插件短路仍在（`ext ? … : ""`）⇒ 无后缀仍落欢迎页（A 半未生效）；⛔ 但**不许崩** | 人工 |

## 二、后半（二进制文本选项）

| # | 现象 | 预期 | 判据 |
|:--:|---|---|---|
| E10 | **旧壳（无 `lk.encoding.isBinary` 面）** | `load` 的特性探测落 `false` ⇒ 恒当文本（今天的既有降级）；⇒ 提示页**根本不会出现** ⇒ 第三颗钮无从点（⛔ 不需要额外分支，也⛔别为它加开关） | 机械（`EditorModel.binary.test.ts` 既有降级用例）＋ 人工 |
| E11 | **强制文本态下的保存** | 按 **D1**：甲 ⇒ 命令面同挡、⛔ 不许只挡 UI（Ctrl+S / 保存命令 / 菜单项三处一致）；乙 ⇒ 写前确认 | 机械（命令层用例）＋ 人工 |
| E12 | **强制文本态 → 想回到提示页** | 必须有反向路（细警示条上的「退回提示页」）⇒ ⛔ 不许做了不可逆 | 人工 |
| E13 | **同一文件开两个标签，其一强制文本** | 状态**住标签**（跟 `state.model.forcedText`）⇒ 另一个标签不受影响 | 人工 |
| E14 | **强制文本态的持久化 / 恢复** | 建议**不记住**（Hot Exit / `restoreLayout` 恢复后回到提示页）——⛔ 避免「上次强制过」被静默继承（数据安全优先） | 机械（恢复用例）＋ 人工 |
| E15 | **超大二进制** | 强制文本要 `detect` + `decode` 全量 ⇒ 需一个体量护栏（如超阈值只显示前 N KB ＋ 提示，或复用既有大文件门槛）；⛔ 不许把主线程卡死 | 人工（造 50MB+ 夹） |
| E16 | **二进制但 `detect` 猜出非 UTF-8 编码** | 照常 `decode`（乱码形态取决于编码猜测）⇒ 提示条上把「编码」一并标出来，让用户知道自己在看什么 | 人工 |
| E17 | **面包屑 / 状态栏** | `forcedText` 态下：面包屑照常；状态栏标 `只读`（甲）＋ 编码；⛔ 行:列 对乱码无意义可省（与提示页态同律） | 人工 |
| E18 | **拟真图** | mockups 的 zone 尺寸（titlebar 30 / icon-bar 42 / sidebar 216 / tabbar 35 / statusbar 22）与 token（`--font-size-2xs 11 / -xs 12 / -sm 13`）须与源码对齐，图↔档互指 | 人工（沿用前案纪律） |
