## 1. MenuId enum → string（E5.6#53）

**文件：** `src/core/services/MenuRegistry.ts:17`

```typescript
// 改前
export enum MenuId {
  TitleBar = "titlebar",
  TabBar = "tabbar",
  // ... 12 个值关死
}

// 改后
export type MenuId = string;

// 壳内部常量（可选——方便壳代码引用）
export const MENU_SLOTS = {
  TitleBar: "titlebar",
  TabBar: "tabbar",
  // ...
} as const;
```

**影响面：** `Map<MenuId, ...>` → `Map<string, ...>`（自动适配）。壳组件约 25 处引用。

## 2. plugin.schema.json 枚举审计（E5.6#55）

15 处 `enum`，分三类：

| 类别 | 处理 | 数量 |
|:--|:--|:--|
| 阻塞第三方（permissions/uiHint/pluginRole/type） | `enum` → `type: string` | 4 处 |
| 壳行为定义（edge/order/viewRole等） | 保留 | 9 处 |
| 半开半闭（iconSource） | 加值 `"lucide"` | 1 处 |

## 4. additionalProperties: false → true（E5.6#61）

**文件：** `plugin.schema.json` 根级

```json
// 改前
"additionalProperties": false

// 改后
"additionalProperties": true
```

第三方可在 `plugin.json` 中加自定义字段——schema 不拒。
