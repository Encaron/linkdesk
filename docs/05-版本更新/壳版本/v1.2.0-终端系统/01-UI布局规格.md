# 01 — UI 布局规格

> 2026-07-28。**底部 Panel 区域 + 终端仿真器 + Output 面板的 UI 规格。**
> 终端内容区由 xterm.js 渲染——此处只定义壳级布局（Panel 位置、分隔条、标签栏、配色）。
> 对标 VS Code Integrated Terminal Panel。

---

## 一、整体布局——Panel 区域在壳窗口中的位置

```
┌──────────────────────────────────────────────────────────────────┐
│ 顶栏    LinkDesk    [文件] [编辑] [查看] ...                       │
├────────┬─────────────────────────────────────────────────────────┤
│ 图标栏  │ 标签栏  [📄 App.tsx ●] [📄 config.ts]            [×]   │
│ 42px   ├─────────────────────────────────────────────────────────┤
│        │                                                         │
│  📁    │  主区（编辑器 / 终端 / 地图 / ...）                       │
│        │                                                         │
│  🔍    │                                                         │
│        │                                                         │
│  ⚙     ├─────────────────────────────────────────────────────────┤ ← 分隔条（4px 拖拽区）
│        │  Panel 标签栏  [>_ PS] [>_ bash] [输出: Git] [输出: 串口] [+] [×] [□] │ ← h=32px
│        ├─────────────────────────────────────────────────────────┤
│        │  PS C:\Users\fengy> ls                                  │ ← xterm.js (h=150px 默认)
│        │  Desktop  Documents  Downloads  ...                     │
│        │                                                         │
│        │  PS C:\Users\fengy> _                                   │
├────────┴─────────────────────────────────────────────────────────┤
│ 状态栏  🟢 UTF-8  Ln 14, Col 8  Spaces: 2                        │
└──────────────────────────────────────────────────────────────────┘
```

| 区域 | 默认尺寸 | 说明 |
|------|:--:|------|
| Panel 高度 | 150px | 默认展开高度 |
| Panel 最小高度 | 60px | 拖拽下限——至少显示一行 |
| Panel 最大高度 | 壳窗口 50% | 拖拽上限——不能超过主区 |
| 分隔条 | 4px | hover 扩展至 6px，cursor: row-resize |
| Panel 标签栏 | 32px | 终端实例 tab + Output 频道 tab |

## 二、Panel 标签栏

```
┌──────────────────────────────────────────────────────────────────┐
│ [>_ PowerShell] [>_ bash] │ [输出: 串口日志] [输出: Git] │ [+] [▴] [×] │
│  ↑ 终端实例 tab             ↑ Output 频道 tab           ↑ 全局操作  │
│  图标 + 名称               图标 + 名称                                │
└──────────────────────────────────────────────────────────────────┘
```

### 终端实例 tab

| 属性 | 规格 |
|------|------|
| 图标 | `>_` codicon-terminal, 14px |
| 标题 | shell 名称 "PowerShell" / "bash" / "cmd" |
| 宽度 | 自适应标题文字, 最小 80px, 最大 180px |
| 选中态 | 底部 2px `--accent` 下划线 |
| hover | 背景 `--tab-hover-bg` |
| dirty | 有未查看输出时标题后 `●`（`--accent`） |

### Output 频道 tab

| 属性 | 规格 |
|------|------|
| 图标 | `📋` 或 codicon-output, 14px |
| 标题 | "输出: {频道名}"——如 "输出: 串口日志" |
| 宽度 | 同终端 tab |
| 区分 | 终端 tab 和 Output tab 中间用 `│` 分隔线（`--separator`） |

### 全局操作按钮（标签栏右侧）

| 按钮 | 行为 |
|------|------|
| `[+]` 新建终端 | 弹出 shell 选择——PowerShell / cmd / bash |
| `[▴]` 最大化 | Panel 占满窗口 50% → 再次点击恢复 |
| `[×]` 关闭 Panel | Panel 完全隐藏——`Ctrl+\`` 恢复 |

### 终端 tab 右键菜单

| 菜单项 | 行为 |
|------|------|
| 重命名 | 原地编辑 tab 标题 |
| 更改颜色 | 弹出 ColorPicker——只改这个终端实例的强调色 |
| 关闭 | 关闭该终端实例 |

## 三、Panel 与主区的分隔条

```
主区
──────────────────────────────────────  ← 分隔条, 4px, cursor: row-resize
  Panel 标签栏
  Panel 内容区
```

| 属性 | 规格 |
|------|------|
| 默认高度 | 4px |
| hover 高度 | 6px（扩展 2px 便于抓取） |
| 颜色 | `--separator` |
| hover 颜色 | `--accent` |
| 拖拽范围 | Panel 最小 60px ↔ 壳窗口 50% |
| 双击 | Panel 折叠/展开（toggle——对标 VS Code 双击分隔条） |
| 动画 | 拖拽时即时跟随（0ms），松手时无动画 |

## 四、xterm.js 终端配色

> 终端配色跟随 LinkDesk 主题——通过 CSS 变量传给 xterm.js 的 `theme` 选项。

```typescript
// 终端实例创建时
const term = new Terminal({
  theme: {
    background: getComputedStyle(document.documentElement).getPropertyValue('--bg-window').trim(),
    foreground: getComputedStyle(document.documentElement).getPropertyValue('--text-primary').trim(),
    cursor: getComputedStyle(document.documentElement).getPropertyValue('--accent').trim(),
    selectionBackground: getComputedStyle(document.documentElement).getPropertyValue('--accent').trim() + '40',
    // ANSI 颜色走主题定义或 xterm.js 默认
  },
  fontFamily: '"Fira Code", "Cascadia Code", Consolas, monospace',
  fontSize: 13,
  cursorBlink: true,
  cursorStyle: 'bar',
});
```

| xterm.js 选项 | 值 | 来源 |
|------|------|------|
| background | `var(--bg-window)` | 跟随主题 |
| foreground | `var(--text-primary)` | 跟随主题 |
| cursor | `var(--accent)` | 跟随主题 |
| selection | `var(--accent)` 40% | 跟随主题 |
| fontFamily | Fira Code → Cascadia Code → Consolas | 固定 |
| fontSize | 13px | 固定 |

## 五、Output 频道视图

```
┌──────────────────────────────────────────────────┐
│ [输出: 串口日志]                       [清空] [📋] │  ← 频道级操作
├──────────────────────────────────────────────────┤
│ [14:32:05] 端口 COM3 已打开，115200bps            │
│ [14:32:06] 收到数据: 0x48 0x65 0x6C 0x6F        │
│ [14:32:10] 发送: [speed, 75]                     │
│ [14:32:15] ⚠ 校验失败，已重试                      │  ← 错误着色
│ ...                                              │
└──────────────────────────────────────────────────┘
```

| 属性 | 规格 |
|------|------|
| 行高 | 20px |
| 字体 | 12px "Fira Code", monospace |
| 时间戳 | `--text-muted`, 11px |
| 普通文本 | `--text-primary` |
| 错误文本 | `--color-destructive` |
| 发送文本 | `--accent` |
| 顶部操作 | [清空] 清除当前频道 / [📋] 复制全部到剪贴板 |
| 自动滚动 | 开——新内容到达自动滚到底部 |

## 六、快捷键

| 快捷键 | 命令 | 行为 |
|------|------|------|
| `Ctrl+\`` | `workbench.action.terminal.toggle` | 打开/关闭 Panel（如果 Panel 已开→聚焦终端） |
| `Ctrl+Shift+\`` | `workbench.action.terminal.new` | 新建终端实例 |
| `Ctrl+Shift+PgUp/PgDn` | — | 切换终端/Output tab |

## 七、状态矩阵

| 状态 | 触发条件 | 视觉表现 |
|------|------|------|
| Panel 关闭 | 默认 / 点 [×] | Panel 完全隐藏——主区占满窗口 |
| Panel 打开——有终端 | `Ctrl+\`` / 点 [+] | Panel 展开 150px + 终端 tab 选中 |
| Panel 打开——无终端 | 关闭最后一个终端后 | Panel 保留（不自动关闭）+ 显示空白区 "[+] 新建终端" 按钮 |
| 终端繁忙 | 命令执行中 | 终端 tab 标题变斜体 |
| 终端退出 | shell 进程退出 | xterm.js 显示 "进程已退出，按 Enter 重启终端" |
| Output 为空 | 频道创建但无输出 | 显示 "暂无输出"（`--text-muted`，居中） |
| 多 tab 溢出 | tab 太多超出标签栏宽度 | 出现 `<` `>` 滚动箭头 |
