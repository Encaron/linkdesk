## 三、交接纪律

1. **开工第一件事**：`npm run ui:build`（dev 轨道解析 `dist`——不重建则「改了没反应」，[03 §五.1](03-文档连锁与发版.md)）。
2. **⛔ 不碰他批在途件**：会话开始时 `git status` 里已有一批别的工作流的改动（实测例：`CLAUDE.md` · `AGENTS.md` · `package.json` · `docs/04-软件更新/00-README.md` · `docs/开发管理/新能力设计流程.md` · `src/hooks/useUpdateScheduler.ts` · `src/core/services/files/FileAssociationService.test.ts` · `docs/04-软件更新/已落地/文件打开方式与贡献点/06-组件户口与组合纪律.md` · 待抉择池另一夹 `分段预览色块边缘串色/` · 未入库的 `scripts/check-no-deferred-placement.mjs` ＋ `deferred-placement-allowlist.json`）。
   ⚠️ **这份名单是快照、不是真相**：每次提交**现读** `git status`，**逐条点名路径**，⛔ **绝不用 `git add -A`**／`git add .`。⚠️ 尤其 `src/core/services/files/FileAssociationService.test.ts` 与本案**同域**——⛔ 不是本案的测试落点（本案断言落在共享件的 `ManagerView.test.tsx`）。
3. **⛔ 实现纪律（轴二）**：必须 `t(变量)`，⛔ 不许 `t("编辑器")` 硬编码具体插件名（门会全绿而对第三方无效）；`pluginId`（机器名）⛔ **不翻**，只翻**显示名**来源（[01 §三](01-方案与落点契约.md)）。
4. **⛔ 不许顺手扩面**：`SelectBox` 触发器圆角（[02 E7](02-边缘情况清单.md)）、检索口径（E16）、`--radius-xs` 统一、`radius` prop——一律另立。
5. **交棒模板**（写进本档下方表 ＋ [00](00-README.md) 状态行）：

   ```
   棒次：AI-N｜阶段：…｜状态：✅ 收棒 ／ 🔴 卡住（卡在哪、需要什么）
   现状：动了哪些文件（逐条）+ 关键读数（git diff 行数／门禁结果／测试名与断言数）
   冻结项：本轮定死不许动的（别人接手时当作不可变）
   下一棒第一件事：一句话（命令级）
   遗留：登记但未做的（编号 → 在哪登记）
   ```

6. **卡住就停、报人工**：门禁报红且三轮内改不出绿、或发现必须扩面（例如插件仓要跟改）——🔴 **停下来报**，⛔ 不许静默放宽门禁／加白名单／扩大改动面。
