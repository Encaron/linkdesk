## 施工棒次（T1–T8）

- [ ] **T1 起仓与声明面**——脚手架＋插件身份＋图标＋市场 debut。
  - 方案：`npx create-linkdesk-plugin@latest`（0.1.25）在 `E:\linkdesk-plugins\official\` 起仓 `pdf-reader`（脚手架自建 git 仓；容器本身绝不 `git init`——`E:\linkdesk-plugins\README.md` 铁律一）；`pluginId = "pdf-reader"`、`minAppVersion` 按现装壳定（0.2.32 起步）；声明面照 [01-任务书 §四⑤](01-任务书.md)（fileAssociations pdf ＋ appearsIn 仅 tabBar ＋ identityField=filePath ＋ i18n 声明＋icon）；`resources/icon.svg` **= [07-插件图标-定稿.svg](07-插件图标-定稿.svg) 原样取用（案 A 红带文档，2026-10-07 用户拍板）**——三处复用（标签栏/市场/打开方式选择器；无图标栏图标）；i18n 声明串过自有字典。
  - 判据：`npm run build` 出 `pdf-reader.linkdesk-plugin`；dev 壳手动装包（拖进市场/开发者安装）后标签页骨架出现、图标上标签栏；官方各仓审计脚本认得这仓（目录下有 plugin.json）。
  - 禁区：不填 `distribution`（废弃字段）；不立任何占位命令/组件（无死代码从第一棒守起）。

- [ ] **T2 引擎引入**——pdf.js 跑通渲染管线。
  - 方案：`pdfjs-dist` 钉版本进 lockfile（登记表 [01-任务书 §五B](01-任务书.md)）；worker 随 vite 打包走通（T2 专项判据）；cmaps/标准字体产物随包；`readBinaryFile` 拿字节 → `getDocument` → 单页 canvas 渲染样例 pdf。
  - 落点：`src/services/pdfDoc/`（`loadPdf.ts` 加载与页面对象 `destroy()` 生命周期；worker/cmaps 产物路径收口 `src/constants.ts`）＋ 构建配置 worker 出包；`src/index.tsx` 只加装配不写业务（03 规范）。
  - 判据：dev 壳实机——样例 pdf 打开渲染出第一页（哪怕 UI 还很糙）；池沙箱 CSP 下 worker 正常起（实机验，不是 dev server 验）；包体读数记录在案。
  - 禁区：worker 打不通**不许**塞主线程凑合——上报，用户拍板。

- [ ] **T3 M1 阅读器主体＋固定底色**——照定稿设计施工（设计已拍板，无停等点）。
  - 方案：照 [00.5-UI布局规格.md](00.5-UI布局规格.md) ＋ [06-设计图.html](06-设计图.html) **定稿**施工——工具栏（翻页/页码/缩放/适宽/适页/搜索位/底色钮）＋连续滚动＋**虚拟化只渲染可视页**（大文件不死——首屏只渲染可视 ±2 页）；错误态两式**照 editor `BinaryNotice` 同款骨架**（[00.5 §三](00.5-UI布局规格.md)：共享 Button＋「打开方式…」/「在市场搜索阅读器」两颗探测接线钮；⛔ 无强开钮）＋加载骨架；**底色纸白＋夜间两档**（拍板定案）：`data-pdf-bg="paper|night"` 根类换档、token 照 00.5 §二表一处定义、不消费壳主题 token；底色切换 = 工具栏钮＋`pdfReader.setBackground` 命令同源；周边工具栏/状态条用 `@linkdesk/ui` 跟主题。
  - 落点：`src/views/ReaderView.tsx`（装配根）＋ `src/views/readerToolbar/`（工具栏钮组）＋ `src/views/readerSurface/`（canvas 与虚拟化窗口）＋ `src/components/ErrorState.tsx`（两态一骨架，含 BinaryNotice 同款探测接线）＋ `src/styles/`（00.5 §二 token 表唯一落点）；根类 `pdf-reader` ＋ `data-pdf-bg="paper|night"`。
  - 判据：实机——单击 pdf 全链（渲染/翻页/缩放/适宽）；**切壳主题阅读区纹丝不动**；底色两档切换即看即得；100MB 级 pdf 滚动不卡、内存不涨穿（页面对象 `destroy()` 纪律）；卸载退回。
  - 禁区：底色枚举只建 `paper|night`（sepia 留档不建——无死代码）；色值只许出现在 00.5 §二表对应的一处定义；**不立 forceOpen 类强开命令/按钮**（2026-10-07 拍板，editor 的 forceOpenAsText 是文本兜底角色自有动作，pdf 无此角色）。

- [ ] **T4 命令化＋i18n（AI 友好化收口）**。
  - 方案：`pdfReader.*` 命令族（pageNext / pagePrev / zoomIn / zoomOut / fitWidth / fitPage / gotoPage / setBackground / toggleSidebar / getStatus 等随 M1 已有功能立——**没有的功能不立命令**）全带 `description`＋`params`（照 [21-插件命令化规范](../../03-插件制造/21-插件命令化规范.md)）；结构化读数 `getStatus`（当前页/总页/缩放/底色档/侧栏态）供 AI 操作；i18n 自有字典补全（en 全覆盖）；配置项**定案一条**：`pdfReader.defaultZoom`（`fitWidth|fitPage|percent`，出厂默认 **fitWidth**，2026-10-07 拍板）声明＋字典同笔。
  - 落点：`plugin.json`（`contributes.commands` ＋ `contributes.configuration`）＋ `src/commands/`（登记表＋handlers，一命令一 handler）＋ `i18n/en.json`；`getStatus` 读数与状态条同源一份数据（归一化）。接线对账表 = [00.5 §七](00.5-UI布局规格.md)，逐颗钮逐条命令过一遍，多一颗少一颗都不行。
  - 判据：命令面板可跑全部命令；`ci-verify` ⑧段（own-dict-coverage）绿；`npm run manual:build` 壳侧手册若收录本插件命令则零手工（声明驱动天然收录）。
  - 禁区：description 是声明数据不是 UI 文字（硬约束 2 例外口径）；title/group 必须 i18n。

- [ ] **T5 M2 文本层**——划选复制＋页内搜索。
