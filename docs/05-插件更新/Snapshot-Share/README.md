## 基本逻辑

一键把当前卡片工作台导出为一张漂亮的 PNG 截图——带 LinkDesk 水印和元数据（设备名、时间戳、数据范围）。截图不是简单的 `html2canvas`——是有设计的：加了边框、水印、底部信息条。

**核心原则：** 这不是截图工具——是**病毒式传播工具**。用户分享的每张快照都是 LinkDesk 的广告。

---

## 处于软件内位置

```
卡片工作台右上角 → 📸 快照按钮（或命令面板 → "导出快照"）
  └─ 生成 PNG
       └─ 复制到剪贴板（主要）
       └─ 或保存为文件（次要）
  └─ Toast："📸 快照已复制到剪贴板"
```

**触发入口：**
1. 卡片工作台工具栏 → 📸 图标按钮
2. 命令面板 → "导出快照"
3. 快捷键 `Ctrl+Shift+S`（对标其他软件的截图快捷键）

---

## 生态地位

| 维度 | 说明 |
|------|------|
| **病毒传播** | 每张分享的快照 = 一次免费广告。工程师社区是天然传播渠道 |
| **用户留存** | 用户分享后有成就感 → 更愿意继续用 |
| **品牌建设** | 右下角水印让看到的人知道"这是 LinkDesk 做的" |
| **依赖链** | 依赖卡片工作台（E4 后）。但技术简单——`html2canvas` 或 `dom-to-image` |

## 关键交互

| 交互 | 触发 | 行为 |
|------|------|------|
| **导出快照** | 点击 📸 / Ctrl+Shift+S | 画布截图 → 添加水印和信息条 → PNG |
| **复制到剪贴板** | 默认行为 | PNG 进入剪贴板 → toast 提示 |
| **保存为文件** | 长按 📸 / 右键菜单 "另存为..." | 弹出保存对话框 |
| **toast** | 导出完成 | "📸 快照已复制到剪贴板"（2 秒后消失） |
| **水印可选** | 设置页可关 | 用户可选择关闭水印（但默认开启） |

### 水印设计

┌─────────────────┐

位置：右下角，距边缘 20px
透明度：0.6
备注：用户可以关掉，但默认开
