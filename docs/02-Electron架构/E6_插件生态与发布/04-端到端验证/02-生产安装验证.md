# 生产安装验证——全链路

> 对应任务：E6#22-#25。从独立构建 hello-world 到在安装版 LinkDesk 里从市场安装——Encaron 亲自验证。

---

## 一、独立构建验证（E6#22）

### 操作步骤

```bash
cd hello-world
npm run build
```

### 检查项

```
[ ] hello-world.linkdesk-plugin 文件存在
[ ] 文件大小合理（~50-300KB——React 不内嵌所以较小）
[ ] 解压验证：
    [ ] plugin.json 完整——字段和原版一致
    [ ] index.bundle.js 存在
    [ ] index.bundle.js 可 import（Chrome DevTools 手动验证）
    [ ] i18n/en.json 存在
```

```
    [ ] 语言切换正常
```

## 三、安装版全链路验证（E6#24）

### 前置条件

```
[ ] hello-world.linkdesk-plugin 已上传到 GitHub Releases
[ ] marketplace.json 已更新——hello-world 条目存在
[ ] GitHub raw URL 可访问
```

### 操作步骤

```
1. 启动安装版 LinkDesk
2. 打开插件市场（侧栏 marketplace 图标）
   [ ] 市场页面正常渲染
   [ ] hello-world 出现在列表中
   [ ] 按钮显示 "安装"

3. 点击 "安装"
   [ ] 进度条显示
   [ ] 下载完成 → "已安装"

4. 查看图标栏
   [ ] Smile 图标出现

5. 点击 Smile 图标
   [ ] 侧栏切换到 Hello 视图
   [ ] 问候语显示正确
   [ ] "Open New Tab" 按钮可用

6. 点击 "Open New Tab" 3 次
   [ ] 3 个标签页出现在标签栏
   [ ] 每个标签页显示不同随机数

7. 打开一个文件 → 编辑器内右键
   [ ] 菜单中 "Hello: Say Hi" 出现
   [ ] 点击 → toast 弹出

8. 按 Ctrl+Shift+H
   [ ] toast 弹出

9. 打开设置 → Hello World 配置组
   [ ] greeting 字段存在，值为默认值
   [ ] 修改 → 侧栏文字实时变化

10. 切英文
    [ ] 菜单中 "Hello: Say Hi" 变英文（保持不变——本来就是英文）
    [ ] 其他 UI 正常切换

11. 关闭 LinkDesk → 重新打开
    [ ] hello-world 仍在图标栏
    [ ] 点击 → 侧栏正常

12. 卸载 hello-world
    [ ] 市场页面 → "已安装" 变 "安装"
    [ ] 图标栏 Smile 消失
    [ ] installed-plugins.json 无 hello-world 记录
```

## 四、Encaron 终极验证（E6#25）

**这是 E6 封站的唯一标准。**

### 条件

```
❌ 不能用命令行
❌ 不能看代码
❌ 不能动任何配置文件
✅ 纯鼠标 + 键盘操作
```

### 步骤

```
1. 如果 LinkDesk 没装 → 下载安装包 → 安装
   如果已装 → 打开

3. 看到 Hello World → 点安装

4. 安装完成后：
   - 点图标 → 侧栏出来了 ✓
   - 打开标签页 → 标签页出来了 ✓
   - 右键菜单 → 有 Hello 选项 ✓
   - Ctrl+Shift+H → 弹出提示 ✓
   - 设置里改 greeting → 侧栏变了 ✓

5. 卸载 → 图标消失了 ✓
```
