# 文件树插件

> 2026-07-24。从旧 P7b 拆分——文件树是第一批消费者插件，验证 E2d 侧栏扩展位 + E2c FileService。
> **性质：** 纯插件——不碰壳代码。Monaco 编辑器相关任务拆分到 `02-Monaco编辑器.md`。

---

## 一、定位

对标 VS Code Explorer。文件树注册为系统视图插件，和终端插件完全相同的注册路径：

```
plugins/file-tree/plugin.json → {"name":"文件树","sidebarRole":"persistent","sidebar":{"component":"sidebar.tsx"}}
  → viewRegistry 注册 → IconBar 出现 📁 图标
    → 单击 📁 → 侧栏 persistent 区域显示文件树
    → 双击 📁 → 文件树变成独立标签页
```

## 二、任务清单

### 任务 1：文件树视图（~200 行）

```
plugins/file-tree/
├── plugin.json          → sidebarRole: "persistent"
├── sidebar.tsx          → 树组件 + 文件列表
├── FileTreeView.tsx     → 标签页模式
└── index.tsx            → 导出
```

**功能：**
- 树形目录浏览：`window.linkdesk.filesystem.listDir()` → 递归渲染
- 点击打开文件 → 关联编辑器插件
- 右键菜单：打开/打开方式…/剪切/复制/粘贴/重命名/删除/新建文件/新建文件夹
- 文件图标（按扩展名显示不同图标）

### 任务 3：文件关联（FileAssociationService）（~60 行）

```typescript
class FileAssociationService {
  private extToCommands = new Map<string, { pluginId: string; command: string }[]>();
  register(pluginId: string, associations: FileAssociation[]): void;
  getCommandFor(extension: string): { pluginId: string; command: string } | undefined;
}

// plugin.json
{ "contributes": { "fileAssociations": [
  { "extension": ".md", "command": "docReader.open", "label": "Markdown 阅读器" },
  { "extension": ".dxf", "command": "cad.openFile", "label": "CAD 查看器" }
] } }

// 文件树双击：
const match = FileAssociationService.getCommandFor(".md");
if (match) CommandRegistry.execute(match.command, { filePath });
```

### 任务 4：系统文件拖入（~50 行）

```typescript
// Electron 拖放监听
window.addEventListener('drop', (event) => {
  for (const file of event.dataTransfer.files) {
    const ext = file.name.substring(file.name.lastIndexOf('.'));
    const match = FileAssociationService.getCommandFor(ext);
    if (match) CommandRegistry.execute(match.command, { filePath: file.path });
  }
});
```
