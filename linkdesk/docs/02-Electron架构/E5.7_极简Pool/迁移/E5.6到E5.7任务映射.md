# E5.6 → E5.7 任务映射

> E5.6 双Pool 执行到 317/644 子任务（51%）时切换架构到极简Pool。E5.6 剩余任务按以下规则分流：
> - **直接搬**——与 Pool 数无关的任务，改任务号进 E5.7 清单
> - **适配搬**——E5.6 概念在 E5.7 中有对应物，改造后进 E5.7 清单
> - **删除**——OverlayWindow / 多Pool 专属任务，架构消失后不再需要
>
> 本表是唯一映射真相。E5.6 清单只保留历史，不再执行。
