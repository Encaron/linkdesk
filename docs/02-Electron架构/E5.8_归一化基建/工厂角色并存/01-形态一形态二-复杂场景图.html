③ 验证点（设置 = 特殊角色——整个 UI 含切换入口、含快捷键页都是设置插件自己画的）：设置不像串口监视器靠配置组承载切换——设置本身就是一个切换页，切换入口本身就是设置。壳只注入数据（全部 N 个设置入口 + 快捷键数据）并保证可切换（逃生门）。 两层标签要分开看：主区标签栏 = 打开哪些视图（壳画，[设置] 只是其中之一，带关闭按钮）；设置页内部 [设置|快捷键] = 设置页自己的两个子页（设置插件画，下划线高亮）。快捷键只在这一层出现一次——不是主区标签、不是左侧导航项。 换 UI：切换入口的位置/格式/风格都可能变（内置顶部条 ⇄ 漂亮右下角胶囊）；快捷键页也一样——内置画成平铺表格（对标真实 KeybindingSettingsView），漂亮把同一份数据画成卡片分区（键帽胶囊）。快捷键是设置的一部分、不独立，随套走，作者只取数据、呈现自由。「恒在」= 可触达性，不是固定在最上面。极简设置（形态一，不声明 factoryRole）不进切换——图标常在、自己的页。
