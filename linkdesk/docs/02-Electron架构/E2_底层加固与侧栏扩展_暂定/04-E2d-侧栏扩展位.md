# E2d — 侧栏扩展位

> 2026-07-24。**全新设计——旧 P6/P7 没有这一项。**
> **性质：** 架构级壳改动——侧栏从 "跟标签页走" 变成 "支持常驻面板"。文件树需要这个坑位。

---

## 一、问题

当前侧栏模型：激活终端标签页 → 侧栏显示终端会话列表。侧栏内容绑定到标签页——切换标签页侧栏内容跟着换。

文件树需要：**侧栏常驻面板——不随标签页切换而消失。** 用户打开终端 → 侧栏应该可以同时显示文件树（下面）和终端会话（上面），而不是二选一。

对标 VS Code：Explorer（文件树）在侧栏常驻，不随编辑器标签页切换消失。终端面板在底部面板。

**这是架构级改动——侧栏的渲染模型变了。** 但它只为 "给插件挖坑"——文件树本身仍然是插件。

---

## 二、设计

### 2.1 槽位模型

```
侧栏
├── primary 槽位（跟标签页走——当前行为）
│   └── 激活终端标签页 → 终端会话列表
│
└── persistent 槽位（常驻——新设计）
    ├── 文件树（sidebarRole: "persistent"）
    ├── 导航菜单（sidebarRole: "persistent"）
    └── ...其他常驻面板
```

### 2.2 plugin.json 声明

```json
{
  "sidebarRole": "persistent",  // "tagFollower"（默认）| "persistent"
  "sidebar": {
    "component": "sidebar.tsx",
    "title": "文件树",
    "icon": "folder",
    "order": 1
  }
}
```

| 值 | 行为 | 例子 |
|------|------|------|
| `"tagFollower"` | 侧栏内容绑定到标签页。切换标签页 → 侧栏换内容 | 终端会话列表 |
| `"persistent"` | 始终渲染，不随标签页切换消失 | 文件树、导航菜单 |

### 2.3 壳渲染逻辑

```typescript
// SidePanel.tsx 改动
function SidePanel() {
  const persistentViews = viewRegistry.getBySidebarRole("persistent");
  const tagFollowerView = viewRegistry.getActiveTagFollower();

  return (
    <div className="side-panel">
      {/* tagFollower 区域——跟标签页走 */}
      <ErrorBoundary pluginId={tagFollowerView?.pluginId}>
        <SidePanelSection>
          {tagFollowerView?.sidebarComponent && (
            <tagFollowerView.sidebarComponent />
          )}
        </SidePanelSection>
      </ErrorBoundary>

      {/* persistent 区域——始终渲染 */}
      {persistentViews.map(view => (
        <ErrorBoundary key={view.pluginId} pluginId={view.pluginId}>
          <SidePanelSection title={view.sidebarTitle} collapsible>
            <view.sidebarComponent />
          </SidePanelSection>
        </ErrorBoundary>
      ))}
    </div>
  );
}
```

### 2.4 和图标栏的联动

图标栏的 persistent 图标独立于标签页图标：
- 点 📁（文件树）→ 侧栏 persistent 区域滚动到文件树 / 展开
- 点 📟（终端）→ 切换到终端标签页 → tagFollower 区域显示终端会话

## 四、完工标准

- 文件树插件声明 `sidebarRole: "persistent"` → 侧栏常驻显示
- 切换到终端标签页 → 侧栏上方显示终端会话（tagFollower），下方文件树仍在（persistent）
- 文件树折叠 → 只保留标题栏
- ErrorBoundary 各槽位独立——persistent 面板崩了不影响 tagFollower
