# E5.8-命令面板失焦修复档案

> 2026-08-29 立案 E5.8#188（Phase 11.22 一般 bug）。用户实机：命令面板（quick-pick）失焦不消失——点面板外任意处面板不关。而右键菜单、悬浮面板、弹窗面板三者的失焦消失都正常。用户提问：*「为什么 float 面板、右键面板、刚才修复的弹窗面板就是失焦消失，而这个就不是？根因是什么？是硬编码、死代码、没有高内聚低耦合、没有归一化的 bug 吗？」*

---

## 一、现象

命令面板打开后，点主区/侧栏任意空白处，面板**不消失**。用户实机：当时唯二关闭方式是「点击面板输入区使输入光标聚焦 → 按 Esc」或「Enter 执行一条命令」。失焦关闭在之前的版本一直正常。

---

## 二、根因（file:line + 机制）

**QuickPickHost.css:7 头注释里 `--kbd-*/` 的 `*/` 提前闭合了 `/**` 块注释**，导致块注释之后的所有文字变成裸 CSS token 组（坏规则），CSS 语法错误恢复（consume-a-qualified-rule）把**首条真规则 `.quick-pick-backdrop` 整条吞掉**，解析从 `.quick-pick-backdrop.show` 处才恢复。

原注释（修复前）：

```css
/**
 * ...
 * 约束：所有颜色走 CSS 变量——禁止硬编码 hex（E5.8#128.6：backdrop 0.3 收编 --scrim-overlay，keycap/hover 收编 --kbd-*/--icon-btn-hover-bg）。
 * z-index 不写死——inline Z_INDEX.quickPick / quickPick-1（constants.ts 常量表，#26）。
 * ...
 */
```

- 第 7 行注释里的 `--kbd-*/` —— `/` 后紧跟 `*`，恰好构成 `*/` → `/**` 块注释在此**提前闭合**。
- 其后所有行（`z-index 不写死…`、`pointer-events 不在此写…`）都变成**裸 token 组**，它们组成一条 malformed qualified rule。
- CSS 解析器按规范执行 error recovery：`consume-a-qualified-rule` 把该坏规则连同**紧随其后的第一条合法规则 `.quick-pick-backdrop { position:fixed; inset:0; … }` 一并吞掉**（坏规则一直消费到遇到下一个 `{…}` 块边界才终止），解析在 `.quick-pick-backdrop.show` 处才恢复。

**结果**：`.quick-pick-backdrop` 的全部声明（`position: fixed` / `inset: 0`）丢失 → 遮罩退化为 `position: static`、高度 0 → 点击「面板外」实际点在底层内容上，`onClick={() => closeCurrent()}` 永不触发 → 失焦不消失。遮罩变量值 `--scrim-overlay` 与 `opacity`/`transition` 是**设计 §5.1 指定值**，代码逻辑本身零问题。

## 四、为什么只有命令面板失焦不消失（用户疑点回答）

四个浮层共享同一套归一化失焦关闭机制（E5.8#107：backdrop 以 `createPortal` 进 `#ld-scrim-plane` + onClick 关闭），但**只有 quick-pick 的 backdrop 依赖 CSS 文件**，且**它是该 CSS 文件的首条规则**——恰好成为坏注释被吞的那一条：

| 浮层 | backdrop 样式来源 | 是否受影响 | 原因 |
|---|---|---|---|
| 右键菜单 ContextMenu | JSX inline style（position/inset/z-index 全在组件里） | ❌ 免疫 | 零 CSS 文件依赖，无文件可被吞 |
| 弹窗 Dialog | `DialogHost.css` 类 | ❌ 正常 | 该文件头注释无 `*/` 陷阱，规则完整 |
| 悬浮面板 FloatingPanel | `FloatingPanel.css` 类 | ❌ 正常 | 同上 |
| 命令面板 QuickPick | `QuickPickHost.css:14` 类 | ✅ 中招 | 首条规则 + 头注释带 `*/` 陷阱 |

**不是硬编码、不是死代码、不是低内聚、不是归一化问题**——代码是最大程度归一化的（`var(--scrim-overlay)`、Z_INDEX 常量、scrim-plane portal 全量复用）。这是**不可见 CSS 解析 bug**：`npm run check`（双工程 tsc + ESLint + 1409 tests + jscpd + pool-css）和浏览器 devtools 全都不报——CSS 解析错误恢复按规范「安静」进行，没有 error 事件。

### 检测模式

`grep '\*/[^\s/]'` 扫 *.css 可抓「非结尾处的 `*/`」（src 仅此 1 例、plugins 0 例）。已顺带扫全仓确认无第二处同类隐患。

`src/pool/floating/quick-pick/QuickPickHost.css:7` 注释改写：
