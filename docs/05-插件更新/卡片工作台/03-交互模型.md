# 03 — 交互模型

> 对标 VS Code 三栏交互——左键/右键/弹窗/hover 各司其职。

---

## 一、交互分工总览

```
┌─────────────────────────────────────────────────────────┐
│                      卡片交互层                          │
│                                                         │
│  默认态              hover 态             编辑态         │
│  ┌────────┐        ┌────────┐        ┌──────────────┐  │
│  │ 温度    │        │ ≡ 温度 ✕│        │ 卡片设置      │  │
│  │        │  ──→   │        │  ──→   │              │  │
│  │ 37.2   │        │ 37.2   │  点 ≡   │ 名称/大小/    │  │
│  │        │        │        │  或右键  │ 颜色/子项... │  │
│  └────────┘        │    ▞   │        └──────────────┘  │
│       ↑            └────────┘              ↑            │
│       │                  ↑                │            │
│  点击卡片本体      hover 2s 后         双击标题/单位     │
│  → 全屏/放大      出现 chrome           → 原地编辑       │
│  (如果支持)                             (不弹弹窗)      │
└─────────────────────────────────────────────────────────┘
```

---

## 二、逐操作详解

### A. Hover——卡片 chrome 显现

| 元素 | 默认状态 | hover 后（2s 延迟） |
|------|------|------|
| 标题栏（≡ + ✕） | `opacity: 0` | `opacity: 1`，150ms 淡入 |
| resize 把手（▞） | `display: none` | `display: block`，右下角 |
| 卡片边框 | `var(--border)` | `var(--accent)` + `box-shadow` |
| 整卡 | — | `cursor: grab`（可拖拽提示） |

**2s 延迟理由：** 鼠标扫过画布时不需要看到每张卡片的 chrome——只有 hover 停留超过 2s 才出现，对标 VS Code 编辑器 tab 的 ✕ 行为。

**触摸设备：** 无 hover。单点卡片 = 选中态（蓝色边框），选中态下 chrome 始终可见。

---

### B. 双击——原地编辑

| 双击目标 | 行为 |
|------|------|
| 卡片标题文字 | 变为 `<input>`，原地编辑，回车确认，Esc 取消 |
| 单位标签 | 变为 `<input>`，原地编辑，回车确认，Esc 取消 |
| 数值大字 | 无效果（数值来自硬件，不可手改） |
| 卡片空白区 | 控制类无效果；显示类 = 全屏（如果卡片支持全屏模式） |

**为什么标题和单位能原地改：** 它们都只是一个字符串——原地改效率最高，不需要弹窗。对标 VS Code 文件树重命名（单击已选中文件 → 原地编辑）。

---

### C. 拖拽——移动卡片位置

| 操作 | 行为 |
|------|------|
| 按住卡片空白区 | 卡片跟随鼠标（半透明 80% + 阴影） |
| 拖动过程 | 其他卡片不移动——画布无限，不挤压 |
| 松手 | 吸附到最近网格点，200ms `power1.out` 滑入 |
| 拖到其他卡片上方 | 弹出"不能重叠"指示（红色边框闪烁） |

**网格吸附算法：**
```typescript
// 松手时计算最近网格点
const gridX = Math.round(mouseX / gridUnit) * gridUnit;
const gridY = Math.round(mouseY / gridUnit) * gridUnit;
```

---

### D. Resize——缩放卡片尺寸

| 操作 | 行为 |
|------|------|
| 拖右下角把手 | 卡片按 `allowedSizes` 顺序切换，实时预览 |
| 方向 | 向右下角拖 → 放大 / 向左上角拖 → 缩小 |
| 松手 | 吸附到下一个 `allowedSizes` 尺寸 |
| 超出 `allowedSizes` | 循环——最小尺寸后再缩 → 跳到最大尺寸 |

**不是任意像素拖拽。** 拖拽把手只在预定义的固定尺寸之间切换。

---

### E. 右键 / ≡ ——打开设置弹窗

| 触发 | 行为 |
|------|------|
| 右键卡片任意位置 | 弹窗在卡片旁弹出 |
| 点击 ≡ 图标 | 同上 |
| 弹窗外点击 | 关闭弹窗（不保存） |
| Esc | 关闭弹窗（不保存） |
| 确定 | 保存设置 → 卡片即时更新 |
| 重置 | 回到该卡片类型的默认设置 |

**弹窗定位：** 在卡片右侧弹出，距离卡片 8px。如果屏幕空间不够（卡片在最右边），弹到左边。

### E-2. 条件规则编辑器——指示灯/数值变色/仪表盘阈值

> 一条规则 = 条件 + 外观。不满足 → 下一条。都不满足 → 默认规则。

**支持的条件（六种）：**

| 条件 | 含义 | 适用场景 |
|------|------|------|
| `== "xxx"` | 等于某值 | `value == "led_red"` → 亮红灯 |
| `!= "xxx"` | 不等于 | `value != "off"` → 任意非关闭状态亮绿灯 |
| `> N` | 大于某数字 | `value > 100` → 超阈值爆红 |
| `< N` | 小于某数字 | `value < 0` → 负值异常亮黄 |
| `>= N` | 大于等于 | `value >= 80` → 高值警告 |
| `<= N` | 小于等于 | `value <= 20` → 低值警告 |

**弹窗中的规则编辑表：**

```
┌─────────────────────────────────────────┐
│  卡片设置——指示灯                     ✕  │
│─────────────────────────────────────────│
│  ...                                    │
│                                         │
│  ── 颜色规则 ──                          │
│  ┌──────────────────────────────────┐   │
│  │ 条件              颜色    闪烁    │   │
│  │ value == led_red   🔴  ☐  [✕]  │   │
│  │ value == led_green 🟢  ☐  [✕]  │   │
│  │ value > 100        🔴  ☑  [✕]  │   │
│  │ ─── 默认 ───        🟢  ☐       │   │  ← 前三条都不匹配时用
│  │ [+ 添加规则]                     │   │
│  └──────────────────────────────────┘   │
│                                         │
│         [重置]  [取消]  [确定]          │
└─────────────────────────────────────────┘
```

**操作：**
- `[+ 添加规则]` → 新行出现：条件下拉 `[== ▾]` + 值输入框 + 颜色块（点击调 ColorPicker）+ 闪烁勾选框
- 每条规则右侧 `[✕]` → 删除该规则
- 规则顺序 = 优先级——从上到下匹配，第一条匹配的生效
- 默认规则（`condition: null`）永远在最下面——不可删除，只能改颜色

**存储——`settings.rules` 数组：**

```json
{
  "settings": {
    "rules": [
      { "condition": "value == 'led_red'",   "color": "#EF4444", "blink": false },
      { "condition": "value == 'led_green'", "color": "#22C55E", "blink": false },
      { "condition": "value > 100",          "color": "#EF4444", "blink": true },
      { "condition": null,                   "color": "#64748B", "blink": false }
    ]
  }
}
```

**规则不强制——`rules` 为空数组或不存在的卡片不受影响。** 指示灯有默认的颜色映射（on→绿/off→灰/error→红），用户不改规则就用默认。

**适用卡片类型：**

| 卡片类型 | 匹配规则后影响什么 |
|------|------|
| 指示灯 | 圆点颜色 + 是否闪烁 |
| 数值卡片 | 数字颜色 |
| 仪表盘 | 指针颜色 + 超阈值区颜色 |
| 进度条 | 填充色 |
| 折线图 | 线条/面积色 |

### B-2. 新建卡片流程——底座先行，类型后选

> 所有卡片共享同一个底座。新建 = 放底座 → 选芯。换类型 ≠ 删了重建。

**三步流程：**

```
1. 右键空白区 → "添加卡片" → 选类型
   │
   ▼
2. 底座出现在点击位置
   ┌──────────┐
   │ ≡ 新卡片✕│  ← CardChrome：标题栏 + 边框 + 圆角 + 拖拽 + resize
   │          │
   │  (空)    │  ← 芯：由 type 决定渲染什么
   │          │
   │      ▞   │
   └──────────┘
   │
   ▼
3. 弹窗自动打开 → 设置 cardId、单位、子项、规则...
   │
   ▼
4. 确定 → 数据到达 → 卡片开始工作
```

**底座（CardChrome）——所有卡片共有的壳：**

```
┌──────────────────────┐
│ ≡ 标题           ✕   │  ← 标题栏——双击改名
│                      │
│                      │  ← 内容区——由 type 决定
│    (不同类型渲染      │
│     不同内容)        │
│                      │
│                 ▞    │  ← resize 把手
└──────────────────────┘

共享行为：
  useCardDrag()     → 拖拽移动
  useCardResize()   → 拖拽缩放
  useCardData()     → 数据订阅
  useCardSettings() → 设置读写

独有渲染（芯）：
  ValueCard     → 28px 大字 + 单位
  GaugeCard     → SVG 弧形 + 指针
  SliderCard    → 拖动条 + 发送逻辑
  ExpressionCard → 公式求值 + 结果显示
  ...
```

**换类型不删卡片——底座不动，芯可换：**

```
温度数值卡片 (type: "value")
  │  右键 → 弹窗 → 类型下拉改选 "仪表盘"
  ▼
温度仪表盘 (type: "gauge")

不变的（底座属性）：
  ✅ 卡片实例 ID (uuid)
  ✅ cardId 绑定 ("temp")
  ✅ 位置 (0, 0) 2×2
  ✅ 标题 "温度"
  ✅ protocolId

变的（芯）：
  🔄 type: "value" → "gauge"
  🔄 渲染变了（大字 → SVG 指针）
  🔄 不适用的设置自动隐藏（value 有 subItems，gauge 没有 → 弹窗隐藏该分组）
```

**弹窗中的类型切换：**

```
┌─────────────────────────────────┐
│  卡片设置                    ✕  │
│─────────────────────────────────│
│  名称  [温度__________________] │
│  类型  [数值卡片 ▾]             │  ← 改这个 → 芯换掉，底座不变
│        [仪表盘    ]             │
│        [折线图    ]             │
│        [指示灯    ]             │
│        [表达式卡片]             │
│        ────────────             │
│        [滑块      ]             │
│        [按钮      ]             │
│        [开关      ]             │
│                                 │
│  大小  [2×2 ▾]    ← 底座属性    │
│                                 │
│  ── 数据 ──    ← 底座属性       │
│  数据源 [temp ▾]                │
│  协议  [跟随标签页 ▾]            │
│                                 │
│  ── 外观 ──    ← 芯专属（不同     │
│  单位  [°C___]    type 显示不同  │
│  小数位 [1 ▾]    分组）          │
│  ── 子项 ──       ← 仅 value    │
│  ☑ 进度条          card 显示    │
│  ☑ 波形图                       │
└─────────────────────────────────┘
```

**类型下拉分两组——显示类在上，控制类在下。** `────────────` 分隔线。表达式卡片和多字段卡片也在显示类分区。

### F. 删除——✕

| 触发 | 行为 |
|------|------|
| 点击 ✕ | `showConfirm("删除此卡片？")` |
| 确认 | 卡片从画布移除 → 从 `workspace.json` 删除 |
| 取消 | 无变化 |

**删除不卸载卡片类型。** 只是画布上少了一张卡片，CardRegistry 里该类型仍在——下次添加卡片时还能选。

### G-2. 高频操作上浮——波形图专用 🆕

> 高频操作（暂停/切窗口/缩放）不放弹窗——在卡片表面直接操作。低频（采样率/颜色/标签）留在弹窗。

```
┌──────────────────────────┐
│ ≡ 温度趋势            ✕  │
│ ╱╲   ╱╲           ⏸    │  ← 右上角：暂停/播放（hover 出现）
│╱  ╲_╱  ╲___             │
│              ╲ ╱╲       │
│               ╲╱  ╲     │
│─────────────────────────│  ← 底部工具栏（hover 出现）
│ 30s │ 60s │ 120s │ ⋯   │  ← 时间窗口标签——点一下即切
│ 曲线1 ☑ 曲线2 ☑        │  ← 双曲线模式：显隐切换
│ scale: +200%            │  ← 缩放比例（拖拽后显示）
└──────────────────────────┘
```

| 操作 | 触发 | 行为 |
|------|------|------|
| ⏸/▶ 暂停/播放 | 点右上角图标 | 冻结/恢复——数据不丢（RingBuffer 继续写），解冻后追上最新值 |
| 切换时间窗口 | 点底部标签 `30s` / `60s` / `120s` / `300s` / `全部` | 即时切换，不弹弹窗 |
| 拖拽 X 轴缩放 | 鼠标在 X 轴区域水平拖拽 | 捏合时间范围——看一段波动 |
| 拖拽 Y 轴缩放 | 鼠标在 Y 轴区域垂直拖拽 | 缩放 Y 轴范围——放大微小波动 |
| 双击重置 | 双击图表区 | X/Y 同时重置——X=当前窗口，Y=auto |
| 悬停查值 | 鼠标悬停 | 十字准线 + tooltip——值 + 时间戳 |
| 曲线显隐 | 点底部曲线名标签 | 每条曲线独立——`设定值 ☑ 实际值 ☑ 输出 ☐` |
| 📏 测量入口 | hover 波形区 1s → 右上角淡入 | 点 📏 → 测量浮层面板打开（默认选中最后一条活跃曲线） |
| 点曲线 | 点曲线本体 | 面板打开 + **自动切到被点的曲线**——点 CH1 蓝线 → 显示 CH1 的测量；点 CH2 绿线 → 切到 CH2。不手动选下拉 |
| 测量浮层面板 | 鼠标移出/失焦 | 自动消失——即时生效，不弹确认 |

**智能检测——不显示无意义的测量项：**

```
波形图自动分析每条曲线的形状 → 只默认开启有意义的测量：

  正弦波 → Vpp/Freq/Avg/RMS（Duty 无意义——自动关闭）
  方波   → Vpp/Freq/Duty     （Avg/RMS 无意义）
  三角波 → Vpp/Freq/Avg
  DC 信号 → Avg/Vmax/Vmin    （Freq/Duty/RMS 无意义）
  未知   → Vpp/Vmax/Vmin/Avg  （Freq/Duty 算不准——自动关闭）

用户仍可手动开/关任何项——自动只影响默认。不是锁定。

**📏 触发——瞬态浮层，不是弹窗：**

```
三种触发各管各的，互不冲突：

  右键卡片空白区              点 📏 / 点曲线            底部 📏 快捷入口
  ─────────────              ────────────            ───────────────
  右键菜单                    hover 波形区 1s          始终可见
  → "卡片设置"               → 右上角 📏 图标淡入      点 → 测量浮层面板
  → "保存为模板"
  → "复制"                   鼠标移出/点浮层外
  → "删除"                   → 面板消失（即时生效）
```

**测量浮层面板——不弹确认，即时生效：**

```
┌────────────────────────────┐
│ 测量                     ✕ │
│────────────────────────────│
│ 曲线: [CH1 ▾]              │
│                            │
│ ☑ Vpp  3.28V  锚点 [左上 ▾]│
│ ☑ Freq 50.1Hz              │
│ ☐ Avg  1.64V               │
│ ☐ RMS  2.32V               │
│ ☐ 波形类型                  │
│                            │
│ ── 渲染 ──                  │
│ 引擎: [Canvas 2D ▾]        │
│ 采样率: [10 Hz ▾]          │
│                            │
│ ── 轴 ──                    │
│ Y 轴: [auto ▾]             │
│ X 标签: [时间____________]  │
│ Y 标签: [电压____________]  │
└────────────────────────────┘
  ↑ 改任何项 → 即时生效
  ↑ 鼠标移出 / 点外部 / Esc → 消失
  ↑ 对标浏览器 DevTools 样式面板——调完就走，不弹确认
```

**两级配置分离：**

| | 卡片设置弹窗 | 测量浮层面板 |
|------|:--:|:--:|
| 打开方式 | 右键 / ≡ | 📏 图标 / 点曲线 |
| 保存 | 确定才保存 | 即时生效 |
| 关闭 | Esc / 点外部 | 鼠标移出 / 失焦 |
| 频率 | 设一次不改 | 天天调——换曲线、开/关测量项 |
| 内容 | 名字/类型/大小/cardId/协议/颜色/外观开关 | 测量项/锚点/渲染引擎/采样率/轴标签 |

**高频 vs 低频——判据：**

```
卡片表面（hover 出现）：          弹窗（右键打开）：
  暂停/播放                         采样率 (Hz)
  时间窗口快捷切换                    X/Y 轴标签
  X/Y 拖拽缩放                      曲线颜色
  双击重置                          样式 (line/area/bar)
  悬停查值                          双曲线 cardId 绑定
  曲线显隐                          轴范围固定值 [min, max]

判据：一分钟内可能做 3 次的 → 表面。设一次再也不改的 → 弹窗。
```

### G. 全屏——双击卡片本体

| 卡片类型 | 全屏行为 |
|------|------|
| 折线图 | 弹出最大化浮层——全屏 Canvas，带时间窗口和 Y 轴控件 |
| 仪表盘 | 放大到 300%，带数值大字叠加 |
| 数值卡片 | 无全屏——双击无效 |
| 控制类 | 无全屏——双击无效 |

全屏浮层：半透明暗色遮罩 + 卡片最大化居中。Esc / 点遮罩 → 退出全屏。

### I. 对齐辅助线——拖拽时品红色引导线 🆕

> 对标 Figma 对齐线。拖卡片经过其他卡片的边缘或中心时，自动显示品红色辅助线 + 轻微磁吸。

```
拖卡片 B 经过 A 的右边缘：

  ┌────┐
  │ A  │
  │    │──────── ← 品红色对齐线出现
  └────┘
       ┌────┐
       │ B  │  ← B 的左边缘吸附到 A 的右边缘
       └────┘
```

| 触发条件 | 对齐线位置 | 磁吸 |
|------|------|:--:|
| B 的左/右边缘接近 A 的左/右边缘 | 垂直红线 | 3px 吸附 |
| B 的上/下边缘接近 A 的上/下边缘 | 水平红线 | 3px 吸附 |
| B 的水平中心接近 A 的水平中心 | 垂直虚线 | 3px 吸附 |
| B 的垂直中心接近 A 的垂直中心 | 水平虚线 | 3px 吸附 |

**不是强制吸附——** 继续拖超过 5px → 脱离磁吸。对齐线只报一次——接近时出现，对齐后消失。

### J. 数据快照——冻结画面 🆕

> 调试时数据跑太快，想看清某个瞬间 → 冻结。对标示波器的 Stop 按钮。

```
正常状态              冻结状态
┌──────────┐        ┌──────────┐
│ 温度      │        │ 温度  ❄  │  ← 蓝色半透明遮罩 + 雪花图标
│ 37.2°C   │  空格  │ 37.2°C   │  ← 数值停在冻结瞬间
└──────────┘  ──→   └──────────┘

点冻结时右上角出现时间戳：❄ 14:32:05.128
再点空格 → 恢复实时 → 遮罩消失，数据追上当前值
```

| 操作 | 行为 |
|------|------|
| `Space` | 冻结 / 解冻 |
| 冻结时 | 卡片停止消费 RingBuffer——显示最后一次收到的值 |
| RingBuffer | 不停止——继续写，不丢数据 |
| 解冻时 | 消费 RingBuffer 最新值——追上当前 |
| 视觉 | 蓝色遮罩 10% 透明度 + `❄` 图标 + 冻结时间戳 |

**所有卡片同步冻结——** 一张冻结 = 全部冻结。不是 per-card 操作。

### K. 卡片联动——A 超标时 B 变色 🆕

> 条件规则的 `effect` 从"改自己"扩展到"改目标卡片外观"。

```
温度卡片规则：
  value > 80 → 风扇卡片的边框变红 + 背景脉冲闪烁

不是改风扇卡片的数据——是改它的外观。
```

```json
{
  "rules": [
    {
      "condition": "value > 80",
      "color": "#EF4444",          // 改自己颜色
      "effect": {
        "target": "uuid-of-fan",   // 🆕 联动目标卡片 ID
        "style": {
          "borderColor": "#EF4444",
          "pulse": true            // CSS 脉冲动画
        }
      }
    }
  ]
}
```

**这是规则系统的自然延伸——** 条件匹配后不只是改自己颜色，还可以向其他卡片发外观指令。不含数据改变——只是外观。

未被选中              被选中
┌──────────┐        ┌──────────┐

| Delete 键 | 删除选中的卡片 |
| 多选 | 暂不支持——v1 只有单选 |

## 四、控制类卡片的特殊交互

| 类型 | 额外规则 |
|------|------|
| 滑块 | 拖动滑块 → 只更新本地显示。松手 → 发送 `[cardId, value]` |
| 按钮 | 点击 → 弹确认框 → 确认 → 发送。默认开确认（按钮最容易误触——一碰就发） |
| 开关 | 点击 → 发送 `[cardId, on/off]` → 等待 MCU 回发确认 |

**为什么没有"撤销发送"：** 串口 115200bps 下数据几毫秒到 MCU。发了就是发了——撤回是聊天软件的事，不是硬件的。防误触靠发送前确认，不靠发送后撤销。

**控制类卡片不可删除 `cardId` 绑定。** 弹窗中"绑定"字段对控制类是必填——删了绑定意味着按钮不知道发给谁。

## 五、与卡片拖拽的冲突处理

| 冲突 | 解决 |
|------|------|
| 滑块卡片——点滑块本体 vs 拖卡片 | 滑块 handle 内不触发拖拽——`onMouseDown` → `stopPropagation()` |
| 按钮卡片——点按钮 vs 拖卡片 | 按钮区域内不触发拖拽 |
| resize 把手 vs 拖拽 | 把手区域不触发拖拽——`onMouseDown` → `stopPropagation()` |

**判断逻辑：** `onMouseDown` 时检测点击目标——如果是交互控件（滑块把手/按钮/resize 把手/✕/≡），不启动拖拽。
