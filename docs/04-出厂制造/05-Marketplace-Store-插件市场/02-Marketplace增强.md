## 两种显示模式

### 模式 1：侧边栏模式（当前已有）

> 侧栏中显示——紧凑列表。快速搜索、安装、启用/禁用。

保留当前 `sidebar.tsx` 的全部功能，作为默认模式。

### 模式 2：全屏商店视图（新增）

> 点击"浏览插件市场"→ 弹出 FloatingPanel（类型 B 悬浮面板）→ 大面积商店体验。

**布局：**
- **左侧分类栏：** 按插件类型/标签分组（串口/地图/主题/语言/仪表/工具/其他）
- **右侧卡片网格：** 插件卡片（图标 + 名称 + 评分 + 简介 + 安装按钮）
- **顶部搜索栏：** 全文搜索 + 标签过滤
- **底部操作栏：** "在主窗口中打开" / "最大化" / "关闭"

**与侧边栏的关系：** 不是替代——双模式。侧边栏用于日常快速操作（禁用/卸载），全屏商店用于发现和浏览。

## 模式切换机制

```typescript
// plugins/marketplace/plugin.json 加 contributes.commands

{
  "contributes": {
    "commands": [
      { "id": "marketplace.browse", "title": "插件市场: 浏览商店" },
      { "id": "marketplace.toggleView", "title": "插件市场: 切换侧边栏/商店视图" }
    ],
    "keybindings": [
      { "key": "Ctrl+Shift+X", "command": "marketplace.browse" }
    ]
  }
}
```

- `marketplace.browse` → 打开 FloatingPanel 全屏商店（如果文件树就绪 → 直接弹出；如果尚未 → 回退到侧边栏模式）
- `marketplace.toggleView` → 当前是侧边栏 → 弹出商店；当前是商店 → 关闭商店回到侧边栏

**实现：**
```typescript
// marketplace 插件内部
function MarketplaceEntry() {
  const [mode, setMode] = useState<'sidebar' | 'store'>('sidebar');

  // mode === 'sidebar' → 渲染 sidebar.tsx（当前侧栏内容）
  // mode === 'store'  → 渲染 <FloatingPanel><StoreView /></FloatingPanel>
  //                    （FloatingPanel 从壳 import）

  // "打开编辑器" → createTab("marketplace", { mode: "store" })
  //                → 标签页内全屏显示商店（非面板悬浮，等价于最大化）
}
```

## 搜索行为——vscode式（2026-08-17 用户拍板）

> 用户追问「搜索框出来的是不是就是商城里没下载的插件？已安装/待安装会不会消失？」——回答并拍板：**vscode式**。改动只动 marketplace 插件内部（`plugins/builtin/marketplace/src/`），不改壳。

**拍板行为（对标 VS Code Extensions 视图搜索）：**

- **搜索非空** → 「已安装/内置/已禁用/未安装」四组 section 头**全部隐藏**，合并为**单一搜索结果列表**——所有匹配项（无论本地状态）平铺一处
- **已安装的匹配项仍然出现**（带 [卸载]/[禁用] 按钮）——不是只显示未下载的（跟 VS Code 一致：搜到已装的直接给卸载入口）
- **清空搜索** → 恢复四组正常显示
- **搜索匹配规则不变**：按 name / pluginId / description（现有 `matchSearch` 逻辑）

> ⚠️ **不是**「搜索 = 只显示未安装」——那是个误解。搜索=全部匹配，已安装项带状态按钮。

## 为什么还是纯插件

Marketplace 增强不碰壳代码——全部改动在 `plugins/marketplace/` 内。用到的壳能力：

| 能力 | 来源 | 用途 |
|------|:--:|------|
| FloatingPanel | 壳组件（v1.2 提供） | 商店面板容器 |
| `getAllPlugins()` | viewRegistry | 列出所有已安装插件 |
| `installPlugin()` | loader | 安装新插件 |
| `executeCommand()` | CommandRegistry | `marketplace.toggleView` |
| `createTab()` | TabActionsContext | "打开编辑器"按钮 |

全部是已有 API——不需要新 IPC 通道或 preload 扩展。
