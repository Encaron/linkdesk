### 大白话四问（照 E6#120 §8.8 形状）

1. **改了什么？** 界面零件的供给方式翻了个面：过去**每个插件各自把一整套界面零件编译进自己的安装包**，现在**壳统一供一套，插件运行时向壳要**（vendor 单实例）。壳与 ui 的版本号从此锁在一条线上（本批同为 `0.2.13`）。
2. **用户看到什么不同？** 界面本身**一个字都没动**（像素、交互、玻璃与 token 全同款）；能感觉到的只有两件：插件套装得**更快更小**（四仓合计 2.44 MB → 0.38 MB），以及**以后壳改进一件零件，所有插件同屏同时变**，不必等作者逐个发版。
3. **作者要做什么？** 升 SDK 到 0.1.41+ 重 build 一次即可（**源码一行不用改**）；⛔ 别再 `import "@linkdesk/ui/index.css"`（判红，无豁免）；组件与钩子的名字**只加不减**（终身承诺）；样式**跟着壳走**，别再自带一份。
4. **下次壳改 UI 会发生什么？** 壳发版时 ui 同号 bump（门禁判据⑤机械核对，漏改拒发）；改一处组件样式 ⇒ **所有插件（在装了该壳版本的机器上）同屏同时变**，插件侧零改动、零重发。
