### 1.2 `pluginError`

```ts
// import { pluginError } from "@linkdesk/plugin-sdk/runtime";
export interface PluginErrorInit {
  /** 机读码（必填非空；E 开头建议，不强制）。壳码见下方保留表，⛔ 插件不得自造变体 */
  code: string;
  /** 给人读的一句（允许中文）；⛔ 拿它当码用 */
  message: string;
  /** 给 AI 的下一步（可省） */
  hint?: string;
  /** 结构化上下文（可省；JSON 可序列化） */
  details?: unknown;
}

export interface LinkDeskPluginError extends Error {
  readonly name: "LinkDeskPluginError";
  readonly code: string;
  readonly hint?: string;
  readonly details?: unknown;
  /** 跨 realm 判别标记（⛔ 不要靠 instanceof） */
  readonly isPluginError: true;
}

export function pluginError(init: PluginErrorInit): LinkDeskPluginError;
```

**契约**：
1. **预期业务错误固定 `return pluginError({...})`**；⛔ `throw pluginError` / 裸 `Error`——跨 contextBridge 的抛出只保留 message，`code`/`hint`/`details` 会丢 ⇒ 门外只剩 `EUNKNOWN`；返回值走结构化克隆，池侧按 `isPluginError:true` 转成带码拒绝。`throw` 仅用于真正的意外。`code` 必填非空（`E` 开头建议，不强制），`message` 必填；`details` 原样透传。
2. 壳 / CLI / MCP **原样透传** `code`，⛔ 猜语义改写。
3. 裸 `Error` / 非本形状 ⇒ `EUNKNOWN`（message 保留）。
4. **保留码**（壳产生，⛔ 插件不得抛）：`EVIEWREQUIRED` / `ENOTACTIVE` / `EUNKNOWNCOMMAND` / `EOPEXPIRED` / `EPOLICYDENIED` / `EPROTECTED` / `EUSERDENIED` / `ESHELLTIMEOUT` / `EUNKNOWN`。
5. 错误信封唯一形状：`{ ok:false, code, message, hint?, details? }`（04 §四）。
6. **落地（2026-11-25）**：`packages/plugin-sdk/src/runtime/plugin-error.ts`（12 条测试）；运行时只校验 `code` 非空与 `message` 非空（作者写错当场 `TypeError`），**保留码禁用**由 SDK ESLint 规则 `check-error-envelope`（T14，已落，13 legs；同时提示 `throw pluginError` 应改 `return`）拦——⛔ 在运行时维护第二张壳码表。保留码源 = contracts `index.cjs` 的 9 码（本地 link 已验，`source="@linkdesk/contracts"`）。

### 1.3 `AsyncCommandMeta`（**仅类型，无运行时导出**）

> 🔴 **用户裁定 #21（2026-11-25）· S6 异步声明走 A 案**：在 `registerCommand` 的 meta 里写 `{ async: true }`，**壳自动包 op**；
> 插件 ⛔ 调 `runAsync`（该运行时 API **取消**，不导出）。

```ts
// import type { AsyncCommandMeta } from "@linkdesk/plugin-sdk/runtime";
export interface AsyncCommandMeta {
  /** true = 壳把这条命令包成长任务：立即回 { pending:true, opId }，后台跑 handler */
  async?: boolean;
}
```

**契约**：
1. 声明点在 `registerCommand(id, handler, meta)` 的 **meta（运行期）**；manifest 的 `contributes.commands[].async` 可作**提前告知**（纯 additive），运行期 meta 覆盖声明（同 `activation`）。壳据此自动包 op，插件 handler 本来就是 async 函数、代码零改动。
2. exec 异步回执 `{ commandId, pending:true, opId, startedAt }`；查询走 `opStatus` → `{ state:"running"|"done"|"failed"|"expired", result?, error?, startedAt, elapsedMs }`；过期 ⇒ `EOPEXPIRED`；`log` 增 `op.completed`。
3. op 注册表 / TTL / 淘汰 / 事件全归**壳**（A/T11）；插件 ⛔ 自建状态机、⛔ 自缓存。
4. contracts 的 `registerCommand` meta 需接受 `async?: boolean`（B 增 / 调度台协调）；SDK ⛔ 另造第二份 meta 类型。
5. **类型面分工**：`AsyncCommandMeta` 由 SDK 出（`runtime/async-command.ts`）；`pending?` / `opId?` / `opStatus` 回执类型归 contracts（B 增），SDK 经 `export type *` 自动转发——⛔ SDK 另写第二份。
6. **T11 结果类型**：`@linkdesk/contracts/ai-bridge`（`AiBridgeExecPending` / `AiBridgeCommandResult` / `AiBridgeOpStatus` / `AiBridgeOpError` / `AiBridgeOpState`）由 `src/types.ts` **显式转发**（主 `linkdesk.d.ts` 不含该子路径），⛔ 另写。

### 1.4 `decodeBytes` ＋ `SERIAL_CODINGS`（T17 原语）

> 🔴 **口径以 B 的消费者现值为准**（调度台 2026-11-25 裁决，覆盖本档早先草案）：编码值是**大写四串**，不是小写 id。

```ts
// import { decodeBytes, SERIAL_CODINGS } from "@linkdesk/plugin-sdk/runtime";
export const SERIAL_CODINGS = ["UTF-8", "GB2312", "Shift-JIS", "Latin-1"] as const;
export type SerialCoding = (typeof SERIAL_CODINGS)[number];

export interface DecodeBytesOptions {
  /** true = 非法序列抛 TypeError；默认 false = lossy（替换为 U+FFFD） */
  strict?: boolean;
}

export function decodeBytes(data: Uint8Array, coding: SerialCoding, options?: DecodeBytesOptions): string;
```

**语义（钉死）**：

| 档 | 行为 |
|:--|:--|
| `UTF-8` | TextDecoder `utf-8`；`strict:true` 时非法序列抛错 |
| `GB2312` | 按 **GBK 超集**解码（TextDecoder `gbk`；兼容 2312 流） |
| `Shift-JIS` | TextDecoder `shift_jis` |
| `Latin-1` | **手工 1:1**：字节 `0x00`–`0xFF` → `U+0000`–`U+00FF`（⛔ TextDecoder `iso-8859-1`，它实为 windows-1252） |

- **默认 `strict:false`（lossy）**：手动档遇到坏字节显示替换符，⛔ 让整屏抛错；`Latin-1` 无非法序列，选项对它无效果。
- **「自动」不是编码、不进 `SERIAL_CODINGS`**（06 §二）：回退顺序（`UTF-8 strict` → `GB2312 strict`）是**串口插件策略**，⛔ 塞进 SDK。
- 解码原语**只有这一处**；插件侧 ⛔ `new TextDecoder` ＋ 手写 GBK 分支（06 §二）。
- 输入只收 `Uint8Array`（contracts 的 `data` 类型），⛔ 再收字符串/数组。
- 落地位置：`packages/plugin-sdk/src/runtime/serial-coding.ts`，barrel `runtime/index.ts`，子路径 `./runtime`（dist 已重建）。
