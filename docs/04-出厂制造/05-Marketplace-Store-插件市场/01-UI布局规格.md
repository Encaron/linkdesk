> **类型：市场插件** | **05-出厂制造 #05** | 2026-07-28。**插件市场全屏商店的 UI/UX 规格。** 消费 FloatingPanel（悬浮窗系统类型 B）作为容器。
> 设计系统来源：`ui-ux-pro-max` → App Store Style Landing + Soft UI Evolution + GSAP hover micro-interaction
> 对标 VS Code Extensions 视图 + macOS App Store。
> 🎨 **交互预览：** [marketplace-preview.html](marketplace-preview.html) 在浏览器查看效果

## 一、原始文档差距分析

`05-Marketplace增强.md`（150 行）是功能架构文档——描述了"有什么功能"但没描述"长什么样"。对照前面 ColorPicker/FileTree/卡片工作台 的制作水准，以下全部缺失：

### 1.1 Wireframe 层面

| 缺口 | 严重度 | 说明 |
|------|:--:|------|
| 无精确尺寸 | 🔴 | 侧栏多宽？卡片多大？搜索栏多高？全凭开发时拍脑袋 |
| 无卡片内部排版 | 🔴 | 图标多大？名称在第几行？评分怎么放的？描述几行截断？ |
| 分类侧栏无视觉规格 | 🟡 | 只有文字列表但无图标/计数/选中态 |
| 搜索栏无设计 | 🟡 | 输入框是圆角矩形还是胶囊形？右侧筛选下拉的位置？ |
| 无分页设计 | 🟢 | 页码是数字还是左右箭头？位置在网格下方还是底部栏？ |
| FloatingPanel 底部按钮栏未定义 | 🟡 | "在主窗口中打开" / "最大化" / "关闭" 三个按钮的排列？哪个是主操作？ |

### 1.2 视觉层面

| 缺口 | 严重度 | 说明 |
|------|:--:|------|
| 零 token 表 | 🔴 | 无任何尺寸/颜色/间距的 CSS 变量定义 |
| 无动画规格 | 🔴 | App Store 风格的核心是卡片的微交互——hover 上浮、入场 stagger、安装进度 |
| 安装按钮只有一种状态 | 🟡 | 原文只提"安装按钮"——但实际需要：未安装(绿)、已安装(灰)、更新可用(绿边框)、安装中(spinner) |
| 评分无格式 | 🟢 | `★4.5` 但星级颜色、空星样式、字体大小都没写 |
| 无"有更新"角标设计 | 🟢 | 原文提了"卡片上'有更新'角标"但没画 |

### 1.3 行为层面

| 缺口 | 严重度 | 说明 |
|------|:--:|------|
| 零状态覆盖 | 🔴 | 加载中？空结果？安装失败？分类切换后网格刷新？ |
| 自适应列数未说明 | 🟢 | 卡片网格是固定 4 列还是 `auto-fill`？ |
| 分类筛选后卡片更新动画 | 🟢 | 切分类→网格重排——是瞬间跳变还是有过渡？ |
| 与 FloatingPanel 的关系模糊 | 🟡 | 原文说"弹出 FloatingPanel"，但 FloatingPanel 是通用壳——商店内容是它的 children。尺寸约束？ |

## 二、ui-ux-pro-max 改进方案

### 2.1 风格定位

| 来源 | 推荐 | 应用到 LinkDesk |
|------|------|------|
| `--design-system` | **App Store Style Landing** | 卡片网格 + 星级评分 + 下载量——对标 App Store 发现感 |
| | **Soft UI Evolution** | 改进阴影（比 flat 有层次，比 neumorphism 清晰）+ WCAG AA+ |
| `--variance 7` | Balanced / Modern | 非对称布局不适合应用商店——保持对称网格 + 规则间距 |
| `--motion 5` | Standard | 卡片 hover 上浮 + stagger 入场 + 按钮状态过渡 |
| `--density 5` | Standard (16-64px) | 比仪表盘稀疏——商店需要呼吸感 |

### 2.2 关键视觉决策

| 决策 | 原文档 | 改进后 |
|------|------|------|
| 卡片背景 | 未定义 | 深于 FloatingPanel 背景的卡片底色——形成层次（对标 App Store 卡片浮在浅灰背景上） |
| 图标 | 未定义 | 48×48px 圆角色块——插件图标不是 16px 小图标，是大色块（对标 macOS App Store 图标） |
| 安装按钮 | 单一"安装" | 三态：安装(accent绿填充) / 已安装(透明+灰边框) / 更新(accent绿边框) |
| 评分 | 文字 "★4.5" | 金色星星 + 灰空星 + 下载量——对标 App Store |
| 卡片 hover | 未定义 | y-4px + scale(1.02) + 阴影 + 边框变 accent——对标 App Store 卡片 |
| 入场动画 | 无 | GSAP stagger fade+slide——卡片从下淡入，`each: 0.04s` |
| 更新角标 | 只提了概念 | 图标右上角 7px accent 圆点——对标 App Store 蓝色更新点 |

### 2.3 与 FloatingPanel 的集成

```
FloatingPanel（04-悬浮窗系统.md 类型 B）
  │
  └── children = <MarketplaceStore />
        │
        ├── <StoreSearch />          ← 搜索栏——胶囊形输入框 + 筛选/排序下拉
        ├── <StoreSidebar />         ← 分类侧栏——图标+名称+计数，160px
        ├── <PluginCardGrid />      ← 卡片网格——CSS Grid auto-fill，180px 列宽
        ├── <Pagination />           ← 分页——← 1/3 → + 总数
        └── FloatingPanel.actions   ← 底部按钮——继承 FloatingPanel 的 actions slot
```

FloatingPanel 负责壳（遮罩/标题栏/关闭/底部按钮），商店内容只关心自己区域——**不重复发明面板逻辑。**

> 🔧 **2026-08-29 落位更新：** 商店落位 = 市场插件主区宽屏标签页（标签页通用表面容器，浮出/独立窗免费），**非独立 FloatingPanel 容器**——本节的 FloatingPanel 集成与底部 actions 栏（[在主窗口中打开]）在标签页落位下消失（主区即宽屏）。本节视觉规格（卡片网格/token/状态矩阵）仍为商店内容参考。

## 四、设计 Token

### 4.1 卡片 Token

| Token | 值 | 用途 |
|------|------|------|
| `--store-card-width` | 180px | 卡片宽度 |
| `--store-card-padding` | 12px | 卡片内 padding |
| `--store-card-border-radius` | 10px | 卡片圆角 |
| `--store-card-icon-size` | 48px | 插件图标尺寸 |
| `--store-card-icon-radius` | 10px | 图标圆角（与卡片等圆角统一） |
| `--store-card-gap` | 12px | 卡片之间间距 |
| `--store-card-hover-lift` | -4px | hover 上浮量 |
| `--store-card-hover-shadow` | `0 12px 24px rgba(0,0,0,0.25)` | hover 阴影 |

### 4.2 卡片内部排版

| 元素 | 规格 |
|------|------|
| 图标 | 48×48px, 圆角 10px, 居中对齐, 纯色背景 + emoji/SVG |
| 名称 | 13px Inter 600, 单行截断, `--text-primary` |
| 版本号 | 10px Inter 400, `--text-secondary` |
| 评分 | `★` 金色 `#EAB308`, `☆` 灰色 `--text-muted`, 字体 10px |
| 下载量 | 10px, `--text-muted`, 简写格式 (5.2k / 1.3k / 892) |
| 描述 | 10px, `-webkit-line-clamp: 2`, `--text-secondary`, 行高 1.4 |
| 按钮 | 全宽 26px, 圆角 5px, 字体 11px 500 |
| 更新角标 | 图标右上角 7px 圆点, `--accent`, `border: 1px solid card-bg` |

### 4.3 按钮三态

| 状态 | 样式 |
|------|------|
| **安装** | `background: --accent`, `color: #000` |
| **已安装** | `background: transparent`, `border: 1px solid --text-muted`, `color: --text-secondary` |
| **更新 vX.Y.Z** | `background: transparent`, `border: 1px solid --accent`, `color: --accent` |
| **安装中** | 按钮变 spinner, 文字 "安装中…", disabled |
| **安装失败** | 按钮闪红 200ms, 恢复"安装", toast 错误 |

### 4.4 分类侧栏 Token

| Token | 值 | 用途 |
|------|------|------|
| `--store-sidebar-width` | 160px | 分类栏宽度 |
| `--store-category-item-height` | 30px | 分类项行高 |
| `--store-category-active-bg` | `var(--tree-bg-selected)` | 选中分类背景 |
| `--store-category-count-color` | `--text-muted` | 计数标记颜色 |

### 4.5 搜索栏 Token

| Token | 值 | 用途 |
|------|------|------|
| `--store-search-height` | 44px | 搜索栏高度 |

## 五、动画规格

> 来源：`ui-ux-pro-max` motion 5 (Standard) + GSAP hover micro-interaction

| 动画 | 时长 | 缓动 | 说明 |
|------|:--:|------|------|
| 卡片 hover 上浮 | 250ms | `power2.out` | `y-4px + scale(1.02) + box-shadow` |
| 卡片 hover 恢复 | 200ms | `power2.out` | mouseleave 反向 |
| 卡片 stagger 入场 | 400ms | `power1.out` | `opacity:0 → 1, y:16 → 0, scale:0.92 → 1`, stagger `each: 0.04s` |
| 按钮状态切换 | 200ms | `ease-out` | 安装→安装中→已安装，颜色+边框过渡 |
| 安装失败闪烁 | 200ms × 2 | `ease-in-out` | 按钮边框红闪 → 恢复 |
| 分类切换——网格刷新 | 卡片先 fadeOut 150ms → grid 更新 → stagger 入场 400ms |
| 搜索防抖 | 300ms | — | 输入停止 300ms 后触发过滤 |

## 六、状态矩阵

| 状态 | 触发条件 | 视觉表现 |
|------|------|------|
| **正常——有插件** | 已安装插件 > 0 | 卡片网格正常渲染 + 分类栏显示计数 |
| **加载中** | 扫描插件目录 | 卡片区域居中 spinner + "正在加载插件列表…" |
| **空——全部分类无插件** | 0 个插件 | 居中大图标 🧩 + "还没有安装任何插件" + "在侧栏搜索并安装插件以开始使用" |
| **空——过滤后无结果** | 搜索/分类过滤后 0 匹配 | 居中 "没有找到匹配的插件" + "尝试其他关键词" |
| **分类选中** | 点分类项 | 选中态背景 `--tree-bg-selected` + 卡片网格过滤到该分类 |
| **搜索中** | 输入关键词 | 300ms 防抖 → 网格过滤 + 分类计数动态更新 |
| **安装中** | 点[安装] | 按钮变 spinner + disabled + 文字"安装中…" |
| **安装完成** | 安装成功 | 按钮变[已安装] + 短暂 toast "已安装 ✓" |
| **安装失败** | 安装出错 | 按钮闪红→恢复[安装] + toast 错误信息 |
| **更新中** | 点[更新] | 同"安装中" |
| **无更新** | 所有插件最新 | "可更新"筛选选项置灰或隐藏 |

## 七、卡片网格自适应

```css
.store-card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, 180px);
  gap: 12px;
  justify-content: center;
}
```

| FloatingPanel 宽度 | 列数 | 触发场景 |
|:--:|:--:|------|
| < 600px | 3 列 | 面板未最大化 |
| 600-840px | 4 列 | 默认 70vw ≈ 630px → 3 列 |
| 840-900px | 4 列 | 最大化 ≈ 900px → 4 列 |
