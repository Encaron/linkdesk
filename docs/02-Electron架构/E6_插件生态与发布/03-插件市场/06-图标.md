# 图标——作者自制 · 全态 · 即时

> 对应任务：E6#30e + E6#29c。市场第一站设计的图标维度（原 03-市场交互设计 §六 拆出）。
> 文档归属：市场设计文档族（[03-市场交互设计.md](03-市场交互设计.md) = 总览索引）。

| 场景 | 图标源 |
|:--|:--|
| 探索插件 · 未装 | catalog `icon`（lucide / codicon / **url**——作者自制彩色图直接 `<img>`） |
| 已安装列表 / 详情页 | 本地 manifest（包内 icon.svg） |
| 已装插件作者换图标 | 随版本更新获得 |

- **未装插件图标 = 作者提供什么显示什么**——PluginIcon 支持显式 icon descriptor 入参（不走 viewRegistry——未装插件无 registry 条目）。
- **「即时改」** = 重新 fetch catalog（5min 缓存）→ 列表/详情刷新即新图标；已装插件随版本更新（诚实边界——已装不读远程目录图标）。
