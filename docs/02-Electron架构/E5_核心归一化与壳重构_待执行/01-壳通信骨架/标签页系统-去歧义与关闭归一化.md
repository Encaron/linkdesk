## E5#50 🔴 同名标签页去歧义——对标 VS Code

### 现状

```
/projectA/main.c → 标签 "main.c"
/projectB/main.c → 标签 "main.c"  ← 完全一样，无法区分
```

**根因：** `FoldersView.doOpenFile` 传 `label: name`（只取文件名）。

### VS Code 做法

```
当多个 tab 的 basename 相同：
  main.c           ← 唯一的一个，不加后缀
  main.c • src/    ← 第二个，加父目录
  main.c • tests/  ← 第三个，不同的父目录
  main.c • src/sub/ ← 如果父目录也冲突，再加一层
  main.c • projectB/ ← 不同根目录
```

### 修复——TabBar 渲染时动态去歧义

```typescript
// src/components/TabBar.tsx——渲染标签名前计算去歧义 label
function getDisambiguatedLabel(tab: Tab, allTabs: Tab[]): string {
  // 只对 editor 类型去歧义
  if (tab.type !== "editor" || !tab.filePath) return tab.label;
  
  const sameBasename = allTabs.filter(t => 
    t.type === "editor" && t.filePath && t.id !== tab.id &&
    normalizePath(t.filePath).split("/").pop() === normalizePath(tab.filePath).split("/").pop()
  );
  
  if (sameBasename.length === 0) return tab.label;  // 唯一——不加后缀
  
  // 有同名——加父目录
  const parts = normalizePath(tab.filePath).split("/");
  parts.pop();  // 去掉文件名
  const parent = parts.pop() || "";  // 父目录名
  return `${tab.label} • ${parent}/`;
}
```

**在 TabBar 渲染中调：** `<span>{getDisambiguatedLabel(tab, allTabs)}</span>`

### 为什么不在 `createTab` 时存去歧义 label

因为标签页是动态创建/关闭的。去歧义取决于**当前所有打开的标签页中有没有重名**——关闭一个 `main.c` 后，另一个 `main.c` 的后缀应该自动消失。

## E5#51 🔴 [×]/中键/右键关闭脏标签页——统一确认

### 现状

| 关闭方式 | 有未保存修改时 |
|---------|-------------|
| Ctrl+W | ✅ 弹确认框 |
| [×] 按钮 | ❌ 静默无反应 |
| 鼠标中键 | ❌ 静默无反应 |
| 右键→关闭 | ❌ 静默无反应 |

**Ctrl+W 的确认逻辑在 `App.tsx closeActiveTab` handler 中。** 其他三条路径走 `TabBar.tsx` → `onCloseTab` → `reduceCloseTab` → 遇到 dirty 直接 `return { closed: false }`——调用方 `TabBar` 不检查返回值。

### 修复——把确认逻辑移到 `reduceCloseTab` 或 `useTabManager.closeTab`

```typescript
// useTabManager.ts closeTab——dirty 确认统一
const closeTab = useCallback((tabId: string) => {
  const tab = allTabs.find(t => t.id === tabId);
  if (!tab) return { closed: false };
  
  if (tab.dirty) {
    // 🔥 dirty 确认——四条关闭路径统一走这里
    showConfirm(
      t("「{{label}}」有未保存的修改，确定关闭？", { label: t(tab.label) })
    ).then((confirmed) => {
      if (confirmed) forceCloseTab(tabId);
    });
    return { closed: false, reason: "dirty" };
  }
  
  return reduceCloseTab(tabId);
}, [allTabs, forceCloseTab]);
```

**删除 `App.tsx closeActiveTab` 中重复的 dirty 确认逻辑。** 四条路径真正归一化。

## E5#52 🟡 标签名不被脏标记覆盖

### 现状

```typescript
// EditorTab.tsx——脏/净切换时
const label = isDirty ? `● ${baseName}` : baseName;
tabActions?.updateTabLabelBySourceId?.(filePath, label);
```

**`baseName` 从 `filePath` 重新取——不读已有的 `tab.label`。** 如果 E5#50 已经把标签改成了 `"main.c • src/"`，Ctrl+S 保存后脏标记去掉 → 标签变回 `"main.c"`——歧义丢失。

### 修复——读 tab 已有的 label，只加减 `●`

```typescript
const currentLabel = getTabBySourceId(filePath)?.label || baseName;
const label = isDirty ? `● ${currentLabel}` : currentLabel.replace(/^● /, "");
tabActions?.updateTabLabelBySourceId?.(filePath, label);
```

## E5#53 🟡 tooltip 显示完整路径

### 现状

```tsx
// TabBar.tsx L314
title={tab.pinned ? t(tab.label) : `${t(tab.label)} — 双击固定`}
```

**只显示标签名——没有路径。**

### 修复

```tsx
title={
  tab.filePath 
    ? `${normalizePath(tab.filePath)}${tab.pinned ? "" : ` — ${t("双击固定")}`}${tab.dirty ? ` — ${t("未保存")}` : ""}`
    : tab.label
}
```
