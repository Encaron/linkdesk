### 2.1 🔴 三处对账（原稿写错的地方——逐条记下来，别再犯）

| 原稿写的 | 现行 Schema 的真相 | 照原稿写的后果 |
|:--|:--|:--|
| `"tabBehavior": { "isSingleton": false }` | 字段名是 **`singleton`**（`tabBehavior` 现有关键字：`singleton` / `isFallback` / `confirmOnClose` / `invokeBeforeClose` / `identityField`） | 字段不存在 ⇒ 静默被忽略 ⇒ 单例行为**不受控**（本该多开的变成单例，或反之），且不报错——最难查的那类 |
| `"appearsIn": { …, "statusBar": true }` | `appearsIn.statusBar` 的类型是 **string = 自绘状态栏组件的路径**（如 `"src/components/statusBar.tsx"`）；**要贡献静态条目用顶层 `statusBar` 数组**（每项 `id` 必填，可选 `icon`/`label`/`align`/`onClick`/`configurable`） | 写成 `true` ⇒ 类型不符；且「静态条目」与「自绘组件」是两条路，混用会两条都不生效 |
| `"views": { "main": { "title": … } }` | `views` 的 **key = 容器 ID**（不是随便起的名），**value 是数组**，每项**必填 `id` + `render`**（`title`/`order`/`when`/`role` 可选） | 对象形状 ⇒ Schema 校验不过；且缺 `render` ⇒ 侧栏点开是空白 |
| `"viewsContainers": { "sidePanel": {…} }` | 容器 ID 必须匹配 **`^[a-z][a-z0-9-]*$`**（全小写 + 连字符）。`sidePanel` 含大写 ⇒ **非法**。用 `hello-world-sidebar` 这种 | 非法 ID ⇒ 容器注册不上，图标点了没反应 |

> 📌 **`pluginRole` / `iconSource` / `icon` / `entry` 四个字段是对的**，原稿这几处没写错——上表只列错的那三条 + 一条 ID 规则。

## 三、src/views/HelloView.tsx（侧栏视图，`views[].render` 指向它）

> 🔴 **2026-09-11 校正两处 API 签名**（原稿照抄会写出不生效的代码）：
> - `configuration.onChange` 是 **`onChange(key, cb)`**——**key 是第一个参数，回调只收 `value`**。原稿写成 `onChange((key, value) => …)`（单参传回调 + 双参回调）⇒ 订阅条件与回调形状**双错**。
> - `tabs.create` 是 **`create(type, opts?)`**——**第一个参数是标签页 type 字符串**，不是 `{pluginId, label}` 对象。原稿写成对象 ⇒ 参数错位。

```tsx
import React, { useState, useEffect } from "react";

export default function HelloView({ isActive }: { isActive: boolean }) {
  const [greeting, setGreeting] = useState("Hello, LinkDesk!");
  const [tabCount, setTabCount] = useState(0);
  // 每次挂载新随机数——用来证明「多标签页 = 多实例」而不是共享一份状态
  const [randomValue] = useState(() => Math.random());

  useEffect(() => {
    if (!isActive) return;   // 🔴 硬约束 14：所有 effect 都要这个守卫

    // 读配置初值
    window.linkdesk?.configuration?.get?.("hello.greeting").then((v) => {
      if (typeof v === "string") setGreeting(v);
    });

    // 订阅配置变化——签名 onChange(key, cb)，cb 只收 value
    const unsubscribe = window.linkdesk?.configuration?.onChange?.<string>(
      "hello.greeting",
      (value) => setGreeting(value),
    );

    return () => { unsubscribe?.(); };
  }, [isActive]);

  // 把问候语推成 context key（供快捷键 when / 状态栏条目消费）
  useEffect(() => {
    window.linkdesk?.contextKey?.set?.("hello.greeting", greeting);
  }, [greeting]);

  return (
    <div style={{ padding: "20px" }}>
      <h2>{greeting}</h2>
      <p>Random value (new per tab): {randomValue.toFixed(4)}</p>

      <button
        onClick={() => {
          // 🔴 签名 create(type, opts)——第一参是标签页 type
          window.linkdesk?.tabs?.create?.("hello-world", {
            label: `Hello Tab ${tabCount + 1}`,
          });
          setTabCount((t) => t + 1);
        }}
        className="button"          /* 🔴 硬约束 1/2：颜色走主题 token，不写 hex；样式走壳共享类 */
      >
        Open New Tab
      </button>

      <p style={{ marginTop: "20px", color: "var(--text-secondary)" }}>
        Try: right-click in editor → "Hello: Say Hi"
        <br />
        Or press: Ctrl+Shift+H
        <br />
        Or change greeting in Settings → Hello World
      </p>
    </div>
  );
}
```

## 三·二、src/index.tsx（激活入口，`entry` 指向它）

```tsx
// 命令 handler 注册——plugin.json 里 commands 声明「有哪些命令」，
// 这里 registerCommand 提供「命令做什么」。两者缺一不可。
// 🔴 方法名是 registerCommand（不是 register）
window.linkdesk?.commands?.registerCommand?.("hello.sayHi", () => {
  // 🔴 方法名是 notifications.show(message, options)（不是 push）；
  //    发出去落在唯一通知面 = 状态栏铃铛宽面板
  window.linkdesk?.notifications?.show?.("Hello!");
});

window.linkdesk?.commands?.registerCommand?.("hello.openTab", () => {
  // 🔴 openOrFocus(type, opts?)——第一参是标签页 type
  window.linkdesk?.tabs?.openOrFocus?.("hello-world");
});
```

> ⚠️ **原稿这里有一段「模块级命令注册」的伪代码**（`if (typeof window !== "undefined" && window.linkdesk) { window.linkdesk.commands?.executeCommand; }`）——**里面全是空语句，什么也没注册**，还容易让人以为「命令在模块级自动注册」。**已删除**。真实规则：**命令声明在 `plugin.json`，handler 在这里 `registerCommand`**（对照 [`docs/03-插件制造/01-插件API契约.md`](../../../03-插件制造/01-插件API契约.md)）。
> 🔴 **模块级只允许一次性、无监听器的初始化**（硬约束 19/20）——**禁止在模块级注册 IPC 监听器**（导入即执行、永不清理）。订阅一律进 `useEffect` + 清理函数。
> 🔴 **API 名字别猜**：本档校正过三个（`registerCommand` / `notifications.show(message, options)` / `tabs.create(type, opts)`）。**写代码前开 [`electron/preload-pool/`](../../../../electron/preload-pool/) 对一遍**——`?? ` 可选链会**静默吞掉拼错的 API 名**（`window.linkdesk?.commands?.register?.()` 不报错、也不注册），这正是这类 bug 难查的原因。
