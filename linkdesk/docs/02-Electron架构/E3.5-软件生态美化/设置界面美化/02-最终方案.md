# 02 — 最终方案

> 2026-07-29 定案。

---

## 插件作者视角

两个可选字段，不写 = 和现在一模一样。

### 四种写法

| 写法 | 效果 |
|------|------|
| 什么都不写 | **平铺**——自己的分组下竖着排，零变化 |
| 只写 `section` | **两级树**——自己分组下有子节点，可折叠展开 |
| 写 `parentGroup` + `section` | **合并+两级树**——归入父分组的子节点下 |
| 写 `parentGroup` 不写 `section` | **合并+平铺**——设置项直接挂在父分组下 |

### 示例

```json
// 插件 A — 什么都不写 → 平铺，和现在一样
"contributes": {
  "configuration": {
    "title": "串口监视器",
    "properties": {
      "serial-monitor.statusBar.txrx": { "type": "boolean", "default": true }
    }
  }
}

// 插件 B — 写 section → 自己分组下有两级树
"contributes": {
  "configuration": {
    "title": "快捷键",
    "properties": {
      "keybinding.showConflictWarning": {
        "section": "冲突检测",
        "type": "boolean",
        "default": true
      },
      "keybinding.allowChords": {
        "section": "组合键",
        "type": "boolean",
        "default": true
      }
    }
  }
}

// 插件 C — 写 parentGroup + section → 合并到"通用 → 主题"下面
"contributes": {
  "configuration": {
    "parentGroup": "通用",
    "title": "主题",
    "properties": {
      "theme-defaults.autoSwitch": {
        "section": "主题",
        "type": "boolean",
        "default": false,
        "description": "根据系统主题自动切换"
      }
    }
  }
}
```

## 代码改动

### `src/core/ConfigurationRegistry.ts`

```typescript
export interface ConfigurationProperty {
  // ... 现有字段不变
  /** 所属子分组名。不提供 = 直接挂在插件分组下平铺 */
  section?: string;
}

export interface ConfigurationContribution {
  title: string;
  properties: Record<string, ConfigurationProperty>;
  /** 合并到哪个父分组。不提供 = 独立顶层分组 */
  parentGroup?: string;
}
```

### `src/components/views/SettingsView.tsx` — ~80 行

- groups useMemo：按 `parentGroup` 合并，按 `section` 建两级树
- 左导航：有 section → 折叠箭头 + 子节点；无 section → 普通按钮
- 右面板：有 section → 大标题 + 小标题 + 仅当前 section 的项；无 section → 跟现在一样全部平铺
- 排序：外层 A-Z，内层 A-Z
- 修改蓝线、Tab ARIA、去 key、齿轮 focus-within

### `src/components/views/SettingsView.css` — ~15 行

- 两级树样式
- 修改蓝线
- 齿轮 focus-within + focus-visible

### `public/schemas/plugin.schema.json` — ~8 行

- property schema 加 `section`
- configuration schema 加 `parentGroup`

### `src/App.tsx` + 各 `plugin.json` — ~15 行

- 现有配置项按需补 `section` 和 `parentGroup`
