# 02-边界清单 —— 轻 Toast

> **为什么存在**：Toast 的失败几乎都发生在"文字太长 / 条数太多 / 位置撞车 / 读屏重复"这四类边界上。
> 本档逐条给**判据与结果**，实现与单测照此表；⛔ 出现表外行为即返工。
> **上游**：[01-API 与组件契约](01-API与组件契约.md)；**下游**：04 任务清单、设计图 05。

## A. 文本

| # | 边界 | 判据 | 结果 |
|---|---|---|---|
| B1 | 单行短文本 | 视觉宽度 ≤ 48 单位 | 一行显示，无省略号 |
| B2 | 两行文本 | 48 < 宽度 ≤ 96 | 两行显示（`line-clamp:2`），仍无省略号 |
| B3 | 超两行 | 宽度 > **96 单位** | **整条降级到面板**；⛔ 截断、⛔ 缩字号、⛔ 滚动 |
| B4 | 含显式换行 | `\n` 行数 > 2 | 降级面板（同 B3） |
| B5 | 中英混排 | 宽度按 **CJK=2 / 其他=1** 计 | 与 B1–B3 同尺 |
| B6 | emoji / 组合字符 | 记 2 单位 | 不得出现半截字符（不截断，自然满足） |

> 阈值 `TOAST_MAX_VISUAL_LEN = 96` 是常量，⛔ 散在组件里。

## B. 动作

| # | 边界 | 判据 | 结果 |
|---|---|---|---|
| B7 | 无动作 | — | 纯文案 + × |
| B8 | 1 个动作 | `action.title` 非空 | 文本按钮显示在文案右侧 |
| B9 | 动作过多 | > 1 | 降级面板 |
| B10 | 动作命令不存在 | `command` 未注册 | 点击**只关闭**（无副作用），⛔ 报错、⛔ 静默假装成功 |
| B11 | 动作点击后 | — | 关闭该条；同 key 后续仍可再弹 |

## C. 严重级与路由

| # | 边界 | 判据 | 结果 |
|---|---|---|---|
| B12 | `error` | severity=error | **一律面板**（需留存诊断） |
| B13 | 未知 severity | 非法值 | 按 `info` 处理并 console.warn（防御） |
| B14 | `ttl` 过大 | ≥ 8000ms | 降级面板（用户想"看一会儿"） |
| B15 | `ttl` 非法 | <1500 / >10000 / 负数 | 夹取到 [1500,10000]；NaN → 缺省 3000 |

## D. 队列

| # | 边界 | 判据 | 结果 |
|---|---|---|---|
| B16 | 同 key 连发 | key 相同 | **更新原条目**（文案/severity/动作），位置不变、TTL 重置；⛔ 新增节点 |
| B17 | 不同 key 第 4 条 | 栈已满 3 | 最旧的一条**立即退场**，新条目贴底 |
| B18 | 一次连发 10 条 | — | 只保留最后 3 条可见；中间的直接丢弃（不排队、不延迟弹出） |
| B19 | 条目正在退场 | 动画中又来同 key | 复用该条目（重新入场），⛔ 出现两条同 key |
| B20 | 插件卸载/重载 | 来源消失 | 其来源的 Toast **立即清除**（不让幽灵提示停留） |

## E. 交互与可访问性

| # | 边界 | 判据 | 结果 |
|---|---|---|---|
| B21 | hover 栈 | 指针在栈内 | **全栈暂停计时**；移出后继续剩余 TTL |
| B22 | 焦点进入 | Tab 到动作/× | 同样暂停；Esc 关闭当前条 |
| B23 | × 的占位 | 任意时刻 | **常驻固定宽度**，仅 opacity 0→1（⛔ hover 才占位——历史上把文字推走/弹回） |
| B24 | 拖选复制 | 用户按住选中文字 | 不得被打断；hover 变化不影响文本位置 |
| B25 | 读屏 | 新条目 | `role="status"` + `aria-live="polite"`；多条只播最新一条 |
| B26 | 与面板同事件 | 同 `taskKey` 两面都出现 | 屏幕阅读器**只播一次**（面板侧标 `aria-live="off"` 或去重） |
| B27 | reduced-motion | 系统设置 | 不做位移/缩放动画，仅透明度或无动画 |

## F. 位置与窗口

| # | 边界 | 判据 | 结果 |
|---|---|---|---|
| B28 | 默认位置 | — | **底部居中**，距状态栏 12px（读 `--statusbar-height`） |
| B29 | 窄窗 | 窗口宽 < 640px | 宽度 = `min(360, 100vw - 32px)`；仍居中 |
| B30 | 与铃铛面板 | 面板展开 | 水平不重叠（面板右下 / Toast 居中）；⛔ 同角落 |
| B31 | DPI / 缩放 | `--ui-scale` 变化 | 字号与间距按 scale 换算，不做像素硬编码 |
| B32 | 多显示器 / 窗口位移 | — | 跟随宿主窗口（`position:fixed` 于窗口层），⛔ 屏幕坐标 |
| B33 | 全屏浮层打开 | 模态/浮层 z-index 更高 | Toast 仍在最上层可见（层次：模态遮罩 < Toast < 系统级）——需在任务 T6 复核 |

## G. 生命周期

| # | 边界 | 判据 | 结果 |
|---|---|---|---|
| B34 | 应用最小化 | 窗口不可见 | **不弹系统通知**；Toast 计时继续，恢复时已过期的不再出现 |
| B35 | 应用失焦 | 非最小化 | 正常显示，不抢焦点 |
| B36 | 主题切换 | 亮/暗 | 两套 token 都过对比度（≥4.5:1 文本） |
| B37 | 多语言长词 | 德/俄等 | 按 B3 判定，超长降级面板（不挤压布局） |

## H. 禁止项（一眼判死）

1. ⛔ 新建第二个 store / 第二个队列 —— 必须复用 `toast.ts`。
2. ⛔ 组件名 `ToastHost` —— 用 `TransientToast`。
3. ⛔ 放右下角 —— 与铃铛面板重合即复现历史删除理由。
4. ⛔ 超长文本截断/缩字号/滚动 —— 只能降级面板。
5. ⛔ hover 才给 × 占位 —— 造成文字位移与拖选破坏。
6. ⛔ Toast 承载进度条 —— 进度只走面板。
7. ⛔ 在 Toast 内做业务判断（价格/权限/安装） —— 它只负责"显示一句话"。
