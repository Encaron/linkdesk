## 八、Phase 5：应用基础设施层 🔄

> 详细设计：[V3-Phase5-设计.md](../phase5_应用基础设施/V3-Phase5-设计.md)  
> 5g 深度分析：[V3-Phase5g-类型系统去硬编码-深度分析.md](../phase5_应用基础设施/V3-Phase5g-类型系统去硬编码-深度分析.md)

**当前进度：** 5a-5e ✅ 完成（48 commits，141 测试全过），5f 🔜 下一站。

**拆分 8 批（5a-5h）：**
- 5a-5e ✅：Registry 暗线 + 右键归一化 + 命令面板/齿轮 + when 条件 + 协议下拉框 + ConfigurationApplier
- **5f 🔜**：StorageService 归一化 + 删旧双写 + 终端专用通道拆除（10 项）
- **5g 📋**：类型系统去硬编码——TabType → string，声明驱动
- **5h 📋**：运行时动态加载——取代 `import.meta.glob`，安装无需刷新
- **5.5 📋**：viewRole 声明 + 终端侧栏控制面板

四个柱子 + 下半身 + 十一盲区：让插件"能做事情"而不只是"能加载"。5h 是最后一个改框架的 Phase——之后 5.5 是桥，Phase 6 是纯消费者。
