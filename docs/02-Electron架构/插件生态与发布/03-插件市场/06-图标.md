> 对应任务：E6#30e + E6#29c + E6#65/#66/#67 + E6#69（14 市场图标系统任务档案批次一/二/二·五 + 改向批）。
> 文档归属：市场设计文档族（[03-市场交互设计.md](03-市场交互设计.md) = 总览索引）。

## 三图模型（E6#69 改向——取代 #67「双图标 cover art」语义）

#69 拍板：`marketIcon` 不再是「cover art 场景封面」。**整幅场景封面不进市场展示位**，已画那批逐个挪进各
插件 README；市场与标签栏统一消费 **Type-2 彩色身份图**。三图各司其职：

| 图 | 语义 | 何处显 / 谁读 | 来源 |
|:--|:--|:--|:--|
| **Type-1 剪影线条**（单色 glyph） | 图标栏界面小图标（对标 VS Code/codicon） | 壳图标栏（只读 `icon`） | 仅图标栏 4 只插件（自备，意象从 codicon 取，不手画） |
| **Type-2 彩色身份图** | 插件在市场与标签栏的「脸」 | 市场侧栏行 + 详情顶显**同一张**；标签栏视图标签 | `marketIcon ?? icon ?? 统一默认彩色块`（共享 util `pickIdentityArt` 一处） |
| **整幅场景封面** | 一景画面，讲功能叙事/作者风格 | 各插件 README（不进市场位、不占展示字段） | 已画批逐枚嵌 README（#69b） |

**字段分工对第三方不可见**：图标栏与字段的「Type-1 剪影」是壳内部事——作者不用知道哪些插件上图标栏。
第三方最小契约 = 零图全链自动兜底，或一张 `icon` 全链自动（见下）。

## 字段机制（plugin.json 顶层，可选）

| 字段 | 语义 | 值 |
|:--|:--|:--|
| `icon` | 界面小图标。图标栏插件此位 = Type-1 剪影（壳图标栏只读）；非图标栏插件此位即 Type-2（标签/市场经裁决链复用） | codicon/lucide 名或包内 svg/png 资产相对路径 |
| `iconSource` | icon 来源 | `codicon` `lucide` `svg` `url`；省略按值推断（含 `.`/`/` → `linkdesk://{pluginId}/{路径}`；否则 codicon 名） |
| `marketIcon` | Type-2 身份彩色图——市场侧栏行/详情头与标签栏视图标签**同显此图** | 包内 svg 资产相对路径（省略 marketIconSource 按路径推断）；缺省 → 裁决回退 icon → 默认彩色块 |
| `marketIconSource` | marketIcon 来源 | 与 iconSource 同枚举；值走 svg 资产路径，source 省略按路径推断（显式 `svg` 会把路径当裸 URL，已装插件会裂——照省略惯例） |

> 🔴 **上面这是「作者在 plugin.json 里怎么写」。** 目录条目（`marketplace.json`）里的同名两对字段是
> **另一套形态**：`icon`/`marketIcon` 一律**绝对 URL** + `iconSource`/`marketIconSource = "url"`
> （publish 自动转，见下「两态两条路」）。两处形态不同不是不一致——它们服务两个不同的读图状态。

- **资产一律 svg**（14 定案 5）；lucide/codicon 只当小图标，不当身份图。颜色在 svg 内自含（字面量）。
- **壳零改动**：图标栏/标签栏只读已装 manifest——图标栏只读 `icon`；标签走共享 `pickIdentityArt`。
- **已装不读远程目录图标**——作者换图随版本更新获得（marketIcon 同此边界）；marketIcon 资产由 SDK
  packager 随 `.linkdesk-plugin` zip 同 icon 待遇拷进包，安装后从包内读。

## 两态两条路（E6#106 补齐——这条此前只有「已装」那半）

**同一个插件，市场行/详情头在两个状态下读的是两份不同的数据源。** 此前只做通了「已装」那半，于是出现
「市场里显白线剪影、装到本地显彩色身份图」= 同一插件两张脸（图标栏插件的 `icon` **按设计**就是 Type-1 剪影）。

| 状态 | 图源 | 形态 | 边界 |
|:--|:--|:--|:--|
| **已装** | 本地包内 `plugin.json`（经壳 `list()` / `getDisabled()` 数据通道） | 包内相对路径 → `linkdesk://<id>/resources/…` | 只从**包内**取；作者换图随版本更新获得；**断网可用** |
| **未装** | 目录条目 `marketplace.json`（官方源 / 作者源） | **绝对 URL + `iconSource:"url"`** | 目录是未装态的**唯一**图源，故必须是 URL——包内路径在未装态恒 404 |

**发布侧铁律（`publish` 自动做，作者零声明）**：SDK publish 会把 `icon` / `marketIcon` 从「包内相对路径」
转成 `https://raw.githubusercontent.com/{owner}/{repo}/v{version}/{路径}`（与 `readmeUrl` 同 tag 同形态）。
三档：作者自填 http(s) URL → 原样留＋补 `iconSource:"url"`；包内路径 → URL 化 + 标 `"url"`；`lucide`/`codicon`
名 → 原样留（消费端白名单/codicon 字体渲染）。**不转 = 未装用户看不到图**。

**消费侧裁决序（四个位统一，禁各写一份）**：`已装 manifest → 目录条目 → 默认彩色块`（共享
`pickIdentityArt`，候选按序）。已装优先**不是美化而是硬边界**：目录条目的图是 URL 形态，已装行若只读目录
就会去拉远程图——破「已装不读远程目录图标」，且**断网即裂图**。

**机械兜底**：插件仓 CI 第 ⑤ 段（`scripts/ci-verify.mjs`）断言目录条目里出现的图标字段必须是绝对 URL +
来源标 `"url"`——**纯字段形态断言，不看插件类型、零插件 ID 知识**（硬约束 10）。

## 标签栏图标（#69f 视图标签 / #69g 文件标签——两域分开管理）

| 标签类型 | 判据（数据/声明字段，禁 pluginId 硬编码） | 显示 | 受 `iconTheme` 影响？ |
|:--|:--|:--|:--|
| **视图标签**（editor 开的插件视图等） | 非文件型（无文件路径字段） | 所属插件 Type-2（`pickIdentityArt`）——无 icon 插件不再 📄 | 否（插件身份图，另一套） |
| **文件标签**（editor 开 .c/.h/.py…） | 标签携文件路径（tab.filePath 数据字段） | **文件类型图标，与文件树同一套**（共享 FileIconResolver） | **是**——切 `app.iconTheme` 即时整批变，不要求重开标签 |

**文件类型图归一化铁律**（#69g）：数据 + 解析 = **共享图标服务一处** src/components/shared/file-icon/
（`FileIconResolver` + 默认表单份）——file-tree 行 / 壳文件标签 / 搜索行同消费；禁编辑器跨插件
import file-tree 或复制一份（= 双源）。**同信号实时**：文件标签与文件树消费同一 `iconTheme:changed`
（appearance.ts:223 广播）→ 重算；插件身份彩色图 / 图标栏小图不受 iconTheme 影响（另一套）。
**可拓展**：作者可**声明式贡献**新文件类型图标 / 整套图标主题（对标 VS Code fileIconThemes），
编辑类第三方插件经 `linkdesk.*` 读 API 渲染与树一致的标签图（additive，禁改中央表）。

## 第三方作者最小契约（#69h）

1. **零图可发**：不配 icon/marketIcon → 市场与标签全链自动落统一默认彩色块。够用即可上架。
2. **一张 `icon` 全链自动**：非图标栏插件填 `icon`（svg 资产或 codicon/lucide 名）→ 市场侧栏行 +
   详情顶 + 标签栏视图标签全显它（裁决链自动复用，声明源省略按值推断）。
3. **可选升级**：想要更讲究的彩色身份图 → 另加 `marketIcon`（svg 相对路径）。不必关心「是不是图标栏
   插件」——Type-1 剪影分工是壳内部事。
4. **文件标签无需作者配**：编辑器标签的文件类型图标由图标主题服务按文件名/扩展提供，作者不配字段
   （如需自定义整套文件图标主题 → 走 file-icon 贡献面，additive）。
