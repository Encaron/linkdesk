> **类型：壳级别** — 壳内通用组件（`src/components/shared/ColorPicker.tsx`），随壳版本发布。被设置页、主题制作器等多处消费。
> **状态：🔥 第四优先——UI 基础设施，设置页强调色、主题制作器全等着它**
> 替换所有手打 hex 的地方。VS Code 有 ColorPicker，LinkDesk 也要有。

---

## 基本逻辑

一个标准的取色器组件——饱和度/亮度面板 + 色相条 + hex 输入框 + 最近使用色块。点击任意触发色块 → 弹出 ColorPicker 悬浮在该色块旁边 → 选颜色 → 确认。

**核心原则：** 不发明新交互——对标 VS Code 的 ColorPicker 行为。工程师用户不需要学习新 UI。

---

## 处于软件内位置

```
设置页 → 强调色行 → 点击色块 → ColorPicker 弹出
主题制作器 → 任意色键 → 点击色块 → ColorPicker 弹出
未来：任何插件 → import { ColorPicker } from '@linkdesk/core' → 直接用
```

**UI 层级：** Popover 层（相对于触发元素定位，不是 Modal）

## 关键交互

| 交互 | 触发 | 行为 |
|------|------|------|
| **打开** | 点击色块 | Popover 弹出在触发元素旁边（自动计算位置，不超出窗口） |
| **选饱和度/亮度** | 在面板中点击/拖拽 | 圆点跟随，实时更新颜色 |
| **选色相** | 拖拽色相条滑块 | 面板颜色矩阵随之更新，实时预览 |
| **输入 hex** | 在输入框输入 | 面板和色相条跳到对应颜色 |
| **最近使用** | 点击色块 | 快速切换为该颜色 |
| **确认** | 点 ✓ / Enter | 触发 `onChange(color)` → 关闭 |
| **取消** | 点取消 / Esc / 点外部 | 恢复原色 → 关闭 |
| **关闭** | 点 Popover 外部 | 同取消 |

### Props 接口

```typescript
interface ColorPickerProps {
  color: string;              // 当前颜色 hex (如 "#FF6B8A")
  onChange: (color: string) => void;  // 确认时回调
  onCancel?: () => void;      // 取消时回调
  recentColors?: string[];    // 最近使用的颜色（最多 8 个）
  triggerRef: React.RefObject<HTMLElement>;  // 定位参照
}
```
