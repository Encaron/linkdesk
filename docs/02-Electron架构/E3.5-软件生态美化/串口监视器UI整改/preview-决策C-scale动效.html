决策 C：transform: scale() 动效

hover 每个按钮观察差异——方案 A 有 scale 放大，方案 B 用 box-shadow 替代

| hover 下方按钮对比两个方案

工具栏按钮

方案 A — 有 scale(1.02)/scale(0.97)
方案 B — 无 scale，box-shadow 光晕

方案 A 的问题：hover 时按钮放大 2%，推动相邻按钮产生抖动。方案 B 仅改变背景色 + 边缘光晕，零位移。

AT READ STATUS VERSION RESET
方案 B — 无 scale
AT READ STATUS VERSION RESET

方案 A 在 pill 多的场景下，hover 放大 + flex-wrap 会导致后面的 pill 跳到下一行。

发送按钮

方案 A — scale(1.02)/scale(0.96)
方案 B — 无 scale，亮度变化
