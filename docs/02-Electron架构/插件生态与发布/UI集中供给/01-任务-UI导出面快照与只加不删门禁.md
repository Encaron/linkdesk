> **为什么它是第一格**：集中化把 `@linkdesk/ui` 的每个导出名变成终身承诺（插件不再自带拷贝，运行时只有壳那一版）——**闸必须先于通道立起来**。L8 的 `check-api-surface-additive.mjs` + `host-api-surface.json` 已为壳面立过同款，本格照抄形状。

## 一、改动点（全部在壳仓 `scripts/` + `package.json`，零 `src/`）

1. **新建 `scripts/gen-ui-surface.mjs`**：
   - 输入 = `packages/linkdesk-ui/src/index.ts`（barrel，**导出面唯一真相源**，头注释已写明）。导出行是规整的 `export { default as X } from "@shared/..."` + `export type {...}`——正则逐行提取即可，⛔ 不引 AST 依赖（照 `gen-api-surface.mjs` 的朴素风格）。
   - 输出 = `scripts/ui-surface.json`：`{ "generatedAt", "components": [...], "types": [...], "helpers": ["inferSliderStep"], "count" }`。
2. **新建 `scripts/check-ui-surface-additive.mjs`**：
   - 与 HEAD 的 `ui-surface.json` diff：**只许新增、不许删除/改名**；缺项判红，报文给出「退役走退役登记 + 钉线窗口」的指引（照 `check-api-surface-additive` 的红报文口径）。
   - `--self-test` 自测（临时目录造两个快照断言增/删两向）——照本仓门禁脚本的自测惯例，进 check 链。
3. **挂链**：`package.json` 的 `check` 串在 `check-api-surface-additive` 之后插两段（`gen-ui-surface --check` 不需要——快照更新是人工动作 + 审查，⛔ 不自动重写快照）：
   `node scripts/check-ui-surface-additive.mjs --self-test && node scripts/check-ui-surface-additive.mjs`
4. **基线**：首跑生成当前快照（17 组件 + inferSliderStep + 4 类型，见 barrel 头注释 54c/120 锚点），`count` 与 barrel 头注释的导出计数一致才许提交——两处数字互为对账。

## 二、验收

- `npm run check` 全绿（新门禁进链）。
- 手工红测一次：临时从 barrel 删一个导出 → 门禁红且报文可导航 → 恢复。
