### ⑴ 第七层是干什么的

**壳与插件源码从此分家。** 插件源码搬进各自独立的 GitHub 仓库，壳仓只留两样：**构建产物**（`bundled-plugins/<id>.linkdesk-plugin`）＋ **文档档案**。出厂套装靠「打包时拉各插件最新已发布版」随包（D3 构建期拉取），不再靠源码住在壳里。真正要解的痛点是**「没上架」**——用户不敢卸载任何插件，根因是卸了没处拿回来；解药 = 每只插件有自己的仓 + 上架两步（publish 只是半程，官方目录收录才默认可见）。现状实测与全部决策住 [00-整理档案.md](00-整理档案.md)；执行序（用户 2026-09-14 拍板）= L5 剩余做完紧接着做 L7、L4/L6 跳过——**L4/L5 已双双封站（2026-09-14），本层是 E6 当前唯一在跑的层**（L6 安全加固与出厂判定排在本层之后）。
