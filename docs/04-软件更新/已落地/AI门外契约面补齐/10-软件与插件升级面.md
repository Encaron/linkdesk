## 二、contracts 与 SDK 的先后（⛔ 倒序会炸）

```
contracts（类型真源） → 壳实现 → SDK（透传/类型） → 插件 → 文档/手册
```

- `contracts` 是**唯一定义**；壳与 SDK 都从它取类型。
- SDK 的 `dist` 是构建产物、dev 轨道直接解析它 ⇒ 改完 SDK 必须重建，否则 dev 里看不到。
- 插件仓各自独立构建（R7 自足）；⛔ 插件直接 import 壳内部。

## 四、其他官方插件

| 插件 | 要动的点 | 说明 |
|:--|:--|:--|
| **file-tree** | 视图态候选（`openFocused`/`rename`/`delete`/`paste`/`collapseAll`/`selectForCompare`/`compareWithSelected`/`removeFolder` 等；后三条运行期注册、`contributes.commands` 未声明，T9/T12 补声明；以 A 的 T5–T8 运行期判定为准）补 `activation`；补 `risk`/`returns`/`example` | doctor 的**跨领域**验收对象（T24） |
| **editor / 编辑器** | 同上；`save` 类写操作 `risk ≥ 1` | 非硬件领域验证 |
| **settings（设置插件）** | 含 `factoryRole:"settings"`；动作命令补 `risk`（改配置 = R2） | 与权限系统 W4 同批 |
| **marketplace** | 运行期注册的 `enable`/`disable`/`uninstall`/`retryInstall`/`retryUpdate` 补进 `contributes.commands`：`uninstall`/`retryInstall`/`retryUpdate`=R3（对齐旧壳表），`enable`/`disable`=R2；补所有描述字段 | 与权限系统安装弹窗相关 |
| **其他各仓** | 统一三件：`activation` / `risk` / `returns+example` | 体量按命令数 |

**批量做法**：先在**一个仓**跑通（建议 file-tree，最贴近非硬件），再逐仓复制；⛔ 一次全改，否则红点分不清。
