## 二、视觉层——逐项差距

### 2.1 快捷键显示 🔴 数据已就绪，代码未接线

| | VS Code | LinkDesk |
|------|---------|----------|
| 快捷键 | 每行右侧显示，keycap 样式 | **渲染代码存在但数据永远 `undefined`** |

**代码证据：**

```tsx
// ContextMenu.tsx:79-80
shortcut: undefined,  // 快捷键暂时不显示——KeybindingRegistry 的 resolve 逻辑留 Phase 5c
```

```tsx
// ContextMenu.tsx:233-235 — 渲染代码已存在！
{item.shortcut && (
  <span className="ctx-item-shortcut">{item.shortcut}</span>
)}
```

```css
/* ContextMenu.css:56-67 — 快捷键样式已存在！ */
.ctx-item-shortcut { ... }
.ctx-item:hover .ctx-item-shortcut { ... }
```

**现状：** TSX 模板、CSS、`ResolvedItem.shortcut` 字段**全部就绪**，只差填充数据。
**所需修改：** 在 `resolved` useMemo 里加一行 `findKeybindingForCommand(item.command)?.key`。

**影响：** 这是本专题最大收益项——右键菜单配快捷键是最常见的"学习快捷键"路径。给 Ctrl+W 标上 `Ctrl+W`、给 F5 标上 `F5`，用户不再需要去快捷键设置页记忆。

### 2.2 菜单项图标

> **Encaron 决策：不加。** 右键菜单保持文字为主的简洁风格，不引入图标增加视觉噪音。

### 2.3 开合动画 🟡

| | VS Code | LinkDesk |
|------|---------|----------|
| 出现 | scale(0.95→1) + opacity 过渡 ~100ms | 瞬间出现 |
| 消失 | 同上反向 | 瞬间消失 |

**同命令面板**——相同的动画方案可以直接复用（scale+opacity transition）。区别是右键菜单是 `position: fixed` 在点击位置，不是居中，transform-origin 需要跟随菜单位置。

### 2.4 无 submenu 支持 🟡

| | VS Code | LinkDesk |
|------|---------|----------|
| 嵌套子菜单 | ▶ 箭头展开子菜单 | ContextMenu 忽略 `children` 字段 |

`MenuItem` 类型已有 `children?: MenuItem[]` 字段（E3f #52a 加的），但 ContextMenu 不处理它。MenuBar 通过 `MenuRenderer` 支持嵌套，ContextMenu 没有。

**影响：** 图标栏齿轮菜单如果复杂起来可能需要（例如"更多操作 ▶"）。当前所有 ContextMenu 注册点都是平级的，暂无需求。**这个先不改，等有实际需求时再动。**

### 2.5 checked/toggle 状态 🟢

VS Code 支持 checkbox/radio 样式的菜单项（如 View > Appearance > Status Bar ✓）。`MenuItem` 无此字段，LinkDesk 暂无此需求。不改。

## 三、死代码/小瑕疵

### 3.1 `.ctx-backdrop` 🟢 死 CSS

```css
/* ContextMenu.css:11-16 */
.ctx-backdrop {
  position: fixed; inset: 0;
  z-index: var(--z-overlay-backdrop);
}
```

任何组件都不引用 `ctx-backdrop`——这是 Phase 5b 最初设计时的残留。组件用的是 `window mousedown capture` 而非 backdrop div（见 ContextMenu.tsx:106-115 的注释解释原因）。**删。**

### 3.2 分隔符 margin 🟢

```css
.ctx-divider { margin: 4px 8px; }
```

左右 8px margin 对全宽分隔符无意义——分隔符已经是 100% 宽度，左 8px 只让分隔符端点凹进去。VS Code 的分隔符也是全宽。改 `margin: 4px 0` 更干净（或者保留 8px 视觉效果也行——不影响功能）。

### 3.3 快捷键字体硬编码 🟢

```css
.ctx-item-shortcut {
  font-family: 'Sarasa Mono SC', Consolas, 'Courier New', monospace;
}
```

硬编码字体。应该走 CSS 变量 `var(--font-mono)`。但 LinkDesk 的 `--font-mono` 可能未在 index.css 定义——需确认。
