# 01 · 机械门禁（挂 `npm run check`）

> 判据：**插件不得持有宿主语义**——路径、域名字符串、配置键特判、系统调用。
> 官方（FACTS 15 仓）error；第三方 warn（不阻断作者，照既有范围策略）。

---

## 一、新增腿 `check-plugin-host-knowledge.mjs`

| # | 判据 | 级别 | 怎么查 | 负控样本 |
|:--|:--|:--|:--|:--|
| **K1** | 插件不得拼宿主路径 | error（官方）/ warn（第三方） | 源码出现 `appData` / `userData` / `%APPDATA%` / `AppData/Roaming` / `linkdesk/appearance` 等拼接 | 在 settings 里拼 `join(appData,"appearance")` ⇒ 红 |
| **K2** | 插件不得持有宿主域名字符串 | error（官方） | 出现 `defaultPathKind` 或 `"appearance"` 作为**域/目录语义**（排除测试与文案） | `defaultPathKind:"appearance"` ⇒ 红 |
| **K3** | 设置插件不得特判宿主配置键 | error ＋ 豁免账本 | `app.` 字面量只许出现在「声明驱动」的通用文件（账本登记）；新增特判 ⇒ 红 | `if (key==="app.themeColor")` ⇒ 红（已在既有代码，先登记豁免再迁） |
| **K4** | 插件不得直调系统能力 | error | `shell.openPath` / `dialog.showOpenDialog` / `child_process` 出现在插件 | 插件自己开目录 ⇒ 红 |
| **K5** | 新宿主动作必须有命令＋手册 | error | `appearance.pickImage` 等新命令缺 `description`/AI 手册 ⇒ 红 | 复用 `check-manual-surface` |
| **K6** | 共享件不得反向持有宿主知识 | error | `@linkdesk/ui` 的 `image-picker` 不出现路径/域字符串 | 组件里写 `appearance` ⇒ 红 |
| **K7** | 插件不得重复实现路径工具 | error（官方） | 插件源码定义/使用本地 `basename/dirname/extname/joinPath`（壳 `linkdesk.path.*` 已覆盖） | file-tree `pathUtils.ts:28-72` 存量 → 先登记豁免再迁；新增 ⇒ 红 |
| **K8** | 插件不得跨命名空间读宿主 `pluginState` | error | 插件里出现 `pluginState.get("app"` / `onChange("app"` | file-tree `useRecentFolders.ts:59` ⇒ 红（迁移后销账） |
| **K9** | 插件不得自拼资产协议 URL | error | 出现 `` `linkdesk://${…}` `` 构造 | marketplace `useDetailPackage.ts:41` ⇒ 红（改用壳 API） |
| **K10** | 插件不得自认宿主文件名 | error（官方） | 出现 `"settings.json"` / `"plugin.json"` 作为**落盘/解析**知识 | settings `SettingsView.tsx:216` ⇒ 红（壳补 API） |

> K3 的账本：`scripts/host-knowledge-exempt.json`（`repo/file/reason/owner/until`）；**过期 = error**。
> 目的不是一次清零存量，而是**新增即拦 + 存量逐个迁**。

## 二、扩展既有腿

| 腿 | 扩展 |
|:--|:--|
| `check-shared-components-zero-shell-deps.mjs`（R6） | 新 `image-picker` 若进 barrel，立即进红区；受控组件不得调 `window.linkdesk` |
| `check-single-implementation.mjs` | 「选图」只能一个共享件（`BackgroundImagePicker`），插件内不得再造 |
| `check-size-tokens` / `check-token-boundary` | 新控件照旧零裸 px / 零 hex |
| `check-ai-surface` | `appearance.pickImage` 必须登记风险（任务 A 的风险表） |

---

## 三、自测

- K1/K2/K4 各一条合成样本（正控/负控）；
- K3 账本：登记条过期 ⇒ 红；新特判 ⇒ 红；
- K5：命令缺手册 ⇒ 红；
- 路径：`official/` 下但不在 FACTS 的仓（如 `geme-tihu-bicycle`）按第三方 warn——**官方名单只认 FACTS**（既有教训）。

## 四、人工评审（门禁抓不住的）

| 问句 | 判据 |
|:--|:--|
| 这条默认值/路径/域，换掉 UI 插件后还在吗？ | 不在 ⇒ 上移 |
| 第三方 UI 不看源码能否做对？ | 不能 ⇒ 补声明 |
| 这是「长什么样」还是「是什么」？ | 长相留插件，语义归壳 |
