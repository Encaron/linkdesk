## 三、推荐（带理由，供拍板参考）

**推荐：B 为底 ＋ 混搭 D 的「完成态彩粒迸发」一个点。**

- **B 当主**：品牌辨识度与气质匹配双满分——安装器与壳内启动过场（暗色、光、玻璃）连成一条品牌线，这正是「提高产品辨识度」的本意；耐看度和成本也在安全区。
- **只借 D 一个点**：完成态彩粒迸发是 D 全场最佳的单点动效，且恰好补 B 的短板——B 的完成屏（光晕对勾）偏静，装完那一刻值得一次性的庆祝；迸发落在深色玻璃上视觉也成立。**动效预算集中打一次**（D 自己的设计哲学「一张牌打一次」搬过来正合适）。
- **A 的价值**：不必整套落选——A 的暖纸白正好是**明色主题 token 的现成参照**（01 §六明暗双主题，A = 明、B = 暗，两套 token 各有出处），实现时直接参考。

**备选口径**：若拍板时想要「最安静高级」，纯 B 也完全站得住（445 分里没有依赖混搭的分数）；若想要「极简耐看优先」，A 是第二名且成本最低。D 整套不推荐单独选——耐看度与成本两项风险最大。

## 四、混搭点单格式（选任何组合照这个说）

按三个「槽位」＋主题底点单，例如：

- 完整说法：**「主题底 = B（暗玻璃）；完成槽 = D 彩粒迸发；进度槽 = B 辉光流光（默认）；明色主题参照 A」**
- 最简说法：**「B ＋ D 的彩粒」**

| 槽位 | A 提供 | B 提供 | D 提供 |
|:--|:--|:--|:--|
| 主题底（全局 token） | 暖纸白编辑部 | 深空玻璃＋光球（**推荐**） | 渐变网底 |
| 首帧/主屏 | 衬线斜体大标题 | 玻璃双包边＋药丸按钮 | 超大双色字 |
| 进度槽 | 2px 细线＋衬线大数字 | 辉光流光胶囊条（**推荐**） | 108px 计数器＋弹簧条 |
| 完成槽 | 描线对勾（最静） | 光晕圆环 | 彩粒迸发（**推荐混搭项**） |

**混搭纪律**：一次混搭最多动两个槽（主题底算一个）；跨风格 token 不混用（A 的衬线不进 B 的玻璃底），收口时由定稿款统一成一份 token 表。
