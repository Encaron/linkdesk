## 容器（2026-08-29 落位更新）

**落位 = 市场插件的一个主区标签页**（`contributes.views location:"main"` 声明，宽屏）——标签页 = 通用表面容器：右键「在悬浮面板中打开」（声明 `floatingPanel.viewId`）→ 浮出面板；拖出 → 独立窗口（E5.8#44）。**容器层不再设计独立宿主。** 早期「FloatingPanel 类型 B」为 2026-07-28 旧设计，已被标签页落位取代（视觉规格仍见 [01-UI布局规格](01-UI布局规格.md)）。

> 🔴 **2026-10-05 补充（落地机制）**：大屏商店**改走本插件既有的 `entry` 页**（`tab type` = 插件 id）——它与上面那句「主区标签页」的**表面形态完全一致**（主区 / 宽屏 / 标签页容器全免费），差别只在**声明机制**：不新增主区 view id，因而**零壳改动**。若将来要「落地页与商店并存」或要开第二个主区表面，再回到 `location:"main"` 那条并接受那处壳改动。理由与逐条差异见 [04-大屏商店落地方案](04-大屏商店落地方案.md) §六。
