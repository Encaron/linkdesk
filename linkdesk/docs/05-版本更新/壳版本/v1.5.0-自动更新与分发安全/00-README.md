# v1.5.0 — 自动更新 + 分发安全

> **类型：壳级别** | 前置：v1.4.x 最新 PATCH

---

## 做什么

LinkDesk 架构安全已经和 VS Code 同级——插件攻不进来、崩不扩散。但**分发信任还是零**——没有签名、没有 HTTPS、没有自动更新。这一版补上。

---

## 三件事

### 1. 代码签名

| 项 | 说明 |
|------|------|
| 问题 | 用户下载 exe → Windows SmartScreen 弹红色警告——"此文件可能不安全" |
| 方案 | EV 代码签名证书（~$300-500/年）→ SmartScreen 秒过 |
| 退路 | 走 Microsoft Store 分发——微软自动签名，免费 |

### 2. HTTPS 下载 + 自动更新

| 项 | 说明 |
|------|------|
| 问题 | HTTP 下载 → 中间人可篡改安装包 |
| 方案 | Let's Encrypt 免费证书 + `electron-updater` 后台下载 + 重启安装 |
| 体验 | 右下角通知"新版本 v1.5.1 已下载，重启安装？" |

### 3. 插件市场审核

| 项 | 说明 |
|------|------|
| 问题 | 用户上传的插件——有没有恶意代码？ |
| 方案 | 初期人工审核（插件少）。后期自动化——扫描 `require`/`fs`/`child_process` 等危险调用 |
| 不过度 | 不学 Apple 的严格审核——LinkDesk 插件有进程隔离，恶意插件也攻不进来 |
