# 安装界面自绘（NSIS 默认向导 → 自绘安装体验）

> **状态：✅ 已拍板立项（2026-10-01）**——设计定稿 **E 混合提案**；技术路线 **T3-b Bootstrapper**；勾选项 = E6#45 四项原样搬（不加自启）；默认路径 `%LocalAppData%\Programs\linkdesk`。已进 04 §三已立项表，按攒批节奏开工（实现拆单见 [01-技术方案.md](01-技术方案.md) §四）。
> 缘起（2026-10-01）：现安装包（`electron-builder` NSIS · `oneClick:false`）弹的是**经典安装向导**，用户希望换成自绘 UI（动画 / 粒子 / 进度条 / 品牌首帧），对标微信 / 钉钉式安装体验。讨论沿革见本会话（04 归属已由目录结构确认：打包态才见效的壳侧体验件，与「程序图标」「启动过场」同族）。
>
> **为什么做（目的，2026-10-01 用户立意）**：**提高产品辨识度**——安装窗口是用户双击安装包后接触产品的**第一个画面**（比启动过场还早），现在这个画面是 NSIS 的默认脸，认不出是 LinkDesk；自绘后品牌语言从第一眼贯穿到每一天。连带三个收益：① 解压等待的几十秒变成品牌展示位，而不是空白向导；② 安装体验与大厂软件（微信/钉钉）看齐，第一印象不掉档；③ 安装器自带语言选择（中/英起步、可扩展），安装体验本身就是产品力的一部分。

## 一、这是什么 / 不是什么

- **是**：双击 `linkdesk-setup-x.y.z.exe` 后弹出的那个**安装窗口本体**的视觉与交互（安装器，installer），不是「先下小下载器再拉包」的下载器（downloader）。
- **不是**：壳内 UI——安装期壳进程还没运行，此面完全在壳外（NSIS / 引导器窗口），`src/` 零参与。
- **UAC 弹窗除外**：双击后的提权弹窗是 Windows 系统绘制的，**任何软件都自绘不了它**；能优化的只有 exe 元数据（图标 / 文件描述 / 发布者名——发布者名要代码签名证书，当前未签名会显示「未知发布者」，如实记录）。
