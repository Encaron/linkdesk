# 01-Theme Carousel（主题轮播）

> **类型：壳级别** — 替换壳内 ThemeBrowser，改核心 UI，随壳版本发布。
> **状态：🔥 第一优先——马上能做，效果立竿见影**
> 把 VS Code 的文字列表主题选择 → 变成缩略图卡片画廊。hover 即时预览，碾压级体验差。

---

## 基本逻辑

替代现有的 ThemeBrowser（QuickPick 文字列表），变成卡片式主题画廊。每个主题一张 150px 缩略图卡片，鼠标 hover = 即时 apply 主题预览（全窗口变色），click = 确认选择。

核心创新：**hover 预览**——VS Code 做不到。鼠标扫过哪张卡片，整个 LinkDesk 外观立刻切换为该主题。松开鼠标恢复原主题。

---

## 处于软件内位置

```
设置齿轮 → 主题 → 颜色主题 → Theme Carousel
命令面板 → "颜色主题" → Theme Carousel
```

**触发入口：**
1. 左下角齿轮菜单 → "主题" → "颜色主题"
2. 命令面板 (`Ctrl+K Ctrl+T` 对标 VS Code)
3. 设置页面内"颜色主题"行 → 点击 → 弹出 Carousel

**UI 层级：** Modal 层（覆盖在主窗口上方，带遮罩）

## 关键交互

| 交互 | 触发 | 行为 |
|------|------|------|
| **hover 预览** | 鼠标进入卡片 | 整个 LinkDesk 切换为该主题（即时，无动画延迟）。鼠标移出 → 恢复 |
| **click 确认** | 点击卡片 | 卡片放大 → 收拢动画（200ms），主题确认应用，关闭 Carousel |
| **横向滚动** | 触控板/鼠标滚轮 | `scroll-snap-type: x mandatory`，滚动到下一组卡片 |
| **左右箭头** | 点击 ← / → | 滚动一组（3-4 张卡片距离），带 `scroll-behavior: smooth` |
| **键盘导航** | ← → 方向键 | 移动焦点框到相邻卡片，焦点卡片自动 hover 预览 |
| **Esc 关闭** | Esc 键 | 恢复原主题，关闭 Carousel |
| **底部入口** | 点击"制作你自己的主题" | 关闭 Carousel → 打开 Theme Maker（#07） |
