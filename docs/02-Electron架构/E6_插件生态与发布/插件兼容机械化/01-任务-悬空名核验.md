> **编号**：`E6#114` ｜ **轮次**：第 8.1 轮 ｜ **队列位置**：**第 1 棒（共 6 棒）**
> **前置**：无硬前置（与格 2 互不依赖，可换序）｜ **提交轴**：壳仓 `scripts/` ＋ `package.json`（挂 npm script）＋ 文档

> **非新能力声明**（`check-design-flow` §8.4 ③）：本格产出的是**一把只读的维护者尺子**（跑给人看，不进 `npm run check`、不判红、不改产品行为、不给插件作者新 API）⇒ **无需新能力设计前置**。

### 8.2 宿主定义集口径（**本格的裁，别再推倒重来**）

**① 算宿主定义集的（三类，机械可数）**：

1. **壳自己的 CSS** = `src/**/*.css` —— **35 个文件**（含**共享组件单一源码 16 个**：`src/components/shared/**/*.css`）。⚠️ **共享组件不在别的包里**：`packages/linkdesk-ui/src/` 只有一支 `index.ts` 再导出，组件本体就住 `src/components/shared/**`（`@linkdesk/ui` 的 `dist/` 由 [scripts/build-linkdesk-ui.mjs](../../../../scripts/build-linkdesk-ui.mjs) 从**这里**构建）⇒ **一份源码、一个口径**。
2. **宿主加载的第三方 CSS**：由 `src/**/*.{ts,tsx,css}` 里的**非相对路径 `@import` / `import`** 机械解析到 `node_modules` ⇒ 今天只有 **1 个**：`node_modules/@vscode/codicons/dist/codicon.css`（**651 个 `codicon-*` 类名**）。这是「第三方自洽不假红」的第二道保险。解析不到的引用**不静默吞**（表里另打一行 ⚠️，今天为 0）。

**③ 判定式（三句话，也是脚本头注的原话）**：

1. **产物喊的名字** = ① `*.bundle.js` 里 `className="x"` / `class="x"` **代码上下文**的字面量（含 `className={"a b"}`；**含插值的模板一律跳过并计数**）＋ `classList.add/remove/toggle/contains("x")` ＋ `querySelector*` / `closest` / `matches` 的**字面量选择器实参**里的类名 ＋ ② 包内 `*.bundle.css` 选择器里出现的类名（**只计数**，见下）＋ ③ 包内 CSS `animation:` 引用的关键帧名。
2. **两个定义集** = **自身**（产物包内 CSS 的定义 ＋ `@keyframes`）／ **宿主**（上面 ①②③）。
3. **悬空 =「产物 JS 喊的 `ldk-*` 名」或「`animation:` 引用的关键帧名」，两个定义集里都没有。**

**④ 🔴 为什么只判 `ldk-*`（本格最要紧的一条裁，也是误报控的根）**：

- **宿主今天的类名面就是 `ldk-*`**（实测：壳 348 个裸定义**全部**是 `ldk-*`，非 `ldk-` = 0）；而**插件结构上不许定义 `ldk-*`**（硬约束 23，`pluginId` 也不许 `ldk-` 开头）⇒「某只产物喊了一个 `ldk-*` 名，它自己不可能满足、宿主今天也没有」**就是**一条真悬空，**不需要任何白名单**。
- **非 `ldk-` 的未定义名只计数、不判**：那里住着 Monaco / VS Code / CodeMirror / `codicon-*` / 插件自己的 DOM 钩子 / 别名表伪名——**假红比漏报更坏**（判据③），而它们**全不是宿主契约**。
- ⚠️ **CSS 选择器里提及的类名同理不判**：`.monaco-workbench .action-label{}` 是**第三方包自己的作用域调优**，包内 CSS **自带**规则 ⇒ 读成「悬空」就重犯 v1 的错（那一版误报 **2145** 处，其中 editor 一只就 ~1029 处 Monaco 名——所以必须有 JS 词法 ＋ 收窄射程）。

**⑤ 🔴 宿主类名定义集「怎么生成、怎么随包下发」——口径写死，交付给格 4 拍（本格只写口径，不建清单）**：

- **生成口径必须与上面 ① 同源**（⛔ 不许另写一把尺子）：扫 `src/**/*.css` ＋ 宿主 `import` 的第三方 CSS ⇒ 用 `scripts/lib/css-selectors.mjs` 的 `bareClassDefinitions` 取**裸定义** ⇒ `classes: string[]`；保留关键帧取 `reserved-class-names.json`（8 条）⇒ `keyframes: string[]`。
- **形态二选一（格 4 拍板）**：**(a) 构建期生成、随包下发**（一个 `host-class-surface.json`，随版本提交，运行时读它）／**(b) 运行时读自己构建出来的 CSS**（壳手里**没有源码**）。今天下发的账里**没有类名栏**（`reserved-class-names.json` 只剩 8 条关键帧、`host-reserved.json` 无类名栏）⇒ **格 4 要先解决「壳手里哪来的类名清单」，再谈读数**。
- ⚠️ **它不是白名单**：它是**定义集**（「今天有什么」），是只加不删的**面**，不是「谁被允许引用」的许可表（红线段②：不引白名单 / 棘轮）。
- ⚠️ **集合语义**：排序后写入（只改顺序 / 注释不产生 diff）＋ **必须与格 2 面快照第 ③ 栏（宿主 `ldk-*` 类名 ＋ 保留关键帧）共用同一个生成器**——否则两处读数互相打架，那正是本系列花了十格在还的债。
