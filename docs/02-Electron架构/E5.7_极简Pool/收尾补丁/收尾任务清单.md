  - 验收：实机 3 连崩出错误页 → 点重试 → 池重建恢复（非无限循环）；重试后再崩仍落回错误页

  - ✅ **用户实机验收通过 2026-08-16**（3 连崩出错误页 → 点重试 → 池重建恢复；恢复后立刻再崩落回错误页——熔断计数保留）。
