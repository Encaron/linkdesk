# 09-命令面（Ctrl+Shift+P 里出现的主题命令）

> **状态：** 提案（2026-08-23 起草）——主题换血后命令面该有什么。
> **一句话：** 主题相关命令从「一个选择器」升级为「选择/配色/复位」三件套；全部走壳 ensureCoreCommands（App 启动注册），标题走 t()（硬约束 2）。

## 1. 命令清单

| 命令 | 标题（i18n key = 中文原文） | 行为 | 状态 |
|:--|:--|:--|:--|
| `theme.pick` | 主题：选择主题… | **两段式 QuickPick**：①选配方（卡片/列表）→ ②该配方有多配色再选配色变体；Enter 应用，Esc 取消 | 升级现有 showThemePicker |
| `theme.pickColorway` | 主题：应用配色变体… | 直接跳配色 QuickPick（活动配方 colorways）；无多配色时置灰 | 新增（可并入上一命令，待拍板） |
| `theme.resetAppearance` | 外观：复位外观覆盖… | `app.appearanceMode→followTheme` + 6 覆盖项清空，回配方默认 | 新增 |
| `theme.resetMix` | 混搭：复位为整体配方… | `app.mixMode→recipe` + 6 来源清空 | 新增（随混搭启用） |

## 2. 现状 → 目标对照

| 现状 | 目标 | 变化 |
|:--|:--|:--|
| `主题：选择主题…` 拉平列表（showThemePicker 现有 QuickPick，↑↓预览/Enter/commit/Esc） | 两段式：配方 → 配色 | 行为升级，命令名保留 |
| 无复位命令 | 外观/混搭各一个复位 | 新增 |
| 命令来源 = 壳 ensureCoreCommands | 不变 | — |

## 3. 注册位置与实现

- 壳启动：App startup 的 `ensureCoreCommands` 注册（对标现有 theme 命令），不挂插件。
- 实现：命令 handler 调 `linkdesk.theme` 数据（[06](06-主题API契约.md) listRecipes/getActive）+ 配置更新（app.theme/app.themeColor/app.appearanceMode/app.mixMode）。
- 预览：现有 showThemePicker 的 ↑↓ 预览机制保留（两段式第二段同样预览配色）。

## 4. 待拍板点

1. `theme.pickColorway` 独立命令是否值得——提案**先并入** `theme.pick`（两段式里选），命令面干净；独立命令排期靠后。
2. 复位命令弹确认吗——提案**不弹**（复位可逆，配方是默认态，误触重选主题即恢复）。
3. 命令图标：无（命令面纯文本，对标 VS Code 主题命令）。
