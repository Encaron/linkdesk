**二轮（同日）**：用户追问「我的个人信息有多少可以放在关于里」⇒ 定下**三条判据 + 分档清单**（[01-设计 §4.2](./01-设计.md)），并拍板加 **GitHub 主页 `github.com/Encaron`**、邮箱**一主一备**、署名口径统一为 **`冯毅力（Encaron）`**。判据的核心是可机械核对的一条：**已随安装包出门的信息，页面显示它零新增暴露、纯增可用性**——而 `Encaron` 正是这种（`product.json` 进 asar、`LICENSE_URL` 进 dist），中文名与邮箱则是**首次进入公开产物**。

## 依赖与碰撞

- 🔴 **与 [程序图标偏小与软件内品牌标不一致](../程序图标偏小与软件内品牌标不一致.md) 的双向边界**（用户 2026-09-26 点名要求两项互相说明）：那一项管**品牌标本身的形状 / 大小 / 留白 / 换源**（`build/icon.ico` 各帧、`public/assets/logo.svg` 换源、`electron-builder.yml` 显式 `win.icon`），落点跨**打包配置 + 标题栏 + 关于页**多处；**本项只管关于页这一页的版式与信息架构**——logo 在本页放在哪、多大（配合新布局）归本项，**标长什么样不归本项**。两项已互指。
- **跨仓后果（最易漏的一条）**：本页新增的界面文字（作者 / 邮箱 / 本版本 / 运行环境 / 查看许可证…）一律走 `t()`，而**应用级词典住在出厂插件 `lang-defaults`（外部仓）** ⇒ 该插件必须 PATCH 发版 + 官方目录收录 + `sync:bundled` 种子保鲜；`npm run check` 里的 `audit-i18n.mjs --strict` 正是拿随壳种子里的那份词典判的。详见 [01-设计 §七](./01-设计.md)。
- **同区在办**：`E6#57.x` 更新批次；[`../发行说明刷新按钮/`](../发行说明刷新按钮/00-README.md) 动的是兄弟标签页（同款"壳直渲染视图 + 壳命令"载体）——本项若开工，排其后、按新 HEAD 改。
- **顺带发现（建议同笔处置，不替它拍板）**：[`../许可证方案待选.md`](../许可证方案待选.md) 写「🔴 实测仓库无 LICENSE」**已过期**——仓根 `LICENSE`（MIT，`Copyright (c) 2026 Encaron`）已在，且 `app.viewLicense` 命令也已落地（`E6#57.10e`，2026-09-13 用户拍板 MIT）。本项把「MIT 全文」挂到本页页脚（**复用那条既有命令**），建议同笔把那张条目的状态改掉或销账。
