🏗️ 核心原则速查
LinkDesk 核心设计原则 —— 做任何修改前对照检查
九条品质戒律 品质戒律 
1. 精益求精 — 不满足于"能用"
2. 慢工出细活 — 宁可慢，不返工
3. 完美 — 不放过任何一个缝 bug
4. AI 友好 — GUI / 结构化文件 / 代码归一化 三层
5. 归一化 — 一个概念只在一个地方实现（不会 v2.6）
6. 插件自由 — 插件可以替换、扩展，不被核心限制
7. VS Code 化 — 对标 VS Code 交互，不降级
8. 易操作 — 用户不查文档就能用
9. 禁止硬编码 — getAssetPath() 归一化，无绝对路径
大厅模型速记 架构大厅 
LinkDesk = Link（连接）+ Desk（桌子）
核心是圆形大厅（提供桌子），插件是周边小房间（独立进程）
交流走大厅 — Registry-mediated / 松耦合
直连走点对点 IPC — 高频推流

核心准入三条机械规则：
1. 多提供方 — 至少 2 个插件能提供此能力
2. 多消费方 — 至少 2 个插件消费此能力
3. 桌子不知道内容 — 核心不感知数据语义
AI 友好三层 AI友好 
1. GUI 层 — 声明式配置，所见即所得
2. 结构化文件层 — JSON/YAML 配置，AI 可读写
3. 代码归一化层 — 一个概念一个实现，AI 改了不会漏
