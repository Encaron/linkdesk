## 二、渲染治理——本棒代码上的三处硬骨头

1. **同一 canvas 并发 `render()` 会炸**：首版用「effect + `cancelled` 标志」逐页渲，标志只能挡住 await **之后**的收尾，挡不住**在途**的那次渲染——滚动到第 7 页时上一次渲染还没落地，新一轮同时开渲 ⇒ pdf.js 抛错 ⇒ 阅读器整屏翻进错误态。**正解 = 单条 drain 循环**：模块内 `renderReqRef`（有新请求就置位）＋ `drainingRef`（已有循环在跑就立刻返回），循环每取一页都在 **ref 上**重验（文档句柄 / 当前 scale / canvas 是否还属于这一页），取消类异常（`AbortException` / `RenderingCancelledException`）按**预期收场**放行、不当故障上报。
2. **中间那版「先查 pending 再渲」是错的**：`pending` 读的是 React state，比 DOM ref 慢一拍 ⇒ 渲染途中缩放会把活悄悄丢掉（页面停在 300×150 空画布）。教训：**渲染决策只能读 ref，不能读 state**——state 是给画面用的，不是给调度用的。
3. **虚拟化窗口**：页面卡片全量铺位（空 div 很便宜），canvas 只挂可视 ±2 页；滚出窗口即 `canvas.width = 0` 拆位图（内存口径的落点）。95MB/500 页实测：**500 张卡片、常驻 canvas 只有 3–6 个**。

## 三、加载态——规格 §三 的「onProgress 进度条」是假的（已同笔修订）

- **实测**：Node 端直喂 pdf.js 一个 95MB 预载缓冲，`onProgress` 事件数 = **0**；池里 `maxProgressWidth = -1`（进度条从未亮过）。原因是 pdf.js 在「整段字节一次交给它」的形态下不发进度，而壳 `readBinaryFile` 本身就是一次性 IPC（无分块、无 total size）⇒ 本项目**拿不到任何真进度**。
- **处置**：删掉确定式分支与 `LoadProgress` 类型（⛔ 不留「永远不亮」的死代码），加载骨架只留**不确定式滑动条**。既不画假百分比（骗人），也不留死分支。
- 规格已同笔改写：[00.5 §三 加载态](../00.5-UI布局规格.md) ＋ §七 接线对照表 C 行。

## 五、过程教训（给后续棒）

1. 🩸 **后台窗口的 rAF 被冻结 ⇒ pdf.js 的分帧渲染永远完不成**（读数看着像「渲染挂了」：`document.hidden=true`、连滚 40 步 42 982 ms、`maxFrameGapMs=0`、canvas 尺寸对但全白）。**这不是插件 bug，是读数环境**。CDP 三件套解开节流：`Page.bringToFront` ＋ `Page.setWebLifecycleState{state:"active"}` ＋ `Emulation.setFocusEmulationEnabled{enabled:true}`（之后 `framesIn1s` 61）。**⚠️ 本棒前半程的部分读数是在节流窗口里取的，已用上述手法全部重取**，档案里以上表为准。
2. **隐藏标签页会报 0 尺寸视口**：keep-alive 后台标签的首帧 / 隐藏期 `reportViewport(0,0)`，照 0 算适宽会得到无意义倍率（0.25 或回退 1）并触发空转重渲。处置：store 直接丢掉非正尺寸读数（切回前台 ResizeObserver 会带真尺寸再来一次）。
3. **手写 PDF fixture 的 xref 极易错**（漏写对象 4 的 offset、`/Size` 差一 ⇒ 池控制台 `Warning: Indexing all PDF objects` ＋ 间歇 `InvalidPDFException`）。生成脚本 `%TEMP%\pdf-t3\gen.mjs` 已修正并自检每个 offset；⚠️ 底色填白后**必须把填充色改回黑**（`q 1 1 1 rg … re f Q` 之后补 `0 0 0 rg`），否则白字白底、看着像没渲染。
4. **`.linkdesk-plugin` 是 zip**，`pluginManager.install` 收**zip 路径**（正斜杠最稳，Git Bash 里反斜杠会被吞）；目录已存在时 install 直接拒绝（「如需覆盖请先卸载」）⇒ **卸载→装**才是干净顺序。
5. `open-tab` 不带 `sourceId` ⇒ 每次开新标签（identityField=filePath 的本义，T2 §五.2 同款）——测试一律带 `--opts {"sourceId":…}`。
