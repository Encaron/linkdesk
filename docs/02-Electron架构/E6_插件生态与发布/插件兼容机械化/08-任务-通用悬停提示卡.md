## 四、禁区

1. ⛔ **不许做成「点击弹层 / toast / 暗屏大面板 / 右键菜单 / 模态框」**——它是**贴锚的常驻说明卡**（口径唯一真相源 = [05 §四](05-任务-市场显示状态.md)）。
2. ⛔ **卡内不放链接与按钮**（`pointer-events:none`）——出卡是「看一眼就走」，不是交互面。
3. ⛔ **不挂原生 `title`**（会与卡同屏打架；`ldk-badge` 自带的 `title` 提议同样要摘掉）。
4. ⛔ **不许起 `Tooltip` / `HoverCard` 这类名字**（语义不清 + 与浮层族混）；名字定稿 = `HintCard` / `ldk-hint-card`（[壳目录规范](../../../开发管理/壳目录规范.md) 铁律：描述它是什么，⛔ 不带消费方字样）。
5. ⛔ **不许做变体 / 参数化皮肤**（`variant` / `tone` / `size` 一堆选项 = 又一个设计系统；先一个形状，真要变体另立格）。
