## 补名规则（D1/D7 配套，全表通用）

1. **≤12 字**、名词短语，去插件前缀（键里已有 `editor.` 就别再叫「编辑器xxx」的归属词）——`editor.autoSave` → 「自动保存」。
2. **短名 ≠ 描述压缩**：描述讲「是什么/怎么选」，短名只当**名字**。「自动保存——off 手动保存 / afterDelay 1秒空闲后…」的名字就是「自动保存」。
3. `renderHint:"action"` 行按**按钮语义**起名（动词开头）：`ai.guide.copyCliLine` → 「复制 CLI 接入行」。
4. `uiHint` 特殊控件行照控件语义：`fontSize` → 「编辑器字号」（描述已这么叫，直接用）。
5. **对标 VS Code 用语**（该设置项在 VS Code 有对应者，跟它叫）：`editor.wordWrap` → 「自动换行」、`file-tree.sortOrder` → 「排序方式」。
6. 枚举显示名（`enumDescriptions`）另算：值 → 中文显示名，一并进 en.json；如 `editor.autoSave` 三档「关 / 延迟自动 / 切换标签页时」。🔴 **形态（2026-10-04 第 2 波实测）**：插件 manifest 里必须是**对象**（`{"off":"关", …}`——schema `plugin.schema.json:372` 规定，数组形态过不了 `npm run build`）；**数组**形态只属壳内部声明与动态推送。渲染侧取字统一走 settings 仓 `enumDescription.ts` 的 `enumDescriptionAt`（两种都吃）——⛔ 别按下标直读（旧 bug 与修法见 [01 层 2](01-方案与落点契约.md)／[02 E22](02-边缘情况清单.md)）。`editor.fontWeight` 的 100–900 数值档按本表原话「数字原样」**不列显示名**（缺项渲染自动回退显值）。
7. **短名底稿列已由布置者于 2026-10-04 全量预填**（89/89）——用户过目即为定稿；执行 AI 只做逐条复核（≤12 字/去前缀/动宾行），个别微调可自改，**成体系改判须用户点头**。
