# E4V#58 根文件夹列表——替代 sticky 的跳转导航

> 2026-08-01。**E4V#57 sticky 放弃后的替代方案。** 不粘、不推、不算——只跳。
> **前置语境：** [[#E4V#57-sticky-放弃]] | [[../E4V#57-致命Bug表]]

---

## 一、定位

E4V#57（81 commits，~162 行 → 全部回退）试图对标 VS Code 的 sticky ancestor chain —— 展开多层目录时父目录粘顶 + 推出动画。因文件树双层滚动架构（`.file-tree-scroll` `overflow-y: auto` + `.side-panel-content` `overflow-y: auto`）与 CSS `position: sticky` 不兼容而失败。

**E4V#58 是降维替代：** 不粘任何树节点。只在 section header 下方放一个根文件夹列表，点击即跳转。用户可以自由上下滚。

---

## 二、设计决策

| 决策 | 选择 | Why |
|------|------|-----|
| sticky？ | ❌ 完全不粘 | 避免 E4V#57 的所有坑 |
| 列表位置 | `SidebarSection` body 内，FileTree 上方 | 不修改共享组件 |
| 列表 sticky | `position: sticky; top: 22px` | 贴在 section header 下方 |
| overflow 链 | **不碰** | 不冒风险 |
| 渲染容器 | FoldersView 内部，`SidebarSection` children | section 内部自己画 |
| 单根行为 | 不渲染列表 | 无需选择 |
| 多根行为 | 渲染列表 | 用户点选跳转 |

## 四、交互

### 点击跳转

```
用户点 📂 vscode
  → 找到 vscode 根节点在 flatItems 中的 index
  → scrollTop = index × 22 - 22(header) - folderListHeight
  → .side-panel-content.scrollTo({ top: scrollTop, behavior: "smooth" })
  → 高亮 vscode 行
```

### 滚动跟踪

```
用户手动滚树
  → scroll 事件回调
  → 扫描当前视口顶部可见的 flatItems
  → 找到第一个 depth===1 的根节点
  → 更新 selectedFolder → 高亮自动切换
```

### 初始状态

- 默认选中第一个根文件夹（`roots[0]`）
- 不自动滚动——用户看到的是树顶部

## 五、配置项

```json
// plugin.json contributes.configuration
{
  "fileTree.rootFolderList": {
    "type": "string",
    "enum": ["always", "never"],
    "default": "always",
    "description": "多根工作区时，是否在树上方显示根文件夹快速跳转列表"
  }
}
```

| 值 | 1根 | 多根 |
|----|-----|------|
| `"always"` | 不显示 | ✅ 显示列表 |
| `"never"` | 不显示 | ❌ 不显示（和1根行为一致） |

### RootFolderList.tsx 接口

```ts
interface RootFolderListProps {
  folders: ExplorerItem[];        // 根节点列表（model.roots）
  selectedUri: string;            // 当前选中/高亮的根文件夹 URI
  onSelect: (uri: string) => void; // 点击回调
  onScrollToRoot: (uri: string) => void; // scrollTo 回调（穿透到 FoldersView）
}
```

### FoldersView 改动要点

```
1. title 从 folders[0]?.name → "工作区"
2. 读配置 ConfigurationService.get("fileTree.rootFolderList")
3. 条件渲染：
   - 单根 → 不渲染 RootFolderList
   - 多根 + "always" → 渲染 RootFolderList
   - 多根 + "never" → 不渲染
4. 渲染结构：
   <SidebarSection title="工作区" ...>
     <div className="file-tree-root">
       {showList && <RootFolderList ... />}
       <FileTree ref={fileTreeRef} ... />
     </div>
   </SidebarSection>
5. RootFolderList sticky top:22px 贴在 header 下方
6. onScrollToRoot: 计算目标 scrollTop → .side-panel-content.scrollTo()
7. scroll 跟踪: 监听 scroll → 更新 selectedUri
```

### RootFolderList 内部

```
1. 读 folders.length → ≤1: return null
2. 渲染容器 div.root-folder-list
   - position: sticky; top: 22px; z-index: 1
   - ≤4: 不定高
   - ≥5: max-height: 88px; overflow-y: auto
3. 每行: div.root-folder-list-item
   - onClick → onSelect + onScrollToRoot
   - selected → class root-folder-list-item--selected
   - icon: codicon-root-folder
   - name: item.name
```
