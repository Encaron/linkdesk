## 二、升级迁移说明（这段是给插件作者看的，写法要求）

放在 §12 末尾一小节，**用作者视角、不含内部任务号**（`check-author-docs-symbols` 会扫；作者面禁用 `E6#…` 这类坐标）。要点：

1. **什么时候会受影响**：你把 `@linkdesk/ui` 升到 **0.2.0** 之后——**不是立刻**。旧版本里组件类名是 `.badge` 这种裸名，包里带的 CSS 与组件自洽，所以**不升级就不会坏**。
2. **什么会受影响**：你**写在插件自己 CSS 里**、用来微调共享组件外观的那些**后代选择器**（例如 `.control-bar .combobox`、`.settings-slider-control .slider` 这类写法）。
3. **怎么改**：把选择器里那个共享组件的类名加上 `ldk-` 前缀（`.combobox` → `.ldk-combobox`、`.slider` → `.ldk-slider`、`.mdv` → `.ldk-mdv`）。
4. **为什么不自动兼容**：这类失配**不报错**，只是样式悄悄不再生效——所以文档必须明写（这也是我们不再保留裸名的原因）。
5. **官方先例**：官方三只插件（serial-monitor / marketplace / settings）已在 0.2.0 同批改完，可作参照。
