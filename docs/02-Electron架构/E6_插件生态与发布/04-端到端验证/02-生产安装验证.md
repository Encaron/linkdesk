```
[ ] hello-world.linkdesk-plugin 文件存在
[ ] 文件大小合理（~50-300KB——React 不内嵌所以较小）
[ ] 解压验证：
    [ ] plugin.json 完整——字段和原版一致
    [ ] index.bundle.js 存在
```

## 二、安装包构建验证（E6#37）

> 🔴 **文件名必须按 [05-文档与发布/02-发布流水线.md](../05-文档与发布/02-发布流水线.md) §〇 的唯一真值规则**——`linkdesk-setup-{version}.exe`（小写 + 连字符 + 带版本号）。原稿写的 `LinkDesk Setup 0.1.0.exe`（大写 + 空格）**正是 `asset-missing` 那个坑的名字**：更新器按小写连字符精确匹配，用大写空格名永远找不到 ⇒ 检查更新成功、下载必失败。

### 操作步骤

```bash
npm run electron:build
```

### 检查项

```
[ ] 构建成功——无 tsc 错误、无 Vite 错误、无 electron-builder 错误
[ ] 🔴 release/ 下有且只有一个 .exe，文件名逐字符 = linkdesk-setup-{package.json version}.exe（E6#42e 门禁脚本）
[ ] 🔴 `product.json` 内嵌版本 === package.json version（E6#37d 版本自证——不符说明构建期注入漏了）
[ ] 安装到 Windows：
    [ ] 安装程序正常启动
    [ ] 安装路径可选
    [ ] 桌面快捷方式创建
    [ ] 开始菜单条目创建
    [ ] 卸载程序存在
[ ] 启动验证：
    [ ] 无白屏
    [ ] 任务栏图标正确
    [ ] 文件树正常
    [ ] 编辑器正常
    [ ] 串口正常（如果有设备）
    [ ] 设置正常
    [ ] 主题切换正常
    [ ] 语言切换正常
```

## 三、安装版全链路验证（E6#38）

### 前置条件

```
[ ] hello-world.linkdesk-plugin 已上传到 GitHub Releases
[ ] marketplace.json 已更新——hello-world 条目存在
[ ] GitHub raw URL 可访问
```

### 操作步骤

```
1. 启动安装版 LinkDesk
2. 打开插件市场（侧栏 marketplace 图标）
   [ ] 市场页面正常渲染
   [ ] hello-world 出现在列表中
   [ ] 按钮显示 "安装"

3. 点击 "安装"
   [ ] 进度条显示
   [ ] 下载完成 → "已安装"

4. 查看图标栏
   [ ] Smile 图标出现

5. 点击 Smile 图标
   [ ] 侧栏切换到 Hello 视图
   [ ] 问候语显示正确
   [ ] "Open New Tab" 按钮可用

6. 点击 "Open New Tab" 3 次
   [ ] 3 个标签页出现在标签栏
   [ ] 每个标签页显示不同随机数

7. 打开一个文件 → 编辑器内右键
   [ ] 菜单中 "Hello: Say Hi" 出现
   [ ] 点击 → **铃铛通知面板出现条目**（⚠️ 原文写「toast」= 已删的右下小卡）

8. 按 Ctrl+Shift+H
   [ ] **同一处通知面板出现条目**

9. 打开设置 → Hello World 配置组
   [ ] greeting 字段存在，值为默认值
   [ ] 修改 → 侧栏文字实时变化

10. 切英文
    [ ] 菜单中 "Hello: Say Hi" 变英文（保持不变——本来就是英文）
    [ ] 其他 UI 正常切换

11. 关闭 LinkDesk → 重新打开
    [ ] hello-world 仍在图标栏
    [ ] 点击 → 侧栏正常

12. 卸载 hello-world
    [ ] 市场页面 → "已安装" 变 "安装"
    [ ] 图标栏 Smile 消失
    [ ] installed-plugins.json 保留 hello-world 条目且 `removed: true`（removed 墓碑——卸载不销账，账本保留 + 目录真删；isInstalled = 在账本 && !removed，统一不按来源划，E6#18）
```

## 四、Encaron 终极验证（E6#39）

**这是 E6 封站的唯一标准。**

### 条件

```
❌ 不能用命令行
❌ 不能看代码
❌ 不能动任何配置文件
✅ 纯鼠标 + 键盘操作
```

### 步骤

```
1. 如果 LinkDesk 没装 → 下载安装包 → 安装
   如果已装 → 打开

2. 打开插件市场 → 搜索 "hello"

3. 看到 Hello World → 点安装

4. 安装完成后：
   - 点图标 → 侧栏出来了 ✓
   - 打开标签页 → 标签页出来了 ✓
   - 右键菜单 → 有 Hello 选项 ✓
   - Ctrl+Shift+H → 铃铛面板里出现条目 ✓
   - 设置里改 greeting → 侧栏变了 ✓
   - 状态栏 → 问候语条目在 ✓

5. 卸载 → 图标消失了 ✓
```

**Encaron 说"行了" → E6 封站 → git tag `v{当前版本}`。**（⚠️ 原文写 `v1.0.0`——**E6 结束 ≠ 自动 1.0**，见 [02-发布流水线.md](../05-文档与发布/02-发布流水线.md) §四：版本号须用户拍板，E6 全程恒 `0.x`。）
