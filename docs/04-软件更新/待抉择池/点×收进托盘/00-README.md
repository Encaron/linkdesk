# 点 × 收进托盘（设置里给一个开关）

> **状态：✅ 方案已定（C1–C5 于 2026-10-03 用户全部拍完），⏳ 待实施——本夹是纯文档／图，至今一个字都没动产品代码。**

> ⚠️ **这是一次既有拍板改判，必须登记**：`electron/main.ts:397-400` 明写「**主窗关闭 = 整个应用退出**」（E5.8#43-3，2026-08-22 用户拍板）。本任务要把它改成「**默认不退出，收进右下角托盘**」——⛔ 不许悄悄改，实现时那条注释要同笔改写。

## 一、你令的原话（2026-10-03）

> 「我发现很多软件即便点 ×，也仅仅只是缩小到 windows 任务栏的『**显示隐藏的图标**』中。我希望我们软件也有这个功能。并且，这个功能是**声明在设置的已有的通用组中**，可以选择性关闭是否点 × 为关软件，**默认为关**，即：**点 × 为放入『显示隐藏的图标』中**。」

⇒ 拆成三件事：

1. 点 × 默认**不退出**，收进右下角「显示隐藏的图标」（＝托盘／通知区）；
2. 设置页**已有的「通用」组**里加一个开关，可以把这件事关掉（改成点 × 直接退出软件）；
3. 默认态 ＝ 收托盘（你说的「默认为关」＝「**点 × 关软件**这件事」默认为关——同一件事的另一种说法，见 01 §二 极性与文案）。

## 四、边界（本轮明确不做）

- ⛔ **不做开机自启**（你没要；产品今天也没有任何 `setLoginItemSettings`）。
- ⛔ **不做自绘的托盘面板**：右下角那个菜单是 **Windows 系统原生菜单**，样式归系统——我们只定菜单项文字。
- ⛔ **不动安装器那一半**（安装器与「更多配置」容器是另一个任务：[../安装器-更多配置/00-README.md](../安装器-更多配置/00-README.md)）。
- ⛔ **不改设置插件本体**（新键是**声明**，渲染照旧；这就是这个任务小的原因）。
- ⛔ 不额外发明状态（例如「记住上次是收托盘还是真退」）——开关只有开／关两态。
