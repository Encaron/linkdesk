# 插件发布流水线

> 对应任务：E6#13、E6#14。从本地 `npm run build` 到插件市场上可见。

---

## 一、完整链路

```
插件作者电脑                           GitHub                    用户电脑
──────────                           ──────                    ────────
npm run build
  → my-plugin.linkdesk-plugin
  → 文件大小 245KB
  → "Ready to publish!"

打开 LinkDesk
  → 插件市场 → "发布插件"
  → 选文件 ──────────────────────→ GitHub Releases
                                    marketplace.json 更新
                                                             打开 LinkDesk
                                                               → 插件市场
                                                               → 看到 my-plugin
                                                               → 点安装
```

## 二、build 命令

### 2.1 实现

```bash
linkdesk-plugin-sdk build
```

实际步骤：

```
1. validatePluginJson("./plugin.json")
   → 失败 → 打印错误，停止

2. defineLinkdeskPluginConfig() → Vite build
   → 产出 dist/<pluginId>.linkdesk-plugin/
     ├── plugin.json
     ├── icon.svg (如果有)
     ├── i18n/*.json (如果有)
     └── index.bundle.js

3. zip dist/<pluginId>.linkdesk-plugin/ → ./<pluginId>.linkdesk-plugin

4. 输出：
   ✔ Build complete!
     File: ./my-cool-plugin.linkdesk-plugin
     Size: 245 KB
     Ready to publish!
```

### 2.2 Vite 配置要点

```typescript
// vite-config.ts 中
{
  build: {
    lib: {
      entry: pluginEntry,
      formats: ["es"],
      fileName: "index.bundle",
    },
    rollupOptions: {
      external: ["react", "react-dom", "react-i18next", "i18next"],
      output: {
        // 确保 CSS 也打进 bundle（如果有）
      },
    },
  },
}
```

## 三、发布入口——插件市场 "发布插件" 按钮

### 3.1 触发位置

marketplace 插件 UI：
- 顶部工具栏 "发布插件" 按钮（仅在开发模式或登录后可见）
- 或者：设置页面 → "发布新插件"

### 3.2 流程

```
1. 作者点击"发布插件"
2. 文件选择对话框（Electron dialog.open）
   → 选 .linkdesk-plugin 文件
3. 壳读文件：
   - 解压临时目录 → 读 plugin.json → 显示预览
   - "确认发布 my-plugin v1.0.0？"
4. 确认 → 上传到 GitHub Releases：
   POST https://api.github.com/repos/{owner}/{repo}/releases
   或 → GitHub REST API 创建 Release + 上传 asset
5. 更新 marketplace.json：
   - clone/拉取仓库 → 加条目 → commit → push
   或 → GitHub API 直接更新文件
6. 返回结果："发布成功！几分钟后可在市场中看到。"
```

### 3.3 简化方案（v1.0）

**不用 GitHub API——用 GitHub Releases 的网页上传。**

```
1. npm run build → 产出 .linkdesk-plugin
2. 打开 https://github.com/{owner}/linkdesk-marketplace/releases/new
3. 拖拽 .linkdesk-plugin 文件
4. 填写 tag 和标题
5. 发布
6. 手动编辑 marketplace.json → 加条目 → commit
```

v1.0 可以接受手动步骤。后续迭代再自动化。
