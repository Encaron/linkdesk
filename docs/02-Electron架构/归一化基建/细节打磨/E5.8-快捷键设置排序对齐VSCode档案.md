# E5.8-快捷键设置排序对齐 VS Code 档案（#184）

> 2026-08-29。**用户实机：快捷键设置里漏看「切换侧栏可见性」（Ctrl+B）**——问「Ctrl+B 是干什么的？为什么没有在快捷键中声明？」。查证后实锤它已声明（shellKeybindings.ts:20 source=builtin），漏看源于排序：设置表格按纯标题字母序排 100 条命令，有绑定的行不浮顶。用户追问「排序是随便做的还是有一套规定」→ 查证规定存在但注释声称「对标 VS Code」与实际实现不符。用户拍板**立案对齐 VS Code 默认排序**。
> 清单指针：E5.8-执行清单 Phase 11.22 #184。
> **非新能力声明**：零新增 API / 配置 / 贡献点——纯排序行为对齐（复制 VS Code 算法），不改任何 `window.linkdesk.*` 契约。

---

## 一、背景与用户实机证据

用户在快捷键设置页翻找 Ctrl+B 未果，报「为什么没有在快捷键中声明」。查证：
- 运行时探测（CDP pool `getKeybindings()`/`getCommands()`）：`ctrl+b → workbench.action.toggleSidebarVisibility`（source=builtin）已在注册表，命令「切换侧栏可见性」已注册（100 命令之一）——**声明无缺，是排序把它埋没了**。
- 用户自认「我之前看漏了应该」——漏看的直接原因是排序。

## 二、VS Code 源码对照（铁证）——默认排序 ≠ 纯标题序

读 VS Code 源码 `src/vs/workbench/contrib/preferences/browser/keybindingsEditorModel.ts`：

```ts
// 默认列表 = 按 compareKeybindingData 排序（keybindingsEditorModel.ts:227）
this._keybindingItems = this._keybindingItemsSortedByPrecedence.slice(0)
  .sort((a, b) => KeybindingsEditorModel.compareKeybindingData(a, b));

private static compareKeybindingData(a, b): number {
  if (a.keybinding && !b.keybinding) return -1;   // ① 有绑定的排前
  if (b.keybinding && !a.keybinding) return 1;
  if (a.commandLabel && !b.commandLabel) return -1;
  if (b.commandLabel && !a.commandLabel) return 1;
  if (a.commandLabel && b.commandLabel) { ... return a.commandLabel.localeCompare(b.commandLabel); } // ② 同组内标题字母序
  ...
}
```

VS Code 还有工具栏「Sort by Precedence (Highest first)」开关（`keybindingsEditor.ts:148`，默认关）。

**结论**：VS Code 默认排序 = **「有快捷键的命令浮顶 → 标题字母序」**，另有按优先级切换。LinkDesk 注释声称「对标 VS Code Keyboard Shortcuts」只对齐了第二层标题序，漏了第一层「有绑定优先」。

## 三、根因（file:line）

| 位置 | 现状 |
|---|---|
| [KeybindingSettingsView.tsx:92-93](../../../../plugins/builtin/settings/src/views/keybinding-settings/KeybindingSettingsView.tsx#L92) | `rows.sort((a, b) => a.title.localeCompare(b.title, "zh"))`——纯标题序，单一判据 |

机制 = 100 条命令（31 条有绑定 + 69 条无绑定）均匀按中文标题排，无绑定/有绑定混排，「切换侧栏可见性」这类标题埋在中段，全靠翻/搜。VS Code 的有绑定浮顶让用户打开面板第一屏就是全部可改的绑定，不会漏。

## 四、改法

| 位置 | 改法 |
|---|---|
| 新建 [keybindingRowSort.ts](../../../../plugins/builtin/settings/src/views/keybinding-settings/keybindingRowSort.ts) | 抽纯函数 `compareKeybindingRows(a, b)`：`key !== "—"`（有绑定）优先，同组内 `title.localeCompare("zh")`——复制 VS Code `compareKeybindingData` 的第一优先级语义，零自创 |
