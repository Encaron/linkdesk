### E5.6#0c 🟡 新文件归属规范——Pool 模型新增文件的目录约定

> E5 建立了 `src/core/{api,registry,services,react,builtin,data}` 和插件 `src/{components,views,hooks,services,utils,styles,__tests__}` 两级目录规范。Pool 模型新增的文件类型（Pool 入口页面、Pool 渲染器）不在这两级体系内——需要约定。

  ```

  ├── index.html             ← 壳窗口入口（已有）
  ├── plugin-view.html       ← 插件独立 WebView 入口（已有，E5.5#9c）
  └── pool.html              ← 🆕 双Pool共用入口（URL query ?zone=sidebar|main 区分）
  ```

- [ ] **E5.6#0c-2** 约定 Pool 渲染进程侧文件归属——`src/pool/` 目录
  ```
  src/pool/
  ├── pool-main.tsx          ← Pool WebView 的 React 入口——根据 zone 渲染 SidebarRenderer 或 MainRenderer
  ├── SidebarRenderer.tsx    ← 侧栏 Pool 渲染器——图标列表 + 视图容器
  ├── MainRenderer.tsx       ← 主区 Pool 渲染器——TabBar + 分屏
  ├── BottomPanelRenderer.tsx← 底部面板 Pool 渲染器——PanelTabBar + 视图容器（E5.6#40 预留口）

  ```
- [ ] **E5.6#0c-3** 约定与现有目录的关系

  - `src/pool/` 和 `src/core/` 平级——Pool 渲染器 ≠ 核心服务。Pool 渲染器可以 import `src/core/`，反之不行
