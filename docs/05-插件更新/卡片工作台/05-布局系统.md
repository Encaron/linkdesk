# 05 — 布局系统

> 无限画布 + 网格吸附 + 缩放。对标 Figma 白板 + 荣耀平板桌面。

---

## 一、核心模型

```
无限画布 = 没有边界的 2D 平面
网格 = 不可见的等距线，间距 = gridUnit（默认 80px）
卡片 = 固定尺寸的矩形，吸附在网格线上

特性：
  - 无边界——上下左右无限延伸
  - 不自动排列——卡片放在哪就停在哪
  - 不挤压——相邻卡片不互相推动
  - 不重叠——放下时检测冲突
  - 空位可见——空白就是空白，AI 能看懂
```

## 二、坐标系统

```
(0,0) ──────────── x →
  │   ┌────┐
  │   │ A  │     ┌────┐
  │   │    │     │ B  │
  │   └────┘     │    │
  │              └────┘
  │        ┌──────────┐
  │        │    C     │
  │        │          │
  │        └──────────┘
  │
  ▼ y

卡片 A: { x: 0, y: 0, w: 2, h: 2 }
卡片 B: { x: 4, y: 0, w: 2, h: 2 }   ← x=4，和 A 之间隔了 2 个空位
卡片 C: { x: 2, y: 4, w: 4, h: 2 }   ← y=4，和上面隔了 4 个空位

A 和 B 之间 x=2→x=3 是故意留空的。
C 在下面，和 A/B 之间 y=2→y=3 是故意留空的。
```

## 三、网格单元——运行时可调

```typescript
// 配置项：app.workspaceGridUnit
// 默认 80px，范围 40-200px

gridUnit = 80:
  1×1 = 80×80   2×1 = 160×80   2×2 = 160×160   4×2 = 320×160

gridUnit = 100:
  1×1 = 100×100 2×1 = 200×100  2×2 = 200×200   4×2 = 400×200

gridUnit = 60:
  1×1 = 60×60   2×1 = 120×60   2×2 = 120×120   4×2 = 240×120
```

**调网格单元 = 改变所有卡片的物理像素大小。** 卡片在网格中的坐标 `(x, y, w, h)` 不变——只是每个格子的像素大小变了。

## 四、碰撞检测

放置卡片时检测：

```typescript
function hasCollision(
  newCard: { x, y, w, h },
  existingCards: Array<{ x, y, w, h }>
): boolean {
  return existingCards.some(card => {
    const horizontal = newCard.x < card.x + card.w && newCard.x + newCard.w > card.x;
    const vertical   = newCard.y < card.y + card.h && newCard.y + newCard.h > card.y;
    return horizontal && vertical;
  });
}
```

**碰撞行为：**
- 拖拽松手时检测 → 有碰撞 → 弹回原位 + 红色闪烁
- 双击空白区新建卡片时检测 → 有碰撞 → 自动偏移到最近空位

## 五、画布视口

```
                    无限画布（逻辑空间）
   ┌────────────────────────────────────────────┐
   │                                            │
   │    ┌────┐              ┌──┐                │
   │    │ A  │              │B │                │
   │    └────┘              └──┘                │
   │                                            │
   │         ┌─────────────────────┐            │
   │         │                     │            │
   │         │   当前视口（屏幕可见） │            │
   │         │                     │            │
   │         │   ┌──────────┐      │            │
   │         │   │    C     │      │            │
   │         │   └──────────┘      │            │
   │         │                     │            │

   │                                            │

   │              │D │                          │

**视口操作：**
- 滚轮 → 上下滚动视口
- Shift+滚轮 → 左右滚动视口
- 中键拖拽 / Space+拖拽 → 平移视口（抓手）
- Ctrl+滚轮 → 缩放视口

## 六、缩放系统

### 右下角缩放控件

```
┌────────┐
│ 150%   │  ← 点击恢复 100%
│ ────   │
│ ──○──  │  ← 滑块：10% ─ 200%
│ ────   │
│ ⊖ ⊘ ⊕ │  ← 缩小 / 适应画布 / 放大
└────────┘
```

| 操作 | 行为 |
|------|------|
| ⊖ 点一下 | 缩 10% |
| ⊕ 点一下 | 放 10% |
| ⊘ 适应画布 | 计算所有卡片的包围盒 → 缩放到刚好全在视野内 + 10% padding |
| 滑块 | 连续缩放 10%–200% |
| 百分比数字 | 点击 → 恢复到 100% |
| Ctrl+0 | 恢复到 100% |
| Ctrl+= / Ctrl+- | 放大 / 缩小 |

### 鸟瞰图（缩到 ≤ 25% 时出现）

```
缩到 25% → 右下角出现小地图：

## 七、布局持久化

```
存储位置: .linkdesk/workspace/{cardset-name}.json

{
  "version": 1,
  "name": "环境监测",
  "gridUnit": 80,
  "viewport": {                    // 可选——保存当前视口位置
    "scrollX": 200,
    "scrollY": 100,
    "zoom": 1.0
  },
  "cards": [
    {
      "id": "uuid-01",             // 卡片实例 ID（UUID v4）
      "type": "value",             // 卡片类型
      "cardId": "temp",            // 绑定的数据 cardId（单 cardId 卡片用）
      // 多曲线卡片用 curves 数组替代 cardId：
      // "curves": [
      //   { "cardId": "pid_sp",  "label": "设定值", "color": "#3B82F6" },
      //   { "cardId": "pid_pv",  "label": "实际值", "color": "#22C55E" },
      //   { "cardId": "pid_out", "label": "输出",   "color": "#F97316" }
      // ],
      "protocolId": null,          // null = 跟随标签页 / 显式: "bracket"/"sbq"/...
      "x": 0, "y": 0,              // 网格坐标
      "w": 2, "h": 2,              // 网格尺寸
      "settings": {                // 卡片个性化设置
        "title": "温度",
        "unit": "°C",
        "decimals": 1,
        "color": null,             // null = 跟随类型默认
        "subItems": ["progress", "wave"],
        "rules": []                // 条件规则——空 = 用默认外观
      }
    }
  ]
}
```

**保存时机：**
- 卡片位置改变后 1s 防抖 → 自动保存
- 卡片设置弹窗点击"确定" → 立即保存
- 切换卡片集 → 先保存当前，再加载新卡片集
- 关闭软件 → 保存

**加载时机：**
- 打开卡片集 → `FileService.readTextFile("workspace/环境监测.json")` → 恢复布局
- 文件不存在 → 空白画布

## 八、布局的 AI 可读性

```json
// AI 读这个 → 一眼理解布局
{
  "cards": [
    { "id": "temp", "x": 0, "y": 0, "w": 2, "h": 2 },
    { "id": "humid","x": 4, "y": 0, "w": 2, "h": 2 },
    { "id": "fan",  "x": 0, "y": 4, "w": 1, "h": 1 }
  ]
}
```

**AI 能推理：**
- "temp 和 humid 之间 x=2→x=3 是空的" ← `x` 坐标不连续
- "左边两列有卡片，右边一整列空着" ← 最大 `x+w=6`，右边 `x≥6` 全空
- "把 fan 移到 humid 右边" → `fan.x=6, fan.y=0` ← 一次 JSON 操作

**这就是方案 3 的实现——AI 通过 JSON 精确知道布局，能帮你重排。**
