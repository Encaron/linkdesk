## 〇、一句话总览（大白话）

市场里每张插件卡片本该显示插件「自己的图」。现在市场**从没拿到插件声明的图标**（半路被删、详情页不看插件自己），所以全部退回通用兜底（侧栏 = 📄 文稿、详情 = 几何符号）。用户要求升级设计：**一枚界面用的小图标 + 一枚市场展示用的大图，是两回事**——功能式插件（Python/翻译）没界面小图标，也要有一张市场展示图；到时要给每个插件画一张 SVG 展示图、没画的统一用规定默认图。

## 一、双图标模型设计定案（用户 2026-09-09 亲口归档）

1. **不是所有插件都是视图向/有界面图标**：功能式插件（如 python 语言插件、翻译插件）没有自己的简化图标，**但市场展示页仍须显示一张图标**——内容不限。
2. **有简化图标的插件可拥有两枚**：图标栏/界面的「简化单色小图标」**≠** 详情页/市场的「正常介绍图标」。双视图类插件拿简化图标当展示图不理想 → 分开声明。
3. **市场展示图标优先用彩色 SVG**：尽量给每个插件绘制一张市场介绍 SVG，届时每个插件 plugin.json **小改一次**（声明或补声明）。
4. **默认图标**：没画展示图的插件，市场统一显示一张**规定好的默认图标**——取代现在的 📄 emoji / codicon-symbol-misc 兜底。
5. **🔥 一律矢量 SVG（2026-09-09 用户加定）**：插件图标统一矢量图——**不要 lucide 图标名、不要 png 位图、不要 emoji 当图标**。简化界面图标与市场展示图都应是 SVG 资产文件。现有 lucide（如 file-tree `FolderTree`）、png（serial-monitor/settings）在逐插件批次一并转 SVG；`icon`/`marketIcon` 落点都指向 `.svg` 文件（iconSource 恒 `svg` 或省略自动按文件名推断）。「lucide/codicon 名 descriptor」自本定案起对**新插件图标**不再作为推荐形式；壳内 UI 装饰性小图标（齿轮/删除/下载这类 codicon）是否一并去留 = 另一盘范围问题，用户另行点名（本档案不扩）。
6. **🔑「市场展示图」是展示框/封面美术，不是图标（2026-09-09 用户定义）**：市场详情/列表那个「图标」位，本质是插件的**展示框（cover art）**——SVG 可以画得非常讲究、非常复杂，**不受「小图标要简洁」约束**。它是一张给插件做门面的美术图，跟界面里那枚单色小图标是两码事（同见定案 2 双图标模型）。市场位语义 = 「展示图（cover art）」；界面位语义 = 「图标（icon）」。本档案凡写「市场展示图 / 展示图标」均按此理解。

## 二、现状 Bug 对账（2026-09-09 现场排查，file:line 证据）

### A　市场列表（已装/内置/禁用）恒显 📄 文稿

- 表现：侧栏所有行图标 = 📄。
- 根因 1：行组件 [ExtensionItem.tsx:78](../../../../plugins/marketplace/src/components/ExtensionItem.tsx#L78) 调 `<PluginIcon pluginId={…} />` **没传 manifest** → 组件 [PluginIcon.tsx:64](../../../../src/components/shared/plugin-icon/PluginIcon.tsx#L64) 无 manifest 恒 `{ emoji: "📄" }`。
- 根因 2（更根子）：**数据源就删了 icon**——`list()` IPC 序列化子集 [types.ts:189-198](../../../../src/core/api/linkdesk-api/types.ts#L189-L198)（PluginListSubset）只有 name/desc/version/core/author/statusBar/contributes/requires **八字段、无 `icon`/`iconSource`**（注释自认「与 handlePluginsCall list 7 字段对齐」，见 [types.ts:131-135](../../../../src/core/api/linkdesk-api/types.ts#L131)）。行组件想传也没得传。

### B　详情页图标不读已装插件自身声明 → 恒几何符号

- 表现：串口监视器等内置（无市场目录条目）插件详情页顶部 = 几何符号（`codicon-symbol-misc`）。
- 根因：[DetailView.tsx:577](../../../../plugins/marketplace/src/views/DetailView.tsx#L577) `iconManifest` **只取市场目录 `entry`** 的 icon descriptor；已装信息 `info.manifest`（[types.ts PluginListSubset](../../../../src/core/api/linkdesk-api/types.ts#L189)）既无 icon 字段、详情页也从不回退读它 → 无目录条目即 [DetailView.tsx:740](../../../../plugins/marketplace/src/views/DetailView.tsx#L740) `codicon-symbol-misc` 兜底。

### C　兜底图案不合规

- 未配图标插件兜底 = 📄 emoji（列表，[PluginIcon.tsx:61/85](../../../../src/components/shared/plugin-icon/PluginIcon.tsx#L61)）+ codicon-symbol-misc（详情）。06-图标.md 承诺「已装列表/详情页 = 本地包内 icon.svg」，实现从未兑现。**缺一个统一、好看的默认图标规定。**

### 反证（证明修法方向对）

- serial-monitor plugin.json `icon: "resources/icon.png"`（[plugin.json:5](../../../../plugins/serial-monitor/plugin.json#L5)）彩色图**确实存在**（磁盘 `plugins/serial-monitor/resources/icon.png`），图标栏正常显示（壳侧直读完整 manifest，不走 `list()` 通道）——**同一张图只要把它送进市场就能显示**，`resolvePluginIcon` 对 `src/linkdesk://` 本就支持 `<img>` 彩图（[iconUtils.ts:54-64](../../../../src/components/shared/plugin-icon/iconUtils.ts#L54)）。

## 三、需要什么 / 补什么 / 怎么补 / 补哪里

### 1. 把图标数据送进市场（先修 bug，让现有图标立刻显形）

- **需要**：`list()` 序列化子集补 `icon?`/`iconSource?`（PluginListSubset + 主进程 list 投影同步）；行组件把 manifest 传给 PluginIcon。
- **怎么补 / 补哪里**：
  - [types.ts:189-198 PluginListSubset](../../../../src/core/api/linkdesk-api/types.ts#L189) 加 `icon?`、`iconSource?`（`PluginManifest["icon"]` 型）；主进程 `handlePluginsCall "list"` 投影把这两字段带上（E5.7#98 那次收窄为 7 字段的原始取舍——现在市场要图标，属同通道需扩）。
  - [ExtensionItem.tsx:78](../../../../plugins/marketplace/src/components/ExtensionItem.tsx#L78) → `<PluginIcon pluginId manifest={plugin.manifest} …>`（manifest 有 icon 即显）。
  - 详情页 [DetailView.tsx:577](../../../../plugins/marketplace/src/views/DetailView.tsx#L577) → icon 源改**回退链**：目录 entry 展示图 → 已装 manifest.icon → 默认图标。已装态不再「无目录条目就几何符号」。

### 2. 双图标字段（设计定案落 schema）

- **需要**：插件可声明两枚图标——现有 `icon`（界面简化图，壳图标栏/标签栏零改动）+ 新增可选**市场展示图字段**。
- **怎么补 / 补哪里**：plugin.json 顶层加可选对（名字待拍板，建议 `marketIcon` + `marketIconSource`，形状照抄 `icon`/`iconSource` descriptor；**按定案 5 一律 svg 资产路径**）；缺省 = 未声明则市场回退用 `icon`。schema 各副本（plugin.schema.json 系）同步 + contracts/linkdesk.d.ts 重生成。市场消费 = PluginIcon descriptor 传「marketIcon ?? icon」（先解析 market 再回退 icon，实现时在 resolvePluginIcon 或调用方裁决）。
- **注意（诚实边界）**：06-图标.md「已装不读远程目录图标」守住——已装展示图只来自**包内**（随版本更新），未装展示图来自 catalog（fetch 即新）。两处是同一美术、两条分发路（打包 zip 内 + 目录 json 内）。

### 3. 默认图标 + 每插件 SVG（设计定案落资产）

- **需要**：规定一枚默认图标 SVG（市场展示无图时的统一兜底，替换 📄/几何符号）；给每个插件绘制市场展示 SVG。
- **怎么补 / 补哪里**：默认 SVG 资产 + 消费点（PluginIcon 或市场层 FALLBACK）；逐插件绘制后写 plugin.json（随 SDK 打包进 zip）。绘制须过 ui-ux-pro-max 设计规范、token 化色彩。

### 4. 已装插件「图标不随版本升」边界

- 已装图标随版本更新（06-图标.md 第 3 行）——给每插件补图属于内容变更 → 须 bump 该插件版本 + 随批重建随包 zip（memory `stale-sdk-built-plugin-zip`：动 SDK build 配置/清单内容必重建已提交 zip），否则 boot 同版/异版都不覆盖、永滞旧图（memory `bundled-same-version-no-refresh`）。
