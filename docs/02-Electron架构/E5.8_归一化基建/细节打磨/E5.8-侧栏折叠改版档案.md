# E5.8-侧栏折叠改版档案（#147）

> 2026-08-27。用户拍板（延续 zone 分割线换边适配讨论）：**折叠语义 = 真消失，不是缩成细条**。「不要这个图标（折叠窄条 ▶）了，折叠时候整个侧栏消失」。图标栏已是「点一下聚焦 / 再点收缩 / 再点展开」toggle 语义（VS Code activity bar 对标），**保留**；顶栏「面板」菜单加「切换主侧栏」命令（对标「打开面板」，label「主侧栏」）。#146 只改展开态分割线 handle 方向，本任务改折叠交互——方向问题（折叠窄条 ▶ 换边不跟随）随窄条删除从根上消解。
> **与 #146 同根不同面**：都是「换边后组件未跟随槽位」。本任务直接消解折叠方向的换边问题（没有窄条可适配了）；#146 仍管展开态 handle 位置归一化。
> 清单指针：E5.8-执行清单 Phase 11.22 #147。

**已知取舍（记录，不搭车）**：`collapsed`（窄条）与 `visible`（完全隐藏）双状态在「折叠=消失」后**表现趋同**（都=整个消失）。本任务保留双状态、壳状态机（LayoutEngine/App/持久化）零改动，只改池侧折叠分支表现——护健壮；状态合并（collapsed ≡ visible）留独立专项，不在此搭车。

## 二、8 维度设计前置

> 任务性质：折叠交互改版（非新能力）——删现状折叠 UI + 新增壳命令入口。方向已由用户拍板（折叠=真消失 / 图标栏保留 / 顶栏菜单命令）。

### ① 能力边界
- **壳能力**（池布局折叠交互）。保底零变化——折叠/展开是壳机制，无插件也工作。
- 删的是现状折叠 UI（28px 窄条 + `▶`），改「折叠 = 整个侧栏消失」。

### ② API 设计
- **零新增 `window.linkdesk.*`，契约零变化。**
- 新增**壳命令**「切换主侧栏可见性」（`workbench.action.toggleSidebarVisibility`）——对标 `togglePanel` 先例（[panelCommands.ts:75-82](../../../../src/core/commands/shell/panelCommands.ts)）：命令只做入口，App/壳消费翻转折叠状态 + 持久化。
- 顶栏「面板」菜单加菜单项（label「主侧栏」，对标「打开面板」）——壳 MenuRegistry 招牌，对标 `MENU_SLOTS.Panel` 先例。
- 可选 Ctrl+B 快捷键（VS Code `workbench.action.toggleSideBarVisibility` 对标）——按现状 keybindings 结构加。

### ③ 通信方式
- **零新 IPC 通道**。折叠/展开仍走 `sidebarAction("toggleSidebarCollapse")`（现状）；顶栏命令 = 壳命令 → 同状态翻转；图标栏 `icon:selected`（现状，保留）。

### ④ 壳侧代码设计
- 改动文件（零新文件）：
  - `src/pool/zones/sidebar/SidebarZone.tsx` — 折叠分支改：collapsed → 整个 zone 消失（wrapper display:none，grid auto 列 0 宽），删 28px 窄条 + `▶` 展开按钮分支；内容容器 keep-alive 逻辑保留（display:none 不卸载，视图状态不丢）。
  - `src/pool/zones/sidebar/SidebarZone.css` — 删 `.side-panel.collapsed`（28px 魔法值①）+ `.side-panel-expand` 样式；`◀` 折叠按钮 `.side-panel-collapse` 保留。
  - `src/core/commands/shell/panelCommands.ts`（或 shellMenus.ts）— 加 `workbench.action.toggleSidebarVisibility` 命令 + 「面板」菜单项。
  - 快捷键（可选）— Ctrl+B。
  - 分割线 handle：折叠态随 zone display:none 自动消失（现状 handle 在 visible 条件块内，折叠分支消失后同源）。
- **单一权威**：折叠状态 = 壳（`collapsed` DTO，LayoutEngine → 池）。池只改表现，零状态机改动。
- **硬约束合规**：命令/菜单走壳注册（非插件 ID 硬编码）；label 走 i18n（显示文本铁律）；零颜色/路径改动。

### ⑤ 插件侧代码设计
- **零改动，零贡献点。** 折叠交互是壳机制（zone 分界线/折叠定义，非插件声明）——插件作者不感知。

### ⑥ 显示设计
- 折叠后主区全屏（grid auto 列 0 宽，天然支持——隐藏 zone 内容空 → auto 列 0 宽）。
- 折叠态零 UI 残留（无窄条无按钮）。**视觉方向问题从根上消失**（没有 `▶` 可适配）。
- 展开入口：图标栏（主，现状语义）+ 顶栏菜单命令（显性兜底）+ Ctrl+B（可选）。
- 展开态 header `◀` 保留为折叠出口（VS Code 侧栏 header 无折叠按钮，但 LinkDesk 已有、用户习惯，保留）。

### ⑦ 配置设计
- **零新增配置项，`app.*` 零变化。** 命令走壳贡献（菜单/快捷键，非配置）。
- 折叠状态持久化沿用现状（LayoutEngine → App 落盘，零改动）。

### ⑧ 代码规范 + 验收
- 归一化：折叠交互只此一处（SidebarZone）；展开入口（图标栏/菜单/快捷键）共用同一壳状态，无第二份折叠逻辑。
- 无死代码：删窄条分支 + 28px/48px 魔法值 + `.side-panel-expand` CSS，无残留。
- **验收**：
  1. `npm run check` 全绿（含 #145 机械门禁）。
  2. **CDP 实机**：折叠 → 整个侧栏消失（主区全屏，零窄条残留像素）；图标栏点击展开 → 侧栏出现；再点收缩 → 消失；顶栏「面板」→「主侧栏」命令折叠/展开；header `◀` 折叠；换边后折叠/展开状态正确 + 展开态 handle 位置正确（#146 交叉验证）；三 zone（侧栏/右栏/面板）零回归。
