## 二、「存储」三行齿轮 —— 逐行定稿草案

> 三行的身份（真名以落代码为准）：行1 `app.storage.cacheDir`（缓存位置）· 行2 `app.storage.used`（已用空间，只读）· 行3 `app.storage.clear`（清除缓存，按钮）。
> ⚠️ 行 2／行 3 本轮**暂缓**（见 [00-README.md](00-README.md) §三）；本节整块留档。

### 2.0 前提：齿轮里已经躺着一批通用项

用户看到的那一格，**不是只有我们放的东西**。以「缓存位置」行为例，真机上会是这样（分三组、组间有分隔线）：

| 组 | 菜单项 | 谁放的 | 什么时候出现 |
|:--|:--|:--|:--|
| navigation | 重置此设置 | 壳（通用，所有行） | 这一行被改过时（`settingModified`） |
| navigation | 复制设置 ID / 复制为 JSON | 壳（通用，所有行） | **恒有** |
| （新组） | 打开缓存目录 / 复制路径 /（可能还有）恢复默认位置 | **留给将来** | 见下表 |

⇒ **"给齿轮加东西"的完整效果 ＝ 通用项 ＋ 我们的专用项。** 设计时必须连着通用项一起看，否则就会踩 §2.5 那个打架。

### 2.1 行 1 · 缓存位置 —— 专用项三项（一揽子推荐）

| 菜单项 | 条件（`when`） | 点了干什么 | 为什么值得放 |
|:--|:--|:--|:--|
| **打开缓存目录** | `settingKey == 'app.storage.cacheDir'`（若也想出现在行 3，写成两个键的 `\|\|`） | 主进程解析**当前生效**的缓存目录（配置为空则解析成默认位置）→ 目录不存在就先建 → `shell.openPath`（普通资源管理器窗口，⛔ 不是模态框） | 用户第 ③ 问的原话诉求；零新控件；照抄先例「打开存储位置」 |
| **复制路径** | 同上 | 把**当前生效**的完整路径写进剪贴板 ＋ 弹一条「已复制：…」 | 用户经常要把路径贴到别处；成本极低 |
| （可选）**恢复默认位置** | `settingKey == 'app.storage.cacheDir' && settingModified` | 清掉这一项的设置 **＋ 清掉注册表里的种子** | ⚠️ **只在选乙案时才加**，见 §2.5 |

> 🔴 **「打开缓存目录」必须解析"当前生效"的路径，不许复制一份字符串**——配置为空时它要能算出默认位置。这条是 [01-方案与落点契约.md](01-方案与落点契约.md) §三 铁律 3 的落点。
> 🔴 **点「打开」时目录可能还不存在**（刚装完、还没跑过软件）：**先建再开**，别弹"找不到"。

### 2.2 行 2 · 已用空间 —— 推荐：**不放任何专用项**

| 候选 | 建议 | 理由 |
|:--|:--|:--|
| 「刷新」 | ❌ 不要 | 这个数字**每 3 秒自己刷**（事实 7）。放「刷新」＝告诉用户"它不会自动更新"，是误导 |
| 「复制已用空间」 | 🔵 可有可无，**默认不加** | 值本身没什么可粘贴的用处 |
| 通用「复制为 JSON」 | ⚠️ **照旧留着，但要如实记一笔** | 在只读行上它复制的是**配置里存的值**（通常是空的），**不是屏幕上那个数字** ⇒ 天然误导。这是壳的既有行为、**全软件所有只读行都这样**，⛔ **不在本件改**（改它＝动通用件，属另一件事），本件只登记这条事实 |

⇒ **行 2 的齿轮 ＝ 只有通用项，我们不加东西。**

### 2.3 行 3 · 清除缓存 —— 推荐：**只借一项「打开缓存目录」，其余不加**

| 候选 | 建议 | 理由 |
|:--|:--|:--|
| 「打开缓存目录」 | ✅ **加**（与行 1 是**同一个命令**，只是 `when` 多认一个键） | 清之前想看看里面有什么、清之后再打开确认 |
| 「清除缓存」也塞进齿轮 | ❌ 不要 | 它在**行上已经有一颗大按钮**了；重复放 ＝ 同一动作两个入口 |
| 任何危险项（红色 `delete` 组） | ❌ 不要 | 齿轮是**hover 才显形**的角落（事实 5），不该藏不可逆动作 |

> ⚠️ **一条明确的界限**：齿轮里的东西**不算"主要入口"**。硬约束 26 要求「每个用户动作至少一条非鼠标路径」——这条靠**把动作注册成命令**满足，**不是靠齿轮**。所以「打开缓存目录」即使只住在齿轮里，也必须是一个**正经注册的命令**（规格见 §2.6）。

### 2.4 行 3 的按钮文字与长解释放哪（06 图的待改处）

真实渲染器的规矩（事实 8）：**动作行的按钮文字 与 行的副标题 是同一个字段**（`description`）。

- 若把长句「清除缓存（只清可再生的临时文件，不动插件与设置）」当 `description` ⇒ 这一行里**同一句长话出现两遍**，按钮还会特别宽。
- **推荐写法**：行 `description` ＝ **「清除缓存」**（短；重复两遍不刺眼）；长解释搬到**「存储」分节的 `groupDescriptions`**（事实 9 的正式落点）：
  > 缓存目录只放可再生的临时文件；清除只清这些，**插件与设置一律不动**。
- ⇒ 06 图那两颗"长按钮"将来要改画——**但图先别动**（等对应功能真做时一起改）。

### 2.5 【★ 核心】通用「重置此设置」与注册表种子会打架

**问题怎么来的**：

```
装的时候你选了 D:\cache      → 安装器把 D:\cache 写进注册表（= 种子）
第一次开软件                  → 软件里还没值 ⇒ 采用种子 ⇒ 设置里显示 D:\cache    ✅ 这一步是对的
你在设置里点通用「重置此设置」 → 设置被清空（= 回到"没设过"）
下次开机                      → 软件里又没值了 ⇒ 又采用种子 ⇒ 又变回 D:\cache     ❌ 弹回来了
```

⇒ 用户会得出「我改了没用 / 这软件有问题」的结论。**这是必须定掉的分叉**，三个解法：

| 案 | 做法 | 代价 | 评价 |
|:--|:--|:--|:--|
| **甲案（推荐）· 种子一次性** | 启动读种子的那一次，**读完就把它从注册表删掉**（无论采用与否）。之后"重置"就真是回到默认了 | 要写一个"消费种子"的动作；注册表不再长期保存"安装时选了什么" | **最少的新增件**：不加菜单项、不加命令、不加 IPC。且与契约精神一致——「只有一处权威」 |
| **乙案 · 留种子 ＋ 专用项** | 注册表保留种子；新增齿轮项「恢复默认位置」（清设置 ＋ 清种子）；**同时**把通用「重置此设置」在缓存位置这一行隐去（给通用项的 `when` 加一条排除） | 多一条命令 ＋ 一条 IPC ＋ 动通用项的 `when` | 好处是**文案直白**（"恢复默认位置"比"重置此设置"清楚） |
| 丙案 · 只加专用项，通用项不动 | ❌ **不推荐** | — | 用户点了通用那个 → 设置清了、种子还在 → 下次开机弹回来。**就是上面那个 bug 原样留着** |

### 2.6 三个新菜单项的命令规格（将来实现期照抄）

| 字段 | 打开缓存目录 | 复制路径 | （乙案才要）恢复默认位置 |
|:--|:--|:--|:--|
| 命令 id | `workbench.action.openStorageCache` | `workbench.action.copyStorageCachePath` | `workbench.action.resetStorageCacheDir` |
| 标题（菜单上显示） | 打开缓存目录 | 复制缓存目录路径 | 恢复默认位置 |
| 分类 | 首选项 | 首选项 | 首选项 |
| 说明（AI 读的那句，必填） | 在系统资源管理器中打开缓存目录（当前生效的位置） | 把当前生效的缓存目录完整路径复制到剪贴板 | 把缓存目录恢复为默认位置（并清掉安装时写入的种子） |
| 参数 | `{ settingKey: string }`（照 `SETTING_KEY_PARAM` 共用常量） | 同左 | 同左 |
| 菜单槽 / 分组 | `SettingItemGear` / `navigation` | 同左 | 同左 |
| `when`（菜单门控） | `settingKey == 'app.storage.cacheDir' \|\| settingKey == 'app.storage.clear'` | `settingKey == 'app.storage.cacheDir'` | `settingKey == 'app.storage.cacheDir' && settingModified` |
| 干活的地方 | 走壳 IPC（主进程解析路径 → 建目录 → `shell.openPath`） | 渲染层剪贴板服务 ＋ 一条提示 | 清设置 ＋ 走壳 IPC 清注册表种子 |

> ⚠️ **一个代价，如实告诉你**：因为 `when` 是**命令和菜单项共用的同一个字段**（事实 12），带 `settingKey` 门控的命令**在命令面板里搜不到**（事实 11）——先例「打开存储位置」今天也是这样。影响 ＝ 普通用户没法从命令面板找到"打开缓存目录"，但 **AI 可以照常调用**。
> 若想让它在命令面板也能搜到，需要给壳的命令注册循环**补一个"菜单专用条件"字段**（约 3 行）——属**动核心注册机制**，默认**不做**，列在这里供将来选。
