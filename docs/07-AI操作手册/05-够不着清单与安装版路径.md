# 05 · 够不着清单 + 安装版操作路径

> 两件事：① **哪些事 LinkDesk 里从来没有门**——如实列册，别拿模拟点击硬凑；
> ② **在用户机器的安装版上**怎么起、怎么装、怎么改配置（没有源码树时你只有这几条路）。

## 一、够不着清单（A 类：⛔ 不承诺能做到）

| 类别 | 具体 | 为什么够不着 | 替代路径 |
|:--|:--|:--|:--|
| **① OS 层窗口几何** | 把窗口**移到屏幕某个坐标**、贴边、改窗口尺寸 | `window` 命名空间只有 `minimize/maximize/unmaximize/close/setZoom/toggleDevTools/isMaximized/onMaximizeChange/setAlwaysOnTop/isAlwaysOnTop/onAlwaysOnTopChange`——**没有 `moveTo` / `setBounds`**。位置与尺寸由用户拖动 OS 窗口产生 | 能做的都在上面那 11 个方法里（最大化/最小化/置顶/缩放/关闭）；要「放到某坐标」= 用户的事 |
| **② OS 拖放（跨程序）** | 从**资源管理器**把文件拖进窗口；从窗口把文件拖到别处 | 走 OS 层 DnD：壳给的 `getFilePath(File)` 是「**别人发起拖放时**拿路径」的接收口，不是「**你发起**拖放」的发射口 | 文件用**路径**直开：`tabs.create("editor", { filePath })` / `filesystem.readTextFile(path)`；导出/另存走 `dialog` |
| **③ 系统文件对话框** | 去点原生「打开/保存」对话框 | 那是**另一个进程的原生窗口**，不在任何 WebView 里，没有任何契约能碰 | 🔴 唯一的门是 `dialog.openFile()` / `dialog.open()`——**它替你弹**，用户选完把路径交回给你；无人值守时**改成路径参数化**（路径你自己填） |
| **④ 指针依赖的手势** | 拖拽分屏/跨窗、hover 才出现的按钮、双击固定… | 相位与阈值门控（[04 章](04-手势隐藏规则.md) 一表）＋ CDP 合成事件坐标不可靠 | 每个手势都有命令替身——见 [04 章 §一](04-手势隐藏规则.md) 总表 |
| **⑤ 软件之外** | 改系统主题、装驱动、操作别的软件的窗口 | 不在 LinkDesk 范畴 | 如实说明超出范围 |

**纪律**：遇到 A 类请求 ⇒ **如实说够不着 ＋ 给替代路径**；⛔ 不要用模拟点击/伪造坐标硬凑，
更不要把「凑出来的结果」说成结构化操作（[01 章 §五](01-操作路径总览.md)）。

## 二、安装版操作路径（在用户机器上干活）

### 2.1 启动（要调试口时）

```bash
LinkDesk.exe --remote-debugging-port=9222
```

- **安装版同样有效**——不必是开发模式。开发模式（`npm run electron:dev`）本身就开着 9222，
  且**壳与池是两个独立 target**（要分别连，见 [06-CDP坑表](06-CDP坑表.md)）。
- 不传这个参数就**没有**调试口（不是「端口没开」，是没有可连的目标）。

### 2.2 静默安装 / 升级

```bash
linkdesk-setup-0.2.21.exe /S
```

- 产物名 = **`linkdesk-setup-{version}.exe`**（`electron-builder.yml` 的
  `artifactName: "${name}-setup-${version}.${ext}"`；⚠️ 是 `${name}` 不是 productName——大小写在 URL 场景敏感）。
- `/S` = **全程无 GUI**、按用户安装（per-user）、**不弹 UAC**。
- 静默装完**不会**自动带调试参数启动——要连着调就用 2.1 手动起一次。

### 2.3 userData 文件面（不开界面也能改）

| 要改什么 | 改哪 | 生效时机 |
|:--|:--|:--|
| 任何设置项 | `{userData}/settings.json` | 改完约 **80 ms** 生效（真机读数）——**不用重启** |
| 安装插件 | 把插件压缩包放进 `{userData}/plugins/` | 启动时被插件加载器扫到并安装 |

- 🔴 **Windows 上设 `APPDATA` 环境变量不管用**——Electron 用 `SHGetKnownFolderPath` 取真实路径，
  不看环境变量。要一份独立配置（做对照实验、留回滚现场），**`--user-data-dir=<路径>` 才是唯一的真隔离手段**：
  ```bash
  LinkDesk.exe --user-data-dir="D:/tmp/ldk-lab" --remote-debugging-port=9222
  ```
- 改 `settings.json` 是「绕开界面」的正路（尤其当某设置项**没有**对应命令/API 时）；
  但改完要**读回来验**（`configuration.get(key)` 或看界面），别只写不读。

### 2.4 🔴 自动更新之后：调试口会掉

- 更新安装器由 `app.relaunch({ execPath, args: ['/S', '--force-run'] })` 拉起
  （`electron/services/update-install.ts`）——**args 显式给全、不继承当前命令行**
  ⇒ **重启后 CDP 调试口丢失**：你约好的 9222 连不上，**这不是软件崩了**。
- 目前**没有**自动恢复通道（＝台账 M5 `AI#17`）。当下做法：更新完再用 2.1 起一次；或更新前先把手上工作收尾。

## 三、判据小结（遇到新场景时怎么判）

| 情况 | 结论 |
|:--|:--|
| `getCommands()` 里有命令，或契约 API 有方法 | ✅ **能做**——走结构化路径 |
| 只有手势能做 | ⚠️ **用手势的命令替身**（[04 章](04-手势隐藏规则.md)） |
| 属于本清单 §一 A 类 | ⛔ **够不着**——如实说，给替代路径 |
