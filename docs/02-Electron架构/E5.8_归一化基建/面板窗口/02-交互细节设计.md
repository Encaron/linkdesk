## §5 用户场景走查（逐 I 编号对照）

### 场景 1：设置链——悬浮面板 → 标签页 → 拖出窗口（唯一路径）

1. Ctrl+, → 弹 B 面板（I8-1）✅
2. 面板内「打开编辑器」→ 面板关闭 + 设置变标签页（I8-4；代价 = unmount 丢未保存输入，I8-11 已接受）✅
3. 标签页拖出主窗口 → D 窗口（I9-1；代价 = 再 remount，I9-3——设置值持久化兜底，**链全程成立**）✅
4. 关窗 × → 设置回归主窗口标签页（I9-9）✅
5. 回程到面板：设置已是标签页时按 Ctrl+, → 聚焦标签页（I8-3 待拍板）；右键「在悬浮面板中打开」→ T → B（I8-3 待拍板）⚠️

### 场景 2：两 tab 拖出并窗 + 逐个拖回自灭（用户本轮点名）

1. 拖出 tab A → 窗口 W1（I9-1）；拖出 tab B → 窗口 W2（I9-1）——两个独立窗口 ✅
2. 拖 W2 的 tab B 靠近 W1 **标签栏** → W1 TabBar 亮吸附提示（I9-4 光语言指示）→ 放手 → **W1 = 两 tab 一窗**，W2 空 → **自灭**（I9-8）✅
3. W1 内分屏（B 拖到 A 右侧 → branch）——同代码零新渲染（I9-5）✅
4. 逐个拖回：拖 tab B 回主窗口 → 只回 B（I9-7）；W1 剩 tab A；拖 A 回主窗口 → W1 **自灭**（I9-8）✅
5. 窗口 chrome：全程每个 D 窗口有 ×/最小化/最大化（I9-11 待拍板方案）⚠️
