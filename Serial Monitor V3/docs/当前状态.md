## 一、项目概况

V3 是 V2 的重架构——保持 V2 全部功能，底盘从 WPF .NET 8 换成 Tauri + React。

| | V2 | V3 |
|------|------|------|
| 框架 | WPF .NET 8 | Tauri v2 + React 18 + TypeScript |
| 接收区 | AvalonEdit | CodeMirror 6 |
| 发送栏 | 多行 TextBox | Monaco Editor 单行 |
| 主题 | DynamicResource | CSS 变量 21 色 |
| 双语 | 自研 T() 函数 | react-i18next `t()` |
| 串口 | C# SerialPort | Rust serialport + tokio |
| 协议 | `[type, subType, ...]` | `[卡片ID, 字段...]` |

### 布局（Phase 3 更新——对标 VS Code）

```
┌──────────────────────────────────────────────────────┐
│ TopBar：串口选择 / 波特率 / 打开 / 中:EN / ☀ / ?       │
├────┬──────────┬──────────────────────────────────────┤
│    │          │ TabBar：[📟 终端] [📊 PID]  [+]       │
│ 📟  │  侧栏    ├──────────────────────────────────────┤
│ 📊  │  220px  │                                      │
│ ⚙   │  可拖拽  │  主内容区                             │
│    │  可折叠  │  （标签页 keep-alive / 分屏 SplitPane） │
│    │  一通到底 │                                      │
├────┴──────────┴──────────────────────────────────────┤
│ ● 已连接 │ TX:1,234  RX:56,789                        │
└──────────────────────────────────────────────────────┘
```

**布局要点：**
- 图标栏（42px）和侧栏（220px 可拖拽，28px 折叠）从顶栏下**一通到底**——对标 VS Code
- 标签栏仅覆盖主区上方，不横跨图标栏和侧栏
- 活跃标签页底部无分隔线，和内容区融为一体（同色 `var(--bg-window)`）
- 标签页进出有 150ms/120ms CSS 动画
- 分屏：纯 CSS grid + 可拖拽分割条（20%-80% 范围），resize 中冻结 CM6 防闪烁

### 基础设施（V2.6 教训）

- **CSS 变量 21+4 色**：所有颜色走 `var(--xxx)`，Phase 3 新增 `--tab-hover-bg` 等 4 个变量
- **ThemeEngine**：JSON 主题文件 → CSS 变量，用户和 AI 都改 JSON
- **react-i18next `t()`**：全部 UI 文字走翻译函数，`en.json` 已就绪
- **归一化 `.form-row`**：标签+控件行强制对齐
- **组件不从 JS 设颜色**：切主题 = 改 `data-theme` 一个属性

| 模块 | 功能 | 测试 |

| DataConverter | Bytes↔Hex↔Text | ✅ |

### Rust 串口层

| 命令 | 功能 |
|------|------|
| `list_ports` | 枚举 COM 口 |
| `open_port` | 打开 + 启动 tokio 读线程 |
| `close_port` | 关闭 + 冲刷残留 |
| `send_data` | 发送字节 |
| `set_dtr` / `set_rts` | 硬件流控 |
| 读线程 | 100ms 超时 → `\n` 拆行 → emit `serial-data` |

### 数据管道

```
STM32 → Rust serialport 读线程 → emit("serial-data")
→ React listen → RingBuffer.write() → rAF drainAll()
→ CM6 appendLine(三色) → 暂停/搜索/导出/裁剪
```

### 已知限制（不影响使用）

| 项目 | 说明 |
|------|------|
| 标签栏内拖拽重排无平滑过渡 | 需要 FLIP 动画库，目前瞬间交换 |
| 标签页多时无横向滚动箭头 | 滚动条隐藏但滚轮可用 |

### Phase 3 关键架构决策

| 决策 | 说明 |
|------|------|
| **图标栏只聚焦不循环不创建** | 📟/⚙ 隐式创建，📊 不创建（tooltip 引导）。点击行为可预测，不依赖 tabs[] 顺序 |
| **CSS display 切换 keep-alive** | 所有标签页同时挂载，`display:none/flex` 控制显隐。CM6 + Monaco 状态不丢 |
| **独立 RingBuffer** | 每个标签页各自调用 `useTauriEvent`。Phase 3 预期 ≤5 标签页，无需 Pub/Sub |
| **2-pane 分屏** | 仅左右/上下分屏，不支持 3-pane 嵌套。V3 不是 IDE |
| **SplitPane 纯 CSS** | 不用 allotment（零外部依赖、无 StrictMode 问题）。`grid-template-columns: X% 4px 1fr` |
| **Phase 3→4 硬约束** | 标签页系统永远不持有/访问/导入 `CardRegistry`。唯一接触点 = `Tab.workspaceName: string` |

## 六、V3 踩坑记录

见记忆系统 `v3-pitfalls.md`。

Phase 3 新踩坑：
- **B4 布局塌陷**：`.app-shell` 用 3 行 grid，TabBar 作为第 2 子元素抢了 `1fr` 行，`.app-body` 被挤到底部。修法：TabBar 移入 `.editor-area`，grid 回到 3 行
- **B5 右键活跃标签页分屏无反应**：`reduceSplitTab` 在 `tabId === activeTabId` 时拒绝分屏。修法：自动找下一个标签页配对
- **B6 SplitPane resize 性能**：`localSizes` 在 useEffect deps 中导致每像素重注册。修法：用 ref 读取最新值
