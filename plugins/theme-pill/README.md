# 全胶囊

所有圆角拉满的泡泡糖主题——**极限壳主题**，压的是 `radius` 域。

## 这是什么

一只**纯数据插件**，演示的是主题系统里的**形状轴**：圆角八档全部拉到 `999px`，于是按钮、输入框、标签、面板统统变成胶囊/圆球；再配上留缝、投影和一圈发丝光边，整扇窗变成一堆浮起来的气泡。

- 插件 ID：`theme-pill`
- 系统类型：亮色（light）
- 色板：泡泡糖
- 压的是：`radius` 域（全胶囊 + 悬浮形态：留缝 / 圆角 / 投影 / 发丝光边）

> 它存在的意义：**证明主题能改形状，不只是颜色。**

## 结构

```
plugin.json                    声明（contributes.themes）
themes/pill-bubble.json        色板（含圆角与悬浮形态设定）
```
