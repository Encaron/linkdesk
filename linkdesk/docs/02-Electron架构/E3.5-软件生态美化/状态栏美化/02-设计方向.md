## P0-1：文字对比度提升（StatusBar.css ~5 行）

**问题：** `--text-muted` (#777) 在深色背景上对比度仅 4.4:1，低于 WCAG AA 下限。

**改：** 状态栏基色从 `--text-muted` 提到 `--text-secondary`。

```css
.status-bar {
  /* color: var(--text-muted); */  /* 删 */
  color: var(--text-secondary);    /* #999——对比度 ~7:1，WCAG AAA */
}
```

联动：`.status-bar-btn` 基色也提到 `--text-secondary`。

```css
.status-bar-btn {
  /* color: var(--text-muted); */
  color: var(--text-secondary);
}
```

## P0-2：分割符改用 CSS 画线（StatusBar.tsx + CSS ~5 行）

**问题：** `│` 文本字符做分隔——CSS 画线代码写了但被文本撑破，成死代码。

**改 TSX：** span 清空内容，纯 CSS 画线。

```tsx
// 改前
<span className="status-divider">│</span>

// 改后
<span className="status-divider" />
```

**改 CSS：** 去掉多余标记，纯背景画线。

```css
.status-divider {
  display: inline-block;
  width: 1px;
  height: 14px;           /* 12px → 14px——稍高一点不显小气 */
  margin: 0 8px;           /* 6px → 8px——项目间呼吸感 */
  background: var(--separator);
  vertical-align: middle;  /* 🆕 垂直居中 */
}
```

## P1：Theme/Lang 按钮改 codicon（StatusBar.tsx ~5 行）

**问题：** `☀`/`☾` Unicode 跨平台渲染不一致，Windows 某些字体下是方框。

```tsx
// 改前
{theme === "Dark" ? "☀" : "☾"}
{lang === "zh" ? "中" : "EN"}

// 改后
<span className="codicon codicon-color-mode" />     // 主题——调色板图标
<span className="codicon codicon-globe" />           // 语言——地球图标
```

按钮需要 tooltip 来补充文字信息：

```tsx
<button className="status-bar-btn" onClick={onToggleTheme}
  title={`${t("切换主题")} (${theme})`}>
  <span className="codicon codicon-color-mode" />
</button>
<button className="status-bar-btn" onClick={onToggleLang}
  title={`${t("切换语言")} (${lang === "zh" ? "中文" : "English"})`}>
  <span className="codicon codicon-globe" />
</button>
```

## P3：错误信息 fade 过渡（StatusBar.css ~5 行）

```css
.status-error {
  /* ...existing... */
```

> 需要 React 侧配合——error 从 null→string 时，先设 opacity:0 再下一帧切到 1。或者用 CSS `@keyframes` 自动触发。简单方案：加 `animation: statusFadeIn 200ms`。
