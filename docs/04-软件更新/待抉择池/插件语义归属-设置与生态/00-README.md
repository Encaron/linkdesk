## 三、判据（详见 02-落位/01）

> **语义归属律**：一个行为的「默认值 / 约束 / 权限 / 路径」由能力所有者声明；UI 插件只做呈现与触发。
> **替换测试**：把该 UI 插件整套换成第三方实现，行为还在不在？不在 ⇒ 住错了层。
