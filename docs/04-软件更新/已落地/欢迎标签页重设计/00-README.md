# 欢迎标签页重设计（serial-monitor 时代遗老 → 与软件当前身份对齐）

> **状态：🟢 已拍板 · 待开工**（2026-10-01 七项决策全拍，记录见 §四）——现状问题已逐条对到代码（`01-设计.md` §一，12 条全带 file:line）、设计前置已过（8 维度 §二）、设计稿已出并经用户过图**通过**；任务安排见 [02-执行清单.md](02-执行清单.md)（T1–T14 五批）。
> 缘起（2026-10-01）：用户实测挑出欢迎页一批问题（原话 12 条，§一逐条对账）——标语还是「通用调试容器」、开始区全部恒显 📄 无真图标、帮助区两行死文案点不动、最近区对已删除文件零反馈、「+」和帮助菜单都没有欢迎入口。结论：**欢迎页没跟上软件的身份演变**——软件已从「通用调试容器」长成「一个容器，装下你所有的工作方式」（关于页 v0.2.18 已换新），欢迎页是最后一个没换脸的壳级页面。

## 一、这是什么 / 不是什么

- **是**：壳兜底欢迎页（`src/pool/views/welcome/`，`tabBehavior.isFallback`）的**数据面 + 交互面 + 观感**整体翻新。它不是插件，是壳级页面——「卸载所有插件后还能用吗」判据恒成立，翻新后同样成立。
- **不是**：① 不动标签页系统架构（保底逻辑 `ensureFallback` 保留）；② 不做「项目管理器」（那是待抉择池另一件，`.linkdesk-project/` 方向）；③ 不新做用户文档站（「使用文档」短期用 toast 过渡，长期归 [发行后-帮助菜单待补项](../../待抉择池/发行后-帮助菜单待补项.md)）。
- **归属确认**：壳侧代码（`src/`）⇒ 04-软件更新，随攒批发版；连带一笔 `plugin-sdk` schema（W2 准入字段）走作者轴 npm，同批发。

## 四、拍板记录（2026-10-01，用户选择题形式逐项拍定）

1. **设计稿**：✅ **通过，按稿开工**（三场景＋明暗四态浏览器实开验证过）。
2. **W2 缺省方向**：**缺省 `false`（白名单制）**——未声明的视图不进「开始」卡、也不进「+」菜单（同源同判据）。⚠️ **breaking 如实记**：① 官方各仓（终端/Git/串口监视器/设置等）需同笔补 `standaloneOpenable: true` 并各走发版＋官方目录收录＋种子追新；② 第三方插件未声明则从这两面消失 ⇒ 作者面文档＋SDK 版本说明公告；③ 编辑器**不声明**＝自然退出「开始」（它自做缺省空态页后可改声明 true，转达该仓自决）。
3. **关闭 ×**：**保留可关**（三个重开入口落地后 × 不再是陷阱；点 × 自动重生等效重置）；`windowLayout.ts` 把 isFallback 如实映射进 closeBehavior，消除与 tabIdentity「不可关闭」注释的矛盾。
4. **toast 通道**：**新通用 toast 契约**（用户确认要右下角静默 toast；「契约」指触发通道不是另一种呈现）。详查后落定形＝**复用既有 `linkdesk.notifications.show()` 加呈现选项 `toast?: boolean`**（该通道 type/persistent/actions 已齐，插件今天就能发通知；缺省 false = 现有通知面板行为不变）＋ 池侧新建自动消失轻提示层（⚠️ 池侧旧右下卡是有意整删的——StatusBarZone.tsx:12「本面板是唯一通知面」——新层是新形态非复活旧卡，开工前读该注释）。
5. **「使用文档」过渡**：toast **指路 AI 手册**——「用户文档整理中——先看『帮助 → AI 操作手册』（随包发货、离线可读）」；点按不直接开手册（名实有别）。
6. **水印**：**正典实心淡显**；「程序图标」档案 §0.1.4 遗留一句话小事并案销账。
7. **（追加拍板，2026-10-01）零标签空场**：用户提议并拍板——「不要欢迎页保底了，我们有打开欢迎页的方式了」：关光标签页 ⇒ 主区**空场背景**（大实心 logo＋LinkDesk 字标），不再是自动重生的欢迎页标签。**本项覆盖 §四3 中「点 × 自动重生等效重置」的行为**（重生取消；× 保留可关照旧，关光即空场）。详案与风险面见 01-设计.md §三 W7。**字标字体用户指定（照录）**：`font: 400 46px/1.1 'Newsreader','Lyon Text',Georgia,'Songti SC','SimSun',serif; letter-spacing:-0.03em` ＋ `.hero h1 em { font-style: italic }`（强调词斜体衬线）——落点 = 新派生 token `--font-mark`（app.fontFamily 显式设置 = 跟随，未设 = 该衬线栈）。
