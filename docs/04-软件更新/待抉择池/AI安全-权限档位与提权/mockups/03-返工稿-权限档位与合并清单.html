#你反馈的问题这版怎么处理
1切英文后权限档位仍是中文，点一下才变不再把「已经翻译好的字符串」缓存进组件；共享件直接拿 i18n key 渲染，语言变化即重绘（徽标同理）。
2「当前权限一览」多余删除整行；档位块下方只保留一条紧凑的能力摘要。
3打勾符号像 emoji去掉符号，改成「允许 / 询问 / 不允许」文字＋语义色；全局文案禁用 emoji（并加机械检查）。
4完全访问通知不自动消失、要清两次通知改为 8 秒自动收起；同一事件按来源去重只留一条；面板不再堆积重复项。
5完全访问时档位块太高（五行）压到两行：四段控件＋一行说明；完全访问时说明行换成一条告警＋「恢复默认」文字按钮。
6这些按钮是壳提供的还是插件自己画的？选择器是共享件（`@linkdesk/ui`），设置插件只做接线；行/按钮由设置插件的通用行渲染。换一套设置插件仍能用同一个选择器。
7完整风险表贴边、按钮是透明小按钮弹窗统一 24px 内边距；主按钮改用标准实心按钮（同「完整操作清单」的确定按钮）。
8完整操作清单里全是 M1 AI#3 这类内部编号命令说明全部改成用户语言；内部编号不进 UI。清单合并进弹窗并重新生成。
9设置显示「逐次确认」，状态栏却是「AI 只读」徽标改为从配置变更事件直接取值（不再回读文件），并与设置页共用同一份档位数据；语言变化也即时更新。
10文档里「红色禁止符号」这类写法容易误解文档与 UI 全面禁用 emoji；改用「禁止 / 注意 / 允许」等文字标签，并加机械检查防止复发。
11设置 ID `ai.policy.mode` 会不会让 AI 自己升档它是配置键，不是命令。AI 写 `ai.*` 配置一律被拒；切档命令标记为「仅限用户」，AI 调用会被拒；没有任何「批准」入口。
12接入凭据是什么AI 客户端连接用的凭据（原有能力）。说明改成一句话，按钮改成「重新生成…」。
13完整风险表 / 当前权限一览 / 开放范围明细 / 完整操作清单 / 细分管理重复合并为一行「AI 能做什么」＋一个弹窗（全部操作 / 敏感能力两个页签）。导航项从 21 项降下来一截。
14文案太口语（「AI 连请求入口都没有」等）全部改成书面语；删掉解释实现细节的句子。
