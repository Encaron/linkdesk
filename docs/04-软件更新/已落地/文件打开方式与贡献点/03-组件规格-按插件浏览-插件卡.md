## 2 · Props 契约（正表）

```ts
interface PluginCardProps {
  pluginId: string;                 // 身份＋副文本第二行（title 过长时 id 是唯一稳定识别物）
  manifest?: ManifestIconShape;     // 透传 PluginIcon——图标唯一裁决源；缺省 → PluginIcon 自兜底
  title: string;                    // 显示名；调用方 t() 后传入（共享件零中文，SourceBadge 先例）
  version?: string;                 // 副文本「id · v1.2.0」
  summary?: ReactNode;              // 常驻摘要（折叠/展开都在）：如「声明 45 类 · 竞争 12 类」——管理器组装（「竞争」口径 = [02 E40](02-边缘情况清单.md)，⛔ 不新造第二套说法）
  expanded: boolean;                // **受控**——展开状态归管理器（搜索联动 M6、批量开合都要求外部持有）
  onToggle(next: boolean): void;
  gearItems?: MenuItem[];           // 卡头齿轮菜单（形状照共享 ContextMenu 既有契约）；缺省 = 不渲染齿轮
  disabled?: boolean;               // 插件停用：卡体降不透明度＋「已停用」徽标，行与动作全部惰性（E5）
  toolbar?: ReactNode;              // 加性扩展（2026-10-06）：卡头与卡体之间的**通用工具条槽**——零业务语义，⛔ 组件不含过滤/排序实现（阈值等策略归组装方）
  children: ReactNode;              // 展开体（行清单）——管理器自组
}
```

- 受控 `expanded` 是有意为之：开合策略（默认全收、搜索命中自动展开等）是**管理器策略**，不是组件策略。
- **加性扩展 `toolbar`（2026-10-06，⛔ 不改写上文）**：`ReactNode` 通用槽，落 `.ldk-plugin-card-toolbar`（**卡头与卡体之间一行**）；🔴 **槽是卡头全宽 `<button>`（`.ldk-plugin-card-toggle`）的兄弟、⛔ 绝不嵌进按钮**（嵌套按钮禁令）。出处 ＝ [已落地/默认打开方式管理器共享化](../默认打开方式管理器共享化/00-README.md) **C5 定案**（首消费方＝设置插件管理器卡内过滤＋排序：`InlineInput`／`SelectBox`，两件都是既有共享件）。
- 状态徽标（已停用/核心）复用共享 `Badge`；`core` 语义照硬约束 11（= 界面不给卸载按钮，**不是**「属于壳」）。

## 3 · 卡头规格（关键实现细节）

- **尺寸**：头高 40px；图标 24×24 圆角 6（`PluginIcon` className 控——与 08 pdot 同尺寸，2026-10-04 解析板定稿）；标题 13px/600；副文本 11px muted（`id · version`，超长省略＋`title` 全文）；齿轮 24×24（右缘内缩 8px）；折角 16px。⚠️ **第 4 波改判（2026-10-05）**：`title` 全文**不走原生 `title=`**（壳门禁判红），改 `data-hint`（`HINT_ATTR`＋延时 0）；副文本实际格式 `id · v1.2.0`。
- **嵌套按钮禁令的解法**：头里有「整头可点（展开）」和「齿轮」两个热区——**不得** button 套 button（非法 HTML）。规格：`plugin-card-head` 是 div，内含①铺满的 `plugin-card-toggle`（真 `<button>`，`aria-expanded`＋`aria-controls` 指体 id）②绝对定位叠在其上的 `plugin-card-gear`（z-index 高一层，兄弟节点——点击天然不冒泡到 toggle）。
- **齿轮菜单**：共享 `ContextMenu` **非模态锚定变体**（E5.8#92 同款——不吞首击），锚 = 齿轮矩形下方 +4px，与 SettingRow 行齿轮完全同款（`SettingRow/gearMenu.ts` 是参照实现）。
- **齿轮菜单 · 载荷律（对外契约，2026-10-05 第 4.5 波补）**：本件固定送**自己的** `context = { pluginId }`（`PluginCard.tsx` 的 `ContextMenu context=` 槽）。⇒ 消费方 handler 收到的是 **`args = [...commandArgs, context]`**：**每项的身份必须走 `commandArgs`**，末尾恒为本件的 `pluginId`；⛔ **不要假设 `args[0]` 是你的数据**（除非该槽位无共享 context）。条文真源 = 作者手册 [22 菜单贡献点](../../../03-插件制造/22-菜单贡献点.md) §载荷 ＋ [05 插件 UI 写法规约](../../../03-插件制造/05-插件UI写法规约.md)（中英同笔）；纠正案原文 = [02 §二](10-纠正案-共享件转正与归一/02-归一化-齿轮锚点与假菜单项.md)。✅ 本波实施即照此（设置页竞争行菜单项：`command: SHELL_COMMANDS.openWith` ＋ `commandArgs: [{ ext }]`）。
- v1 菜单项（修正 08 的 M4 示意）：①**清除相关默认覆盖**（＝本插件声明范围内全部覆盖键批量 `setDefault(ext, null)`——无论当初指向谁、含单家锁定，计数随显；零覆盖则置灰）②**复制插件 ID**（剪贴板面**阶段 0 勘察**——keybinding 视图有复制先例则同款，无则本项 v1 砍掉，不留死钮）。③~~打开插件详情~~——**壳现无承载命令（已查空），v1 不含**，待壳有「插件详情」承载另案挂账；09 图同步修正。
- hover 出齿轮＝SettingRow 同款机制（`opacity:0` → 头 hover 显形），键盘焦点到达齿轮时**恒显**（不只 hover）。

## 4 · 展开体规格（行 = 可操作控件，不是说明书——2026-10-04 用户纠偏定稿）

> 初稿把行做成「只读徽标＋hover 才现的文字钮」被用户否决：徽标表状态、**下拉才是控件**，两件事不捏在一起；hover-only 依赖也是 ui-ux-pro-max 反模式。权威样张 = mockups/09。

- **行高 30px**；左列扩展名 12px mono 照抄**归一后的存储键**（声明 `.MX` → 显示 `.mx`，E10/E34 零语义）；中列**状态徽标**；行尾**行内下拉＝主控件**（共享 SelectBox/Combobox）。
- **状态徽标四态＋一异**：①「默认（自动）」本插件是激活序自动胜者；②「当前默认（用户指定）」覆盖表指向本插件；③「候选 · 默认：X」本插件落选；④「唯一处理者（自动）」单家类型（E29，只出现在卡里）；异态「失效覆盖」（红）＝覆盖表仍指向已卸载插件——解析已回声明序但**键保留**（E6 惰性，重装复活），状态可见而非静默。
- **行内下拉选项** = 「自动」＋全部候选插件——**控件标签只写「自动」**，机制（覆盖表无键时按激活序取首候选）进说明文字与作者文档，⛔ 口语机制短语不进 UI（用户 2026-10-04 文案纪律）；**控件显示覆盖态而非生效态**（否则「显式重选当前胜者=锁定」无法触发 onchange）；单家类型选项=「自动＋自己」，显式选自己＝**锁定防漂移**（E35：未来第二家进来不漂移，E2 同机制零新规则）。
- **下拉挂现成共享件**（⛔ 不私造第二只）：`SelectBox`/`DynamicSelect`（@linkdesk/ui 既有导出）。**圆角裁剪铁律**：弹出面板 `border-radius: var(--radius-sm)` ＋ `overflow: hidden`——hover 高亮实心块四角被裁、贴圆角边界；⛔ 直角高亮溢出圆角是历史真 bug（先例 = `SelectBox.css:85-87`「用户审计 #1」原注释；同族先例 = NumberInput 0.2.38 单一容器模型「圆角只写外框、内部零圆角」）；投影 `var(--shadow-pop)` 挂面板自身（overflow 只裁内容不裁阴影）。
- **下拉 token 消费表（全 var() 跟随主题，零写死色，组件不立新 token）**：底 `--bg-input`／`--bg-window`、边 `--border`／`--separator`、字 `--text-primary`/`--text-muted`/`--text-on-accent`、选中态 `--accent`＋`--bg-selection`、角 `--radius-sm`（面板）／`--radius-xs`（触发器）、投影 `--shadow-pop`、层叠 `--z-dropdown`、字号 `--font-size-sm`/`--font-size-md`（清单 = `SelectBox.css` 实际消费集）。自由度 = 调用方仅可经 className 局部覆写既有 var，⛔ 不另立第二套色值。
- **写入即联动**：卡内写 ⇒ 竞争区该类按生效值自然拆格/并回（E32）、覆盖表与文件树选择器即时互见（E31）——文件树选择器/竞争区下拉/卡内行下拉三写入面同一真源。
- **搜索联动**（E38）：搜索命中插件名/扩展名 ⇒ 命中卡自动展开；清空不自动收起（用户自己收）。
- 体**限高滚动** 280px（编辑器 45 类不撑爆页面）；行下拉弹出层走 OverlayPortal——滚动容器内不被裁剪（E37）。
- 卡齿轮（hover 显现、焦点恒显）：①**清除相关默认覆盖**（＝本插件声明范围内全部覆盖键，无论当初指向谁、含锁定，计数随显）②复制插件 ID（剪贴板面阶段 0 勘察，无面则砍）。~~打开插件详情~~ 挂账（壳无承载，§3）。
- 折角旋转 150ms、`prefers-reduced-motion` 零过渡、焦点环三站（头/齿轮/行下拉）全可见。
