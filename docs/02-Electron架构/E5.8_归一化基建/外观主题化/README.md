# 外观主题化（Theme = 完整外观配方 + 域贡献者）

## 已拍板快照（16 条）

1. 字体：壳零内置，系统栈兜底 + 主题插件自带字体（getAssetPath）
2. 图标主题先不做，单独立案
3. 摸底先行（02 文档即产物）
4. 主题 = 外观 token 覆盖层，边界 schema 锁死（01 §3）
5. 覆盖粒度 = 全局 scale 系数（04 §4）——**决策 E 精化：圆角 scale，玻璃改绝对覆盖**（blur px/opacity/tint）
6. 圆角 = 语义八档 + 偏门值归并（02 §5.2）
7. 字体纯主题层，不进设置层
8. 外观全局共享 + 按窗继承
9. 主题 = 域贡献者，缺的域继承默认（03）
10. 风格 vs 配色分离（03 §4.4）——**决策 B：配色变体严格只颜色**
11. 玻璃连续 scale 不是二元开关（04 §6.2）
12. **混搭 = 按域换来源**（用户原话：不用某主题的字体、用主题 A 风格 + 主题 B 配色；颜色域来源 = 配方+配色）——[10](10-混搭设计.md)
13. **主题组 = 独立配置贡献**（决策 D）：壳注册 pluginId `appearance`，主题 key 从通用组迁走——[08 §5](08-持久化与配置.md)
14. **新格式 only、零向后兼容读**（决策 F）：现有主题插件迁移改造（theme-defaults/mint-soda/twilight-forest）——[05 §5](05-主题数据模型.md)
15. **ai化 = AI 友好度**（2026-08-23 澄清）：schema 自文档化 + 文档读者含 AI + 示例可仿造 + 一种写法——[07 §0](07-代码规划.md)
16. **surface 域 schema 预留**（决策 C）：per-surface 精调键随 #50.6 token 表冻结
