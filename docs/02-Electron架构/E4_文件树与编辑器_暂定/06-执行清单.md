## 第 19.6 轮：IPC 文件监听频道隔离——独立频道防 watcher 串扰 🔧

> 🔥 **E4V#55f 发现——文件树 10s 缩回史诗级 bug 的治本修复。**
> **症状：** 启动 10s 后展开的目录自动缩回，twistie 显示 ▼ 但子节点消失。
> **根因：** `FileService.watchFile()` 底层 IPC 频道 `filesystem:changed` 是全局的。KeybindingRegistry 监听 `appDataDir` 的 `fs.watch` 事件和文件树的 `fs.watch` 事件走同一条 IPC 通道——所有 `onFileChange` 监听器收到所有 watcher 的事件。10s 时 Electron 写 Preferences + .tmp 文件 → 快捷键系统的 watcher 检测到 → IPC `filesystem:changed` → 文件树的监听器也收到了 → `model.refresh()` ×28 → 竞态 → 树缩回。
> **教训：** 全局 IPC 频道是缝 bug 的温床——第一个 watcher 时没问题，第二个 watcher 加入后无声崩溃。两个模块互不知道对方存在，各自看代码都看不出毛病。

## 第 19.7 轮：Sticky 推出动画 ❌ 放弃

## AI 友好度检查清单（每任务执行前）

> 来源：`📦 已归档/00.8-跨任务审计与预防.md` §九
> 🆕 E4 R11-12 实测三类高发 bug 模式（2026-08-01）

- [ ] 涉及路径字符串？→ 入口 `normalizePath()` + 拼接 `joinPath()`
- [ ] 需要文件扩展名？→ `import { extension } from "./pathUtils"`
- [ ] 需要持久化？→ `PluginStateService`，不写 localStorage/新文件
- [ ] import 核心类型？→ `import type { ... } from "@src/core/..."`，不重定义
- [ ] 需要路径比较？→ 两端都 normalize 后再比
- [ ] 涉及拖放？→ 走 `executeSafeDrop()`（E4V#3 归一化函数）——不另写安全检查
- [ ] **🔥 异步操作有中间态？→ 清 null 后必须立即重建**——`children=null` + `isExpanded=true` → twistie 展开无内容。refresh/expand/reveal 等必须走原子方法
- [ ] **🔥 模块级变量存组件状态？→ 存 ref 对象，不存 .current 快照**——FoldersView 不重渲染时快照过期。用 `h()` getter 每次读最新
- [ ] **🔥 useMemo deps 遗漏？→ 配置/状态变更不触发重算**——`flattenTree` / `renderedItems` 等 useMemo 必须覆盖所有输入源（sortOrder/compactFolders/decoration）
