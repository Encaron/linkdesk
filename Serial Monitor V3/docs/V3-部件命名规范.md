# V3 窗口部件命名规范

> 所有讨论、设计文档、代码注释统一使用这里的名称。不出现"三栏中间右边那个"。

---

## 一、完整窗口结构

```

├──────────────────────────────────────────────────────────┤

├────┬────────────────────┬─────────────────────────────────┤
│    │  ③ 侧栏标题         │  ④ 标签栏                      │
│    │  "收发设置"  [◀]    │  [📟 终端] [📊 心率检测] [⨁]   │
│ ⑤  ├────────────────────┼─────────────────────────────────┤
```

## 二、部件名称对照表

| 编号 | 名称 | 别称（不要用） | 说明 |
|:--:|------|------|------|
| ① | **标题栏** | — | Windows 原生的最顶栏，显示图标 + 标题 + 最小化/最大化/关闭按钮 |
| ② | **顶栏** | TopBar | 软件自绘的全局操作栏：串口选择、波特率、打开按钮、工具按钮 |
| ③ | **侧栏** | SidePanel、左侧栏 | 左侧设置面板，内容随活跃标签页变化 |
| ③子 | **侧栏标题** | — | 侧栏顶部的标题行——"收发设置" + [◀] 折叠按钮 |
| ④ | **标签栏** | TabBar | 主区顶部的标签页列表。每个标签页一个按钮 + [×] 关闭 + 最右侧 [⨁] 新建 |
| ⑤ | **图标栏** | IconBar、左侧竖条 | 最左边 42px 的图标列——📟 终端、📊 工作台、⚙ 设置 |
| ⑥ | **主区** | MainContent、主显示区、内容区 | 标签页内容显示区域。分屏时分成两个面板 |
| ⑦ | **状态栏** | StatusBar | 底部连接状态 + TX/RX 计数 |

## 三、标签页相关

| 名称 | 说明 |
|------|------|
| **标签页**（Tab） | 一个可切换的内容单元——终端标签页、工作台标签页、设置标签页、JSON 编辑器标签页 |
| **标签栏**（TabBar） | ④——横排显示所有标签页的容器 |
| **活跃标签页**（activeTab） | 当前正在显示/聚焦的标签页。决定侧栏内容 + 键盘焦点 |
| **[×] 关闭按钮** | 标签页右侧的关闭按钮 |
| **[⨁] 新建按钮** | 标签栏最右侧的新建标签页按钮 |

## 四、分屏相关

| 名称 | 说明 |
|------|------|
| **面板**（Pane） | 分屏后的一个独立显示区域。左面板 / 右面板，或上面板 / 下面板 |
| **分屏**（Split） | 拖标签页到主区边缘形成左右/上下双面板 |
| **分割条** | 两个面板之间的可拖拽分隔线 |
| **drop zone** | 拖拽标签页时主区边缘的高亮吸附区域 |
| **drop indicator** | drop zone 的半透明蓝色高亮 |

## 五、图标栏相关

| 名称 | 说明 |
|------|------|
| **图标栏**（IconBar） | ⑤——最左边 42px 的图标列 |
| **图标按钮** | 图标栏中的单个按钮——📟 / 📊 / ⚙ / 🎨(未来) |
| **选中态** | 图标按钮的蓝色指示条 + 光晕 |

## 六、侧栏相关

| 名称 | 说明 |
|------|------|
| **侧栏**（SidePanel） | ③——左侧设置面板，220px 默认宽度 |
| **侧栏标题** | 侧栏顶部的标题行——标题文字 + [◀] 折叠按钮 |
| **侧栏折叠** | 侧栏折叠为 28px 窄条，只显示 [▶] 展开按钮 |
| **侧栏内容** | 侧栏的主体内容——终端设置 / 卡片属性 / 导航菜单（随活跃标签页变化） |

## 七、顶栏相关

| 名称 | 说明 |
|------|------|
| **顶栏**（TopBar） | ②——全局操作栏 |
| **串口控制区** | 顶栏左侧——COM3 ▼ / 115200 ▼ / [● 打开] |
| **工具区** | 顶栏右侧——中/EN / ☀ 主题 / ⚙ |
| **☰ 汉堡菜单** | 顶栏最左侧的菜单按钮（Phase 6） |
