## 🆕 远期规划——更多市场插件

> 以下全是 **市场插件**——不改壳一行代码。LinkDesk 是通用容器，核心不知道插件的用途。串口监视器只是恰好第一个插件——下面这些方向同样合法。

### 04 — 🗺️ 地图插件

> **类型：市场插件** | Leaflet + GPS 轨迹 + 热力图 + GPX 导入。

嵌入式场景——无人机/机器人/车载——GPS 数据第一展示就是地图。串口收 NMEA 句子 → 解析经纬度 → 地图上实时画点。历史轨迹回放 + 热力图（哪里停留最久）。

**为什么是 LinkDesk：** Google Earth 不是开发工具。嵌入式工程师需要一个轻量、可接串口数据的地图。

**技术：** Leaflet（开源，零依赖）+ GPX 解析 + 串口数据管道消费。

### 05 — 逻辑分析仪

> **类型：市场插件** | 数字信号时序图——8/16 通道。

嵌入式调试标配。Saleae Logic 的软件层——硬件是用户自己的（Cypress FX3 / USB 逻辑分析仪 ~$10）。不做硬件，只做渲染。

```
┌─ 逻辑分析仪 ──────────────────────────────────┐
│ CH0: ──┐   ┌──┐   ┌──────┐   ┌──┐           │
│ CH1:   └───┘  └───┘      └───┘  └──────     │
│ CH2: ──────┐     ┌─┐  ┌─┐  ┌────────────    │
│            0     1   2   3   4   (ms)        │
└───────────────────────────────────────────────┘
```

**技术：** Canvas 2D 逐行渲染 + 信号协议解码（I2C/SPI/UART 标注在波形上方）。

### 06 — 协议调试器

> **类型：市场插件** | MQTT / Modbus / CAN 总线——三大 IoT 协议。

串口只能看字节流。协议调试器能解析帧结构——显示 Topic/Payload（MQTT）、寄存器地址/值（Modbus）、CAN ID/数据（CAN）。不只是"显示"——能**构造并发送**协议帧。

```
┌─ MQTT 调试器 ─────────────────────────────────┐
│ Broker: [192.168.1.100:1883    ] [连接]       │
│                                                │
│ 订阅: [device/+/temperature      ]            │
│                                                │
│ ── 收到 ──────────────────────────────────── │
│ 14:32:05  device/1/temperature  26.3°C        │
│ 14:32:06  device/2/temperature  31.8°C        │
│ ── 发送 ──────────────────────────────────── │
│ [device/1/led] [ON]               [发送]      │
└────────────────────────────────────────────────┘
```

### 07 — 固件烧录工具

> **类型：市场插件** | 对接 openocd / jlink / st-flash——消费壳的烧录服务（主进程 spawn 外部工具）。

嵌入式开发者装 CubeIDE / Keil 只为烧录。LinkDesk 里有终端 + 串口——就差烧录。选固件文件 → 选烧录器 → 点烧录 → 终端看进度 → 串口监视器看输出。全在同一个软件里。

```
固件: [firmware.hex           ] [浏览]
烧录器: [STM32F407 (ST-Link)   ▾]
[烧录] [校验] [擦除]

输出:
> openocd -f stlink.cfg -f stm32f4x.cfg
> Programming... 100%
> Verified OK
> 用时: 3.2s
```

### 08 — 3D 模型查看器

> **类型：市场插件** | Three.js + STL/OBJ/STEP 加载。

3D 打印 + 机械设计 + PCB 外壳。不是所有人需要——但需要的人会因为这个装 LinkDesk。拖入 STL → 旋转/缩放/剖切 → 截图分享。
