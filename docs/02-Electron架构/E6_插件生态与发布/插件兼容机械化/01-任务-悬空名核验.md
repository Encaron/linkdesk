# 格 1 · 任务 `E6#114`：**悬空名核验**——插件产物喊的名字，宿主机里还有没有定义

> **一句话**：插件产物里烘进了一批名字（类名、关键帧名），**今天没有任何尺子量得出「这些名字宿主还认不认」**——宿主改名/删除之后，插件只是**悄悄丑了**（实证：`.input → .ldk-input`，`settings` v1.0.12 → v1.0.13 输入框丢底色/边框/圆角，零报错）。本格造这把尺子：**产物喊的名字，既不在它自己包里定义、也不在当前宿主里定义 ⇒ 报悬空**。
>
> **编号**：`E6#114` ｜ **轮次**：第 8.1 轮 ｜ **队列位置**：**第 1 棒（共 6 棒）**
> **前置**：无硬前置（与格 2 互不依赖，可换序）｜ **提交轴**：壳仓 `scripts/` ＋ `package.json`（挂 npm script）＋ 文档
> **规模**：一个只读审计脚本（≈ 250–400 行）＋ `--self-test` ＋ 一份读数档。**预期零 `src/` 改动、零 SDK 改动、零发版**
> **非新能力声明**（`check-design-flow` §8.4 ③）：本格产出的是**一把只读的维护者尺子**（跑给人看，不进 `npm run check`、不判红、不改产品行为、不给插件作者新 API）⇒ **无需新能力设计前置**。

## 二、要做（**四步，缺一即半成品**）

### 第一步：脚本 `scripts/plugin-dangling-name-audit.mjs`（只读、只报不拦）

- **输入**：① `bundled-plugins/*.linkdesk-plugin`（6 只，**真 zip**）② 官方 18 仓的**构建产物**（各自仓里的 `dist/*.linkdesk-plugin`；**已经构建过**，本格**不替它们构建**——没产物就报「未构建（跳过并计数）」，**不许静默跳过**）。
- ⛔ **读 zip 的正确姿势**：它们是 zip（`head -c 4` = `PK\x03\x04`）⇒ 必须 `unzip -p <zip> <entry>`。**不许用 grep 扫 zip**（会读到全 0，那不是读数）。
- **判据（三句话，逐字写进脚本头注）**：
  1. 取「产物喊的名字」= ① `index.bundle.js` / `views/*.bundle.js` 里 `className="x"` 形态的**类名候选**（字面量，含 `className={"a b"}` 的裸字符串；**含插值的模板一律跳过**并计数）＋ ② 包内 `*.bundle.css` 的选择器里出现的类名 ＋ ③ 包内 CSS 的 `animation:` 引用的关键帧名。
  2. 取两个定义集：**自身定义集** = 该产物包内 CSS 的 `@keyframes` ＋ 选择器里**被定义的**类名；**当前宿主定义集** = 壳 `src/**/*.css` ＋ 共享组件 CSS ＋ `packages/plugin-sdk/schemas/reserved-class-names.json` 的 8 条保留关键帧。
  3. **悬空 = 喊了，但两个定义集里都没有** ⇒ 逐条报（`仓/插件` ＋ 名字 ＋ `文件:行`）。
- 🔴 **两个定义集「在哪跑、从哪取」——本格必须写死，否则后面两格会以为现成就有**：
  - **维护者侧（本格 ＋ 官方仓审计）**：宿主定义集读**源码**（壳 `src/**/*.css` ＋ 共享组件 CSS）——够用。
  - **软件里（格 4 的运行时读数）**：壳手里**没有源码**，而**今天下发的账里根本没有类名清单**（`reserved-class-names.json` 只剩 8 条关键帧、`host-reserved.json` 无类名栏，见 [00 号档 §二第 15 条](00-整理档案.md)）⇒ 本格交付时要把**「宿主类名定义集怎么生成」的口径**写死成一个**构建期可生成、可随包下发**的清单（生成口径与自身的判据同源），交给格 4 拍「随包下发 or 运行时读自己产物」，交给格 6 搬进 SDK。
  - **已装插件怎么读**：本机 `%APPDATA%\linkdesk\plugins` 里是**解包目录**（不是 zip，见 [00 号档 §二第 16 条](00-整理档案.md)）⇒ 尺子应当**同时支持两种输入**：目录（已装）＋ zip 条目（随包种子/官方仓产物）。
- **为什么这样判不会假红**：第三方库是**自洽**的（Monaco 喊的 `monaco-workbench` 在它自己注进包里的 CSS 里有定义 ⇒ 命中「自身定义集」）⇒ `editor` 天然 0 报。⚠️ **这一条必须用真样本验**（见 §三 判据①）。
- **准入**：`plan` 阶段的输入面**只为对账**；动手前先跑一遍把今天的读数记下来（`--baseline`），收尾再跑一遍比对。
