## 一、步骤

1. **壳 bump**：`package.json` `0.1.65` → **`0.1.66`** + **同笔**写 `CHANGELOG.md` 的 `## v0.1.66` 段（`check-changelog-section` 会验「版本号在 CHANGELOG 里有非空段」；**bump 与 CHANGELOG 必须同一笔**）。
   - 段的写法照既有风格（用户视角：「修好什么 / 现在能看到什么 / 影响面」）。**内容要点**：共享组件的样式类名统一加了命名空间前缀，避免插件界面里「名字撞车导致的显示异常」这一类问题；**对用户无可见变化**（纯标识符）；已装的主题/插件**不需要重装**。

2. **tag + 出包**：`git tag v0.1.66` 并推送（**用户已授权推送**）→ 确认 CI 出包三资产齐（照 L7/#109b 的既有读数口径）。
3. **出厂种子刷新**：`npm run sync:bundled -- --latest`（读官方目录刷新账与种子；**必须在本轮做**——三只插件刚发新版，箱子要跟上）。

   | 2 | 设置 → 外观/任一滑杆行 | 滑杆样式正常（`.settings-slider-control .ldk-slider` 调优是否生效） |
   | 3 | 设置 → 任一表单行（开关） | 开关样式正常（`.form-row > .ldk-toggle`） |
