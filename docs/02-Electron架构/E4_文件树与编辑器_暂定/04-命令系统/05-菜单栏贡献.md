## 六、注册方式

```typescript
// FileTreeContextMenu.tsx activateFileTreeContextMenu() 中追加：
registerMenuItems(MenuId.MenuBar, "file-tree", [
  // 文件
  { command: "explorer.newFile",   group: "file_new",     label: "新建文件" },
  { command: "explorer.openFolder",group: "file_open",    label: "打开文件夹…" },
  // 编辑
  { command: "explorer.cut",       group: "edit_clipboard", label: "剪切" },
  { command: "explorer.copy",      group: "edit_clipboard", label: "复制" },
  { command: "explorer.paste",     group: "edit_clipboard", label: "粘贴" },
  // 查看
  { command: "workbench.view.explorer", group: "view_panels", label: "资源管理器" },
]);
```

**对标圆形大厅：** 文件树注册自己的菜单项到 MenuBar。编辑器注册自己的。Git 注册自己的。`TitleBar` 统一渲染、`MenuRenderer` 统一渲染子菜单、`ContextKeyService` 统一求值 when 条件。

## 八、AI 进场须知 🛡️

- **核心已就绪——只需 `registerMenuItems(MenuId.MenuBar, ...)`**
- **TitleBar 按 group 分组**——同 group 的菜单项出现在同一个下拉菜单里
- **子菜单走 `MenuRenderer`**——递归渲染，支持嵌套
- **when 条件可用**——`ContextKeyService.matches()` 在渲染时求值
