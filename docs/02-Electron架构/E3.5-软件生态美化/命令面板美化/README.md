## 消费方

QuickPick 是归一化壳，三个场景共用：

| 场景 | 组件 | 特点 |
|------|------|------|
| 命令面板 | `CommandPalette` | `renderItem` + `renderItemActions`（齿轮） |
| 主题浏览器 | `ThemeBrowser` | `onHighlight` 即时预览 |
| 语言选择器 | `LanguagePicker` | 简单列表 |

**改 QuickPick → 三者一起受益。** 但 renderItem/renderItemActions 是各场景自己的，所以命令面板的特定改进（如快捷键显示）在 CommandPalette.tsx 里改。
