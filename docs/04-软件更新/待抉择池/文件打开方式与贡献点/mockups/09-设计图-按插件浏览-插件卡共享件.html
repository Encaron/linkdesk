卡交互 C1–C10（每条都能在本图点出来；08 的 M1–M10 在本页继续成立）
  1. C1 展开即全功能：卡体不是说明书——每行 = 状态徽标＋下拉，下拉与 08 竞争区同写 workbench.fileAssociations（E31 第三写入面）。
  2. C2 行内下拉＝逐类写：候选类下拉列出「自动＋全部候选插件」，当前生效值选中；改选 → 覆盖表 → toast＋日志＋竞争区当场拆格（C9）。
  3. C3 唯一处理者可锁定（E35）：单家类型下拉仍有「自动＋自己」——显式选自己＝锁定，将来第二家插件进来也不漂移（E2 同款机制，零新规则）。
  4. C4 卡齿轮：重置我设的默认（本插件声明范围内所有覆盖键，含锁定，计数随显）＋复制插件 ID；「打开插件详情」挂账（壳无承载）。
  5. C5 状态徽标四态：默认（自动）／当前默认（你设的）／候选 · 默认是 X／唯一处理者（自动）；指向已卸载插件的失效覆盖键 → 红点提示「失效覆盖」（E6 惰性：键还在，重装复活）。
  6. C6 搜索联动：搜索命中插件名或扩展名 → 卡自动展开、不命中收起过滤（受控 expanded 的管理器策略；复用既有「搜索设置」）。
  7. C7 停用（E5）：卡降透明＋行下拉全禁＋解析不参选——别的候选即时补位（.jpg 从 A 掉到 B 当场可见）。
  8. C8 装卸（E1/E6）：装第二家 → 竞争区新行＋默认不漂移；卸载被覆盖指向者 → 惰性失效回声明序；重装复活。
  9. C9 E32 拆格联动：卡内单类写入 ⇒ 该类按「生效值」从聚合格里自然拆出独立行；恢复自动 ⇒ 并回——卡与竞争区同屏互证。
  10. C10 怪串原样（E34）：Keil 助手声明 uvprojx / MX——机器不认识它，标签照抄归一存储键 .uvprojx / .mx，照样能锁。
