> 近期已修过的光晕、磨砂、下拉菜单，都是「同一个东西写了两套」。本轮在动工前先堵死：

| 东西 | 唯一出处 | ⛔ 禁止 |

## 七、风险与回滚

| 风险 | 处置 |
|---|---|
| 壳 CSP 拦外链视频 | A4 前置；只放行 `https:`，⛔ 放开 `unsafe-*`；拦则改壳并加测试 |
| GitHub raw 缓存导致换图不生效 | 稳定 URL＋`?v=`/哈希；D2 写进作者文档 |
| 第三方作者没图 | 生成式封面兜底；不阻断、不报错 |
| 多图拖慢市场 | 上限 3 帧＋lazy；F6 实测 |
| 目录 `collections` 缺失 | D1 补齐；换槽位只改 JSON |
| 回滚 | 批次独立；B 的兜底始终存在；出问题按批次 revert（插件版本随代码改动走） |

## 八、明确不做

- ⛔ 拖拽式策展/画布编辑器（LabVIEW 式）。
- ⛔ 第二套媒体字段 / 第二套画廊 / 第二套轮播。
- ⛔ 图片托管/转码/CDN 服务（只消费作者 URL）。
- ⛔ 自动播放、卡内视频播放（本轮）。
- ⛔ 社会证明、服务器推荐。
- ⛔ 替作者编排板块；只提供可声明的槽位。
- ⛔ 把卡片/媒体抽进 `@linkdesk/ui`（卡片长相属市场插件私有）。
