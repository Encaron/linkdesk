## 四、三个坑（先记死）

1. **运行中的 Chromium 占着缓存文件** ⇒ 当场删不掉，只能「重启后彻底清空」。⛔ 界面**不许谎报**「已清空」。
2. **渲染层 `readonly` 与 `action` 互斥**（设置插件 `renderControl.tsx` 的两条互斥分支）⇒ 「只读值 ＋ 按钮」**挤不进同一个键、同一行**。⚠️ 这是**声明层**的互斥；**控件层**可以两样同排。所以本轮落成**两个键、两行**，不是硬凑一行。
3. **缓存 ≠ 数据**（真机实测 2026-10-02）：`%APPDATA%\linkdesk` 共 **70.6 MB**，其中只有 **≈14.6 MB 可再生**；**`plugins` 的 55.5 MB 是数据**。混为一谈 ＝ 「一键把你装的插件全删了」。
