# 主题字段速查——字段在哪、变量叫什么

> **本页只做两件事：① 告诉你每个字段的权威定义在哪；② 给你"域 → CSS 变量"的对照索引。**
> 🔴 **字段的权威定义只有一个地方：`theme.schema.json`**（SDK 包内 `schemas/theme.schema.json`）。本页**不复制 schema**——复制就会漂移。

| | |
|---|---|
| 读者 | 已经在写配方，要查"这个键叫什么、对应哪个变量"的人 |
| 形态 | 索引（查表 → 跳到真源） |
| 不是 | 教程（→ [01-做一个主题插件](01-做一个主题插件.md)）· 配方写法深度参考（→ [11-主题制作](../11-主题制作.md)） |

---

## 一、配方顶层字段

| 字段 | 必需 | 含义 |
|:--|:--:|:--|
| `id` | ✅ | 配方 id（全局唯一；与 `plugin.json` 里 `contributes.themes[].id` 一致） |
| `name` | ✅ | 显示名（主题选择器标题） |
| `type` | ✅ | `"dark"` \| `"light"`——深浅基线 |
| `colorways` | ✅ | **配色变体数组**（单配色也写 1 项）——每项 `{ id, name, colors }` |
| `appearance` | ❌ | 风格域（单值、稀疏）——缺的域/键继承壳默认 |

> 只有这 5 个顶层字段。每个字段的类型/枚举/描述以 `theme.schema.json` 为准。

## 二、`appearance` 四域 → CSS 变量对照

### `radius` —— 圆角八档

| 配方键 | CSS 变量 | 语义 |
|:--|:--|:--|
| `xs` | `--radius-xs` | 滚动条 / 开关 / 拖拽指示 |
| `sm` | `--radius-sm` | 输入框 / 按钮 / 小标签（**用量最大**） |
| `md` | `--radius-md` | 设置分组 / 卡片 |
| `lg` | `--radius-lg` | 对话框 / 悬浮面板 / 菜单 |
| `xl` | `--radius-xl` | 玻璃态大面板（引擎标尺档，壳当前默认表面很少消费） |
| `2xl` | `--radius-2xl` | 最大面板 / 背景容器 |
| `pill` | `--radius-pill` | 胶囊（`999`） |
| `full` | `--radius-full` | 圆形（`50`） |

> 只写你想改的档，例如 `"radius": { "md": 10, "lg": 16 }`。

### `glass` —— 玻璃与悬浮材质

| 配方键 | CSS 变量 | 语义 | 关掉它写什么 |
|:--|:--|:--|:--|
| `type` | — | 玻璃配方（枚举只有 `"glass"`）；**缺省 = 无玻璃** | 不写 `glass` 域 |
| `blur` | `--glass-blur` | backdrop 模糊 px | `0` |
| `saturate` | `--glass-saturate` | 饱和度增强 | `1` |
| `tint` | `--glass-tint` | 玻璃面叠加色 | `"transparent"` |
| `opacity` | `--glass-opacity` | 玻璃面不透明度（1 = 不透明） | `1` |
| `specular` | `--glass-specular` | 顶部高光强度（液态玻璃"反光"） | `0` |
| `specularColor` | — | 高光基色（缺省白；alpha 仍由 `specular` 给） | — |
| `morph` | `--glass-morph` | 形变过渡 ms（"响应"） | `0` |
| `radius` | — | 悬浮面板圆角 px（0 = 直角贴边） | `0` |
| `shadow` | （映射 `--shadow-lift`） | 悬浮投影开关 | `false` |
| `texture` / `textureOpacity` | （写入 per-surface 背景族） | 可平铺纹理图资产路径与不透明度 | 不写 |

> ⚠️ **大面积 `blur` 是 GPU 负担**——用得越克制越流畅。

### `font` —— 字体

| 配方键 | CSS 变量 | 取值 |
|:--|:--|:--|
| `ui` | `--font-ui` | **系统字体族名字符串**（用户机器上已有），**或**资产相对路径（`assets/xxx.woff2`——壳注册 `@font-face` 后用族名） |
| `mono` | `--font-mono` | 同上（代码/面板等宽字体） |

### `background` —— 图片背景

| 配方键 | CSS 变量 | 语义 |
|:--|:--|:--|
| `image` | `--bg-image` | 图片路径（**相对路径**，壳包 `url()`） |
| `opacity` | `--bg-opacity` | 图片层不透明度 |
| `mask` | `--bg-mask` | 遮罩**明暗系数（number 0–1，0 = 无遮罩）** |
| `maskColor` | （同上） | 遮罩基色（缺省黑） |
| `mode` | — | `"panorama"`（默认，整张铺满）\| `"zones"`（同图按窗口区域连续切片） |

> 🔴 **`mask` 是数字（0–1），不是颜色字符串**——要指定遮罩颜色用 `maskColor`。
> （[11-主题制作](../11-主题制作.md) 的满配示例里曾把它写成 `rgba(...)`，与 schema 不符，已订正。）

## 三、`colorways[].colors` —— 颜色 token 怎么起名

**规则一句话：键 = CSS 变量名去掉 `--` 前缀。** 你在配方里写 `"bg-window"`，壳就把它写进 `--bg-window`。

**作者最常改的一批**（不是全集）：

| 分类 | token 名 |
|:--|:--|
| 背景面 | `bg-window` · `bg-card` · `bg-input` |
| 文字 | `text-primary` · `text-secondary` · `text-muted` · `tone-surface-deep` / `tone-ink-on-deep` · `tone-surface-light` / `tone-ink-on-light` |
| 强调色 | `accent` · `accent-hover` |
| 分隔与边框 | `border` · `separator` |
| 图标 | `icon-inactive` |
| 状态 | `status-connected` · `status-disconnected` · `error` · `warning` · `success` |
| 滚动条 | `scrollbar-thumb` · `scrollbar-thumb-hover` |
| 角标 | `badge-background` · `badge-foreground` · `badge-text` |
| 浮层 | `scrim-dialog` · `scrim-overlay` · `floating-panel-backdrop` · `context-menu-shadow` |

**全集在哪**：壳的默认主题 token 全表 = 仓库 `src/index.css` 的 `:root`（近百个）。
**只想改几个就写几个**——没写的继承基线（浅色主题继承浅底、深色继承深底）。

> ⚠️ **别指望改 `--accent` 就完事**：有些控件故意读自己的 token（例如开关的 `--toggle-on-bg`）而不是 `--accent`——设计上就是让它们可以不同步。要精确控制就去读那个控件实际用的变量。

## 四、资产与路径

| 类型 | 放哪 | 配方里怎么写 |
|:--|:--|:--|
| 字体 | `assets/xxx.woff2` / `.ttf` | `"font": { "ui": "assets/MyFont.woff2" }` |
| 背景图 | `assets/xxx.png` / `.jpg` / `.webp` | `"background": { "image": "assets/bg.png" }` |
| 纹理 | `assets/xxx.png`（可平铺） | `"glass": { "texture": "assets/paper.png" }` |
| 插件图标 | `resources/icon.svg` | `plugin.json` 的 `icon` 字段 |

🔴 **一律相对路径**（相对插件工程根）。绝对路径（`/assets/...`）打包后会炸——壳用统一的资产解析器把相对路径变成可访问 URL。

## 五、稀疏覆盖与继承（记住这一条就够）

```
colorways[].colors  只写你要改的颜色键  →  没写的继承基线
appearance.域       只写你要改的域     →  没写的域整个继承
appearance.域.键    只写你要改的键     →  没写的键继承壳默认
```

**写得越少越稳。** 壳以后调整默认外观，写得少的主题自动跟着变好；写得多的主题会"卡在旧值"。
