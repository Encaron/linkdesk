### Bug E5-1 🔴🔴🔴 Events 类型漂移——emit 和 on 不匹配

**历史：** E3j #77 events 系统——`emit("icon:selected", id)` 发 string，`on("icon:selected", (payload) => {})` payload 是 any。如果发 `{ id: "marketplace" }` 而不是 `"marketplace"` → 运行时静默炸。无编译期检查。

**E5 触发条件：** 壳内四个区域通过 events 通信——IconBar emit、Sidebar+M
MainContent+StatusBar 各自订阅。四个区域由不同人（或不同 AI）维护 → 改一个区域的 emit 签名 → 其他三个区域的 on handler 全炸。

**🔥 防线——代码级：**
```typescript
// src/core/ShellEvents.ts —— 壳内通信唯一类型定义
interface ShellEvents {
  "icon:selected":    string;          // pluginId
  "sidebar:toggled":  boolean;         // isOpen
  "tab:focused":      { pluginId: string; tabId: string };
  "statusbar:update": StatusBarEntry[];
  "zone:resized":     { zone: string; width: number };
}

// 类型安全的 emit/on——编译期检查所有调用
function emit<K extends keyof ShellEvents>(event: K, payload: ShellEvents[K]): void;
function on<K extends keyof ShellEvents>(event: K, handler: (payload: ShellEvents[K]) => void): () => void;
```

**🛡️ 验证：** 写错 `emit("icon:selected", { id: "x" })` → tsc 当场报错——不等到运行时。

### Bug E5-2 🔴🔴🔴 事件订阅泄漏——mount 注册 unmount 忘清理

**历史：** E3j #81 双份渲染根因——`_initIPC()` 模块级注册 IPC 监听器，永不清理。壳 fallback 切空 div 后 IPC 监听器仍存活 → 僵尸回调。修复：引用计数 + useEffect cleanup（#81-2）。

**E5 触发条件：** 四个区域各自订阅 ShellEvents → 每个区域有 2-4 个 `on()` 调用 → 总共 8-16 个事件订阅。区域组件 unmount 时如果有一个没 cleanup → 僵尸订阅 → 事件来了处理不存在的 DOM → 静默报错或白屏。

**🔥 防线——代码级：**
```typescript
// 每个区域的 useEffect 必须返回 unsubscribe
useEffect(() => {
  const unsub1 = events.on("icon:selected", handleIconSelected);
  const unsub2 = events.on("sidebar:toggled", handleSidebarToggled);
  return () => { unsub1(); unsub2(); };  // ← 忘了这行 → 内存泄漏 + 僵尸回调
}, []);
```

**🛡️ ESLint 已覆盖：** `no-module-level-ipc-listener` 拦截模块级注册。但 useEffect cleanup 缺失目前无机械拦截——需代码审查手动检查。

### Bug E5-6 🔴 剪贴板 Provider 覆盖——两个插件注册同一个 when

**历史：** E3f #59f——`CommandRegistry.registerCommand` 覆盖已有命令时 `console.warn`。E3b #36f9——`setConfigurationValue` 写入前 enum 验证。

**E5 触发条件：** `ClipboardProviderRegistry.register({ when: "editorFocus", onCopy })`——如果两个插件都注册了 `when: "editorFocus"` → 后注册的覆盖先注册的 → 先注册的插件的复制逻辑失效。

**🔥 防线——代码级：**
```typescript
// src/core/ClipboardProviderRegistry.ts
register(provider: ClipboardProvider): void {
  const existing = this._providers.find(p => p.when === provider.when);
  if (existing) {
    console.warn(
      `[ClipboardProvider] ⚠️ "${provider.when}" 已有注册者，被覆盖。` +
      `旧: ${existing.pluginId} → 新: ${provider.pluginId}`
    );
  }
  this._providers.push(provider);
}
```
