## 做什么

现在 LinkDesk 打开没有"项目"概念——只有标签页。对标 VS Code 的 `.code-workspace`。

```
.linkdesk-project/
├── project.json          ← 项目名、描述、默认串口
├── workspace.json        ← 卡片工作台布局
├── settings.json         ← 项目级设置（覆盖全局）
└── .gitignore
```

---

## 用户看到的

```
欢迎页
├── 最近项目
│   ├── 📁 STM32-温控系统        ← 最近打开过
│   ├── 📁 ESP32-环境监测
│   └── 📁 无人机飞控
├── [打开文件夹...]
└── 快速开始（新建项目）
```

**"打开文件夹" → 检测到 `.linkdesk-project/` → 自动恢复布局 + 设置。**

---

## 壳改动

| 改什么 | 说明 |
|------|------|
| `FileService` 加 `openProject(path)` | 读 project.json，恢复 workspace + settings |
| 欢迎页加"最近项目"列表 | 从 `prefs.json` 的 `recentProjects` 读取 |
| 标题栏显示项目名 | `LinkDesk — STM32-温控系统` |
| 项目级设置覆盖全局 | `ConfigurationService` 加层级：项目 > 用户 > 默认 |
