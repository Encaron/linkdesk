## 二、设计 Token——文件树

> **来源：** `ui-ux-pro-max` Dark Mode (OLED) palette + density 8 (dense dashboard spacing)
> **对标基准：** VS Code Explorer 侧栏

### 2.1 尺寸 Token

| Token | 值 | 用途 |
|------|------|------|
| `--tree-item-height` | 22px | 树节点行高——对标 VS Code list row |
| `--tree-indent` | 16px | 每层缩进量——对标 VS Code `indent` |
| `--tree-indent-guide` | 8px | 缩进引导线距左边缘偏移（即 twistie 左 edge = indent - 8px） |
| `--tree-twistie-size` | 16px | twistie 展开/折叠图标尺寸 |

| `--tree-icon-gap` | 6px | 图标与文件名间距 |
| `--tree-item-padding-x` | 8px | 行内水平 padding |
| `--tree-item-padding-y` | 1px | 行内垂直 padding（行高 22px - 内容 20px = 2px / 2） |
| `--tree-scrollbar-width` | 8px | 滚动条宽度（hover 时从 4px 扩展到 8px） |

## 五、状态矩阵——所有组件 × 所有状态

### 5.1 文件树状态

| 状态 | 触发条件 | 视觉表现 |
|------|------|------|
| **正常** | workspace root 存在，目录非空 | 文件树正常渲染 |
| **空工作区** | `roots.length === 0` | [WelcomeView](#92)——"你没有打开文件夹" + [打开文件夹] 按钮 + 最近文件夹列表 |
| **空目录** | 展开的目录无任何条目 | 显示 "此文件夹为空"（11px，`--tree-dimmed`，缩进到应有层级） |
| **加载中** | `listDir()` 异步进行中 | twistie 替换为 16px spinner（`--search-spinner-color`），树节点文字保持显示 |
| **加载失败** | `listDir()` reject（权限拒绝/路径不存在） | 目录节点显示 ⚠ 图标 + "无法读取目录" tooltip |
| **工作区根不存在** | 上次打开的文件夹被删除 | 根节点显示 🚫 图标 + 红色文字 + hover tooltip "文件夹已被删除或移动" + 右键 [移除文件夹] |
| **选中** | 单击 / 键盘导航 | `background: var(--tree-bg-selected)` |
| **选中(未聚焦)** | 文件树 blur（点击编辑器区域后） | `background: var(--tree-bg-selected-unfocused)` |
| **hover** | 鼠标悬停行 | `background: var(--tree-bg-hover)` |
| **高亮(reveal)** | `revealInExplorer` 调用 | `background: var(--tree-bg-highlight)` → 2s 后过渡回正常 |
| **拖放目标目录** | 拖文件到目录节点上 | `background: var(--tree-bg-drag-target)` |
| **拖放插入线** | 拖文件到两行之间 | `border-top: 2px solid var(--color-accent)`（蓝色横线） |
| **拖放无效** | 拖祖先到后代 / 拖到自己身上 | 红色闪烁 200ms × 2 次 + 回弹到原位 |
| **排除文件** | 匹配 `files.exclude` 模式 | 不显示在树中（被 `FileExcludeFilter` 过滤） |
| **排除目录变空** | 目录所有内容均被排除 | 目录本身也不显示（对标 VS Code） |

### 5.2 搜索面板状态

| 状态 | 触发条件 | 视觉表现 |
|------|------|------|
| **正常** | 搜索完成，有结果 | 结果树渲染——按文件分组 |
| **初始** | 搜索面板打开但未搜索 | 搜索框为空，结果区空白，显示 🔍 占位文字 "输入关键词搜索"（`--tree-dimmed`） |
| **搜索中** | `FileSearcher.search()` 执行中 | 搜索框右侧显示 16px spinner + 结果区底部状态栏显示 "搜索中…" |
| **无结果** | 搜索完成但零匹配 | 显示 "未找到结果。尝试其他关键词或调整筛选条件。"（UX 规则：不空白） |
| **结果截断** | 结果 ≥ 2000 | 底部状态栏显示 "已显示前 2000 个结果。请优化搜索条件。"（黄色文字） |
| **被取消** | 用户点击 [×] 取消 | 结果保留上次搜索内容 + 搜索框右侧 spinner 变为 [搜索] 按钮 |
| **搜索错误** | 文件读取失败 | 文件头显示 ⚠ 图标 + "读取错误" |
| **替换确认** | 用户点击 [全部替换] | `DialogService.confirm("将在 N 个文件中替换 M 处。\n此操作不可撤销。是否继续？")` |
| **替换完成** | 替换成功 | 底部状态栏短暂显示 "已替换 M 处"（`--color-accent` 文字，2s 自动消失） |
| **搜索结果导航** | F4/Shift+F4 | 编辑器跳转到对应行 + 行号区域短暂高亮 |

### 5.3 编辑器状态

| 状态 | 触发条件 | 视觉表现 |
|------|------|------|
| **正常** | 文件已加载 | Monaco 编辑器渲染文件内容 |
| **加载中** | 大文件读取中 | 编辑器区域显示居中 spinner + "正在加载 {文件名}…" |
| **加载失败** | 权限拒绝 / 文件不存在 | 编辑器区域显示居中错误占位——⚠ 图标 + "{文件名} 无法打开" + 错误原因 + [重试] 按钮 |
| **二进制文件** | 编码检测失败 / 文件类型非文本 | 编辑器区域显示 "无法在文本编辑器中打开二进制文件。" + [用系统默认程序打开] 按钮 |
| **dirty** | 文件被修改未保存 | 标签页标题显示 ●（`--color-accent`） |
| **dirty + 关闭** | 关闭 dirty 标签页 | `DialogService.confirm("是否保存对 {文件名} 的更改？")` + [保存]/[不保存]/[取消] |
| **保存成功** | Ctrl+S 成功 | ● 消失 + 状态栏短暂显示 "已保存"（1.5s 自动消失） |
| **保存失败** | 写入权限被拒绝 | toast "{文件名} 保存失败：权限被拒绝" |
| **外部修改** | watchFile 检测到文件被外部程序修改 | 标签页标题后显示 "[已修改]" 文字（`--color-accent`，点击重新加载） |
| **外部删除** | watchFile 检测到文件被删除 | 标签页变暗 + 编辑器内容保留但顶部显示横幅 "文件已被删除——关闭以丢弃内容" |
| **编码切换** | 用户点击状态栏编码 → 选择 | 编辑器重新解码 + 重新渲染 |

## 六、动画规格

> 来源：`ui-ux-pro-max` motion 3/10——微妙微交互。所有动画尊重 `prefers-reduced-motion`。

| 动画 | 时长 | 缓动 | 触发条件 |
|------|:--:|------|------|
| twistie 旋转（▶ → ▼） | 100ms | `ease-out` | 展开目录 |
| twistie 旋转（▼ → ▶） | 100ms | `ease-out` | 折叠目录 |
| 树节点展开/折叠 | 跟随 twistie + 子节点 150ms `ease-out` 淡入 | | |
| `revealInExplorer` 高亮 | 0ms 立即高亮 + 2s `ease-out` 消退到透明 | | 跨插件定位文件 |
| 拖放插入线出现 | 50ms `ease-out` | | dragOver 命中两行之间 |
| 拖放目录高亮 | 100ms `ease-out` | | dragOver 命中目录节点 |
| 拖放无效闪烁 | 200ms `ease-in-out` × 2 次（红色闪现 + 消退） | | 非法拖放目标 |
| 搜索 spinner | 连续旋转动画 | | 搜索执行中 |
| 搜索结果出现 | 文件头 `ease-out` 150ms 淡入（stagger——每个文件延迟 30ms） | | 搜索完成 |
| 替换完成提示 | 状态栏文字 200ms 淡入 → 保持 2s → 200ms `ease-out` 淡出 | | 替换完成 |
| tab preview → pin | `font-style` 200ms `ease-out` 过渡 | | 编辑内容后自动 pin |
| dirty ● 出现/消失 | 150ms `ease-out` 缩放（scale 0 → 1 / 1 → 0） | | 修改/保存 |
| 右键菜单出现 | 150ms `ease-out` 缩放 + 淡入（壳 ContextMenu 已有） | | 右键文件 |
| 行内重命名输入框 | 100ms `ease-out` 淡入（覆盖在原文件名上） | | F2 |
| 行内重命名确认 | 100ms `ease-out` 淡出 → 文件名立即出现 | | Enter |
| 行内重命名取消 | 100ms `ease-out` 淡出 → 原名立即恢复 | | Esc |
| 状态栏编码文字切换 | 150ms `ease-in-out` 交叉淡入淡出 | | 编码切换 |
