# 01 — 全量 UI/UX 审计

> 2026-07-29 定稿。

---

## 当前 vs 目标

| | 当前 | 目标 |
|------|------|------|
| 导航 | 平铺列表，一个插件一个分组 | 两种模式共存：平铺 / 两级树 |
| 右面板 | 一个分组一个页面 | 有子节点时一次只显示一个 section |
| 组织 | 按插件分组——"通用"/"主题"割裂 | 逻辑分组——强调色归入主题 |
| 向后兼容 | — | 旧插件不改一行，行为不变 |

---

## 插件作者四种写法

| 写法 | 效果 |
|------|------|
| 什么都不写 | 平铺——自己的分组下竖着排，和现在一模一样 |
| 只写 `section` | 两级树——自己的分组下有子节点，可折叠 |
| 写 `parentGroup` + `section` | 合并进父分组——归入父分组的子节点下 |
| 写 `parentGroup` 不写 `section` | 平铺进父分组——设置项直接挂在父分组下，不分子节 |

## 数据层

两个新字段，都在声明文件里，都是可选的。

### `ConfigurationProperty.section?: string`

写在每个设置项上——"我属于哪个子分类"。

### `ConfigurationContribution.parentGroup?: string`

写在插件 `plugin.json` 的 `contributes.configuration` 上——"我整体归入哪个父分组"。

## 保留项

### 1. 两级导航架构（核心）

`ConfigurationProperty` + `section`，`ConfigurationContribution` + `parentGroup`。

SettingsView 改动 ~80 行：左导航渲染两级树，右面板一次只渲染一个 section。

### 2. 修改标记蓝线

`inspectConfiguration(key).userValue !== undefined` → CSS class `modified` → `border-left: 2px solid var(--accent)`

### 3. 齿轮键盘可达

`.settings-row:focus-within .settings-row-gear { opacity: 1 }` + `:focus-visible`

### 4. Tab ARIA

`role="tablist"` + `role="tab"` + `aria-selected`

### 5. 切分组不 remount

去掉 `key={activeGroup?.pluginId}`
