## 一、版本号规则：CHANGELOG 是唯一真相源

软件更新点**不按本目录顺序走，也不按预设版本号走**——用着用着发现哪里不好，那个点就该更新，可能插队到任何规划点之前。流程：

```
发现更新点 → 进「待抉择池」（不占版本号）
          ↓ 拍板要做
开 v1.x-*/ 目录立项（此时才定版本号，颗粒自定）
          ↓ 做完
CHANGELOG.md 落版本段（版本号唯一真相源）+ 本 README 已立项表划销
```

MINOR/PATCH 颗粒、MAJOR 触发条件沿用 [CHANGELOG.md](../../CHANGELOG.md) 既有口径；本目录只管「点什么、做没做」，不管「号排到几」。
