# 01 · 壳侧目录（非平铺）

> 判据：一个 feature 一个夹；按职责再分子夹；⛔ 不在 `services/` 根上平铺一堆 `policy*.ts`。
> 依赖方向：`contracts` ← `ui`（纯展示）← 插件；`electron/policy` → `ipc`；`src/core` → `preload`。

## 二、文件职责（防止「什么都往 index 塞」）

| 文件 | 只做 | ⛔ 不做 |
|:--|:--|:--|
| `policy/index.ts` | 组合导出、事件订阅 | 不实现判定/不读配置 |
| `policy/modes.ts` | 枚举与文案键 | 不 import 任何 UI |
| `policy/risk.ts` | 风险登记表 | 不解析命令参数 |
| `policy/decide.ts` | 纯函数 | 不 IO/不弹窗 |
| `policy/protected.ts` | `userOnly` 判定 | 不维护 id 名单（元数据为准） |
| `policy/elevation.ts` | 请求→用户确认→写档位 | ⛔ 不暴露「批准」为命令 |
| `policy/policyState.ts` | 内存态 + 事件 | 不直接写 settings（走配置服务） |
| `aiPolicyCommands.ts` | GUI 动作的薄命令 | 不自己判风险（调 `policy`） |
| `src/core/services/aiPolicy/store.ts` | 订阅与缓存 | 不读 settings.json |
| `src/pool/shared/ai-policy/*` | 只画 | 不判定、不写档位 |

## 三、命名与硬编码纪律

- 档位值只走 `PolicyMode` 常量：`read|ask|auto|full` 字符串**只允许出现在 `modes.ts`**；其它处一律引用常量。
- 风险值只走 `Risk` 常量：`R0–R3` 字符串**只允许出现在 `risk.ts`**。
- 配置键 `ai.policy.*` 只允许出现在 `src/App/config/aiBridge.ts` 与 `policy/`；⛔ 池与插件里不出现字面量。
- 回执/确认文案：全部由 `receipt.ts` / 风险表的 `what/why` 生成；⛔ 各处手写第二份。
