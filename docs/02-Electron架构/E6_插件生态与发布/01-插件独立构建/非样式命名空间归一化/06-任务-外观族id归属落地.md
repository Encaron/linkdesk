## 二、禁区

- 🔴 🔴 **不许碰主题机制**：`commitTokens` · `theme:changed` 广播链 · `preload-pool` 写池 `:root` · `#ld-float-layer` · `[data-theme="light"]` · 域表 / 混搭 / 配方键 —— [29 号档](../样式命名空间归一化/29-主题系统保护条款.md) §一 P1–P7 ＋ §二「**唯一的真危险**」逐行适用。**发现自己那条规则会冻死主题系统 ⇒ 当场改规则，不许照做。**
- 🔴 **不许给 `check-theme-audit` / `check-theme-schema` / `check-font-scale-audit` 顺手收紧**。
- 🔴 **不许合并主题两本账**（除非 1.35 明确裁决合并并论证不碰 P1）。
- 🔴 **不许抛错**（[00 档 §2.7](00-整理档案.md)）。
- 🔴 **不许改名存量 10 主题 / 20 配方 / 4 语言包 id**（除非 1.35 论证同时满足「零 UI 变化」＋「`app.theme` 无损迁移」）。
- 🔴 **不许把 token（`--*`）拉进来**（CSS 系列件 6 的射程）。
- 🔴 **不许引白名单 / 基线 / 棘轮**。
- 🔴 **不许把「黄灯」写成「红」**（存量反例就是证据）。
- ⚠️ **上位约束**：**零 UI 变化**（除版本号；**主题统一调控 / 字体 / 翻译三条横切零回归**是硬判据）· 只做加法且名字一次定对 · [29 号档](../样式命名空间归一化/29-主题系统保护条款.md) 优先 · 对外宽容。
- ⚠️ 照旧：不跳 `npm run check` · 推前现测代理 · 推完 `ls-remote` 对 SHA · **提交只按路径 `git add <本格文件>`**。
