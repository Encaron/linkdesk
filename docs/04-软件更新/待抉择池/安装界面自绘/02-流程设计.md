# 02 · 流程设计（从双击到完成的九幕 + 选项时机）

> 本文管**交互流程**；技术落点见 [01-技术方案.md](01-技术方案.md)，视觉见 [mockups/E-混合提案.html](mockups/E-混合提案.html)（定稿）与 [mockups/E-卸载屏.html](mockups/E-卸载屏.html)。九幕与 mockup 的屏序一一对应（mockup 从第②幕开始演——第①幕系统绘制，演不了）。

## 一、选项时机总判（先答「什么环节问用户」）

- **路径 + 4 个勾选项 = 同一屏、安装开始前一次问完**（推荐方案甲：默认收进「自定义安装」展开区，主流程一次点击「立即安装」；方案乙向导式分屏列为备选）。理由：安装一旦开始不应再打断；国内主流安装器（微信/钉钉）均为「一次收集、全程免打扰」。
- **默认路径**：`%LocalAppData%\Programs\linkdesk`（决策点见 00-README §四.5——per-user 路径升级更稳，绕开 Program Files 权限差异）。

## 二、九幕全流程

| 幕 | 画什么 | 谁画 | 要点 |
|:--|:--|:--|:--|
| ① 双击 exe → UAC | 提权弹窗 | **Windows 系统**（不可自绘） | 能优化的只有 exe 元数据：图标（已有）、文件描述「LinkDesk 安装程序」、发布者名（需代码签名证书，当前「未知发布者」⚠️ 如实记录，不假装） |
| ② 自绘首帧（品牌过场） | logo 动画 + 产品名 + 版本 ＋ **语言下拉（右上角，默认中文，切换即时生效全界面）** | 引导器 | ~1.5s，可点击跳过；与壳内启动过场（v0.2.19 款）同一品牌语言；语言选择持久化见 §四末行，机制见 01 §五 |
| ③ 主屏 | 「立即安装」大按钮 ＋「自定义安装」次入口 ＋ 协议一行小字 | 引导器 | 默认路径展示；「自定义安装」展开 ⇒ 幕④ |
| ④ 自定义展开区 | 路径输入行（可改＋浏览）＋ **4 个勾选项** | 引导器 | 默认收起不挡主流程；展开态点「立即安装」同样开跑 |
| ⑤ 进度 | 分段真实进度 ＋ 风格动效 | 引导器 | 四段：解压文件(0–70) → 注册 linkdesk:// 协议(70–80) → 写系统项：快捷方式/右键菜单/PATH(80–92) → 收尾校验(92–100)；IO 抖动时动画平滑推进**不倒退** |
| ⑥ 完成 | ✓ ＋「运行 LinkDesk」默认勾 ＋「完成」 | 引导器 | 勾着点完成 ⇒ 首启；去掉 ⇒ 仅退出。失败分支见 §三 |
| ⑦ 首启交接 | 壳启动过场 | 壳（既有 v0.2.19 款） | 安装器退出与壳启动无缝相接（退出即启动，无黑屏空档） |
| ⑧ 升级安装（覆盖） | 同③–⑥但文案换「升级到 x.y.z」 | 引导器 | 读注册表带出**上次的选择**；完成后**不**弹「运行」默认勾（用户本就在用） |
| ⑨ 卸载 | 自绘卸载器（[mockups/E-卸载屏.html](mockups/E-卸载屏.html) 四帧；入口 = ARP「应用和功能」/ 开始菜单） | 引导器卸载模式（2026-10-01 翻案，NSIS 卸载器退役） | 反注册：快捷方式 / linkdesk:// 协议 / 右键菜单 / 编辑器注册 / PATH 项（精确匹配）/ 安装目录；**「保留我的数据」默认勾**——勾 = 留 userData（现状行为显性化：现行 NSIS 卸载从不碰 userData 也不提示）；勾掉 = 一并删除 userData（⚠️ 不可逆，实现时加行内二次确认，且须排在进程优雅关闭之后）⇒ 下次新装即**全新工作区＋仅出厂插件**（架构保证：userData = 唯一可写运行根，E6#15d；非随包插件只存在于 userData，随包插件首启由 boot 重新解压出厂 zip） |

## 三、失败兜底（不静默）

| 情形 | 行为 |
|:--|:--|
| 磁盘空间不足 | 进度前预检目标卷剩余空间，不足即自绘错误屏（需多少 / 剩多少 / 换路径入口） |
| 解压损坏 / 校验不过 | 错误屏（错误码 + 「重新下载安装包」链接指向 GitHub Release） |
| 中途取消 | 进度屏提供「取消」→ 回滚已解压文件后退出，不留半成品 |
| 已有实例在跑 | 检测 linkdesk 进程 → 询问关闭（「关闭并继续」/「稍后」），不静默杀进程 |

## 四、4 个勾选项清单（＝ 现状 E6#45 勾选页，原样搬进自绘 UI）

> 🔴 **勘误（2026-10-01）**：本档初稿把勾选项写成「桌面快捷方式/PATH/右键合并项/开机自启」——**记错了**。现状安装器（**E6#45**，2026-09-13 用户逐项拍板、照抄 VS Code）的附加任务页就是下面四项，默认值正是「两个勾」；桌面快捷方式**刻意不在页上**（electron-builder `createDesktopShortcut:true` 无条件创建，「出一个管不住的勾选框 = 骗用户」），开机自启**现状没有这项**。原文档：[../../02-Electron架构/插件生态与发布/07-Shell集成与多窗口/03-安装器勾选页与注册表.md](../../../02-Electron架构/插件生态与发布/07-Shell集成与多窗口/03-安装器勾选页与注册表.md)。

| # | 选项（现状勾选页） | 落点 | 现行默认 | 备注 |
|:--|:--|:--|:--|:--|
| 1 | 文件右键菜单「通过 LinkDesk 打开」 | `HKCU\Software\Classes\*\shell\OpenWithLinkDesk` | ☐ | 带图标；页挂在「选目录」与安装之间（customPageAfterChangeDir） |
| 2 | 目录右键菜单「通过 LinkDesk 打开」 | `...\Directory\shell\` ＋ `Directory\Background\shell\`（桌面空白处右键） | ☐ | 卸载三键整树删 |
| 3 | 注册为受支持文件类型的编辑器（13 个扩展名） | Capabilities ＋ OpenWithProgids（不抢默认程序） | ☑ | 弃用 electron-builder 自带 fileAssociations（无条件注册、接不上勾选框），`installer.nsh` 手写 |
| 4 | 添加到 PATH（重启终端后生效） | `HKCU\Environment`（标记＋备份法，卸载精确恢复不误伤） | ☑ | `linkdeskctl` CLI 垫片依赖它 |

> **是否新增「开机自启」项 = 待拍板决策点**（现状没有；要加建议默认不勾、写 `HKCU\...\CurrentVersion\Run`）——本件默认**不加**，四项原样搬。

> 幕⑧升级时：四项勾选默认值以**注册表现状反推**（现状已实现——右键键已在 ⇒ 保持勾、不在 ⇒ 维持默认；静默升级不复活用户取消过的项，`installer.nsh` 的 `lkInitTaskDefaults`）；自绘化后此口径原样保留。语言选择则持久化 `HKCU\Software\LinkDesk Installer → Language`（新加，见下）。
>
> 现状另有 **E6#42d 覆盖安装方向守卫**（`installer.nsh` customInit）：同版/降级弹窗确认、默认取消，静默 `/S` 直接拦（退出码 1602）。自绘化后此守卫**原样保留**——T3-b 时引导器先比版本，需要确认时弹自绘确认屏，否则才调静默安装；口径不变。
>
> 另有**语言下拉**（首帧右上角，非勾选项）：默认 `中文`，选择即时生效并持久化 `HKCU\Software\LinkDesk Installer → Language`，升级安装带出上次选择；语言清单由 `build/installer/i18n/` 目录枚举（加语言 = 加一个 json，零代码）——机制见 [01-技术方案.md](01-技术方案.md) §五。
