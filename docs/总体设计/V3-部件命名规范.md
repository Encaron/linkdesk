# V3 窗口部件命名规范

> 所有讨论、设计文档、代码注释统一使用这里的名称。不出现"三栏中间右边那个"。
> **命名原则：不绑串口、不绑软件名。** SerialMonitor / Serial_xxx / V3_xxx 这类前缀全部避免。终端可以叫 serial（它是串口插件），核心通用组件不能。

## 二、部件名称对照表

| 编号 | 名称 | 别称（不要用） | 说明 |
|:--:|------|------|------|
| ① | **标题栏** | — | Windows 原生，图标 + 标题 + 最小化/最大化/关闭。不参与 V3 布局 |
| ② | ~~顶栏~~ | TopBar | **Phase 4 移除。** Phase 3.5 之前用于串口控制 + 全局工具 |
| ③ | **侧栏** | SidePanel、左侧栏 | 左侧设置面板，内容随活跃标签页变化。Phase 4 从窗口顶部开始（衬 VS Code） |
| ③子 | **侧栏标题** | — | 侧栏顶部的标题行 + [◀] 折叠按钮 |
| ④ | **标签栏** | TabBar | 主区顶部的标签页列表，仅覆盖主区宽度。拖拽/分屏行为不动 |
| ⑤ | **图标栏** | IconBar、左侧竖条 | 最左边 42px，从窗口顶部到底部。Phase 4：内容动态化（插件注册），含 📟📊⚙🧩 |
| ⑥ | **主区** | MainContent、EditorZone、主显示区 | 标签页内容。分屏时多面板。keep-alive 不变。E5.7 Zone 英文名：MainZone |
| ⑦ | **状态栏** | StatusBar | 底部。**Phase 4 承载插件贡献的状态条目 + 全局项**（语言/主题/通知）。见下 |

## 三、标签页相关

| 名称 | 说明 |
|------|------|
| **标签页**（Tab） | 一个可切换的内容单元——终端标签页、工作台标签页、设置标签页、JSON 编辑器标签页 |
| **标签栏**（TabBar） | ④——横排显示所有标签页的容器 |
| **活跃标签页**（activeTab） | 当前正在显示/聚焦的标签页。决定侧栏内容 + 键盘焦点 |
| **[×] 关闭按钮** | 标签页右侧的关闭按钮 |
| **[⨁] 新建按钮** | 标签栏最右侧的新建标签页按钮 |

## 四、分屏相关

| 名称 | 说明 |
|------|------|
| **面板**（Pane） | 分屏后的一个独立显示区域。左面板 / 右面板，或上面板 / 下面板 |
| **分屏**（Split） | 拖标签页到主区边缘形成左右/上下双面板 |
| **分割条** | 两个面板之间的可拖拽分隔线 |
| **drop zone** | 拖拽标签页时主区边缘的高亮吸附区域 |
| **drop indicator** | drop zone 的半透明蓝色高亮 |

## 五、图标栏相关

| 名称 | 说明 |
|------|------|
| **图标栏**（IconBar） | ⑤——最左边 42px 的图标列 |
| **图标按钮** | 图标栏中的单个按钮——📟 / 📊 / ⚙ / 🎨(未来) |
| **选中态** | 图标按钮的蓝色指示条 + 光晕 |

## 六、侧栏相关

| 名称 | 说明 |
|------|------|
| **侧栏**（SidePanel） | ③——左侧设置面板，220px 默认宽度 |
| **侧栏标题** | 侧栏顶部的标题行——标题文字 + [◀] 折叠按钮 |
| **侧栏折叠** | 侧栏折叠为 28px 窄条，只显示 [▶] 展开按钮 |
| **侧栏内容** | 侧栏的主体内容——终端设置 / 卡片属性 / 导航菜单（随活跃标签页变化） |

## 七、顶栏相关（Phase 4 移除）

> Phase 4 去掉顶栏。对标 VS Code——无独立全局工具条。串口控制移入终端插件内部工具栏。语言/主题移到状态栏。图标栏从窗口顶部开始。

| 名称 | 说明 |
|------|------|
| ~~顶栏（TopBar）~~ | Phase 4 移除 |
| ~~串口控制区~~ | 移入终端插件内部（`COM3 ▼ 115200 ▼ [● 打开]` → 插件自管） |
| ~~工具区~~ | 语言/主题移到状态栏右下角 |
| ~~☰ 汉堡菜单~~ | 随顶栏一起移除 |

## 七-B、状态栏条目（Phase 4 新增——插件贡献点）

状态栏条目由插件在 `plugin.json` 中声明。核心全局项（语言/主题/通知）总是存在。

| 名称 | 来源 | 说明 |
|------|------|------|
| **连接状态** | 终端插件 | `● COM3 已连接`——可点击打开终端设置 |
| **流量计数** | 终端插件 | `TX:1,234 RX:56,789`——纯显示 |
| **协议指示** | 协议插件 | `方括号协议`——可点击切换协议 |
| **语言切换** | 核心 i18n | `中:EN`——点击弹出语言面板。总是存在 |
| **主题切换** | 核心 ThemeEngine | `☀`——点击弹出主题面板。总是存在 |
| **通知铃铛** | 核心通知队列 | `🔔 (3)`——点击弹出通知历史。总是存在 |

## 九、E5.7 Zone 系统登记（2026-08-13）

> E5.7 极简Pool 引入 Zone——布局区域 = 一个 React 组件文件（`src/pool/zones/`）。**中文名沿用本规范固定名称**（Zone 是"区域"的实现形式，不发明新名）。

| `IconBarZone.tsx` | 图标栏 | ⑤ |
| `SidebarZone.tsx` | 侧栏 | ③ |
| `MainZone.tsx` | 主区 | ⑥——标签栏+标签页整体（每面板自带标签栏 35px）。EditorZone 更名而来 |

| `RightSidebarZone.tsx` | 右侧栏 | 新增（未来）——右侧面板 |
| `StatusBarZone.tsx` | 状态栏 | ⑦ |
| `FloatingLayerHost.tsx` | 浮层 | 新增——Toast/ContextMenu/QuickPick/Dialog 的 position:fixed 容器 |

**已取消：** TabBarZone——独立标签栏 zone 不建，标签栏留在主区内每面板自带（E5.6#16.5 自包含教训）。TopBarZone（2026-08-13）——与已移除的②顶栏（TopBar）重名；面包屑若做，并入主区每面板（自包含原则同 TabBarZone）。
