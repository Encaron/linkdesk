# 插件市场

![marketplace 场景封面「货架的窗」（E6#69b 三图模型——整幅场景封面住 README，市场展示位走 Type-2 彩色图）](resources/cover.svg)

LinkDesk 的应用商店——**装插件、看插件、管插件，都在这一个插件里**。

> 最会被人抄的那只插件，是它自己。所以它的 README 不能是空的——你正在读的这份，就是市场详情页「详情」页签会显示的那份内容本身。

## 这是什么

LinkDesk 的插件入口（出厂自带，图标栏顶部）。对标 VS Code 的扩展视图：**左边逛货架，右边看说明书。**

- 插件 ID：`marketplace`
- 打开方式：图标栏顶部 · 侧栏常驻
- 标签页行为：单例（只有一个插件详情页）

**它自己也是一个插件。** 货架是它画的，但货架上的每一件（包括它自己）走的都是同一套 `plugin.json` 声明——市场不认插件 ID，认识的是声明字段。

## 你会看到什么

**左栏（侧栏）**——最上面是搜索框，下面四个折叠区：

| 区块 | 装的是什么 |
|:--|:--|
| **已安装** | 已经在盘上的插件，带版本号；有新版的会亮出「可更新」 |
| **探索插件** | 目录里的货——装之前就能看说明、看更新记录 |
| **已禁用** | 被停用的插件，一键启用回来 |
| **内置** | 随软件发货的那批（`core: true`） |

**右栏（主区）**——插件详情页，三个页签：

- **详情**——截图画廊 + README 正文
- **功能**——插件贡献了什么（命令、视图、配置…），来自它的 `plugin.json`
- **更改日志**——它的更新记录

页头有封面缩略图、名称、版本、作者和**动作条**（安装 / 更新 / 卸载）。装之前看的是目录里的说明，装之后看的是包里的说明——**同一套界面，两种数据源。**

## 怎么用

1. **逛**——左栏「探索插件」翻目录；搜索框直接过滤。
2. **看**——点一行进详情页。**装之前 README 和更新记录就能看**（这两样会随目录一起发布，不用先下载整包）。
3. **装**——点「安装」。**每次都会弹确认卡**，看清楚再点。
4. **更新**——详情页有新版就亮「可更新」；也可以在心里勾「自动更新」，让它在后台自己装完再通知你。
5. **卸**——动作条「卸载」。`core: true` 的插件（含本插件）不显示卸载按钮。

## 三条纪律（作者与用户都该知道）

**① 「更新目标」和「显示的最新版」是两个值。**
你在版本下拉里挑了某个旧版，市场会记下「这个人想停在旧版」——**自动更新从此跳过它**，界面上一个字都不多说。这是尊重你的手动选择，不是坏了。想解除，勾一下「自动更新」或在下拉里选回最新版即可。

**② 装之前能看说明，是因为说明跟着目录走，不跟着包走。**
README 和更新记录在目录（`marketplace.json`）里各有一份；装完切成读包内的 `README.md` / `CHANGELOG.md`——**装的是哪一版，说明就是哪一版。** 作者不写 `CHANGELOG.md`，详情页的「更改日志」页签就是空的（诚实地说「未附带」，不编）。

**③ 目录是可以加的。**
`marketplace.marketplaceSources` 里加一个仓库 URL，就能发现那个作者的全部插件（对方仓库根目录放一份 `marketplace.json`）。官方目录是默认项之一，不是唯一项。

## 怎么读这份源码

| 想看什么 | 去哪 |
|:--|:--|
| 入口 | `src/index.tsx` |
| 侧栏五个 surface（搜索 / 已安装 / 探索 / 已禁用 / 内置） | `src/views/sidebar/` |
| 详情页（三页签 + 页头 + 动作条 + 元数据侧栏） | `src/views/detail/DetailView/` |
| 安装确认卡 | `src/views/confirm/` |
| 目录模型（`marketplace.json` 解析、多源合并、版本挑选） | `src/services/marketCatalog/` |
| 目录来源（拉取、5 分钟缓存、来源配置） | `src/services/marketSources/` |
| 更新发现（启动调度 → 计划 → 执行 → 通知） | `src/services/updateDiscovery/` |
| 安装闸（版本 / 依赖 / 最低宿主版本判定） | `src/services/installGate.ts` |
| 每个插件的更新意愿（自动更新 / 停旧版） | `src/services/installedUpdateMeta.ts` |
| 声明（两个容器的贡献点都在这里） | `plugin.json` |
