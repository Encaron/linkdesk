### 3.2 屏幕与状态机

- **安装 6 态**：`uac`（系统绘制，壳内只放提示帧）→ `home`（品牌行＋大标题＋立即安装＋自定义展开区）⇄ → `progress`（四段真实进度）→ `error`（失败分支）｜`finish`（彩粒＋运行勾选）。DOM 挂点与类名 = mockup 的 `#s-*` 区块，**类名即规格**。
- **卸载 4 态**：`confirm`（数据保留默认勾＋红色卸载）→ `running`（运行中检测，可「稍后」）→ `progress`（四段清理，**无取消**，墨色条）→ `finish`（数据去留徽章如实呈现）。
- **mockup 脚手架不算产品**：`.cap`/`.note`/「重新播放」/「演示：失败分支」/UAC「是」按钮是设计注记与演示控制，实现时不存在。
- 真实窗口 = mockup 的 `.shell+.win` 全幅渲染（无边框窗）；光球/微尘作为窗内背景层（inset 0），页面外不存在「桌面」层。
- 🔴 **2026-10-02 修订（3d #2）：页面外现在有「桌面」了**——真窗口做成**逐像素透明**：建窗后 `WS_EX_LAYERED` ＋ `SetLayeredWindowAttributes(…,255,LWA_ALPHA)` ＋ `DwmExtendFrameIntoClientArea(-1,-1,-1,-1)`，controller 就绪后经 `ICoreWebView2Controller2::put_DefaultBackgroundColor{0,0,0,0}` 让 WebView2 也透明。桌面色随之从 `body` 挪到页面新增的 `.frame`（`position:absolute;inset:0`，`border-radius:32px;background:var(--desk);overflow:hidden`）——**body 底色会传播到画布，画布不吃半径**，故半径与裁切都必须挂 `.frame`；窗口轮廓＝`.shell` 的 32px 弧线，原先系统给的那圈 ≈8px 小圆角（`DWMWCP_ROUND`，半径不可设）与它露出的 `--desk` 灰楔形一并消失。**降级门**：宿主三段 ＋ `put_DefaultBackgroundColor` 全成功才把角偏好翻成 `DWMWCP_DONOTROUND` 并给页面注入 `data-alpha`（`app.css` 整段透明样式挂这个属性）；缺任一半 ⇒ 一字不翻，退回今天的不透明＋系统圆角（绝不半成：半成会露未绘制像素＝黑角）。**代价照旧**：无边框窗（透明前后）都没有系统阴影；透明楔形区仍吃鼠标点击；Win10 无角偏好、透明机制待复测。详见 3d-评审记录.md 第 2 条 + `bootstrapper/README.md` 件 2c 段。

### 3.3 动效清单（全 transform/opacity；`prefers-reduced-motion` 降级必须保留状态语义）

入场 enter .8s · shimmer 流光 1.6s 循环 · 彩粒 burst 一次 40 粒（仅安装完成屏）· 光球漂移 22/26s alternate · 微尘 rise 9–19s · 对勾描线 .7s（.25s 延迟）· 勾选弹入 .3s。进度条推进 .3s linear（**数值只前进不倒退**）。

### 3.4 i18n 装载器规格（01 §五的实现面）

- `build/installer/i18n/zh-CN.json`（默认）＋ `en.json`；**语言清单 = `fs.readdir` 扫描**该目录（加语言 = 加文件，零代码）。
- key 命名按屏：`installer.home.title` / `installer.progress.step1` / `installer.uninstall.confirmTitle` …（完整 key 面 = 两份 mockup 全部文案，无例外）。
- 渲染：`t(key)` 查表 → 缺 key 回落 `zh-CN` → 再缺回落 key 名；切换即时重渲染（mockup 的 `[data-i18n]` 补丁即参考实现）；持久化 `HKCU\Software\LinkDesk\Installer → Language`，卸载器与升级安装读同键。

### 4.2 件 1a · 引导器壳 spike（先验证再铺开）

- **验收**：本机出 ≤5MB 单文件 exe；无边框窗口 780×570；加载 `app.html` 全屏渲染；DevTools 可开（`--debug` 参数）；Per-Monitor V2 DPI 声明。
- **推荐路径**：C++ Win32 ＋ WebView2（NuGet `Microsoft.Web.WebView2`，`wWinMain`＋`CreateCoreWebView2EnvironmentWithOptions` 约 200 行；资源加载用 `SetVirtualHostNameToFolderMapping` 映射 `https://installer.local/` → 本地目录，避开 file:// 限制）。
- **备选**：C# WinForms ＋ WebView2（开发快，但 self-contained 体积 70MB+ 不可接受、framework-dependent 依赖系统 .NET——spike 里量完再定，C++ 是默认）。
- **WebView2 运行时缺失兜底**：检测注册表/系统，缺失则弹系统对话框给官方 runtime 下载链接（Win10/11 绝大多数自带）。

### 4.3 件 2 · 安装活（风险最集中的一件，🔴 先读）

- **载荷**：electron-builder `target: 7z` 产出 `app-<ver>.7z`（= win-unpacked）。
- **单文件拼合**：安装包必须仍是单 exe（下载链接/latest.yml 语义不变）。**方案 A（默认）**：`copy /b bootstrapper.exe + marker + app.7z linkdesk-setup-x.y.z.exe`，引导器启动时读自身找 marker 偏移取 7z 流（7z 格式支持从流解压）；**方案 B**：随包 `7z.exe`。**spike 先行**，量体积与解压性能。
- **解压与进度**：调 7z（`7z x -o<dir> -y -bsp1` 读 stdout 百分比）或 7z SDK 回调 → 映射到四段进度的 0–70%。⚠️ 7-Zip 许可（LGPL＋unRAR 限制）在 06-发布管理发布清单注记。
- **注册表写入清单（照抄 `installer.nsh` customInstall，key 逐条不得增删）**：13 扩展名 OpenWithProgids＋Capabilities（.txt .py .js .json .md .html .css .ts .tsx .yaml .xml .csv .log）、`LinkDesk.Document` ProgId 三键、`Software\LinkDesk\Capabilities` 两值、`Software\RegisteredApplications`、右键三键（`*\shell` / `Directory\shell` / `Directory\Background\shell` 的 `OpenWithLinkDesk`，带 Icon）、PATH（`HKCU\Environment`，**PathBackup/PathAdded 标记法**，写后 `SendMessageTimeoutW(0xFFFF,0x001A,0,"Environment")`）。
- **ARP 注册**（新）：`HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\<沿用 electron-builder 现有键名格式>`：DisplayName/DisplayVersion/Publisher/DisplayIcon/UninstallString/NoModify/NoRepair/EstimatedSize。🔴 **兼容性**：必须沿用现键名（版本守卫与覆盖安装靠它认旧装），实现前先在实机读一次现装版本的键名照抄格式。
- **版本守卫**（E6#42d 口径移植）：JS 重写 semver 比较（参照 `src/core/utils/plugin/semverUtils.ts`，**不搬运只对照**）；同版/降级 → 自绘确认屏（对应 mockup 无此屏，**复用 error 屏骨架**加「仍要安装」）；静默模式直接退 1602。
- **更新链**：壳内更新器下载的 artifact 仍是 `linkdesk-setup-x.y.z.exe`（= 引导器单文件），静默安装 = 引导器 `--silent` 参数（全静默：默认选项直装，守卫拦截时退 1602）。**默认选项来源**：升级时按注册表现状反推（02 §四升级口径）。
- **卸载器**：同一引导器 exe 以 `--uninstall` 运行（UninstallString 指向 `<installdir>\uninstall.exe --uninstall`（🔴 2026-10-03 改判，见台账 §三 #4-改判））；清理逐条移植 `customUnInstall`；**「保留我的数据」**默认勾，勾掉 ⇒ 优雅关闭后删 `%AppData%\LinkDesk` 整目录（⚠️ 不可逆——UI 行内二次确认，02 §二幕⑨）；卸载器自删 = 子进程 `cmd /c ping -n 2 127.0.0.1 >nul & del <自身>`。
- **优雅关闭**：枚举顶层窗口发 `WM_CLOSE`（**禁止 taskkill 硬杀**），10s 超时回「稍后」。
- **关闭按钮与 WM_CLOSE 分流**（无边框窗无系统 X，全部自管）：右上角自绘 ✕（样式 = mockup `.xbtn`）／Alt+F4／Esc 三路汇入同一处理器，按阶段分流——主屏/确认屏直退（未写入零损失）；安装进度 = 走取消回滚分支；**卸载进度 = ✕ 置灰且 Alt+F4 被吞**（清理必须走完）；完成屏 = 与「完成」按钮等价。
- **无标题栏窗的拖拽区**：brand 行与各屏空白区注册为 HTCAPTION（可拖动窗口）；按钮/输入/链接排除。**Enter = 当前屏主按钮**（home=立即安装）；路径行内校验（非法字符/无权限）错误**就近显示在输入框下**，不改全局错误屏语义。
