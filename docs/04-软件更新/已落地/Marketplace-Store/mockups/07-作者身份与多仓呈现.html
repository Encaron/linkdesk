设计说明 · 作者身份与多仓

2026-11-22 拍板版。HTML7 是 HTML6 的可操作副本；新增部分演示「作者—仓库—插件」三层与单仓上下文，不代表最终代码。

一句话

我也只是一个插件作者，区别只是我是官方。 商店永远锁定一个「当前仓库」；作者是身份，仓库是门面，插件是货架。没有“全源”首页/分类/排行。

当前仓库模型（D1）

  • 市场首页 = 当前仓库自己的首页；首次打开 = 官方市场仓。
  • 切仓后，首页/分类/搜索/排行/全部插件全部跟着切。
  • 首页不出现其他作者、不出现其他作者的仓；跨作者只在作者页/作者坞发生。

仓库首页槽位

槽内容规则
槽 1第一个 hero声明才有；没有 hero → 槽 2 变第一视觉
槽 2当前作者的仓库卡横排硬保留；右侧「查看全部 N 个插件」
槽 3+作者声明板块按 sections 原顺序；第 2 个 hero 就地渲染

仓库卡只在作者自己组内交换；首页槽 2 与全部插件页也读同一份仓顺序。

作者页（一页两模式，D3）

  • 浏览：作者组头（源数/仓数/插件数）+ 底下他的仓卡；组头单击折叠（▾/▸），点仓进首页。
  • 管理来源：同一棵作者组树 + 源行（URL/状态/停用/刷新/移除）；来源页并入；组头单击折叠。
  • 作者容器卡：外层同一张容器卡，浏览槽放仓卡、管理槽放源行；一套拖动控制器，两页不各写一套。
  • 「添加网络源」「添加本地插件」常驻作者页页头，不是只靠右上角加号。
  • 页头排序提示可关闭 ×；关掉后工具栏留小 ? 重开；关掉后记住（ui.prefs）。
  • 空态「还没有添加作者源」住在作者页/作者坞；首页不再出现。

排序（D4）

  • 唯一真相源 = marketplaceSources 数组顺序；所有页面同源。
  • 默认顺序＝安装/添加顺序：官方核心仓预装在最前；之后添加的源依次追加；用户拖动后按手动顺序。本地组固定末尾、不参与作者排序。
  • 作者坞列表/胶囊头像读同一份作者顺序；选中用高亮，不强行置顶。
  • 作者坞底部提示在「作者页/管理来源」同一行右侧；可关闭 ×，原位 ? 重开；关掉后记住。
  • 长按拖作者容器到另一作者容器上 = 两者交换；长按仓卡/源行到同作者目标上 = 两者交换；⛔ 跨作者不换。
  • 无上下箭头；组头单击折叠；整条组头/仓卡/源行长按 380ms 拖动（不是只抓手）；提前移动=原生文字选择/复制；Esc 取消。
  • 拖动时整条抬起虚化跟随（ghost）；目标卡高亮 + ⇄；⛔ 无上下插入线；松手两项交换并短暂高亮。
  • 浏览页仓卡网格 1–4 列随容器宽度变；交换按目标卡，不按坐标；拖到其他作者卡上只提示不能交换。
  • 排序也有命令面（见设计文档）；产品界面不显示 AI 区/命令名。

删除权（D5）

源能删？能停用？
官方核心仓（设置/市场/核心插件）⛔ 不能⛔ 不能
官方预置源 / 官方作者其他仓✅ 能✅ 能
第三方作者仓✅ 能✅ 能

作者无权决定自己删不删；第三方清单里的 core: true 不认。官方更新可预置源，但预置 ≠ 锁死。

来源/仓库行的「内置」标签取消；只有官方核心仓标「不可移除」。本地组固定末尾、不可拖。

只有安装即存在的官方核心仓锁位置有意义；其他仓添加顺序不确定。锁定 ≠ 冻结：官方核心仓仍可单仓刷新。

停用 / 移除

  • 停用：源还在、不拉取；插件退出商店/分类/搜索/排行；已装插件照常运行；点启用即恢复，不用重新添加。
  • 移除：删源与缓存；已装插件默认保留（可勾选卸载）；要再显示必须重新粘贴源地址添加。
  • 每行都有单仓刷新（含官方核心仓）；顶部「刷新内容」是全量刷新，不能替代单仓刷新。
  • 刷新/检查更新必须 toast 结果：有更新报数量、没更新说「已是最新」、失败说失败；纯导航/折叠/展开/排序视图不 toast。
  • 已装/已购按 pluginId 识别；授权住壳 licenses，不随源删除而消失。

分类（只算当前仓库）

  • 原瓷片样式，8 个分类，点一下原地展开；箭头旋转向下。
  • 只列本仓有货的分类；没有“网络”就不出网络。
  • 左栏分类计数 = 当前仓库计数；空分类灰显/隐藏。
  • 分类页（开发/文档/硬件…）不跟作者/仓手动顺序，按既有排序（下载/更新/名称/作者/仓）。
