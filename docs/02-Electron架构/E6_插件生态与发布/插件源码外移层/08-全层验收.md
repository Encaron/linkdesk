## 一、总账（照 [总档案 §五](00-整理档案.md) 七条逐条跑）

### 1.1 结构账

```bash
# ① 壳仓 plugins/ 下只剩夹具
git ls-files plugins/ | cut -d/ -f2 | sort -u
#   期望：panel-demo / floating-panel-demo（发货插件归零）

# ② 壳侧绑定归零
grep -rn "plugins/\(editor\|file-tree\|marketplace\|settings\|python\|serial-monitor\)" \
  tsconfig.json vitest.config.ts eslint.config.js knip.json package.json scripts/*.mjs
#   期望：零命中，或每条都有解释（夹具/注释/文档指针）
```

### 1.2 独立性账（**每条都在壳仓之外验**）

```bash
# 逐只：全新临时目录
git clone <插件仓> /tmp/verify-<id> && cd /tmp/verify-<id>
npm ci && npm run build && npm run lint && npm run validate
ls *.linkdesk-plugin        # 期望：产出 zip
```
🔴 **不许在壳仓里验**——在壳仓里 `npm ci` 会把根 workspaces 的一切都装上，**那验不出独立性**（这正是本层要治的病）。

### 1.3 分发与新鲜度账

> 🔴 **2026-09-14（7.4 轮）口径订正**：出厂随包 = **账里 `seed:true` 的那些（今天 6 只基础插件）**——
> 决策 D4 原写「其余不随包、纯市场」，7.4 轮由用户亲口确认并落地。**账覆盖官方全集（18 条）**，
> 但**箱子只装 seed 集**：`lock.plugins.length` 与「箱内 zip 只数」从本轮起**是两个数**，别再混读。

```bash
npm run check:bundled-freshness                # 期望：绿灯（默认联网比对官方目录）
npm run sync:bundled -- --offline              # 期望：绿灯（只验「箱内 ≡ 账」）
node -e "const l=require('./bundled-plugins.lock.json'); console.log(l.plugins.length, l.plugins.filter(p=>p.seed).length)"
#   期望：18 条（官方全集）  6 只（随包集 = D4 基础插件）
ls bundled-plugins/*.linkdesk-plugin | wc -l   # 期望：= 上一条的「随包集」数（箱子 ≡ 账的 seed 集）
```

## 二、回归对照（本层最容易忽略的一条）

**`npm run check` 的覆盖会变小**——插件从壳的编译/测试图里摘出去了。**这不是回归，是本层的目的之一**（壳只考壳）。

但要**如实登记前后数字**（🔵 **L7 前基线已于 2026-09-14 L7 立案当天实测**，见下表「L7 前」列——**这就是比对的基准，别重测**）：

| 项 | L7 前（2026-09-14 实测） | L7 后 | 说明 |
|:--|:--:|:--:|:--|
| 壳仓 vitest 文件数 / 用例数 | **178 文件 / 2,429 用例**（`npm run check` EXIT=0） | **153 文件 / 2,063 用例**（截至 7.4 轮末，2026-09-14 复测；`npm run check` EXIT=0） | 下降量 = 25 个测试文件（**逐条核对去向，不许只说「少了就对」**）；7.4 轮只改了 7 例的**输入来源**（种子 → 冻结快照），**没增删测试文件** |
| `npm run check` 耗时 | 记录 | 记录（其中 vitest 段 20.2s） | 应该变快 |
| **官方插件只数**（备了案、在官方目录里、可装回来） | **18** | **18** | **必须不变**（少了 = 迁移丢件） |
| **随包种子只数**（箱子里的 zip） | 18 | 🔴 **6**（7.4 轮按 D4 收箱，2026-09-14 用户拍板） | **这一项本轮就是变小的**——不是丢件：少掉的 12 只仍在官方目录、可随时装回（见 §1.3 口径订正与 [05 §七.6](05-出厂种子保鲜.md)） |

🔴 **判据：官方插件只数不变（18）+ 被收箱的 12 只都能从市场装回 + 每个消失的测试文件都能在插件仓里找到对应物。**
