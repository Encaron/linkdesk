## 二、Phase 1 圆角参考系唯一权威（#118）

**方案**：滑杆 = 系统标尺上「标准圆角」一个值。六档（xs..2xl）+ pill 全部平铺 = 滑杆值，clamp 进 [0,32]。删 ratio 概念（`值 ÷ 主题值` × `值 × 主题值` 全灭）。

选此方案的判据：禁止硬编码（零新增常量 vs B 的硬编码阶梯表）· AI 友好 layer 3（「滑杆 16 → 全 16」单心智模型）· 归一化（一条规则）· 语义（滑杆=用户全局覆盖一个值；六档阶梯=主题作者表达，followTheme 不动）。

**改动**：
- `tokens.ts:251-264` `applyRadiusAbsolute`：删 `md` 读取与 `ratio` 计算；六档全写 `clampRadiusPx(absPx)`px。注释改写（删「保主题层级性格」矛盾注释，改标尺语义）。
- `tokens.ts:296-301` ①c pill 直写已绝对，不动。
- 测试更新（断言非 md 档比例结果的 2 处）：
  - `recipe.test.ts:110-116`：`applyRadiusAbsolute(8, {md:"6px"})` → sm 从 `"0px"` 改 `"8px"`（全档=滑杆）。
  - `seeds.test.ts:307-311`：`applyRadiusAbsolute(12, {md:"8px",sm:"4px",lg:"12px"})` → sm `"6px"`→`"12px"`、lg `"18px"`→`"12px"`。
- 其余路径零触碰：followTheme 主题不动；`app.surfaceRadius` 存在性门控语义实现时核对。

**验证**：`npm run check` 全绿；单测断言覆盖「六档+pill 全 = 滑杆值」「0 → 全 0 直角」「32 → 全 32」；CDP 三主题（普通/直角/全胶囊）滑杆 0/16/32 六档+pill 全一致；followTheme 主题零变化。

## 八、E5.8#125 玻璃合成层漏 zone 切片图透明度（2026-08-27，commit `844768d8`）

**现象（用户报）**：`app.zoneBackgroundImage` + `app.backgroundImage` 都设图，`app.glassOpacity` 拉到 0 → 期望全窗背景图（backgroundImage）透出，实际只有 zoneBackgroundImage 变亮、全窗背景不透。

**根因（非 Phase 11.17 回归）**：git log 验证 #118-#124（浮层权威/圆角标尺/归一化清扫）零玻璃代码——根因在 **Phase 11.16 玻璃合成层**。`synthesizeGlassSurfaces` 激活时只把 `SURFACE_COLOR_KEYS`（8 个 `bg-*` 表面配色键）合成 `color-mix` 半透明，但 **zone 切片图漏网**：zone 表面 `::after`（挂 `--surface-bg-image` = zoneBackgroundImage）opacity 恒 `var(--surface-bg-opacity,1)` = 1，不随玻璃 alpha 合成。层叠上 zone 表面（z1）盖在 `.background-layer`（z0 全窗背景图）之上 → glassOpacity=0 时表面配色全透明，但 zone 切片图仍不透明盖死全窗背景图 → 「只有 zone 图变亮」。

**修复**（`tokens.ts` `synthesizeGlassSurfaces` + `constants.ts` `GLASS_SURFACE_KEYS` + `index.css` zone `::after`）：
- 合成层新增派生键 `glass-surface-bg-opacity = 原 surface-bg-opacity × spec.alpha`（active 且 `surface-bg-image` 非 none 时写；panorama 无 surface-bg-image 天然跳过）。
- zone `::after` opacity 改 `var(--glass-surface-bg-opacity, var(--surface-bg-opacity, 1))`——优先读派生键，未激活/无派生键回退原值（零变化回主题原生）。
- **不改原键 `surface-bg-opacity`**——播种反推 `app.backgroundOpacity` 读它（seeds.ts:108），改写会污染播种。
- `glass-surface-bg-opacity` 进 `GLASS_SURFACE_KEYS`（随 variables 广播给池，stale 清理由 lastCommittedKeys 差集承担）。

**验证**：
- 单测 1298 绿（玻璃测试 12→19）：alpha 0/0.4 派生键；用户 backgroundOpacity 0.5×alpha 0.6→0.3 相乘；未激活不写派生键原键不动；无 zone 图（none/空/纯 panorama）不写派生键；applyRecipe 集成（zone 图+glassOpacity=0 → :root 落 0，清配置回空；zone 图+blur → 派生键 0.5）。
- **CDP 实机直验（用户当前配置零改动只读）**：`:root` `glass-surface-bg-opacity`=**"0"** 已落（原 surface-bg-opacity 1 × alpha 0）+ `glass-surface-alpha`=0 + `bg-window`=`color-mix(…calc(0 * 100%), transparent)`（表面配色全透明）；挂 zone 图的 `main-zone`/`panel-zone` `::after` **computed opacity=0**（切片图全透）；无 zone 图的 `side-panel-zone` ::after opacity 1 但 bgImage=none 无影响；`.background-layer`（z0 fixed）sailor-moon.jpg 挂载 → **全窗背景图透出**。修复目标达成。
