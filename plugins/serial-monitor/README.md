# 串口监视器（serial-monitor）

> LinkDesk 官方 · **第一个视图插件** · 接收区 + 发送栏 + 侧栏设置
> **理念一句话：** 它不猜你连的是什么设备——只把「电脑和机器之间的对话」原样摊开在你面前。开发板、传感器、无人机、下位机……任何用串口说话的设备，你都在这里看它进来的字节、发你要出的字节。它是通用容器基础设施的第一次真实验证，也正因如此，它**不绑定任何特定用途**。

## 这是什么

串口监视器是 LinkDesk 的第一个视图插件（出厂预装，可卸载）：串口工具栏选端口/波特率打开后，接收区实时滚进设备数据，发送栏打字回车就发出去。**它本身不含任何「懂某种设备」的逻辑**——HEX 也好 ASCII 也好，你看到的就是串口线上原原本本的东西；想进一步把字节解析成含义，请配协议解析插件（见下文建议）。

## 界面三块 + 一盏灯

- **接收区**（CM6）：数据实时进来。开关**时间戳**、切**文本/HEX** 编码、设**换行符**（很多设备靠 `\r\n` 断句）、显隐**行号**；**暂停**滚动盯某一帧、**清空**、**复制/全选**、**搜索**、**导出日志**留档。
- **发送栏**：敲一行发一行，文本与 HEX 两态切换、**消息回显**开关；常用指令存成**快捷发送**，右键条目可回填到发送区 / 编辑 / 删除。
- **侧栏**：**会话列表**（每个串口一个会话、一个标签页，互不串台）+ **收发设置**面板。
- **状态栏那盏灯**：连接时亮青、断开变灰，是这插件自己放上去的，跟着端口状态实时走。

一个细节：关掉会话标签页时会先问你「要不要关串口」（可关确认提示）——先收尾、再关页，不会留下偷偷开着的端口。

## 上手

1. 设备插上电脑 → 打开串口监视器，工具栏选 **端口** + **波特率**（常见 115200 / 9600）。
2. 点 **打开**——连接灯亮起，接收区开始滚数据。
3. 下方发送栏输入（如 `AT+RST`）回车 → 发出去，回显或设备的应答看得清清楚楚。

收不到 / 乱码？先查三件事：**波特率对不对**、**换行符匹配不匹配**（设备回 `\n` 你却设 `\r\n`，行会粘连或粘成一坨）、**HEX 视图**看原始字节是不是编码问题。

## 建议搭配（它自己声明的关系）

| 插件 | 关系 | 用途 |
|---|---|---|
| protocol-bracket | 建议（suggests） | 不装则只能看**原始数据**；装上它，字节才能解析成有含义的字段 |
| workspace | 推荐（recommends） | 配合它的**卡片**把串口数据可视化 |

## 设置

| 设置 | 含义 | 默认 |
|---|---|---|
| `serial-monitor.statusBar.connection` | 状态栏显示连接状态指示灯 | 开 |
| `serial-monitor.confirmOnClose` | 关闭会话标签时先确认（并收尾关串口） | 开 |

侧栏「收发设置」面板内还有：时间戳、编码（文本/HEX）、换行符、回显、行号——随开随关，改动即生效。

## 常用命令（右键菜单 / 命令面板）

| 命令 | 做什么 |
|---|---|
| 复制 / 全选 | 复制接收区选中内容 |
| 清空接收区 / 清空发送区 | 一键清空对应区 |
| 暂停接收 | 冻结滚动，盯住某一帧（再按恢复） |
| 导出日志 | 把这一会话的收发记录导出成文件留档 |
| 切换到 HEX 发送 / 关闭消息回显 | 发送行为开关 |
| 隐藏行号 | 接收区更紧凑 |
