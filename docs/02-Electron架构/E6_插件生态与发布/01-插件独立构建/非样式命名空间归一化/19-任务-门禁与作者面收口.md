### 2.2 账定稿

- 五个家族齐全（命令前缀 / 设置键 / 外观 id / 上下文旗子 = 现状四件；i18n 只出文档不出账）。

- **`version` 字段**（先例有）。
- 🔴 **账的生成器要能被独立复跑**（照 `npm run backfill:catalog-identity -- --check` 的形态：`--check` 空跑核验 ＋ `--self-test`）。

### 2.3 作者面两棵树（**中文维护者树 ＋ 英文主显树**）

新增/改写的内容（**逐条落**）：
1. **「宿主保留的名字」总表**（命令前缀 / 设置键 / 外观 id / 上下文旗子）——**规则句 ＋ 表**；
2. **一句话规则**：「**宿主保留的不许占；插件自己写的名字必须带 `<pluginId>` 前缀**」（**不需要查表就能记**）；
3. 🔄 **「三类全局概念名为什么不需要带前缀」**：**文件关联扩展名 · 语言定义扩展名 · 语言包语言码**（[00 §〇c.2](00-整理档案.md)）—— 说明它们**不是「没主」，是「本就不该有主」**（⚠️ **旧的「VS Code 共享命名空间不改名」那段已作废，别再写**）；
4. **i18n 桶键的命名建议**（**建议不是强制**，理由 = 跨仓不可判）；
5. **迁移说明**（若某件判了改名）。

🔴 **同笔跑**：`npm run docs:build`（产物不许手改）＋ `check-author-docs-symbols`（**禁内部任务号 ＋ 正文裸 `#` 坐标**）＋ `check-author-docs-links`（出界链接白名单）＋ `check-author-docs-bilingual`（**加篇要登记 `FILENAME_MAP`**）＋ `check-reserved-names-doc-sync`（账 ↔ 两棵树双向）。

### 2.4 端到端保真（**发版后必做**）

照 L7 7.8/1.14⑧ 的既有姿势：
1. **货架保真**：真 tarball 解包核（**不是看本机 pack**）——账在包内、腿与工具**同源**、作者面两棵树在文档包内；
2. **真装一次**：临时工程 `npm i @linkdesk/plugin-sdk@latest` ⇒ **正控零偏离 ＋ 塞一条违规 ⇒ 报点带「应以 `<pluginId>.` 开头」** ⇒ **跑完 sha256 逐字节还原**；
3. 🔴 **消费者侧的闸要真合上**（记忆 `sdk-published-not-equal-enforced`）：**读消费者 `node_modules/@linkdesk/plugin-sdk/package.json` 的 `version`（不是 `npm view`）** ＋ **在消费者里塞一条它本该拦住的违规看它当场红**；
4. ⚠️ **要刷 lock 的仓用 `npm update @linkdesk/plugin-sdk`**（**`npm install` 对仍满足区间的旧 lock 是空操作**——这是"假绿"的第二个来源，实测）。

## 四、禁区

- 🔴 **不许改各件已定的判据逻辑**（本格是收口：**账 ＋ 文档 ＋ 发版 ＋ 核验**）。
- 🔴 **不许手改 `docs:build` 的产物**（产物由生成器逐字节产出）。
- 🔴 **不许 `npm publish <文件夹>`**（runbook 坑②：裸名字会被当成包规格去解析别人的包）；**必须 `cd` 进目录** ＋ 显式 `--registry`。
- 🔴 **不许用 `release:mark --allow-drift`**（会清掉别人的提醒）。
- 🔴 **不许给主题相关门禁"顺手收紧"**（[29 号档](../样式命名空间归一化/29-主题系统保护条款.md) §六）。
- 🔴 **不许引白名单 / 基线 / 棘轮**（账是**生成式 ＋ 双向对账**，不是手抄豁免表——**这条边界本格要守住**）。
- ⚠️ **上位约束**：**零 UI 变化**（除版本号；含主题/字体/翻译三条横切零回归）· 只做加法且名字一次定对 · [29 号档](../样式命名空间归一化/29-主题系统保护条款.md) 优先 · 对外宽容。
- ⚠️ **推送等用户当次点头 ＋ 带代理 ＋ 推完 `ls-remote` 对 SHA**；⛔ **撤版只能用户本人**。
- ⚠️ **提交只按路径 `git add <本格文件>`**（**禁 `git add -A`**）。
