### 1.1 冲突处理现状（两条注册路径）

| 路径 | 归属怎么来 | 出处 |
|:--|:--|:--|
| **`plugin.json` 静态声明** | **真 `pluginId`** | `src/pluginLoader/contributions/contributions.ts:65`（`registerCommand(pluginId, {...})`） |
| **运行时注册**（池 / 壳各半程） | 🔴 **`commandId.split(".")[0]`——名字第一段** | `src/core/registry/commands/CommandRegistry.ts:150`（`registerPoolCommandMetadata`）· `:186`（`registerShellLocalCommand`）· `electron/preload-pool/commands.ts:36-39`（`commandOwnerId()`，同一约定） |

**覆盖分支**（`src/core/registry/commands/CommandRegistry.ts:57-73`）：

```ts
if (_commands.has(command.id)) {                       // :58
  const existing = _commands.get(command.id)!;
  for (const [pid, ids] of _pluginCommands) {          // :62
    if (ids.has(command.id) && pid !== pluginId) {     // :63
      console.warn(`[CommandRegistry] "${command.id}" 被覆盖——原注册者: ${pid}，新注册者: ${pluginId}`); // :65
      break;
    }
  }
  existing.handler = command.handler;                  // :67  ← 覆盖照旧发生
  existing.title = command.title;
  existing.placeholder = command.placeholder;
  return () => {};                                     // :71  ← 首注册者持删除权（防误删他人命令）
}
```

⇒ **warn 只是打印，覆盖照旧**；且**删除权归首注册者**——即「后来者的注册被记住、却由别人持有删除权」，语义已经拧了。

### 1.2 🔴 本格新发现：三个**可判定的真害**（30 号档未记）

| # | 真害 | 机制 | 出处 |
|:--:|:--|:--|:--|
| **H1** | **覆盖告警会被整段吞掉** | 两个插件都**运行时注册** `acme.doThing` ⇒ 推导归属**都是 `"acme"`** ⇒ `pid !== pluginId` **恒 false** ⇒ **静默覆盖，一声不响** | `:63` ＋ `:150,186` |
| **H2** | **注销会牵连别人的命令** | `unregisterCommands(pluginId)` 按 `id.startsWith(pluginId + ".")` **整片删** ⇒ 插件 `beta` 注册的 `acme.foo` 会在**卸载 `alpha`** 时被一并摘掉 | `electron/preload-pool/commands.ts:82-87` |
| **H3** | **`on-command` 激活会去 import 别人** | 命令 handler 池内 miss 时，池按 `commandOwnerId(commandId)` **去 import 那个"属主插件"** ⇒ **名字的第一段被当成身份用** | `electron/preload-pool/commands.ts:45-61` |

> 🔑 **H1 是本轴的样板级发现**：它说明**「归属」这件事在本仓有两种表达——「表里记的」与「从名字推的」——而两者可以互相矛盾**。修法不是「把 warn 喊大声点」，而是**让归属只有一个来源，且那个来源是身份而不是名字**。

1. **同插件重注册是合法的**（`:59-61` 注释：「loader 先注册元数据（title/category/when），组件 mount 时重注册 handler……**不覆盖元数据**」）⇒ 任何"拒绝覆盖"的规则**必须先判"是不是同一个 pluginId"**；

### 2.3 存量 21 个 `explorer.*` 的裁决（**必须逐条给结论，不许含糊**）

- 若判「**漏网**」⇒ 改名方案 ＋ **代价量化**（谁引用它：`plugin.json` 的 menus/keybindings？插件源码的 `executeCommand`？**壳仓 / 其余 17 仓 / 官方目录**？）＋ **是否触碰「零 UI 变化」**。
