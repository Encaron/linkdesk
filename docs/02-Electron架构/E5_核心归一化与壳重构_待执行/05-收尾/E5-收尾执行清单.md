## 🔴 致命级 Bug 预判——盲审 + E5 历史教训

> 每个风险有精确的根因、触发条件、预防代码。**不是"注意一下"——是具体的代码防线。**

### Bug 收尾-1 🔴🔴🔴 打包后白屏——loadFile 路径差一级

**根因：** E5#23 `electron/tsconfig.json` `rootDir: "." → ".."` 后 `__dirname` 多一层 `electron/`，`../dist/index.html` 变成 `dist-electron/dist/index.html`——实际在 ASAR 根目录。

**🔥 防线：**
```typescript
// electron/main.ts:96
mainWindow.loadFile(path.join(__dirname, '../../dist/index.html'));
```

### Bug 收尾-2 🔴🔴 预览标签页替换致同 ID 碰撞

**根因：** `useTabManager.ts` L230 复用旧 tab `id`，`generateId` 基于 filePath 生成确定性 ID。旧文件再打开 → 同 id 碰撞。

**🔥 防线：** 删 `id: previewTab.id` 覆盖 + Step 4 后 ID 碰撞检测。

### Bug 收尾-3 🔴🔴 层叠上下文隔离——所有 overlay 都可能被遮挡

**根因：** App.tsx zone wrapper `position:fixed` + zIndex 创建独立层叠上下文。子元素 z-index 无法穿越。

**🔥 防线：** ContextMenu → Portal（治标）→ OverlayPortal 通用组件（治本）。

### Bug 收尾-4 🔴 initAll 半残启动

**根因：** init 链 7 步异步串行——任一步 reject → 后续静默跳过。

**🔥 防线：** `unhandledrejection` 全局监听 + App 集成测试 mock 每步失败。
