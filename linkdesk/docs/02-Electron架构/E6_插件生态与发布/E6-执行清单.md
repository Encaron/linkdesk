## 执行顺序与依赖

```
第 1 层（必须最先——地基）
  E6#1-#5: plugin-sdk                  ← 无依赖
  E6#6-#8: loader 改造 + 安装/卸载      ← 依赖 E6#1-#5
  E6#36: PluginInstallService          ← 依赖 E6#6-#8（需要知道安装/卸载流程）
  E6#31-#35: 内置插件 + 壳瘦身 + 迁移    ← 依赖 E6#6-#8 + E6#36
  E6#37: protocol.ts 路径解析           ← 依赖 E6#31（需要知道 bundled-plugins 结构）

第 2 层 ∥ 第 3 层（可并行）
  E6#9-#11: 脚手架                     ← 依赖 E6#1-#5
  E6#12-#13: dev + build 命令          ← 依赖 E6#1-#5
  E6#14: 发布入口                      ← 依赖 E6#6-#8 + E6#15

  E6#15-#16: marketplace.json + 改造   ← 无依赖
  E6#17-#19: 下载安装 UI + 搜索 + 更新  ← 依赖 E6#6-#8 + E6#15

第 4 层（第 1-3 层后）
  E6#20-#21: 测试插件设计+开发版验证    ← 依赖 E6#5(SDK类型) + E6#11(脚手架)
  E6#22: 独立构建                      ← 依赖 E6#5(SDK build)
  E6#23-#25: 生产安装全链路             ← 依赖 E6#22 + E6#17

第 5 层（全程穿插）
  E6#26-#27: 文档（随时）
  E6#28-#30: CI + 官网 + 发布清单      ← 第 1 层后
```
