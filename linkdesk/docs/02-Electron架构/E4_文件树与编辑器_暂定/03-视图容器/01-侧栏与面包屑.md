## 三、VS Code 差异

VS Code 的 Explorer 是一个 **ViewPane**（有 `ViewPane` 基类），不是普通的 React 组件。`ViewPane` 提供了：
- 视图标题栏（带 action buttons）
- 可见性切换（右键视图标题→显示/隐藏子视图）
- 拖拽视图到其他 View Container
- Context key 自动绑定（`viewVisible` / `viewFocus`）

我们的 `sidebar.tsx` 是一个扁平的 React 组件——没有 ViewPane 框架。
