## 🔴 Bug 1（严重）：loadFile 生产环境路径错误

### 位置

`electron/main.ts:96`

```typescript
mainWindow.loadFile(path.join(__dirname, '../dist/index.html'));
```

### 根因

打包后 `__dirname` = `dist-electron/electron/`（E5#23 `rootDir: "."` → `".."` 导致输出路径多一层 `electron/` 前缀）。

`../dist/index.html` = `dist-electron/dist/index.html` ❌

实际 `index.html` 在 ASAR 根目录的 `dist/` 下——需要 `../../dist/index.html`。

### 症状

生产环境（`npm run electron:build` 打包后）窗口加载失败 → **白屏**。开发环境不受影响（走 Vite dev server）。

### 修复

```typescript
// main.ts:96
mainWindow.loadFile(path.join(__dirname, '../../dist/index.html'));
```

### 验证

```bash
npm run electron:build
# 启动打包后的 exe → 窗口正常渲染，无白屏
```

### 连带风险

**E5#23 回顾：** `electron/tsconfig.json` 的 `rootDir: "."` → `".."` 是为了允许 `electron/` import `shared/types.ts`（FileEntry 类型合并）。副作用是 `package.json` 的 `"main"` 从 `dist-electron/main.js` 变为 `dist-electron/electron/main.js`，`__dirname` 多一层。

如果未来改 `rootDir` 或 `main` 字段，需重新验证此路径。

## 🟡 Bug 2（非严重）：生产环境图标路径

### 位置

`electron/main.ts:57`

```typescript
icon: path.join(__dirname, '../../build/icon.ico'),
```

### 根因

`build/icon.ico` 不在 ASAR 打包范围内。`buildResources` ≠ `files`——electron-builder 默认只打包 `dist/` 和 `dist-electron/`。

打包后 `icon.ico` 不在 ASAR 中 → `nativeImage.createFromPath()` 返回空 → Electron 使用默认图标。

### 症状

生产环境窗口图标退化为默认 Electron 图标（任务栏 + 标题栏）。仅影响美观，不崩溃。

### 修复

**方案 A（推荐）：** 在 `electron-builder.json` 中配置 `extraResources`：

```json
{
  "extraResources": [
    { "from": "build/icon.ico", "to": "icon.ico" }
  ]
}
```

然后用 `process.resourcesPath` 拼接路径：

```typescript
const iconPath = app.isPackaged
  ? path.join(process.resourcesPath, 'icon.ico')
  : path.join(__dirname, '../../build/icon.ico');
```

**方案 B：** 把 `icon.ico` 复制到 `dist/` 目录（构建脚本中做），打包时随 `dist/` 进 ASAR。但图标文件不应该在 web 资源目录里。

### 验证

```bash
npm run electron:build
# 检查任务栏 + 标题栏图标 → LinkDesk 图标，非默认 Electron 图标
```

## 🔴 Bug 3（休眠中——多 WebView 已回退）：plugin-view.html 构建入口缺失

### 位置 A：`vite.config.ts:79`

```typescript
build: {
  rollupOptions: {
    input: {
      index: resolve(__dirname, 'index.html'),
      // ❌ 缺少 plugin-view.html
    },
  },
},
```

### 位置 B：`electron/ipc/plugin-view-handlers.ts:46`

```typescript
// linkdesk:// URL 映射到错误的路径
// ❌ 按插件目录而非共享文件
```

### 根因

多 WebView 架构中，每个插件的 WebContentsView 加载 `plugin-view.html`。这个文件是**共享的壳 HTML**（所有插件 WebView 共用），不是按插件目录存放的。

两处错误：
1. Vite 构建不打包 `plugin-view.html` → 生产环境 404
2. `linkdesk://` 协议 handler 的路径映射指向了插件目录 → 找不到文件

### 症状

当前无影响——多 WebView 已回退，`pluginViews.create()` 被注释。恢复多 WebView 后：插件 WebView 白屏或加载 `about:blank`。

### 修复（多 WebView 恢复时执行）

**A: vite.config.ts**
```typescript
input: {
  index: resolve(__dirname, 'index.html'),
  'plugin-view': resolve(__dirname, 'plugin-view.html'),  // ← 加
},
```

**B: plugin-view-handlers.ts**
```typescript
// 映射到共享的 plugin-view.html，不是插件目录
const viewPath = path.join(__dirname, '../../dist/plugin-view.html');
```

### 验证时机

多 WebView 恢复时——取消 `loader.ts` 中两行 `pluginViews.create()` 注释后，立即修这两处，再验证。
