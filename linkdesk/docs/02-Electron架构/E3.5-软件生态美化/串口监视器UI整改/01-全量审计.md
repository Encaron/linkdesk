# 01 — 全量 UI/UX 审计

> 审的范围：6 个组件 · 14 个文件 · ~2,900 行代码
> 审的维度：布局 · 配色 · 图标 · 动效 · 间距 · 字体 · 无障碍 · 响应式

---

## 严重度定义

| 标记 | 含义 | 标准 |
|------|------|------|
| 🔴 | 破坏性 | 用户困惑、无法完成任务、违反硬约束 |
| 🟡 | 一致性 | 风格断裂、与系统其他 UI 不一致 |
| 🟢 | 打磨 | 不完美但功能正常、细微改进 |

## 一、ControlPanel（控制面板）

### 🔴 CP-1 — 连接状态点脉冲动画无限循环

**位置**：[ControlPanel.css:46-48](../../../plugins/user/serial-monitor/src/ControlPanel.css#L46-L48)
**当前**：`.control-dot.on { animation: dotPulse 2s ease-in-out infinite; }`
**问题**：UX 规范明确——`Continuous Animation` 仅用于 loading 指示器，不用于装饰。连接状态不是 loading，绿点持续脉冲分散注意力。
**修复**：去掉 `animation`，连接时仅静态绿色 + `box-shadow` 微光。

### 🟡 CP-2 — 选择器控件视觉扁平无层次

**位置**：[ControlPanel.tsx:113-140](../../../plugins/user/serial-monitor/src/ControlPanel.tsx#L113-L140)
**当前**：COM/波特率/协议三个 SelectBox 用 1px 竖线分隔，无背景色、无边框，完全融入命令条。
**问题**：用户难以区分"这只是文本标签"还是"可交互的下拉框"。SelectBox 是交互控件，应有可感知的可点击性。
**修复**：SelectBox 加微妙的 `background: var(--bg-input)` + `border-radius: 4px` + `padding: 2px 8px`。

### 🟢 CP-3 — 连接按钮文字 "● 打开" 用 ● 字符

**位置**：[ControlPanel.tsx:150](../../../plugins/user/serial-monitor/src/ControlPanel.tsx#L150)
**当前**：`{connected ? t("断开") : t("● 打开")}`
**问题**：● 是文本字符不是图标，在不同字体下渲染不一致。应该用 codicon `circle-filled`（已有 `control-dot` 左侧指示灯，按钮里不需要重复）。
**修复**：按钮只需文字 "打开" / "断开"，左侧指示灯已经传达连接状态。

### 🟢 CP-4 — 断开按钮 hover 变红色

**位置**：[ControlPanel.css:100-103](../../../plugins/user/serial-monitor/src/ControlPanel.css#L100-L103)
**当前**：`.control-connect-btn.connected:hover { border-color: var(--terminal-err, #EF4444); color: var(--terminal-err, #EF4444); }`
**问题**：好的交互意图——断开是破坏性操作，hover 变红警告。但 `var(--terminal-err)` 变量名暗示来自终端插件（已改名 serial-monitor），应统一为 `--danger` 或 `--serial-disconnect`。

## 二、工具栏（Toolbar）

### 🔴 TB-1 — 大量 Emoji 作为功能图标

**位置**：[index.tsx:1141-1181](../../../plugins/user/serial-monitor/src/index.tsx#L1141-L1181)
**当前**：
- `⏸ 暂停接收` / `▶ 继续接收`
- `▸ 命令面板`
- `📡 筛选`
- `🔍 搜索`
**问题**：违反 UI/UX Pro Max 硬规则——"No emojis as icons (use SVG: Heroicons/Lucide)"。Emoji 在不同 OS 渲染不同（Windows 彩色、macOS 扁平、Linux 缺失），破坏跨平台一致性。LinkDesk 已有 codicon 字体系统（`codicon codicon-xxx`）。
**修复**：全部替换为 codicon：
- ⏸ → `codicon-debug-pause`
- ▶ → `codicon-debug-start`
- 📡 → `codicon-filter`
- 🔍 → `codicon-search`
- ▸ → `codicon-terminal`（或去掉命令面板按钮——见 TB-2）
- 导出日志 → `codicon-export`
- 清空 → `codicon-clear-all`

### 🟡 TB-2 — "命令面板" 按钮不该在工具栏

**位置**：[index.tsx:1144-1146](../../../plugins/user/serial-monitor/src/index.tsx#L1144-L1146)
**当前**：`<button onClick={() => window.dispatchEvent(...)}>▸ 命令面板</button>`
**问题**：VS Code 的命令面板是 `Ctrl+Shift+P` 键盘快捷键，不在终端工具栏里。这个按钮属于"帮助用户发现功能"的临时措施，放在工具栏里占空间且语义不匹配。
**修复**：移除工具栏按钮。命令面板入口在标题栏 ☰ 和快捷键已足够。

### 🟡 TB-3 — `transform: scale()` 在 hover/active 导致布局抖动

**位置**：[index.css:83-88](../../../plugins/user/serial-monitor/dist/style.css)（源文件 `SerialMonitorView.css`）
**当前**：`.toolbar-btn:hover { transform: scale(1.02); }` `.toolbar-btn:active { transform: scale(0.97); }`
**问题**：`scale()` 放大 2% 会推动相邻按钮，产生视觉抖动。且没有 `@media (prefers-reduced-motion)` 适配。
**修复**：去掉 `transform: scale()`，仅用 `background` 和 `color` 变化反馈。如有需要，用 `outline` 或 `box-shadow` 做视觉强调。

### 🟡 TB-4 — 工具栏按钮缺少 `:focus-visible` 样式

**位置**：[index.css:69-94](../../../plugins/user/serial-monitor/dist/style.css)
**当前**：`.toolbar-btn` 只有 `:hover` 和 `.active`，无 `:focus-visible`。
**问题**：键盘 Tab 导航时，看不到焦点在哪个按钮上。
**修复**：加 `&:focus-visible { outline: 2px solid var(--accent); outline-offset: -1px; }`
