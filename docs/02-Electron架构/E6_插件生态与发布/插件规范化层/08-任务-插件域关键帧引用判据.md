## 二、要做（**四步，缺一即半成品**）

### 第一步：SDK 腿新增判据 `packages/plugin-sdk/src/eslint/checks/keyframe-refs.ts`

照 `checks/selector-form.ts` 的**既有形态**写（它是 1.26 刚落地的最近样板：`collectCssUnits` 采集 → 判据 → `CheckViolation[]` → `isDisabled` 知情绕行 → fail-closed）。

**允许集 = 三条并集**（🔴 这三条是**本格的裁**，别再推倒重来）：

1. **本仓被扫描 CSS 里的 `@keyframes` 定义** ← 主集（1.3 的三对就是这个形态）；
2. **宿主保留账** `schemas/reserved-class-names.json#keyframes`（8 条，见 §1.4）—— 它是**已登记的公共面**，插件引用它属于合法消费；
3. **同批扫描到的其他 CSS 单元里的定义** —— 覆盖「随仓携带的三方 CSS」（`node_modules` 与 `dist` 已被 `scan.ts` 的 `SKIP_DIRS` 排掉，所以这说的是被作者放进 `src/` 的 vendored 文件）。

**明确不做的四件**（防越界 —— 这些是别的判据或别的轴的活）：

- ⛔ **不判前缀**（「关键帧名必须 `<pluginId>-` 开头」是 `plugin-prefix.ts` 判据②的活）；
- ⛔ **不判「该不该引用某一个名字」**（只判**悬空**，不判意图 —— 照 S2/S3 的既有纪律：**管形态、不管意图**）；
- ⛔ **不判「引用了别的插件的关键帧」**（跨仓不可判 ⇒ 连黄灯都难，别顺手做）；
- ⛔ **不给「泛词清单／白名单」兜底**（手抄表必腐烂 —— 这是 CSS 系列反复否决过的形态）。

**名字抽取口径**：🔴 **必须与壳侧 `scripts/lib/css-selectors.mjs:255-274` 的 `animationRefs()` 同源**。跨包**不能 import** ⇒ 照本仓既有的跨包口径做法：**用自测锚（锚词）把两份钉在一起**（先例：1.24 的 `judgeTokenScope()` 与 SDK 那份由自测锚⑦ 钉文案；1.26 的选择器形态由锚⑧ 钉）。⇒ **本格新增锚⑨**，锚词取 `ANIMATION_KEYWORDS` 的一条 ＋ 那句「跳过 `--*`」的理由文案。

**fail-closed**：拿不到 `pluginId` 或 CSS 单元 ⇒ 照 `selector-form.ts` 既有纪律（**静默放过 = 门禁变瞎子**）。
