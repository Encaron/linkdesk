## 一、定位与用户故事

用户原话（2026-10-04）：「如果我们制作了 pdf 阅读器插件，那么以后文件树的 pdf 文件被单击时打开方式就是 pdf 阅读器插件；退回路径则是卸载或没装时继续默认以编辑器打开——类似 VS Code，它甚至会在 toast 提示我应该装一个 vscode-pdf 插件。」
定位补全（2026-10-07）：本插件是**辅助型阅读插件**，与编辑器插件同类——**官方插件市场的示例插件之一**（示范「一行声明接管文件类型」的完整写法），**不进出厂种子**，走市场安装、「装了才接管」即验收。

## 二、贡献什么（声明面，全部现成机制）

| 声明 | 作用 |
|:--|:--|
| `contributes.fileAssociations: [{ "extension": "pdf", "displayName": "PDF" }]` | **接管单击与 OS 打开方式**：文件树单击、Windows「打开方式→LinkDesk」都经壳的 `FileAssociationService` 解析到本插件。⚠️ 字段口径（role 是否填、displayName 必填否）以 T1 时现装 SDK `plugin.schema.json` 为准——`distribution` 是**废弃字段勿填**（03-插件制造 06 §对账） |
| `contributes.commands` | `pdfReader.*` 命令族进命令面板——**AI 友好化是本插件硬要求**（见 §六-5），不是可选项；随 M1 功能同棒上（无死代码） |
| `contributes.i18n` | 自有字典 `i18n/en.json`（谁的仓谁译文，E6#161 口径） |
| `icon: "resources/icon.svg"` | **商城展示图标**——标签栏（`appearsIn.tabBar`）、市场列表、打开方式选择器、README 说明区多处展示；⛔ **无图标栏贡献**（不做 `appearsIn.iconBar`／侧栏视图——辅助型定位） |
| 无菜单贡献 | 不往文件树右键加项（「打开方式」选择器是壳侧通用能力，不需要每家自己写） |

## 三、打开逻辑（链路）

单击／OS argv → 壳解析（`fileAssociation.getPluginFor("pdf")`）→ `tabs.create("pdf-reader", { sourceId: filePath })` → 插件 entry 收 `filePath`（同 editor 的 sourceId 单通道口径）→ `window.linkdesk.filesystem.readBinaryFile` 拿字节 → pdf.js 渲染。**全程不碰壳、不碰文件树、不碰编辑器。** 可视化 = [04-流程图.html](04-流程图.html) 下半幅。

## 四、引擎选型（定案）

**pdf.js（`pdfjs-dist`）——2026-10-07 复核三竞品后维持定案**：tomoki1207/vscode-pdfviewer（元老，pdf.js）、mathematic-inc/vscode-pdf（2.7M+ 安装，"powered by the latest pdf.js"）、AdamRaichu/vscode-pdf-viewer（web 兼容轻量）——**三个 vscode 竞品全部基于 pdf.js**，方向无争议。文本层可划选复制、页内搜索、缩略图/目录全自绘；Mozilla 维护、生态熟；体积 ~1–2 MB（Monaco 先例在，editor 连它都打包，bundle 体积不是门槛）。⚠️ worker 文件随包走通 vite 打包 = T2 专项判据。

| 方案 | 结论 |
|:--|:--|
| Chromium 内置 PDF | **否**：池渲染进程沙箱/CSP 下 iframe 指向 `file://` 的行为未验证；UI 不可定制；文本层不可控；等于把产品押在一个赌不上桌的机制上 |

## 八、依赖与边界

- **对壳零硬依赖**——fileAssociations 机制已在跑（壳 ≥0.2.32），`minAppVersion` 按现装壳定。
- **多只 pdf 阅读器共存（微软/Adobe/第三方都会来）**：默认裁决全部在壳（覆盖表＋选择器＋第二只装上不静默漂移）——本插件零「争默认」逻辑。
- **不做**（v1 冻结；编辑/涂鸦、保存、打印、手势、打开资源管理器 = M4 后续升级点，见 §五）：编辑/另存 pdf；pdf 转文本之类内容提取面；向壳申请任何新通道（readBinaryFile 现成）；右键菜单贡献（v1）；**「仍旧以本插件强开」兜底钮/命令**（editor 的 forceOpenAsText 是文本兜底角色自有动作，pdf 无此角色——2026-10-07 拍板；错误态照 editor `BinaryNotice` 同款走「打开方式…」＋「在市场搜索阅读器」两颗探测接线钮，范本 = editor 仓 `src/components/BinaryNotice.tsx`）。
