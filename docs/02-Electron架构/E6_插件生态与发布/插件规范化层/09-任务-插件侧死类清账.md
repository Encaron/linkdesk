## 〇、🔴 为什么这条值得单独立一格

**它不是"清垃圾洁癖"，是 1.24 已经真的咬过一次的同一类伤。**

1.24（`#109n-b`）当时的经过：token 挂在**三个**自有根类之下，其中第三个 `.serial-monitor-sidebar` 看着一切正常 —— **实机一测才发现那个类在 DOM 里根本不存在**，于是侧栏状态点的颜色被**静默丢掉**，当场修正重发（`1.0.16`）。⇒ **死类不是"无害的冗余"，它是一个会静默吃掉功能的挂载点**：写的人以为自己在给某块 UI 定样式，实际那行 CSS 永远不会生效，**而且不报错**。

那轮只逮到 1 处（还是靠实机撞上的）。本格把它**系统性重数了一遍**：**10 处 / 3 仓**（§1.1），其中**第 10 处正是 1.24 那条警告指着的那一个**（`.serial-monitor-sidebar` 的规则本体 —— 1.24 只把 token 从它身上挪走了，规则本身留到了今天）。
