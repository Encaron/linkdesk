## 插件列表

### 工作台

> 卡片网格仪表盘——嵌入式/IoT 场景用。

`react-grid-layout` 拖拽式卡片布局。内置 5 种卡片类型（仪表盘/滑块/数值/折线图/开关）。第三方可注册新卡片类型。

**谁用：** 串口/I2C 数据可视化——温度、速率、波形。不是所有人需要。

**文档：** `插件_工作台与OLED_暂定/00-README.md`

### OLED 模拟器

> Canvas 逐像素渲染 128×64 OLED 屏幕。

I2C 数据 → 主进程 → Canvas `requestAnimationFrame` → 逐像素渲染。照抄 E1 串口服务模式。

**谁用：** 嵌入式开发——有 OLED 硬件，需要在电脑上看屏幕当前画面。

**文档：** `插件_工作台与OLED_暂定/00-README.md`（同目录）

### AI 助手

> 内嵌 AI 对话 + 代码补全——对标 VS Code Copilot Chat。

侧栏对话界面 + Monaco 内联建议。支持 Anthropic / OpenAI / DeepSeek / 本地模型。`iconLocation: "bottom"`，对标 Copilot 的位置。

**谁用：** 需要 AI 辅助的用户——不是所有人都想装 AI。

**文档：** `01-AI与智能体.md`

### 智能体（Agent）

> AI 助手升级版——自主执行任务。

工具调用权限：读文件 / 写文件 / 执行命令 / 搜索代码 / 读配置。走用户确认（Allow / Deny / Always Allow）。最大步数 + 超时限制防失控。

**谁用：** AI 助手用户进阶——让 AI 自主改代码。

**文档：** `01-AI与智能体.md`（同文件——Phase 2 部分）

## 为什么独立发布

| 内置（壳版本） | 官方插件（Marketplace） |
|------|------|
| 所有人大概率需要 | 特定人群需要 |
| 随壳更新 | 独立版本号 |
| 卸载 = 功能缺失 | 卸载 = 用户不需要 |
| 例：Git、终端、菜单 | 例：工作台、OLED、AI |
