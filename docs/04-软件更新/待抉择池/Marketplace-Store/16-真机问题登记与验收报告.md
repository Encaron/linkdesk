**① 单层呈现的实现（F14 配方组成部分）**
- 选项 A：本体退场——hover 时被盖住的重复本体 `visibility:hidden`
- 选项 B：展开层完全不透明盖死
- **推荐：双保险都上（A＋B）**。理由：玻璃主题下 B 单独用需要把不透明度调很重（破坏玻璃质感）；A 单独用在展开层几何小于本体时会露边；两者都是 CSS 级成本，叠加后任何主题都稳。

**② 浮起面配方 token 的名字与归属（F14 平台案）**
- 选项 A：`--ldk-pop-surface / --ldk-pop-blur / --ldk-pop-border / --ldk-pop-shadow`，住 `@linkdesk/ui`（插件可消费）＋壳 ThemeEngine 同名镜像

- **推荐：A**。理由：平台方案的本意就是给所有自绘作者用——私有 token 等于下一个作者又没得用（回到本末倒置）；`ldk-` 前缀符合共享件惯例（硬约束 23：ldk- 属宿主）；壳同款＝全软件一致。

**③ ⋯ 菜单的实现路线（F21）——✅ 已定稿（2026-11-21 用户裁决：用共享 ContextMenu）**
