## 一、命令面板（Ctrl+Shift+P）

| # | 操作 | 预期 |
|:--:|------|------|
| 1 | **Ctrl+Shift+P**（任意位置） | 面板出现，搜索框自动聚焦 |
| 2 | 面板打开→**不输入任何搜索词** | 列出所有已注册命令（15+），每条右侧灰色 category 标签 |
| 3 | 输入「**清空**」 | 出现「清空接收区」「清空发送区」 |
| 4 | 搜索「清空」→**回车** | 命令执行，面板关闭，接收区清空 |
| 5 | 输入「**终端**」 | 所有 terminal 命令出现（按 category 搜索） |
| 6 | 输入「**xyz123**」 | 列表为空 |
| 7 | 面板打开→**点面板外空白处** | 面板消失 |
| 8 | 面板打开→**Esc** | 面板消失 |
| 9 | 面板打开→**ArrowDown** 3次 | 第3项高亮 |
| 10 | 输入搜索词→ArrowDown→**改输入词** | 选中重置为0 |
| 11 | 切换到**非终端标签页**→Ctrl+Shift+P | 面板仍能打开（keep-alive） |

| 17 | 搜索「行号」→回车 | 行号显示切换 |
