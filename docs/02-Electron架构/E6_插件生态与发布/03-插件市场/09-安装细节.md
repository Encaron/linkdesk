# 安装细节——绿色按钮背后

> 对应任务：E6#30.9。用户 2026-08-29 拍板「意义也很大」。
> 文档归属：市场设计文档族（[03-市场交互设计.md](03-市场交互设计.md) = 总览索引）。
> 安装不只在成功时是按钮——进度、失败、断网、多窗一致都是第一站体验。

## 一、下载进度（E6#30.9a）
- 详情页 🟢安装按钮内显示进度（下载中 → 百分比/动画 → 完成）。
- 依赖 E6#13 IPC handler 进度事件 + E6#31 下载（`fetch(downloadUrl)` → ArrayBuffer → 进度）。

## 二、失败 / 重试（E6#30.9b）
- 下载中断、校验失败 → 明确失败态 + 「重试」按钮（不是转圈装死）。
- 断网 / 源不可达 → 失败态 + 区分「网络问题」提示（国内访问 GitHub 可能慢/不稳——Gitee 源可缓解，见 [01-GitHub-Releases方案.md](01-GitHub-Releases方案.md) §六 多源）。

## 三、装完体验
- 装完 toast + 状态自动切换「禁用/卸载」（E6#30.5c 已有）。

## 四、多窗口即时一致（E6#30.9c）
- **E5.8 跨窗事件联动现成能力**——市场装完，其他窗口的侧栏/详情立即同步，**零新 API**（本项 = 验收项，不是开发项）。

## 五、toast 反馈——插件自调，零新 API（E3j#76）
> 顶部横幅禁用（用户拍板：把整个 UI 往下推 + 影响性能）——一切事件反馈走右下角 toast。视觉 = mockups/02 帧 2/3/7。

- 进度 / 失败 / 缺依赖 / 装完成功 toast **全由市场插件自调** `window.linkdesk.notifications.show(msg, { type, progress })`（四方法 show/update/finish/cancel，IpcBridgeHandler/ui.ts，E3j#76 已实现）——插件自己决定显示什么，壳零改动、零新 API。
- **进度**：`show(msg, { progress: true })` → `handle.update("正在安装… 62%")` 循环改文字 → `finish(msg)` 收尾（图形进度条 UI 留未来，API 面已现成）。
- **失败**：`show("安装失败：…", { type: "error" })` + toast 内 [重试] 主动作；**缺依赖**：`show("无法安装：缺少依赖 …", { type: "warning" })` + [查看依赖]；**装完**：`show("已安装：X", { type: "info" })`（lifecycle onDidInstall 先例同款）。
