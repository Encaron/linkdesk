# 05 — 插件更新

> 2026-09-13 重组定案：原「05-版本更新/官方插件」+「04-出厂制造」留下的插件档案 + 拆出的终端系统/Git 合并至此，改名 **插件更新**。
> **分类退役**：不再有「官方插件/市场插件/内置插件」之分——plugins 目录已铺平，大家都只是普通插件，区别只有 `core:true`（**仅 UI 上禁止点击卸载**，防新手把设置等删了没地方点回来；命令行/工程手段不受限，高手随意，甚至可以自己再做一个设置插件）。
> 软件本体的更新归 [`../04-软件更新/`](../04-软件更新/)。

## 一、每个插件只更新自己

- **版本号各插件独立**（各自 package.json 的 semver），不占软件版本号；插件补丁档案（如 文件树 `FT#` 清单）就是该插件的进度真相源。
- **开发工作流（2026-09-14 起为现行规矩，E6 第 7 层判据先立）**：插件**源码真相源 = 插件自己的 GitHub 仓库**（`Encaron/linkdesk-plugin-<id>`），壳仓只留构建产物（`bundled-plugins/` 出厂种子快照）与文档档案（判据五条 → [`../03-插件制造/09-插件目录规范.md` §源码位置与分发物的关系](../03-插件制造/09-插件目录规范.md)）。单个插件的新版本在仓外独立工程目录开发（布局 → [../03-插件制造/15-多仓开发与本地工作区.md](../03-插件制造/15-多仓开发与本地工作区.md)），直接装到安装版上实测，不必回本仓库全量构建。每只插件单独建仓、单独写文档；本目录只留「这个插件想往哪更新」的档案，不承担开发目录。
- ✅ **源码物理搬迁已完成（2026-09-14，E6 第 7.2 轮）**：18 只发货插件源码已外移各自独立仓并推送；壳仓 `plugins/` **今日已空**（历次开发夹具均已下架，仓内不再存放任何插件源码）。**整层已于 2026-09-14 全层封层**（七条判据 ＋ 四本账 ＋ 回归对照 ＋ 作者面三档计时全跑完）——总账与全部实测读数 → [`../02-Electron架构/插件生态与发布/插件源码外移层/08-全层验收.md`](../02-Electron架构/插件生态与发布/插件源码外移层/08-全层验收.md)。
- **出厂随包只装 6 只基础插件**（设置 / 插件市场 / 语言 / 基础主题 / 文件树 / 编辑器；判据 =「断网、零插件时用户能不能自救」）。**其余（含串口监视器、Python、各主题）走市场按需安装**——都在官方目录里，卸了随时装得回来。谁随包由账 `bundled-plugins.lock.json` 的 `seed` 字段声明（**数据，不是代码**），新鲜度由门禁 `check-bundled-freshness` 守。
- 🔴 **CHANGELOG 体积纪律（2026-10-01，E6#164 拍定）**：插件仓的 `CHANGELOG.md` **照旧全量保留**（它是历史真相源，只治**分发面**）；**分发面**（市场目录 `versions[].changelog` ＋ zip 内 `CHANGELOG.md`）由 SDK 打包时**自动只带最近 N = 5 版**（`CHANGELOG_WINDOW`，判据一处）——**作者零声明、零改动，⛔ 也不给插件作者写这条口径**（用户拍板：非「插件制造」内容不进作者文档，污染他们的文档）。**收敛逐插件、逐次发版发生**：每只插件**下次发版**时它自己那条历史才变薄，存量 zip 与目录条目一字不动（⛔ 不做整档重写）。设计与实测读数（17 仓 CHANGELOG 198.7 → 90.6 KB、目录条目 158.0 → 83.9 KB）→ [15 号档](../02-Electron架构/插件生态与发布/01-插件独立构建/15-变更日志膨胀与分发面裁剪-立案与设计前置.md)。**✅ 已实测（2026-10-01，五只随包插件真发一版 · 用户授权）**：包内 `CHANGELOG.md` 各 **5 段**（官方主题 8,717→6,726 · 文件树 52,545→47,346 · 设置 37,647→30,434 · 编辑器 8,655,235→8,653,942 · 市场 78,734→61,986 B）· 目录 `versions[].changelog` 带正文各 **5 条**（版本行 11/16/19/8/26 **全留**，回装旧版不受影响）· 出厂种子 ＋ 官方目录同笔刷新（**壳侧 `src/` `electron/` 零改动**）。`lang-defaults` 未在本批（**并发会话在飞**），其 1.0.41 由该会话发布、包内实测亦 5 段 ⇒ **随包 6 只无缺口**。**第二批（同日，用户「都可以发版一次」）**：其余 9 只官方仓同法发版（python 1.0.9 · serial-monitor 1.0.31 · 七只主题 1.0.8/1.0.9/1.0.10），包内各 5 段、目录带正文各 5 条（serial-monitor 172,953→160,645 B）⇒ 🏁 **官方 16 仓全部收敛完毕**（目录里再无官方条目的历史散文超 5 版）。
