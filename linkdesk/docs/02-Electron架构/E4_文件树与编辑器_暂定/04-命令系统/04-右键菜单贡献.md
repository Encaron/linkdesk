## 二、菜单结构

```
MenuId.FileContext
├── 1_navigation
│   ├── 打开          (explorer.openFile, when: explorerItemIsFile)
│   ├── 在侧边打开     (explorer.openToSide, when: explorerItemIsFile)
│   ├── 打开方式…     (explorer.openWith, when: explorerItemIsFile)
│   ├── 在文件管理器中显示 (explorer.revealInOS)
│   └── 在终端中打开   (explorer.openInTerminal, when: explorerItemIsDir)
├── 2_editing
│   ├── 剪切          (explorer.cut, when: !explorerItemIsRoot)
│   ├── 复制          (explorer.copy, when: !explorerItemIsRoot)
│   ├── 复制路径       (explorer.copyPath)
│   ├── 复制相对路径   (explorer.copyRelativePath)
│   └── 粘贴          (explorer.paste, when: explorerItemIsDir && !explorerClipboardEmpty)
├── 3_creation
│   ├── 新建文件       (explorer.newFile, when: explorerItemIsDir || explorerItemIsRoot)
│   └── 新建文件夹     (explorer.newFolder, when: 同上)
├── 4_modify
│   ├── 重命名        (explorer.rename, when: !explorerItemIsRoot)
│   └── 删除          (explorer.delete, when: !explorerItemIsRoot)
├── 5_search
│   └── 在文件夹中查找 (explorer.findInFolder, when: explorerItemIsDir)
└── 6_compare (空——留给 Git 插件注入)
```

## 三、菜单注入机制

**Git 插件示例：**
```typescript
registerMenuItems(MenuId.FileContext, "git", [
    { command: "git.stageChanges", group: "6_compare", when: "explorerItemIsFile" },
    { command: "git.revertChanges", group: "6_compare", when: "explorerItemIsFile" },
]);
```

**圆形大厅原则：** 文件树不知道 Git 存在。Git 在 `MenuId.FileContext` 上注册自己的菜单项——`ContextMenu` 组件统一渲染、`ContextKeyService` 统一求值 when 条件。

## 四、AI 进场须知 🛡️

- **分组号决定顺序**——同组内按注册顺序排列
- **when 条件走 `ContextKeyService.matches()`**——支持 `&&` / `||` / `!`
- **`explorerClipboardEmpty` context key 待 #26 接入**
- **`activateFileTreeContextMenu()` 幂等**（`_registered` guard）
- **右键前先选中**——对标 VS Code：右键的项不在当前选中集合 → 自动切单选中。`sidebar.tsx` `handleContextMenu` 已做
