# E5.8#186 插件详情页文字可复制档案

> 2026-08-29。用户提出：「插件详情的介绍页所有东西都应该可以复制，你怎么认为」→ 讨论后拍板：**内容全可复制，交互件不复制**。

## 一、原因（机制）

- 全局 `user-select: none`（[index.css:198](../../../../../src/index.css#L198)，html/body/#root/#pool-root）——壳 UI 文字默认不可选中，防误选。
- 白名单仅两条「可带走的信息」：`.dialog-host-message`（DialogHost.css:53）+ `.toast-message`（ToastHost.css:111）。
- 插件详情页整页无白名单 → 名称/版本/作者/描述全不可选中；其中侧栏「标识符」（[PluginDetailPoolView.tsx:171](../../../../../src/pool/views/plugin-detail/PluginDetailPoolView.tsx#L171) mono 等宽）最该可拷，现在只能手抄。

## 二、改法（拍板边界）

`PluginDetailView.css` 单文件，零 TS：

- `.plugin-detail` 容器 `user-select: text`——详情页=内容页，对标 VS Code 插件详情页：正文可选中、按钮不选中。
- 交互件/装饰回 `user-select: none`：`.pd-btn`（启用/禁用/卸载）/ `.pd-navtab` / `.pd-icon-container`（含 96px 占位图标 + 内置徽标）/ `.codicon`（按钮/提示条内图标字形不参与选中）。
- `.plugin-detail-empty`（「插件 xx 未安装」空态，含插件 ID）`user-select: text`。
- 零视觉变化（交互属性，非样式 token，无新配置/API）。

## 三、验证

- `npm run check` 全绿。
- CDP/实机：详情页拖选名称/描述/标识符变蓝 + Ctrl+C 可复制；按钮/标签页拖选无效。

## 四、执行注

- commit 见执行清单 #186 ✅ 行（E5.8#186 插件详情页文字可复制）。
- 契约提醒：容器级开 `text` 后，**未来新增交互件须补回 none**（清单：按钮/标签页/图标容器）。新增正文自动可选中，无需再开。
