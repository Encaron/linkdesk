# 壳版本 — 路线图

> **类型：壳级别** | 2026-07-24 → 2026-07-28 重组。**改壳代码才发版。内置插件随版本一起出——所有人标配。**
> 悬浮窗系统（原 04）和 Marketplace 增强（原 05）已迁移到 [04-出厂制造](../../04-出厂制造/)。

---

## 一、版本号规则

```
MAJOR.MINOR.PATCH
  1  .  2  .  3
```

**LinkDesk 对标 VS Code + Obsidian 模式——1.x 长期维护，MAJOR 极难触发。**

| 位 | 触发条件 | 预计频率 |
|:--:|------|:--:|
| **MAJOR** | 架构级变更——插件 API 不兼容、数据格式不兼容、IPC 协议重写 | **5~10 年一次** |
| **MINOR** | 壳新增能力——新 preload API、新面板区域、新内置插件 | **功能做完就发** |
| **PATCH** | 纯修复——Bug 修、性能优化、安全补丁 | **修好就发** |
